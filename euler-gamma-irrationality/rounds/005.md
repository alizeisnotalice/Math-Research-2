# 第 5 轮 · 符号证书与有间隔首项引理

2026-11-25 · 欧拉常数无理性

**有限符号。** 令 x=16t。对 [32,64] 饱和基的两支向量，去掉尾端零项后多项式 P(x/16) 的次数都为 31。对幂基作整数 Bernstein 变换：第 j 个系数乘上公共正因子 m!16^m 后为 Σ_{k≤j}a_k16^{m−k}binom(j,k)m!/binom(m,k)。递归二等分用 de Casteljau 整数加法；同号 Bernstein 系数严格确定区间内部符号，端点独查。两支在 0<x<1 上的零点数都是零，第一支严格负、第二支严格正。这从积分本身独立复核第 2 轮的符号。第 3 轮长度下界同时适用于这两支，故未得到趋零序列。执行 python -B computation/formal/signs.py，输出 [signs.json](../computation/formal/signs.json)。

**有间隔的首项。** 固定 0<δ<1，取整数向量支撑在 {N}∪[N+⌈δN⌉,2N]，v_N≠0。若沿无穷块 Ev=0 且 log||v||₁=o(N)，则 γ 无理。证明：在 0<t≤1/16 上，用首项 |v_N|d_{2N} 作单位，余项至多
\[
\|v\|_1\max_{j\ge N+\lceil\delta N\rceil}
  (d_{2j}/d_{2N})16^{-(j-N)}.
\]
由素数定理 log d_m=m+o(m)，在 N≤j≤2N 上一致有 log(d_{2j}/d_{2N})=2(j−N)+o(N)。故上式 ≤ exp(−(log16−2)δN+o(N))，最终小于 1。整个多项式与首项同号，原积分严格非零。又 |R|≤2^{-N}||v||₁→0，反证完成。第一轮的抽屉原理在删去间隔后的线性多个列上仍给出短核向量；它可能在指定首坐标取零。由此得到一个只涉及整数的缺失命题：短核能否在指定单坐标上非消失。取 δ=1/4 作为固定待验目标。

**该策略也受整除约束。** 在 N+1 为奇素数的无限族，其对应行首列为 2d_{2N}H_N（区间 (N,2N] 只有一个 N+1 的倍数）。取 L 为 (2N,2(N+⌈δN⌉)] 内的素数乘积。尾部各列的对数系数都被 L 整除：每个这样的素数大于 j 且不超过 2j，只进入 d_{2j}，不会被分母至多 j 的调和数消去。因此 L/gcd(L,d_N H_N) 整除 v_N。分母 d_N 和 2d_{2N} 与 L 互素，且 log(d_N H_N)≤N+o(N)，log L=2δN+o(N)。若 δ>1/2、v_N≠0，则 log|v_N|≥(2δ−1)N+o(N)。这严格排除了该素数族上“大于半块的间隔 + 次指数长度”这一组合；δ=1/4 的问题仍在。本轮推导基于 Sondow 权重，未主张首创性。

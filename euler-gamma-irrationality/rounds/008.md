# 第 8 轮 · 混合 Laguerre 取值的素数偏移障碍

2026-11-25 · 欧拉常数无理性

取 [Van Assche–Wolfs 命题 2.5–2.6](https://arxiv.org/html/2404.09799v3)，x=1，整数化 D=n!d_n。记 U_r=r!F_{r;2}(1)=Σ binom(r,s)²binom(r+s,s)r!/s!。在第 7 轮的相同条件 p≥7、n=p+r、2r+1<p 下有
\[
 Q_n/d_n\equiv2U_r,\qquad P_n\equiv5(d_n/p)U_r\pmod p .
\]
证明：使用第一轮导数单和，分子权重相比 F₂ 的乘子是 4H_k−2H_{n-k}−H_{n+k}。当 k<p，n!/k! 含 p，d_n 又含 p，调和数至多损失一个 p；所以该段分子模 p 及分母除 d_n 后模 p 均消失。当 k=p+s、0≤s≤r，Lucas 同余使两个二项因子分别成为 binom(r,s)²、2binom(r+s,s)，而 n!/k!≡r!/s!。调和乘子的 p 倍模 p 是 4−0−3/2=5/2。逐项累加得到结论。固定 r 后 U_r 为正整数，故对充分大的素数 p，v_p(Q_n)=1，v_p(P_n)=0。特别是“在 n=p 处取值后必额外约去 p”的猜想失败。

**统一尺度。** 混合型及 Rivoal 均取 n!d_n 作共同乘子；Rivoal 递推保留原初值 −1,4,77/4 与 1,7,65/2。该改进整性见 [Hessami Pilehrood，推论 5](https://arxiv.org/pdf/1004.0578)。1≤n≤64 与技能脚本分别交叉核对。混合型的 170 个素数偏移算例吻合同余（2 项 U_r≡0）。n=64 的混合型、Rivoal 约分分母位长分别为 498、440，约分形式分别约 +1.24×10^115、−1.27×10^104，严格端点见数据。用混合型文献上界乘约分分母后仍是 O(n!d_n n^(−9/8) exp(sqrt(n)/2)/g_n)；当前局部同余不给出消去此阶乘的公因子下界。无限子列的非消失同样未证。

复现：分别运行 python -B computation/formal/valuations.py mixed、参数 riv，再运行 python -B computation/formal/check_skills.py mixed riv。见 [混合型](../computation/formal/mixed.json) 和 [Rivoal](../computation/formal/riv.json)。

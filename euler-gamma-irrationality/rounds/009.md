# 第 9 轮 · 两条 Meijer G 轨迹的整数化比较

2026-11-25 · 欧拉常数无理性

检验 Kalisch 等 [arXiv:2610.13919v1，定理 1–3 及 §§6–8](https://arxiv.org/html/2610.13919v1)。源点为零，取 (0,0;1,1,1) 和 (−1,0;1,1,1)，都在作者 r=3 的已证轨迹参数族内。状态行取 (G,θG,θ²G)，在 z=1 用三阶微分方程消去 θ³。上参数降低一步对应 θ+1−a，下参数升高一步对应 b−θ。每次移位更新参数后再乘下一个矩阵；保留原状态基，无需 CVM 换基。

记步矩阵为 M(j)，整数对偶为 D=s M(j)^(-T)。基准轨迹 det M=(j+1)^6，s=(j+1)^4；第二条 det M=8(j+1)^6(2j+1)^3，s=8(j+1)^4(2j+1)^3。在所有非负整数 j 上均正，已符号验证 M Dᵀ=sI。行投影 u=(1,1,0)、v=(1,1,1)，列投影 e₁；原点定理给出 u·S=γ、v·S=1。

关于文献的泛型前提：取原系统三支渐近解为基本矩阵的行，第三行为强次优势解 S。其逆转置的各行给出相应的对偶基；e₁ 作为初值行在第三支对偶方向上的坐标为 S(0)·e₁=G(1)。此值严格正：原点 G 的 Mellin 变换 Γ(s)^3Γ(1−s)^2 在 0<Re s<1 上分解为 Γ(s) 与两份 Γ(s)Γ(1−s)，对应 e^(−x) 与两份 1/(1+x) 的乘法卷积，在 x=1 为正。依原文定理的泛型条件与对偶极限识别目标；该极限给出最终非零分母。前 32 步的具体投影分母逐项另验。

两条轨迹 n=1,2 的约分对依次为 (4/7,115/198)、(4/7,23611/40896)，前者的 32 项与技能脚本原始系数完全一致。n=32 的约分分母分别有 199、436 位（二进制），约分后形式约为 +5.23×10^42 与 −8.79×10^108。有限例未显示第二轨迹在整数形式上取得收益，未推出渐近劣势或无理性。执行 python -B computation/formal/cmf.py（SymPy），再执行 python -B computation/formal/check_skills.py cmf，见 [矩阵与精确端点](../computation/formal/cmf.json)。

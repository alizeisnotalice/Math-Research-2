# 第 7 轮 · Aptekarev 素数偏移同余

2026-11-25 · 欧拉常数无理性

沿用 [Hessami Pilehrood 二人，推论 4](https://arxiv.org/pdf/1010.0429) 的整数对 P_n,Q_n。置 w_k=binom(n,k)²(n+k)!。分子为 Σw_k(H_{n+k}+2H_{n-k}−2H_k)，分母为 Σw_k。文献给出 |P_n−γQ_n|~cT_n，其中 c>0，T_n=(2n)!n^(−1/4)exp(−sqrt(2n))。因此沿子序列获得非零趋零形式，当且仅当 limsup gcd(P_n,Q_n)/T_n=∞。

**素数偏移引理。** 取素数 p≥7，n=p+r，0≤2r+1<p。则
\[
 Q_n/p\equiv-Q_r,\qquad P_n\equiv-3Q_r\pmod p .
\]
在 k≤r，Lucas 同余给出 binom(n,k)≡binom(r,k)。Wilson 同余给出 (p+r+k)!/p≡−(r+k)!。三项调和数乘 p 后分别贡献 1、2、0。对 r<k<p，二项系数含 p；对 k≥p，阶乘至少含 p²。全程 n+k<3p<p²，调和数至多损失一个 p，故这些项在两个同余中均消失。求和即证。

对固定 r，除去 Q_r 的有限个素因子，最终每个 p 都满足 v_p(Q_{p+r})=1、v_p(P_{p+r})=0。因此该 p 留在约分分母中。这个局部障碍只给出一个因子 p；log p 的收益或损失距 log T_n 的 n log n 量级很远。它不能给出全部公因子的上界。

1≤n≤64 的有限和、独立递推与本机技能原始整数对逐项一致；170 个 (p,r) 验证两个同余，3 项 Q_r≡0，未把这些例外误判为赋值一。n=64 时约分分母有 519 个二进制位，公因子有 211 位。执行 python -B computation/formal/valuations.py apt 和 python -B computation/formal/check_skills.py apt。前者生成 [apt.json](../computation/formal/apt.json) 的全部整数与严格余项端点，后者只在交叉复查时需要安装用户技能。

# 有界度树上的二峰 normalizer：第24轮

令 \(A_2(G)\) 是恰有两个峰的标号数，\(B(G)\) 是恰有两个峰且两个最高
标签都是峰的标号数。第二出生纤维恒等式给出

\[
  A_2(G)/B(G)=\mathbb E_B L.
\]

本目录考察“\(A_2\le C(\Delta)B\)”在有界度树上的可行性；它是方格归一化
控制的模型问题，不是方格问题的等价改写。

## 精确积分消息法

给每个顶点独立 \(U[0,1]\) 标签，根树中以父标签为 \(x\) 为条件。保留峰数变量
\(z\) 至二次项。对子树根 \(v\)，令 \(A_v(x)\) 是不计根自身峰时的生成函数，
令 \(B_v(x)\) 是所有子根标签低于 \(x\) 时的生成函数。若孩子为 \(c\)，有

\[
 A_v(x)=\prod_c\left\{\int_0^1 A_c(t)dt+
 (z-1)\int_x^1B_c(t)dt\right\},\qquad
 B_v(x)=\prod_c\int_0^x A_c(t)dt .
\]

无父根的完整峰多项式为

\[
 \int_0^1[A_r(x)+(z-1)B_r(x)]dx.
\]

这是多项式有理系数恒等式；截断 \(z^3,z^4,\ldots\) 不会影响 \([z^2]\)。

为求 \(B\)，对每个有序非邻根对 \((x,y)\) 删除这两个最高根。余下每个树分量中，
把与 \(x\) 或 \(y\) 相邻的点标成高度为一的外边界；再以同一递推但强制内部无峰
计算该分量概率。各分量相乘，最后对根对平均。完全二叉树中，根对的自同构轨道由
\((\operatorname{depth}x,\operatorname{depth}y,\operatorname{depth}\operatorname{LCA}(x,y))\)
决定，故只计算每个轨道一个代表。

`tree_peak_dp.py` 以 `fractions.Fraction` 实现这两套递推。它已通过：

1. 路径 \(3\le n\le11\) 的每个 \((A_2,B)\) 与独立的全子集整数 DP 完全一致；
2. 完全二叉树 \(h\le5\) 中，轨道合并与逐根对求和完全一致；
3. 一峰系数与树根 hook-length 和
   \(\sum_r (n-1)!/\prod_{v\ne r}|T_{v,r}|\) 一致。

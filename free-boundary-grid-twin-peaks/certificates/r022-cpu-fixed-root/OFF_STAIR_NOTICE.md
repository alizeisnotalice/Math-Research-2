# n=11 首批阶梯编号错误记录

用户指定的坐标阶梯是

\[
(0,0),(1,0),(1,1),(2,1),(2,2),(3,2),(3,3),(4,3),(4,4),(5,4),(5,5).
\]

对于顶点编号 `root=y*11+x`，对应正确编号应为
`0,1,12,13,24,25,36,37,48,49,60`。首个批处理脚本在第五项之后误写成
`23,34,35,45,46,56`。这些文件是有效的、各自独立的 fixed-root SMC
输出，但坐标不属于指定阶梯，因而不能用于所要求的相邻根比。本目录保留它们
作为可审计的离阶梯探索；`run_n11_corrected_stair.sh` 用新的种子重新计算缺失的
`25,36,37,48,49,60`，最终汇总只使用正确的 11 个根。

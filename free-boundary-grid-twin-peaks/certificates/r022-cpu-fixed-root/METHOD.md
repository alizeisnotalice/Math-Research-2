# 固定根一峰 normalizer 的对象与有限核验

令 (h_r) 是自由边界 (P_n\square P_n) 上、唯一峰为最高标号顶点
`r` 的**标号全序**数目。程序逐次生成顶点的标签由高到低排列，故其
normalizer `Z` 的目标是 (h_r)，绝不是 (h_r/N!)。所有根的和为
(A_1)。

固定第一个顶点后，SMC 从 rank 2 开始；每个前缀的 fully-adapted 权重是
可接到既有集合的未使用邻点数。故其产品估计 (h_r)。最后一位只抽样并
直接检验恰一峰；不再 MH。每个粒子每副本的 MH 提案数因此是

\[
 P L (N-2),
\]

而不是无条件程序中的 (PL(N-1))。

在长度 `r` 的固定根有效有序前缀空间上，原 swap/replace 提案 (Q) 是
对称的：替换和 swap 均可由同一个位置的反向替换或反向 swap 唯一恢复。
本程序接受端点当且仅当它仍有效且第一个字母仍为根 `r`，其他端点留在
原状态。因此限制后的核 (K(x,y)=Q(x,y))（(x\ne y) 均在该空间）仍对称，
对角线拒绝补全后也对称，均匀固定根前缀律不变。这说明使用此 MH 核不会
破坏目标均匀律；并不说明该核在一般 (n) 的不可约性或混合时间。

`verify_fixed_root.py` 穷举 n=3 全部根与所有前缀深度，直接检查：

1. `allowed` 产生的子前缀支持恰等于递归穷举支持；
2. 所有限制核矩阵逐项对称；
3. 所有列和等于所有行和 (rN)，故均匀律不变。

独立 Python 子集 DP 还重算 n=3/4 的全部 (h_r)，并与 C++ `exact` 输出
逐根一致。n=3, n=4 的总数分别为 29,568 和 35,704,394,880。

小样本 SMC 校准：n=3 使用 (P=257,R=128)，n=4 使用
(P=4096,R=64)，各根和 (L=0,4,16) 都单独运行。`fixed-root-verification.json`
验证完整 replicate、种子、`dead=0`、提案计数和精确 (h_r) 比较。75 个
有限校准中绝对相对误差的最大值为 1.074%，仅为实现诊断。

# r022b：闭 domino helper 分类

严格结果：对任一闭 domino 覆盖的独立非 star 峰集，\(K=3\) 必为 \(2+1\)，而
\(K=4\) 可为 \(3+1\) 或 \(2+2\)（含交换两侧）。特别地，\(3+1\) 是原猜想中必须
保留的形态。峰叶必早于所属中心，故每个 \(K=3\) 形态自动满足 r021 的稳定 helper
秩条件；\(3+1\) 型用一个中心消去两个峰，\(2+2\) 型用两个中心依次消峰，均严格
保留一个距离 3 双峰对。

已写出三种形态对应的有秩倒数预算：(4) 为带 domino cover 标记的三峰式，(5) 是
\(3+1\) 的单 helper 式，(7) 是 \(2+2\) 的链式双 helper 式。前两式的常数已额外
计入“重侧重命名会忘掉有序 cover 方向”的二重性，第三式的完整标记保留该方向。
故三式都可与 \(e_{\rm ord}(P)\) 的 multiplicity 对接；它们仍不产生逐 source 的
常数贡献。
第一未证步骤仍是这些秩比在 r020 加权局部账本下的平均下界；尚未得到原双峰题结论。

有限精确核验：`domino_classification.py` 对 \(3\le n\le7\) 所有自由边界 domino
枚举，只有声明的类别，且无中心峰。运行结果与复现命令见 `REPRODUCE.md`。

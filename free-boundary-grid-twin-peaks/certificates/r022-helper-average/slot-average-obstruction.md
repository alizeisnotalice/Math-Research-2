# r022：删 helper 后的基础 word 与插槽平均的时间障碍

对稳定 helper 操作，固定三峰 source 的局部数据 \((p,z,q,r)\)，删去 \(z\) 得到
基础 word \(B\)。把 \(z\) 插回 \(r\) 后的不同旧槽，不一定都保持恰三峰：若
\(B\) 中出现一个额外峰 \(v\)，而它在 source 中唯一靠 \(z\) 的较早邻接被压住，
则 \(z\) 必须在 \(v\) 之前。

这解释了 r021 的大纤维族为何不反驳倒数加权：在那里删去 \(z\) 后仍恰三峰，全部
旧槽合法，\(\Theta(N)\) 个源各带 \(\Theta(1/N)\) 权重，合起来是常数量。可是不能
将这个抵消当作一般事实。

对每个 \(n\ge5\)，令

\[
q=(4,2),\quad p=(1,2),\quad r=(2,1),\quad z=(2,2),\quad v=(2,3).
\]

在完整 \(G_n-\{z\}\) 上取根序 \((q,p,r,v)\) 的多根 BFS 森林，并按父先于子形成
base word。此时 base 恰有四峰 \(q,p,r,v\)。在 \(r\) 后插 \(z\) 的所有槽中，只有
紧在 \(r\) 后、即 \(v\) 前的一个槽使 \(z\) 先于 \(v\) 并压掉 \(v\)，从而得到恰三峰
\(q,p,r\)。其稳定 helper 加权增益为

\[
\frac{R-P}{N-R-1}=\frac1{N-3}. \tag{1}
\]

所以即使按删 \(z\) 后的同一 base word 聚合，也没有来自纯合法槽数的**逐 fixed-base**
统一正下界。这不否定原均匀 \(K=3\) 条件律下的总体平均仍可能有正下界；它只说明
该结论必须控制这些 base 在总体中的加权质量，或用另一种重排保留其秩信息。局部
domino 几何和峰 birth 条件本身不足以完成这一步。

`single_valid_slot_family.py` 对 \(n=5,\ldots,12\) 在完整方格逐词检查 base/source/
target 的峰集及唯一合法旧槽。这是一个时间排序障碍，不是原双峰问题的反例。

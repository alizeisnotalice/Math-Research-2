# r022：删 helper 后的精确条件插槽账本

本笔记只讨论 r021 的已验证稳定 helper 标记
\((p,z,q,r)\)，且 word 中

\[
 P< R< Z,
 \qquad p\sim z\sim r,\qquad z\not\sim q,
\]

并把 \(z\) 移至 \(p\) 与 \(r\) 之间所得到的双峰 word。位置从 \(0\)
开始编号，\(N=|V|\)。

## 一个精确的条件平均式

固定任意一类带标记 source word，并要求删掉 \(z\) 后，\(p,r\) 的位置仍为
\(P,R\)（这在 \(Z>R\) 时自动成立）。把删点后的对象记为 base \(B\)。对每个
base 定义

\[
 J(B)\subseteq\{R+1,R+2,\ldots,N-1\}
\]

为那些把 \(z\) 插入该槽后仍属于这一个带标记 source 类的槽。每个 \(t\in J(B)\)
给出一个不同的标号 word，反之每个该 source 唯一回复 \((B,t)\)。因此，若在这一
带标记类上取均匀 word，严格地有

\[
 \mathbb P(t=s\mid B)=\frac1{|J(B)|}\quad(s\in J(B)), \tag{1}
\]

而 base 的边际律是按 \(|J(B)|\) 倍加权的。r021 的每个 source 所带权重不依赖
\(t\)，正好是

\[
 \phi(B)=\frac{R-P}{N-R-1}.
\]

故无条件平均的精确形式为

\[
 \mathbb E\,\phi
 =\frac{\sum_B |J(B)|\,(R_B-P_B)/(N-R_B-1)}
        {\sum_B |J(B)|}. \tag{2}
\]

这是一个有限计数恒等式，没有独立性假设。特别地，“给定 base 后插入位置可交换”
仅给出 (1) 的 **有效槽集合上的均匀性**；它完全没有说明 \(J(B)\) 在全部
\(N-R-1\) 个旧槽中的密度，也没有说明 \(P,R\) 的条件秩。

## 两个相反极端及大纤维不会破坏加权上界

r021 的大纤维族给出同一个标记输出至少 \(N-3\) 个 source；其 \(P=0,R=1\)，
而反向旧槽总数为 \(h=N-2\)。所以这批 source 在 r021 加权双计数中的总负载至多

\[
 \frac{N-3}{N-2}<1.
\]

也就是说，线性未加权纤维被恰好设计的 \(1/h\) 权重吸收；它本身不能反驳平均式
可能有正下界。

相反，`slot-average-obstruction.md` 的完整方格族有 \(P=1,R=2\) 以及
\(|J(B)|=1\)，故它对 (2) 的唯一 source 贡献为

\[
 \phi(B)=\frac1{N-3}.
\]

于是无论“每个 base 有多少合法旧槽”，还是“该 base 下每个 source 的间隔比例”，
均没有确定性的正下界。两种极端都可在完整 \(P_n\square P_n\) 中出现。这只否定
逐 base 的下界，不能否定按原 \(K=3\) 均匀条件律对所有 base 取平均后的正下界。

## 真正仍缺少的概率估计

要从 r021 的上界得到 \(A_{2,d=3}\) 的有效下界，至少需要在某个由 r020 的局部
非 star 三峰账本导出的带标记 source 类中证明

\[
 \sum_B |J(B)|\frac{R_B-P_B}{N-R_B-1}
 \ge \delta\sum_B |J(B)|. \tag{3}
\]

其中 \(\delta>0\) 不依赖 \(n\)，或找到替代该比较的保秩映射。(3) 正是 (2) 的
平均有正下界的形式，是均匀标号条件律下的时间排序/条件秩结论。

注意不能把 (3) 改写成

\[
 \frac{\sum_B |J(B)|(R_B-P_B)}
      {\sum_B |J(B)|(N-R_B-1)}\ge\delta. \tag{4}
\]

后者把 \(g/h\) 再按 \(h=N-R-1\) 加权，一般与 (3) 不等价。即使固定
\(N=19\)，只从账本允许的约束 \(1\le |J(B)|\le h\)、\(g,h\ge1\) 看也已如此：

* 两个不同 base 分别取 \((g,h,|J|)=(1,1,1),(1,9,1)\)。则 (3) 左端除以
  \(\sum|J|\) 为 \(5/9\)，而 (4) 左端为 \(1/5\)。例如可取位置
  \((P,R)=(16,17),(8,9)\)。
* 取八个不同 base 各有 \((g,h,|J|)=(1,2,1)\)，再取一个有
  \((9,9,1)\)。则 (3) 的平均为 \(5/9\)，而 (4) 为 \(17/25\)。相应位置可以
  取 \((15,16)\) 和 \((0,9)\)。

故不能以任一个式子推出另一个具有同一常数的式子；这些是有限抽象账本例子，不声称
由方格标号实现。上面的两个 fixed-base 方格例也没有证明 (3) 失败；它们仅说明 (3)
不能由逐 base 的最小值、局部 domino 几何或 (1) 的可交换性直接推出。本轮没有证明
或否定 (3) 在完整原律下成立。

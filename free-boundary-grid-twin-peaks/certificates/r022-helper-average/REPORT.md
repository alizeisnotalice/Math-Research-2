# r022：helper 平均插槽路线

r021 的严格加权不等式为

\[
\sum_{\mathrm{legal}}\frac{R-P}{N-R-1}\le32A_{2,d=3}.
\]

本轮把 source 按删去 helper \(z\) 的基础 word 分组，并得到一个严格的条件插槽
恒等式，见 [`conditional-slot-identity.md`](conditional-slot-identity.md)。给定 base
只是在它的有效旧槽集合上均匀；base 本身则按有效槽数长度偏置。大纤维族中至少
\(N-3\) 个 source 的总倒数负载至多 \((N-3)/(N-2)<1\)，因此不会破坏 r021 的
加权上界。新的完整方格族说明相反极端也真实存在：base 有一个仅能由 \(z\) 压住的
额外峰时，\(r\) 后只有一个合法旧槽，且该 source 的加权贡献仅 \(1/(N-3)\)。

因此，纯局部 birth/空间几何至多在这里被证明**不能给出逐固定 base 的常数下界**。
这一个 base 族不排除原 \(K=3\) 总体条件律下的加权平均仍有正下界。第一未证步骤
正是该总体时间排序估计：需证明条件秩比值的加权平均下界，控制 helper 之前被其
压住的额外峰数或其最早 birth 秩，或者发明不同的保秩平均重排。当前没有把 r020 的
\(\Omega(N^2A_1)\) 局部多峰质量转为 \(A_{2,d=3}\) 下界，也不涉及 \(K=4\)。

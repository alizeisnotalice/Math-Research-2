# r037：角根 L-infinity 环增长词给出 Gamma 的对数上界

## 结论（严格）

主证明中的 Gamma 排除了根的邻点。对每个 n >= 3，存在一个以角点为根的
P_n □ P_n 单峰增长词，使得

    Gamma <= tilde-Gamma <= 1 + (11/3) H_(n-1),

其中 H_m = sum_(j=1)^m 1/j。因此这条确定性的 Gamma 下界路线至多能给出
Theta(log n) 的量级：已有的 Omega(log n) 下界在量级上是尖锐的。

这里仅是在单个词上构造 Gamma 的上界。它不是 B/A1 的上界，也不涉及对单峰词
的加权平均，故不推出 twin-peaks 问题的正面或反面结论。

## 构造和记号

把格点写成 (x,y)，0 <= x,y <= n-1，根为 (0,0)。依次处理 L-infinity 环

    R_k = { (x,y) : max(x,y)=k },  k=1,...,n-1.

在每个 R_k 内采用顺序

    (k,0),(k,1),...,(k,k),(k-1,k),...,(0,k).

每个新点与较早点相邻，所以这是合法的一峰增长词。以下使用题设的
l_p（最早早邻居的秩）及 b_p（以 p 为唯一早邻居的孩子的最早秩；没有则 N+1），
其中 N=n^2；根不求和。为避免根邻点的处理遮蔽构造，定义扩展量 tilde-Gamma 为所有
非根 p 的同一非负项之和；真正的 Gamma 从中删去根的两个邻点。因此 Gamma <= tilde-Gamma，
以下逐项上界均针对 tilde-Gamma。

每个环上恰有两个“唯一早邻居”的孩子：

    C_k=(k,0),       D_k=(k,k).

它们各自唯一的早邻居为 (k-1,0) 与 (k,k-1)。环内其余点均已有两个不同的早邻居。
除根外，所有会成为这类孩子父点的点都在 C_k 或 Z_k=(k,k-1) 中（其中 Z_1=C_1）；
末层 C_(n-1) 没有这类孩子，但为方便仍同组单列。秩的直接计算给出：

    contribution(C_1) = 1;
    contribution(C_k) = 1/(4k-1),       2 <= k <= n-2;
    contribution(C_(n-1)) = 1/(4n-5);
    contribution(Z_k) = 1/(2k-1),       2 <= k <= n-1.

对于每层的角点 D_k，l_(D_k)=k^2+k，且 b_(D_k)=N+1，所以其项为

    1 / (n^2-k^2-k).

除此以外，第 k 环至多有 2k 个点；其最早早邻居已在前 k-1 环，故 l_p <= k^2，且
每项不超过 1/(n^2-k^2)。于是精确的逐层控制为

    tilde-Gamma <= [C 和 Z 的项]
                   + sum_(k=1)^(n-1) 1/(n^2-k^2-k)
                   + sum_(k=1)^(n-1) 2k/(n^2-k^2).

最后两和分别不超过 H_(n-1)/n 和 2 H_(n-1)：

    n^2-k^2-k >= n(n-k),
    2k/(n^2-k^2) <= 2/(n-k).

而 C 项不超过 1 + H_(n-1)/3，Z 项不超过 H_(n-1)。因此

    tilde-Gamma <= 1 + (10/3 + 1/n) H_(n-1)
                <= 1 + (11/3) H_(n-1).

这也处理了环内角点的第二类唯一早邻居事件；忽略它会造成不完整的计数。

断言上述 tilde-Gamma 的 11/3 上界及 Gamma <= tilde-Gamma。

    cd "$OUT"  # first copy ring_gamma.py into this external directory

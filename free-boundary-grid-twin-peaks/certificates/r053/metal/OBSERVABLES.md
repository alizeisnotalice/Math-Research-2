# 首接触可达性与对角路径的有限数值诊断

原 Swift Metal 的随机推进内核未改。本轮只读终端根和前缀，在宿主端增加两类归约。
三阶17粒子的终端跟踪由独立 Python 程序逐粒子复算，含首接触秩、分量可达
最大距离、四组角点路径成本及两种整词重加权。十六阶两次同配置复跑，与第52轮的
各重复旧峰距直方图、旧矩、种子和对数归一化逐项相同。

## 角点路径

置 \(D=2n-2\)。把有序根 \(p,q\) 匹配到两个固定相对角点，
最小曼哈顿路径总长为 \(D-|p_x+p_y-q_x-q_y|\)。
允许从两组对角角点选一组时，总长是 \(D-\rho(p,q)\)。
原因是两个对角方向中可选与横、纵位移符号相容的一组，
两个绝对对角投影的最大值恰等于曼哈顿距离。
归约同时记录第52轮两个点各自择最近固定角点的总长，
以及固定匹配与可任选对角匹配的差。上述量只依峰对，使用第一合并权。

本机24阶用了65,536粒子、8重复、64次移动，GPU 核时间约739秒。
固定角点匹配的平均总长诊断约39.02，允许择对角组后约28.88。
这比较的是固定 \(n\) 的路径长度和有限采样权。

## 首接触

删低峰 \(q\) 得到的前缀、高峰和首邻秩在合法的 \(j-1\)
个低峰插槽间保持不变。对任何这类统计量 \(f\)，严格有
\[
  \sum_{\pi:K_n=2} f(\pi)
     =\sum_{\omega:\,K_n=2,\ R_\omega(q)=2}(j(\omega)-1) f(\omega).
\]
故实现用精确权 \(L=j-1\)，先计算 \(V\setminus N[K]\)，
再找含 \(q\) 的分量，在原图度量下取最大可达根距。每重复按源峰距投影的
整数权与独立的旧 GPU 距离归约完全相同，所有首接触秩权总和也逐重复一致。
十六阶用131,072粒子、12重复、16次移动。在观测的近源权中，
距离阈值9、15的可达比例都为1，直径30的可达比例为0。
这些是有限样本的取值。插槽恒等式是精确的，SMC 输出仍没有混合误差界。

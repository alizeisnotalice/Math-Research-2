# r020：规范最短路提升的精确逆纤维 DP

固定一峰输出 \(\sigma\)，并固定 \(d\ge2\)。要求 \(\sigma\) 前 \(d\) 点为

\[
u,z_1,\ldots,z_{d-1},
\]

一条有序最短路前缀。最短路规则固定为：在所有把到终点的曼哈顿距离减少一的邻点中，
每一步取顶点编号最小者。令 \(P=\{z_1,\ldots,z_{d-1}\}\)，删去 \(P\) 后保留次序的
词为 \(\tau\)，其首点仍为 \(u\)。

候选低峰 \(v\) 只能满足

\[
v\sim z_{d-1},\qquad d_G(u,v)=d,\qquad
\operatorname{canpath}(u,v)=(u,z_1,\ldots,z_{d-1},v). \tag{1}
\]

对每个这样的 \(v\)，用状态 \((i,S)\) 做精确整数 DP，其中 \(\tau\) 前 \(i\) 点和
\(S\subseteq P\) 已经放入原词。初态强制为 \((1,\varnothing)\)，即 \(u\) 是首点。
下一步可放下一个固定的 \(\tau\) 点，或任一 \(P\setminus S\) 点。每一步按原图邻接
直接判定是否出生：

* 放 \(P\) 点时必须有已放邻点，否则拒绝；
* 放 \(v\) 时必须没有已放邻点；
* 放其他 \(\tau\) 点时必须有已放邻点。

终态 \((|\tau|,P)\) 的路径数是该候选 \(v\) 的逆像数；对 (1) 的候选 \(v\) 求和，
得到 \(m_d(\sigma)\)。

这是精确而非上界：任一 DP 路径给出恰有两个出生点 \(u,v\) 的原词；按 (1) 提升后，
内部点被置为给定前缀且其余顶点相对次序正是 \(\tau\)，所以像恰为 \(\sigma\)。
反之任一规范提升原像的内部点位置和次序形成唯一 DP 路径。复杂度为每个候选
\(v\) 的 \(O(N\,2^{d-1}d)\)。

文件 exact_inverse_fibre_n3.py 完整枚举 \(3\times3\) 的全部双峰词，独立实施规范提升，
并对每个一峰输出、每个 \(d=2,3,4\) 将 DP 的 \(m_d(\sigma)\) 与真实输出纤维逐项
比较，而不只比较距离总和。

# Finite short-gap consequences

The public script consumes the final r032 public n=6 global CRT output and
n=7 fixed-highest-root centre CRT output. It uses only Python integers and
`Fraction`.

The n=6 global `L>=6` lifted mass is approximately 0.3256225. The n=7-centre
`L>=6` lifted mass is approximately 0.6396299. At that centre, QE8 has
strictly negative slack for t=4,5,6; n=6 has nonnegative slack at those finite
thresholds. The centre observation is not a global n=7 result, and neither
calculation is an asymptotic conclusion.

`source-historical-output.json` is retained only as historical provenance.
`public-output.json` was regenerated using this package's final public CRT
outputs, so its input SHA-256 values intentionally differ from the historical
source output.

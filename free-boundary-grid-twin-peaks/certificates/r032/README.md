# r032 public certificate preparation

This package separates two kinds of material.

* `analytic-r45/` contains the r45 seven-point local argument.  Its finite
  seven-vertex bipartite exhaustive lemma supports the stated computer-assisted
  theorem for finite connected bipartite graphs of at least seven vertices.
  It is not an asymptotic conclusion.
* `spatial-r45/` proves the specified fixed-layer, far-distance local spatial
  identity.  It controls neither all layers nor the original global limit.
* `independent-prefix-dp/`, `n6-h45/`, and `n7-center-h45/` are finite exact
  computational certificates only.

The n=6 material was produced after r031 was frozen: its source directory has
an old r031 label, but this public archive deliberately assigns it to r032.
The n=7 centre material contains only `v=24`; r033 work on other holes is not
part of this package.

Use [REPLAY.md](REPLAY.md). No binary, GPU trace, private absolute path, or
large production log is included.

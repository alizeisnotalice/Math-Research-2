# 逐行词严格否定纯 clean-chain 打包候选 P

工作候选P要求：每个自由方格一峰词可抽取若干彼此顶点不交的clean-chain families，若第α族有h_α条链、M_α个eligible内部点，则Σ_α M_α³/h_α ≥ c N² log n。内部点必须具有一个在加入时以它为唯一早邻的后继孩子。这个全称候选是假的。

取第38轮逐行词，pos(x,y)=yn+x+1，root=(0,0)。x,y≥1的点都有两个早邻（左、上），所以它不可能是任何sole-parent child。只有顶行或首列（除根）的点有唯一早邻。因此，能拥有sole-parent child的eligible父点只可能是

(x,0)，2≤x≤n−2；以及(0,y)，2≤y≤n−2。

其数目恰为2(n−3)。顶行和首列末端没有后继孩子；根及其邻点被eligible定义排除。

每个clean-chain内部点必属于上述集合。由于候选要求各族互不交，同一eligible内部点不重复，故Σ_α M_α≤2(n−3)。又h_α≥1，所有M_α非负，于是严格有

Σ_α M_α³/h_α ≤ Σ_α M_α³ ≤ (Σ_α M_α)³ ≤ 8(n−3)³。

N²logn=n⁴logn，而8(n−3)³/(n⁴logn)→0。这排除了任意固定c>0下的候选P。

不受影响的结论：单个clean-chain family的调度下界2M³/(9hN)仍可成立；第38轮Ψ的占用恒等式仍成立；逐行词自身Ψ=O(Nlogn)且有大量b=N+1的无sole-child点。失败环节是“所有代价都可由这种链包支付”的覆盖提取，而不是局部链不等式。

若要继续，必须给无sole-child点单独计重，或采用可重叠但带严格重数预算的多尺度结构。上述反例不否定Ψ≥cNlogn，更不证明或证伪原双峰距离命题。

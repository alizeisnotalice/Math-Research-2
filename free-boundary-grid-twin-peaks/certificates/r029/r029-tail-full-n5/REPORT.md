# r029：完整 \(5\times5\) 穿孔首邻点尾分布

## 严格有限结果

对每个孔 \(v\)，在 \(H=G-v\) 上计数 \(\mathcal D_{v,p}\)（首点为孔外峰
\(p\)），并令 \(L=J-1\) 为 \(p\) 的首邻点前的位置数。新程序获得了完整的
\(L\) 分布，不是抽样也不是浮点计算。

对 \(n=5\)，六个 D4 孔轨道代表 \((0,0),(1,0),(2,0),(1,1),(2,1),(2,2)\)
均已顺序精确完成。按轨道大小合并后：
\[
 A_2=7063261481362958280000,
 \qquad B=2910913997686940072256,
\]
并逐项匹配 R027 独立集容斥表。特别地
\[
 B/A_2={659174365418238241\over1599470444149220625}.
\]

令 \(T_t=\sum_{v,p}\#\{\zeta\in\mathcal D_{v,p}:L\ge t\}\)。完整全局
直方图及所有 \(T_t\) 保存在 `n5-tail-summary.json`。在这个**有限**方格中，
每个孔类及合并后的全局尾均满足
\[
 T_{t+1}\le {4\over5}T_t\quad(t\ge1).
\]
全局连续比的最大值在 \(t=10\)：
\[
 {T_{11}\over T_{10}}
 ={158566110322056772\over207987999029580947}
 \approx0.762381056<\frac45.
\]
这是一个严格的 \(n=5\) 有限事实；它不证明该收缩对所有 \(n\) 成立，也不
提供渐近尾界。

中心孔 \(v=(2,2)\) 的结果为
\[
 B_v=128248880907336820800,
 \quad A_{2,v}=544327093683260035200,
 \quad B_v/A_{2,v}={2055270527361167\over8723190603898398}.
\]
这也精确匹配 R027 的逐孔值。

## 算法与严格性

固定孔后先在全部 \(S\subseteq V(H)\) 上以降序子集 DP 计算
\[
 f(S)=\sum_{x\notin S:\;x\in N(v)\ \text{或}\ N_H(x)\cap S\ne\varnothing}
 f(S\cup\{x\}),\qquad f(V(H))=1.
\]
对每个孔外根 \(p\)，前缀严格限制在
\(S=\{p\}\cup I\subseteq V(H)\setminus N(p)\)。压缩前向 DP 给出所有合法
前缀词数 \(g_p(I)\)，然后把
\[
 g_p(I)\sum_{x\in N(p)}f(S\cup\{x\})
\]
加到 \(L=|S|\) 的桶。每个词有唯一的“首个 \(p\)-邻点”，所以这些桶无重无漏。
每根另断言 \(\sum_t h_p(t)=f(\{p\})\)。

对 \(n=5\)，\(M=24\)。所有计数均以带溢出检查的 `unsigned __int128`
完成。严格的粗界为：\(f(S)\) 至多为剩余顶点的全排列数；对固定孔 \(v\)，
每个前缀--首邻点--后缀三元组计数的是 \(H_v\) 上某个完整词的互不重叠子族，
故固定孔的桶和 \(B_v\) 均不超过 \(24!\)。再对 25 个孔求和，完整图的任一桶
及 \(B\) 均至多 \(25\cdot24!=25!\)，而
\(A_2=\sum_t t h(t)\le24\cdot25!<2^{128}\)。
程序在每次加法、乘法前检查该界对应的机器溢出条件。

独立核验：新的 C++ 程序在 \(n=3\) 与 \(n=4\) 对所有孔、所有 \(L\)-桶均逐项
匹配 r028 的独立 Python 前缀 DP；后者又已逐孔匹配 R027 独立集容斥表。\(n=5\)
则用全部六个 D4 代表的总量及逐孔 \((A_{2,v},B_v)\) 回对 R027 表。

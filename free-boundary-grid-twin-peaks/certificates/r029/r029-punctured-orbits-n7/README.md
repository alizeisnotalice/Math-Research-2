# Exact n=7 D4 punctured table

This package keeps the 36 new modular residues for nine noncentral D4 orbit
representatives, their exit/resource receipts, and the ten independent
selected-hole reconstructions.  The central four residues and Pratt
certificate are deliberately referenced from r028, rather than duplicated.

The frozen parent audit also checked historical source and binary hashes.
No historical binary is archived here; consequently the portable replay below
rechecks the mathematical certificate, residues, receipts, D4 orbit sums, and
the r026 global totals, but does **not** purport to rerun those binary-hash
checks.  This distinction is material.

Every claimed value is finite n=7 data.  The all-vertex `Bv/A2v >= 1/5`
check does not establish a uniform-in-n bound.

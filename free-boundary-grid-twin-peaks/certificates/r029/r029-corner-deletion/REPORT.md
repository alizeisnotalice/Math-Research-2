# r29：角点局部删除引理的独立审计

## 严格结果

对自由 \(n\times n\) 方格 \(G\)（\(n\ge3\)），删除
\(D=\{(0,0),(1,0),(0,1)\}\) 后的图 \(H\) 满足

\[
A_1(G)\le(n^2)_8A_1(H).
\]

完整构造、合法性证明及纤维计数在 [CORNER_DELETION_LEMMA.md](CORNER_DELETION_LEMMA.md)。
关键点是先把五点连通缓冲区 \(T\) 置入输出词；因此被删的 \(D\) 从不充当保留顶点的唯一此前邻点。
这是一条局部 \(A_1\) 比较，不能单独关闭原双峰远距问题。

## 有限精确核验

脚本 [corner_deletion_audit.py](corner_deletion_audit.py) 用 Python 3.15.0 运行，记录：

* \(n=3\)：穷举所有 \(9!=362{,}880\) 个降序标号词。恰一峰的 \(G\)-词为
  \(A_1(G)=29{,}568\)，每一个都经映射成为 \(H\) 上恰一峰下降连通词；
  \(A_1(H)=120\)，观察到的最大纤维为 \(28{,}224<(9)_8=362{,}880\)。
* \(n=4\)：独立的整数子集 DP 给出
  \(A_1(G)=35{,}704{,}394{,}880\)，\(A_1(H)=42{,}708{,}336\)，且
  \[
  35{,}704{,}394{,}880\le(16)_8\cdot42{,}708{,}336
  =22{,}162{,}141{,}383{,}782{,}400.
  \]

这些计算只交叉核验映射和计数；一般 \(n\) 结论由上述解析证明承担。

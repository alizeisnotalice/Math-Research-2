# Scope and replay inputs

The retained JSON is a completed finite cross-check of the corrected modular
source against the independent short-tail IE and r028/r029 tables.  To rerun
that cross-check one needs the 104 corrected modular checkpoints, which are
not duplicated here because they are reproducible intermediate residues and
the earlier candidate batch is invalid.  The independently replayable formula
check is in `../r029-short-tail-ie/REPLAY.md`; the complete n=5 reference is
in `../r029-tail-full-n5/REPLAY.md`.

This package contains no claim that the omitted checkpoints or a future n=7
run establish an all-n statement.

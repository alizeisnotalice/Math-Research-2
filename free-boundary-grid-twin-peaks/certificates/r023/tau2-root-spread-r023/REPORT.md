# r023：\(\tau_2\) 固定根扩散

严格结果：对任意固定高根 \(x\) 和非邻低根 \(y\)，顶二完成核满足
\(h_x(y)\ge a_x/(N-1)\)。这给出每个固定根的远低根未归一化质量下界 (3)。

严格否定的候选：即使固定同一个角根，\(h_x(y)\) 也不随 \(d(x,y)\) 点态增加；
\(n=3,4,5\) 有同边界方向的明确反例。故不能用逐点反射/推远根比较。

最具体未证步骤是聚合尾界 \(\sum_{d>\varepsilon n}h_x(y)\ge cH_x\)，或足以替代它的
根平均式；点态低峰激活下界已在别处严格失败，未在本轮使用。\(\tau_2\) 尾界本身
也不自动给原 \(K=2\) 条件律结论。

精确整数 DP 对 \(n=3,4,5\) 复算全部 pair kernel，并报告固定根半尺度尾质量和
所有点态比较反例；无随机或 GPU 计算。

# r22 高粒子固定根批次

此独立目录只重复根 `(0,0),(1,0),(1,1)`，依坐标生成 root IDs
`0,1,12` 并检查相邻曼哈顿距离。每根顺序运行 `P=262144,R=256,L=16,T=12`，
不与其他根并发。normalizer 是由高到低标号有序词中、首字母（最高标号唯一峰）
固定为 root 的计数 (h_r)，不是概率或除以 (N!\) 的量。

每根的随机 seed base 为 `0xA0228000 + root*2^36`，远大于同一 run 中的
replicate/根/步偏移，且不同于先前批次。源码及二进制 SHA-256、编译命令和
运行参数冻结在 `run-manifest.json`；CSV 同时含自身完整的运行元数据。

本批的目的只是降低前几个根的有限 SMC 方差。即使完成，也不把跨根估计比写成
严格计数或任何根比不等式的证明。

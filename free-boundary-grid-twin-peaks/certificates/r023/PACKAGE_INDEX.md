# r023 archive package index

This is a staging package for topic-local, whitelist publication. It contains
only materials whose runs had naturally ended when checked. It does not
contain executables, caches, full terminal traces, credentials or the r024
MacBook/local production jobs that were still active.

Included packages:

- `root-activation-r023`: final sharp activation theorem and finite exact
  scans. The authoritative proof is `corner-redundant-root.md`.
- `tau2-lift-theory-r023`: first-merge fibre identities and the sharp abstract
  constant-four second-moment bound.
- `top2-d4-r023` and `fixed-state-completion-root-r023/top2-reference`:
  exact top-two accounting plus independent n=3..5 reference verification;
  see its Q-normalization erratum.
- `helper-exact-dp-r023`, `added-edge-response-r023`, and
  `tau2-root-spread-r023`: finite exact auxiliary results and counterexamples.
- `tau2-lift-production-r023`, `geodesic-production-r022`,
  `gpu-inverse-production-r021`, and `fixed-root-highp-r022`: ended finite
  SMC production diagnostics with source, raw output/summary as needed, and
  run receipts.
- `tau2-distance-r023`: terminal-kernel source and small exact/fixture
  validation; its large traces are excluded.

`rounds/023.md` and `STATE-r023-append.md` are drafts for the topic tree.
`SHA256SUMS-r023.txt` is the complete file manifest, generated after all
included files were copied. Every retained file is below 10 MiB.

# Reflection--covariance reduction

For a first-merge branch pair, the archived report derives exact weighted
coordinate-moment formulas.  Full vertical reflection changes each branch
first moment's sign and leaves their product unchanged.  Consequently global
reflection alone cannot decide the sign of the covariance sum.  The first
remaining analytic step is a weighted one-branch exchange or cumulative
completion comparison.

The included 3 by 3 exhaustive check validates the finite normalization and
the formulas.  This is a reformulation and obstruction for a proof route,
not a new asymptotic covariance bound and not a result about the original
problem.

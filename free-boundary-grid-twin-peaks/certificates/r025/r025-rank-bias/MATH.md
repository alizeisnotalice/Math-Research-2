# r025：固定 \(\tau=2\) 有序前缀的 rank-biased MH 提议

令 \(\Omega_r\) 为长度 \(r\) 的不同顶点有序前缀，其中出生恰在 rank
\(1,2\)；当 \(r=1\) 时只有首个出生。提议先选 rank \(i\)，再均匀选
顶点 \(v\in V\)。若 \(v\) 在前缀，交换它和 rank \(i\)；否则以 \(v\)
替换 rank \(i\)。试探前缀若不在 \(\Omega_r\)，就拒绝并留在原状态。

r025 的 rank 分布为

\[
p_0=p_1=\frac14+\frac1{2r},\qquad p_i=\frac1{2r}\ (i\ge2),
\]

对 \(r=1\) 取 \(p_0=1\)。这恰是先以概率 \(1/2\) 均匀取
\(\{0,1\}\)，再以概率 \(1/2\) 均匀取全部 \(\{0,\ldots,r-1\}\)。

更一般地，对任何固定 rank 权重 \(p_i\)，提议核在 \(\Omega_r\) 上对称。
若两个合法前缀由活跃顶点 \(i,j\) 的交换相连，则有两种生成方式，故

\[
q(x,y)=\frac{p_i+p_j}{N}=q(y,x).
\]

若它们由 rank \(i\) 的外部顶点替换相连，则

\[
q(x,y)=\frac{p_i}{N}=q(y,x).
\]

其余候选都进入拒绝自环。因此均匀律在 \(\Omega_r\) 上满足详细平衡；这里不
需要 MH 接受率修正。这个结论只针对**固定 rank、固定 \(\tau=2\) 的前缀核**。
它不证明跨 rank 的 SMC 无偏性、不证明混合速度，也不证明祖先退化已经改善。

`verify_rankbiased_prefix.py` 用 `Fraction` 完整枚举 \(P_2\) 的全部
rank \(1\) 至 \(4\) 前缀和 \(P_3\) 的 rank \(1\) 至 \(5\) 前缀，逐对核验
行和、支持不变和详细平衡；还对非均匀任意固定 rank 权重重复核验。

## 对根集合移动的逐边增益

在 \(r\ge2\) 时，旧的均匀选 rank 规则给每个 rank 的质量 \(1/r\)。若一条
合法 swap 边交换一个根 rank \(0\) 或 \(1\) 与一个非根 rank \(j\ge2\)，其
提议质量从 \(2/(rN)\) 变为
\[
 {p_0+p_j\over N}={1/4+1/r\over N},
\]
所以逐边倍率恰为
\[
 {r\over8}+{1\over2}.
\]
若根 rank 被前缀外顶点替换，质量从 \(1/(rN)\) 变为
\((1/4+1/(2r))/N\)，倍率恰为
\[
 {r\over4}+{1\over2}.
\]
交换 rank \(0\) 与 rank \(1\) 不改变无序根集合，故不属于这个几何移动比较。
这些是固定状态、固定合法边的提议质量比较；接受是否通过仍由前缀合法性决定，
所以它们不是混合速度或方差下降结论。

对于 \(2\le r\le32\)，单独的 Fraction 代数检验逐个确认 rank 权重和为 1，且
上面两个倍率分别等于 \(r/8+1/2\) 与 \(r/4+1/2\)。这与完整状态空间的详细
平衡检验相互独立。

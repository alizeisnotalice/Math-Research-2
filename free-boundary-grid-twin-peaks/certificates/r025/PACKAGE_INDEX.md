# A022 第25轮归档草稿索引

此目录是待主线审阅的归档草稿，不是 Git 工作区。它只含已经完成并得到本轮核验的材料；
原方格问题仍未解决。

- `r025-strip-entropy/`：全 n 两行条带熵下界、n=3 独立整数审计及证明说明。
- `r025-rank-bias/`：固定 prefix rank-biased move 的 Fraction 详细平衡、宿主构建和小 GPU
  trace 的 proposal 级重放；不包含生产 SMC。
- `r025-fixed-root-n11/`：三个已完成 n=11 固定根批及公共审计脚本；启动记录中带私人机器
  标识的文件未收录。
- `r025-macbook-gpu/`：截止前已完成的 n=16/n=24 terminal 批。n=16 raw 只保留 gzip；n=24
  raw 在 10 MiB 以下，直接保留。
- `r025-local-n24/`：完整本机 n=24 raw 的后处理恢复；明确区分显示型浮点残差与整数群组恒等式。
- `r025-genealogy/`：两个已完成 n=24 批的只读跨重复权重诊断；不反推未记录的祖先信息。
- `r025-normalizer-tail/`：由首次合并严格推出的 top-two normalizer--距离必要约束、
  n=3 全枚举及两份 n=24 plug-in 违反检查，并以 Fraction 给出本机 `.15`、MacBook
  `.18` 的确定性二择误差下界。它限制有限输出的解释，不定位数值失效原因。
- `r025-grid-reflection/`、`r025-grid-geometry/`：方格解析路线的精确改写与有限整数数据。

未收入本草稿：本机重启后尚在补齐的 CPU/GPU 批、截止时仍运行的远端后续队列、二进制、
编译缓存、私有网络/主机资料和重复临时 trace。

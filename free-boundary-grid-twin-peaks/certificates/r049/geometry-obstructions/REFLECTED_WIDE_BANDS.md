# A022 第49轮补充：加宽条带中完整首合并权的超表面反射差

存在两套连通的面积阶平衡首合并形态，只反射右支就从其中一套得到另一套。两套形态的左右支内计数、各支大小、总边界大小及同一早峰前缀计数精确相同，完整首合并权之比仍为 \(\exp(\Theta(n^{3/2}))\)。条带宽度为 \(\Theta(\sqrt n)\)。

## 完整坐标

取整数 \(L\ge1\)，令
\[
 W=2L+9,\qquad J=4L+1,\qquad
 n=J(W+1)-1,\qquad
 c=\lfloor n/8\rfloor,\quad y_0=(n-1)/2.
\]
坐标取 \(0,\ldots,n-1\)。第 \(j\) 条带是 \(j(W+1)\le y\le j(W+1)+W-1\)，其中 \(0\le j<J\)。条带之间隔一行。偶数条带属于左支 \(A_0\)，其中填到 \(x=n-c-2\) 为止。奇数条带属于右支 \(B_0\)，其中从 \(x=c+1\) 填到最右。另给两支各一条整高的边柱，左为 \(x<c\)，右为 \(x\ge n-c\)。两条边柱连接各自全部条带。因余出一整行或一整列间距，\(A_0,B_0\) 之间没有边。未被覆盖的同行空点只有单列间隔和条带分隔行，前者有相邻边柱，后者相邻的偶带和奇带的横向并集横跨全图。因此 \(A_0\cup B_0\) 支配整图。

第 \(j\) 条带与下一条带之间的分隔行为 \(g_j=j(W+1)+W\)，\(0\le j<4L\)。它与其在 \(\sigma(x,y)=(x,n-1-y)\) 下的反射分隔行配对。若 \(j<2L\)，称其为该对的上半。每一分隔行在横坐标 \(x_t=c+6+12t\le n-c-7\) 的所有位置重复以下缺口。对于面向分隔行的某侧，令 \(\varepsilon=\pm1\) 为从 \(g_j\) 指向该侧的方向。以中心 \((x_t+u,g_j+\varepsilon)\) 删除中心、同一行左右两个邻点及更向内的一步邻点 \((x_t+u,g_j+2\varepsilon)\)。在上半的分隔行两支均取 \(u=0\)。在下半的配对分隔行左支取 \(u=-1\)，右支取 \(u=1\)。去掉这些缺口所得两支为 \(A,B\)。第二形态只把右支反射成 \(B'=\sigma B\)。

各缺口中心与边柱、条带另一端或另一组缺口都有隔离。每条带有完整的中部横行。贴着分隔行的残余点可直接向内部走到完整横行，原因是缺口的两个外层点若与内点同列，则它们同时被删。残余点因此沿完整中部横行连接到各自边柱。两支均为原方格连通诱导子图。在未挖缺口的两支，二度点只可能位于方格外边与厚边柱的角、或条带远端的角。条带与边柱相接的凹角至少三度。这些二度角点彼此间隔至少两步。挖缺口产生的新二度点必在某个缺口的一步邻域内，由宽5、高4的固定矩形覆盖。相邻缺口的一步邻域因横向间隔12、纵向间隔至少 \(W+1\) 而互不相邻，且它们到原二度角点亦至少隔一格。故诱导二度点分量的大小有统一界，不出现增长长度的二度走廊。

取
\[
 w=(n-c-1,y_0),\qquad
 p=(n-c-2,y_0-1),\qquad q=(n-c,y_0).
\]
中央偶带包含 \(y_0-1,y_0,y_0+1\)。故 \(w\) 横向邻接两支各一点，无其他支间边。它及 \(q\) 都被 \(\sigma\) 固定。\(p,q\) 距离3。将 \(w\) 分别加入 \(A\cup B\) 与 \(A\cup B'\)，得两个有效首合并前缀 \(S,S'\)。

## 权重差的计算

任何未被删除的点都是已揭示点。缺口中除面向分隔行中心外，其余三点都有仍保留的同支邻点，故已被支配。中心的所有邻点均已删除或在原本的分隔行中，所以未被支配。任何分隔行位置恰在其左右两组缺口对应的横向三个删除位置重叠时才未被支配。单列间隔空点仍被边柱支配，因为缺口不接触边柱。故所有未支配点都明确定域在小缺口组内，没有剩余因子。

每组的局部未支配中心集合与常宽缝反射例中的 \(C_\Delta\) 仅相差转置和刚性位移。上、下镜像对在第一形态的错位是 \((0,2)\)，第二形态是 \((1,1)\)。相配的两个局部中心集合总大小都为8。不同横位置间距至少10、不同分隔行间距 \(W+1\)，各组闭邻域不重叠。因此仍使用精确局部因子 \(g_0=119/495,\ g_1=17/50,\ g_2=29/55\)。若 \(M\) 为符合 \(x_t\) 范围的横位置数，得到
\[
 |U(S)|=|U(S')|=8(2L M),\qquad
 \frac{h(S)}{h(S')}
 =\left(\frac{g_0g_2}{g_1^2}\right)^{2L M}
 =\left(\frac{20300}{18513}\right)^{2L M}.
\]
前缀大小相同，所以此比既是规范化完成率之比，也是整数完成数之比。因为 \(M\asymp n\)、\(L\asymp\sqrt n\)，指数为 \(\Theta(n^{3/2})\)。两支由条带、厚边柱和局部缺口组成。除 \(O(n^2/W)\) 个分隔点、单列间隙及删点外，方格被两支填满。左支恰比右支多一条带，面积差为 \(W(n-2c-1)=o(n^2)\)，故两支各为 \((1/2+o(1))n^2\)。整体大小和两未支配集大小相同又给 \(|\partial S|=|\partial S'|\)。

右支反射给一峰词图同构并固定 \(q\)，左支与 \(p\) 一致。两形态的完整首合并计数共同的支内交错因子因此相消。若另固定 \(p,q\)、\(R_q=2\) 及首邻秩3，仍由要求交错前三符号为 \(A,B,B\) 实现，故该同一早峰子计数的比也不变。两个计数都可除以同一 \(A_2(n)\)；这是原条件律两个真实事件的比值。未证明它们之一有绝对正质量，因此不决定原题的远峰概率。

## 本机核验

使用 Python 3.15.0 运行 audit_reflected_bands.py。调用独立局部容斥与子集完成双算法，然后逐尺寸构造两套条带形态并检查完整方格的诱导邻接、支配、未支配依赖分量、边界大小、根峰标签次序、归一化后缀因子及指数比。实际通过的尺寸为 \(n=59,125,207,419\)，局部镜像对数为 \(6,28,78,260\)。还检查了所测各个形态的二度顶点连通分量大小有统一界。执行正常退出，输出见 audit_reflected_bands.stdout。

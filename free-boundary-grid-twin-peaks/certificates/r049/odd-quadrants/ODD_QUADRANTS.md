# 十一阶四象限的严格有限下界

把 \(11\times11\) 方格沿第5行和第5列后的缝分为高度 \(5,6\)、宽度 \(5,6\) 的四个矩形。每个矩形中要求恰一个诱导峰，且同一列半幅的两个诱导峰都是水平缝两侧、外侧横坐标相同的邻点。左侧外边起第0、1列可取，右侧外边起第0至3列可取。任意选取全图标签的四区域交错。

同侧两个根中标签较低者被自己的对齐邻点压掉。标签较高者的全部跨区域邻点只可能包括这个对齐根。其他顶点已有本区域高邻点。因此恰有两个原图峰，水平坐标之差至少 \(10-1-3=6>11/2\)。原词可恢复四个限制词和两个外列位置，计数唯一。

令 \(a_{h,w}(x,y)\) 为矩形中根在 \((x,y)\) 的单峰词数。行数为 \(h\)，列数为 \(w\)。反射和转置后，上述可数子族的计数为
\[
\binom{121}{25,30,30,36}
\left(\sum_{x=0}^1 a_{5,5}(x,0)a_{6,5}(x,0)\right)
\left(\sum_{x=0}^3 a_{6,5}(0,x)a_{6,6}(x,0)\right).
\]
使用第48轮五阶根账、已有六阶方根账和本轮矩形根账。矩形共有30点。用闭邻域联合峰递推和三模 CRT 求所需的12个根，再以独立 Python 整数计数复验。精确分子与未条件化质量见 n11-numerator.json。

分母的低内存替代直接利用同样的四象限。在每个矩形内，只数原邻域没有越出自己所在矩形的受保护点。两条靠缝的边去掉后，其余点的峰判定即为原图峰判定。四个受保护峰数之和必须至多2。若恰有两个受保护峰，全图最高标签必须受保护。若最高标签受保护但第二大标签不受保护，第二大标签必须邻接最高标签。最高标签受保护时，该邻接只可能在同一矩形内。

对单矩形，从保护点的独立峰集累加三个联合峰矩。第一列统计所有地方词，第二列限制最大值在不受保护点，第三列限制最大值受保护、第二名不受保护且不邻最大值。第47轮的闭邻域矩公式不要求未受保护点只位于一条边，因此可直接用在两条靠缝边。对每列用整数二项反演。合并四个局部序时，用多项组合数计入交错。最高一或两名的区域索引固定后，剩余标签仍任意交错。由此精确减去两类违背必要条件的词。三个小矩形的全排列独立验证各列直方图。

这个分母上界除上述无重分子得到
\[
\mathbb P_2(\rho_{11}>11/2)>3.04149\times10^{-20}.
\]
它是严格有限下界。精确有理数见 four-block-bound.json。更紧的完整二分隔五模分母已在两机完成。相同分子的改进下界见 [五模精确复核](../n11-dense/verification.json)。

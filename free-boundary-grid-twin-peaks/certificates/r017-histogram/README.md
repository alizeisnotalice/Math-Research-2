# r017 terminal Manhattan-histogram independent audit

This is the curated archive of an independent audit workspace. The historical
name frozen_base_r016.swift refers to the new boundary-bitset source, not to the
older five-word production kernel.  The selected `local-hybrid-math` workflow was used only to run short
Metal P=17 checks and exact CPU/Python comparisons; no large production job was
started.

`verify_kernel_identity.py` proves by byte comparison that the base and

64 and 65), final allowed counts, and `lastT`.

## Actual certificate

`histogram-independent-certificate.json` (SHA-256
`df6766cdd3495d8420bae874db9dd8a88a7bfaee9ea6930b2a4e6a56d20f83ce`)
is generated by an independent Python verifier.  It compares the host
instrumented and frozen base runs for exact equality of
`tau, replicate, seed_hex, Z, U, logZ, dead`, then recomputes every histogram
bin directly from each returned root pair by Manhattan distance.

Coverage is P=17, one replicate per case:

- n=3, every tau=2,...,10;
- n=16,24,32 at tau=2, floor(N/2), N-1, N, N+1.

All 24 cases passed.  In alive two-root cases, independently reconstructed
`hist_raw` is exact and sums to 17.  At N-1 and N it verifies real death:
`lastT=0`, terminal allowed counts all zero, and all bins zero.  At N+1 it
verifies an alive one-peak state: `lastT=17`, terminal allowed counts all one,
and histogram is `null` because root 2 was never selected.

The FK normalization is explicitly certified: if an SMC run is alive, then
the preterminal state has N-1 occupied vertices and exactly one final legal
vertex per particle, so `lastT=P`; for raw terminal bin count `H_b`, its
unnormalized FK estimator is `Z*(H_b/P)=Z*(H_b/lastT)`.  No division by
`lastT` is made for dead runs.

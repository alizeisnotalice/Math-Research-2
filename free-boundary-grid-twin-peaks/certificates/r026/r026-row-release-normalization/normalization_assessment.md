# 行释放公式与顶行归一化

令 \(T\) 为顶行，\(H_T=h(T)\)。顶行的内部一峰词数为 \(2^{n-1}\)，故
\[
p_n=\frac{2^{n-1}H_T}{A_1(n)}.
\]
顶行双峰臂族的精确质量仍为
\[
\frac{F_n}{A_2(n)}=\frac{H_T2^{n-3}(2^{n-1}-2)}{A_2(n)}
=\frac{2^{n-1}-2}{4R_n}p_n,\qquad R_n=A_2/A_1.\tag{1}
\]

两行释放恒等式精确分解 \(H_T\)，但其直接比较对象是固定首集 \(R\) 的完成数 \(H_R\)，不是全体一峰词 \(A_1\)。更明确地，首个 \(2n\) 集恰为 \(R\) 的一峰词质量为 \(a(R)H_R\)，其中 \(a(R)\) 是 \(2\times n\) 梯图的连通增长词数。行释放只给
\[
 E_a\frac{(M+n)!}{(M+a)!}\le\frac{H_T}{H_R}
 \le\frac{(M+n)!}{(M+1)!},\quad M=n(n-2),\ a=\lceil n/2\rceil,\tag{2}
\]
而要用这一固定条带质量排除顶行事件，仍须控制
\[
\frac{2^{n-1}H_T}{a(R)H_R}.
\tag{3}
\]
式 (2) 不能单独给 (3) 的趋零：其上界约为 \(n^{2n}\)，与梯图内部连通词 \(a(R)\) 的量级比较尚未从该公式推出。将 \(R\) 与全体大小 \(2n\) 的连通首集求和也需要避免跨首集重数并量化完成数，当前没有此类全局注入或平均界。

更强地，单独以 \(R\) 作比较在有限数据中并没有朝所需方向发展。独立梯图 subset-DP 与 row-release DP 给出
\[
 \frac{2^{n-1}H_T}{a(R)H_R}
 =\frac12,\quad\frac{1881}{1120},\quad\frac{80122343}{9920222}
 \quad(n=3,4,5).
\]
再用给定的 \(H_R(6)\) 得到第四个精确值；四项约为 \(0.5,1.68,8.08,51.44\)。这只是有限数据，既不证明其发散，也不排除该比值随后下降，或存在带常数预算的固定条带比较。它仅否定一种**单位重数且在这些尺寸已经要求 \(a(R)H_R\) 压过顶行质量**的简单注入。要从条带路线取得归一化上界，仍需全 \(n\) 比较或将许多不同二维首集的加权质量一起纳入，并对逆像累积给出控制。

因此 row-release 是精确的表面纤维分解和强条带熵结论，却没有给出 \(p_n\) 或 (1) 的全 \(n\) 上界。第一未证步骤是：构造一个覆盖顶行首集词的全局注入/重数受控族，或证明所有合适二维首集的加权总质量相对顶行至少以超指数因子增长。

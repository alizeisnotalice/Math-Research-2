# A022 r027 certificates

This package contains only finished and audited material from the cutoff.

- r027-monotone-n7: all 64 n=7 corner-monotone finite IE counts.
- r027-monotone-proof: obstructions to adjacent-turn, contraction-edge, and local four-word proofs.
- r027-merge-rb-production-audit: production aggregator invariants, underflow fixture, and nine rejection tests.
- r027-n12-merge-rb: completed n12 finite production raw, trace-payload replay, and hardened aggregator audit.
- r027-l64-recovery: canonical32 recovery mapping, exact rational necessary-cone replay, and summaries; its ESS is severely concentrated.
- r027-completion-layer: final modular layer-rolling source, Pratt/CRT checks, n=3..7 residues, and the independently verified n=8 top-row completion count.
- r027-global-normalizer: exact rank-one deletion/promotion identities and n=3..5 punctured normalizer tables.

The grid twin-peaks problem remains open. The completion-layer package now certifies the finite top-row completion count through n=8, but does not count full A2(8) or supply an asymptotic conclusion. The punctured identities localize, but do not prove, the missing root-transport estimate. N12 and L64 are finite diagnostics; L64 has severe normalizer concentration, and a passed necessary-cone check is not an accuracy certificate. Later GPU work is excluded.

# A022 第45轮：Lipschitz 安全切割互斥族的锐渐近规模

## 计数对象

在自由边界 \(n\times n\) 方格中用 \(h=(h_0,\ldots,h_{n-1})\) 表示纵向切割，左侧 \(L_h\) 的第 \(y\) 行为 \(x<h_y\)，右侧 \(R_h\) 为其补。要求 \(1\le h_y\le n-1\) 及 \(|h_{y+1}-h_y|\le1\)。事件 \(E_h\) 是左右两侧各有唯一峰，分别在各自外根带。用于下述渐近结论的根带及宽度区间统一固定为
\[
 d=\lceil n/4\rceil,\qquad a=d+1,\quad b=n-d-1,\quad
 x_{\rm left}<d,\qquad x_{\rm right}\ge n-d,\qquad h_y\in[a,b].
\]
两根的所有全图邻点都在本侧，故 \(E_h\) 属于原全图双峰事件。每个 \(E_h\) 的峰距至少 \(n-2d+1\)。因而当 \(n\) 足够大时，\(E_h\subseteq\{\rho>\varepsilon n\}\) 对任意固定 \(0<\varepsilon<1/2\) 成立。

## 舍入类内有共同标号

指定首行目标奇偶 \(\alpha\in\{0,1\}\)。逐行向下舍入，取
\[
 g_y\in\{h_y-1,h_y\},\qquad g_y\equiv \alpha+y\pmod2.
\]
相邻 \(g\) 差为奇数，绝对值至多2，故恰为1。若若干轮廓得到相同 \(g\)，对每一行其宽度只能是 \(g_y\) 或 \(g_y+1\)。

设这一类中最窄、最宽的逐行轮廓为 \(k_y=\min_h h_y\)、\(l_y=\max_h h_y\)。共同左核 \(x<k_y\) 与共同右核 \(x\ge l_y\) 都连通，分别由外侧整列连接各自每行的非空段。二者之间的自由点仅在 \(l_y=k_y+1\) 的行出现，每行恰一个，且两个水平邻点分属左右共同核。若自由点存在，则 \(1\le k_y\le n-2\)，这两个邻点在方格内。选共同左、右的允许安全根各一个，先分别从根出发为两共同核写出连通降序词，末尾再写所有自由点。限制到该类任一切割，任何入左侧或右侧的自由点都有同侧已写的水平邻点，所以两侧分别保有同一对指定根。根安全保证全词恰有两个峰。故该舍入类中所有事件同时有共同标号。

在上述固定外根带区间内，共同安全根存在。另一个适用情形是固定中央首行宽 \(h_0\in[2,n-2]\)、其余行宽允许为 \(1,\ldots,n-1\)，且预先允许两个顶角 \((0,0),(n-1,0)\) 作为根。首行横邻由 \(h_0\) 范围保证安全，两个纵邻分别在必属于左、右的外列。共同标号证明要求各事件允许一对共同安全根。

## 任意两轮廓交集的精确判据

仍在左、右不相交的固定外根带模型，或更一般地已固定同一左右根指派的模型，考虑 \(h,k\) 的共同左侧 \(I=L_h\cap L_k\)、共同右侧 \(O=R_h\cap R_k\)。允许根集可以随轮廓变化，此时每侧需额外存在一个在两事件中都允许且都安全的根。假设这两个共同允许根存在，则
\[
 E_h\cap E_k\ne\varnothing
 \quad\Longleftrightarrow\quad
 L_h\setminus L_k,\;L_k\setminus L_h
 \text{ 的每一连通分量都含一顶点同时邻接 }I,O.
\]
必要性为第42轮的差分量最大标签判据。根在共同侧，故该最大点在两个相关限制图中都需要更高邻点，且两邻点分别来自 \(I,O\)。

充分性由降序词构造给出。两共同侧连通，先写各自以共同允许安全根开头的连通词。随后对每一差分量，首先写一个同时邻接 \(I,O\) 的桥顶点，再从该点写整个分量的连通词。对于两切割，桥顶点各有一个已写的同侧邻居，分量内其他点有已写的同分量邻居。两切割因此都保有同一对侧内峰，根安全保证全图也恰有这两个峰。

对 1-Lipschitz 轮廓，双侧桥可由行宽判定。在 \(h_y>k_y\) 的行，差点邻接 \(I\) 要求 \(x=k_y\)，邻接 \(O\) 要求 \(x=h_y-1\)。水平邻接直接给出这两个必要条件。竖直邻接则分别用 \(k_{y\pm1}\le k_y+1\) 与 \(h_{y\pm1}\ge h_y-1\) 给出同样条件。故桥点只可能在恰差1的行，此时两个水平邻点实际提供双侧桥。交换 \(h,k\) 得到同样结论。于是判据等价于每一差分量包含一个所在行恰差1的点。若共同允许根集在任一侧不交，则两个事件的同指派交集已空。

## 互斥容量上界与渐近锐性

由于每个舍入类有共同标号，一族逐词两两互斥的 \(E_h\) 在每类最多取一个。在固定 \(h_0\) 的情形用 \(\alpha=h_0\bmod2\)，则 \(g_0=h_0\)，可能的 \(\pm1\) 增量序列至多 \(2^{n-1}\) 个。因此第44轮达到的 \((1-o(1))2^{n-1}\) 是固定中央起点的锐渐近。

对上述共享外根带的近中央宽度区间 \([a,b]\)，现允许任意 \(h_0\)，统一用 \(\alpha=0\)。可用 \(g_0\) 是 \([a-1,b]\) 中的偶数，至多 \((b-a+1)/2+1\) 个。记最大互斥族的规模为 \(K_n\)，则
\[
 K_n\le 2^{n-1}\bigl((b-a+1)/2+1\bigr).
\]
下界取所有偶数起点并且全程留在 \([a,b]\) 的 \(\pm1\) 轮廓，组成族 \(\mathcal H_n\)。整个族统一满足 \(h_y\equiv y\bmod2\)，故第44轮的奇偶排重对不同起点照样成立。计数时对每个符号序列令 \(S_0=0\)，\(S_1,\ldots,S_{n-1}\) 为部分和，记 \(m=\min S_j,M=\max S_j\)。允许的偶数起点恰为 \([a-m,b-M]\) 中的偶数，数目至少 \((b-a+1)/2-(M-m)/2-1\)。在公平独立符号下，
\[
 \mathbb E(M-m)\le 2\mathbb E\max_{j\le n-1}|S_j|\le4\sqrt{n-1}.
\]
取首次达到 \(|S_j|\ge t\) 的时间 \(\tau\)。在 \(\tau\le n-1\) 上，条件于到达时的历史，后续符号仍均值为零，故 \(S_{n-1}^2\) 的条件期望至少为 \(S_\tau^2\ge t^2\)。于是 \(\Pr(\max|S_j|\ge t)\le\min(1,(n-1)/t^2)\)，积分给出最后一个不等式。

对符号序列求和后，
\[
 2^{n-1}\bigl((b-a+1)/2-2\sqrt{n-1}-1\bigr)
 \le |\mathcal H_n|\le K_n
 \le 2^{n-1}\bigl((b-a+1)/2+1\bigr).
\]
由于 \(b-a+1=n-2\lceil n/4\rceil-1\)，特别有
\[
 |\mathcal H_n|\sim K_n\sim (n/4)2^{n-1}.
\]
相对固定中央起点，共享安全外根带的所有互斥 1-Lipschitz 切割至多增加 \(\log n+O(1)\) 的对数预算，全起点同奇偶族实现这个增加。

## 原远峰事件的充分条件

记 \(N=n^2\)，\(Z_2=A_2/N!\)。令 \(Z_L(h)\) 为左侧的根带一峰词数除以 \(|L_h|!\)，\(Z_R(h)\) 同理。所构造族互斥且要求严格远峰。均匀取 \(h\in\mathcal H_n\)，置
\[
 D_n=\mathbb E_h\log\!\left(\frac{Z_2}{Z_L(h)Z_R(h)}\right).
\]
由计数交错与 Jensen，
\[
 \mathbb P_2(\rho>\varepsilon n)
 \ \ge\ \sum_{h\in\mathcal H_n}\frac{Z_L(h)Z_R(h)}{Z_2}
 \ \ge\ |\mathcal H_n|e^{-D_n},
 \qquad 0<\varepsilon<1/2,\quad n\text{ 足够大}.
\]
故若沿无穷子列证得 \(D_n\le(n-1)\log2+\log n+C\)，其中 \(C\) 为固定常数，则该子列远峰概率的下极限至少 \(e^{-C}/4>0\)。相比第44轮固定起点的条件，这一族放宽了 \(\log n+O(1)\) 的代价预算，仍需证明受原 \(A_2\) 归一化的平均区域计数下界。

对本族每项接口 \(e=2n-1\)，且对任一原标号至多一个切割事件成立。保持根带约束时，联合律自然盆地落在该族的概率与原律拼接并集概率之间满足
\[
 2^{-(2n-1)}\mathbb P_2\Big(\bigcup_{h\in\mathcal H_n}E_h\Big)
 \le \widehat{\mathbb P}_2\big(C\in\mathcal H_n,\ \text{两根在指定根带}\big)
 \le (3/4)^{2n-1}\mathbb P_2\Big(\bigcup_{h\in\mathcal H_n}E_h\Big).
\]
这是第44轮的逐接口双边界在此互斥族的应用。原拼接事件有固定正质量时，该自然盆地概率仍指数小。

## 本机交叉核验

以 Python 3.15.0 运行 audit_rounding_capacity.py。对 \(n=4,\ldots,7\) 的 849 个固定中央起点轮廓检查舍入，以单调揭示闭包确认 88 个舍入类各有完整共同词。对 \(n=4,\ldots,6\) 的 19,387 个轮廓对，用揭示闭包独立判定交集非空，与差分量双侧桥判据逐对比较。闭包判定从两个根先写开始。任一有效词可把两根稳定前置，而已合法的顶点加入只会增加后续合法邻点。对 \(n=7,\ldots,14\) 的8个安全根带区间，用一维转移和按每条走步序列的极差计数两种整数算法逐项复核全起点族规模。输出见 audit_rounding_capacity.stdout。执行正常退出。容量渐近与交集判据由上述解析证明给出。

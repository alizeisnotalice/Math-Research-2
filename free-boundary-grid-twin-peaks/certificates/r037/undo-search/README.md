# r046：Psi 搜索的局部 Undo 优化

本包是 r037 归档前的最小公开准备材料。它实现并冻结了对 r040 一峰词 Psi 搜索器的局部回滚优化；不包含生产搜索输出，也不提出新的数学定理。

## 数学对象与状态

对一个从 root 开始的一峰词，pos[v] 是顶点秩。每个非 root 顶点必须有严格更早的邻点。对顶点 p：

* l[p] 是其邻点的最早秩；
* sole[v] 是 v 的唯一早邻；若没有或有多个则为 -1；
* b[p] 是以 p 为唯一早邻的顶点的最早秩；若没有则为 N+1；
* 对 root 及其邻点以外的 p，R_p = b[p] - l[p] - 1 必须为正，Psi 累加 (l[p]-1)/R_p。

交换两项的秩只会改变：端点及邻点的 sole，以及这些顶点、旧 sole-parent 和其一层邻域的 l,b。实现将前者记为 S、后者记为 P，只快照 S/P、两个交换位置和 Psi。方格最大度为 4，故每个提案的 Undo 快照大小由常数个局部邻域控制，而不是随 N 增长。

候选被拒绝或使一峰条件失效时，rollback 恢复全部快照项；接受后才保留增量状态。审计时另复制一次完整 State、从头重建，并逐项比较 a,pos,l,b,sole 与 Psi。完整 State 拷贝仍用于保存新 best 和审计，这两个场景是有意保留的。audit=1 只审计合法候选；非法候选的回滚正确性由局部影响集与快照恢复不变量承担，不能把它误写成一次从头重建的审计。

## 相对路径小重放

在公开证书树中，本目录预期为 certificates/r037/...，并要求冻结 r040 源位于相对目录 ../../r036/finite-candidates/psi_search.cpp。运行：

    REPLAY_OUT=/Volumes/data/CodexTemp/T2/your-fresh-replay bash replay_small_gate.sh

脚本会验证 r040/r046 源哈希，分别编译，在四个小例以 audit=1 运行 10,000 次提案，用 cmp 比较完整输出，并以 verify_psi.py 作独立精确验证。若公开树采用别的布局，可设 BASELINE_SOURCE=/path/to/r040.cpp；该文件仍须匹配冻结 SHA-256。

编译缓存使用 data 卷共享缓存，输出及 build 均置于 REPLAY_OUT，不写进证书树。

新增 audit_rollback.cpp 完整枚举 n=2、3 的全部一峰词及所有位置交换：非法候选直接回滚；合法候选从头 rebuild 后模拟拒绝回滚。精确核对 a,pos,l,b,sole,psi 恢复，包含同位置和 root 的空操作。实际通过 256 与 2,395,008 项；属于有限实现核验。

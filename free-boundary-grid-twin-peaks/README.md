# A022：自由边界方格双峰距离

对象为最近邻自由边界图 G_n=P_n□P_n，N=n²。双射标号均匀，峰指比所有图内邻点标签高的顶点；P₂ 是恰有两个峰条件下的原均匀律，ρ_n 为原图曼哈顿距离。

目标：证明对所有固定 ε>0 有 P₂(ρ_n>εn)→0，或构造固定 ε,c>0 及无穷子列使该概率至少 c。总目标在严格闭合前保持开放。

# A022：自由边界方格双峰距离

对象为最近邻自由边界图 G_n=P_n□P_n，N=n²。双射标号均匀，峰指比所有图内邻点标签高的顶点；P₂ 是恰有两个峰条件下的原均匀律，ρ_n 为原图曼哈顿距离。

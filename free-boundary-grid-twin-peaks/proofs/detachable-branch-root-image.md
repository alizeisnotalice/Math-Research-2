# r018b：可拆分支像集的首次合并根公式

沿用 r018 的规范可拆块：首次合并前的两个分支按最小顶点编号写为 \(A,B\)，合并点为
\(w\)，并把 \(B\) 作为规范分支。令

\[
 q_B(w)=\frac{\sum_{v\in B\cap N(w)}a_B(v)}{a(B)}, \tag{1}
\]

其中 \(a_B(v)\) 是 \(G[B]\) 单峰相对词根在 \(v\) 的数目。这里 \(w\) 总与 \(B\)
有边是首次合并状态的定义；(1) 额外要求的是**该分支限制词的根**确实贴合 \(w\)，两者
不能混同。

## 1. 像集的精确识别

规范可拆块插入的像集，恰等于所有规范首次合并二峰词中满足

\[
 \text{\(B\) 的限制词之根属于 }B\cap N(w) \tag{2}
\]

的词。

正向：可拆块源词为 \(A,w,B,\tau\)，故 \(B\) 的首点（限制词根）邻接 \(w\)；交错
不改变各侧限制词根，且 \(w\) 是首次合并。

反向：给定 (2) 的二峰词，取其首次合并前的规范两个分支及各自限制词。把整个 \(B\)
块移到 \(w\) 后，保留 \(A\)、\(B\) 内部词和尾词的相对次序，得到一峰词
\(A,w,B,\tau\)：\(w\) 接到 \(A\)，\(B\) 根接到已出现的 \(w\)，其余 \(B\) 点有
本支较早邻点，尾词原有较早邻点仍全部更早。该操作与前向交错互逆。首次合并状态唯一，
最小编号约定消除了两个分支的交换，故没有额外纤维。

因此有精确恒等式

\[
 \boxed{
 A_1\mathbb E_1J
 =\sum_{(S,w)}W(S,w)q_B(w).
 } \tag{3}
\]

这是原条件律下可研究的根贴合加权平均，而不是固定树或指定构造族的计数。

## 2. 同一账本中的 \(\beta=0\) 支持

令 \(a=|A|,b=|B|\)。在固定首次合并状态中，\(W\) 已包括所有 \(\binom{a+b}{a}\)
交错。由“\(\beta>0\) 当且仅当低峰分支为单点”，其正支持比例恰为

\[
 \psi(a,b)=
 \begin{cases}
 1,&a=b=1,\\
 b/(b+1),&a=1<b,\\
 a/(a+1),&b=1<a,\\
 0,&a,b\ge2.
 \end{cases} \tag{4}
\]

故

\[
 \mathbb P_2(\beta>0)=\frac1{A_2}\sum_{(S,w)}W(S,w)\psi(|A|,|B|). \tag{5}
\]

这给出两个彼此不同、可闭合的平均问题：

\[
 \sum Wq_B(w)\quad\text{（若足够大则由 (3) 增强 \(R\) 下界）},
\]

以及

\[
 \sum W\psi(a,b)\quad\text{（若相对 \(A_2\) 很小则 \(\beta\) 支持衰减）}.
\]

现有仅知 \(\mathbb E_1S\asymp N\)，并不控制任一和；尤其不能以 \(B\cap N(w)\ne\varnothing\)
替代 (1)，也不能以 \(a,b\) 的普通计数代替其 \(W\)-加权平均。

## 3. 独立整数核验

`audit_first_merge_root_n4.py` 用子集 DP 计算每个诱导子图的单峰根计数、无出生完成数
\(h(S)\)，直接实施 (3)--(5)。它独立重现已认证值：

\[
\begin{array}{c|r|r|r}
n&A_1&A_2&\sum Wq_B\\\hline
3&29568&143808&97618\\
4&35704394880&779299174080&389050636544
\end{array}
\]

其中 \(n=3\) 的最后一列恰等于 r018 可拆块枚举的 \(\sum_LJ(L)=97618\)，交叉验证了
像集双射。对 \(n=4\)，同一程序得 \(\beta>0\) 数为 \(266753826624\)、\(\beta=0\) 数为
\(512545347456\)，也与已有独立递推一致。选中像的单个最大首次合并秩贡献在 \(M=8\)；
这是有限诊断，不是渐近结论。

## 4. 第一可研究平均引理

要由多步插入达到 \(\log R_n\ge c n\log n\)，足够的新命题是

\[
 \frac1{A_1}
 \sum_{(S,w)}W(S,w)q_B(w)\ge\exp(cn\log n). \tag{6}
\]

要直接证明 \(\mathbb P_2(\beta>0)\to0\)，则足够证明 (5) 右端趋零。两者都明确要求
对原 \(W\)-完成数权重的估计；r017 的自由能、固定分支构造或未加权接口大小均不能代替。

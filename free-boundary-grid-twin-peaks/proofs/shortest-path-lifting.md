# 最短路内部点提升：总界与大纤维障碍

状态：严格证明；适用于有限连通图，网格结论始终用原图距离。N为顶点数，A_k为恰有k峰的标号数，R=A₂/A₁。令p_d为均匀单峰条件律下，降序前d个顶点按顺序形成长度d−1的原图最短路的概率。下降阶乘记作(x)_k。

## 1. 提升与唯一恢复

给定双峰标号L，最高峰为u，低峰为v，d=d_G(u,v)≥2。按固定规则选一条最短路
\[
 u=z_0,z_1,\ldots,z_d=v.
\]
从降序排列中取出内部d−1点，把它们按z₁,…,z_{d−1}顺序放到u之后；其余点保留相对顺序，重新赋予1,…,N的标签，得到L′。

L′恰有一个峰u：每个提升点有更高的路径前驱；v有更高的邻点z_{d−1}；任意其余原非峰点，其原有的更高邻点若在路径内部则被提升，否则相对次序保留。全局最高点u仍是峰。L′的降序前d点正是z₀,…,z_{d−1}，是原图最短路前缀。

固定d和输出L′，上述内部点由输出的第2至第d个点唯一确定。只须记录它们在原L中各自的旧标签；这些标签是{1,…,N−1}中d−1个互异值。将这些点放回旧标签，再按剩余相对顺序填入余下标签，即恢复唯一L。无需另存v：恢复后的L自行确定第二峰。因而每个输出的原像数至多(N−1)_{d−1}。

于是对每个整数r≥2，
\[
 \boxed{\mathbb P_2(\rho\le r)
 \le R^{-1}\sum_{d=2}^{\min(r,\operatorname{diam}G)}(N-1)_{d-1}p_d.}
\]
这补齐了附件中该总界的注入账本；它不同于只计固定一条路径或固定根的概率。

## 2. 原问题的必要窗口

在n×n方格，N=n²。若某无穷子列上log R_n≥a n log n（a>0固定），取0<ε<min(a/2,2)，则用p_d≤1得
\[
 \mathbb P_2(\rho\le\lfloor\varepsilon n\rfloor)
 \le\exp\{-(a-2\varepsilon)n\log n+O(\log n)\}\longrightarrow0.
\]
故该子列上远峰概率最终至少1/2，足以证伪。结合第2轮加权提升，原题肯定答案必须同时满足
\[
 \boxed{R_n/n²\to\infty,\qquad \log R_n=o(n\log n).}
\]
**这两个条件仅为必要条件；尚未证明实际R_n是否落入该窗口。**

取r=2n−2，左侧为1，得到普适上界
\[
 R_n\le(2n-3)N^{2n-3},\qquad \log R_n\le(4+o(1))n\log n.
\]
若能严格加强p_d的完成数加权衰减，则上述必要窗口仍有缩小空间；本轮没有这样的渐近定理。

## 3. 最大纤维不能统一改成C^d d!

令n≥4，u=(0,0)，v=(n−1,0)。它们之间的唯一最短路内部点集为P={(i,0):1≤i≤n−2}，p=n−2。令H=G\P，q=(n−1,1)，每个内部点的锚为(i,1)。H\{v,q}连通。

从u在H\{v,q}中连通生长，先沿(0,1),(1,1),…,(n−2,1)纳入全部锚点，再取前r−1个点，其中r=⌊N/2⌋。接着揭示v、q，再按固定连通次序完成H。v在H中的唯一邻点q尚未揭示，故H序恰有u、v两个出生点。

将P的有区别顶点以任意次序、任意位置穿插到v之后的H尾部。所有内部点的锚已在v之前，故不会新增峰；u,v仍是两峰。每个这样的标号提升P后都得到同一个输出。尾部H点数h=⌈N/2⌉−p，因此纤维大小精确为
\[
 F_n=(h+p)!/h!=\big(\lceil N/2\rceil\big)_{n-2}.
\]
n≥6时F_n≥(n²/3)^{n−2}。对任意固定C，这比C^{n−1}(n−1)!增长更快，故不存在适用于全部输出的C^d d!纤维上界。

这是否定一种过强计数改进的严格障碍，**不是原问题的反例**：尚未证明这类输出占A₁的质量足够大。

## 4. 实际核验

verify_shortest_lift.py枚举3×3全部143808个双峰标号，逐一核验唯一峰输出、原图最短路前缀及旧标签恢复。距离2、3、4的最大原像分别7、48、175，均不超过8、56、336的理论界。

geodesic_fiber.py穷尽n=4、5、6构造的56、1716、73440个穿插，独立复查峰集和同一输出；n=7仅核验4个确定性样本（一般结论由上面的推导承担）。具体结果见computation/results/*r003.json。

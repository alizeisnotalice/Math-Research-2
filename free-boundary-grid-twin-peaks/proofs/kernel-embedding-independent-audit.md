# S8 嵌入与孤立洞放大的独立审计

状态：严格的辅助完成核反例扩展；不是 twin-peaks 原题的反例。

令 S8 为既有 8×8 连通前缀，独立整数认证给出 m=49、边界14 和
p8 = 198947127410665164977798511882264205133 / 686832275881468514216635111007873246808。
这里 p(S) 是所有有序二步延伸的完成数和除以 h(S)。

对任意 n>=8，把 8×8 形状置右下，块外全并入 S。补图就是平移的 R8，诱导图不变。块外新增的邻接只可碰到局部 (0,0),(1,0)，二者本已 frontier，故边界和二步对不变。S 连通：n=8 是原例；n>8 时块外连通并通过局部 (0,1) 左侧外点接入 S8。因此同一 14p8>4 对一切 n>=8 成立。

对 n>=18，再挖 H={(2i+1,2j+1):0<=i<=4,0<=j<=3}。H 最大坐标 (9,7)，右下块起于 n-8>=10，故 H 与 R8 无边；各洞互不相邻且邻点全在 S。删洞后 S 仍连通（块外偶坐标骨架避开奇-奇洞）。故新补图为 R8 加20个孤立点：m=69，边界34；洞不贡献二步对，原12个二步对未变。

完成计数严格按带标号穿插：h_new(S)=(69!/49!)h8(S)，而每个二步项 h_new(Sxy)=(67!/47!)h8(Sxy)。故
p_new=(49*48)/(69*68)*p8，且
34 p_new=(392/23)p8=198947127410665164977798511882264205133 / 40298832513453509762710733554033379277
约为4.936796304067815，大于4。

一般 ell 个同类洞给 (14+ell)p_ell=(14+ell)*49*48/((49+ell)(48+ell))*p8。相邻比大于1当且仅当 ell<20，ell=20 时相等；因此 ell=20、21 并列最优（若21洞可实现）。

实际独立图论检查器在 n=18,19,32 上均确认：基底 R=49、boundary=14、two_step_pairs=12；加洞后 R=69、boundary=34、two_step_pairs=12，补图分量为20个单点、一个2点和一个47点。完整 JSON 同目录。

范围：这只迫使任意普适点态 p(S)<=C/boundary 的 C 至少4.9367963；不否定更大常数，更非双峰问题反例。

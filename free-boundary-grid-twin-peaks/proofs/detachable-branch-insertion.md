# r018：规范可拆分支的多步插入与其真实缺口

令一峰标号按高到低为 \(L=(x_1,\ldots,x_N)\)。已有精确恒等式

\[
 R_n=\frac{A_2}{A_1}=\frac{\mathbb E_1S}{\mathbb E_2\beta},
 \qquad \mathbb E_1S\asymp N, \tag{1}
\]

且 \(\beta>0\) 当且仅当首次合并前的低峰分支是单点。本轮审计能否把该单点操作
替换为长 \(b\) 的低分支，从而给出超面积的 \(R_n\) 下界。

## 1. 一个可逆的多步插入下界

称一峰词有一个**规范可拆块** \((a,b)\)（\(a,b\ge1\)），若它可写为

\[
 L=(\alpha_1,\ldots,\alpha_a,\ w,\ \gamma_1,\ldots,\gamma_b,\ \tau), \tag{2}
\]

其中 \(A=\{\alpha_i\}\)、\(B=\{\gamma_i\}\) 无边相连，\(w\) 同时邻接 \(A\) 与
\(\gamma_1\)，\((\gamma_1,\ldots,\gamma_b)\) 是从 \(\gamma_1\) 开始的连通增长词，且
\(\min A<\min B\)（固定顶点编号的规范定向）。

把 \(\alpha\) 与 \(\gamma\) 作任意保序交错、随后放入 \(w\) 和原尾词 \(\tau\)。前
\(a+b\) 点恰有两个连通分支，\(w\) 是首次合并；尾词的每一点原有的较早邻点仍更早。
故每个交错都给出恰二峰词。第一次合并状态唯一恢复 \(A,B,w\)、两侧内部词和尾词，
规范定向消除了交换两个分支的二重性。因此这是无重注入，给出

\[
 \boxed{
 R_n\ge\mathbb E_1 J(L),\qquad
 J(L)=\sum_{(a,b)\text{ 规范可拆块}}\binom{a+b}{a}.
 } \tag{3}
\]

规范定向只按固定顶点编号，不按全局标签；任意交错后 \(B\) 根未必是较低峰。当
\(a,b\ge2\) 时，两支均非单点，才与交错无关地严格有 \(\beta=0\)。因此 (3) 的长分支
部分确实在试图制造 \(\mathbb E_2\beta\) 的小质量，而不是把已有单点提升重新计数。

## 2. 为什么它目前不推出超面积比值

(3) 把问题缩为一峰完成数律下 \(J\) 的下界。没有逐词的正下界：一个词可以在早期
填满所有可用邻接，从而不存在任何满足 (2) 的可拆块。更本质地，(2) 是对**有序**
完成数核的局部模式要求；单峰前缀的普通边界大小或 r015 的固定树子族不控制它在
均匀一峰律下的质量。

即使有许多可拆块，必须使用 (3) 的无重账本。若忽略规范定向，交换两个首次合并分支
会产生真实的二重纤维；若忽略整个 \(B\) 的恢复而只记录根点，则纤维可随 \(b\) 成组合
量增长。故把每个长度 \(b\) 的候选简单相乘来声称 \(n^{cn}\) 个输出，是不合法的。

对于 \(b=1\)，这个构造包含已有单点两步插入的一部分；不定向的 \(n=3\) 审计已经
出现最大纤维 2。已有精确恒等式 \(B_+=A_1\mathbb E_1T\) 只计低峰为单点的方向，
不能自动升级为长分支的正比例质量。

## 3. 有限核验和具体失效

`audit_detachable_branch_n3.py` 完整枚举 \(3\times3\) 的全部 \(A_1=29568\) 个一峰词。
对 \(b=1\) 的不定向操作，共有 35264 个源事件、114624 个候选输出，均重新判定为二峰；
但只有 99840 个不同输出，最大负载恰为 2。脚本还枚举所有规范可拆块：存在一峰词

\[
 (0,1,3,2,4,5,6,7,8)
\]

其 \(J=0\)。因此即使在最小非平凡方格，也不能用逐源“至少一个延迟分支”建立 (3)
的正下界。

这不是对 \(\mathbb E_1J\) 的渐近反例；它精确标出第一未证步骤：需要一个关于均匀
一峰完成数核的加权下界 \(\mathbb E_1J\)，或等价地需要控制 \(\beta=0\) 首次合并
状态的总完成数质量。现有 \(R\asymp N/(\mathbb E_2\beta)\)、首次合并分解和固定
距离纤维障碍均不提供该估计。

## 4. 结论

多步插入并未给出 \(R_n\ge\exp(cn\log n)\)，也尚不能证明
\(\mathbb P_2(\beta>0)\to0\)。它提供了一个严格、可继续估计的候选量 \(J\)，同时
排除了无累计权重预算地把分支长度选择相乘的做法。下一项真正足以改变结论的估计是
\(\mathbb E_1J\) 的超面积下界，或对 \(\beta=0\) 完成数权重的全局下界。

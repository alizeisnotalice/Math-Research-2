# 全局前二标号扇区：收缩、严格恒等式与比较障碍

令 $S=\{u,v\}$ 是非邻二点集。定义 $h_G(S)$ 为在 $S$ 已按最高两标号揭示后，余下顶点的降序加入序列数，每个加入点必须邻接早先集合。把 $S$ 收缩成单个根，删环并合并重边，得到根图 $G/S$。逐序列对应立刻给出

$$h_G(S)=a(G/S;\mathrm{root}),$$

右端是收缩图从该根开始的单峰增长序数。这里保留的是原图中 $u,v$ 的曼哈顿距离；收缩只用于计数。

若把 $u,v$ 固定为全图最大的两标号，非邻性使它们自动为两个峰。不存在其他峰恰好等价于其余点按上式增长，故

$$A_{2,\mathrm{top2}}=\sum_{u\ne v,\,u\not\sim v}h_G(\{u,v\}).$$

该数是一般 $A_2$ 的子计数；一般双峰标号的前二全局标号可能相邻，不能混用两者。

## 与首次合并的精确联系

固定首次合并状态 $(S,w;A,B)$，令 $a=|A|,b=|B|,q=a+b$。固定两侧的单峰内部序列及首次合并后的后缀后，所有 $\binom q a$ 个两侧交错均给出一般双峰标号。前二全局标号分别来自两个分支，当且仅当交错起首为 $AB$ 或 $BA$，故恰有

$$2\binom{q-2}{a-1}$$

个交错。因此该状态的前二扇区比例严格为

$$\theta(a,b)=\frac{2ab}{q(q-1)}.$$

所以 $A_{2,\mathrm{top2}}/A_2$ 是首次合并权重下的 $\theta(|A|,|B|)$ 平均。这个等式把“所有方格上前二扇区有固定正质量”准确地归约为：首次合并不能在总权重意义下由极度不平衡的两分支支配。它也解释了当前障碍：若某侧为单点，比例仅为 $2/q$。`audit_top2_first_merge.py` 用已有首次合并递推独立验证 $n=3,4$，与前述 $h$ 计数一致。

## 独立的包含—排除审计

对任意独立集 $I$，令 $C(I)=N!\,\mathbb P(I\text{ 均为峰})$。固定全局前二种子 $S$ 后，可能出现额外峰的点只能在
$Z_S=V\setminus\operatorname{closed}(S)$。条件化并包含—排除给出

$$h_G(S)=\frac1{N(N-1)}\sum_{I\subseteq Z_S\atop I\text{ independent}}
(-1)^{|I|}C(I).$$

`audit_top2_h.py` 用此式和 Python 任意精度整数独立重算 $n=3,4,5$ 的每个非邻种子对，逐距离合并后与反向增长 DP `top2_h_dp.cpp` 一致。特别地，前二扇区占一般双峰计数的比例为

| $n$ | $A_{2,\mathrm{top2}}/A_2$ |
| --- | ---: |
| 3 | $81984/143808\approx0.5701$ |
| 4 | $350682265920/779299174080\approx0.4500$ |
| 5 | $2910913997686940072256/7063261481362958280000\approx0.4121$ |

这是有限精确证据；尚无对所有方格的正下界。

## 可用而不足的单调性

若在固定顶点集、固定种子上向图中加边，则每个原来有效的增长序列仍有效，故 $h$ 对加边单调。它不能直接比较不同种子对的收缩图：收缩前会删去不同的两个顶点，且剩余边结构通常互不包含。

更强的候选“距离增大使 $h(\{u,v\})$ 增大”已经严格失败。在 $5\times5$，反向 DP 给出

$$
h(\{(0,0),(4,4)\})=525072267486404352,
$$

而中行相距二的对 $\{(2,2),(4,2)\}$ 有

$$
h(\{(2,2),(4,2)\})=6211927162564578000.
$$

前者原图距离为 $8$，后者为 $2$。因此根移动、反射或加边若要导出前二扇区的远峰正占比，必须比较聚合权重或构造有受控重数的映射；逐对距离单调性不是可用引理。

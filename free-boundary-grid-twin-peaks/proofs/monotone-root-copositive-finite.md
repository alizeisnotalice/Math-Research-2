# r019：原根切协方差在非负锥上的有限精确认证

设 B 的 (j,k) 项为原 K=2 条件律、均匀定向根 (X,Y) 下的
Cov(s_j(X),s_k(Y))，s_j(v)=1−2·1{x(v)≤j}。这里每个条目都已经减去边际均值乘积。

任何只依赖横坐标的非降函数都可唯一写成
f(x)=c+Σ_j a_j s_j(x)，其中 a_j=(f(j+1)−f(j))/2≥0。
因此 Cov(f(X_x),f(Y_x))=aᵀBa。要求 −B 共正等价于这个同函数相关不等式；
它不要求所有 B_jk≤0，也不要求 −B 半正定。对于非零 a，可齐次归一化 Σa=1。

## 有限面枚举定理

对任意实对称 d×d 矩阵 B，二次型 q(a)=aᵀBa 在单纯形
Δ={a≥0:Σa=1} 上达到最大值。取所有最大点中支撑 I 最小者。它位于该面的相对内部，
一阶必要条件为

B_II a_I = λ·1，1ᵀa_I=1，q(a)=λ。

这个点的带边框线性系统

[ B_II  −1 ; 1ᵀ  0 ] [a_I;λ] = [0;1]

必可选为非奇异系统。否则取非零核向量 (d,δ)，满足 B_II d=δ·1、1ᵀd=0。
乘以 a_Iᵀ 并利用驻点条件得到 δ=0；故 d≠0 且既有正分量又有负分量，B_II d=0。
沿 a_I+t d，约束和二次型均不变；选择 t 到首次触及面边界，得到同值而支撑更小的最大点，矛盾。

所以枚举所有非空支撑、求解其非奇异带边框系统、保留非负解，再取最大候选值，
就得到全局最大值。候选中可能有局部最小或鞍点，但它们都是可行点，不会造成虚假的全局上界。
奇异系统可按上述最小支撑论证跳过。本次所有被枚举系统实际都非奇异。

此论证仅用紧性、面内微分及线性代数。没有使用共正锥有限阶 SDP 外逼近，也没有把其必要条件当充分证书。

## 原方格 n=3..7 的精确结果

`exact_simplex.py` 直接读取整数根矩，使用 Python Fraction 求解每一个面。
输入 n3 由 9! 全枚举核验，n4..6 使用完整独立集，n7 使用 D4 轨道的八变换平均。
结果中的 μ_n 是 −max_{a∈Δ}aᵀB_na，因此对本表有限 n 有严格证书

Cov(f(X_x),f(Y_x)) ≤ −μ_n (Σ_j a_j)² < 0

（f 非常数且非降）。

## 范围与第一缺口

这些结果只证明 n=3..7。μ_n 随这些有限尺寸迅速下降，不能猜定一个对 n 一致的锥内负间隙；
即便一般 n 的非正性成立，也仅给 C_n≤0，仍不足以给原峰距的固定正比例尾部。
原任务仍需要原模型下尺度为 n² 的负协方差，或独立边际方差下界与可用负相关结论。
本轮没有给出这些一致估计，也没有证明或证伪原远峰命题。

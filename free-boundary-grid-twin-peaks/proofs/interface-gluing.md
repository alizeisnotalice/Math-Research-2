# r011：安全盆地的接口拼接与根迁移障碍

本笔记只研究一个固定划分的精确拼接账本，以及它对“把近根质量可逆地搬到远根”的
限制。记 (G=P_n\square P_n)，但前两个命题也适用于任意有限图。所有计数仍是
均匀标号且恰有两个严格局部峰的未归一化计数；不使用 n=7、n=8 的数值作为证明。

## 1. 安全根的交错双射

固定 (V=A\sqcup B)，令 (a=|A|,b=|B|)，并取 (p\in A,q\in B)。这里的
**几何安全**假设是

\[
 N_G(p)\subseteq A,\qquad N_G(q)\subseteq B. \tag{1}
\]

令 (u_A(p)) 是 (G[A]) 上唯一局部峰为 (p) 的相对标号数，(u_B(q))
同理。一个长度 (a+b) 的 (A/B)-交错词记录全局标号从低到高（或从高到低，
固定一种约定）属于哪一侧；此类词数为 \(\binom{a+b}{a}\)。

**引理 1（精确交错）。** 在 (1) 下，限制到两侧相对标号和交错词给出双射

\[
 E(A;p,q)\longleftrightarrow
 \mathcal U_A(p)\times\mathcal U_B(q)\times\operatorname{Sh}(a,b),
\]

因而

\[
 |E(A;p,q)|=\binom{a+b}{a}u_A(p)u_B(q). \tag{2}
\]

**证明。** 属于 (E(A;p,q)) 的全标号按其定义唯一地给出两侧唯一峰的相对
次序及其交错词。反之，给定两侧各一个峰的相对标号与任意交错词，侧内非峰仍有同侧
更高邻点，故在全图仍非峰；(1) 保证两个侧内峰没有跨界邻点，故仍是峰。没有
第三个峰，故得到 (E(A;p,q))。两个构造互逆。\(\square\)

注意 (2) 不是把两侧的**绝对**标签集预先固定；交错词已经精确计入所有
\(\binom{a+b}{a}\) 个标签集及交错。故完整矩形构造中的二项式因子并非必须付出的
面积级熵损失。

对自然森林，令 (L(\alpha,\beta,w)) 是该双射给出的标号。此前的精确式可写成

\[
 \Omega_{p,q}(A)=
 \sum_{\alpha\in\mathcal U_A(p)}\sum_{\beta\in\mathcal U_B(q)}
 \sum_{w\in\operatorname{Sh}(a,b)}
 \theta_{A,B}(L(\alpha,\beta,w)), \tag{3}
\]

其中 \(\theta\) 是所有自然森林箭头均不跨界的条件概率。因此

\[
 2^{-|E(A,B)|}\binom{a+b}{a}u_A(p)u_B(q)
 \le\Omega_{p,q}(A)
 \le\binom{a+b}{a}u_A(p)u_B(q). \tag{4}
\]

这是对具有几何安全根的固定盆地的精确、无重数拼接表达。它与 r010 的
“森林根邻域安全只损失 \(4^{-8}\)”兼容：后者把真实远根标号质量的一个固定比例
放入满足 (1) 的盆地和；(3) 再对每一个这样的盆地展开。

## 2. 真正未消去的接口代价

式 (2) 消除了一个常见但错误的面积级损失：若为了方便而只保留“所有 A 标签均
小于所有 B 标签”的一个规范交错词，则每对侧内标号只保留一个交错，而正确纤维有

\[
 \binom{a+b}{a}.
\]

在平衡情形 \(a=b=N/2\)，这个错误规范化损失是
\(inom N{N/2}\asymp2^N/\sqrt N\)。这是一条严格的纤维计数，不是熵启发式。
因此任何将两侧标签整体分层的“胶合”证明，最早已经在选规范交错词处付出面积级
指数代价；必须保留 (3) 的全部交错词。

保留全部交错后，式 (3) 中唯一显式损失是 \(\theta_{A,B}\)。当前一般界只有
\(2^{-|E(A,B)|}\)，所以对于长度 \(\Theta(n)\) 的切割，现有方法仍留下
\(\exp[-\Theta(n)]\) 的接口代价。这里不能把下界误读为“真实代价必然指数”：要把
它改进为常数，必须利用交错词平均、接口比较或新的结构，而非只由点态
\(a_v/(a_v+b_v)\ge2^{-b_v}\) 推出。

## 3. 根迁移不是局部常数纤维：路径证书

即使没有接口，唯一峰根的位置本身也能带来指数级纤维差。对路径 \(P_m\)，令
\(U_m(r)\) 为唯一局部峰在第 (r\) 个顶点（从 0 起）的相对标号数。则

\[
 U_m(r)=\binom{m-1}{r}. \tag{5}
\]

证明是：从两个端点向根，标号必须严格上升；左右两条强制链的相对交错可任意，
共有 (5) 个。于是端点根的纤维为 1，而中央根的纤维为
\(\binom{m-1}{\lfloor(m-1)/2\rfloor}\asymp2^m/\sqrt m\)。

这给出一个可核验的反例，否定下列**仅凭局部优先表/侧内唯一峰性质**的根迁移
设想：将一条长度 \(\Theta(m)\) 的根通道的根从中央搬到端点，同时声称源、靶
相对标号纤维可由统一常数比较。该类比较在 (5) 已相差指数因子。它不是自由方格
上不存在更精巧质量传输的证明；它精确定位了任何“逐侧重根而不使用二维额外结构”
方法最早失去统一常数的步骤。

在自由方格中，这条证书不能直接当作原题反例：一条单格宽通道的内部根通常有外侧
邻点，未必满足 (1)。因而要把它用于 (P_n\square P_n)，仍需构造带缓冲的二维通道
并控制其余顶点的纤维；本轮没有假定该提升成立。

## 4. 小规模精确核验

`audit_interface_gluing.py` 完整枚举 2×4 矩形的 (8!\) 个标号，记录外列安全根
的区域单峰计数；并完整枚举路径 (P_m\;(2\le m\le8))，逐个根位核对 (5)。
这些有限核验只检查计数公式和实现，不替代上面的组合证明，更不涉及 \(n\to\infty\)
的远峰比例。

## 5. 结论与第一处未证步骤

已有的 (4^{-8}) 安全根引理加 (3) 表明：证明远峰正质量时，无须为安全根或两侧
标签交错再付面积级代价。要获得所有 (n) 一致的计数比，还必须证明一条新的、
目前未证的接口平均估计，例如对足够大的远根安全盆地族有

\[
 \sum \theta_{A,B}(L)\ge c
 \sum 1
\]

并同时把该族的 \(\binom N{|A|}u_A(p)u_B(q)\) 总量与 \(A_2(n)\) 比较。
路径证书说明不能只通过把每个近根侧内排序“重根”为远根排序来完成这一步：其
纤维已可为指数级。当前没有可逆变换的累计入负载 \(\le C\)，也没有断言不存在
利用完整二维结构的另一种变换。

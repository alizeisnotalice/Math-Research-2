# 两步端点检查核：可逆性与有限通信类审计

令 \(W_r\) 是全部长度为 \(r\) 的无重复有序顶点词，令
\(X=\mathcal X_r^\tau\subset W_r\) 是指定 birth ranks 的有效词集合。
在 \(W_r\) 上定义 \(Q\)：均匀选择 \((i,v)\in\{1,\ldots,r\}\times V\)，
若 \(v\) 已在词中则交换位置 \(i\) 与其当前位置，否则以 \(v\) 替换位置
\(i\)。不在中间步骤检查 birth。

## 严格对称性

对不同 \(x,y\in W_r\)，若它们有相同顶点集，则一个非平凡交换可由两个
有序提议产生，正反各有概率 \(2/(r|V|)\)；若顶点集恰差一个点，则唯一的
替换提议正反各有概率 \(1/(r|V|)\)。其余对的转移概率均为零。因此

\[
 Q(x,y)=Q(y,x),\qquad Q^2(x,y)=Q^2(y,x).
\]

这里包括 \(i\) 位置本来的顶点给出的自环；它不影响该等式。

现在做两次 \(Q\) 提议得到终点 \(y\)，只在终点检查：若 \(y\in X\)，
接受 \(y\)，否则留在原来的 \(x\in X\)。记此核为 \(K\)。对不同的
\(x,z\in X\)，

\[
 K(x,z)=Q^2(x,z)=Q^2(z,x)=K(z,x).
\]

而

\[
 K(x,x)=Q^2(x,x)+\sum_{y\notin X}Q^2(x,y).
\]

故行和为一，且 \(K\) 在有限集合 \(X\) 上对均匀分布可逆。这是一个
严格的不变性结论；它不包含不可约性、谱隙或混合时间结论。

## 精确通信类的等价枚举

对有效端点 \(x,z\)，有 \(K(x,z)>0\) 当且仅当存在一个无重复中间词
\(y\in W_r\)，使 \(Q(x,y)>0\) 与 \(Q(y,z)>0\)。因此代码对每个有效
\(x\) 枚举全部 \(r|V|\) 个一次提议的中间词 \(y\)，以 `y -> first owner`
映射合并共享同一 \(y\) 的有效端点。这不存边，并且包括 \(y=x\) 的
自环；所以所得 union-find 连通分支恰为端点检查 \(Q^2\) 核的通信类。

`two_step_endpoint_connectivity.cpp` 对 n=2 的全部 r/tau，以及 n=3 的
全部 \(1\le r\le9,2\le\tau\le9\) 实际完成此计算。84 个实例中每个有
至少两个状态的有效空间都恰有一个通信类。这个有限结果说明两步端点检查
消除了本目录中一步有效性检查所见的小方格分裂；它不能推广为一般 n 的
不可约性，更不能代替混合分析。

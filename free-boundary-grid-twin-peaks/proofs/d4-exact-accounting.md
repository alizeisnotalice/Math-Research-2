## 对称压缩不改变递推

方格二面体群 D4 作用于独立集，C(gI)=C(I)。以 canon(I)=min_g gI 作为代表，则
\[
 C(I)=\frac{\sum_{v\in I}C(\operatorname{canon}(I\setminus\{v\}))}{|I\cup N(I)|}.
\]
删除不同点得到同一个代表时，必须保留重复项。删除后的集合未必仍是代表，必须重新正规化。取全部八幅像 I_g，有 canon(I−v)=min_g(I_g−g(v))，所以可以缓存 I_g 而不改变计数。

峰数、曼哈顿距离及欧氏平方距离均在 D4 下不变。每代表的贡献须乘真实轨道大小 8/|Stab(I)|，不能统一乘8。第5轮保留相邻两个基数层的 C 表，同时保存全部代表掩码；哈希仅是索引，不参与算术。

## 独立 Burnside 核验

独立 Python 验证器对恒等元素使用逐行独立集转移；对其余对称元，先取顶点置换周期，一个不动集合必为周期的并。含内部边的周期禁止选，相邻周期互斥，周期大小为多项式次数。因此加权商图独立集多项式给出每个群元素、每个基数的不动集合数。八个多项式求和除8，得到代表逐层数。

n7 原始独立集总数1280128950，代表总数160152689；两种不同枚举在全部26个非零基数层完全一致。该核验只认证状态空间覆盖；C 值另用递推交叉和选定集合的 Python 任意精度子集递推检查。

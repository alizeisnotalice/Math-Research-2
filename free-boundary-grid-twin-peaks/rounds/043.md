# 第43轮 中央切割的重数与七阶方格计数

2026-11-18。研究对象为自由边界方格上的均匀双峰标号，距离为原图曼哈顿距离。

令 \(n=2m+1\)。每行的左侧宽度取 \(m\) 或 \(m+1\)，等价于给中央列各点指定左、右归属。对于 \(n\ge7\)，外四分之一根带与固定半部的内边界分离。固定半部内的峰不受中央列归属影响，每侧必须恰有一个这样的峰且位于根带。内边界的局部峰则强迫对应中央点与自己同侧且具有更高标签。余下约束只检验中央点是否有更高的同侧横邻点或纵邻点。因此保留相邻两行归属即可逐行精确计数，状态数为四。

逐标号重数可达 \(2^n\)。先给固定两半部各排一个从外角出发的一峰词，再加入中央列，任意分配中央点都保持双峰。另一个构造依次加入两个同样的角根、左顶行前缀、中央列前3点，再加与第三个中央点相邻的左右界面顶点。这两个固定半部的临时峰同时要求第三个中央点归入自己一侧。随后每步邻接已有前缀，仍可填满全图。两个构造均有距离 \(n-1\)，重数却分别为 \(2^n\) 和0。两种障碍对每个奇数 \(n\ge5\) 成立。[证明](../certificates/r043/BINARY_CUT_MULTIPLICITY.md)

证伪线完成 \(n=7\) 全部128个二值曲线事件计数。两侧分别通过独立集容斥算允许根的一峰词数，再乘二项交错数。MacBook 完成全部128项，相关进程已退出。两条交替曲线的区域计数另由末点删除子集递推独立认证。本机重放32个 \(n=5\) 门槛、4个 \(n=7\) 代表和转移小门槛，并审计全部128个事件的交错乘积、反射及归一化。

事件计数之和为 \(162492250696126049348416111751504718204933980525701248\)，除以精确 \(A_2(7)\) 得到约1.18540，是命中曲线数的期望。由最大重数128得到并集质量至少约0.00926094。保留单个常宽曲线可取得更强的严格下界：\(\mathbb P_2(\rho_7>7/2)>0.02218587\)。[整数证书](../certificates/r043/n7-curves.json)

对有限混合抽样，以精确事件计数选择曲线，在两侧按整数完成数选词，再均匀交错。理想均匀整数源下，混合律在一条词上的质量正比于其命中重数 \(X\)，所以并集质量等于 \((\sum_h C_h/A_2)\mathbb E[1/X]\)。固定种子的有限样本给出 \(n=3,5,7\) 的构造并集数值分别约0.23392、0.15489、0.06562。父 Agent 用四状态递推重算全部65,536个 \(n=7\) 样本，与逐曲线枚举的重数直方图一致，并逐词核验全图峰数、原图距离。有限样本只用于判断这组中央切割能否维持质量。[复现及口径](../certificates/r043/REPLAY.md)

证明线的第一缺口仍为完整首次合并权下的全局空间估计。证伪线需建立固定正占比的无穷子列。中央二值曲线的最大重数与抽样诊断促使下一轮检查严格不交的奇偶宽度族。

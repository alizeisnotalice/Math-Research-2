# 第25轮：条带熵障碍、前缀核审计与有限权重诊断

日期：2026-11-17（Asia/Shanghai）。对象仍是自由边界方格
\(P_n\square P_n\) 上的均匀标号，在恰有两个严格峰条件下的原图曼哈顿峰距。
**原题仍开放，目标 active。** 本轮的有限 SMC 和辅助比较均不构成渐近概率结论。

## 严格方格结果：两行条带不能给出常数底数表面代价

令 \(T\) 为顶行，\(R\) 为前两行，\(H_T=h(T)\)、\(H_R=h(R)\)，并令
\(M=n^2-2n\)、\(b=\lfloor n/2\rfloor\)。对每个 \(n\ge3\)，已证明

\[
\frac{H_T}{n!H_R}
\ge\frac{\binom{M+b}{b}}{\binom nb}
\ge(n-2)^b. \tag{1}
\]

证明按每个从 \(R\) 出发的完成词的内部出生集选择第二行 gate；删去第二行后可以唯一恢复完成词、gate 及交错，故无重数。\(3\times3\) 整数穷举的六个 \(R\)-完成词给出 96 个两两不同的合法像（\(H_R=6,H_T=156\)）。这严格否定了任何固定 \(C\) 的
\(H_T\le n!C^nH_R\) 比较。

该结果只否定“固定两行条带释放”路线：它没有把 \(H_T\) 与全体单峰词数
\(A_1(n)\) 比较，因此既不给 \(p_n\) 上界，也不解决顶行两峰臂族的归一化。

## 严格有限核：rank-biased 前缀移动

对固定 \(\tau=2\) 的有序合法前缀，设 rank 选择分布为
\[
p_0=p_1=\frac14+\frac1{2r},\qquad p_i=\frac1{2r}\ (i\ge2).
\]
任意固定 rank 权都使交换/替换提议对称，故保持该有限前缀空间的均匀律。Fraction
全枚举已核验 \(P_2\) 的全部 rank 与 \(P_3\) 的 rank 1--5；最大例为 3808
状态、62936 个非零转移项。对根--非根合法 active swap，提议质量变为旧均匀选择的
\(r/8+1/2\) 倍（只在 \(r>4\) 时严格增大）；对根--前缀外替换变为
\(r/4+1/2\) 倍。独立的 n=3 小 GPU trace
又逐 proposal 重放成功。

这只是固定 prefix 核的实现与详细平衡审计。它不证明 SMC 无偏性、混合速度、方差改善或原题结论；新的 implementation metadata 不能通过冻结 r023 聚合器。

## 完成的有限数值证据

1. MacBook 完成 n=11 三个固定根单峰批：每个 \(P=262144,R=128,L=16\)，
   账本、种子与退出状态核验通过。根 13、24、25 的有限 normalizer 均值约为
   \(7.88\cdot10^{158},1.068\cdot10^{160},5.399\cdot10^{160}\)。这些有限根比不证明
   坐标传输不等式。
2. 已自然结束的 MacBook \(\tau=2\) terminal 批为 n=16
   \((P=262144,R=128)\) 和 n=24 \((P=131072,R=64)\)。源、元数据、种子、群组恒等式与
   正常退出均已有审计；估计值只作有限比值诊断。
3. 本机 n=24 `strat` 批的 GPU 内核事实上完整结束；原 driver 仅在后处理处把约
   \(10^{-216}\) 的显示型浮点残差错判为失败。逐组整数恒等式均为零，冻结聚合器经尺度
   容差及完整账本核验后接受该 raw。其完整提升权重 ESS 仅约 1.45/64，最大份额约 0.808。
4. 对两个 n=24 批分别诊断显示，集中主要已在 \(Z\) normalizer 层：本机 `strat`
   的 \(Z\) ESS 为 1.138，乘入 \(L\) 后为 1.450；MacBook `multi` 为 3.400 与
   3.588。因记录没有 parent ID 或逐层祖先数据，无法逆向归因谱系退化。两方法本轮不合并
   作更高精度声明；这是证据质量限制，并非禁止跨方法合并的数学定理。

## 严格一致性诊断：两批 n=24 plug-in 距离输出不能作为原律值

令 \(B\) 是两个最高标签均为峰的双峰词数，\(A=A_2\)。首次合并两支大小为
\(a,b\)、\(q=a+b\) 时，\(m=q(q-1)/(2ab)\)、\(\theta=1/m\)。点态有
\(m\ge2(1-1/\rho)\)，故严格得到
\[
\frac BA\le\sum_{d\ge2}\frac{d}{2(d-1)}\mathbb P_2(\rho=d),
\qquad
\mathbb P_2(\rho>r)\le\frac{2r}{r-1}(1-B/A)\quad(r\in\mathbb Z,\ r\ge2).\tag{2}
\]
这在 \(3\times3\) 的全 \(9!\) 枚举中逐词核验：
\(A_2=143808\)、\(B=81984\)、\(B/A_2=61/107\)。

把两份 n=24 输出中的 \(\bar m=E_B L=A/B\) 和同一 complete-\(K=2\) 的
\(L\)-加权距离直方图分别代入 (2)，线性必要条件的残差却为本机 `strat`
\(-.2313943395\)、MacBook `multi` \(-.2794570891\)。在 \(r=12\)，本机 tail
\(.559325\) 超过必要上界 \(.497990\)，MacBook tail \(.994332\) 超过 \(.403400\)。
所以每一批的有限 plug-in 比值不能同时被解释为原始 \(K=2\) 律的精确量；旧 \(Q\) 和
tail 数字现在只可保留为失败/低可信诊断，不能再用作趋势推论。进一步将保存小数作为
有理数精确归一化，得到确定性误差下界：每份汇总的 \(B/A\) 绝对误差和距离分布总变差
误差至少有一项大于本机的 \(.15\) 或 MacBook 的 \(.18\)。这不是置信区间，也不说明
是哪一项或何种程序机制造成偏差。

这一矛盾本身不指定错误来源：它既不单独证明代码 bug，也不提供显著性结论或混合失败证明。
它只使用严格的结构必要条件来限制这些有限 SMC 输出的解释。

## 反射路线的精确重写与有限表面数据

首次合并分解给出精确坐标协方差和方差的完成数加权分支矩表示。整条竖直反射同时令两支
一阶矩反号，故其乘积逐项不变，不能单靠全局对称决定协方差符号。第一未证条件是单支
反射/交换的累计完成数比较。\(3\times3\) 全枚举只核验了这些公式的有限归一化。

顶行单峰概率精确到 n=5，且一行与两行完成数的基础夹逼已复核；有限数值与阶乘型猜想相容，
却不提供任何全 \(n\) 上界。结合 (1)，只排除了形如 \(H_T\le n!C^nH_R\) 的固定条带
常数底数代价比较；其他归一化或全局比较仍未排除。

## 第一未证步骤

证明线仍需控制 \(W\)-加权根几何的 \(o(n^2)\) 量级，尤其是平衡且宏观分离分支的总权重；
证伪线仍需给出固定 \(\varepsilon,c>0\) 及无穷子列上的归一化远峰质量下界。条带熵下界、
反射重写和有限 SMC 均未填补这一缺口。

# 第31轮：短间隔恒等式与空间误差的局部支撑

日期：2026-11-17（Asia/Shanghai）。对象仍是自由边界方格、均匀标号在恰有两峰
条件下的原律及原图曼哈顿距离。本轮重新核对了 [Problem 9](https://sites.math.washington.edu/~burdzy/open_mathjax.php)
的提问范围及 [Twin peaks](https://arxiv.org/abs/1606.08025) 的原文入口；没有把其他
图族结论迁移为方格结论。**原题仍未闭合，总目标 active。**

## 证明线：两个全尺寸短桶恒等式

以下降顶点词表示标号，B 是两峰恰占最高两个标签的切片。若较低峰的首邻点在
完整词中位于 J_full（从1起），则项目间隔是 L=J_full−2；删去最高点后的对应
位置 J_H 满足 L=J_H−1。记 h_t=#{w in B:L=t}。本文各 h_t 都已对全部最高点
求和，不能默认逐孔成立。

**第一条：无三角形的连通图、N≥3，满足**
\[
 \boxed{A_1=4h_1-2B.}
\]
交换两个最高标签是 B 上无不动点的对合。第三点必须邻接至少一个峰，否则会
成为第三峰；若只邻一个峰，对合中的两个方向恰有一个 L=1；若同时邻两峰，
两个方向均有 L=1。因此
\[
 2h_1-B=B_{q=2},
\]
其中 q=2 表示两个单点分支在第三点立刻合并。在无三角形图上，一峰词的前三点
必诱导 P3。对固定三点集与后缀，一峰前缀有4种，立刻合并的双峰前缀有2种，
从而 B_(q=2)=A1/2。方格满足该图条件。一般含三角形的图有明确的三角形修正项，
不能省去假设。

**第二条：连通双部图、N≥5，满足**
\[
 \boxed{h_2=2h_3.}
\]
固定最高五点集 S，令 F_G(S) 为其后每个新点都有早邻点的完成词数。对 G[S]
中首两点不相邻、后三点各有早邻点的有序五元组，分别数出 L=2、L=3 的前缀。
二者差记为 c(G[S])，则无重无漏地有
\[
 h_2-2h_3=\sum_{|S|=5}c(G[S])F_G(S).
\]
双部五点图中，只需检查下列可能贡献的类型；其他不连通类型的局部项为零。

| 五点类型 | L=2 前缀数 | L=3 前缀数 |
|---|---:|---:|
| P5 | 16 | 8 |
| 度序为 3,2,1,1,1 的树 | 8 | 4 |
| K1,4 | 0 | 0 |
| C4 加一叶 | 8 | 4 |
| K2,3 | 0 | 0 |
| P3 与 K2 的不交并 | 16 | 8 |

该分类可由树度序及双部五点图中唯一可能的环长4直接得到，表中有限前缀计数
逐项抵消。完整整数检查另覆盖全部1024个五点标号图、每图120个前缀。
无三角形图中唯一的非双部五点障碍为 C5，其差为20，因此还有精确修正式
\[
 h_2-2h_3=20\sum_{G[S]\simeq C_5}F_G(S).
\]
P4 的 h2=4、h3=0 说明 N≥5 的范围不能任意删去。两条方格恒等式均为解析
计数结论，完整小图枚举只承担有限交叉核验；它们不推出长尾控制。

## 空间加权版本：差项只在局部峰距出现

对无序根对的任意对称权 f，交换最高标签或首次合并交错的方向平均给
\[
 2h_1(f)-B(f)=B_{q=2}(f).
\]
在方格上 q=2 的两个根都是同一合并点的邻点，其曼哈顿距离恰为2。因此若
d 是曼哈顿距离、r 是平方欧氏距离，逐几何桶严格有
\[
 2h_1(d,r)=B(d,r)\quad(d>2).
\]
而对 f=r，前三点 P3 的端点平方距离只能是2或4，故
\[
 A_1\le2h_1(r)-B(r)\le2A_1.
\]

对首次合并前两支大小 a,b≥2、q=a+b≥5，固定两支内部词并平均两个根方向，
精确交错概率为
\[
 P(L=2)=\frac{(a-1)(b-1)}{(q-2)(q-3)}=2P(L=3).
\]
一支为单点且 q≥5 时，这两桶均没有贡献。因此 h2(f)−2h3(f) 只来自 q=3、4。
相应合并集合至多5点且连通，原图两根距离至多4。于是
\[
 \boxed{h_2(d,r)=2h_3(d,r)\quad(d>4).}
\]
这是远距受限测度的精确倍数关系；远距质量非零时可归一化为相同的条件分布。
它不适用于区分哪个峰更高的有序权。

令 E_t=sum_(d,r) r h_t(d,r)。差的支撑上 r≤16，与 h2=2h3 合并可得
\[
 \left|\frac{E_2-2E_3}{n^2B}\right|\le\frac{64}{3n^2}.
\]
该小量只比较两个短间隔桶，绝不是完整 Q_n 的上界。长间隔及其原律提升权重
仍未被控制。

## 证伪线：排除两个过强的局部化步骤

n=3、5 的已认证联合表给出 h2(r)−2h3(r) 分别为 −2144 和
−25171711895253355200。因此未加权等式不能逐几何桶延伸到所有近距离。
n=3 的全9!根对核及独立前缀完成数重构逐项一致；根对差矩阵行和非零、
非对角元有正有负，不能直接视为正导通率的图 Laplacian。

进一步把最高五点的平方距系数写作 c_r(S)，则
\[
 h_2(r)-2h_3(r)=\sum_{|S|=5}c_r(S)F_G(S).
\]
完整枚举63个固定、12个自由连通五格形态发现正系数。例如
\[
 S=\{(0,0),(0,1),(0,2),(1,0),(1,2)\},\qquad c_r(S)=4.
\]
另有 c_r=2 的形态。故不能由 F_G(S)≥0 逐项推出全局平方矩差非正；小尺寸总差
为负不提供这种符号证明。不连通类型 P3⊔K2 的有向系数虽非零，但逐反向根对
相消，对本轮的无序对称权贡献为零。审查时已纠正混淆这两种权的初稿推论。
这些反例排除的是候选估计，不是原题反例。

## 全孔 n=7 短尾与独立总量交叉

九个非中心孔类的36个模计算全部正常结束。每份输出、资源与退出回执哈希已核对，
独立集层数匹配第29轮表；四素数经49节点 Pratt 核验，乘积大于48!。
直接余因子 CRT 与 Garner CRT 一致。中心复用第30轮证书，没有重跑。
D4 重数覆盖49点，得到
\[
\begin{aligned}
h_1&=28443479882254336626820089933464290504438276060466688,\\
h_2&=12332995834770101489308116699661000325356606074820608,\\
h_3&=6166497917385050744654058349830500162678303037410304.
\end{aligned}
\]
主线把 4h1−2B 与第5轮独立完整计数的 A1 逐整数比较，完全一致；h2=2h3 也
精确成立。相应立刻合并事件的原律概率等于 1/(2R7)，约 .0004897489。

全局二次尾包络仅在已知 t=2、3、4 三点完成精确有限检查，不能声称全部层通过。
其中 t=2 的上界本来大于1，不具有区分力；中心逐孔加强仍在 t=4 失败。
L≥4 占 B 质量约17.3828%，经 L 提升却占原律约47.7604%，余部条件均值约6.62853。
这说明仍有不可忽略的提升质量留在尾部，不能截断后直接收尾。

## 后续计算实现与 n=32 GPU 结果

一般多源前缀容斥实现已扩展到 h1,…,h5，保留有序前缀及四方向有向边重数，
先累加完整模分子再乘下降阶乘逆元。n3全9孔、n4全16孔、n5六个孔类共124个
模 checkpoint 与完整间隔直方图逐项匹配。n7 显式 opt-in 防护已实际检查。
本轮认证范围仅为这些小尺寸门槛；后续 n6 或 n7 生产另轮处理。

MacBook 的 n32、P=262144、R=32、L=16 GPU 批自然完成：32条重复、32条条件平均
记录、元数据及结束标志齐全，冻结聚合器重放通过。记录中的重复权重 ESS 约
1.000000000335，最大权重份额约 .999999999833；Q_mRB≈.2250941584、
Q_L≈.2250789448。权重几乎被一次重复占满，因此这些值不能作为原条件概率、
混合或渐近趋势的可靠证据。聚合器检查的是输入与实现不变量，没有另做概率精度
认证，也未把未执行的必要条件检查写成通过。

该 GPU 计算用时6642.30秒，最大RSS为2483257344 B，peak footprint为3151137168 B，
资源回执为零swap。驱动、计算与防休眠进程均已确认退出。接续任务遇到新的SSH
连接故障；已编译的 h45 模块仅完成远端小样，未把尚未启动的生产算作完成。

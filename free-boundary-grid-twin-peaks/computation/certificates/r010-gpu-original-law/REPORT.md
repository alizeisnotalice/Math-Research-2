# r001：直接原条件律 GPU 顺序重要性抽样

状态：数值探索与实现校准。它直接覆盖下降标号的 \(K=1\)、\(K=2\)
路径，不是对原条件概率的严格认证。

## 实现与严格的理想化恒等式

`gpu_original_law_sis.swift` 实现两个提议。模式0在出生数少于2时从所有
未揭示点均匀选取，已有两出生后从边界均匀选取；模式1首点任取、以后
一直从边界选取。前者的完整路径恰为所有至多两峰的标号，后者恰为所有
一峰标号。理想精确随机数下，路径权重是每步候选数的乘积，故
\[
  \mathbb E(W\mathbf1_{K=2})=A_2,
  \quad \mathbb E(W\mathbf1_{K=2}\|X-Y\|_2^2)=A_2n^2Q_n,
  \quad \mathbb E(W)=A_1\ \text{(模式1)}.
\]
每线程记录两个峰、欧氏平方和曼哈顿平方。Metal和CPU对相同整数种子的
一条完整轨迹核对 `logW,births,p1,p2,e2,rho2`；每一批都检查 command
buffer 状态。

实际程序使用单精度 GPU 对数权重、有限状态 xorshift32 和双精度 host
log-sum-exp。因此上式是算法目标，不是对实际浮点实现的无偏性证明。
不同 `mix32` 种子是确定性流，不能称作已证明独立。

模式0/1分别在n=7跑33,554,432条、在n=8,12跑67,108,864条。硬件提交时间
（Metal `gpuStartTime/gpuEndTime` 的和）为：n7=3.687/3.680秒，n8=12.705/

\(\widehat Q=0.348028\)、ESS=3347；模式1给 \(\widehat A_1/A_1=1.001121\)、
ESS=74210。n8模式0 ESS=455、最大权重0.0375。n12模式0 ESS=6.31、最大

运行时共取得199次 AGX Device Utilization 采样，平均93.84%，197次不低于
70%，最高100%。这是设备级瞬时状态，不能表述为独占或全程满载。运行结束
后 GPU 子进程已不存在；采样 shell 的遗留子进程也已专门终止并核验。

## 结论和下一步

直接原模型 SIS 的小尺寸计数与距离矩核验通过，因而它是比完成核更贴近
目标的 GPU 入口；但未分层版本在n=8、12的ESS已经不足，不能支持任一
渐近方向。下一阶段应按第二出生秩和根位置分层，并把每个线程组的稳定
`sumW,sumW2,sumW_e2,sumW_rho2` 放到GPU归约，保留死端为零贡献，之后才
讨论批间Z加权。有限样本比值 \(\widehat Q\) 自归一化且有偏，所有结果仅用于
算法诊断和构造搜索。

## r002：第二出生秩分层

`gpu_original_law_tau.swift` 对每个下降秩 \(\tau=2,\ldots,N-1\) 单独运行：
在 \(\tau\) 前只从边界选，在 \(\tau\) 时只从未揭示非边界选，以后再只从
边界选。若强制前缀走入死端，线程写 `alive=0`，但仍占样本分母。因而每一
条成功的全路径仍满足 \(q_\tau W_\tau=1\)，层和恢复 \(A_2\)；没有以幸存
比例重新归一化。

实际运行每个n=2..6层131072条、n=7,8层262144条，共189层、596批；189个
CPU/GPU单轨迹检查及所有 command buffer 检查通过，进程退出后核验不存在。

|2|1.000000006|0.5000000|0|
|3|0.999308|0.4895009|−0.0000407|

作为更细校验，n=3六个有支持秩层的单层 \(A_{2,\tau}\) 相对误差介于

推断任何渐近概率。

## r003：试点驱动、独立种子的分层生产

`tau-r001` 只作为分配试点：对每层以
\(\sqrt{\widehat{\operatorname{Var}}(W)}[1+|n^2(Q_\tau-Q)|]\) 评分，
每层至少4批，然后将余下批按分数分配。生产的 `0xA022E***` 种子域与试点
`0xA022D***` 不同，**所有下列合计均没有并入试点**。这个评分不包含
\(W^2e_2^2\) 的直接估计，且由试点选择样本量；它是减小退化的工程启发，
不是置信程序。

|生产|层数/批数/样本数|\(\widehat A_2/A_2\)|\(\widehat Q\)|备注|
|---|---:|---:|---:|---|
|n=7|47 / 512 / 33,554,432|0.998767594|0.344552864|精确 \(Q_7\) 差 +0.000134549|
|n=8|62 / 768 / 50,331,648|—|0.337922982|尚无此处使用的精确 \(A_2,Q\) 基准|

n=7的47条、n=8的62条 CPU/GPU 完整单轨迹检查均通过；两个 JSONL 都含每批
`tau,index,seed,gpu_seconds,wall_seconds`，分别有512和768批，且各自的GPU
进程已在完整性检查前退出。提交等待时间为8.140秒/10.410秒，GPU区间和为
7.310秒/8.907秒，故此实现里主机读取每线程输出尚非主要瓶颈；在有独立批间
校验前没有冒险替换为线程组浮点归约。n=8值仅为搜索/算法诊断，不能同原题的
条件概率结论混同。

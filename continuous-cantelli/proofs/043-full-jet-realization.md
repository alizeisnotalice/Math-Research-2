# 全部对角和外核系数的实际光滑实现

设 g(u)=p₁(a+u)，固定 c,R>0。对任意实数列 (T_n)_{n≥5}，存在全轴正 C∞ 函数 w，w(0)=c，c/2≤w≤3c/2，使得令 v(a+u)=u⁴w(u) 于 |u|<R，真实的截断势

    S_R(y)=∫_{−R}^R g(u)H_{v(a+u)}(y−u)du,      H_s=½∫₀ˢp_t dt,

在 0 邻域为 C∞，且 [y^n]S_R=T_n 对所有 n≥5 精确成立。方差在此核心外可任意非负有界连续延拓，原点全局最小值0已取到。定理不规定低四阶系数。高阶目标可以没有任何增长界。

## 普通导数与系数身份无需全局精确性

令 μ_R 为 |u|<R 的源输入所生的高斯混合输出子测度。它有 C∞ 密度。在零点附近以 C∞ 紧支撑截断源输入，其特征函数是 ∫ψ(u)g(u)e^{iξu−ξ²u⁴w(u)/2}du；在 z=|ξ|^{1/2}u 坐标，频率为 |ξ|^{1/2}，振幅的每个 z 导数在支撑上由多项式乘 e^{-cz⁴/4} 一致支配。故任意 N 次分部积分给 O_N(|ξ|^{−(N+1)/2})。剩余输入远离零，方差有严格正下界，得到 e^{-c_R ξ²} 衰减。由绝对 Fourier 反演可任意次微分其密度。在 distributions 意义 S_R″=μ_R−g·1_{(−R,R)}，故 S_R 在原点邻域 C∞；这里不采用未正则化的点态密度公式作零点导数。

已有四次近对角展开是实变量有限阶 Taylor 展开，对任意上述 w 成立。具体为

    [y^n]S_R=I_n(w)+Σ_{1≤j≤(n−2)/2}(n+2j−2)!/(2^j j! n!) · [u^{n−2j−2}]g w^j,
    I_n(w)=∫_{−R}^R g(u)[z^n]H_{u⁴w(u)}(z−u)du.

它通过 |u−y|≤|y|/2 上的尺度 u=y+y²z 以及外区的有限 Taylor 估计得到；现已证 S_R 自身光滑，故该展开给出经典导数而非仅 Peano 数据。对于 n=k+4，k≥1，合并对角和为

    g(0)w_k/2 + P_k(w₁,…,w_{k−1}),       w_j=[u^j]w.

这里 P_k 是只依赖 g 的已知 Taylor 数据及 c 的有限多项式；首个 j=1 项给出非零对角系数。其余 j≥2 只读不高于 k−2 阶的数据。

## 对外核反馈的一致控制

固定 u≠0，在 |z|≤|u|/4 有 Re((z−u)²)≥u²/2。对 c/2≤w≤3c/2，

    |[z^n]H_{u⁴w(u)}(z−u)| ≤ C_R (4/|u|)^n exp(−c'/u²).

于是对所有这类 w，有 |I_n(w)|≤K_n（例如可取 K_n=C_R^{n+1}√(n!)）。不需要 w 的任何导数界。实数 s>0 的 H_s 在上述复圆上关于 s 连续；若 w_j(u)→w(u) 各 u≠0 成立，则利用 Cauchy 系数和共同可积包络，有 I_n(w_j)→I_n(w) 对每个固定 n 成立。

## Borel 截断和 Brouwer 不动点

依次选择有限常数 M_k≥1 使

    M_k ≥ (2/g(0)) ( |T_{k+4}|+K_{k+4}
                         + max_{|a_j|≤M_j, j<k}|P_k(a₁,…,a_{k−1})| ).

所有右端都已知。令 C 为乘积盒 Π_{k≥1}[−M_k,M_k]，取 C∞ 截断 χ 支撑 (−1,1)，在零附近恒1，0≤χ≤1。选择 ε_k∈(0,min(R/2,2^{-k})) 足够小，使对所有 |a_k|≤M_k，a_k u^kχ(u/ε_k) 的 sup 范数≤c 2^{-k−2}，以及一至 ⌊k/2⌋ 阶导数的 sup 范数各≤2^{-k}。可行性来自 m 阶导数有 C_{k,m} M_k ε_k^{k−m} 上界。定义

    w_a(u)=c+Σ_{k≥1}a_k u^k χ(u/ε_k).

每阶导数的尾部都一致收敛，w_a 光滑且在正盒内，其第 k 阶 Taylor 系数恰好是 a_k（非零阶）。参数 a 的逐坐标收敛给 w_a 至少一致收敛，实则每阶一致收敛。因而对固定 n，I_n(w_a) 为乘积拓扑上的连续函数。

设连续坐标映射

    Φ_k(a)=2[T_{k+4}−I_{k+4}(w_a)−P_k(a₁,…,a_{k−1})]/g(0).

所选 M_k 保证 Φ(C)⊆C。对前 N 坐标，固定其后所有 a_j=0，把 Φ 投影到前 N 坐标。有限矩形自映射有 Brouwer 不动点 a^(N)，把它的尾部设为零。逐坐标紧性及对角法给趋向 a∈C 的子列；对各固定 k，此子列最终有 N≥k，故连续性给 Φ_k(a)=a_k。代回真实系数身份便得所有目标同时成立。此构造仅断言存在，未给一般唯一性或数值收敛的迭代法。

## 一个无法由系数测试识别的平坦误差

令 T_n=0 对 n≥5。实际 S_R 在0的 Taylor 级数为某次数≤4 的多项式 P，但它严格不在原点实解析。若实解析，μ_R 的光滑密度在原点某邻域是 g+P″。它在正负两条开半轴各处都实解析：固定 y₀≠0，离零足够近的输入与 y₀ 有正距离，故其热核在复小圆上有统一可积上界；其余输入有共同正方差下界。零输入为零测点。由实解析唯一性，μ_R 密度势必在全实轴（至多除去0）等于 g+P″。两尾可积强迫 P″=0，进而 μ_R 质量为 1，却由定义等于 ∫_{−R}^Rg<1，矛盾。因此 S_R−P 是有零全 jet 的实际非零平坦误差，每个原点邻域都不能消失。

而且对每个 0<r≤R，小核心 S_r 本身的 jet 也有统一全阶 Cauchy 预算。设

    H_r(z)=P(z)−∫_{r≤|u|<R}g(u)H_{u⁴w(u)}(z−u)du.

在 |z|≤r/4 时被积核全纯且统一有界，因为 Re((z−u)²)≥u²/2；因此 H_r 的全纯模界 B 可选为独立于 r 的常数。对 |y|<r/4 的实 y，S_r(y)−H_r(y)=S_R(y)−P(y)，与 r 无关。故 [y^n]S_r=[z^n]H_r，满足共同预算 B(4/r)^n，但同一真实平坦误差遮住了每个核心的解析性。构造并未实现任何 Gaussian 全局精确输出。

上述 T_n=0 的构造满足之前纯 jet 论证所用的全部上界；故已证的临界下型、上侧零型及相应符号必要条件彼此确实可兼容。其共同成立只描述一个零点处的无限 jet，不判定原猜想。

## 定量隐函数实现

可以把上述存在构造加强为确定截止族中的 Banach 压缩。其关键是 I_n 不仅连续，还有对整组参数统一的 Lipschitz 界。在正盒 w∈[c/2,3c/2]，对实标量 w 求导，

    ∂_w H_{u⁴w}(z−u)=(u⁴/2)p_{u⁴w}(z−u).

同一复圆估计给 |∂_w h_n(u)|≤C_R(4/|u|)^n |u|² exp(−c′/u²)。故 |I_n(w)−I_n(ŵ)|≤L_n‖w−ŵ‖∞，其中 L_n 有限且独立于待选坐标盒。用 z_k=a_k/M_k 作归一坐标，在单位 ℓ∞ 闭球（实数列）上工作。由截断的 sup 预算，‖w_z−w_{z′}‖∞≤(c/4)‖z−z′‖∞。设 C_k 为 P_k(M₁z₁,…,M_{k−1}z_{k−1}) 在单位矩形上的 sup-范数 Lipschitz 常数，有限且仅依赖先前的 M_j。递推选择 M_k 时加上

    M_k ≥ 4 [C_k+(c/4)L_{k+4}]/g(0).

此前自映射条件继续保留。于是缩放映射 z↦(Φ_k((M_j z_j)_j)/M_k)_k 在完备单位闭球上 Lipschitz 常数≤1/2。由压缩映射定理，从零启动的 Picard 迭代在 sup 范数内收敛，利用固定点在单位球内，m 次迭代误差≤2^{-m}。唯一性只涉及所选 M_k 和 ε_k 的参数化；一般光滑实现没有唯一性主张。若几个目标的模在同一递归预算内，则对应缩放固定点间距≤(4/g(0))sup_k |T_{k+4}−T′_{k+4}|/M_k。显式收敛率不意味着无算法描述的任意目标序列可以数值计算。

## 独立有限算例

本机 Python 3.13.18、mpmath 1.3.0 以 65 位精度取 a=0、c=1、R=0.4，分别在半径0.08与0.04截断 u²、u⁴ 两个参数，对真实外核 I₆、I₈ 做正半轴积分并反解对角反馈。得到 w₂≈−27.1647901516577、w₄≈239.801828398721；正外核约 2.72573127215 与 96.7746869889，分别被负对角项抵消。三次迭代报告的绝对残差为当前工作精度下的 0 及 3.04×10⁻⁶⁴。这是指定有限系统的浮点校准。全阶结论由前述解析和压缩估计承担。

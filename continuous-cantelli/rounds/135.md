# 第135轮　整条远翼在大参数下的一致全阶符号

若 f 在 [a,∞) 严格为正，右尾下、上极限 l,h 满足 l>1 且 h−l<(l−1)²，则对每个固定阶 n，存在统一 q₀，使所有 y≥a、q≥q₀ 同时满足严格导数符号。结论包括有大于1的右尾极限、内部任意多峰的图，且与反翼和原点接触律无关。配合第122轮的远切点估计，该翼任何第 n 阶错误符号都只能出现在一个有界参数矩形中。证明也给出同阶整数差分的大参数正性。[统一尾部比较](../proofs/135-whole-wing.md) · [精确多项式校验](../computation/round135)

一般连续 Cantelli 猜想仍未解决。

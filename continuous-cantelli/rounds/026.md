# 第26轮　缩小平移窗口与导数增长条件

第25轮证明固定宽度窗口在平移输入极限下有正质量。本轮把半径缩至 K log|t|/|t|。对导数至多多项式增长的实解析精确 f，每个这种窗口都含有 f(x)≤1+80 log|t|/t² 的点。因此若 |f′(x)|=o(|x|/log|x|) 在两尾成立，f 必恒为 1。这一条件允许导数无界。[证明](../proofs/026-translated-window.md)

使用复参数 t+iu 的完整恒等式，截去高方差部分，再以方差 80 log(t)/t² 的独立高斯平滑。低频截断误差小于 t⁻³⁰，高频由平滑控制。得到的局部密度下界能检测依赖 t 的小窗口，超出了仅由弱收敛可得的固定窗口结论。

计算材料见 computation/round026。SymPy 验证指数变换，65 位 mpmath 对 t=16、64、256、1024 检查 Fourier 尾积分。在 t=64，反演所用密度误差上界约 2.13×10⁻¹⁹。另在有限 λ=20 下核验高平台证书：核心 |x|≤1 取 f≥x²，其余取 f≥3/4，若 |x−20|≤20×0.49 时 f≥2，则变换值至多 437513/588000<1。将半宽比例改为 0.485 后，取各段下包络时变换值却超过 1；这区分了两个具体检验窗口，不主张一般最优。运行 python certificate.py 与 python r025_esscher_check.py 可分别复算。一般连续猜想仍开放。

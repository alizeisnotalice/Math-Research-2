# 第22轮　双侧平坦幂次与两机计算

若全局最大点的亏损在两侧均有有限的 α 次幂首项，α>2，至少一个系数为正，则 α 必须为偶整数且两侧系数相等。证明将输出密度的高阶导数减去零亏损基线，以高斯半轴矩区分左右系数。[证明](../proofs/022-flat-powers.md)

本轮同时归档第20–22轮使用的两机校验程序，见 computation/round022。Python 3.13.18、SymPy 1.14.0 与 mpmath 1.3.0 用于 Hermite 矩因子核对及 70 位数值校验（flat_power_check.py 与对应 JSON）。证明覆盖所有满足假设的指数；同系数的偶次幂仍开放。

- 本机 Apple M6 运行 12 个 CPU 进程；对数接触首批 1024 组、每组 12 个尺度，有 15 次整机 CPU 空闲率采样为零。Metal 的 96 点求积扫描 47,554,560 组，命令缓冲区计时 0.556 秒，实测整机 GPU 100%，启动前也为 100%。局部参数子网格命中比值 1.41599，CPU 复核相对差约 4.0×10⁻⁶。
- MacBook Apple M5 Pro 运行 15 个 CPU 进程，主扫描 15,728,640 个 Sobol 样本，102 秒墙钟，合计 882.3 个进程 CPU 秒，采样整机 CPU 空闲 0–0.12%。原生 Metal 细化 328,840,479 组，命令缓冲区计时 38.72 秒，另有半径 1/8 和 1/16 的独立扫描。设备利用率包含其他并行任务。
- 数值搜索导出独立有理证书。令 t∈[1/3−10⁻⁴,1/3+10⁻⁴]，c²=(5913t³+954t²+96t−8)/(21t+6)，d=t/c，x₀=3d−2/c，左右亏损分别是 cu 和 du³。在半径 3/16、ε=2⁻²⁰、y=x₀+1/8，核心已贡献至少 9030753/22000000，而所有 M>1 的目标密度小于 1/√6。脚本用 256 个有理区间给出下界。本证书提供有限尺度证据，第20轮的一般排除不依赖这个半径。

复算时可将所需子目录复制到临时盘运行。从 remote-cpu 运行 python3 exact_uniform.py 即可核验有理证书。对主 CPU 搜索，以 0 到 14 分别作为 scan.py 的 shard 参数，使用 --exponent 20 --shards 15 --order 24 --out 指定各自 JSON。local-cpu 的 log_contact.py 和 quadrature.py 在当前目录写入结果。Apple Silicon 上从 local-metal 运行 swiftc -O core.swift -o core 再运行 ./core full . 96；从 remote-metal 用 swiftc -O scan_pre_stable.swift -o scan，细化参数为 1536 65 129 33 2048 以及分块大小与输出文件，要求同目录含 density.metal。编译时可用 -module-cache-path 指定已有的缓存目录。GPU 搜索使用浮点数。

追加批次核验：本机 12 个工作进程在转折区域完成 2048 组新参数，114.8 秒后全部退出。MacBook 五次正式 Metal 扫描合计 890,620,411 个参数组合，命令缓冲区计时合计 112.32 秒。三个受控半径批次的整机 GPU 平均利用率分别为 98.66%、98.84%、98.10%；开始前已有 97% 负载。本轮没有将整机负载归为单个计算进程。

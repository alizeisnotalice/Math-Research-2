# 第60轮　高阶接触匹配与远侧过零位置的双机检验

在左右两侧光滑、首项高于二次的接触模型中，若前 m−1 阶方差系数一致，第 m 项的有符号系数差为 A，则密度的 (m−2) 阶单侧系数以导数归一化后的差为 m! g(a) A/2。[推导](../proofs/060-matched-jumps.md)。另推导了有限耗散模型右侧第二个过零点的位置：令 s_Q 是报告所列端点近似二次式的大根，在所列参数固定、a→∞时，实际过零点满足 (s_*−s_Q)s_Q→1。[完整模型及推导](../computation/round060/mac-metal/README.md)

双机本轮实际四路重叠按两份时钟校准中较保守者为41.996秒。在两机时钟相对偏差保持实测范围的条件下，两台 GPU 同时执行本课题命令且两组 CPU 计算均在运行的时长至少29.02秒。本机 CPU 在重叠窗有25次采样为整机空闲率零；MacBook CPU 部分采样仍有约11%空闲。两机 GPU 利用率采样是整机值。[本机收据](../computation/round060/local-cpu/matched-jump-receipt.json) · [跨机时钟核验](../computation/round060/mac-cpu/four_way.json)

本机首批 Metal 在最后检查点后中断，贡献按该检查点截断。修复后完整复跑覆盖1,487,405,056个新段参数，累计86.529秒命令时间；同一段的未完前缀未重复计入。三种求积阶数与CPU复核的最大绝对差为6.19×10⁻⁷。MacBook 首批 CPU 的阶数下界不适用，修正后15进程运行102秒，检查3,888,640组；MacBook GPU完成1,173,988,701个耗散模型参数点、累计257.279秒命令时间。所有进程均已退出。[本机 GPU](../computation/round060/local-metal/README.md) · [MacBook CPU](../computation/round060/mac-cpu/summary.json) · [MacBook GPU](../computation/round060/mac-metal/summary.json)

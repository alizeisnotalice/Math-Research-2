# 第115轮　远处高斯窗口的局部阈值必呈二次增长

固定窗口方差 w>1，把中心 x 处唯一的正临界耦合记为 b_w(x)。对一般非恒定精确图，在两个无穷远处分别有 0<c≤liminf b_w(x)/x²≤limsup b_w(x)/x²≤1/[2w(1−inf f)]，其中 c 可由 w 及 f 的上下界显式给出。没有单峰、尾极限或尾部连续模假设。证明使用高斯桥，把大半条实线上的被积函数变成同号；在一个固定区间上保留的负量足以控制另一远尾。

b_w 是实解析函数，在唯一最小点两侧分别严格单调。固定超临界耦合的两个端点临近合并时，以系数为 1 的平方根规律接近。这些结论把第101轮的阈值扩展到每个观测位置。[双边二次界与两端点规律](../proofs/115-remote-window.md)

一般连续 Cantelli 猜想仍未解决。

# 第32轮　依局部亏损深度缩小尾部窗口

假定正尾 f≥1−o(1)，每个固定紧区间的倾斜质量趋于零，且在 E_t=[t/2,3t/2] 上 t²(1−f) 的正部至多为 C log t。对任意固定 0<δ<1，仅测量 |x−t|≤t^(−1+δ) 的亏损，设其 t²(1−f) 正部上确界为 H_t。则常数 A,B 存在，使每个充分大的 t 附近都存在 x 满足

    |x−t| ≤ A(1+H_t)/t，    f(x) ≤ 1+B(1+H_t)/t²。

若附近的亏损为 O(t⁻²)，就将第26轮的窗口从 O(log t/t) 缩至 O(1/t)。证明使用具有紧支撑频谱的 sinc 偶次幂，正亏损和负亏损分别给出实和复高斯平均。对深窄低谷也有用倾斜质量表达的例外集版本。[证明与完整假设](../proofs/032-adaptive-window.md)

SciPy 以频谱积分和条件高斯积分核对六组参数，最大绝对差小于 4×10⁻¹⁵。[计算脚本](../computation/round032/round032_adaptive_packet_audit.py) · [结果](../computation/round032/round032-adaptive-packet-audit.json)。一般连续猜想仍未解决。

# 第110轮　稀疏谷的全轴积分与四阱候选的符号变化

构造同一个连续稀疏多谷剖面，在两列尺度上的全轴积分分别有对数率 9/400 与 −9/128；在全轴增长的子序列上，单位窗仍以 −1/8 衰减。该剖面检验了截去远尾会带来的误判。本机 M6 Metal 执行 5,107,482,624 次参数求值，设备命令累计 94.999 秒；九个代表用 CPU 独立复核。[解析估计与有理证书](../computation/round110/local/proof.md) · [本机记录](../computation/round110/local/README.md)

对另一组精确匹配均值和四阶矩的四阱候选，得到全族排除及临界附近最后一次变号的位置展开。MacBook M5 Pro 完成 1,314,232,284 次实变换评估，设备命令累计 73.048 秒。一个 Float32 样本报告六次变号，双机 CPU 复核为两次；明确的区间证书给出另一剖面在 λ=6 时 log F(6)>1.0551197。两批 Metal 已退出。两机计算分批运行，未测得四路同步满载。[四阱推导与复现](../computation/round110/mac/README.md) · [运行摘要](../computation/round110/mac/summary.json)

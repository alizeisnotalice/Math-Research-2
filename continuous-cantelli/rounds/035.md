# 第35轮　双机计算、平坦核心与浅尾井证书

1. 若 a≥16 且 |y|≤1 时 f(a+y)≤1−(8/5)(1−y²)²/a²，取观测区间 J=a+[−1/8,1/8]。只用该井内的输入，其贡献除以 |J| 已至少为 27467687481/26843545600>1，故任何外部延拓都与原恒等式矛盾。这是 64 个有理子区间和奇阶指数 Taylor 下界的结果。[精确证书](../computation/round035/remote-metal/rational_rectangle.py)
2. 对 t=4096 的临界原点输入带和远尾输入带，两带在平移观测窗口的合计贡献严格超过 141071/138240；若取所给的等号模型，在标称 t 时两带的合计却小于 40655/43008。结合两个来源能检出单参数测试漏掉的违规。[推导](../proofs/035-shifted-test.md) · [证书](../computation/round035/remote-cpu/certificate.py)
3. 指定形状的双侧平坦核与单侧平台核，在 M=2 时给出分别超过 16/15 与 27/25 的密度比。另一个 a=51/50 的指定核心，对所有 M≥1 均违反目标密度。[有限尺度分析](../proofs/035-leakage.md) · [证书](../computation/round035/local-metal/exact_witness.py)

本机 M6 使用 12 个 CPU 工作者与原生 Metal。两次 GPU 求积分别计算 2,479,357,952 与 1,811,939,328 个参数组合，命令时间 59.646、61.065 秒。细化批次的两个设备启动相差 0.455 秒，12 个 CPU 工作者均可运行的重叠采样跨度为 59.681 秒，其中 55.607 秒为已计时的 Metal 命令。整机 CPU 空闲率在这些采样中为 0%，整机 GPU 运行均值 99.13%，启动前已为 100%。

MacBook M5 Pro 的 15 个 CPU 工作者在 24 秒内处理 23,592,960 个样本。Metal 同期计算 305,322,875 个比值，命令时间 27.595 秒。该机 CPU 与 GPU 重叠约 23 秒，CPU 空闲率三次采样均为 0%，43 次 GPU 整机采样为 98–100%。两台机器分别获得了 CPU/GPU 同时工作的记录。本轮未观测到两台机器的四个作业共同重叠。

本轮高阶 CPU 长作业的完整输出将在退出核对后补入下一轮。计算用于发现和复核证书。大样本计数不扩大上述排除条件。[运行环境、脚本与输出](../computation/round035/README.md)。一般连续猜想未解决。

# 第52轮　超二次接触的区间质量展开与收缩窗口

在取到全局最大值的点平移坐标，记真实方差为 v，高斯源密度为 g。取任意非负光滑参考方差 w。设 v,w=O(|u|^q)，v−w=O(|u|^α)，q,α>2。则有同一个双侧多项式 Q，使 ∫₀ʰg(v−w)=Q(h)+O(|h|^(α+q/2))。Q 中只允许出现 α+1≤j<α+q/2 的整数次数 j。真实方差只需满足上述函数值界。

因此在距接触点 O(r) 范围内，即使窗口长度远小于 r，只要仍远大于 r^(q/2)，就可从窗口平均恢复唯一的 α 阶系数。若 w=0 且 α 不是偶整数，任何这样的窗口内 v 的平均值都是 o(r^α)。这一条件还约束只在某些尺度出现的窄峰。[证明](../proofs/052-interval-mass.md)

证明将高斯热势在区间中积分。时间变化量为 O(r^α)，噪声能越过两个端点的有效宽度为 O(r^(q/2))，两者之积给出误差阶。独立审查复核了内外区估计与两侧符号。对含振荡项的参考扰动作了五个尺度的确定性数值求积以校验边界误差归一化；程序只计算有限截断窗口的诊断量。运行 python boundary.py 可复现。[数值输出](../computation/round052/boundary.json)

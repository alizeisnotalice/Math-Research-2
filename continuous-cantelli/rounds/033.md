# 第33轮　远尾高值区间迫使指数窄的低谷出现

设 f 为连续精确解，正尾 f≥1−o(1)，且沿正向倾斜时任意固定紧区间的质量趋于零。若某个 δ>0 和固定长度 r>0 满足 f≥1+δ 在一列向右远去的长度 r 区间上成立，则全局连续模满足

    limsup_{h↓0} log(1/h) ω_f(h) ≥ r²/8。

若 f 可微，同一端还满足 limsup log⁺|f′(x)|/x ≥ r/2。证明在区间的外端点作指数倾斜，找出向内偏移且亏损深度达到常数除以 x 的点集。该集合在倾斜测度下具有正质量，而其 Lebesgue 长度随 x 指数衰减。由此得到逼迫连续模增长的点对。[证明](../proofs/033-plateau-compensation.md)

作为推论，若 f 实解析且一致连续，并且 log⁺|f′(x)|=o(|x|)，则 f 恒等于 1。小于 1/log(1/h) 阶的全局连续模同样给出实解析刚性。没有均匀正则性的连续图仍然开放。

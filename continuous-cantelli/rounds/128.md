# 第128轮　精确非图模型的负差分可推迟到任意高阶

给定任意有限导数阶 N 和有限参数段 [0,Q]，存在 δ>0，使每个满足完整实变换且时间标记在 [0,1+δ] 的模型，都在两个方向、全部空间切点上通过这些阶数和参数的正性检验。证明在紧空间区用 E(F−1)²≤δ 与常数图比较，远区使用第122轮与图形无关的估计。

同时给出仅有 1−ε、1、1+ε 三个时间层的显式正联合分布。它保持标准高斯空间边际和全部实变换，却在 1−ε 的空间小区间产生负余量。ε 趋零时，其首个负整数差分的总阶数必趋于无穷，即使允许为每个模型重新选择空间测试。这解释了有限测试的盲区，也把“必须用单值连续图”的缺口具体化。[统一定理与三层构造](../proofs/128-deep-tests.md)

一般连续 Cantelli 猜想仍未解决。

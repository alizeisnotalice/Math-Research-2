# 第27轮　临界指数扰动的频率平均

设 V(u)=cuⁿ(1+O(u)) 是非负实解析模型，n≥4 为偶数，c>0，真实方差在所取到的最大点附近满足 |v(a+u)−V(u)|≤C exp(−d/|u|^(n−2))。令 k=n−2，θ=π/[2(n−1)]，并置

    d* = 2/(n c k) · [k sin(θ)/2]^(2(n−1)/n)。

则存在只依赖 n 的 ε_n>0，使 d≥(1−ε_n)d* 的模型全部被排除。[完整证明](../proofs/027-critical-packet.md)

d* 是单频绝对值估计中真实扰动的最坏衰减率与解析模型鞍点衰减率相等的位置。把相邻频率用复高斯权重平均后，实轴上的两个误差峰都严格降低，而解析模型保有一个主鞍点。两者之间的严格差值使临界系数下方的一小段也可排除。证明未计算 ε_n 的最优值，数值扫描所得阈值不充当 ε_n 的证书。

计算见 computation/round027。以 SciPy 校准 n=4,6,8,10,16,32 的实轴误差峰；δ=0.005 时均观察到下降。另作不同任务的双机校验：

- 本机 12 个 CPU 进程与原生 Metal 同时运行 51.108 秒（全部 12 个工作进程共同窗口）。该窗口 27 次 CPU 空闲率采样皆为零。CPU 对 384 个剖面在 6 个尺度比较正误差包络，4,608 个积分的两种求积结果差至多 1.78×10⁻¹⁵。Metal 对实作用量执行 5,888,802,816 组浮点计算，命令缓冲区时间 43.072 秒；相关源码在 local 子目录。
- MacBook 的独立计算研究第25–26轮的尾部窗口。原生 Metal 细化扫描 4,694,053 个合成剖面、455,323,141 个偏移组合，52.244 秒 GPU 命令时间。所有参数的正性边界及其超额均限于所选剖面。remote 子目录保存独立的 Swift、着色器、CPU 后验核验脚本及数值结果。第26轮的 tilted_rep.py 记录了相应 CPU 独立窗口扫描。临界解析扰动定理由本轮解析证明给出，不依赖这些尾部实验。

复算频率包络可用 python critical_packet_check.py；单机原生 Metal 及 Python 批量脚本的模型、参数与版本见随附源码及结果。一般连续问题、任意强度临界扰动和更慢衰减的非解析余项仍开放。

本机 action-main.json 的全网格归一化诊断在 h=b=0 时会放大二分求根约 10⁻¹⁹ 的绝对舍入残差，不能将该条诊断的极值当成数学现象。限定非零系数的分区及频率平均的解析证明不使用这个极值。

修正复算中，action_corrected.metal 单独处理零系数及局部根区间。在 787,480,576 组新的校准中，原先非零不对称剖面的符号结论保持一致，零剖面的虚假归一化极值消失。对应结果为 action-stability.json；复现修正内核时须显式选用该着色器。

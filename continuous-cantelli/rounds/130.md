# 第130轮　总阶949的严格负差分与两机交叉复算

第5轮精确非图模型已在总阶949检测到严格负性：D_{551,398}(ψ)<0 对支撑在指定空间小区间中的每个非零非负光滑 ψ 成立。MacBook 的中点积分余项证书严格控制时间变量而非使用浮点网格插值；另外两机按不同空间盒分工，在 [2.935950,2.936058] 上形成连续无缝的54盒负号证书。更低总阶948虽已在危险邻域出现严格正证书，本轮没有把全对角最小性列为已证。[负性证明与邻阶范围](../proofs/130-difference.md) · [负区证书](../computation/round130/negative) · [交叉复算](../computation/round130/joint/report.json)

本机12个及 MacBook 15个 CPU 工作者在同一窗口积分，两个 Metal 设备同时检验不同的数学输入。按实测时钟差区间保持稳定计算，首批全部27个工作者的共同作业窗口超过3.53秒；在该窗口内，两块 GPU 同时执行本题命令的时间至少2.66秒。这仅量化可归因的并行作业。两块 GPU 各自的完整追加检验实际运行约50秒。计算程序均已退出。[可复核的时间交集](../computation/round130/joint/overlap.py)

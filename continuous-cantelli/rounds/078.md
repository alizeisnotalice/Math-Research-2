# 第78轮　临界接触奇部漂移的次阶速度

沿用第70轮的双对数临界模型。令 κ 表示归一化的两翼奇部差，d 为负侧的归一化亏损。若 κ 有界，加权尾积分的阶可提升到 O(D²)；若 κ→4a，则其阶为 o(D²)，D 是文中给出的显式参照量。特别地，在 κ=4a+A d+o(d) 或 κ=4a+A d²+o(d²) 的两种展开中都必须有 A=0。证明使用有界奇部差和精确偶通量抵消首两项。形式级数的系数恒等式以整数算术核对至80阶。一般临界芽仍有余地。[证明末节](../proofs/078-critical-refined.md) · [计算](../computation/round078)

一般连续 Cantelli 猜想仍未解决。

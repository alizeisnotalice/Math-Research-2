# 第82轮　全实线 Jensen 余项和双侧凸势的数值辨识

给出一族在一切非零位移上具有严格 Jensen 均值符号的显式扰动。相同形状下，一个振幅使非线性余项在全轴严格不足，另一个振幅存在非零平衡点。故单个倾斜参数达到严格配平也可来自非精确图。本机 M6 Metal 扫描2,005,401,600组双侧位移，105.001秒墙钟，设备命令91.603秒。一个浮点零值在70位复核中约为−6.80×10⁻⁷。[全实线证明与计算](../computation/round082/local/README.md)

对称候选若匹配高斯方差和四阶矩，非零的看涨期权函数差在正半轴至少两次变号。MacBook Metal 对438180组候选与81个行权价进行了35492580项比较，原生命令2.319秒；一个样例的七次变号经 CPU 复核。增加共同高斯噪声后，首个不匹配的高阶矩决定残差的首项。两台机器本轮负载时段各异，计算均已退出。[定理与收据](../computation/round082/mac/README.md)

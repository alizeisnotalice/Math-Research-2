# 第132轮　任意标记的大参数中心区域全阶符号估计

对每个固定阶数 n，直接估计热预解式的自由项和带标记项，得到含显式常数的全空间下界。当 z=√(2q) 充分大，所有满足 z|y|≤log z+n log log z−Bₙ 的截点均有严格正确的第 n 阶符号。证明只用标准高斯空间边际与非负标记，也适用于无界标记。它补充第122轮的小参数带和远端估计。复算逐阶核对了前13个导数多项式的递推恒等式，任意阶由归纳证明。[全局下界与中心区证明](../proofs/132-central.md) · [符号复核](../computation/round132)

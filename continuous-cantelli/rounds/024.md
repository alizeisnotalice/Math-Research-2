# 第24轮　解析接触之外的两种余项

在已取到的最大点，设 w 是任一光滑非负的局部参考方差且 w(u)=O(u⁴)。若真实亏损减去 w，在左右侧分别为
u^α (log(1/u))^β (c±+o(1))，α>2，且至少一个系数非零，则 **β=0，α 必须是整数，左侧系数必须等于 (−1)^α 乘右侧系数**。允许残差变号。这特别排除了四次首项之上的非零逆对数修正。完整推导见 [带符号残差证明](../proofs/024-signed-residual.md)。在 Mellin 矩有简单零点时，对核取原函数，比较对数尺度 L 与 2L，因而无需对 o(1) 余项求导。

**极小非解析扰动。** 上轮的复鞍点论证也排除与有限 n 阶解析模型 V 相差 O(exp(−d/|u|^γ)) 的实际亏损，其中 γ>n−2、d>0、n≥4 为偶数。取固定小核心，使真实 v 与 V 都 ≥c′|u|ⁿ。第23轮核心输出的带状解析上界仍对真实 v 成立：其证明只用真实核心仅在中心为零和离中心正下界。两个核心 Fourier 变换之差由实变量均值定理至多为
C ξ² ∫ exp(−d/|u|^γ−c′ξ²|u|ⁿ/2)du。
代换 |u|=ξ^(−2/(n+γ))z，z^(−γ) 与 zⁿ 的正线性组合有严格正的最小值，故此差至多 C′ξ² exp(−κξ^(2γ/(n+γ)))。该指数幂大于 (n−2)/(n−1)，不足以抵消第23轮解析模型在同相频率上的下界。临界 γ=n−2 的一般系数仍未处理。

**实际计算。** 以下材料位于 computation/round024。SymPy 精确验证 1≤k≤18 的 Hermite 矩与简单根导数；mpmath 在 60 位和 85 位复核对数尺度积分。另用非对称解析实例 v=u⁴(1+u/5) 检查上轮移动鞍点，55 位求积在最高校准频率处得到实际值与预测值之比约 0.999948−0.000087i。

- 本机 12 个 CPU 工作进程与原生 Metal 同时运行 61.709 秒。重叠窗口 37 次整机 CPU 采样空闲率皆为 0%，本组 CPU 占用中位数为 640.9%。Metal 共评估 3,523,215,360 个参数组合，命令缓冲区时间 59.854 秒。CPU 两种积分方法对 768 项带符号扰动的最大绝对差约 1.74×10⁻¹²。
- MacBook 的 15 个 CPU 进程共评估 15,728,640 个样本，累计 1279.4 CPU 秒，墙钟 160 秒。Metal 于同一运行窗口评估 556,184,720 个组合，命令缓冲区 49.908 秒，83 次整机 GPU 采样均为 100%。所有这些采样均在本课题 CPU 工作进程运行窗口内。两台机器的本批任务均已退出。设备利用率包含其他进程。
- 对允许两侧系数变动的四次包络 (15/4)u⁴/r²≤v(a±u)≤(17/4)u⁴/r²，0<r≤1/8、6/5≤a≤5/4、3/2≤M≤2，取 ε=r²/1024。核心密度在 a 处的有理下界是 143026539/500000000，高于目标上界 1/4。此处缩小 r 会改变包络系数。另一本机有理证书在固定参数 a=3/2、M=2、c=4096、r=1/8、ε=2⁻³² 给出精确四次核心的密度比 >7/6。有限尺度证书用有理数计算，独立于浮点筛选。

复算可在临时目录运行 mellin_audit.py、analytic_germ_check.py 及 remote-cpu/quartic_certificate.py。对于 CPU 并行实验，local-cpu/quartic_contact.py 使用 --cases 64；remote-cpu/quartic.py 分别给出 shard 编号 0 至 14 及 --exponent 20 --order 28 --shards 15 --out 结果路径。两个 Metal 子目录分别包含 Swift 主程序、对应的同目录着色器和浮点扫描摘要。文件内记录采样及设备参数。一般连续猜想仍开放。

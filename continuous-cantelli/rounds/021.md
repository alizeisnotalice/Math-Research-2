# 第21轮　振荡接触的局部比例

在每个取到的全局最大点，集合 v(a+u)≤u² 的缩放指示函数有唯一弱星极限，且该极限是空间常数。由此即使亏损比值没有单侧极限，各固定缩放区间的平坦相比例也必须一致。精确公式、可积性及弱星极限的唯一性见 [证明](../proofs/021-contact-phase.md)。

独立审查还可直接改用方差 τh² 的零阶密度，令 τ 趋零恢复近似恒等算子。本轮主证明使用平移的一阶导数及零阶质量。SymPy 1.14.0 实际核对热方程以及外区界所需的两个归一化多项式，分别为 −z³ 和 (z⁵−z³)/2；复算脚本为 computation/round021_kernel_bounds.py。弱星紧性和极限交换的依据在证明中给出。能否排除严格介于零和一之间的比例仍开放。

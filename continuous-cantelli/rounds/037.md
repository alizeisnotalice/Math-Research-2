# 第37轮　四次接触处的 Taylor 级数必须发散

若存在 d>0 及在原点附近实解析的 H，且 H(0)=1，则精确解的局部方差不能在某个 a 的两侧满足

    v(a+u)=d u⁴ H(u)² + O_J(|u|^J)，对所有正整数 J 成立。

因此，若光滑精确解有四次接触，其 Taylor 级数必须发散。这个结论也适用于连续图，只要它具有上述全阶值估计。它同时包含非零五次项和从六次或更高次才开始修正的解析参考。一般的发散 Taylor 级数仍未被排除。

证明在高斯变量 b 给定时研究 u↦u+b u²H(u) 的两个逆分支。五次项把纯四次模型第 N 个偶阶系数的下界放大了 exp(|H′(0)|√N/(2√d)) 倍。对扰动的 Hermite 估计必须保留同一指数因子，得到相对误差 O(N^(−5/2))。在 b 有界且空间截断生效的区域，通过先对 b 积分并追踪两个解析移动端点处理截断。[完整证明](../proofs/037-convergent-quartic-jet.md)

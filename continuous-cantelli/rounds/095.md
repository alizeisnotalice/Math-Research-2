# 第95轮　反射壁和不等尾临界系数的双机 Metal 核验

本机 M6 的反射壁积分有闭式和可复算的上下界。固定几何的 h^(3/2) 首项有显式次阶修正；同时变化几何和时间时并不一致。Metal 实扫4,028,366,848组，墙钟100.003秒，命令累计80.854秒。CPU 自适应积分复核九个分层代表，最大对数差8.12×10⁻⁵。[证明与本机收据](../computation/round095/local/README.md)

MacBook 的远尾与边缘联合校准保留56,543,178个有效点，Metal 命令累计4.885秒。一次诊断的积分窗重叠，已从正式计数剔除；两机 CPU 对十个向量独立复核，最大 GPU/CPU 对数余量差1.45×10⁻⁶。解析估计另给出指定双重饱和展开下 (log r)²/r⁴ 的系数上限 −16。这些只在列明的饱和条件下适用。四路 CPU/GPU 批次均已退出，本轮未测得持续四路同步满载。[MacBook 推导及结果](../computation/round095/mac/README.md)

# 第74轮　双机 Cantor 谐波扫描与任意有限阶精确消去

给定 N，取两个大于 N 的互异素数 p,q，在 2pq 个格点上构造两个不同陪集的循环并集。得到基本周期为整圈、方差只有两个取值而前 N 个非零谐波全部精确消失的图。该图为分段常数；它说明有限谐波测试的局限。[构造与证书](../computation/round074/local-metal/proof.md)

本机 CPU 用12个进程算出3220个谱值，独立46位复核的最大绝对差为2.89×10⁻¹³。本机 Metal 扫描395,870,208组，设备执行累计78.991秒。MacBook CPU 用15个进程完成3,890,432组，嵌套复核699,062组。高振荡的6例经提高阶数，与独立递推相差小于10⁻¹⁵。MacBook Metal 扫描98,703,360组，设备执行累计100.156秒。单精度极小系数有显著相对误差，按 CPU 复核解释。四路作业均退出；各自采样不构成两台机器持续同步满载的证明。[脚本与测量](../computation/round074)

一般连续 Cantelli 猜想仍未解决。

# 第66轮　噪声宽度上的高阶有符号扰动与振荡检测

若光滑参考方差以 c u^q 起始（c>0，q≥4 为偶数），实际方差与参考的差是 O(|u|^α)，α>q，则第52轮的平均系数可以在长度等于任意固定正倍数 r^(q/2) 的窗口上读取。归一化扰动在这个尺度的局部弱星极限是唯一常数；非整数 α 时等于零。允许实际方差不可微。证明先用高阶热核导数消除平滑背景，再把有限个噪声宽度的积分与第52轮的大窗口相接，从而确定常数。[有符号定理](../proofs/066-signed-noise-scale.md)

即使仅规定一侧为 u^q[c+η(u)H(ωu^(−p))+o(η)]，p=q/2−1>0，H 为连续周期函数，对任意代数小的文中振幅，也可排除非恒定 H。用带复频率的高斯测试函数，排除范围延至 η=exp(−a u^(−pγ))、0<γ<1、a>0。在 γ=1 时文中给出足以排除的明确频率门槛，临界情形的低频有限谱仍有余地。[代数振幅](../proofs/066-weak-oscillations.md) · [指数小振幅](../proofs/066-wave-packets.md)

符号核验了180个用于消去光滑项的高斯矩。关键复响应另用独立数值积分核对，最细校准误差为3.06×10⁻¹⁰。[计算记录](../computation/round066)

一般连续 Cantelli 猜想仍未解决。

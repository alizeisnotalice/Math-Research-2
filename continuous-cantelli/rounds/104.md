# 第104轮　有效尾指数与有符号热余量的精确开始时刻

对任意有界连续精确图，右侧位置 y>0 的时间迹从 min(c₊,inf_{x>y}f(x)) 精确开始。这里 c₊ 由全部远尾子水平集的高斯质量决定，每层都可以具有多个分量。若 H=sup f>1，且每个非零点有证明中列明的一侧连续模，则至少一翼满足 c<H−1。因此两侧均趋近 H、只在高斯指数尺度的窄区间中反复深跌的一类连续图被排除，即使两侧点态下极限都小于 1。具体例允许 H=1.6、谷底 0.95、整数 n 附近的井总宽度不超过 C exp(−n²)。[开始时刻、稀疏性及证明](../proofs/104-tail-onset.md) · [半直线时间迹次序](../proofs/104-resolvent-order.md) · [复算](../computation/round104)

# 第25轮　全局 Hölder 实解析类的刚性

满足全局 Hölder 条件的实解析精确 f 必为常数。第23轮所需的全局最大值在此处由两端 f→1 自动取得。核心步骤是在精确指数权重下证明 X−t⇒N(0,1)，由正高斯窗口质量排除远处固定高度、固定宽度的高峰。同时得到“两端分别有极限”的实解析类刚性，覆盖两端最终单调及有限临界点情形。[证明](../proofs/025-tilted-tail.md)

若 f 在原点有二次零点，证明还给出两端正超额的带常数三次下界。用 Python 3.13.18、SymPy 1.14.0 与 mpmath 1.3.0 计算 120 个紧邻域积分结果及 8 个尾部结果。对纯二次模型，将半轴结果与高斯分布函数的闭式比较，最大差约 1.38×10⁻⁷⁶。这些计算校验归一化，弱收敛证明使用完整恒等式。复算脚本和结果在 computation/round025/origin_tail.py、origin-tail-results.json。

仅有实解析性而没有远处的统一正则性或两端极限时，尚不能保证最大值取到。一般连续、有界且全局 Hölder 的非解析解也尚未整体排除。

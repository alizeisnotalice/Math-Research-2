# 第20轮　非对称最大点

2026-11-18。证明见 [一阶导数证明](../proofs/020-asymmetric-maximum.md)。在任一取到的全局极大点，平方距离归一化后的亏损不能一侧趋零、另一侧趋无穷。证明对完整积分使用同一可积上界，不需要控制远处接近最大值的速度。

第17轮的偶数阶符号论证要求两侧均尖锐，并另行处理了平台与线性的特殊情形。本轮的一阶导数保留了方向信息，排除了整个线性—三次局部模型。此前对该模型的四阶系数运算仍可作为渐近校验；排除结论直接由一阶极限给出。一般连续情形仍开放。

复算方法：运行 python round020_odd_contact.py <输出路径>（mpmath，脚本位于 computation）。核心半径 0.08，两种求积在十组参数上的最大差约 6.0×10⁻⁴²。取 c=d=x₀=1、ε=10⁻²⁴，核心的缩放导数约 0.09653235263026，解析极限约 0.09653235263005。证明适用于完整积分。

独立有限尺度核验见 computation/round020_odd_certificate.py。x₀=3、左右系数为1、半径1/4、h=2⁻³⁰ 时，右侧缩放积分仅取 t∈[1,2] 即大于 1/1594323（用 B≤2、g(3+ht)>1/(3·3⁸)、g(t/√B)>1/(3·3²)、t/B^(3/2)>1/3）。左侧核心绝对值至多 h∫₀^{1/4}u^(-1/2)du=h，外部左侧由 sup_s |p′_s(u)|≤1/u² 得上界 16h。Fraction 脚本核验差值为正，目标导数却为负。

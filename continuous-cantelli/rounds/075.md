# 第75轮　双机同步复算与连续方差图的有限谐波精确消去

给定任意 N，在整圈构造基本周期为一整圈的连续非恒定距离幂方差，使前 N 个谐波精确消失。取两个大于 N 的互异素数，再删去两组不相邻、等间隔的数字。第一代的等长缺口在低频抵消，所有深层修正由首位相位因子消去。基数385的显式样例在指定参数下第7和11谐波严格可检。[构造与核验](../computation/round075/mac-metal/README.md)

本机12个 CPU 进程核验2592个频率，56位与独立复算最大绝对差 9.76×10⁻¹³；期间整机 CPU 空闲采样为0%。本机 Metal 扫描383,942,656组，设备命令101.018秒，222次整机 GPU 采样均为100%。MacBook 的15个 CPU 进程扫描25,223,168组，整机空闲采样15.33%–26.57%；其 Metal 扫描47,308,800组，命令120.477秒，252次采样均为100%。若两机运行期间时钟差保持在事后测得的范围内，四路作业至少重叠19.5706秒，在此期间两台 GPU 的原生命令同时执行至少10.09秒。全部作业均已核验退出。[四路计时复算](../computation/round075/mac-metal/overlap.json) · [本机 CPU](../computation/round075/local-cpu/r075-local-cpu-receipt.json) · [MacBook CPU](../computation/round075/mac-cpu/summary.json)

MacBook CPU 首批模型的固定截断会漏掉最深尺度的首项贡献。扩大积分范围后，六个固定幂次样例与解析首项的最大相对差为2.26×10⁻⁷。另得幂次逼近2时的单侧热迹过渡公式和负的一阶修正。[证明](../computation/round075/mac-cpu/near_quadratic.md)

# 第145轮　全实轴一致逼近、逐项精确校正与连续模的必然丢失

从第128轮固定的精确三层联合律出发，证明存在光滑有界的单值图列。它们在两个固定有理点的高度差恒为1/4，均值精确，每一轮前 n 个指定非零有理倾斜参数也精确；全部实参数的最大绝对误差不超过 2⁻ⁿ。另有固定时间和固定光滑非负测试，在整列后段见证严格负的热余量。复参数紧集上的留出也收敛。其弱极限在每一空间开区间都混合至少两层时间，故没有任何子列能在一个正长度区间保持共同连续模。构造严格满足紧性路线的其余条件，并定位其失败之处。[构造与有限约束校正证明](../proofs/145-approximation.md)

# 第23轮　解析最大点的局部刚性

第22轮留下了偶次、同系数的平坦接触。本轮证明，只要最大点附近的亏损有收敛幂级数，所有这些非恒定接触都被排除。证明不需要整个函数解析。若整个函数实解析且取到全局最大值，就由解析唯一性得到常数解。[证明](../proofs/023-analytic-maximum.md)

论证从两个方向估计同一个局部输出测度的 Fourier 变换。完整高斯输出迫使局部密度可延拓到一条复带，因此变换至少按指数衰减。解析亏损给出两个非退化鞍点，在可选的一列频率上二者同相，其衰减只能是伸缩指数型。两个估计互不相容。

以 a=3、c=1 做独立数值校准。Python 3.13.18、mpmath 1.3.0，在 55 位精度下沿移位轮廓积分 z 的实部区间 [−2,2]。对于四次接触，调相指标从 4 增至 64 时，相对于主项的复比从 1.02262−0.17419i 变为 1.00146−0.04269i。有限积分用于校验相位和符号，严格余项见证明。运行 python round023_saddle.py 可在标准输出获得结果（脚本位于 computation）。

一般连续猜想仍开放。具有非解析余项的偶次首项、在最大点无限阶平坦的光滑函数、以及上确界不取到的情形均未被此定理排除。

# 第48轮　六次接触的解析参考与平坦扰动

设六次接触的参考方差为 c u⁶ H₀(u)²，其中 c>0，H₀ 在零点实解析且 H₀(0)=1。本轮对两类扰动证明了排除结论。

- 若实际方差与参考方差的函数值之差为 O(exp(−d/|u|⁴))，则 d>(2·2^(2/3)/3−1)/(4c) 已足够。此结论不需要扰动在扇区内解析。[实变量证明](../proofs/048-real-critical.md)
- 若实际方差振幅与 H₀ 的差可以在左右两个复扇区内分别解析延拓，并在那里满足任意阶平坦估计，则在[证明所列开角条件](../proofs/048-sextic-fold.md)下也可排除。这允许实轴上的衰减显著慢于上述指数界。参考函数有任意高阶解析修正时，结论仍成立。[一般解析参考](../proofs/048-general-sector.md)

条件化高斯变量后，六次模型对应局部三次映射，其中部分参数有三条实逆分支。证明分别估计实折点和复共轭折点对高阶密度系数的贡献；相位可能抵消时，选取有正下界的阶数子列。两名 Astra 独立核验了分支截断、系数归一化与临界指数。[独立审查](../proofs/048-independent-audit.md) · [数值及符号核验](../computation/round048/r043_sextic_sector_check.json)

缺少扇区延拓和指定实指数界时，本轮报告中的定理不能直接使用。

一般连续 Cantelli 猜想仍未解决。

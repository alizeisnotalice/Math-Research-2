# 第28轮　原点临界接触留下的尾部质量

对 f(±u)=u²/[2(ℓ+b log ℓ+d)]、ℓ=log(1/u)，同向参数 t 的原点核心贡献约为 exp(d)(log|t|)^(b−1/2)/√2。因此 b>1/2 或 b=1/2 且 d>log(2)/2 都不相容。当核心仅占固定比例 m<1，对剩余质量的条件分布仍可证明第25轮的高斯平移极限。由此排除两侧均未饱和、全局 Hölder 且仅在原点外解析的这一类函数。完整论证见 [原点模型证明](../proofs/028-origin-log-contact.md)。

本机用 mpmath 50 位计算 b=0、1/2、1，d=0，log t=100、1000、10000 的九组积分。在 b=1、log t=10000 时，中央窗口贡献约 70.63957，和渐近预测的比为 0.99899437。脚本计算中央窗口，证明另行控制窗口外部。复算命令为 python computation/round028_origin.py（从课题目录运行）。一般连续情形、临界饱和后是否仍有定量尾部返回均开放。

# 第67轮　谷底 Fourier 系数、有限谐波匹配与双机核验

对圆周均匀输入，精确平稳要求全部非零 Fourier 谐波消失。已证明在常数附近存在基本周期为 2π 的非恒定方差图，使前三个谐波精确为零。隐函数定理给出严格存在性；一个固定高频例子的86位数值求解把前三个坐标压到2.88×10⁻⁸⁷，第四谐波约0.195124。谷底形状与允许谐波另有精确渐近，包括从尖点到二次极小的对数过渡。[有限测试构造](../computation/round067/mac-metal/README.md) · [谷底渐近](../proofs/067-circle-fourier.md)

本机 GPU 在105.011秒内完成523,632,640组扫描，Metal 命令累计99.997秒；十个分层代表值与CPU的复数绝对误差至多5.06×10⁻⁸。MacBook GPU在40个分层覆盖1,895,301,120组，Metal累计100.019秒。MacBook CPU的15个进程运行122秒，计算65,323,008组；平滑坐标求积独立复核1,984组精确Bessel模型，最大差2.22×10⁻¹⁶。CPU期间整机空闲率采样25.53%–26.7%。[本机 GPU](../computation/round067/local-metal/README.md) · [MacBook 记录](../computation/round067/mac-cpu/summary.json)

本机 CPU 先后遇到稀峰求积差异超限及分点数上限，两次结果均未用于验证。改为细分稀峰并按分点数分配求积容量后，32个模型的160项跨算法复核全部通过，最大差8.27×10⁻¹¹；成功批次37.49秒。此轮四路分别投放，没有确认持续同时满载。计算完成后各进程均已退出。[临界面积模型](../proofs/067-log-area.md) · [本机复核](../computation/round067/local-cpu/critical-area-summary.json)

一般连续 Cantelli 猜想仍未解决。

# 连续版 Cantelli 猜想

## 问题与假设
X,Y 独立，均为 N(0,1)，φ:R→[0,∞) 全局连续。若 X+φ(X)Y 为高斯，是否 φ 必为常数？记 a=φ²，m=E a(X)。不预设有界、可微、单调或尾极限。

完成标准：一般连续情形的完整证明，或连续非恒定反例及精确分布验证。数值近似高斯和有限阶矩匹配不构成完成。

## 复现
实际命令、版本、输出及证据范围见各轮报告。第2轮已在本机与 MacBook 执行；第3轮为精确时间网格核验；第4轮包括受限连续函数拟合、独立高精度积分和有理结构证书。

第5轮新增高斯边际非图放松反例，以及连续振荡近解的全变差收敛与非稳定性证明；原题仍开放。

第6轮给出零接触宽度、对数临界修正及共同质量预算；仅处理边界层，严格正 f 情形仍待研究。

第7轮建立内部最低点与两端高斯衰减、线性指数和−3幂次的条件性匹配，排除双高斯凸起族；修正尾候选仍未通过完整恒等式。

第8轮给出条件性的中心Taylor数据—有限阶尾系数递推；明确定位第7轮候选的次阶不匹配。

第9轮证明全部形式尾部匹配仍不足以保证完整恒等式；后续重点转向有限参数约束。

第10轮证明有限变换样本与有限矩能被光滑非恒定函数精确匹配；完整恒等式仍失败。

第11轮给出固定幅度与连续模下的统一截尾检测证书，并将其扩展为一般尾部的必要贡献预算。

第12轮把有限约束插值强化到固定幅度、正方差及输出全变差趋高斯；共同连续模仍失效，原题未解决。

第13轮用定向有理积分排除两个核心邻域的任意非负尾部补全，并明确凸上界放松的不足。

第14轮补充反向核心排除和锐利单参数尾部包络，严格区分单点可修复与联合可行。

第15轮建立核心剩余测度的跨频率半正定约束，并以有理三角测试证书排除光滑严格次解的有限核心邻域。

第16轮排除已取到的非退化二次全局极值，并给更平坦极值的中心禁区；仍不解决一般连续情形。

第17轮以高阶密度导数排除0<α<2的幂次尖极值，并给一般局部负矩必要条件及连续分段仿射推论。

第18轮排除外部具有统一间隙的有限对数尖峰配置；8个独立工作区开展5项审查与3项后续研究。

第19轮以定量尾部预算替换统一间隙，并给临界幂次的充分系数条件；原题仍未解决。

第20轮以一阶热核导数排除一侧平坦、另一侧尖锐的全局极大接触。

第21轮证明全局极大点的平坦相在所有缩放区间具有相同极限比例。

第22轮排除非偶次的双侧平坦幂次首项，并强制偶次首项的两侧系数相等。

第23轮证明取到全局最大值的实解析精确解必为常数。

第24轮给出光滑参考项之上幂次对数残差的必要条件，并排除解析模型的部分非解析极小扰动。

第25轮通过平移输入的高斯极限证明全局 Hölder 实解析类刚性，也覆盖两端有极限的实解析类。

第26轮将高斯平移尾部结论细化到 K log|t|/|t| 的观测窗口，排除导数增长为 o(|x|/log|x|) 的非恒定实解析候选。

第27轮以相邻频率的高斯平均排除一类临界指数尺度上的非解析扰动。

第28轮计算临界原点零点的倾斜质量，并在其未饱和时建立剩余输入的条件高斯极限。

第29轮给出饱和原点零点的两个次阶门槛，并在剩余质量趋零时证明条件平移极限。

第30轮证明一般精确图的倒数方差中心满足统一的区间质量估计。

第31轮证明局部 Hölder 零平台的边界增长下界，推出局部 C^{2,η} 精确图的零平台必延伸至全实线。见 [轮次报告](rounds/031.md)。

第32轮在局部亏损为 O(t⁻²) 等条件下把尾部返回窗口缩至 O(1/t)。见 [轮次报告](rounds/032.md)。

第33轮证明固定长度的远尾高值区间强迫指数尺度的振荡。见 [轮次报告](rounds/033.md)。

第34轮排除具有双侧无限阶平坦最大点的非恒定光滑精确图。见 [证明](proofs/034-infinite-order.md)。

第35轮用两机 CPU 与 Metal 完成浅尾井及平坦核心的有限尺度排除。见 [报告](rounds/035.md)。

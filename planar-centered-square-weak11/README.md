# 二维中心正方形精确弱 (1,1) 常数

研究对象是 Lebesgue 背景下
\[
M_\square f(x)=\sup_{r>0}(4r^2)^{-1}\int_{x+[-r,r]^2}|f(y)|\,dy,
\qquad C_2=\sup_{f\ne0,\lambda>0}\lambda|\{M_\square f>\lambda\}|/\|f\|_1.
\]
两个坐标使用同一半径，正方形中心就是接收点，半径遍历全部正数。

目标是一般输入上界与合法有限 L¹ 输入序列的极限匹配。精确值可用有唯一性证明的方程刻画，但拟合、多位小数一致、固定模型最优或单独区间改进都不是完成。确定精确值并独立复核后停止研究。

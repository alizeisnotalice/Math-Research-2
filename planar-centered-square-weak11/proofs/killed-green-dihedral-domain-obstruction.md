# 任意四重对称单连通 Brownian 退出域及有限正混合的成本障碍

2026-11-15；第38轮主命题候选。第33轮冻结材料保持不变。

## 定理

令D={|x₁|+|x₂|≤1}。设Ω⊂R²为有界单连通域，D紧含于Ω，且Ω在旋转π/2与实轴反射下不变。无需Ω凸、星形、与D同形或具有光滑边界。令G_Ω(z)=G_Ω(0,z)为生成元Δ的杀死Brownian占用Green密度，延拓为Ω外零。

则

    (1/2)∫G_Ω > (6π/5) G_Ω(1)。                         (T)

特别地，任意合法标量majorant K=aG_Ω≥1_D，其成本满足

    (1/2)∫K > 6π/5 > 18/5 = 3.6。

更一般，任意有限正混合K=Σ_{j=1}^N a_jG_{Ω_j}，a_j≥0，每个Ω_j满足同样条件，若K≥1_D几乎处处，则

    (1/2)∫K > 6π/5。

这严格排除该整个非同形、非凸、非星形域族及其有限正混合对继承3.590865312933上界的改善。结论是比较核族的成本地板，不是C₂下界。

## 1. 对称性、映射及一个必要点约束

取归一化Riemann映射F:𝔻→Ω，F(0)=0，F'(0)>0。唯一性和域的旋转/反射对称性给

    F(iw)=iF(w)，F(conj w)=conj F(w)，
    F(w)=Σ_{n≥0} a_n w^(4n+1)，a_n∈R。

有界性给F∈H²，故Σa_n²<∞。因为1∈Ω，反射对称性与单射性使q=F^(-1)(1)实；F在(-1,1)的实导数处处不为零，且在0为正，因此q∈(0,1)。这一步不依赖Ω边界正则性，也不要求实轴与Ω的所有交集连通。

Green的共形变换给

    G_Ω(1)=−logq/(2π)。                                  (1.1)

半积分成本的必要点约束只需这个值。对单核的最佳归一化c=essinf_D G_Ω≤G_Ω(1)，但证明(T)不需要辨认c的实际位置。

## 2. Parseval及Cauchy–Schwarz

圆盘Green为−log|w|/(2π)。换元和圆周Parseval给

    ∫G_Ω=∫_𝔻 [−log|w|/(2π)]|F'(w)|²dw
          =Σ_{n≥0}(4n+1)²a_n² ∫₀¹(−logr)r^(8n+1)dr
          =(1/4)Σ_{n≥0} a_n²。                          (2.1)

非负项允许Tonelli；有界域的退出期望有限。F(q)=1和Cauchy–Schwarz给

    1 ≤ (Σa_n²)(Σq^(8n+2))
      =(Σa_n²) q²/(1−q⁸)。                              (2.2)

故由(1.1)–(2.2)，

    [(1/2)∫G_Ω]/G_Ω(1)
       ≥ π(1−q⁸)/[4q²(−logq)]。                         (2.3)

这是必要成本下界，未把Cauchy–Schwarz最优系数声明为可单射的映射，也未以有限求和代替完整Green。

## 3. 一个准确正平方和给全参数地板

对t∈(0,1)，

    −logt ≤ (1−t)/√t。

证明：置s=√t，h(s)=s^(-1)−s+2logs满足h(1)=0、h'(s)=−(s−1)²/s²≤0，故h(s)≥0。

在(2.3)置t=q²，并用该上界放大正分母，得

    π(1−q⁸)/[4q²(−logq)]
      ≥ π(1+t+t²+t³)/(2√t)
      = π(1+q²+q⁴+q⁶)/(2q)。                            (3.1)

以下是精确有理系数恒等式：

    q⁴+q²−(12/5)q+1
      =(q²−1/3)²+(5/3)(q−18/25)²+28/1125 >0。          (3.2)

因此(3.1)严格大于6π/5，得到(T)。π>3便给6π/5>18/5，已严格超过旧3.590865312933，无需依赖未经认证的小数。

## 4. 有限正混合没有遗漏

对每个j，(T)给

    (1/2)∫a_jG_{Ω_j} ≥ (6π/5)a_jG_{Ω_j}(1)，

只要a_j>0就是严格不等式。有限项求和后

    (1/2)∫K > (6π/5)K(1)。

至少一个a_j>0，因为K≥1_D。每个Ω_j紧含D，有限相交仍含D的一个邻域，故K在顶点1附近连续。D中有趋向1的正面积集合，由几乎处处K≥1得K(1)≥1，完成混合结论。

各单核不必先分别归一化；因此上述推论确实覆盖利用不同域的Green值互补的有限正混合。无限混合、负系数混合、非D4域、非单连通域、其他生成元及非Green核均不在本定理声明范围内。

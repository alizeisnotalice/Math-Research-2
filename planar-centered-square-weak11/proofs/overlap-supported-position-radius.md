# 第47轮：按竖支持相交约束认证更大的单轴仿射区间

日期：2026-11-15。该定理放宽第39轮“全部raw横端点保持全预序”的充分条件；第39/45轮冻结代码和输出不修改。它只作用于已完整覆盖的固定有限矩形族，不提供一般C₂上界，也不保证算出的半径达到最近面积转折。

## 1. 固定完整族与可用域

在中心s=0附近，设已验证一个参数区间|s|≤h_*，其中：源副本目录、bbox成员及质量固定；未列入下述候选目录的盒始终为空；统一尾界有效。候选盒在区间内允许从当前活跃变为空，或当前为空以后再激活，故不能仅保留中心的活跃子集。

候选接收矩形为

    E_i(s) = F ∩ (l_i(s),r_i(s)) × (c_i,d_i),
    l_i(s)=a_i+u_i s,   r_i(s)=b_i+v_i s,

F=[f_L,f_R]×[f_B,f_T]固定，c_i,d_i固定。约定横或纵长度不正时为空。令Y_i=(c_i,d_i)∩(f_B,f_T)。恒空的Y_i可删除；其余Y_i为固定非空开区间。实际sqrt质量半径已包含在a_i,b_i,c_i,d_i中，这些系数可为实代数数。

对原始完整slab，h_*≤min(H,δ_empty)；对从它重中心所得候选族，必须使用剩余原源slab和**原来未列入目录的空盒**余量，例如h_*≤min(H−|s_shift|,δ_empty−|s_shift|)。新中心变空的已列入盒仍留在候选目录，以下自身端点约束负责其不激活。不能以旧全局raw端点半径作为放宽后的硬上限，也不能放松上述目录和未列入空盒前提。

## 2. 相交支持的全预序充分条件

称i、j相关，当且仅当|Y_i∩Y_j|>0。候选盒自身始终相关于自身。将F的两条竖边界当作固定横端点，其竖支持是整个(f_B,f_T)，因此与每个非空Y_i相关。

**定理1。** 若在区间I⊆[−h_*,h_*]内，对每一对相关候选盒，来自它们的所有横端点之间的相对全预序保持不变，且每盒自身横端点、每盒横端点与F竖边界的全预序也保持不变，则完整面积A(s)=|⋃_iE_i(s)|在I上仿射。

证明：以全部固定Y_i端点和F_y边界把竖轴分为有限个正高开条带。对任一条带J，包含J的候选盒集合I_J固定。任意i,j∈I_J的竖支持都包含J，所以|Y_i∩Y_j|>0。假设因此保证I_J内全部横端点及F边界的全预序固定。其横区间是否为空、clip选择、全部一维横gap的覆盖状态都固定；持久相等类合并，零宽gap删除。横并长是固定覆盖系数乘仿射横gap之和，故仿射。把各条带固定高度乘横并长求和即得A仿射。竖端点零测集不影响面积。此证明包括候选盒在中心为空的情形：自身/clip比较在I内固定，使该盒仍为空。

不同竖支持不交的raw横端点可以在I内交换顺序；在任何正高条带内它们从不同时出现，故不需约束。定理不排除同一参数处其他相关事件改变面积，也没有把每次相关交换断言为真实有贡献事件。

## 3. 外竖区间与保守相交关系

可对每个真实Y_i使用包含它的固定外有理区间Y_i^+⊆[f_B,f_T]。若真实竖支持正长度相交，外区间也必正长度相交。因此把所有|Y_i^+∩Y_j^+|>0视作相关，只会增加约束，不会漏掉必要约束。外区间仅端点接触时没有正高共同条带，可不构成边；若实现把触点也视作相关，仍安全但更保守。

这允许不先求真实全部y根端点的精确排列。外区间可由dyadic定向根界和原有理坐标产生，不能用四舍五入近似导致真实支持被缩小。F的两边界节点在全部正高竖条带保持激活。

## 4. v∈{0,1}时的可认证半径

本节仅允许全部raw横端点速度属于{0,1}。在s=0把横端点相同且速度相同的整个仿射表达式合并成一个节点；不同速度在中心相等且相关时没有正的对称稳定半径。初版实现可以对任意中心异速相等直接fail closed，即使其支持不交；这是实现适用范围的保守限制。

按外竖区间端点分成正高条带。在每个条带激活所有其Y_i^+覆盖该条带的候选盒的两个raw横端点，并始终激活F两节点。一个端点节点可能由多个盒共享，须保持引用计数，不可因一个盒退出就错误删除节点。

把该条带内活跃节点按s=0真实横值排序。对相邻且速度不同的节点p<q，以定向区间取得真实正间隙g_pq=e_q(0)−e_p(0)的正有理下界g^-_pq。令g_*^-为全部正高条带上这些有理下界的最小值。没有异速相邻对时记g_*^-=+∞。定义

    δ_new = min{h_*, g_*^-/2}.                          (1)

若任何所需下界≤0，必须加精度或拒绝给正半径，不能忽略该对。

**定理2。** 在上述精确中心排序和完整条带激活前提下，δ_new>0保证定理1的相交支持全预序条件，因此完整A在[−δ_new,δ_new]仿射。中心已认证的β在该整个区间保持不变。

证明：同速节点的差恒定。任取一个条带内的异速节点对p<q；沿当前排序从p到q，因为两端速度不同，至少有一个相邻异速对r<r+1，且

    e_q(0)−e_p(0) ≥ e_{r+1}(0)−e_r(0) ≥ g_*^-.

两端速度差绝对值1，所以|s|≤g_*^-/2时原差仍≥g_*^-/2>0。故该条带全部异速对及同速对的全预序不变。每个相关盒对在某一正高外条带共同出现，条件覆盖全部相关比较；F边界和每盒自身两端点也自动包含。再用定理1。

若使用一般速度，间隙除以2不足以承担速度差；仅用当前相邻异速gap的上述证明也不能原样推出最早事件。模块必须拒绝非0/1速度；本轮不声称一般速度版。

## 5. O(n log n)完整计算接口

全部raw横端点真排序一次。每个外竖区间的上下端点给两个竖扫线事件；相同y事件须成组处理，只在下一严格更大y端点之间的正高条带更新全局最小值。点接触事件不产生正高条带。

树节点保存：该范围第一个/最后一个当前激活横端点，以及内部相邻异速对的最小正间隙下界和见证。合并左右子树时，仅需再检查左末与右首的速度是否不同。叶记录共享canonical端点的引用计数，正计数才激活。根给当前竖条带的相邻异速最小值；遍历全部竖条带即得到(1)。初始x/y排序和O(n)次更新各需O(n log n)比较/树操作；精确根区间精度的算术成本另计，不把位复杂度隐去。

应输出：上游完整slab/重中心输入hash，h_*每个上限的来源，速度域验证，根bits，候选矩形数、canonical横节点数、竖事件/正高条带计数、引用计数平衡、g_*^-、限制节点与其共享外竖条带、δ_new、旧全raw半径供比较，以及所有依赖源码hash。新结果的完整性仍依赖上游slab已验收，不得将条件模块结果自行包装成全输入认证。

小例至少覆盖：竖支持严格不交时忽略近横交换；正长相交时保留该交换；竖端点只触而无正高交；共享横端点引用计数；F裁剪边界；同速/持久等号；中心异速等号fail closed；非法速度拒绝。独立验收可在小例逐条带穷举全部相关异速对，和树最小值比较。真实数据需绑定完整目录并验证δ_new相对旧半径的准确关系；未有运行结果前不宣称半径实际扩大。

## 6. 研究范围

本轮优化的是完整有限矩形表示的稳定性证书，不是构造一般C₂上界。即使δ_new大于旧半径，它仍只是充分半径，限制pair可能是外y区间造成的保守边或真实相交但被其他盒遮住的事件；不能据此自动声称最大步长、最近有贡献事件或精确饱和墙。真实正/负斜率及独立括区证书可以另行定位局部极大区间，量词仍只在指定单轴路径。

# R53：九格全部质量单纯形的有限覆盖证书

本轮严格结论：对每个九格质量向量 w_i≥0、Σ_i w_i=1，存在九格顺序 π，使累计质量膨胀容器 V_π 的面积满足

    |V_π(w)| ≤ B = 1055588376525711924597571 / 302231454903657293676544
                 ≈ 3.4926489595935775 < 7/2.

这里即使 w_i=0，仍可把该空格的闭矩形放入 V；本结论对这个更大的容器也成立。因此它包括闭单纯形的所有面，且不需要四个外围行/列质量 >1/4 的假设。B 是本有限证书的统一外界，不声称最优。

## 对象与编号

坐标带为 [0,1/4]、[1/4,3/4]、[3/4,1]。编号 j=3x+y，x,y∈{0,1,2}；第 j 格 C_j 是相应两个闭带的直积。源标签按 R49 的不交归属分配，闭格的重叠仅作容器，不重复记质量。对于一个九格排列 π，令 s_k=Σ_(t≤k)w_(π(t))，并定义

    V_π(w)=∪_(k=1)^9 (C_(π(k)) + [-sqrt(s_k)/2,sqrt(s_k)/2]^2).

即使有空格也保留全部九项。跳过空格只会删去容器，对实际有质量格的累计质量没有影响。

## 有理盒覆盖

从 [0,1]^9 与 Σw=1 的交开始。对任一有理盒 l≤w≤h，先同时计算

    l'_i=max(l_i, 1−Σ_(j≠i)h_j),
    h'_i=min(h_i, 1−Σ_(j≠i)l_j).

右端全部使用更新前的 l,h。任何盒内满足 Σw=1 的向量都仍在新盒内，故此收紧不漏掉可行点。内部节点在某个坐标 j 的有理 cut 处分成两个闭盒，分别以 cut 更新上端或下端；二者并集覆盖父盒。根节点、每个收紧盒、分割坐标、cut、左右孩子都在证书中保存。

完整树共177节点、89叶、最大深度31，无被省略节点。独立于选序启发式的标准库检查器从根递归重建每个孩子的输入盒和同时收紧后的盒，逐项核对证书；所有节点只访问一次。因而89个叶覆盖整个闭质量单纯形。

## 每个叶上的统一面积外界

叶盒固定选取一个排列 π。对每个前缀，准确有理上界为

    u_k=min(Σ_(t≤k)h_(π(t)), 1−Σ_(t>k)l_(π(t))).

任一该叶中的可行 w 都满足 s_k≤u_k；后一个上界使用总质量约束，不能以彼此独立的前缀近似替代。令 D=2^40，并用整数平方比较得到唯一整数 H_k=ceil(D sqrt(u_k)/2)。每个扩大闭格均包含在端点属于 D^(-1)Z 的外矩形中；全部九项保留，包括 u_k=0 的情况。检查器直接核验

    4 H_k^2 den(u_k) ≥ D^2 num(u_k),
    H_k>0 ⇒ 4(H_k−1)^2 den(u_k) < D^2 num(u_k).

各外矩形的并面积是整数 N_leaf / D²。生成器用横向扫线求面积；独立实现的作者检查器用全部横纵端点形成的矩形小格枚举求面积，二者逐叶相同。每个叶均有 2N_leaf<7D²。取89个叶的最大值，约去公因数即上述 B；严格余量为

    7/2−B = 2221715637088603270333 / 302231454903657293676544 >0.

由此得到所述全部质量向量结论。证书内的排列来自浮点启发式选择；启发式只提供候选，任何错误或次优选择均不会绕过有理覆盖、向外平方根和整数面积验收。重放检查器不依赖 C++、NumPy、SciPy 或启发式库。

## 到真实点顺序的接口与范围

对任意有限正原子源，总质量 M>0，若所有源包含于某个边长 sqrt(M) 的轴平行 ambient 方块，将各原子按不交九格归属分组，按该叶的排列连续插入各格，格内顺序任意。R49 的前缀支配给出：第 k 格中每个真实点 proxy 的有效质量不超过该格完成时的总前缀质量 M s_k，中心在该闭格中，故真实 proxy 并集包含于 sqrt(M) 缩放的 V_π(w)，面积 ≤B M。这一步不要求格本身是 eligible 组件。

这严格闭合 R49 的有限维残余命题 CB_3.5，并给出了更小的 bbox 条件类常数 B。任意一般输入的全部源未必可装入边长 sqrt(M) 的 ambient 方块；本证书本身没有闭合跨大 bbox、高 rank 相交组件预算，也没有得到一般 C₂≤B 或精确 C₂。

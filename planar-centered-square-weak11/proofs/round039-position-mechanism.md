# 第39轮：产品位置域顶点归约与真实单轴正斜率证书

日期：2026-11-15（Asia/Shanghai）。本轮得到一个固定质量有限模型的顶点归约，以及R29输入的一条真实单轴正斜率区间。它不新增一般C₂上界，不以本次局部斜率代替R35等轮的独立下界认证，也未定位一个精确饱和墙。

## 1. 有限产品位置域的归约

对固定正质量、固定阈值/周期、具有同一完整副本目录和统一尾界的紧产品位置域D_x×D_y，第31轮的完整有限表示给出彼此独立的横、纵超平面分层。每个闭产品单元P×Q上的完整比值为双仿射式。固定y先把x移到P的某顶点使值不降，再固定该x把y移到Q的某顶点使值不降，所以整个位置域的最大值可在有限顶点对中取得。

完整证明为 `proofs/fixed-mass-product-vertex-reduction.md`，SHA256 `f09ec086cb3b89a1bd873680c0c666daa9d9bae6113383dbf106774aa6317c4a`。该归约允许低维同轴约束和碰撞，必须保留产品条件；只有包括λ在内的全部数据均为有效实代数数时才声称有效代数算法。没有原子数一致的墙数或候选数界。

## 3. 正斜率的准确区间结论

对全部活盒的原始横端点和F边界，实际认证24656个真实端点类的全预序；持久相等类合并，原始未被clip选中的支仍参与稳定性。端点间隙给出

    δ = 561489540315834114922821552388999 /
        86469112845513523200000000000000000000000 > 0.

δ同时不超过H与δ_empty。于是全部源成员、空盒状态、原始横端点顺序、clip分支在闭区间[s₀−δ,s₀+δ]内固定。由第31轮定理，完整面积存在同一个常数β，使

    A(s)=A(s₀)+β(s−s₀),  |s−s₀|≤δ.

按完整x扫线，每个相邻横端点间的固定y并长记为Y_j，真实端点速度记为v_j，则

    β = Σ_j (v_{j+1}−v_j)Y_j.

生产结果及独立整数sort-merge重放逐分数一致给出

    82711662599225853187437 / 1208925819614629174706176
      ≤ β ≤
    82711662599225853188199 / 1208925819614629174706176.       (1)

分母是2^80，两界均严格正；β约0.0684174837341，是**面积对实际位移**的斜率。换算到J=λA/M及τ，

    dJ/dτ = (P/M)β > 0,
    |τ−17/5000000|≤δ/P.

δ/P约1.97530777831398×10^-9，dJ/dτ约0.01065867127585133。准确结论使用(1)及有理P/M，不以这些小数承担认证。它已经定位一个真实正斜率区间；仅由R35相邻样本正差商本来不足以推出该中心导数。

## 4. 最小安全半径并不是饱和墙

当前δ由两个raw横端点的保守顺序间隙限制。其唯一来源是box25244的左端点与box25243的右端点，bbox索引分别为[137,138,25,25]与[137,137,36,36]。前者y中心小于3/5，后者y中心大于24/5；两者半径平方均小于1/100，故前者y支持在7/10以下、后者在47/10以上，严格不交。

因此这个横端点交换发生在不相交水平带中，不能被称作已识别的面积饱和。两个局部进入/退出操作作用在互不相交的y集合上，交换顺序不改变各自对并长的增减；单独这个交换不产生总面积斜率转折。当前δ是充分的全端点稳定半径，不是最大上升距离，也不是下一个真实有影响墙的距离。

要定位单一饱和墙，仍需完整地跟踪有效事件，在同一已分离事件两侧认证相应斜率。若只得到一个正斜率中心和一个更大的负斜率中心，则可由连续性证明二者之间有内点最大值，但不能据此宣称中间只有一个墙。本轮不把多方向、一般质量或一般L¹局部最优从一条单轴路径推出。

## 5. 实际验证与证据边界

两份数学证明/合同均已通过两位Sol解析独审。产品域小例为两原子9/16模型，独立实际检验81闭产品单元的2025次双仿射/顶点支配及低维面45次检查；这些小例辅助解析证明。

完整枚举器另经逐行审读、实际重跑自检及复杂公分母有限/周期小例。真实slab独审重建3953目录、全部50850源事件和候选对覆盖，核对全部25466活盒的质量、半径与端点、拒绝类汇总及最小余量见证；未独立重放44045029次拒绝分类，其正确性同时依赖已审实现与精确判据。独审还逐分数验证上节两限制盒的y支持不交。

扫线独审没有调用生产段树求并，而在共同整数格上用sort-merge，对290个Δv≠0的gap重放完整y并长（最多4461活盒），复核全部端点排序、clip与δ最小合并，得到与(1)逐分数相同的界。实际CPython3.15.0，最终主进程CPU约1.202秒（不含另行重放的3个tiny CLI子进程CPU）；未重枚举44045029盒。所有过程无浮点容差；带随机小例的脚本另固定其种子。详见相应实现独审与运行manifest。

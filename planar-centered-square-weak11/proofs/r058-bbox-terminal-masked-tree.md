# R58：bbox 叶子、删除覆盖与全局接收交叠证书

2026-11-15。新 R58 稿；R49/R53 的冻结文件不改。本文给任意有限正原子输入的显式充分证书，没有证明每份输入均存在通过预算的树，也没有新一般 C₂ 上界。真实 halo 为 H，严格门槛 1；本文混合使用插入方形作覆盖和真实 halo 的局部叶子定理，所得覆盖不是原插入 proxy U。

## 1. 局部终端规则及真实组件

假设已经严格证明局部常数 B：支撑可装入边 √M 方块的任意质量 M>0 正有限测度满足 |H(μ)|≤BM。本轮 R53 提供

B=1994727599733432151936139/604462909807314587353088<33/10。

**引理 1（bbox 放大终端）。** 任意有限 bbox 最大边长为 d 的正有限测度 μ，质量 M，均有

|H(μ)|≤B max(M,d²)。                                                   (1)

证明：令 α=max(1,d²/M)。支撑装入边 √(αM) 方块，H(μ)⊂H(αμ)，后者面积≤BαM。α 只是辅助测度的放大；原树中源质量仍为 M。证毕。特别 d²≤35M/33 时，由 B<33/10 得 |H(μ)|<7M/2。此规则允许任意源数、任意 rank，不要求整个源组 eligible。

有限源标签组 A 的 eligible 超图按 d(S)²<m(S) 定义，C 是其通常连通组件，不把连通组件误认作 eligible 集合。每个真实见证的捕获标签集必 eligible，所以 H(A)=∪_C H(C)。组件源质量不交，且其真实 halo 两两不交。证明：若同一中心 x 同时有两个组件的严格见证，取较大半径 r 的方形；它同时捕获两个非空源组 S、T，且 d(S∪T)²≤4r²<m(较大半径见证组)≤m(S∪T)，得到跨组件 eligible 边，矛盾。闭方形边界不影响该严格不等号。对本树的任意两个叶子，在其最近共同祖先的删点后分属不同组件，同一论证证明叶子真实 halo 两两不交。插入 proxy U 不享有这个自动不交结论。

## 2. 有限删除树与接收覆盖

树节点携带源标签子问题 A_v；同一父节点的孩子标签不交。可停止作为叶子；否则选择一个源 p_v，删除它，孩子取 A_v\{p_v} 的 eligible 组件。每个内部节点必须提供有限矩形并 E_v，满足

R_p(A_v)⊂E_v，

R_p(A)=∪_{S⊂A\{p}} ∩_{i∈S∪{p}} [p_i+(-√m(S∪{p})/2,√m(S∪{p})/2)²]。 (2)

空接收矩形丢弃。可取精确 R_p，也可取 R49 的新点方形 Q_p，其面积 T_p=max{m(S):p∈S⊂A,d(S)²<m(S)}；还可取经有理外舍入的 Q_p 矩形。真实包含 R_p⊂Q_p 已有严格证明。有限算法只需源 bbox 端点：任意候选子集补入 bbox 内全部源后，几何端点不变且质量增加，接收矩形只扩大。因此 (2) 可由全部含 p 的完整源盒构造，不是在原问题的接收点或半径上重述 sup。

单节点有 H(A_v)=R_p(A_v)∪∪_child H(A_child)，故

H(A_v)⊂E_v∪∪_child H(A_child)。                                       (3)

记内部节点集合 I，叶子集合 L，P=∪_{v∈I}E_v。有限递归得到

H(A_root)⊂P∪∪_{l∈L}H(A_l)。                                          (4)

所有被删源以及所有叶子源标签组成根输入的严格不交分割：

M=M_del+Σ_l M_l，M_del=Σ_{v∈I}m(p_v)。                               (5)

叶子中内部 source rank 和源数都不限。单源也可直接用面积 M_l 的精确终端替代 (1)。

### 删除集合的保守版本：无需先选择点顺序

也可预先选择任意删除标签集 D，取剩余 A\D 的实际 eligible 组件作为叶子，给每个 p∈D 取在完整原输入 A 上计算的 T_p(A) 和 Q_p(A)，并令 P=∪_{p∈D}Q_p(A)。任何真实见证若捕获某个 p∈D，其中心就在 Q_p(A)；否则它的捕获标签组属于单一剩余组件。因此 (4)—(7) 原样成立。无需假设删除顺序，完整原输入 cap 只是比逐节点重新计算更保守。可有限枚举 |D|≤k 的删除集、以 (7) 作评分，D=∅ 对应组件终端。它是明确有限算法，不保证固定小 k 足以覆盖一般输入。

## 3. 全局遮罩与显式核心：一次扫线付清交叠

对每个叶子选择有限矩形并 G_l⊂H(A_l)，并提供其包含证明。可直接用以下任意组合：各单源面积 m_i 的中心方形；某个指定 eligible 源组的真实接收矩形；特别完整叶子 eligible 时，使用其完整 bbox 的接收矩形。选择 G_l=∅ 也合法。

令 G=∪_lG_l，定义完全可计算的核心交叠信用

Ω=|P|+Σ_l|G_l|−|P∪G|=|P∩G|≥0。                                             (6)

**定理 2（全输入有限充分证书）。** 任何上述有限删除树及覆盖、核心数据，都严格给

|H(A_root)| ≤ |P∪G|+BΣ_l max(M_l,d_l²)−Σ_l|G_l|
             = |P|+BΣ_l max(M_l,d_l²)−Ω。                            (7)

证明：由 (4)，H(root) 被 P∪G 和各 H(A_l)\G_l 覆盖。因此其面积≤|P∪G|+Σ_l(|H(A_l)|−|G_l|)。对每个叶子应用 (1)。各 G_l⊂H(A_l) 确保扣减合法。证毕。

这比逐分支只用祖先遮罩更强：|P| 对所有内部覆盖取一次真实并，内部/内部交叠不会重复付款；Ω 保留全部内部覆盖与叶子核心的交叠，包括不在同一祖先分支的覆盖。这里各 G_l 本身两两不交，由上面的组件几何结论自动成立；不能声称还需支付叶子/叶子真实 halo 的交叠。没有把同一源质量重复分配给不同叶子。所有量都是有限源盒质量、平方比较、矩形并面积和已认证常数 B；不需要待估计的 H 的准确面积。

由 G_l 两两不交，(7) 也可写成 |P|+Σ_l[Bmax(M_l,d_l²)−|P∩G_l|]。若实现已经扫线计算 P∪G，原公式完全相同。

给定任意叶子顺序也能恢复 R49 遮罩观点：先付 P，然后第 l 叶子只须扣除 |P∩G_l|；各叶子的核心信用相加恰为 Ω，总信用与顺序无关。

**其他已证叶子上界可以直接合并。** (7) 中每个 Bmax(M_l,d_l²) 可替换为任意独立认证的标量上界 U_l≥|H(A_l)|，并取多个上界的最小值；扣除 G_l 的合法性不依赖上界来自何种构造。R49 给 eligible rank r_l 的质量排序界 r_l M_l；也可对任意一个固定插入顺序，用每步前缀中含新点的最大严格 eligible 质量 T_j 生成 Q_j，得到 U_l=|∪_jQ_j|。前者的证明是质量非递减插入时 T_j≤r_l m_j，后者由每个新增严格见证必须捕获新点的有限归纳得到。反序、坐标序和质量序都能提供候选上界，不能因某固定顺序在其他输入很差而否定其在指定叶子上的认证用途。以浮点计算这些并面积得到的搜索分数仍需区间或精确算术认证。

若只求真实 halo 上界，可把 E_v 从 Q_p 换成更小的 R_p 或其严格外包，(7) 只会改善；不能因此声称覆盖原 proxy U 的全部面积。

## 4. K 预算：真正缺少的几何条件

由 (5) 和 max(M_l,d_l²)=M_l+(d_l²−M_l)_+，(7) 的右侧≤KM 等价于显式不等式

|P|−K M_del +BΣ_l(d_l²−M_l)_+
       ≤ (K−B)Σ_l M_l +Ω。                                            (8)

这是一个可独立审查的成功证书：左侧是合并全部删除覆盖后、扣除删除源预算的几何超支，以及叶子过宽的额外成本；右侧是局部常数相对目标 K 的真实余量和实际接收交叠。没有未定义系数、无限尺度 sup 或待计算 halo 面积。

K=7/2 时，K−B>1/5。若各叶子 d_l²≤M_l，则叶子过宽项为零，只要

|P|−(7/2)M_del ≤ (7/2−B)Σ_lM_l+Ω，                                  (9)

就得到合法一般输入的 3.5 证书。即使某叶子稍微不 eligible，也可由 (8) 支付它的过宽项；(1) 的 35/33 条件是只有一个叶子、P=∅ 的特例。

任意有限输入都存在形式上的树（例如删到单源），但目前没有证明它必满足 (8)。新的研究义务是证明：对任意高秩、整体 bbox 过宽的连通分量，能选删除树使全部删除覆盖并的超支被终端余量和真实接收交叠支付。密集簇内部每个原子质量很小，而含它的组合接收可能用到很多旧质量，不能逐点预先断言 |E_v|≤Km(p_v)。另一方面密集簇可以作为任意大叶子停止，或由多个相近删除覆盖的全局交叠 Ω/P 并面积结算；不能从逐点付款失败推出树证书失败。

(8) 不自动给该选择定理，也不是把目标原样作为叶子成本：叶子成本由已证 B 和有限 bbox 决定，内部成本由有限源 incidence/矩形覆盖决定。若要得到统一一般常数，仍须建立覆盖并 P 与源质量的上述几何预算。现有九格质量单纯形定理单独不承担这一跨 bbox 条件。

## 5. 实际精确例证：任意大 rank 的宽连通组件

质量 1 的中心源 p=(0,0)，两侧各质量 1 的 q×q 等质量网格（q≥2），其 bbox 为中心 (±11/10,0)、边长 η=1/100 的方块。总质量 3。每个侧簇完整 eligible；p 加任一完整侧簇也 eligible，故总 eligible 超图连通，rank 至少 q²+1。任意跨两侧的源组 bbox 宽至少 219/100，其平方>3，所以不存在同时遇到两侧的 eligible 组。删除 p 后恰有两个侧簇组件，任意 q 均可作为叶子。

根最大 cap T_p=2，取有理覆盖 E_p=(-3/4,3/4)²，因为 (3/2)²>2。每个叶子的完整捕获核心 G_l 是中心 (±11/10,0)、边 99/100 的方形，面积 9801/10000；两个核心互不交，每个与 E_p 交面积 2871/20000。因此 |P|=9/4，Ω=2871/10000，(7) 给

|H|≤9/4+2B−2871/10000 <85629/10000 <(7/2)·3。

而根 bbox 最大边长为 221/100，平方为 48841/10000>3；仅把整个根作为局部终端给 B·48841/10000，超过目标 21/2。本例验证树接口确实能处理整体过宽且 rank 任意大的连通分量；它不是关于所有输入都能选择这种简单树的断言。

附带 Fraction 脚本实际使用 q=3（19 原子），枚举全部源坐标完整 bbox 并核对根 cap、删除后组件分类、核心并面积、Ω、预算恒等式及严格有理比较。完整 q 参数结论由上面解析式承担。没有随机数、容差或 MATLAB。复现命令为 python3 planar-centered-square-weak11/computation/r058_bbox_terminal_tree_check.py。

# R55 共同 Cauchy 平滑势：解析公式、完整合法性与边界缩减

2026-11-15。独立复核附件，不修改 R51 或已有零质量障碍附件。固定

    ρ(x)=|x₁|+|x₂|，D={ρ≤1}，U=1/ρ，A=−|D₁|−|D₂|，
    p_t(x)=t²/[π²(t²+x₁²)(t²+x₂²)]，t>0.

设 σ 为紧支撑中心对称概率测度（有限非负对称原子是特例），ν_t=σ*p_t。本文结论不要求 σ 与 D 分离；但正的 D 支配常数必须另外验证。定义

    V_t=U*p_t，Q_t=U−V_t，W_t=U−V_t*σ，K_t=(W_t)_+，
    m_t=essinf_D W_t，J_t=(∫K_t)/(2m_t)（只在 m_t>0 时）.

## 1. 无须数值积分的 V_t 完整分支

令 a=|x₁|、b=|x₂|。由 V_t=2π∫_t^∞p_s ds，初等部分分式给

    V_t(a,b)=(2/π)[b arctan(b/t)−a arctan(a/t)]/(b²−a²)，a≠b；
    V_t(c,c)=[arctan(c/t)+ct/(t²+c²)]/(πc)，c>0；
    V_t(0,b)=2 arctan(b/t)/(πb)，b>0；
    V_t(0,0)=2/(πt).

第三行也由第一行直接得到，单列便于处理轴线。第二行是对 f(c)=c arctan(c/t) 的差商取极限，而非代入 0/0。t>0 时 V_t 是光滑偶函数，轴上坐标偏导数为 0。直接使用第一行会在 a≈b 或 t 很大时出现浮点抵消；这些闭式给的是精确解析身份，不保证任意直接浮点评估稳定。

对固定非零 x，t↓0 时 V_t→U。a,b>0 时

    Q_t(a,b)=2t³/(3πa²b²)+O(t⁵)；

a=0、b>0 时 Q_t(0,b)=2t/(πb²)+O(t³)。不能把非轴上的 t³ 估计统一延拓到轴。对有界的 (a,b) 集合，t→∞ 时一致有

    V_t(a,b)=2/(πt)−2(a²+b²)/(3πt³)+O(t⁻⁵).            (1)

还总有 0≤V_t≤U（原点按奇值处理）及 V_t≤2/(πt)。

## 2. 全 L¹、准确签名质量与 Kato

R51 已严格证明 W_σ=U−U*σ∈L¹，AW_σ=2π(σ−δ₀)。已有零质量附件证明 ∫W_σ=0。半群势分解给

    Q_t=2π∫₀^t p_s ds≥0，∫Q_t=2πt，AQ_t=2π(p_t−δ₀).

因而合法分解为

    W_t=W_σ+Q_t*σ∈L¹，
    AW_t=2π(σ*p_t−δ₀)，∫W_t=2πt.                     (2)

这里的非零积分不是对两个发散势的形式抵消；(2) 使用两个真实 L¹ 函数。W_t 偶，K_t 非负、偶且 L¹，准确恒等式是

    ∫K_t=2πt+∫(W_t)_−=[∥W_t∥₁+2πt]/2.               (3)

R51 的平滑—光滑凸近似—两次 L¹ 极限证明只用 W∈L¹ 及 AW=2π(ν−δ₀)、ν≥0，并不需要 ν 紧支撑。因此逐字适用于 ν_t：

    AK_t≥0 于 R²\{0} 的分布意义.                    (4)

它包括轴线和正部接缝；不需逐点检查生成元或删去这些集合。只要另有认证 m₀≤m_t、m₀>0，即有一般输入比较界 C₂≤∫K_t/(2m₀)。式 (4) 本身没有认证任何候选的正 m_t 或积分成本。

同样，有限混合 Σw_jp_{t_j}(·−z_j) 在位置均值 Σw_jz_j=0 时 L¹，签名质量 2πΣw_jt_j；若 (z,t,w) 与 (−z,t,w) 配对，则偶性及 (4) 成立。时间不能在一对 ±z 上任意破坏偶性。

## 3. 全菱形最小值：两个严格的边界缩减条件

### 3.1 位置源距离至少 2

对 a,b≥0、a+b>0，V_t=2π∫_t^∞p_s ds 在每个坐标上递减；Q_t=2π∫₀^tp_s ds 同样递减。故由 V_t=U−Q_t，

    0≤−∂_a V_t(a,b)≤1/(a+b)²，
    0≤−∂_b V_t(a,b)≤1/(a+b)².                       (5)

正坐标直接微分；轴由 V_t 光滑及单侧极限得到。给定 ρ(v)=1、0<r≤1，若 supp σ⊂{ρ≥R}、R≥2，则

    dW_t(rv)/dr
      ≤−1/r²+∫[ρ(z)−r]⁻²dσ(z)
      ≤−1/r²+1/(R−r)²≤0.                           (6)

因此每条从原点出发的射线单调不增，m_t=min_{ρ=1}W_t；R>2 时 (6) 严格。进一步 W_t≥W_σ，故 R>2 时还保有 m_t≥(R−2)/(R−1)>0。式 (6) 中的积分版本可能在 R<2 的某个具体 σ 上仍足够，但须认证整个 0<r≤1。

### 3.2 足够大的共同时间，不限制位置

直接最大化 p_s 的坐标导数：|∂₁p_s| 在 x₂=0、|x₁|=s/√3 取最大值

    sup_x|∂_jp_s(x)|=9/(8√3π²s³).

从而

    sup_x|∂_jV_t(x)|≤C/t²，C=3√3/(8π).              (7)

任意概率 σ 的卷积保持这个界。因此当 t≥√C≈0.4547 时，

    dW_t(rv)/dr≤−1/r²+C/t²≤0，0<r≤1.               (8)

在这一时间范围可合法只查边界。有限不同时间混合的充分条件为 CΣw_j/t_j²≤1。式 (8) 不保证 m_t>0。

### 3.3 一般对称性不足以推出边界缩减

取 σ=(δ_(1/2,0)+δ_(-1/2,0))/2、t=1/(10π)。在 x=(1/2,0)，由 V_t(0)=2/(πt)，

    W_t(x)=2−[V_t(0)+V_t(1,0)]/2<2−1/(πt)=−8.

而在 ρ(x)=1，ρ(x−z)≥1/2，故 V_t*σ≤U*σ≤2，W_t≥−1。于是内部值严格低于全部边界值。这是精确反例，否定无附加条件的一般边界缩减。它的源在 D 内，**不构成** 1<inf_suppσρ<2、源与 D 分离子类的反例；本附件未证明该子类无条件可缩减。若小时间候选不满足 (6)/(8) 等条件，仍需完整 D 认证。

### 3.4 当前 14 轨道固定 LP 的准确边界缩减证书

另考虑未概率归一化的实际固定组合

    F_t=A U−Σ_j c_j (V_t*σ_j)，A=Σ_jc_j，c_j≥0，

其中 σ_j 是位于 ρ=R_j>1 的轨道均匀概率测度。设 B=Σ_jc_j/(R_j−1)²。因为 r/(R_j−r) 在 0<r≤1 上递增，式 (5) 给

    dF_t(rv)/dr≤[−A+Σ_jc_j r²/(R_j−r)²]/r²
                 ≤−(A−B)/r².

于是 B<A 就是全部 t≥0 的严格射线递减证书；t=0 在 D 内没有源奇性，U 的坐标折线用单侧导数/绝对连续性即可。有限分布保证对折点取分段导数后合法积分。

实际读取核心任务固定输入并复制为 `computation/inputs/cauchy-smoothed-interface/fixed-lp-input.json`；按其声明把 JSON 数字先解析成 binary64，再转成准确有理数。逐点检查所有 R_j、中心对称和非负系数，得到

    A=1077997594621154451/576460752303423488，
    B=590282611469651589893609/384506527545787259289600，
    A−B≈0.3348584481371618>0，B/A≈0.8209339669295426.

正性由脚本 Fraction 的整数比较准确承担，小数仅供阅读。因此这个保留的固定输入在任何共同平滑时间 t≥0 上，完整 D 最小值确实等于边界最小值。仍未认证边界最小值为正或其数值，也未认证积分。特别注意，输入元数据 `total_mass=1.8700277344358458` 与准确 binary64 系数和 A 相差 `147/576460752303423488`；零质量及 L¹ 抵消应使用准确 A 或明确统一归一化，不能混用元数据舍入值。轨道字段名 t 是位置形状参数，不是本附件的共同平滑时间。

## 4. 时间带来的准确渐近权衡

Q_t 随 t 增加，所以 W_t、K_t、m_t 及 ∫K_t 都单调不减；分子分母同时增加，不能由此判定 J_t 单调。

当 t↓0，

    0≤W_t−W_σ=Q_t*σ，∥W_t−W_σ∥₁=2πt，
    0≤∫K_t−∫(W_σ)_+≤2πt.                          (9)

若 σ 与 D 有正的 ρ 距离 δ，则 Q_t(x−z)≤8t/(πδ²)，因为某个坐标差至少 δ/2，给 p_s≤1/[π²(s²+(δ/2)²)]。所以 (9) 的 D 上差还一致趋 0，m_t→m_0；若 m_0>0，J_t→J_0。轴上的 O(t) 行为说明不能普遍改成 O(t³)。

当 t→∞，(1) 在 x∈D 及 z∈suppσ 上一致，故

    m_t=1−2/(πt)+O(t⁻³).                            (10)

该结论不依赖提前假定边界缩减：U≥1，且边界 U=1，一致余项同时给上下界。

又 W_t≥W_σ，故 (W_t)_−≤(W_σ)_−∈L¹；对每个非零固定 x，V_t*σ≤2/(πt)→0，于是 (W_t)_−→0。支配收敛和 (3) 给

    ∫K_t=2πt+o(1)，
    J_t=πt+2+o(1).                                 (11)

因此固定位置源的过度共同平滑使成本线性发散；重尾去除零签名质量障碍的代价不能忽略。这里 +2 是解析常数，来自 D 归一化，不是数值拟合。未声称任何 t 的最优性，也未由 (11) 推出全族成本地板。

# 第22轮补充：单尺度临界平台已否定不受限 L¹ 新增质量预算

固定二维 Lebesgue 面积、中心轴平行共同半径方形及严格阈值1，记 H(h)={x:存在r>0，使∫_{x+[-r,r]²}h>4r²}。对任意0<ε≤1/4，令 f=1_{[-1,1]²}，g_ε=4ε·1_{[-1/4,1/4]²}。二者非负、有界、紧支撑且可积，||f||₁=4、||g_ε||₁=ε。由于0≤f≤1且0≤g_ε≤1，每个方形的各自平均均不超过1，故严格 H(f)=H(g_ε)=∅；即使局部平均等于1也不进入halo。

对任意接收点x∈[-1/4,1/4]²，取同一个半径r=1/2。方形x+[-1/2,1/2]²包含整个g_ε支撑，且包含于[-1,1]²，面积为1。因此其中f的积分恰为1，g_ε的积分恰为ε，混合平均为1+ε>1。整个接收方块都属于H(f+g_ε)，所以纯混合新增面积 |H(f+g_ε)\(H(f)∪H(g_ε))|≥1/4，其与新增质量之比至少1/(4ε)，在ε↓0时无界。由此单尺度、固定旧输入已经否定不受限L¹上的任何统一新增质量预算；这里没有用多尺度叠加。

本附件由主Agent提出简例，用于精确说明原R22结论的适用边界：跨尺度机制不是所有L¹反例的必要机制。不受限L¹结论本身由上述更简临界平台即可得到；[原跨尺度构造](cross-scale-insertion-obstruction.md)的独立内容在于有限原子输入加入单个原子时，N个分离尺度各有明确的严格混合激活区域，以及其可定量控制的有限L¹平滑传递。两例都只排除指定预算，不给出新一般弱(1,1)上界，不否定动用旧质量余额的预算。附带[Fraction脚本](../computation/threshold_plateau_insertion_check.py)仅对ε=1/1024作一次确定性精确核验，核对接收方块四角的包含关系、面积、质量及严格平均；全ε、全接收点的结论由前两段解析证明承担。实际运行记录见[准确输出](../computation/results/cross-scale-budget/threshold-plateau-exact.json)。复现命令：`python3 -B computation/threshold_plateau_insertion_check.py --out computation/results/cross-scale-budget/threshold-plateau-exact.json`。

# 第46轮补充：接缝源窗口的准确切相位条件

本补充绑定主证明 `high-ratio-reflection-edge-obstruction.md`，其冻结 SHA256 为
`9bf263dc2914990cd2643dd35f043aa29c5ac83f5ee817257f3b267c7ed9f8c8`。
主稿保持原字节。本补充精确化其 §5 中“深度小于 30、最后五列”的相位条件，
不改变任何面积状态、系数或结论。

两冻结模板的横周期与最右源坐标均为

\[
P_x=\frac{328734960629}{50000000000},\qquad
x_{\max}=\frac{979821360288625294630001}{150000000000000000000000}.
\]

直接有理运算给出

\[
\boxed{x_{\max}+4P_x-30
=\frac{424640887836625294630001}{150000000000000000000000}>0.}
\tag{S1}
\]

真正相对反射轴满足 \(C>x_{\max}\)，因此所需充分条件是
\(C+4P_x>30\)。仅凭 \(5P_x>30\) 对一般切相位不足；本输入使用 (S1)。
同一结论适用于核计算采用的有理外移轴 \(\bar C\ge C\)。

设有限输入源胞元编号为 \(0,\ldots,N-1\)，真实轴
\(c_N=(N-1)P_x+C\)。新接缝的左半接收窗口为
\([c_N-15,c_N]\)，所有非空混合接收矩形由半径 \(r<15\) 见证。
因此在该窗口中可能捕获的原侧源，其横坐标严格满足

\[
x>c_N-30=(N-5)P_x+(C+4P_x-30)>(N-5)P_x.
\tag{S2}
\]

原胞元中的横相位均在 \([0,P_x)\)。编号不大于 \(N-6\) 的源横坐标
严格小于 \((N-5)P_x\)，所以 (S2) 排除它们：只有最后五列可能影响接缝。
特别地，当 \(N\ge5\) 时 \(c_N-30>0\)，接缝窗口看不到左截断。
镜像侧由反射得到完全相同的结论；旧接缝状态的半径上界为 10，亦已被同一
较宽目录涵盖。与主稿的纵向三行边带和 \(N\ge6\) 端角分解合并，原面积多项式及
\(D_N=2(N-6)\gamma+2\Gamma\) 的稳定范围保持不变。

[准确检查程序](../computation/reflection_cut_phase_check.py)逐一核验两冻结输入的
SHA256、半开横相位、\(P_x\)、\(x_{\max}\) 及 (S1)，实际 Python Fraction 输出见
[切相位证书](../computation/results/reflection-edge/cut-phase.json)。此补充只核查缺失的
充分条件，没有重跑或冒称重跑任何大面积状态。

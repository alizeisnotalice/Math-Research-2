# 接缝带反射与显式有限原子复杂度差距

状态：作者证明，2026-11-15；独立审查由 `sol_reflection_geometry` 提供；`sol_reflection_limits` 提出同时使用底带的系数二强化。第30轮材料；正式归档由主 Agent 统一执行。本文的全部对象为二维 Lebesgue 接收测度、轴平行中心正方形、两轴共同半径、全尺度以及严格水平集。

## 1. 对象、结论和证据范围

令
\[
H_\lambda(\mu)=\left\{x:\sup_{r>0}\frac{\mu(x+[-r,r]^2)}{4r^2}>\lambda\right\},
\qquad J(\mu,\lambda)=\frac{\lambda|H_\lambda(\mu)|}{M},\quad M=\mu(\mathbb R^2)>0.
\]
`C2` 始终指一般非负有限 L1 输入的最优弱常数。`C2,N` 指至多 N 个正原子输入的比值上确界；重复位置先合并。

本文证明两项新的定量结论：

1. 任意有限正原子输入，在最右 halo 接缝反射后，有
\[
J(\mu+T_\#\mu,\lambda)-J(\mu,\lambda)
\ge \frac{3-2\sqrt2}{4}\frac{m_{\min}}M.\tag{1}
\]
此式不依赖旧接收矩形右端的最小正间隙，也不依赖支撑直径。

2. 对所有整数 N≥1，
\[
\boxed{C_2-C_{2,N}\ge d_N,
\qquad d_N=2160\,25920^{-2^{N-1}}.}\tag{2}
\]
这是极弱但完全显式的有限原子复杂度障碍。它不证明反射迭代趋于 C2，不是趋近 C2 的构造性上误差界，也不计算 C2 的精确值。

证明采用有限集合几何、阈值分割和有理不等式。实际 Python 3.15.0 `Fraction` 计算只辅助核对常数和前八项递推，不替代任意 N 的解析归纳；详见配套脚本与输出。无随机种子、无浮点容差。

## 2. 精确有限 halo 与边界接缝

对每个非空原子子集 I，记质量 M_I 和源盒 [a_I,b_I]×[d_I,e_I]，令
\[
r_I=\sqrt{M_I/(4\lambda)},\quad
R_I=(b_I-r_I,a_I+r_I)\times(e_I-r_I,d_I+r_I).
\]
只保留两边均为正的矩形，记所得有限族为 F。严格水平集准确等于这些开矩形的并。原因是严格见证捕获的原子集合满足其最大捕获距离小于 r_I；反过来矩形内的中心可取严格小于 r_I 的捕获半径。允许额外原子被捕获，允许源盒退化。

写 u_I=a_I+r_I、v_I=d_I+r_I，令
\[
c=\max_{I\in F}u_I,\quad k=\sqrt2-1,
\quad r_0=\sqrt{m_{\min}/(4\lambda)},\quad w=kr_0/2.
\]
每个源点都严格位于 x<c，因为其 singleton 矩形的右端也不超过 c。关于 x=c 的反射 T 把全部源移到 x>c，原 halo 与反射 halo 分别在 x<c 和 x>c；两份源以及两份旧 halo 均不相交。

在边界带内的全部矩形
\[
F_w=\{I\in F:u_I\ge c-w\}
\]
中选 v_I 最大的一个，记为 S_+，r_+=r_(S_+)、Y=v_(S_+)；再选下端 e_I−r_I 最小的一个，记为 S_-，r_-=r_(S_-)、Z=e_(S_-)−r_-。两者可以是同一子集。该族非空，每个所选子集的 g_±=c−u_(S_±) 都满足 0≤g_±≤w，且 r_±≥r0。任何族内非空矩形的下端严格低于上端，因此 Z<Y。必须将 `u_I=c-w` 的矩形也纳入选择，持久相等的右端全部保留。

## 3. 上、下新混合见证和完整排除

先看上方所选子集，临时简写 S=S_+、r=r_+、g=g_+。S 的最小源横坐标 a_S=c−g−r。由于全部原源位于 c 左侧，S 与 TS 的并的源盒准确为
\[
[c-g-r,c+g+r]\times[d_S,e_S],
\]
质量为 2M_S，临界半径为 √2r。其接收矩形的横向为
\[
(c-(kr-g),c+(kr-g)),
\]
纵向为 (e_S−√2r,Y+kr)。由 r≥r0、g≤w 得 kr−g≥kr0−w=w。原 R_S 非空还给 e_S−r<Y，因此
\[
B_+=(c-w,c+w)\times(Y,Y+kr_+)
\subset H_\lambda(\mu+T_\#\mu).\tag{3}
\]
完全相同地，用 S_- 与 TS_- 的混合源盒得到
\[
B_-=(c-w,c+w)\times(Z-kr_-,Z)
\subset H_\lambda(\mu+T_\#\mu).
\]
这两个合法混合见证可以不同；并未假定反射后只有这两种混合见证。Z<Y 保证两条新增带不交。

对任意旧矩形：若 u_I<c−w，则它与两带均横向分离；若 u_I≥c−w，则其上端≤Y、下端≥Z，与两带均纵向分离。此二分覆盖全部旧矩形，包含接缝等号和各类重合端点。两带在 T 下均不变，因此也与反射旧 halo 分离。故
\[
|H_\lambda(\mu+T_\#\mu)|
\ge2|H_\lambda(\mu)|+2wk(r_++r_-).
\]
除以 2M/λ 得
\[
J(\mu+T_\#\mu,\lambda)-J(\mu,\lambda)
\ge G:=\frac{\lambda wk(r_++r_-)}M
\ge\frac{k^2m_{\min}}{4M},
\]
即 (1)。闭方形定义不造成阈值等号问题：每个带内中心的最大捕获距离严格小于对应混合临界半径，可取中间半径作严格见证。

若只取上方一条带，所得正确但弱一倍的保证为 k²m_min/(8M)。这是原始接缝带提案；最后定理同时使用上、下两带。

## 4. 有限 L1 转移与显式损失

有限原子比值必须合法传递到一般 L1，不能直接把原子测度称为 L1 输入。

令 S_r=Σ_(I∈F)r_I、R=r_++r_-。在每个原子 p_i 周围，用均匀方块密度
\[
m_i(4\eta^2)^{-1}\mathbf1_{p_i+[-\eta,\eta]^2}
\]
替代该原子；反射副本同样处理，所得 f_η 的总质量准确为 2M。把各旧 R_I 的四边向内移 η 后，任一保留中心到相应原子团全部支持的最大距离仍严格小于 r_I，所以仍有严格阈值 λ 的正方形见证。新混合 B_± 的四边也内移 η，同理可用各自混合源盒的临界半径 √2r_±。旧内缩区域、其反射以及两条新内缩带仍两两分离。

宽 h、高 ℓ 的矩形四边内移 η 的面积损失至多 2η(h+ℓ)，即使它内缩后为空也成立。旧 R_I 的周长半数至多 4r_I，因此一份旧 halo 的面积损失至多 8ηS_r。两条新带的总损失至多 2η(4w+kR)。于是
\[
J(f_\eta,\lambda)\ge J(\mu,\lambda)+\frac{\lambda wkR}{M}
-\frac{\lambda\eta}{M}(8S_r+4w+kR).\tag{4}
\]
特别取任意
\[
0<\eta\le\frac{wkR}{2(8S_r+4w+kR)}
\]
即保留至少半个几何增益。此界保证 η<w/2=kr0/4，故两条新带内缩后均非空。令 η↓0，则不损失 (1) 中的常数地得到
\[
C_2-J(\mu,\lambda)\ge\frac{k^2}{4}\frac{m_{\min}}M.\tag{5}
\]
这里“无损”是对一列有限 L1 输入取上确界的极限论证，不声称单个光滑输入取得原子反射面积。

任意有限原子 σ 亦由全部接收矩形的同一内缩估计得到 J(σ,λ)≤C2。这包括下一节使用的二原子下界。

### 4.1 自然反射迭代与总增长下限

保持同一个正阈值 λ，令 μ0=μ。对每个 j≥0，按 §§2–3 对当前有限原子 μj 重新选择最右接缝 c_j，令
\[
\mu_{j+1}=\mu_j+(T_j)_\#\mu_j.
\]
每一步当前源均严格位于 c_j 左侧、镜像源均严格位于其右侧，故没有跨副本碰撞；每份副本内部也保持不同位置。因此 μj 仍为有限正原子测度，原子数准确为 2^jN，总质量为 2^jM，最小绝对原子质量始终为 m_min。阈值没有改变，适用的全尺度中心正方形几何也没有改变。每一步内部的上下两带由当步 Z_j<Y_j 保证不交；不同步的新增带不需要在同一个空间并集中互不相交，因为以下只对相邻比值的差求和。

写 J_j=J(μj,λ)。由 (1)，
\[
J_{j+1}-J_j\ge\frac{k^2}{4}\frac{m_{\min}}M\,2^{-j}.
\]
故对每个整数 l≥1，
\[
J_l-J_0\ge\frac{k^2}{2}\frac{m_{\min}}M(1-2^{-l}).
\]
每个 μl 都是有限输入，分别用 §4 的任意精度 L1 转移得 J_l≤C2。于是令 l→∞得到更强的全局差距
\[
\boxed{C_2-J(\mu,\lambda)\ge\frac{k^2}{2}\frac{m_{\min}}M.}\tag{5a}
\]
无需构造无限质量的极限输入。序列 J_j 严格递增且有上界 C2，因而比值极限存在；上述论证只给总增长的下限，**没有证明这个极限等于 C2**，也没有给趋向 C2 的误差上界。

## 5. 两个完全自足的常数

### 5.1 一般上界 C2≤9

对严格水平集的任意紧子集 K，为每个中心选一个严格见证闭方形。它们的内部覆盖 K，可取有限子覆盖。按半径非增次序贪心选取彼此作为闭集不相交的方形；每个落选方形与一个半径至少同大的入选方形相交，因而包含在后者的三倍同心方形内。入选闭方形不相交，故
\[
|K|\le9\sum_j|Q_j|<9\lambda^{-1}\sum_j\int_{Q_j}f
\le9\|f\|_1/\lambda.
\]
内正则性给一般 L1 上界 C2≤9。此处不复用旧项目的更精细数值上界。

### 5.2 二原子下界 C2≥1+k²/2>1+1/12

取质量 m 的一个原子、r=√(m/(4λ))，以及它关于 x=r 的反射。两份 singleton 接收方形互不相交，面积总和 8r²。唯一二点混合接收矩形在 x 方向的宽为 2kr，纵向为 (−√2r,√2r)。除去 singleton 并集，其上、下各有一个面积 2k²r² 的矩形，因此
\[
J_{\mathrm{pair}}=1+k^2/2=5/2-\sqrt2.
\]
有限 L1 内缩传递给 C2≥此比值。正数平方比较
\[
(17/6)^2>8,\quad(71/25)^2>8
\]
分别证明
\[
k^2/2>1/12,\qquad k^2/4>1/25.\tag{6}
\]

## 6. 删除小质量与显式归纳

由质量缩放和共同空间伸缩，可将任意输入化为总质量 M=1、阈值 λ=1，而不改变 J。归纳命题是：对每个正阈值以及至多 N 个正原子，J≤C2−d_N。

N=1 时 J=1，由 (6) 可取 d1=1/12。

假设 N−1 的结论成立，写 d=d_(N−1)。如果原输入已有至多 N−1 个原子，直接使用归纳结论；否则其原子数 N≥2。取最小原子质量 ε，拆分 μ=ν+εδ_p，其中 ν 的总质量为 1−ε、至多 N−1 个原子。对任意 0<t<1，最大算子的次可加性给
\[
H_1(\mu)\subset H_{1-t}(\nu)\cup H_t(\varepsilon\delta_p).
\]
这只是上界用的全 halo 包含关系；没有要求旧、新、混合 halo 可拆成互不相交的区域。用归纳结论和 singleton 精确面积，
\[
J(\mu,1)\le\frac{(C_2-d)(1-\varepsilon)}{1-t}+\frac{\varepsilon}{t}
\le C_2-d+\frac{9t}{1-t}+\frac{\varepsilon}{t}.\tag{7}
\]
取
\[
t=d/45,\qquad \tau=d^2/180.
\]
递推一直保持 0<d≤d1<9，故 t≤1/5，且 9t/(1−t)≤d/4。

- 若 ε<τ，则 ε/t<d/4，(7) 给 C2−J>d/2。
- 若 ε≥τ，则 (5a)、(6) 给 C2−J≥(k²/2)ε>τ/12=d²/2160。

由于 d²/2160≤d/2，两分支共同给
\[
d_N=d_{N-1}^2/2160.
\]
直接归纳解此递推为 d_N=2160·25920^(−2^(N−1))，证明 (2)。过程不调用固定 N 达到性、紧性或任何与位置/直径有关的统一模连续性。

## 7. 近极值含义与限制

若某个至少二原子的输入满足 C2−J≤ε，则 (5a) 必须满足
\[
m_{\min}/M\le\frac2{3-2\sqrt2}\,\varepsilon.
\]
若原子质量还满足 m_min≥βM/N，则更直接有
\[
C_2-J\ge\frac{(3-2\sqrt2)\beta}{2N}.
\]
不加质量平衡假设时，(2) 至少给原子数的双对数必要增长：当 0<ε<1/12，J≥C2−ε 蕴含
\[
N\ge1+\log_2\!\left(\frac{\log(2160/\varepsilon)}{\log25920}\right),
\]
整数 N 按向上取整解释。

旧 δ 证书可以退化而真实增益不退化；另一方面，在高比值核心远右添加极小质量羽点，会使最右接缝反射的真实增益趋零。配套 `sol_reflection_limits` 文档分别提供这两类准确例子。本归纳通过删除小原子处理后一情形，因此不被单次反射增益的反例否定。

有限周期截断的 m_min/M 通常是截断尺度的平方倒数，而边界损失可能仅按尺度倒数下降。因此单独 (1) 不保证反射增益战胜周期有限化误差。一般 L1 达到性、一般最优上界及匹配近极值列仍开放。

# 固定紧支撑与单位质量下，网格质量聚合没有一致 halo 误差率

日期：2026-11-15（Asia/Shanghai）。本稿只否定一种特定的一致逼近主张：把每个 h 网格胞的全部质量集中到其左下格点，再进行本层质量量化，并不能在所有单位质量、同一固定紧支撑的非负 L¹ 输入上，以 h→0 一致保留严格阈值 1 的 halo 面积。它**不**证明有限图最优值 C₂−L_n 没有收敛率，因为有限图可以重新优化，未被迫采用原输入的逐胞聚合。

## 1. 全尺度两原子模板

在 R²、共同半径轴平行中心方形、严格阈值 1 下，取

μ_s=s²δ_{(−s/2,0)}+s²δ_{(s/2,0)}, s>0。

两 singleton halo 各为边长 s 的开方块，内部不交；二原子共同见证矩形的宽高为 (√2−1)s 和 √2 s。其在 singleton 并外新增面积为 (√2−1)²s²。因此

|H(μ_s)|=(5−2√2)s²， μ_s(R²)=2s²， β:=|H|/mass=5/2−√2>1。

这是全部三个非空源子集的完整 halo，未丢弃尺度或用任意矩形替代共同半径方形。

## 2. 单位质量、固定支撑、任意细网格

令 n≥3、h=2^(−n)、s=h/8。在固定矩形 D=[0,8]×[0,4] 的每个 h×h 半开网格胞 B_ij 内，取中心 c_ij，放一个平移模板 μ_s。共有

K=(8/h)(4/h)=32/h²

个胞；每胞质量 2s²=h²/32，所以有限测度 μ_h 总质量准确为 1。所有原子严格在各自胞内部。

不同胞原子间的最小无穷范数距离至少 h−s=7h/8。所以捕获不同胞原子的方形必须满足 r≥r₀=7h/16。

用无限 h 方格、每格在中心放质量 m₀=2s² 的基线支配有限阵列；原子相对中心位移≤δ=s/2=h/16。逐标签输运及逐轨道计数给所有 x,r

μ_h(Q(x,r))/(4r²) ≤ ρ(1+(h+2δ)/(2r))²， ρ=m₀/h²=1/32。

在 r₀ 右端的上界准确为

(1/32)(1+9/7)²=8/49<1，

且随 r 递减。因此所有严格见证均捕获同一胞的原子；各模板 halo 又全位于该胞内部（横向半宽至多 s，纵向半高至多 s/√2，均<h/2）。由此得到准确全尺度恒等式

|H(μ_h)|=K(5−2√2)s²=β。

## 3. 原模型的胞质量聚合与量化

令 Π_h 把每胞全部质量集中到该胞左下格点，则

Π_h μ_h = (h²/32) Σ_ij δ_{(ih,jh)}。

不同格点距离至少 h。若 r<h/2，方形至多捕获一原子；若 r≥h/2，逐轨道计数给平均≤(1/32)(1+h/(2r))²≤1/8<1。因此完整 halo 恰为互不交的 singleton 开方块并，每个面积等于其质量，故

|H(Π_h μ_h)|=1。

第32轮层级的质量步长是 d_n=2^(−4n)。每胞质量与步长之比为

(h²/32)/d_n=2^(2n−5)∈N， n≥3。

所以向下质量舍入完全不改变 Π_h μ_h。这一损失来自联合几何被聚合，不能归咎于未控制的舍入质量。

## 4. 传到真正 L¹，保留固定正损失

把 μ_h 的每个原子均匀铺在以其为中心、半宽 ε=s/4096 的小方块上，得 f_h≥0。所有小方块仍严格位于原胞内，f_h 支持于固定 D，且 ∥f_h∥₁=1；因此 Π_h f_h=Π_h μ_h，包括后续质量量化。

对单个模板的三个源子集，原临界半径分别为 s/2、s/2、s/√2。把每个接收矩形的半径减少 2ε；对其中任一接收中心，用减少后半径再加 ε 的方形，即捕获平滑后全部相应质量，且最终半径仍严格小于原临界半径。因此这三个缩小的开矩形均在 H(f_h) 内。

每个 singleton 矩形的面积损失≤8sε；二原子矩形损失≤4ε(2√2−1)s≤8sε。并集损失不超过三个损失之和，故全部 K 个胞保留面积至少

|H(f_h)|≥β−24Ksε=β−12/4096=β−3/1024。

这些内矩形留在互不交的胞内，所以它们的面积可以逐胞相加。这里不需要证明平滑后完全没有其他见证；任何额外见证只提高下界。

由于 √2<10/7 且 1/14−3/1024>1/16，严格有

|H(f_h)|−|H(Π_h f_h)| ≥ 3/2−√2−3/1024 > 1/16， 对所有 n≥3。

于是，不存在仅依赖 h→0 而趋零的误差 ω(h)，使所有非负、单位质量、支持于 D 的 L¹ 输入 f 都满足

|H(f)| ≤ |H(Π_h f)|+ω(h)。

## 5. 对层级的正确含义

每个**固定** f 的有限严格见证仍可在足够细网格和质量步长下保留，第32轮 L_n↑C₂ 的逐输入密度证明不受影响。本例的 f_h 随 h 变化，准确否定交换“对全部 f 一致”与“h→0”次序。

它也不排除通过其他网格位移、自适应模板、重新缩放或全局重新优化取得 L_n 的一致误差率。尤其不能从这个量化算子的失败推断 C₂−L_n 有固定正下界。下一步若用一个统一近似引理控制图层级误差，必须保留胞内模板，或证明另一个可替代的全局选择机制。

实际证据：`computation/check_grid_aggregation_obstruction.py` 使用 Python 3.15.0 Fraction，核查 n=3,…,8 的质量归一化、源间距、输运尾界、量化整除、平滑胞内包含和严格固定差值。一般 n 和完整 halo 的结论由上面解析证明承担；脚本不枚举巨大阵列的全部源盒。

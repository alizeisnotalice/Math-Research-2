# R53：按见证半径分裂的无小质量收缩界

2026-11-15。对象为二维中心轴平行共同半径、严格门槛1的真实halo H，不是插入proxy。此处给全n、任意高rank与bbox的定量收缩定理，并用九格新常数给可检查的3.5条件类；未得到一般C₂≤3.5。

## 1. 任意固定源块的通用传递

令有限正测度μ分成n个不交源块（也可为n份正子测度，质量只记一次），总质量M>0。每块质量m_i>0，选代表点c_i，且该块全部源点都满足||p−c_i||∞≤δ。收缩测度μ_c=Σ_i m_i δ_(c_i)。原子数和最小原子/块质量均不受限制，代表点可以重合；非原子Borel子测度同样适用。

**定理。** 对任意r₀>0，令a=(1+δ/r₀)²，则

    H(μ) ⊂ H(aμ_c) ∪ ∪_(i=1)^n [c_i+(-r₀−δ,r₀+δ)²],                (1)

从而

    |H(μ)| ≤ |H(aμ_c)| +4n(r₀+δ)².                                (2)

若保留几何交叠，(2)的最后一项可替换为这些小方形在H(aμ_c)外的真实并面积。原质量始终按块唯一归属；a只在辅助收缩测度中放大，不冒充新增可用源质量。

证明：任取x∈H(μ)及严格见证Q(x,r)，μ(Q)>4r²。若r≥r₀，每个被Q捕获的原源点所属代表点都在Q(x,r+δ)；把该块全部质量放在代表点只能增大已捕获量，所以μ_c(Q(x,r+δ))≥μ(Q)>4r²。又a≥(1+δ/r)²，得到aμ_c(Q(x,r+δ))>4(r+δ)²，故x∈H(aμ_c)。若r<r₀，Q至少捕获一个源点p；其代表点满足||x−c_i||∞≤r+δ<r₀+δ，给(1)的第二项。严格不等号在r=r₀及δ=0时均保留。证毕。

与饱和bbox状态外差界相比，此界不枚举2^n或n⁴个可能捕获块集，也不需要eligibility余量；代价是质量放大a和小半径见证的显式接收面积。它不是对原proxy的无损压缩。

## 2. 九格局部上界的定量适用范围

本轮已严格认证的常数为

    B=1994727599733432151936139/604462909807314587353088<33/10.

九格全质量单纯形证明：任意正有限测度ν，若其支撑可装入边√mass(ν)方块，则|H(ν)|≤B mass(ν)。有限Borel测度的直接映射见覆盖核心独审§二。

设代表点bbox最大边长为d。把质量再放大到能容纳其bbox，给任意ν的局部推论|H(ν)|≤B max(mass(ν),d²)。代入(2)，得完全可计算的无rank条件式

    |H(μ)| ≤ B max(aM,d²) +4n(r₀+δ)².                             (3)

特别d≤√M时，设ε=δ/√M、τ=r₀/√M，则

    |H(μ)|/M ≤ B(1+ε/τ)²+4n(τ+ε)².                               (4)

当ε>0时，右侧导数为2(τ+ε)(4n−Bε/τ³)，故在唯一点τ=(Bε/(4n))^(1/3)达到全局最小，值为

    [B^(1/3)+(4n)^(1/3) ε^(2/3)]³.                               (5)

ε=0由τ↓0给B。式(5)不把根式近似当严格数值证书；下面用有理选择直接支付预算。

若n≤9、d≤√M且δ≤√M/1250，取r₀=√M/25，则a≤(51/50)²，(4)严格给

    |H(μ)|/M < (33/10)(51/50)² +36(51/1250)²
                 =10916397/3125000 =3.49324704 <7/2.               (6)

其与3.5的有理余量为21103/3125000。这把一个明确紧块条件类接入3.5；不需要原输入整体bbox可装入√M方块，也不需要跨块rank低。一般大bbox组件不保证有n≤9、此位移阈值和代表点bbox条件，不能省略这些前提。

对于多个实际eligible组件，可分别提供(3)或其他接收证书，再按真实halo组件分解及面积次可加性相加；用到的源质量保持组件间不交。更广的自适应分解仍需额外证明。

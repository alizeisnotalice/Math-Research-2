# 非圆域检验：同形菱形 Brownian killed Green 核的成本障碍

2026-11-15；第33轮冻结之后的独立续作，未纳入033清单，轮次待root分配。没有改动已冻结核条件。本稿给出连续参数全域成本下限，不给新C₂数值界。

## 对象与结论

D={x∈R²:|x₁|+|x₂|<1}，Ω_R=R D，R>1。生成元固定A=Δ；G_R(x)=G_{Ω_R}(0,x)是原点出发的杀死Brownian Green占用密度，τ_R是退出时间。令

    c_R=essinf_{x∈D}G_R(x)>0，K_R=G_R/c_R，
    J_R=(1/2)∫K_R=E₀τ_R/(2c_R)。

这是合法Lin比较核：ΔG_R=ν_exit−δ₀，K_R≥1_D、非负、偶、可积。本次检验的域是真正非圆的菱形，且Green奇性随生成元匹配。

**定理。** 对所有R>1，

    J_R ≥ π(1+√2)/2 > 379/100 = 3.79。

因此整个同形菱形Brownian杀死Green族都不能改善继承上界3.590865312933。不需要假设Green在D的最小值发生于顶点；证明只使用一个顶点的值作为必要约束。

## 1. 明确共形映射与Green归一化

视R²为复平面。设

    H(w)=∫₀^w (1−t⁴)^(−1/2)dt，I=H(1)，
    F_R(w)=(R/I)H(w)。

根号取单位圆盘内在0取1的解析分支。F_R是单位圆盘到Ω_R的Schwarz–Christoffel映射：预顶点1,i,−1,−i分别映到R,iR,−R,−iR；每条边界弧映成直线段，角度均为π/2。可直接由dF_R(e^{it})/dt的辐角在每个四分之一圆周恒定验证。归一化F_R(0)=0、F_R'(0)>0确定此映射。

唯一q∈(0,1)满足H(q)=I/R，且F_R(q)=1。Δ对应的圆盘Green是−(2π)^(−1)log|w|，二维Green共形不变，故

    G_R(1)=−logq/(2π)。                                  (1.1)

由于顶点1是D闭包上的点，G_R在其邻域连续且该邻域包含D内部正面积集，

    c_R≤G_R(1)。                                         (1.2)

这一步不需要找出整个D的最小点。

## 2. 退出期望的准确级数

设b_n=binom(2n,n)/4^n。二项式展开给

    H(w)=Σ_{n≥0} b_n w^(4n+1)/(4n+1)。

对任何解析映射F(w)=Σ_{k≥1}a_k w^k，用Green变换和圆周Parseval：

    E₀τ_Ω=∫_Ω G_Ω(0,z) dz
      =∫_{|w|<1} [−log|w|/(2π)] |F'(w)|² dw
      =Σ_{k≥1} k²|a_k|² ∫₀¹(−logr)r^(2k−1)dr
      =(1/4)Σ_{k≥1}|a_k|²。

非负项允许Tonelli，且本域有界所以退出期望有限。于是

    E₀τ_R=R² S/(4 I²)，
    S=Σ_{n≥0} b_n²/(4n+1)²≥1。                           (2.1)

结合(1.1)–(2.1)，消去R=I/H(q)，得到

    J_R≥π S/[4 H(q)²(−logq)]
        ≥π/[4 H(q)²(−logq)]。                            (2.2)

这里只对退出期望下放松S≥1，并对c_R上放松为顶点Green。两项放松均使右侧成为必要成本下界；没有反向解释成可行上界。

## 3. 对全部q的初等估计

函数B(q)=q(1−q⁴)^(−1/4)满足B(0)=H(0)=0，且

    B'(q)=(1−q⁴)^(−5/4)≥(1−q⁴)^(−1/2)=H'(q)。

所以H(q)≤B(q)。令t=q²∈(0,1)，则

    H(q)²(−logq) ≤ [−t logt]/[2√(1−t²)]。                (3.1)

对s=√t，函数s^(−1)−s+2logs在(0,1]的导数为−(1−s)²/s²≤0，且在1为零。因此

    −logt ≤ (1−t)/√t。

代入(3.1)得

    H(q)²(−logq) ≤ (1/2)√[t(1−t)/(1+t)]。

有理函数h(t)=t(1−t)/(1+t)的导数是(1−2t−t²)/(1+t)²；其唯一最大点t=√2−1，最大值(√2−1)²。因此

    H(q)²(−logq) ≤ (√2−1)/2。

代回(2.2)得到J_R≥π/[2(√2−1)]=π(1+√2)/2。最后取π>31415/10000、√2>14142/10000，其乘积/2为准确的75842093/20000000=3.79210465>3.79；这两个下界另由Arb实际定向核验。若只与旧3.590865312933比较，更粗的π>3、√2>7/5已给出严格>18/5=3.6。□

# 第32轮辅助核验：半径截断下的二维 collar 精确拼接

作者：sol_recursive_geometry，2026-11-15。交付 astra_recursive/root；本文件未提交、未推送，不宣称新一般 C₂ 界。

## 1. 对象与状态

固定 R>0、λ>0；所有密度非负且属于 L¹，背景为 Lebesgue R²，Q_r(x)=x+[-r,r]²，
H_R(f;λ)={x:存在 0<r≤R，使 ∫Q_r(x) f>4λr²}。
只对上式严格阈值工作。对矩形 B 定义
I_R(B)={x∈B:dist∞(x,∂B)>R}，C_{2R}(B)=B\I_{2R}(B)。
空 core 允许出现。边界线为零面积；以下密度及矩形相交均按 a.e. 解释。

一个块 B 的充分状态为：
(1) 已知 B、R、λ；(2) h(B)=|I_R(B)∩H_R(f1_B;λ)|；
(3) 受限测度 f1_{C_{2R}(B)} dx，等价于对**每个二维轴平行矩形** A 给出
P_B(A)=∫_{A∩C_{2R}(B)} f。
若要输出 halo 集合本身，(2) 需存相应集合，而非面积标量。状态 (3) 通常是无限维状态；不能把“有精确递推”解释成“得到有限维优化”。

## 2. 精确拼接引理（含窄块、角接缝及多块跨越）

设有有限个轴平行矩形 B_i，内部两两不交，a.e. 铺满矩形 B；令 f=Σf_i，f_i≥0 支持于 B_i。
不要求子块边长≥2R 或≥4R。则全部子块上述状态唯一确定 parent 状态，并唯一确定任意
x∈B\∪I_R(B_i) 的严格 halo 成员资格；还确定全部 x∉B 的成员资格。

证明：若 x∈I_R(B_i)，对所有 r≤R 有 Q_r(x)⊂B_i，故完整平均和局部平均逐半径相同。
同时 I_R(B_i)⊂I_R(B)。令 G=I_R(B)\∪I_R(B_i)。对 x∈G 及任意 j，证明
Q_R(x)∩B_j⊂C_{2R}(B_j)，忽略边界。
若 x∈B_j，由 x 不在 child core 得到某坐标方向上的到一条边距离≤R；Q_R 的该方向最远点到这条边距离≤2R。
若 x∉B_j，x 在某坐标投影外，该方向 Q_R∩B_j 内每点到对应边距离≤R。
这两种情形覆盖所有块，且与有多少个接缝、是否四块共角、是否跨过很多窄块无关。因此

D(x,r)=Σ_j P_{B_j}(Q_r(x))=∫Q_r(x)f，x∈G，0<r≤R。

于是 h(B)=Σ_j h(B_j)+|{x∈G:存在 0<r≤R，D(x,r)>4λr²}|。
这是两个方向的等价：真实见证的每项质量均被 profile 保留；由 profile 得到的严格见证也是真实同半径方块，未组合不同半径或不同接收中心。

同理对 x∈B\∪I_R(B_i) 或 x∉B 上述重构成立。
parent profile 由 P_B(A)=Σ_j P_{B_j}(A∩C_{2R}(B)) 给出，因为
C_{2R}(B)∩B_j⊂C_{2R}(B_j)：任一点到 child 边界的距离不大于到 parent 边界距离。
P_B 对非矩形 A∩C_{2R}(B) 的值由矩形分割/差分求出；不能把此式误读成只允许一次矩形查询。
所有 strict halo 都是开集：固定 r 时积分关于中心连续；故面积合法。分层递推重复应用引理，顺序无关。

注意：从 child 内部只保存 h_i 而丢弃其 halo 形状，仍足够递推 parent 的 h，原因是所有 child cores 整体包含于 parent core；若再引入任意非矩形裁切则此标量结论不再自动适用。

## 3. 2R 的必要性与一维边际反例

2R 是上述普适几何接口的尖锐宽度。给定 0≤w<2R，取 child B=[0,10R]×[-10R,10R]。
令 ε=(2R−w)/4，a=R−ε，d 位于 (w,2R−ε) 内。取足够小正方形 S，以 (d,0) 为中心，
使 S⊂Q_R((a,0)) 且 dist∞(S,∂B)>w。令 f=(5λR²/|S|)1_S，
g 为 f 沿 y 轴平移 4R。两者宽 w collar 测度完全相同（皆零），在 child strict core 上的截断 halo 面积也完全相同：沿 y 平移保持所有平均与 core 裁切，且所有相关 halo 中心均远离上下边界。
但 x=(a,0) 的半径 R 平均对 f 为 5λ/4>λ，对 g 所有 r≤R 平均均为零。
Q_R(x) 跨 x=0 接缝。因此宽 w 数据及内部 halo 面积不能确定全部接缝见证。
此结论是对逐点精确见证接口的否定；不单凭本例声称所有可能的更弱面积状态均失败。

只存完整一维 x、y 边际同样不足。令 f=1_{[0,1]²}+1_{[1,2]²}，
g=1_{[0,1]×[1,2]}+1_{[1,2]×[0,1]}。
两者 x、y 边际都等于 1_[0,2]；但在 x=(1/4,1/4)，R=1/4 时，
f 的半径 R 平均为 1，g 的所有 r≤R 平均为 0。
取 λ=1/2，严格 halo 不同。二维矩形累计量能识别这些差异；其两条轴边际不能。

## 4. 全尺度与有限 L¹ 误差接口

(A) 对总质量 m<∞ 的非周期 f，若 m≤4λR²，则所有 r>R 都满足平均≤λ，
所以 H(f;λ)=H_R(f;λ)。这是全空间、全接收中心成立的 tail cap；相等亦合法。
对无限周期输入总质量无穷，不能使用此结论，须另外提供统一 periodic tail certificate。
例如周期 (P,T)、每格质量 m、ρ=m/(PT)，对任意 x,r 可用完全计入相交周期格得到
平均≤ρ(1+P/r)(1+T/r)。若该上界在 r≥R 严格小于λ即可；较紧旧证书可另行代入。
若周期平均≥λ，则这个 tail 接口不能排除大半径，不能机械宣称截断即全尺度。

(B) L¹ 扰动 e=||f−g||₁ 的正确接口带阈值余量：对 0<η<λ，
H_R(g;λ+η)\H_R(f;λ)⊂H_R(|f−g|;η)，
H_R(f;λ)\H_R(g;λ−η)⊂H_R(|f−g|;η)。
两者面积各≤9e/η。常数9可由有限见证子覆盖按半径递减贪心取不交方块，再3倍扩大覆盖得到；
一般可测集合经紧子集和有限子覆盖极限得到。此处不依赖待改进的一般 C₂ 上界。
无阈值余量的同层面积连续性不成立：第22轮临界平台反例已排除此类普适主张。

(C) 若 f 为双周期局部可积输入，横向/纵向都保留 n×n 完整周期格而得有限 L¹ 输入 F_n，
截断接收点距裁切外边界>R 时所有 r≤R 平均原样保留。因此内周期格的严格 capped halo 精确保留；
边界接收条带面积 O(n)，总质量 n²m，故合法有限 L¹ 弱比值的下极限≥周期 capped 比值。
只需内侧格达到距边界>R；当周期长度小于2R，删掉的整格层数增加但固定，误差仍O(1/n)。
这是下界传递；若想从周期枚举证明全部有限 L¹ 上界，仍需单独给出逼近完备性及阈值/半径处理。

## 5. 柱周期有限图接口的几何核验

固定 h>0、纵向周期 T=Nh、有限柱字母表，各字母规定一柱宽 h、纵向一周期中的完整非负密度。
接收条带 S_j=[jh,(j+1)h)×[0,T)。对 x∈S_j，r≤R，见证横向源坐标属于
[jh−R,(j+1)h+R]。故 k=ceil(R/h)+1 时，只依赖字母 j−k,...,j+k；+1 为安全冗余。
纵向源必须按 lift 到 R² 的周期密度积分：当2R≥T，同一周期格可有多个 lift，必须逐份计入，不能按torus集合去重。

长度2k+1的窗口作 deBruijn 有向边，重叠长度2k的窗口作顶点。
该边 reward 是 S_j 内完整严格 H_R 面积，cost 是中心柱一纵周期质量。以下 A/M 比值公式按 λ=1 写；若保持任意固定 λ 且目标为弱比值 λA/M，应把 reward 换成 λ 倍面积。
周期字串对应闭游走，reward、cost 分别可加；反向每个闭游走对应一个横周期字串。
任意正cost闭游走分解为simple cycles，正cost循环的比值加权平均不超过最大正cost simple cycle ratio；
若存在零cost cycle，中心柱逐边都为零，周期字串全零，其 reward 亦为零。
因此受限类的最优比值精确等于有限个正质量simple cycles的最大 ratio。

**唯一根修正**：必须写 F(z)=max_{C simple, M_C>0}(A_C−zM_C)。只要非空，
有限正斜率 M_C 使 F 严格递减，且 ±∞ 两端异号，故唯一实根为 max A_C/M_C。
若将 all-zero self-loop 纳入 max，则 F(z)=0 对所有 z≥最优比值，唯一性失败。
每边 A_C 的实际认证计算仍是另一个任务；有限图及方程只刻画此固定 h,T,alphabet,R 的受限类，不是一般 C₂ 方程。

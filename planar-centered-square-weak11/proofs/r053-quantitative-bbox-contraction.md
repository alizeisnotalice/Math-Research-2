# R53：任意高秩块的定量收缩与接收并集误差

2026-11-15。本稿独立于已完成的 R49，且不改已有 R53 block-interface 草稿。对象是平面中心轴平行共同半径、严格门槛为 1 的 halo。以下是解析定理；附带 Fraction 例证只核对有限算术和并面积。没有新一般 C₂ 上界。

## 1. 固定质量归属，原子数不限

有限正原子输入 μ 的源标签分成 n 个不交非空块 C_i。每份原子质量恰属一块；几何 bbox 可以重叠。设 m_i=μ(C_i)>0，M=Σm_i，B_i=[l_i^x,u_i^x]×[l_i^y,u_i^y] 为该块真实闭 bbox。取代表点 c_i∈B_i，令 δ_i=max_{p∈C_i}||p−c_i||∞；真实 bbox 知道时可直接由四端点计算。收缩测度为 μ_c=Σm_i δ_{c_i}。

对非空块指标 J，记 m_J=Σ_{i∈J}m_i，r_J=√m_J/2，δ_J=max_{i∈J}δ_i。定义开矩形，空边长时按空集处理：

D_J=(max_J l_i^x−r_J, min_J u_i^x+r_J) × (max_J l_i^y−r_J, min_J u_i^y+r_J),

E_J(t)=∩_{i∈J}(c_i+(-t,t)²)，D=∪_{J≠∅}D_J。

**定理 1（无需 rank/eligibility 余量的任意块接口）。**

H(μ)⊂D，H(μ_c)⊂D，且

|H(μ)| ≤ |H(μ_c)| + (|D|−|H(μ_c)|)
         ≤ |H(μ_c)| + Σ_{J∈F} e_J,                                      (1)

e_J=|E_J(r_J+δ_J)|−|E_J(r_J)|≥0。                                     (2)

这里 F 可取全部非空 J，或下一节的 saturated 家族。若 s_x(J)=max_J c_i^x−min_J c_i^x，s_y 同理，则 e_J 可直接计算为

[(√m_J+2δ_J−s_x)_+(√m_J+2δ_J−s_y)_+]
−[(√m_J−s_x)_+(√m_J−s_y)_+]。                                        (3)

证明：任取真实严格见证方形 Q(x,r)，令 J 是其实际遇到的块。各块至少有一个被捕获原子，故 x∈∩_{i∈J}(B_i+[-r,r]²)，且 4r²<μ(Q)≤m_J。于是 r<r_J，给 x∈D_J；边界原子不会破坏最终开矩形的严格端点。对代表点同理，或直接用 c_i∈B_i 得 E_J(r_J)⊂D_J。有限原子 halo 的完整子集公式给 H(μ_c)=∪_J E_J(r_J)。由 |p−c_i|∞≤δ_i，端点比较给

D_J⊂E_J(r_J+δ_J)。                                                   (4)

所以 D_J\H(μ_c)⊂E_J(r_J+δ_J)\E_J(r_J)。对有限并取测度、保留原有 H(μ_c) 的整片遮罩，得 (1)。这没有把不同 J 的 m_J 相加当成可用源质量；Σe_J 只是几何外差的上界。证毕。

若要求完全保留相交，可直接扫线计算 |D|−|H(μ_c)|，而不使用 Σe_J。给 F 任意顺序 J_1,…,J_q，令 A_k=D_{J_k}\(H(μ_c)∪∪_{h<k}D_{J_h})，则这些 A_k 不交，且 |D|−|H(μ_c)|=Σ|A_k|。这是接收面积的精确去重账本，块的源质量归属从始至终固定且不交。

## 2. 有限算法：至多 min(2^n−1,n⁴) 个块状态

对非空 J，设 L_x=max_J l_i^x，U_x=min_J u_i^x，L_y=max_J l_i^y，U_y=min_J u_i^y，并定义

K(J)={i:l_i^x≤L_x，u_i^x≥U_x，l_i^y≤L_y，u_i^y≥U_y}。

这允许 L_x>U_x 或 L_y>U_y，不能误加“块 bbox 有公共交点”的条件。J⊂K(J)，四个极值在 K(J) 上完全不变，且 m_K≥m_J，故 D_J⊂D_K。K(K(J))=K(J)。因此令 F 为所有不同 K(J)，便有 D=∪_{K∈F}D_K。每个 K 由四个来自输入 bbox 端点的阈值决定，所以 q=|F|≤min(2^n−1,n⁴)。可枚举 n⁴ 个四阈值组，构造其中的非空 K、再去重；逐 K 算 m_K 和矩形、扫线取并。复杂度依赖块数 n，不依赖块内原子数或 eligible 超图 rank。可以安全删除空 D_K，进一步减少误差求和。

## 3. 显式误差，及其能和不能传递的结论

对任意 J，包括原 E_J(r_J) 为空、或某边恰为零的阈值情况，均有

0≤e_J≤4δ_J√m_J+4δ_J²。                                               (5)

证明：若 √m_J−s_x 和 √m_J−s_y 均非负，展开 (3)，两项原边长均≤√m_J，得 (5)。若有原边长为负，扩张后该边正部至多 2δ_J，另一边正部至多 √m_J+2δ_J，故 e_J≤2δ_J√m_J+4δ_J²；两边均负时更小。零边界也由同式处理。证毕。

特别 δ=max_iδ_i，q=|F| 时

|H(μ)| ≤ |H(μ_c)| +4qδ√M+4qδ²。                                     (6)

如果不用 saturated 家族而用全部子集，还可由 Σ_Jm_J=2^(n−1)M 与 Cauchy 得

Σ_Je_J≤4δ√[(2^n−1)2^(n−1)M]+4(2^n−1)δ²。                           (7)

应实际比较 (3)、(6)、(7) 及精确并差，不默认选最粗式。

因此，对任意原子数、任意 highrank/大 bbox 组件，只要给出一个具有 n 个紧块的固定分割，以及收缩测度的真实上界 |H(μ_c)|≤KM，就得到 K+ε 的合法原输入上界，其中 ε 可由 (3) 或并差实际认证。这里不需最小单原子质量、最小块质量、严格 eligibility 余量或拓扑不变。固定 n、δ/√M→0 时误差趋于零；即使代表点的某子集恰卡在 eligibility 等号，结论仍连续有效。

这澄清九块 finite-simplex 结果通向一般输入的准确义务：若九块代表点证书已证 KM，需再支付上述块几何误差，或证明其被 K 内部余量/接收交叠吸收。九格块的 δ 通常是固定比例 √M，并不自动趋零；任意大 bbox 连通组件也不保证存在少量紧块。因此本定理给任意分割的定量接口，没有无损地把所有组件归约成九点问题，不能据此宣称一般 3.5。相反，允许 n 随细分增长时，(6)/(7) 未必趋零；需要控制有效 saturated 状态数或直接的并差。这是明确可检验的额外预算，不是原子 eligibility rank 限制。

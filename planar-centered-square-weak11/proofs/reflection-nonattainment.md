# 有限原子反射严格增益：来源核查与研究限制

原来源是旧 T 中第5轮的独立草稿，准确身份见 `references/sources.json` 的 `reflection_draft`。T2 已独立审读其 §§1–6；本稿重述关键论证，没有把历史计算当成本轮运行。

## 点态反射定理

设 μ 是非零有限正原子测度，阈值 λ>0，总质量 m。对每个非空原子子集 I，以其质量 M_I、外接盒 [a_I,b_I]×[d_I,e_I] 定义
\[
r_I=\sqrt{M_I/(4\lambda)},\quad
R_I=(b_I-r_I,a_I+r_I)\times(e_I-r_I,d_I+r_I).
\]
省略空矩形后，严格水平集 H 是这些有限开矩形的并。正向由任一见证中全部原子得到子集，反向在最大捕获距离与 r_I 之间取正半径；这是全尺度的精确公式。

令 c 为所有 R_I 的最大右端，在右端为 c 的矩形中选最高上端 Y 的一个，记其子集 S、半径 r。所有源原子都严格位于 x<c，因为每个 singleton 给出非空矩形。关于 x=c 反射为 μ*，则两份旧严格水平集分别在 x<c 和 x>c，彼此不交。

令 k=√2−1，δ 为其他右端与 c 的最小正间隙（没有时取 ∞），ε=min(δ,kr)>0。S 和反射 S 的并具有质量2M_S，源盒横向端点 c−r,c+r，混合接收矩形横向为 (c−kr,c+kr)，上端为 Y+kr，下端严格低于 Y。因此
\[
B=(c-\varepsilon,c+\varepsilon)\times(Y,Y+kr)
\]
属于新严格水平集。任何旧接收矩形或因右端≤c−δ 与 B 横向分离，或因右端为 c、上端≤Y 而纵向分离；反射侧同理。因此
\[
|H_\lambda(\mu+\mu^*)|\ge 2|H_\lambda(\mu)|+2\varepsilon kr,
\qquad
\frac{\lambda|H_\lambda(\mu+\mu^*)|}{2m}
\ge\frac{\lambda|H_\lambda(\mu)|}{m}+\frac{\lambda\varepsilon kr}{m}.
\]
严格正增益依赖输入和阈值，不能从 δ>0 推出统一于原子数的正下界。

## 对原研究目标的含义

有限原子的 F(λ)=λ|H_λ| 连续；λ↓0 时缩放后的所有位置合并，F→m；λ 足够大时只有互不相交的 singleton 接收方形，F=m。因此若其弱比值大于1，必在某有限正阈值达到。单原子的反射已给大于1的比值，再由有限原子到 L¹ 的严格内矩形平滑传递得到一般 C₂>1；若某有限原子弱比值达到 C₂，则在该阈值反射并同样平滑会超过 C₂，矛盾。

进一步的 `C₂,₂N > C₂,N` 和 `C₂,N < C₂` 使用旧原子基础中“固定至多N原子的最大值实际达到”这一额外定理。T2 已读审其紧性、碰撞和零质量处理，但本轮不把这项推论的依赖隐藏在反射点态结论中。

这排除了固定有限原子数达到一般常数的路线。它没有证明一般 L¹ 不达、逐一 N→N+1 严格增加、反射迭代的收敛速度，或者反射所得序列必趋于 C₂。周期构造经有限化形成下界序列，与有限原子不达性没有冲突。

## 固定模板

输入为 N 个正质量源，总质量归一化为1；位置为分母10000的有理网格点，正整数权重除以总权重。对每个非空源子集 S，严格 eligible 条件为 d_bbox(S)²<m(S)。本轮 C++ 以128位整数比较，Python 独立重放以任意精度整数比较，无浮点 eligibility 门槛。

对原完整输入的每个源 p，T_p 是所有包含 p 的 eligible 子集质量的最大值，Q_p 为以 p 为中心、半边长 sqrt(T_p)/2 的方块。枚举全部删除集 D（含空集），|D|≤3；剩余源按所有完全包含于剩余源的 eligible 超边划分真实超图连通分量。

每个叶分量 L 的已知 scalar 上界取以下各项的最小值：B max(M_L,d_L²)、r_L M_L，以及四个固定顺序的真实前缀 proxy 方块并面积。B 使用 R53 的已认证系数约3.299999995647862；r_L 为叶内最大 eligible 子集基数。四个顺序为质量递增、质量递减、x递增、y递增，平局按源编号。每步 proxy 质量精确取当前前缀内包含新源的最大 eligible 子集质量；这些 caps 用 subset-SOS 最大值查询预计算。四个 proxy 并面积均为合法上界候选，不声称最优顺序。

叶 core G_L 由全部 singleton halo 方块及（若整个叶 eligible）完整叶的 capture-center 矩形取并构成。完整叶矩形坐标为 [maxx−sqrt(M_L)/2,minx+sqrt(M_L)/2] 与对应纵坐标区间的直积。令 P 为删除源的 Q_p 并集，最终计算

    score(D)=area(P∪全部G_L)+Σ_L(U_L−area(G_L)),

并取所有 |D|≤3 的最小值。此公式的几何有效性由结构分支证明；搜索中矩形面积使用双精度，只作为数值证据，未包装成定向区间证书。与结构分支核对后确认，proxy 半边长为 sqrt(T)/2，叶源质量不重复支付，core 可与任意有效 U_L 组合。

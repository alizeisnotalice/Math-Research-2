# 完整位置—质量变分：单轴分段仿射、双仿射腔与近极值必要条件

日期：2026-11-15（Asia/Shanghai）。作者工作区基线 `f9502e0df212da80e489494087f67a27645ab356`。

本稿的主结论是：固定全部质量而只移动一个坐标轴时，完整原子 halo 的面积沿仿射路径连续分段仿射；允许两个坐标轴独立变化时，在完整组合开腔中面积是双仿射式，因而非平坦局部极大不能位于开腔内部。全部源子集、新激活、重合端点分裂和接缝均包含在表示中。附录给联合位置—质量变分及相关二阶上界。结论适用于每个有限原子模型，以及具有统一尾界的有限基胞周期模型；不提供一般 L¹ 上界或 C₂ 精确值。

## 1. 对象、统一有限目录和严格 halo

阈值固定为 λ>0，几何基固定为中心、轴平行、共同半径的正方形。参数 θ 属于紧凸多面体 D。每个基标签的位置 p_i(θ)=(x_i(θ),y_i(θ))、质量 w_i(θ) 均仿射，且 w_i(θ)≥ε>0。先取以下两种对象之一。

* 有限原子：μ_θ=Σ_i w_i(θ)δ_{p_i(θ)}。取 R>0 满足 max_D Σ_iw_i≤4λR²；所有 r≥R 均无严格 λ 见证。选择固定有界矩形 F，包含所有 p_i(D)+[-R,R]²，则完整 halo 均在 F 中。
* 周期原子：固定周期 (P_x,P_y)，μ_θ=Σ_iΣ_{k∈Z²}w_i(θ)δ_{p_i(θ)+(k_1P_x,k_2P_y)}。取固定基胞 F=[0,P_x)×[0,P_y)，并**另行认证**全 D 统一尾界：r≥R 时无严格 λ 见证。本文不从抽样推出此假设。

周期情形因所有 p_i(D) 有界，只存在有限多个副本标签 (i,k) 可能在某个 θ 时落入 W=[-R,P_x+R]×[-R,P_y+R]。把它们全部列入固定有限目录 I；有限原子情形令 I 为全部原子。目录允许在部分参数处移出 W 的冗余副本。两副本或源坐标碰撞时保留标签和正质量，不在变化过程中改变目录。

对每个非空 S⊆I 定义

    m_S(θ)=Σ_{j∈S} w_j(θ),   t_S(θ)=min{R, sqrt(m_S(θ)/(4λ))},
    a_S=min_{j∈S}x_j, b_S=max_{j∈S}x_j,
    c_S=min_{j∈S}y_j, d_S=max_{j∈S}y_j,
    E_S(θ)=F ∩ (b_S−t_S,a_S+t_S) × (d_S−t_S,c_S+t_S).

边长不正的开矩形记为空。则对每个 θ，严格 halo 满足

    H_θ∩F = ⋃_{∅≠S⊆I} E_S(θ).                         (1)

证明：任意严格见证半径 r<R 所捕获的所有副本构成非空 S⊆I；其所有源距中心≤r，且 r<sqrt(m_S/(4λ))，故中心属于 E_S。反向若 x∈E_S，则 d=max_{j∈S}||x−p_j||∞<t_S；选 d<r<t_S 得 r<R、m_S>4λr²，实际捕获额外源只增加质量。因此 x 有严格见证。F 的半开边界不影响面积。

(1) 是**理论完备目录**，不建议实现 2^|I| 枚举。固定一个源坐标全预序层后，可将任意 S 扩张成其 bbox 内的全部标签 T：bbox 不变、m_T≥m_S，故 E_S⊆E_T。因而实现可压缩为该层的全部饱和坐标盒。不同层的盒成员可能不同，必须在进入新层后重新建立完整目录；不能沿用基点的旧活跃盒。全部子集表示承担跨层完整性证明。

记 A(θ)=|H_θ∩F|，M(θ)=Σ_iw_i(θ)（周期情形仅对基胞标签求和），J(θ)=λA(θ)/M(θ)。分母始终是实际质量。

## 2. 固定质量时的精确位置结构

本节假设全部 w_i 固定。于是每个 t_S 是固定正数；只有 bbox 和裁剪端点变化。

先按全部源 x/y 坐标比较分层。每层中 a_S,b_S,c_S,d_S 都是选定源坐标的仿射式。再比较每个接收端点与 F 边界、所有 x 端点彼此、所有 y 端点彼此，并记录矩形两边是否严格为正。这些比较均为仿射函数的符号，故给有限超平面分层。全部输入有理/实代数时，分层超平面的系数可有效代数表示。

每一相对层中使用端点**全预序**：恒等的表达式以及仅在该墙层相等的表达式均合并为等价类，零宽间隔不列入格。写互异端点为 X_0<⋯<X_p、Y_0<⋯<Y_q，完整覆盖系数 η_jk∈{0,1} 在层中固定，则

    A(θ)=Σ_{j,k}η_jk (X_{j+1}(θ)−X_j(θ))(Y_{k+1}(θ)−Y_k(θ)).     (2)

端点连续，有限矩形并的面积连续；例如其对称差包含有限条宽度趋零的边界带。因此 A 连续，邻接层公式在共同闭包上一致。这个论证包括空矩形出生/消失、接缝开闭及端点重合，不另丢边界项。

**定理 1（单轴路径）。** 若所有 y_i 固定且所有 x_i(s)=x_i(0)+sv_i，s∈[s_-,s_+]，则 A(s)、J(s) 连续分段仿射。把全部比较的零点按序记为 s_-=τ_0<⋯<τ_N=s_+；每个非空开区间上

    A(s)=α_k+β_k s,
    A(s_+)−A(s_-)=Σ_k β_k(τ_{k+1}−τ_k).                 (3)

证明：y 端点及长度固定；每个区间的 x 端点仿射，η 固定，代入 (2)。恒等于零的比较保留为同一等价类，不产生无限事件；端点处由连续性拼接。只沿墙走的路径同样适用。

故在基点，左右导数都存在但未必相等。正总增益仅推出至少一个正长度区间 β_k>0；**不推出 β_0>0，不推出整个路径单调，也不识别具体赢家盒**。沿单轴路径的局部最大可发生于向下折点或平坦区间；不能从分段仿射性推出端点给全局最大。

**定理 2（双轴位置与双仿射式）。** 两轴都作 θ 的仿射运动时，A 在每层是次数≤2的多项式。若把全部 x 坐标、全部 y 坐标作为相互独立的变量，则在任一完整组合开腔 Ω 内，

    A(x,y)=c+a·x+b·y+xᵀCy.                              (4)

周期副本坐标只增加固定平移量，不改变此式。证明：每个 X 差仅仿射依赖 x，每个 Y 差仅仿射依赖 y，(2) 相乘即得 (4)。没有 x_i x_j 或 y_i y_j 项。对一般低维耦合参数族，代入 x(θ),y(θ) 后可以出现 θ² 项。

“完整组合开腔”指剔除恒等比较后所有非恒等比较均严格的一片开域；特殊的共享源坐标等号在全独立变量域中是墙，不能当成开腔内部。先固定一个位置配置开域，其相关紧局部块具有同一完备副本目录 I、同一接收域 F 和统一尾界；Ω 必须限制在这个适用域内，不能把原紧参数域 D 的公式无条件用于 D 外。有限原子情形仍要求 F 包含整个邻域的完整 halo。

## 3. 无非平坦内点局部极大及定量近极值条件

在固定质量的开腔 Ω 中也可写

    J(x,y)=c₀+a₀·x+b₀·y+xᵀBy,
    ∇²J = [ 0  B ; Bᵀ  0 ].                             (5)

**推论 3。** 若 (x₀,y₀) 是相对于全部 x/y 独立小扰动的局部极大，且属于 Ω，则 J 在该腔的多项式恒定。

证明：内点局部极大使梯度为零且 Hessian 半负定。但对任意 u,v，二次型在 (u,v)、(u,−v) 处分别为 ±2uᵀBv，故半负定迫使 B=0；再由梯度为零得 a₀=b₀=0。

因此固定质量的非平坦局部极大必须处于至少一个真实组合墙上。此结论不保证极大存在，也不把某条低维曲线上的极大排除：J=1+xy、x=s,y=−s 给 1−s²，正是耦合方向的反例。

为连接一般常数，有限原子和本稿周期输入均有 J≤C₂。有限原子可用同质量紧支撑平滑：对每个严格见证把半径增加趋零量，保留严格裕量，再用 Fatou；周期情形采用 R1 已证有限块截断和平滑传递。这里不要求原子本身属于 L¹。

**推论 4（定量必要条件）。** 若以 z₀=(x₀,y₀) 为中心的闭欧氏球 B(z₀,ρ)⊆Ω，且同一完整表示(1)、双仿射式(5)及统一尾界在整个球内有效，令 g_x=∂_xJ(z₀)、g_y=∂_yJ(z₀)、Δ=C₂−J(z₀)，则

    Δ ≥ max{ ρ||g_x||₂, ρ||g_y||₂, (ρ²/2)||B||op }.       (6)

证明：只沿 x 梯度方向走距离ρ，(5) 没有纯 x 二次项，收益恰ρ||g_x||₂；y 同理。B≠0 时选单位左右奇异向量 u,v 使 uᵀBv=||B||op。令 h=(ρu/√2,ρv/√2)；h 和 −h 均可行，其中一者线性收益非负，二次收益均为ρ²||B||op/2。所有终点 J≤C₂，得到 (6)。B=0 时最后一项平凡。

于是 δ 近极值输入只要有同腔余量ρ，就必须满足 ||g_x||₂,||g_y||₂≤δ/ρ、||B||op≤2δ/ρ²。它精确区分“趋向组合墙”和“梯度/跨轴系数趋零”两种可能；没有统一ρ时不推出任何一般 L¹ 形状稳定或统一导数界，也不假定一般近极值可由固定有限维模型描述。

## 5. 联合位置—质量的精确一、二阶式

回到第1节仿射质量族。所有 m_S>0，所以 sqrt(m_S/(4λ)) 在 D 的一个邻域解析。依次对源坐标序、cap支、裁剪/端点全预序与矩形正长度分半代数层；(2)仍成立。每层面积是二次多项式、仿射式乘 sqrt(m_S)、及 sqrt(m_S m_T) 的有限和。持久等号层独列。

沿任意可行直线 θ(s)=θ₀+sv，各比较在充分小的 s>0 上或者恒为零，或者符号稳定；正质量保证对应根式解析。因此存在单侧解析分支。未cap支令 m'_S=Σ_{j∈S}Dw_j[v]，则

    t'_S=m'_S/(8λt_S),
    t''_S=−(m'_S)²/(64λ²t_S³).                            (8)

cap支的 t'_S,t''_S 均为零；等号处按实际单侧分支选择，不能任取同一导数。bbox端点取所选单侧仿射支；裁剪接收端点则取常数或 a_S/b_S/c_S/d_S±t_S 的所选单侧解析支。在下式中令 X、Y 分别代表一个被覆盖小格的相邻 x、y 端点之差，则

    A'=Ση(X'Y+XY'),
    A''=Ση(X''Y+2X'Y'+XY''),
    J'=λ(A'/M−AM'/M²),
    J''=λ(A''/M−2A'M'/M²+2A(M')²/M³).                    (9)

(9)中的 M 为实际基胞总质量；M''=0。墙上完整单侧公式已通过全预序改变反映接缝和新生矩形，不应再手加或遗漏边界修正。

若是可行局部极大，则每个可行直线右方向必须 J'₊≤0；若 J'₊=0，还必须 J''₊≤0。这只是必要条件，不足以保证局部最大，尤其不能只测一个方向集或忽略曲线趋近的墙层。

## 6. 相关参数的二阶认证上界及墙层限制

令 C 为一个凸参数小盒，各保留层 S_σ 的真实 J 公式解析延拓为 f_σ 到含 C 的开邻域。正质量给此延拓；cap/端点分支在延拓中固定，延拓外值无需有实际 halo 意义。置 T_σ=C∩closure(S_σ)，只保留非空 T_σ，要求它们覆盖 C，且 f_σ=J 在 T_σ（由完整表示和连续性核验）。

选 c∈C、r=max_{θ∈C}||θ−c||₂。假设在整个 C 认证 ||∇²f_σ||op≤K_σ，且 ℓ_σ 是线性最大值的准确值或有误差ε_σ的上界：

    sup_{θ∈T_σ} ∇f_σ(c)·(θ−c) ≤ ℓ_σ
       ≤ sup_{θ∈T_σ} ∇f_σ(c)·(θ−c)+ε_σ.

则

    U_σ=f_σ(c)+ℓ_σ+K_σr²/2,
    max_C J ≤ max_σ U_σ,
    0≤U_σ−sup_{T_σ}J≤ε_σ+K_σr².                        (10)

证明：对每个 θ∈T_σ，沿 C 中的线段对延拓 f_σ 作 Taylor，余项绝对值≤K_σr²/2。上界立即成立；取线性项的最大点或趋近最大序列并使用余项下界，得到误差式。**不要求 T_σ 凸，也不要求线段留在该层**，但 Hessian 界必须在整个 C 的解析延拓上成立。

同一稳定层充满 C 时，线性项在 C 角点最大，保持共同参数相关性，(10)给 O(h²)误差。若跨墙而把 T_σ 的线性优化放宽到整个 C，仍得到上界，却可能只有 O(h)误差；没有ε_σ=O(h²)认证，不得保留二阶收敛声称。墙层、持久等号及各侧的闭包匹配不能省略。

可认证粗 K 可从(8)及(2)取得：若m_S≥m_min>0、仿射系数向量a_S=∇m_S，则

    ||∇t_S||₂≤||a_S||₂/(4sqrt(λm_min)),
    ||∇²t_S||op≤||a_S||₂²/(8sqrt(λ)m_min^(3/2)).          (11)

对每项 XY，Hessian为Y H_X+X H_Y+∇X∇Yᵀ+∇Y∇Xᵀ；再结合(9)的多变量商法则处理 J。全部系数/根界必须定向，浮点 Hessian 或旧活跃盒不能承担(10)的认证。

# 第22轮：跨尺度新增面积不能按新增质量一致收费

日期：2026-11-15。独立工作区研究交付；未提交、未推送。本文只排除一个明确的一般上界预算，不给出新 C₂ 上界，不研究 P=M，也不重开固定核族。

## 1. 准确命题

令 Q(x,r)=x+[-r,r]²，H(μ)={x:存在 r>0，使 μ(Q(x,r))>4r²}，其中背景面积为二维 Lebesgue 测度、两轴共用半径、所有尺度、严格门槛1。定义纯混合新增部分

    A(μ,ν)=H(μ+ν) \ (H(μ)∪H(ν)).

**命题（一般新增质量预算失败）。** 对每个整数 N≥1 和 0<ε≤1，存在 N 个互异共线正原子的有限测度 μ_N，使

    |A(μ_N,εδ₀)| ≥ Nε/9.                                      (1)

此外存在非负、有界、紧支撑、有限 L¹ 函数 f_N,g_N，满足 ||g_N||₁=ε，并有

    |H(f_N+g_N) \ (H(f_N)∪H(g_N))| ≥ Nε/36.                    (2)

因此不存在有限常数 K，使所有有限源、或所有非负 L¹ 输入都满足

    |H(f+g) \ (H(f)∪H(g))| ≤ K ||g||₁.                       (3)

未扣除新增源自身 halo 的预算 |H(f+g)\H(f)|≤K||g||₁ 也失败。这里新增 g 可以是一枚原子的平滑近似。此结论不是说普通弱(1,1)常数无限：旧输入质量随 N 增长，证明一般弱界时仍可使用旧质量的余额。

## 2. 基线无左半平面 halo

设 p_i=2^i，i=0,…,N−1，源点为 (p_i,0)。设

    m_0=4,
    m_i=4(p_i²−p_(i−1)²)  (i≥1),
    μ_N=Σ_i m_i δ_(p_i,0).

所有质量正，前缀质量精确为 Σ_(j≤i)m_j=4p_i²，总质量4^N。

若一个中心 x=(u,v) 满足 u≤0，且 Q(x,r) 捕获至少一个源点，令 i 为捕获源的最大编号。其捕获质量至多4p_i²，且 r≥p_i−u≥p_i，故 μ_N(Q(x,r))≤4r²。不捕获源时当然也不严格超阈。因此

    H(μ_N) ⊂ {u>0}.                                         (4)

这使用的是任意半径、任意捕获子集，未假定见证只捕获前缀。

## 3. 每个尺度都有一块新的严格混合见证区域

加入 ν=εδ₀，取

    w_i=ε/(9p_i),    r_i=p_i+w_i,
    R_i={ (u,v): −w_i<u<0, p_i/2<|v|<p_i }.

对任意 x∈R_i，Q(x,r_i) 捕获原点及所有 j≤i 的源点：横向最大距离严格小于 p_i+w_i，纵向距离小于p_i。又因为 r_i<2p_i、u<0，所有 j>i 的源点均在方形右侧之外，故实际 exact incidence 正是新原子加前缀。

严格见证余量为

    (4p_i²+ε)−4r_i²
      = ε/9−4ε²/(81p_i²)
      ≥ 5ε/81 > 0,                                         (5)

其中使用 ε≤1≤p_i²。因此 R_i⊂H(μ_N+ν)。由(4)，R_i 与 H(μ_N) 不交。新原子单独的 halo 是 (−√ε/2,√ε/2)²，而 R_i 满足 |v|>p_i/2≥1/2≥√ε/2，故 R_i 与 H(ν) 也不交。

各 R_i 的纵向开带互不相交；相邻尺度仅在零面积边界相接，未丢弃正面积接缝。每个 R_i 面积精确为

    |R_i| = w_i · 2(p_i−p_i/2)=ε/9.

求和证明(1)。不存在数值拟合、有限半径网格或被忽略的更大尺度：这里有限个显式见证已足以给下界，而(4)对全尺度成立。

## 4. 有限 L¹ 传递：旧 halo 仍不能进入选定区域

取共同的有理平滑尺度

    η=ε/(144p_(N−1))=min_i(w_i)/16,
    φ_η=(4η²)^(−1) 1_[−η,η]²,
    f_N=μ_N*φ_η,    g_N=εφ_η.

二者均是有限 L¹ 函数，||f_N||₁=4^N、||g_N||₁=ε。设收缩后的中心区域

    S_i={ (u,v): −3w_i/4<u<−w_i/4,
                   5p_i/8<|v|<7p_i/8 }.

第一，任意 u≤−η 的中心、任意 r>0，由非负卷积/Fubini 及(4)的逐方形估计，

    ∫_Q(x,r) f_N
      = ∫ φ_η(z) μ_N(Q(x−z,r)) dz ≤4r².

因为 z_1≥−η，使 u−z_1≤0。S_i 上 u<−w_i/4<−η，因此 S_i∩H(f_N)=∅。这里没有通过 halo 集收敛来推断补集稳定，而是给出了全尺度直接估计。

第二，在 S_i 使用同一半径 r_i。原点与前缀原子平滑后的全部质量都被捕获：最大的横向距离至多 p_i+3w_i/4+η<r_i，纵向距离至多7p_i/8+η<r_i。故由(5)，S_i⊂H(f_N+g_N)。即使还捕获额外质量也只增强严格不等式。

第三，任意 x∈S_i，任何捕获 g_N 正质量的方形都必须满足

    r≥|v|−η > 5p_i/8−η ≥5/8−1/144>1/2≥√ε/2.

所以该方形面积严格大于ε，而总 g_N 质量只有ε，不能严格超阈。于是 S_i∩H(g_N)=∅。

S_i 之间仍互不相交，每个面积为

    |S_i|=(w_i/2)·2(p_i/4)=ε/36.

求和证明(2)。对任意给定 K 取整数 N>36K 即否定(3)。这是严格 L¹ 反例，而不只是原子模型的障碍。

## 5. 对上界几何预算的准确含义

失败的是“每次新增源质量，只用这次新质量支付所有新激活区域”的统一预算，包括先扣掉新增源自身 halo 再收费的版本。同一小源在 N 个尺度上与不同旧前缀混合，每个尺度都产生可分离的正面积收益；旧输入在 u=0 上恰有多尺度临界见证。

任何沿这种源插入或簇合并思路的有效一般预算，都必须另行控制重复使用新增质量的成本，例如同时动用旧质量预留，或证明适用构型的有效尺度数限制。本例不排除这些更强的预算，也不否定已有弱(1,1)上界。它不证明 K=2 或任意特定 K 不可能成为一般弱常数，不计算 C₂，也不比较任意候选极值输入。

本例没有周期接缝；这反而说明纯混合激活的困难在最简单的非周期共线输入中已经存在。若有限几何规则另附不在本例中成立的分离/密度条件，应当分别验证，不能把本反例外推成所有局部几何规则均失败。

# R54 双周期反射的有限 L¹ 转移：独立双向核验

日期：2026-11-15。固定二维 Lebesgue 接收面积、中心轴平行正方形、共同半径、严格阈值 λ=1。此附件不改冻结 R46，也没有计算新的真实左缝面积。

## 1. 对象及独立尾界

沿用 `double-reflection-closure-audit.md` 的双周期测度 Π_N：N≥7，横周期 T_N=2W_N、纵周期 P_y、每胞元质量 M_N=2Nm，W_N>6P_x>30。原标签在交替的长度 W_N 块内各有 N 个间距 P_x 的点。

任意长度 L 的横区间，若 L<W_N，最多跨一条块缝，每标签点数≤L/P_x+2。若 L≥W_N，分为 q 个完整块及至多两个端碎块，点数≤(L−qW_N)/P_x+2+qN≤L/P_x+L/W_N+2，因为 N<W_N/P_x+1 及 q≤L/W_N。每标签纵点数≤2r/P_y+1，乘积计数与正权重求和合法。

故 r≥15 时，原平均统一满足 Π_N(Q_r)/(4r²)≤c<1，其中

c=max{ρ(1+P_x/15)(1+P_y/30), ρ(3/2)(1+P_y/(6P_x))},
ρ=m/(P_xP_y)。

前者适用于15≤r<W_N/2，后者适用于r≥W_N/2。实际 R41 数据的准确 Fraction 复算给 c≈0.9993268958951075。所有近似显示均不承担正负判断；准确分数在 `transfer-independent-check.json`。这个计数没有把非整周期 2W_N 误换成2NP_x。

## 2. 平滑仍有统一 R15

令 φ_ε 为质量1、支撑于[−ε,ε]²的非负均匀密度，g_ε=Π_N*φ_ε。对任意中心与r≥15，

 g_ε(Q_r)≤Π_N(Q_{r+ε})≤4c(r+ε)²，

因此平均≤c(1+ε/15)²。实际准确核验

 c(1+(1/1024)/15)²<1，

近似为0.9994570208203767。于是所有0<ε≤1/1024，g_ε没有r≥15的严格见证。任何有限原子截断的同样平滑f≤g_ε，也没有这样的见证。此结论统一于N≥7以及有限截断大小。

## 3. 单胞元平滑面积双向收敛

固定N，取F=[ℓ,ℓ+T_N)×[0,P_y)，S_N=|H_1(Π_N)∩F|。令Z为Π_N在F+[−16,16]²中的有限原子集；ε≤1/1024时，F内r<15的平滑见证只可能用到Z中的原子。

对每个非空子集I⊂Z，记总质量M_I、外接盒[a_I,b_I]×[d_I,e_I]，s_I=√(M_I/4)、t_I=min(15,s_I)。定义

 E_I=F∩(b_I−t_I,a_I+t_I)×(e_I−t_I,d_I+t_I)。

由完整外接盒论证，H_1(Π_N)∩F=∪_I E_I；枚举全部子集仅用于有限性证明，计算可用完整bbox代替。

若x∈H_1(g_ε)∩F，以r<15为见证，将所有其平滑支撑与Q_r相交的Z原子组成I。总完整原子质量M_I不小于实际捕获的平滑质量，故s_I>r；这些原子至x的无穷范数距离≤r+ε<t_I+ε。因此

 H_1(g_ε)∩F ⊂ ∪_I [F∩(b_I−t_I−ε,a_I+t_I+ε)×(e_I−t_I−ε,d_I+t_I+ε)]。

右侧是有限个随ε趋零的扩张矩形。即使原E_I退化或为空，其极限新增部分也至多为线段；有限矩形并边界面积零。故其面积趋于S_N，得到limsup |H_1(g_ε)∩F|≤S_N。

下界可显式取D=2^b，k_I=⌊Ds_I⌋，

 t^-_{I,D}=max{0,min(15−1/D,(k_I−1)/D)}。

其内矩形并U_D⊂H_1(Π_N)∩F，面积S^-_{N,D}→S_N。每个非空内矩形均有s_I−t^-_{I,D}≥1/D和15−t^-_{I,D}≥1/D。若ε≤1/(2D)，对其任意中心，半径t^-_{I,D}+ε<min(s_I,15)的正方形完整捕获I的平滑质量，故U_D⊂H_1(g_ε)。于是

 |H_1(g_ε)∩F|→S_N  （ε↓0）。

这给面积双向收敛，并非只给可传递下界。

## 4. 有限截断、完整全平面面积及合法序列

保留Π_N的K_x×K_y个源胞元，平滑为f_{K_x,K_y,ε}。它非负、紧支撑、属于L¹，准确总质量K_xK_yM_N，即使相邻小方块重叠，质量加法仍成立。

取安全保护层q_x=2、q_y=4。实际准确比较有q_x T_N>15+ε（由T_N>12P_x即可）以及q_yP_y>15+ε。若K_x>4、K_y>8，所有保护层内部接收胞元的r<15源依赖都保留。另一方面，f≤g_ε，且任意水平集中心到某个保留源的距离<15+ε，故完整全平面水平集落在源块加保护层的至多(K_x+4)(K_y+8)个胞元中。因此

 [(K_x−4)(K_y−8)/(K_xK_y)] S^-_{N,D}/M_N
 ≤ |H_1(f_{K_x,K_y,ε})|/||f_{K_x,K_y,ε}||_1
 ≤ [(K_x+4)(K_y+8)/(K_xK_y)] |H_1(g_ε)∩F|/M_N，

其中下界要求ε≤1/(2D)。这同时控制截断源块外的halo，没有只计算内部面积却声称上界。

例如j≥1时取K_x=K_y=j+9、D_j=2^(j+9)、ε_j=2^(−j−10)，便有

 |H_1(f_j)|/||f_j||_1 → S_N/M_N = J_N。

此序列不要求周期轴有理；可构造真正L¹函数。若需要准确可计算候选，使用向外有理轴与对应真正横周期，再另行控制两条缝的轴误差即可。

## 5. 固定N正负差距的准确含义

独立系数恒等式是

 J_N=A/m+K/(mN)，K=b_x+γ_L+γ_R。

因此对于固定N，若K>0，以上指定有限L¹序列的阈值1比值最终>A/m+K/(2mN)；若K<0，则最终<A/m+K/(2mN)<A/m。后一结论证明该指定逼近序列最终保留负差距；它不是对所有平滑/有限化的断言。

**阈值范围不可省略。** 本附件只论证J(f;1)=|{M f>1}|/||f||_1。完整弱比值sup_{λ>0} λ|{M f>λ}|/||f||_1还可能在其他阈值更大；仅有λ=1的K<0不能证明该完整弱比值低于A/m。这一点也适用于将反射路线冻结的表述。

已有R41部分系数独立Fraction复算给出γ_L的break-even区间约[3.4688294373373485,3.4688294396891606]。准确γ_L>3.46882944足以证明K>0；准确γ_L<3.46882943足以证明K<0。其后完成的真实左缝old/new证书已由新脚本独立聚合，见§7。

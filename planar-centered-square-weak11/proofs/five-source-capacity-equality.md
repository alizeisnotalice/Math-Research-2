# 五个有限源的容量等号与普通饱和分割

日期：2026-11-15。本稿证明：碰撞合并后至多五个正质量源点的容量LP满足P=M，且总能用普通不交饱和标签分割实现容量等号。不需要非整数分数权。一般有限N的等号仍开放；本稿不提出新的C₂界。

## 1. 对象与分数完美覆盖的准确等价

设互异源点p_j∈R²，质量m_j>0，M=Σ_jm_j，阈值λ=1。Q(x,r)=x+[-r,r]²是闭轴平行正方形，两轴共用半径。对非空源标签S定义

    W_S={(x,r):r>0, Q(x,r)恰捕获S, 4r²<m(S)},
    c_S=sup{4r²:(x,r)∈W_S},   m(S)=Σ_(j∈S)m_j.

只保留W_S非空的标签。称c_S=m(S)为饱和。令

    P=max Σ_S c_S z_S,
      z_S≥0,  ℓ_j:=Σ_(S∋j)z_S≤1.

标签有限、每个z_S≤1，故最大值存在。准确恒等式

    M−Σ_S c_Sz_S
      =Σ_j m_j(1−ℓ_j)+Σ_S(m(S)−c_S)z_S

说明P≤M，且P=M当且仅当饱和标签超图存在非负分数完美覆盖：每个源点的负载恰1。普通不交饱和标签分割是更强的充分条件。重合源可先相加质量：任何incidence同时捕获或排除整组，源负载条件重复，合并不改变P或M。

这里等号是连续严格半径的supremum容量LP等号。实际非零严格见证的目标B仍小于M；有限饱和分割只能让严格见证目标任意逼近M。特别地，本命题没有给halo面积新的估计。

## 2. 三个基础几何事实

**最后退出引理。** 设Q_ℓ为随ℓ>0递增的闭正方形族，边长ℓ。假设每个源点在某个固定临界边长进入并永久保留，允许永不进入；至少一个正质量源在每个ℓ>0均被捕获。则存在饱和标签S，由该族中一列边长逼近实现。

证明：F(ℓ)=μ(Q_ℓ)−ℓ²在小ℓ时正、大ℓ时负；质量项是只有有限个向上正跳跃的阶梯函数。令ℓ_*为最后正值区间的右端。它不能是进入跳跃：左侧正值序列给左极限非负，正跳跃将使右侧仍严格正。故它是某个恒定标签层内部的零点，m(S)=ℓ_*²；从下方逼近给严格exact-incidence见证。允许零点先遇跳跃、负区间后重新变正等情况，因为所取的是最后退出。证毕。

固定中心p_j、边长ℓ的同心方形满足此引理，所以**每个源点属于至少一个饱和标签**。若至多一个单例不饱和，取包含该例的饱和标签，其余点用单例，即得普通分割。

**空象限事实。** 若以p为顶点的某个闭坐标象限不含其他源，在此象限内取p为角点、任意边长的方形就可隔离p，故其单例饱和。反过来，不饱和单例的四个闭坐标象限都含其他源。

凸包顶点都有这种空象限：取严格暴露向量n满足n·(q−p)>0对其他源成立，取坐标符号s_i使n_i s_i≤0。对应闭象限上的点都满足n·(q−p)≤0。因而所有凸包顶点单例饱和。

**共线及单侧扩展事实。** 非轴平行直线上的每个源都有与该直线只交于自身的闭坐标象限，因此所有单例饱和。水平共线时，从最左未处理源x_i开始用

    Q_ℓ=[x_i,x_i+ℓ]×[y₀,y₀+ℓ]

作最后退出，得饱和前缀，删除后重复；以前删掉的点全在x_i左侧，不被新方形捕获。垂直情形交换坐标。这证明所有共线源都有普通饱和分割。

同理，若除至多一个源外全部在同一轴平行直线上，沿直线作上述前缀分割，并把方形的垂直方向选为背离线外源的闭半平面。线外源不会进入；线外源本身有朝外的空象限，单例饱和。故此情形也有普通分割。

非共线且N≤4时，至少三个凸包顶点意味着至多一个单例可能不饱和。因此N≤4也已解决。以上事实完整处理碰撞合并、共线退化以及有限阈值边界。

## 3. 五点情形的规约

只需考虑五点非共线且恰有两个不饱和单例p,q；否则由§2处理。余下三个点称为守卫点。至少三个凸包顶点都是饱和单例，所以三个守卫确为全部凸包顶点，特别地它们单例均饱和。

p和q的四个闭坐标象限均含其他源。下面用这一必要条件完全分类所需的几何。只作平移、坐标反射和两轴交换，不作改变方形几何的非等比缩放。

## 4. 两异常点不共享坐标：全源标签饱和

可设p=(0,0)、q=(a,b)，a,b>0。取守卫s位于p的西南闭象限，守卫r位于q的东北闭象限；两者必不同。记第三个守卫为t。

在p处，q和r均严格东北。p的西北与东南象限必须由s,t覆盖；若s在严格西南，则t须同时在西北与东南，其交集仅p，违反源点互异。故s在p的西轴或南轴。交换两轴可设

    s=(-s₀,0),  s₀>0.

于是t必须在p的东南象限，尤其t_y≤0。在q处，p,s严格西南，t不可能在西北（因为b>0）。故r同时位于q的东北、西北象限，即r_x=a；r≠q给r_y>b。而q的东南象限只能由t覆盖。因此几何被迫成为

    p=(0,0), q=(a,b),
    s=(-s₀,0), r=(a,b+r₀), t=(a+t₀,-v),
    a,b,s₀,r₀>0,  t₀,v≥0.                         (1)

包括t₀=0或v=0的边界，不要求一般位置。全源的两坐标跨度为

    D_x=a+s₀+t₀,  D_y=b+r₀+v,  D=max(D_x,D_y).

对任意0<ℓ<D_x，可取长度ℓ的闭横区间，严格包含于(-s₀,a+t₀)且包含0；再取长度ℓ、包含0、上端在(0,b)的纵区间。乘积方形恰捕获p：s,t被横区间排除，q,r被纵区间排除。故

    c_{p}≥min(m_p,D_x²).

同样，对任意0<ℓ<D_y，取长度ℓ的闭纵区间严格包含于(-v,b+r₀)且包含b，再取长度ℓ、包含a、左端在(0,a)的横区间。s,p被横区间排除，r,t被纵区间排除，恰捕获q，故

    c_{q}≥min(m_q,D_y²).

两个单例都不饱和，迫使m_p>D_x²、m_q>D_y²。因此

    M> D_x²+D_y² ≥ D².

以全源bbox中点为中心，边长由下方趋近√M，且始终大于D，便精确捕获全源并满足严格门槛。全源标签饱和，单块分割成立。特别地，若M≤D²，两个不饱和单例必共享一个坐标。

## 5. 两异常点共享坐标：半平面分割

设p=(0,0)、q=(a,0)，a>0。p的西北、西南象限需要x≤0的守卫；q的东北、东南象限需要x≥a的守卫。这两组守卫不交。

若两侧都没有y=0的守卫，则左侧需要两个不同守卫分别位于正、负y，右侧也需要两个，至少四个守卫，矛盾。因此至少一侧存在轴上守卫。必要时反射x并交换p,q，可设左侧有s=(-s₀,0)，s₀>0。

若右侧也存在轴上守卫，则至少四点位于水平线，由§2的单侧扩展事实完成。否则右侧东北、东南需求必须由其余两个守卫承担，因而

    g_+=(x_+,y_+), g_-=(x_-,y_-),
    x_+,x_-≥a,  y_+>0>y_-.

方形[-ℓ,0]×[0,ℓ]在0<ℓ<s₀时恰捕获p，所以c_p≥min(m_p,s₀²)。p不饱和给m_p>s₀²。于是同一族在ℓ从下方趋近√(m_p+m_s)>s₀时恰捕获{s,p}：q,g_+,g_-均在正x半平面而被排除。因此{s,p}饱和。

再考虑

    Q_ℓ=[a,a+ℓ]×[-ℓ/2,ℓ/2],   ℓ>0.

这是嵌套的合法方形族，永远包含q、永远排除s,p；g_±若进入，只向上增加捕获质量。最后退出引理给某个饱和T，满足q∈T⊆{q,g_+,g_-}。T外的守卫单例饱和。因此{s,p}、T及剩余守卫的单例构成普通不交饱和分割。

§4和§5穷尽两个不同异常点的相对位置，完成N≤5定理。一般P<M反例若存在，合并后至少需要六个不同正质量源。此处并未证明N≥6的普通分割或分数完美覆盖。

## 6. Balanced超图假设并不成立

不能直接假定饱和标签关联矩阵是balanced矩阵（即无奇数阶、每行每列恰两个1的方子矩阵）。取三点

    (0,0), (2,0), (1,2),  各质量3.

三个二元标签均饱和，容量均为6。对2<ℓ<√6，分别用

    [(2−ℓ)/2,(2+ℓ)/2]×[-ℓ,0],
    [1−ℓ,1]×[0,ℓ],
    [1,1+ℓ]×[0,ℓ]

精确捕获标签{0,1}、{0,2}、{1,2}；边长趋近√6即可。三条二元标签与三个顶点组成三阶奇圈关联子矩阵，故整个饱和超图并非balanced。这只是排除这一结构假设；所有单例也饱和，P=M且普通分割当然存在。

# 第7轮：纵向缩放的分段结构与整个参数族排除

日期：2026-11-15（Asia/Shanghai）。前轮 `23c74a9f0eb778cc82c92a9a0f1d62826665630d` 已推送并核对远端。一般 C₂ 下界仍由第6轮提供，本轮新增结构定理和受限族的严格排除。

## 结构与范围

固定第3轮输入的质量、横坐标和横周期，将全部纵坐标及纵周期同乘 β。对 `β∈[999/1000,1001/1000]`，已证明完整胞元水平集面积 A(β) 连续分段仿射。证明先用统一尾界固定完整源窗口，再包含全部源盒，包括当前未激活的盒；横端点不动，纵端点形如 `βc±sqrt(M/4)`，完整端点次序确定各仿射区间。

[理论稿](../proofs/vertical-scaling-chambers.md)给出严格门槛、周期边界、退化接触和代数输入假设。其第7节记录理论写作时的计算范围；本轮随后完成下述全盒和参数区间计算。这里尚未枚举全部精确代数接触点，未确定精确最大参数。

## 全参数族认证

准确有理内外半径构造所有 β 的接收矩形。对每个闭参数子区间，把每条纵端点在区间上的极值作为单盒包围，再算矩形并面积，得到对区间内**每个** β 有效的上界；它不是两个端点面积的最大值。

604次二分后形成605个叶区间，全部保留，包括481个剪枝叶和124个活跃叶。最佳参数为 `131072001/131072000`，其内界与全族上界分别是

\[
\frac{987667890573390915392448042207372452669953042610510993381017279307}
{580029066880618331372585843329025756055562354688000000000000000000}
\le\sup_{\beta\in[999/1000,1001/1000]}\frac{A(\beta)}m
\le U_{\rm vert}:=
\frac{12345848703507942316369700743488547218109639108470777925864599229}
{7250363336007729142157323041612821950694529433600000000000000000}.
\]

阅读用区间为 `[1.7027903375343652,1.7027903473739487]`，认证宽度约 `9.83958e−9<1e−8`。第4轮一般下界减 U_vert 的准确值为

\[
\frac{15872342571145128158571724265648308331465098027014558389571}
{7250363336007729142157323041612821950694529433600000000000000000}>0.
\]

因此整个指定纵向缩放族都严格低于已知一般下界，不能在此族内形成趋于 C₂ 的极值列。此排除不涉及区间外 β、质量变化、横向变化或扩大周期原子数，U_vert 不是一般 C₂ 上界。

## 实际独立验证

主计算以 Python 3.15.0 标准库运行，完整初始化18.120秒，604次二分连同初始化共127.643秒，按准确误差目标结束。生成完整固定窗1016个原子、2,329,036个坐标盒；原实现保留55769个可能盒。先前五个有理参数点与原周期算核的内外面积逐分数一致。

独立检查器使用行质量累加及活动区间并面积，从原始 R3 输入重建全部族盒，安全筛选后留下6811个可能贡献盒。它没有调用主程序的族类、前缀和或并面积函数，未重跑分支搜索，而是逐一复算605叶：全部上界准确相同，最佳点内界也准确相同；耗时99.408秒。另有4个退化、跨周期、新激活及内部面积高于两端的独立小例通过。

证明、程序和全叶证书经[独立审查](../reviews/vertical-scaling-review.md)通过。最佳点还用原两套完整周期程序重算并一致。13MiB可再生族缓存留在 CodexTemp，公开归档605叶最小证书、独立复验结果、最终脚本和准确输入。

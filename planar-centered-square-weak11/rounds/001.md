# 第1轮：51原子周期输入的完整水平集认证

日期：2026-11-15（Asia/Shanghai）；计算开始于11月14日。T2 基线提交：`86709667247a9e8563b996a7d422bd7272c0372a`。

## 本轮问题与结论

原第4轮的51原子周期输入提供一般 L¹ 下界，但其有限见证并尚未认证为完整水平集。本轮固定该准确输入、λ=1，证明全半径尾界与有限枚举完备性，计算胞元内真实严格水平集的有理内外包围。

令 R₅₁ 为该固定周期输入的胞元水平集面积除以胞元质量。两套独立计算给出
\[
\frac{4629593106418826487624326959763271900003966948610305702577}
{2718886251002898428308996140604808231510448537600000000000}
\le R_{51}\le
\frac{4629593106439743895915565913648976073008324699549563515077}
{2718886251002898428308996140604808231510448537600000000000}.
\]
显示为 `[1.7027535097178624773..., 1.7027535097255558511...]`。准确宽度为
\[
\frac{35699043483714481298268455260770561603}
{4640232535044946650980686746632206048444498837504}
\approx7.693373815665617\times10^{-12}.
\]

左端精确等于旧 L₄，**本轮没有改善一般 C₂ 的数值下界**。新结果是：对这一完整周期输入，在当前阈值下，旧有限子证书遗漏的真实比值至多为上述宽度。右端只约束 R₅₁。

| 结论 | 范围与证据 |
| --- | --- |
| 所有 r≥5 都不能成为严格见证 | 每个中心、连续全部半径；解析计数界加准确分数 |
| 完整水平集为有限坐标盒接收矩形的并 | 指定周期输入；自足解析证明 |

| 有限原子不能实现一般常数 | 反射论证已独立文本核查；不提供趋近速度 |

## 实际验证与复现

准确尾界 g(5)<1 将全尺度归约到 r<5。窗口1016个不同原子位置、109×29个坐标，枚举2,329,036个闭坐标盒；裁剪后6811个内框，去重后内外各6398个矩形。

- 主程序：Python 3.15.0，二维整数前缀和加线段树并集，bits=40，最终运行约0.957秒。
- 独立程序：Python 3.9.6，逐列累加质量加活动区间条带合并，最终运行约2.367秒；两个完整矩形集合及全部准确面积逐项一致。
- 主程序7项测试通过。独立程序18个小例核对全子集与坐标盒、条带与坐标格面积，包含碰撞、根号相等、退化框和内空外非空；随机部分固定种子20261114。
- 本机 Wolfram Language 15.0.0 批处理实际核对六项准确符号命题，全部 True，退出码0；不把这些标量检查称作全几何形式化。
- 主工作区再次运行测试及保存结果的一致性检查，通过。其作用不等于再次运行全部独立枚举，记录分别保留。

复现命令和输出分类见 [计算说明](../computation/README.md)。最终代码、最小输入、软件版本、准确参数、紧凑输出及来源 SHA 已归档。可再生的大矩形数组保留在 CodexTemp，未提交。

## 失败路线与下一轮

旧有限见证并与完整水平集之间的未计入收益很小，因此不能通过“补漏旧见证”获得显著的新下界。下一轮改变实际输入，优先检查守质量、位置和周期扰动的完整水平集；正方向必须重新认证，有限方向无增益不能称局部最优。

一般输入的精确 C₂ 仍开放。旧一般上界 `C₂<3.590865312933` 的来源状态保留，本轮没有重跑其核条件；未从周期上界或有限原子非达性推出任何匹配一般上界。

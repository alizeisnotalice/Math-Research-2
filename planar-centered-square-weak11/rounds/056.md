# 平面中心正方形弱(1,1)：第56轮 共同背景的比例预算障碍与残差接口

日期：2026-11-15（Asia/Shanghai）。本轮证明一个限定输运预算类的准确障碍，提出保留空间重叠的残差接口；没有新的 C₂ 数值界，精确常数与匹配极值列仍开放。

## 实际捕获质量的比例预算不可能一致成立

对非负 L¹ 输入和严格阈值 1，在接收集 Ω 的每个点，从所有真实共同半径严格见证中允许任意可测选择或概率混合；每份接收需求按该见证正方形内的实际总源质量成比例分配。源点负载取相对于源测度的本性上确界。此类包含所有确定性选择、重叠与随机混合，但不包含一般的非比例空间分配。

令 L=16·2ⁿ（n≥1），D=[−L,L]×[0,L]，A=[−1,1]×[0,1]，f=1_D+1_A，Ω={(s,t):4≤t≤L/4, |s|≤t/2}，S=[−1,1]×[1,2]。这是有界紧支撑 L¹ 输入；r=t 为真实严格见证。每个严格见证都包含正面积公共源块 S，故任何上述比例计划的最大负载至少 8n/99；该下界随 n 无界。即便只强制每份需求中固定正比例 θ 用这一规则分配，其负载也无一致上界。每个见证方块都不越过 D 的左右及上边界，其实际捕获支撑的 bbox 恰为 Q∩D，且 μ(Q∩D)=μ(Q)；因此障碍也适用于此例的真实捕获 bbox 总质量与共同半径。该结论不排除非比例源分配或其他一般上界证明，也不声称已得到原子离散化。

更精确地，设 R(t)=(t+√(t²+4))/2，则限定接收集上全部此类计划的负载下确界为

    J*(L) = [ (1/4) log R + 1/(16R⁴) ]_{R=2+√5}^{R=R(L/4)}.

严格见证使下确界不被达到；选 r_k(t)=t+(1−1/k)(R(t)−t) 的合法见证序列可趋近它。公式只针对指定 Ω，不能写成完整 halo 的最优值。完整解析证明及量词见 [核心证明](../proofs/shared-background-proportional-budget.md)。

## 保留空间重叠的残差接口

对阈值 λ 和真实 halo H，把 b=min(f,λ)1_H 的接收需求直接由同位置源支付，剩余需求 q=(λ−f)₊1_H；原始源剩余 σ₁=f−b。每个真实严格见证方块满足 σ₁(Q)−q(Q)>λ|Q\H|≥0。若总源容量允许 Kf，K≥1，则剩余容量是 σ_K=σ₁+(K−1)f；保留最后一项不可省略。

对于接收集 E 及其见证方块的并 N(E)，残差分配的必要切条件准确为 λ|E|+b(N(E)\E)≤K∫_{N(E)}f。这里按源并集计数，不能把多方块共同源重复支取。有限已认证 incidence 模型中，如每条单元边可合法提升为源接收点分配，则相应全部切条件充要；一般可测模型本轮只声明必要性。强制同位置基底是额外限制，不保证达到原问题最优常数。

上述 Ω 上 f=λ=1，故其需求由同位置基底支付，公共 S 不再反复收费；这只解除本例对该接口的障碍。两小方形的精确 L¹ 例说明单个方块残差正性不足以推出所有容量一切条件；有关构造和复核见 [残差输运接口](../proofs/round056-baseline-residual-transport.md)。

## 实际核验与来源

[独立审核](../reviews/shared-background-proportional-independent-review.md)及其 [检查程序](../computation/round056/shared_background_proportional_independent.py) 和 [输出](../computation/round056/shared-background-proportional-independent-output.json) 使用 Python 3.15.0、Fraction、无随机数，实际通过 5,855 项几何/常数及 36 项最优值/原函数检查，退出 0；对数浮点检查仅供数值参考。核心作者用 Python 3.13.18 和 SymPy 1.14.0 实跑 [八项符号恒等式](../computation/round056/shared-background-symbolic-output.json)，退出 0，输入见[最小输入](../computation/round056/shared-background-minimal-input.json)。[残差接口检查](../computation/check_round056_baseline_residual.py)实际核对 12 个顶点与 36 个楔形见证；容量一残差小例的准确亏损至少 1849/2500。独立审核者另绑定[两份证明的最终版本](../reviews/round056-binding-review-receipt.md)，并实际用 Fraction 核对残差小例；有限检验不代替解析证明。准确 SHA 和完整材料见本轮[统一清单](../computation/results/round056-integration-manifest.json)。R50 已冻结材料只读复用，未冒称重跑。

剩余问题是证明有用的重叠邻域切预算，或构造可释放部分同位置基底的其他分配；这些接口均未建立匹配的一般上界。本轮文件由主代理整合、提交与核验推送。

# 第5轮：有限源对偶的完整容量与方法边界

日期：2026-11-15（Asia/Shanghai）。前轮提交 `eacc1e9f187d136ac5cdbea9bbf8c4c22ab44cda` 已推送并核对远端。此轮不改变一般 C₂ 的上下界。

## 严格接口

固定任意 N 个不同位置的正原子，按严格正方形见证实际捕获的源集合 S 定义容量 `c_S=sup 4r²`。这些容量来自全部连续半径和中心，并非有限采样菜单。源上负载≤1的见证目标上确界等于有限 LP

`P(μ)=max Σ c_S z_S`，其中 `z≥0`、`Σ_{S∋j}z_S≤1`。

证明给出：对任意 ε∈(0,1)，至多 N 个实际严格见证可以实现至少 `(1−ε)P(μ)`，且 `P(μ)≤μ(ℝ²)`。容量端点一般不被严格见证取得，单原子已足以说明这一点。详见 [完整证明](../proofs/general-dual-interface.md)及[独立审查](../reviews/general-dual-review.md)。

关键几何不等式 `|H(μ)|≤K P(μ)` 仍未证明；正文证明它与原有限源弱型上界等强。因此本接口不能被称为已改进的一般上界，更不是精确常数的方程刻画。

## 可重现反例与有限检查

构造任意 N 个指定见证方形，其源支持负载 LP 值为4N，而全空间负载 LP 值为4。该差距只针对指定见证族；它否定将支持负载证书原样提升为全空间证书，不否定所有依赖输入的支持负载方法。

两个单位原子说明仅保留单例源盒会漏掉面积 `3−2√2>0`。另给出只见无权交叠关系、置换等变的权重规则的无界损失例。所有反例均明确限制所排除的规则，未声称一般覆盖方法失效。

Python 3.15.0 的准确有限检查实际得出 N=5 时支持目标20、全空间目标4，嵌套例最优4、等权目标116/125。质量探针以 seed=20261115 生成100个五原子准确输入，Python 3.13.18/SciPy 1.18.1 的 HiGHS 仅负责发现候选；有理重构实际认证100个 `P(μ)=μ(ℝ²)`。

审查指出初版只有汇总后，作者实际重跑同一100例并保存逐例输入、容量、正权重和负载。独立检查器随后用不同的中心区域容斥方法认证全部482个正容量，再准确核对100份目标与负载，未调用原容量枚举函数、未用 LP、未重跑随机搜索。独立复验耗时约0.123秒。另有4个连续门槛/退化小例通过。

100例没有发现 `P<M` 不是通用等式的证明；也不能把容量 LP 取等写成实际严格见证取等。当前通用 `P=M` 仍开放。

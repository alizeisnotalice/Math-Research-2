# 第2轮：完整几何上的第51原子位置改进

日期：2026-11-15（Asia/Shanghai）。基线为第1轮提交 `0edaa3c61469e3842819e55376ab6a04fb201d7d`，已推送且远端 main 哈希实际一致。

## 结论

保持周期、全部质量及前50个原子不动，把第51个原子移动
\[
\Delta x=-\frac{149}{51200}P_x,\qquad
\Delta y=-\frac{1587}{512000}P_y.
\]
对新输入的完整周期水平集重新计算，并传递到有限 L¹ 输入，得到
\[
C_2\ge L_2=
\frac{2314835849133269232486614994466899569639517189976392890351}
{1359443125501449214154498070302404115755224268800000000000}
=1.7027824156155194\ldots.
\]
相较旧 L₄ 的准确增益为
\[
\frac{67065043380887337730584892183244181390874745583}
{2320116267522473325490343373316103024222249418752000}
\approx2.89058976568\times10^{-5}>0.
\]

新输入完整周期比值的认证外界约为1.7027824156231863。它与 L₂ 的窄包围仅说明这个输入的计算精度；一般输入上界仍沿用原来源 `C₂<3.590865312933`，本轮未重跑其核证书。精确 C₂ 尚未确定。

证明及有限误差见 [下界传递](../proofs/round002-lower.md)，最终输入见 [准确配置](../computation/inputs/r002_final_0475.json)，独立审查见 [复核记录](../reviews/round002.md)。对每个整数 N>6，显式平滑输入的比值至少 `(1−6/N)²L₂`，不是直接把周期测度代入 L¹ 定义。

## 搜索与实际算力

第1批冻结924个任务：三档步长下的守质量搬运、单原子位置变化及两方向周期缩放。最优中间候选0302仅将第51原子的 y 减去 P_y/1000，已独立认证。

随后固定其余输入，运行第51原子的局部33×33网格、全胞元32×32粗网格及原基线，共2114个去重点；依预先约定的严格改善规则，再做三批各1089点、步长逐次除以4的细化。全部6305个任务完成，零错误。最终是 batch3 的0475号候选。

所有任务都重新计算完整水平集，精确检查尾界、源窗口和候选的严格面积包围。排序使用准确分数，显示小数不参与比较。本轮没有证明连续位置参数上的局部或全局最优，也没有把粗网格阴性当成排除证据。

本机12核、16GiB内存；各批使用12个 Python 工作进程。五批累计墙钟约968.73秒，累计子进程 CPU 时间约10418.22秒。一次实际采样合计1140% CPU、驻留约461MiB；不能据单次采样声称每个时刻均100%利用。各批资源和来源身份见 `computation/results/round002/search_ledger.json`。

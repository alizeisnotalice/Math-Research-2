# 第13轮：超胞元质量支配的全尺度尾界

日期：2026-11-15（Asia/Shanghai）。本轮建立并核验可改变标签质量的超胞元输运接口；它提供后续候选计算的充分尾界，**本轮不提出新的 \(C_2\) 下界**，也不证明超胞元或一般输入的最优性。

## 引理和接口

基线周期原子质量均严格为正，目标超胞元对每个基线副本保留一一对应的完整标签，目标质量非负且不全为零。对每个标签选固定的超周期 lift，使位移的无穷范数不超过 \(\delta\)，并以准确分数取 \(\kappa=\max(w'/w)>0\)。质量不要求守恒。对所有中心和半径，逐标签比较给出
\[
\nu(Q(x,r))\le\kappa\mu(Q(x,r+\delta)),\qquad
\frac{\nu(Q(x,r))}{4r^2}\le\kappa G_\delta(r),
\]
其中
\[
G_\delta(r)=\frac{m}{P_xP_y}
\left(1+\frac{P_x+2\delta}{2r}\right)
\left(1+\frac{P_y+2\delta}{2r}\right).
\]
若 \(\kappa G_\delta(R)<\lambda\)，严格水平集没有半径不小于 \(R\) 的见证。目标比值及有限块平滑使用目标**实际总质量**，不能替换成 \(\kappa\) 倍基准质量。证明、严格门槛、碰撞和周期绕回的处理见 [supercell-mass-domination.md](../proofs/supercell-mass-domination.md)。

[新算核](../computation/periodic_halo_dominated.py)在碰撞合并之前检查完整标签、周期、质量、lift 与 \(\delta\)，以逐标签准确比值计算 \(\kappa\)，并输出实际目标质量及尾界余量；质量守恒仅在显式选项启用时另行检查。其 SHA256 为 `a697093e30172da71528dc3668add00ea4083811cc2b69ef3a0fc9942eded5e3`；已审基础输运核为 `491edb2b6e4763dad22214d16032139c63cb0d59d8427f2cd1694e86e71bd5e9`，逐字节差异见 [transport_to_dominated.diff](../computation/results/round013/transport_to_dominated.diff)。

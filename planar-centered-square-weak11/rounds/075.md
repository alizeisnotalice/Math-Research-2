# 第75轮：全尺度耦合帽与连续双外原子支付

日期：2026-11-16（Asia/Shanghai）。对象仍为二维、中心、轴平行正方形、共同半径、严格阈值1。本轮一方面严格否定把 R74 无帽单外原子半质量支付直接推广到两个外原子；另一方面保留完整内部网格的位置和全部边长的容量帽，得到任意 n≥3 的正交两外原子精确质量多面体，并证明 n=3 正交等质量族的整个连续参数域满足真实单角支付。由此得到一个可含多个角区外源对的合法共同输入结构类，其完整删除面积至多86/27<7/2。任意外源的四角预算、一般均匀网格的7/2目标及精确 C₂ 仍开放；已归档一般上下界未变。

## 1. 无帽半质量推广严格失败

取内部 σ=δ_(0,0)，外部 ν=4δ_(-2,0)+4δ_(0,-2)。在整个西南象限 O 中，保留全部7个 full 标签和全部3个 residual 标签，真实删除为

    |[H(σ+ν)\H(ν)]∩O|=4√2+√5/2−25/4>1/2。

准确值约.524888238242275；例如 √2>707/500、√5>559/250 给出面积>131/250>1/2。生产核用两个不同的72-bit定向面积算法得到一致的端点整数，独审另用符号根式的水平分片重建。它不是有限采样推断。

完整几何中，内部 singleton 贡献1/4，两个混合 pair 的外伸部分共同贡献√5/2−1，triple 在扣除全部残余后贡献4√2−11/2。遗漏 triple 会低估，而仅扣残余 singleton、遗漏残余 pair 会高估。因此 R74 的“内部东北质量压到原点，然后使用无帽半质量支付”不能直接用于两个有效外位置。

[反例与资格证明](../proofs/r075-two-outside-obstruction-and-global-cap-qualification.md)还解析处理 d≥2 的族 ν=d²δ_(-d,0)+d²δ_(0,-d)，得到真实象限面积极限5/4−1/√2>1/2。该极限来自闭式分解，没有额外计算 d=4、8 或进行随机搜索。d=2 的内部单原子不是完整输入的最大块，该无帽反例不是主课题的合格反例。

把位置缩小到1/3、质量缩小到1/9，并补回完整 S_3 后，两个外原子位于 (−2/3,0)、(0,−2/3)，各质量4/9。所有单位窗容量确实通过，但闭平方窗 [−2/3,4/9]² 的质量为4/3，大于边长平方100/81，缺口8/81。被这个非单位窗捕获的额外内部点虽然不在有效角区源窗口内，仍对同一个外源质量向量施加必要限制。另一个独立区别是象限与实际有限角区：即使只看缩放后的局部三原子，其真实 Γ_3 面积也小于1/18；不能直接拿全象限反例值当角面积。

## 2. 任意 n≥3 的精确共享质量多面体

令 e=1/n²，h=(n+1)/n²，内部 σ_n 在 {0,h,…,(n−1)h}² 上均匀分配质量1。保留这些原位置，对0<a≤1考虑

    ν=b1δ_(-a,0)+b2δ_(0,-a)，b1,b2≥0，
    C_k=max(1,[a+(k−1)h]²)。

[完整网格帽证明](../proofs/r075-orthogonal-two-outside-full-grid-caps.md)及[不等质量附注](../proofs/r075-unequal-orthogonal-outside-capacity-polytope.md)给出所有闭正方形容量帽的精确等价条件：

    b1+b2 ≤ U_n(a)=min_k(C_k−k²/n²)，
    b1,b2 ≤ V_n(a)=min_k(C_k−k/n)。

两外源共同捕获的内部点是 anchored 矩形前缀，最大边对应的方形前缀控制总质量；单外源则由其 k×n 内部前缀控制。各自可行并不等于可独立拼接，质量和的约束始终保留。

这个最小值还能准确缩成两行。a≤e 时只允许零外质量；e<a≤1 时令 K=1+floor((1−a)/h)，则 U、V 各只可能由最后一个边长不超过1的前缀 K，或紧接着的非单位前缀 K+1 决定。单位侧行随 k 下降，非单位侧行随 k 严格上升。这明确定位了单位窗检查遗漏的那一条决定性容量约束。

等质量 b1=b2=b 时 U_n≤2V_n，单外源行冗余，精确可行条件变为 b≤B_n=U_n/2。对 n=3，B_3 有五段显式公式，两个根式切换点为 α=(3√14−8)/9、β=2√3/3−4/9；特别地 B_3(2/3)=32/81，严格小于无帽反例嵌入使用的4/9。Root 的 Wolfram 核实际验证五段最小值公式、切换点次序和四个边界等式。一般 n 的两行化及不等质量多面体由解析证明承担。

## 3. 一个完整连续参数域的真实角支付已证明

对完整 S_3、等质量正交对 ν=bδ_(-a,0)+bδ_(0,-a)，在全部容量条件0<a≤1、0≤b≤B_3(a)下，定义 Γ=[−1/2,−1/9]²。本轮严格证明

    |[H(σ_3+ν)\H(ν)]∩Γ|<1/18。

这保留完整 S_3 的容量约束；角区几何再由 R74 精确局部化化为内部原点加两个外原子。四个含内部点的 full 接收矩形，减去三个完整 residual 接收矩形，全部裁剪到 Γ，给出真实差集。没有把整个西南象限当作 Γ，也没有把 residual pair 或 triple 混合标签丢掉。

[参数证书与结构类推论](../proofs/r075-certified-orthogonal-corner-payment.md)使用闭根参数盒 [1/9,1]×[0,4/9]。每个参数盒先按单调上界 B_3(a_U) 去掉不可能的质量带，再用所有参数共同的 full 外包与 residual 内包给统一面积上界。完整树只有71节点、35次二分、36个认证终端盒、7条容量剪带，最大深度9，没有未决参数。

所有终端盒的最大有理上界约.055378587515263，严格小于1/18；准确分子分母及正余量已列入证明和摘要。72-bit有理平方根界、矩形并差面积、容量剪带及父子覆盖关系均用准确算术验证。独审不调用生产代码，以水平分片重新计算全部71个节点面积、284个平方根界和572个切片，并完整检查覆盖结构，恢复同一有理最大值。a<1/9 只能 b=0，角面积准确为1/324，补齐剩余退化域。这是覆盖全部连续参数的证书，不是有限参数搜索的阴性结论。

## 4. 对共同输入的四角与完整删除推论

设 n=3，原共同外源 ν 已满足完整 S_3 的所有容量帽。在每个有效角区源窗口 P 内，允许以下两种结构：至多一个任意正外原子；或相对于该内部角顶点、按 D4 反射坐标表示的一对等质量正交外原子。各角的参数可以不同，四个 P 之外仍可有任意有限外源。

限制到单个 P、但保留完整 S_3，只会降低所有窗质量，故仍满足全帽。正交对的参数自动满足本轮精确容量条件；单原子情形使用 R74 的一般支付。由真实全半径局部化，每角至多1/18，四角总计至多2/9。非角区容器面积为80/27，因而

    Δ≤80/27+2/9=86/27<7/2。

这里始终从一个已全局可行的共同输入出发，不是把四个分别可行的角候选拼起来。对只有西南正交对的纯族，另外三角各准确贡献1/324，进一步得到 Δ≤109/36<7/2。上述结论不要求该族的每个参数点都唯一最大、连通或非 terminal；若额外限制到这些域，结论仍成立。

不等质量附注只证明精确容量多面体；本轮面积证书没有覆盖不等质量对，也未覆盖任意两个外源位置或任意 n 的多内部角几何。不能把“容量已准确刻画”误写成这些更大输入类的面积预算已证。

## 5. 实际计算和复核范围

生产反例只计算一个 d=2 输入，保留全部7个 full 和3个 residual 标签，以定向 x-event 并区间和二维压缩网格两算法认证。独审另完成一次符号根式水平分片重建。一般 d≥2 闭式及极限是证明，不冒称另跑其它 d。

单位帽资格核用 Python Fraction 完整遍历225个单位窗中心参数层，保存捕获集合和准确帽余量，并准确核非单位窗缺口8/81及根号有理界。独审全文审查这部分解析证明与源代码/结果，没有重复225层运行。

正交可行族先运行31×31=961个中点作为是否继续认证的决策探针。每点对完整 S_3 加两外源的65个 bbox 帽作有理检查，共62465次；局部真实角面积是浮点，显示最大值约.02743034，仅说明该族值得尝试证书。随后一次参数树构造在约.024秒内完成71节点证明；没有继续细分以追求最优值。独审对保存的整棵树重算，不重新求树，不重跑961点探针。

Root 使用 Wolfram15 验证 n=3 五段容量公式。首次源文件有换行语法错误，未产生成功数学结果；即使 launcher 返回0，也没有把它当作验证通过。修复后的实际运行约1.18秒，五个不等式存在性查询均返回 False，切换点次序与四个边界等式为 True，launcher15038及kernel15058均退出后确认消失。失败源、失败回执、最终源、结果和回执分别保存。本轮没有启动 MATLAB。

全部实际运行都有源代码、最小输入、软件版本、参数、结果及退出记录。核心两个容量证明未另开重复计算：其解析论证由 root 与独审全文检查，Wolfram、生产核和独审执行各在独立组件记账。最终逐文件清单还区分旧依赖的版本绑定与本轮重新计算，不改 R74 已冻结材料。

## 6. 结论与尚未解决处

本轮不能成立的路线已经明确：两个有效外源下，内部质量压到原点后的无帽半质量支付为假。有效替代进展是保留完整网格位置的全 n 精确容量多面体、单位/非单位交界两条决定性约束，以及 n=3 正交等质量族的整个连续参数域真实支付。后者给出含多个角区外源对的共同可行结构类 Δ≤86/27。

一般两外源位置、正交不等质量对的面积预算、更大 n 的多内部角结构及任意有限外源仍未解决。若继续，应沿已得到的共享质量多面体与真实 residual 联合几何推进，而非重新采用无帽 collapse 或只查单位窗。精确 C₂ 和一般上下界保持原状态。

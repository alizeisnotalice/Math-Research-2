# planar-centered-square-weak11：第62轮 耦合整单元源残差与界面跳变曲率证书

日期：2026-11-15（Asia/Shanghai）。数学基线：第60轮正占用核接口；所读来源定位和 SHA256 见本轮 manifest。V1、V2、V3 各自冻结后运行，不覆盖前版代码。本报告只归档 kernel 分支的新证明和五个实际候选。

## 本轮目标与假设

对象仍为二维 Lebesgue 背景、中心轴平行共同半径、全尺度弱 (1,1) 常数 C₂。采用第60轮记号 A=−|D₁|−|D₂|、U=1/(|x₁|+|x₂|)、Q_h=U−P_hU≥0。有限 D4 对称源密度 f=Σa_C1_C，a_C≥0，与 λ≥0 产生 K=Q_h*(λδ₀+f)。必须在每个完整源单元上证明

    R_C(x)=λp_h(x)+P_hf(x)−a_C≥0。

这给出非负合法源以及准确半质量 πh(λ+Σa_C|C|)。完整 D 上 K 的正下界仍是单独的认证任务。本轮不以顶点采样替代整单元源正性，也不以普通 Gauss 求积或 D 采样替代完整 D 认证。

目标是去掉第60轮“每个正基函数分别取下确界再求和”的损失，改用同一位置的完整耦合残差，并通过严格曲率余项覆盖连续单元。已有 midpoint 最优值的严格 C4 反例与 cellinf 4.718867 浮点结果保持冻结，没有重跑。

## 失败路线、反例与未解问题

同参数从 V1 到 V2 再到 V3 的下降，支持“带符号组合及内部界面消项减少当前连续域松弛损失”的判断。它没有达到继承上界3.590865312933，也不是一般核族的最优性或下界证书。五个合法源核仍缺完整 D 上界面比较的认证。

把 V3 子矩形从2分到4分改善有限；固定粗 δ=.125 而将 h 从.15减为.075反而显著恶化。解析机制是 f 在整单元上为常数、g 连续，必须支付单元角点和共享界面的较大密度；δ/h 增大时原点峰与单元角点更不相同。该现象不否定 R60 的逼近定理：定理先固定 h 细化单元，再令 h 下降，未保证固定粗单元减 h 有效。

下一 kernel 轮唯一优先设计是**非均匀 tensor 矩形网格：中心细、外侧粗**，控制源函数中央分辨率并保留有限尾部支撑。同行共享 y 宽度、同列共享 x 宽度时，界面跳变消项继续成立；D4 交换坐标时同时交换矩形宽度，半质量按实际面积计算。这是下一设计，未实现、未运行，当前不启动 V4 或额外网格。完整 D 的正时间积分认证接口已在主证明§6给出，仍需独立实施与实际证书。

一般精确 C₂、匹配的一般上界与合法极值列仍开放。本轮没有改善一般上下界，也没有重新运行继承上界的旧证书。

# 第74轮：角区局部化、单有效外原子支付与多源兼容障碍

日期：2026-11-16（Asia/Shanghai）。对象保持二维、中心、轴平行正方形和共同半径，严格阈值为1。本轮证明一个一般结构类的真实删除面积严格小于7/2：每个角区的有效源窗口内至多有一个正外原子，其余位置可以有任意有限外源，且完整输入仍满足最大 eligible 质量1的约束。任意多有效外原子的四角预算仍未解决；精确 C₂ 及已归档一般上下界均未改变。

## 1. 本轮主定理：保留残余 halo 的实际支付

令 e=1/n²，h=(n+1)/n²，w=1−e，σ_n 在 {0,h,…,(n−1)h}² 上均匀分配质量1。有限正外源 ν 使 S_n 保持最大 eligible 质量1，等价于全部闭正方形的质量帽 μ(Q_R)≤max(1,R²)。记 D=H(σ_n+ν)\H(ν)，Δ=|D|，C=[−1/2,w+1/2]²。

西南角 Γ=[−1/2,−e]² 的每个有效见证半径均小于1/2，其源正方形严格包含在 P=(−1,1/2−e)²。四个 D4 反射窗口两两不交，边界上的原子不能进入这些见证。全 halo 与残余 halo 同时局部化，故 Γ 上的实际 D 精确等于仅用 σ_P、ν_P 得到的差集。检验容量时仍保留完整 σ_n；不能把质量 m_P=floor(n/2)²/n² 的 σ_P 当作局部最大块。

[单有效外原子定理](../proofs/r074-single-effective-outside-corner-payment.md)证明：任意质量 m 的东北象限内部原子测度，加一个正外原子，在西南象限内的真实 halo 差面积至多 m/2，不需要质量帽。把内部质量移到原点只增加 full halo，残余 halo 不变；随后对两个原子的混合见证带直接估计，内部 singleton 贡献至多 m/4，混合新增再贡献至多 m/4。整个论证保留所有残余半径，没有把 full halo 代替删除。

因此，只要每个 P 内至多有一个正外原子位置，就有

    四角实际删除总面积 ≤ 2 floor(n/2)²/n² ≤ 1/2，
    Δ ≤ 3−3/n⁴+2 floor(n/2)²/n² < 7/2。

这里允许 P 之外任意多个外原子；同位置质量先合并。该定理证明了所有 n≥3 的一个结构类，未证明一般外源可以压缩成该结构。完整局部化与后续障碍见[核心证明](../proofs/r074-corner-localization-and-borel-half-mass-obstruction.md)。

## 2. 多源推广必须解决的真实障碍

两个不交窗口的可行外源不能独立拼接。对 S_5，分别添加质量8/25的单原子 (−12/25,6/25) 或 (−12/25,18/25)，两输入各自都有唯一最大 S_5，且连通、非 terminal。合并后，单位窗 [−12/25,13/25]×[0,1] 捕获15个内部原子和两个外原子，质量31/25>1，破坏全局帽。该有限例说明局部源窗口虽不交，跨窗口质量仍受共同约束。

独审另给一个有限 n=3 例：外原子 (−1/3,−1/4) 的质量为3/50。完整输入仍以 S_3 为唯一最大块，但局部 {原点,外原子} 是质量77/450的 eligible 块，大于 σ_P 的质量1/9，准确否定“局部内部块仍最大”的假设。

D4 质量平均确实保留线性容量帽；这与直接拼接不同。上述 n=3 输入与其 D4 平均均可行、唯一最大、连通、非 terminal，却在闭接收格 [−.201,−.199]² 上出现原输入属于实际删除、平均后甚至不属于 full halo 的现象。独审用共同严格见证及全部局部子集验证该格，面积1/250000。它只否定逐点或逐格保留型对称化，不宣称总角面积非凹，也不构成主预算反例。

## 3. Borel 放松严格否定辅助半质量支付，但未否定主预算

对 n=5，取 J=[−1/25,1]²，在 P\J 上放常密度 c=100/111 的 Borel 外源，其他位置无外源。密度小于1使其残余 halo 为空。全部单位窗帽可由144个闭临界顶点验证：每个开参数胞元内旧原子计数固定、密度捕获面积双线性，闭顶点的原子计数支配相邻端点极限。任意边长 R≥1 的正方形中，可以放一个单位子窗包住其捕获的全部内部原子；剩余区域只有密度≤1的外源，因此单位帽推出所有 R 的帽。密度100/111在单位窗 [−13/25,12/25]² 上恰好饱和，不能增加。

64×64 接收格的严格有理上下证书给出

    175099/2048000 ≤ |D∩Γ| ≤ 204723/2048000，
    2/25 < 下界 < 上界 < 631/5000。

即角面积在 [.08549755859375,.09996240234375] 内，严格超过 m_P/2=.08，却仍低于单角主预算1/8+3/(4·5⁴)=.1262。下包有1655个闭格及共同半径严格余量；上包排除2161个格，另有280个格未分类。该例只否定将辅助半质量界直接推广到 Borel 外源。有限多外原子的辅助界和主四角界都没有被它否定。R72/R73 已证明 full halo 减残余 halo 的面积不能通过常规原子逼近直接转移；本轮不作这种转移。

最初32×32中点探针同时查看 n=5,9,17 的候选密度，只有 n=5 随后完成全部帽和面积认证。n=9、17 的探针不附带全帽或面积结论。另一个继承 R72 叶证书的四角裁剪得到旧 Borel 族 n=5 总角面积约 [.16560,.16958]、n=17 约 [.12902,.14036]，均低于各自主预算；n=5 又严格否定更强的 Borel 总角≤4/25。裁剪未新增叶分类或细分，保留 R72 的审查范围：n=5 全分类叶独立复核，n=17 仅完整分割和32个分类叶抽核。

## 4. 有限计算与准确证据范围

生产分支对四个既有有限输入的16个角作局部化对照，新增11次不同的限制输入几何计算，full、residual 和实际差面积的有理区间均一致。随后仅做两个指定 seed 和一个 cross seed 的三方向质量改善批次。单对角 seed 的真实西南角面积约.02231014；双正交 seed 约.02878210；两个小步改善后为.0291471246353845，仍远低于.08和.1262。最终输入为 S_5 加5个正外原子，全部487帽行通过，唯一最大、连通且非 terminal。没有扩大固定源位置优化。

三方向、12个有理线步是最终数学批次；一次末尾 I/O 失败后用未改源代码重跑，故实际执行量为6次 LP、24个线步评估，不是新增 seeds。面积结论来自完整几何的72-bit定向有理区间，LP浮点方向本身不承担证明。

单外原子支付的作者 Python 核实际执行255个一维、4335个二维有理回归，以及 n=3 实际输入的46个闭包、28个 eligible 块检查；连续一般定理由解析证明承担。核心 Borel 最终核实际检查144帽顶点，执行4861个下包事件测试、3733个上包前缀测试。独审从原始坐标重建全部529个点/开区间参数层及1156个角极限，并完整重放1655个下包格和2161个排除格，独立执行3283个必要上界测试。得到相同有理面积区间和最小严格余量2209/284160000。

Root 的1200输入、3进程逆残余信用探针测试另一个候选：在闭 Q=[−1/2,1/2]² 内、中心不属于严格 H(ν) 时，是否 ν(Q)≤4|H(ν)∩Q|。质量缩放和资格为有理运算，面积为浮点；没有比值超过4+10⁻⁶，不能推出一般不等式。补充核准确验证两个对角原子质量8/15、7/15的等号例：两点联合质量等于跨度平方而不 eligible，两 singleton 在闭 Q 内的面积和为1/4，故比值恰为4。该等号依赖闭 Q 计入边界原子，不是角区支付证明。

所有实际运行的代码、最小输入、结果、软件版本与退出记录见组件清单；本轮没有启动 MATLAB。核心证书最终 PID84403、先前下包 PID77691 和探针 PID72264 均 exit0 后确认消失。独审分别记录其三个计算组的真实退出范围，不将源码阅读写成完整重跑。先前下包结果被最终完整重算替代，144顶点和1655下包记录完全一致，保留初版源快照和回执以解释历史运行。

## 5. 本轮结论与未解接口

本轮主进展是“每角一个有效外原子”的一般真实支付定理及完整 Δ<7/2 的结构类。有限拼接和局部最大误认已经有严格反例；Borel 半质量放松也被严格否定。任意有限多外原子的单角≤1/8+3/(4n⁴)、四角总和≤1/2+3/n⁴，以及一般均匀 S_n 的实际 Δ≤7/2，仍然开放。

若继续，最小实质接口应是至少两个有效外原子时的共同残余信用支付：同一外源质量向量满足完整 S_n 的全部帽，混合见证所用质量必须由真实残余面积或角区空缺支付；不能分别最优化各角后拼接，也不能以局部内部质量冒充最大块。单有效外原子的解析估计提供一个可核基例；本轮没有证明逆残余信用候选，也不再扩大固定胞元或固定源数值搜索。

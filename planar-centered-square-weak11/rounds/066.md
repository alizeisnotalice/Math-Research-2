# 平面中心正方形弱(1,1)：第66轮 质量分层恒等式与填充容器的三源障碍

日期：2026-11-15（Asia/Shanghai）。本轮证明分层预算的准确损失就是低容器里的真实空洞，并构造一个连通、非终端、唯一最大块两轴都厚的三源输入，**严格否定固定 theta=3/4 的填充容器选择命题**。同一输入的真实删除小于1，所以这不是原始删除选择猜想的反例。一般C₂上下界未改变，精确C₂及匹配的一般上界／合法极值列仍未解决。

## 一般恒等式及正面几何界

对最大质量eligible块S，记m(S)=L，完整halo为H，删除后的真实halo为R，真实删除D=H\R。低容器C_theta是bbox(S)按半径sqrt(theta L)/2扩张的矩形；高层P_theta是全部与S相交、质量大于theta L的eligible闭包接收矩形之并。theta<1时须保留S本身。

R64的共同严格见证结构给出准确等式

    D\C_theta=P_theta\(C_theta∪R)。

于是令U_theta为右边面积、K_theta=|C_theta∩R|，便有

    B_theta=|C_theta|−K_theta+U_theta
           =Delta+|C_theta\H|。

这里Delta是真实删除面积。B_theta随theta非降，因而对这一准确预算反复扫描theta只会偏向最小容器，不能自行产生一般选择定理。证书不通过可能完全由空洞项造成。定向内／外矩形界必须按差集的方向组合，残余halo须重新按实际剩余源计算。详见[分层主证明](../proofs/r066-layered-high-competition-budget.md)。

另对任一高竞争者T，令a=m(T∩S)、b=m(T\S)，保持原T的bbox，用质量b构造较小接收矩形E_T(b)。它确实包含在残余halo中，并且

    |E_T(m(T))\R|≤|E_T(m(T))\E_T(b)|≤a。

最后一步来自F(t)=(sqrt(t)−u)_+(sqrt(t)−v)_+的导数介于0与1。这是一般解析界；将全部侵蚀环先取并再测量，仍是合法外包。接近临界的双轴bbox还可用接收面积

    (m−d²)(sqrt(m)−e)/(sqrt(m)+d)

来支付，正方bbox时对临界余量呈平方量级。但不能把各T的a直接相加当成L的固定倍数。完整[侵蚀、薄壳和重复容量证明](../proofs/r066-erosion-rim-and-repeated-capacity.md)给出连通非终端的双行族：唯一最大块质量1且两轴均厚，7N/32−1个跨外源高竞争者的a之和准确等于(41/64)(7N/32−1)，随N无界。它否定逐见证容量相加，不否定真实并集预算。

## 三源输入否定固定四分之三容器选择

取alpha=1023/1024、epsilon=1/1024，源为

| 位置 | 质量 |
| --- | --- |
| (0,0) | 1/5 |
| (alpha,alpha) | 4/5 |
| (alpha+1/8,alpha) | epsilon |

前两点组成唯一最大块S，m(S)=1，两轴宽均alpha>3/4。S和后二点组成的eligible边使全输入连通；实际全域非终端余量为6982433/34603008>0。全部七个非空子集可直接核对，高闭包仅有重源单点、S和后二点。

残余singleton halo全在C_(3/4)中，旧信用K=epsilon。重源单点的接收方形在C外的面积为33/80−sqrt(3/20)，从而

    B_(3/4)≥(alpha+sqrt3/2)²+33/80−sqrt(3/20)−epsilon。

用sqrt3>433/250及sqrt(3/20)<97/250，得到严格有理证书

    B_(3/4)−7/2>246397/131072000>0。

因为最大块唯一，这同时否定固定theta的形状预算选择及更强的无形状补偿选择；即使先做连通分解、终端分支和薄轴分支也无法避开它。另一方面，完整halo可用三个明确矩形覆盖，准确得到Delta≤1+1/1048576；生产几何及独立几何的定向完整证书进一步给出

    B_lower≈3.50309040474105，Delta_upper≈0.999688668942791。

因此原始Delta≤3.5L选择猜想仍开放。失败的是把近满bbox扩张里的空洞全部预付，而不是高层矩形的并集计算。证明和最小输入见[三源厚块障碍](../proofs/r066-three-source-fat-envelope-obstruction.md)、[作者输入](../computation/inputs/r066-three-source-fat-envelope.json)。这里的小数只是保存有理区间的摘要，严格结论由上述分数证书及完整区间承担。

较早的[五源形状损失例](../proofs/r066-five-source-shape-loss-obstruction.md)具有唯一薄最大块，只否定不分形状的强条件；它的实际B<1.5。保留这个例子是为了记录强条件失败和真正容器预算失败的区别，不把其结论扩大到厚块分支。

## 实际有限诊断及范围

本轮没有延长R64的固定位置LP。用冻结生产程序对R64最终21点输入、R63的72个结构输入及两个确定性小控制进行分层／侵蚀计算，所有聚合均使用真实矩形并，不把个体面积之和冒称并集。

| --- | --- |
| R63固定结构样本 | 72输入、199个proper最大块；199个B均≤3.5L；181个强补偿通过，18个严格失败，无模糊项 |
| R64最终输入 | Delta≈1.23599351，B≈3.19023669，hole≈1.95424318，U≈0.00076523049，K≈0.063232421875 |
| 原始侵蚀诊断 | 上述199块加R64一块，共200块、1101个高竞争者；83块的环并区间与真实U区间相同 |
| 五源控制 | 完整几何与六项sqrt3闭式相容；薄最大块的强条件严格失败，B仍通过 |
| 三源厚块控制 | 唯一最大块、连通／非终端／厚轴均准确通过；B严格失败，真实Delta严格小于1 |

199块中有46个厚块，连通且全域非终端的32个厚块均通过强条件；这些是指定样本事实，三源控制已证明不能外推一般命题。18个强条件失败里，唯一厚块来自一个独立紧致终端组件；五个连通非终端且全部最大块失败的旧样本均有薄最大块。分类时没有把不连通全域的标签当成真正未支付的厚组件。

R64的五个高闭包含S，另四个跨角竞争者质量约0.995至0.999，但接收矩形各小于1/4000。它们的残余质量低于原bbox临界质量，所以原bbox侵蚀内核为空；小未支付面积来自几何临界余量，不能解释成大残余核支付。83个相同区间也只是一批有限输出事实，不证明一般集合相等。

1101个个体中1074个向外几何区间上端已≤a；另27个上端仅受根界舍入影响，最大超出约3.72×10^−21，所有下端仍≤a。一般a上界由解析证明成立，不能把区间上端的舍入超出写成反例。

作者实际检查包括720个侵蚀有理标量例、旧单行族四个规模、五源31子集、三源7子集及严格有理符号。root对厚双行族N=32,64,…,384实际枚举12例共1,009,644个完整bbox，均通过；Python3.13.18，wall0.144919秒，虽请求12workers，短任务实际使用5个worker PID，均已退出。一般全N结论由解析证明承担，未计算这一族的完整halo面积。

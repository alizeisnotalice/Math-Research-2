## 范围与共同前提

参数以中心为原点，`dz=z-z0`、`dt=t-t0`，限制为 `|dz|≤ρH`、`|dt|≤ρT`。每个原始标签的质量为 `w+μ dt`，x 速度为 0 或 1。中心所有标签质量严格正，完整请求 T 区间质量非负；最终 ρ 另保证质量不低于中心的一半。源副本、坐标类排序及跨度/可达性预筛的有效性继承自被接受的单轴源 slab；旧的固定质量空盒半径没有沿用。周期尾界用总质量的全 T 仿射上界重新核对。

审计接受“源 slab 是冻结枚举器的真实完整输出”作为外部前提。哈希字段本身并不能认证任意手工构造 JSON 的正确性。实际全输入集成须核对源 slab 文件身份和生成记录。

## 空盒扰动界与整数缩放

对任一跨度或裁剪失败条件，令中心有向距离为 `d0=D/(jS)`、速度 `v=u/j`，`j∈{1,2}`，盒质量整数为 M、质量导数整数为 MU，共同质量尺度 W。置 `B=4Wλ_num`，则中心半径平方为

`r0²=min(R², M λ_den/B)`。

设 `q0=d0²-r0²>0`。因 `x↦min(R²,x)` 为 1-Lipschitz，对 `0≤ρ≤1` 有

`|(d0+v dz)²-d0²| + |r²(dt)-r0²| ≤ ρL`,

`L=|v|(2|d0|+|v|H)H + |MU| λ_den T/B`。

所以 `ρ≤q0/(2L)` 保证失败条件仍有 `q≥q0/2>0`。裁剪距离还需保持正号；实现另限制 `ρ≤d0/(2|v|H)`，故 `d≥d0/2`。跨度条件依靠正半径和连续性也不可能跨过零。

整数式 `K=min(M λ_den S²,(RS)²B)`、`Q=D²B-j²K` 满足 `Q=j²S²Bq0`。写 `H=hn/hd`、`T=tn/td`，实现中的整数 L 满足

`L_integer=j²S²B hd²td L`。

因此代码的 `Q hd²td/(2L_integer)` 恰为 `q0/(2L)`。质量导数同中心质量共用 W，前缀和取的是源标签导数的准确周期副本，不是按 bbox 中心质量比例猜测。

每个空盒选择其所有已验证失败条件中最大的有效半径，然后对全部被拒盒取最小半径，方向正确。几何上没有源的零质量盒导数也必须为零；实现显式检查。

## 零裕量、根式与分支

当 `Q=0` 时，仅当 `u=0` 且 `MU=0`，或全请求 T 区间的质量下界已在 cap 上方时，失败的严格条件恒等号成立，可永久排除。其余零裕量盒都收入候选目录，记录为 `empty_equality_wall`，不会因为固定质量时为空而消失。若另一独立失败条件已有正裕量，仍可依据该条件排除。

候选根式保留 `[a,v,sign,q0,q1]`，即 `a+v dz+sign sqrt(q0+q1 dt)`。即使 q0 是有理平方，q1 非零时也未折入常数。cap 分支的非持久中心等号会报错而不出具完成证书；非零 cap 间距用半间距保护。最终再逐候选核对根内量严格正及 cap 分支不变。

本候选目录模块并不排序这些端点。得到正 ρ 与完整盒目录，不等于二维端点顺序单元已经认证。

## 固定位置质量插值引理

固定源坐标、域 `(fl,fr)×(fb,ft)`、阈值 λ 和截断 R。对 bbox 极坐标 `(a,b,c,d)` 定义

`d_B=max((b-a)/2,(d-c)/2,b-fr,fl-a,d-ft,fb-c,0)`。

盒的裁剪饱和矩形具有正面积，当且仅当

`R>d_B` 且 `m_B(t)>4λ d_B²`。

证明：矩形 x 区间为 `(b-r,a+r)`、y 区间为 `(d-r,c+r)`，`r=min(R,sqrt(m_B/(4λ)))`。两个区间与域各有正长度的全部严格条件正好是 `r>d_B`。

若质量关于 t 仿射，两个端点均为空，则在固定的 `R>d_B` 情形下两端质量都不超过同一门槛，故整段均为空；`R≤d_B` 时恒为空。两端均活跃也在整段保持活跃。因此两个完整端点目录的 key 并集覆盖整段；若 key 集准确相等，则活跃目录在整段恒定。

应用到 R52 前，必须核对两个端点使用同一源坐标类/周期副本、同一 λ/域/R，以及质量确为同一仿射路径。仅有两个目录大小均为 26,327 不够，须比较完整 key 集或其规范摘要。若零质量导致源类变化，需先使用共同源超目录。该引理只处理固定 z，不认证任意正的 z 邻域，也不判断原始端点交叉是否在并轮廓上可见。

## 完整质量路径上的位置区间扩展

更一般地，若两个端点质量各自的完整单轴目录已经证明其遗漏盒在 `|dz|≤δ_i` 恒为空，则取共同位置区间 `|dz|≤min(δ_0,δ_1)`。对区间中每个固定 z，以上同一门槛引理说明：在两端候选 key 并集之外的盒，对全部质量插值参数仍为空。因此这两个端点候选集合的并集在整个质量×位置矩形上完整。所用 δ_i 必须是遗漏盒证明的半径，而不是只有源排序保障的 H。

此结论要求在整个共同区间使用同一源类和 bbox 编号，端点遗漏证明引用同一完整源超目录；单凭 active key 相等或几何上源数量一致不能替代该核对。两个质量端点的尾界均严格且总质量仿射，则同一 R 上的统一尾界由端点最大总质量给出。端点候选中的盒在离开中心位置后可以变为空，仍必须保留并进一步认证端点顺序、裁剪和根式分支。

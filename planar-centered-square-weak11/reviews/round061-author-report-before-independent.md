# 第61轮：有限源并集切的正向容量证书

日期：2026-11-15（Asia/Shanghai）。本轮已完成作者证明、准确算核和十二批计算，**尚未完成独立审查**。没有得到新的一般 C₂ 界。

对有限原子输入，保留所有真实共同半径见证能够捕获的源。完整 bbox 的有理内外接收矩形把外包 halo 切成有限胞元；胞元标签 T 是全部内矩形所允许源的并集。准确面积 W_T 给出每个非空源集 S 的上包切 Z(S)=Σ_{T⊆S}W_T。真实闭源切 D(S)≤Z(S)，故全部切的最大比值给出允许非比例分配的正向容量证书。

令 Γ 为所有 bbox 外矩形面积减内矩形面积之和，则作者证明 0≤Z(S)−D(S)≤Γ。原始证书成本与真实最优自由分配成本之差至多 Γ/min_j m_j；固定有限输入下细化端点可趋于零。另由 R53 的局部定理，D(S)≤B max(m(S),d(S)²)，其中 B<3.3。二者取小给出源并集几何证书，紧凑源切 d(S)²≤m(S) 可直接由 B 支付。完整对象、量词和严格见证构造见 [作者证明](../proofs/finite-source-union-cut-certificate.md)。

程序同时保存内 halo 的准确整数非比例输运流。它在合法内矩形源关联上运行；没有把外包边当成真实严格见证。完整 halo 的分配存在性由全部真实切的上包认证推得，未声称存储其含根式面积的显式流。

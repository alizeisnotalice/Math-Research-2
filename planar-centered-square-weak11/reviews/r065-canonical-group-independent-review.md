## 1. 规范组的对象与符号

物理跳变行是相邻源密度右减左／上减下。给网格外密度 ID0 且 a_0=0，非零行的两端轨道 ID 形成规范无序对 `(lo,hi)`，定义 `d_g=a_hi−a_lo`。物理方向若正端是 hi，符号为 +1，否则 −1，故 `d_r=s_r*d_g`。

这个分组依据相同的密度差线性形式，绝非源点距离、矩形宽度或实际数值恰好相近。不同物理函数的位置与横向宽度继续保留在 psi_r 中。外部 ID0 **不是 λ 的变量 ID**：GD 对 `(0,hi)` 只在源密度 hi 列加1，省略外部负列，代码没有误扣原点振幅。

两轨道 ID 相同的行在符号上恒为零，可省略；一个符号非零组若某个候选恰有两密度相等，仍保留其组，它只是该候选的 d_g=0。作者正确区分这两种零。

代码从物理 JD 行的两个非零密度列取 pair，符号取高 ID 列的系数。GD、SG 的每项都为0、±1，且显式断言 `JD−SG*GD` 无非零项。这个整数恒等式正确。

## 2. 两个坐标的真实函数与区间方向

同一组在两个坐标中分别定义

    Psi_g,xx=Σ_(垂直r) s_r*psi_r，
    Psi_g,yy=Σ_(水平r) s_r*psi_r。

源密度差 d_g 可以共享，但两个函数和区间不能混为一个。代码 GX/GY 分开，随后 XP/XN、YP/YN 分别取正负方向，满足该要求。

若物理函数 psi_r∈[L_r,U_r]，则组区间为

    L_g=Σ_positive L_r−Σ_negative U_r，
    U_g=Σ_positive U_r−Σ_negative L_r。

V3 的 `pl'*XP−pu'*XN` 和 `pu'*XP−pl'*XN` 与之完全一致。负号必须交换端点。精确有理反例：`[1,2]−[3,5]` 的正确范围为 `[-4,-1]`；错误地把两个上端直接相减会给上界−3，漏掉真实可取的−1。代码未犯此错。

共同正负部分满足 d_g=dplus−dminus，dplus,dminus≥0，故仍有 `d_g*Psi_g≤dplus*U_g−dminus*L_g`。非最小拆分只增加区间宽度乘额外部分，不要求互补。curvA 的行移项为上界−η≤0，η有非负下界；sourceA 继续使用正确 EX/EY，各向余项方向未变。

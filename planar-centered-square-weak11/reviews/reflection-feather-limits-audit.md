# 极端反射退化附件：Astra独立审读

日期：2026-11-15；审读者 astra_reflection。来源为独立工作区 pcw-sol-reflection-limits，绑定哈希如下。本次从全文公式重新核对，不仅复用作者的 PASS 标签。

- δ 退化例：三个右端确为 1/2、√2/2−t、√2/2；旧 halo 的纵界 √2/2 与四点混合矩形的纵界 1 给新增面积至少 (2−√2)^2。故 δ→0 不代表真实增益趋零。
- 羽点例：D−A>√(2(M+ε)) 排除除羽点镜像对之外的全部跨簇子集，因其源跨度超过全体临界直径；各存活簇 halo 也横向分离。羽点对完整新增面积 k²ε，归一化真实增益为 k²ε/[2(M+ε)]。这是真实面积等式，不只是某个选定见证下界。
- 四方向版本：原/镜像的不同羽点、核心之间，至少一个坐标跨度达到 D−A；只有当前极端的羽点与其镜像例外。相同排除覆盖四个坐标极端。
- 有限 L1 转移：任意严格见证接触的云团标签给外扩 τ 的子集接收矩形；内缩 τ 保证完整捕获。即使原矩形某侧非正，取侧长正部后面积增量仍不超过 4τ√T+4τ²。因此全部 2^K−1 子集的并误差 (10) 正确，包含原来为空而平滑后激活的标签。
- 真正 L1 极端 cη 与原子极端 c 相差至多 η，反射云团距理想反射原子至多 3η。这解释了 (12) 的 3η 参数；(13) 给实际增益上下界，而不是把原子反射轴直接冒充 L1 的最右 halo 轴。
- 固定比值/固定N反例的量词不否定有限N与C2之间的正差距。小羽点极限回到少一个原子的核心，正是主证明删除分支处理的情形；双带增强也未改变这个事实。

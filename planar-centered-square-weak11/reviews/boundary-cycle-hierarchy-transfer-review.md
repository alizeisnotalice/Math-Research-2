## 1. §6：无需 tail 的周期到有限 L¹ 传递

成立。周期输入的截断 halo 只产生一般全尺度常数的**下界**，不需要证明周期大半径不激活。

每个非空内矩形要求 t_I^->0，故 max(0,·) clipping 不激活，并有

    t_I^- ≤ (floor(Ds_I)−1)/D ≤ s_I−1/D.

cap R 激活只会进一步减小 t。空矩形t=0无需余量（此时s可能<1/D；作者已正确限定为非空矩形）。对内矩形每个接收点，全部源的最大L∞距离严格小于t。把原子铺到半宽 ε=1/(2D) 的小方块后，半径 t+ε 捕获整份源质量，且

    t+ε ≤ s−1/(2D) < s,

所以 m_I>4(t+ε)²，严格见证保留。该半径可能略超过R，但目标算子是全尺度M，合法；若目标仍为capped M_R，则需另缩inner cap，作者未如此主张。

q=ceil(R/min(P,T))+1 足以保留源见证；每源与接收点的各坐标距离<R。删去q层接收胞元后，所需源仍在K×K源胞元内。平滑支持可越出外部裁切边界，不损害L¹、紧支撑或质量等式。质量准确K²m，内接收胞元至少(K−2q)²个，每格保留A_D^-面积，式(13)成立。

式(14)用的唯一代数估计是1−(1−2q/K)²≤4q/K。有限矩形并端点收敛给A_D^-→A，不要求D单调，也未调用错误的同层halo面积连续性。由有限D,K的误差预算即得每层L≤C₂。

## 3. §7：密度、有限严格见证与质量舍入

成立。正文的统一正余量可定量展开如下；这是说明强化，无必须修补项。

给f≥0∈L¹与紧K⊂{Mf>1}。固定半径积分关于接收中心连续，因此有限组半径r_i及开覆盖U_i、统一δ>0满足

    ∫Q(x,r_i) f ≥4r_i²+δ  (x∈K∩U_i).

K有界、r_max有限，可取有界盒完整包含这些方块；截断f至该盒完全保留见证且质量不增。支撑相交网格胞数≤C h_n^{-2}；集中到左下角的L∞位移≤h_n，质量步δ_n=2^{-4n}向下舍入总损失

    E_n < C h_n^{-2}δ_n = C2^{-2n} →0.

放大半径至r_i+h_n捕获舍入前全部见证质量；只要

    E_n+8r_max h_n+4h_n² < δ,

就仍严格超阈值。R_n→∞保证这些半径最终<R_n。此处理覆盖K的全部点，未以有限点检查或弱收敛替代halo稳定性。

每格质量≤截断f的总质量，最终<2^n，舍入后属于W_n。含支撑和K的固定盒可经网格整数倍平移放入一周期内部：T_n→∞，P_n可取充分大的h_n整数倍。其他周期副本只增加见证质量，单胞质量m_n≤||原f||₁。因此

    L_n≥|K|/m_n≥|K|/||原f||₁.

正面积K已迫使m_n>0；零面积K下界平凡。紧内逼近加f上确界，结合L_n≤C₂及嵌套，严格推出L_n↑C₂。没有给出统一可计算收敛率。

## 4. §8：跨层势函数的上界充要条件

对任意实z，C₂≤z iff每层G_n存在势p_n满足所有边a_e−zb_e≤p_n(v)−p_n(u)，成立。

固定层的正向沿闭游走求和消去势差，得所有正质量循环ratio≤z。反向：z≥L_n时，所有正质量循环总边值≤0；零质量循环的面积和成本都0，这由闭游走对应周期字串推得，而非假设每条零cost边reward为0。添一个超级源向所有顶点连0权边，p(v)取最大路径值；非正循环可删除而不减路径值，故只需有限条simple paths，p有限并满足所有边不等式。

跨层正向由L_n≤C₂≤z逐层给p_n；反向由所有L_n≤z及单调极限成立。量词只是“每层存在某个p_n”，没有隐藏统一形式、统一维数或一致范数控制。仍含无穷层，作者已准确说明它不是C₂的固定维求解方程。

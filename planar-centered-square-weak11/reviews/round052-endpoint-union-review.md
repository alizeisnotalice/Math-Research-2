## 已认证的结果

在物理 x 位移 `z0=328734960629/100000000000000000`、质量参数 `t0=1/2` 周围，给定完整联合 bbox 证书的 26,327 个矩形具有同一端点全序、裁剪选择及覆盖组合。一个便于引用的闭矩形为

    |z-z0| <= 1/50000000,   |t-1/2| <= 3/5000.

JSON 还给出更大的精确有理半径，十进制展示分别为约 `2.29528874382428e-8` 与 `0.000698218631639448`。所有小数仅作展示，顺序、半径和符号由有理/定向根区间承担。

令 A 为完整基胞 halo 面积、M 为实际基胞质量。认证区域上 `A_z=beta(t)` 与 z 无关；beta 是精确十项平方根加常数：

    beta(t) = -175603458831370317/64000000000000000
              + sum_k c_k sqrt(q0_k+q1_k*(t-1/2)).

全部十项的有理 `c_k,q0_k,q1_k` 保存在 `certificate.json: beta_root_terms`。在中心，

    beta ~= -0.0716436120973465139701927999975,
    beta_t ~= -1.29165726193975463433520175917e-7.

实际 `M_t=0`，故 `J=lambda*A/M` 满足

    J_zt = lambda*(M*beta_t-M_t*beta)/M^2 = lambda*beta_t/M.

中心约为 `-6.12121124481669723896259775929e-9`；整个较大认证闭矩形上位于 JSON 的精确有理区间内，其十进制外观为

    [-6.121211246655691011e-9, -6.121211242977703467e-9] < 0.

这里 z 是物理位移。若使用 `sigma=z/P8`，则 `A_sigma=P8*beta`、`J_sigma,t=P8*J_z,t`，其中 `P8=328734960629/100000000000`。不能把未缩放导数直接称为归一化位移导数。

## 为什么这个小矩形的端点序有效

每个原始 x 端点表示为 `a+v*dz+s*sqrt(q0+q1*dt)`；y 端点的 v=0。恒定有理平方根只在 `q1=0` 时折入 a。即使 q0 是有理平方，`q1!=0` 时仍保留根式身份。中心值归一化相同而完整五元组不同的端点被拒绝；本次真实输入没有这种非持久等号。

在原联合候选证书的基半径 Z,T 上，每个根式的正下界来自 `q0-|q1|T>0`。取有理根下界 rlo，则端点的质量 Lipschitz 常数不超过 `|q1|/(2*rlo)`。对中心排序相邻的 e,f，令 g 为定向区间给出的严格正间隙。将半径按 rho 缩小，使

    rho*(|v_f-v_e|*Z+(L_e+L_f)*T) <= g/2.

故两个端点在闭矩形中仍有至少 g/2 的正间隙。生产程序检查 25,232 个 x 端点、10,821 个 y 端点以及全部 36,051 个相邻间隙，包括所有原始端点和基胞裁剪边。每个候选矩形的裁剪后边长在中心严格为正，端点序不变使其在整个区域中保持正。全部遗漏盒始终为空及尾半径支不变依赖另行审查的联合 bbox 证书；本文件没有重跑遗漏盒枚举。

## 精确导数及独立复核

排序后的相邻 x 区间上，活跃矩形索引固定。令其 y 区间并长度为 U_j(t)，x 端点速度为 v_j，则

    A_z = sum_j (v_(j+1)-v_j)*U_j(t).

由于全部 y 端点序固定，U_j 是固定端点差之和，得到 beta 的上述根式。逐项微分给

    beta_t = sum_k c_k*q1_k/(2*sqrt(q0_k+q1_k*dt)).

`position_mass_endpoint_union.py` 用直接排序/合并 y 区间执行这一定义，不导入生产 UnionTree 或旧端点 sweep。它对 302 个非零速度差区间求和。

独立的 `audit_position_mass_endpoint_union.py` 从 3,953 个已保存周期源重新绑定标签、周期移位、中心质量和位置，以 Fraction 双前缀和重新计算所有 26,327 个活跃 bbox 的质量和质量导数（24,547 个非零），并核对每个原始端点的 q0、q1 与源坐标。它另外采用

    beta = sum_e v_e*(U_before(e)-U_after(e))

这一端点跳跃望远镜式，通过 404 个移动端点的 before/after 并集精确重建同一十项根式。所有 36,051 个最终间隙漂移不等式再次独立核对；160 位 beta 区间包含于冻结的80位固定质量斜率区间。没有重跑 45,633,320 个候选 bbox。

## 原始墙与有效并边界的区别

端点身份交换不保证面积公式发生切换。例如对 `|s|<1/2`，令 A=[-2,-s]x[0,1]、B=[s,2]x[0,1]、C=[-1,1]x[0,1]。A 的右端点 -s 与 B 的左端点 s 在0交换，但 A、B 均与 C 重叠，矩形并始终为 [-2,2]x[0,1]（开闭边界不影响面积）。这个解析例子与脚本有理点控制说明：必须证明穿越位置处的实际暴露覆盖发生变化，才能称为有效 union 墙。

R52 的旧 `t*=0.4372085136...` 原始端点墙在本次局部认证矩形外。本审查既不把该原始墙称为有效墙，也不把局部负混合导数延伸至 t in [0,1]。实际旧墙的遮盖核验由几何审查材料承担。

# 对 `round022-parent/R9_wide_proof.md` 的独立审查

审查对象为主线程的 `R9_wide_proof.md`、其既有
`R9_support_rows.py` 和 `R9_support_rows.json`。本记录只读审查，未运行会改写主线程 JSON 的脚本，也未修改主线程任何文件。

## 结论

审查通过。宽支撑版正确保留了 II 支中常数为零、但行多项式未必为零的
\(A_5,B_1,B_2\)。没有使用已撤回窄支撑稿中“由允许集合反筛未知行”的错误步骤。

## 逐项核对

* 程序的上界集合与 JSON 一致：II0 为
  \(A\subseteq\{0,1,2,5\}\), \(B\subseteq\{0,1,2,3,8\}\)，
  II1 为 \(A\subseteq\{0,1,2,5,8\}\), \(B\subseteq\{0,1,2,3\}\)。
  这些仅由已知低端正项筛出，且主证明未把它们倒用为正性假设。
* I 的两种 t 支以及 III 的两种 t 支的余数配对与 JSON 一致。每个用到的
  \(A_r(0),B_s(0)\) 都来自原低端前缀；尤其 III1 中 \(B_1(0)=0\)、
  \(B_2(0)=1\) 的使用正确。
* II0 的行
  \[
  r_6=A_5B_1=0,\qquad r_7=A_5B_2=0
  \]
  与 JSON 完全一致。若 \(A_5\ne0\)，整环性才推出 \(B_1=B_2=0\)；若
  \(A_5=0\)，证明改用 \(r_8=A_0B_8=R\) 的两种不可分解分配。没有把
  \(A_5(0)=0\) 错写成 1。
* II1 的完整行确含进位项
  \(vA_8B_1,vA_8B_2,vA_8B_3\)。\(A_5=0\) 时，从
  \(A_8B_0=R\) 的两种分配，以非负次数/预算依次消去 \(B_1,B_2\)，随后
  \(vA_8B_3\) 矛盾；\(A_5\ne0\) 时才由 \(r_6,r_7\) 消去它们。最后两种
  \(A_0B_3=R\) 分配分别由 \(A_2+A_5=1\) 和
  \((1+v)A_2=R\) 排除，后者在 \(v=-1\) 给矛盾（\(R(-1)=1\)）。
* 文中对 \(R=1+v+\cdots+v^5+v^8\) 的归一化非负不可分解性可由三低前缀和
  \(c_9,c_{11},c_{10}\) 的零系数自含证明；它只用于常数项为 1 的行因子，未被错误地用于 \(A_5,B_1,B_2\) 等常数为 0 的行。

因此，按当前宽支撑证明的量词范围，\(R(x)R(x^9)\) 的三低端分支均被严格排除为非标准分解。该审查不涉及尚在外部审查中的其他文件或一般猜想。

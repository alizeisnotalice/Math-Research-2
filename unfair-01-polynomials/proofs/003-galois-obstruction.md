# 共轭逃逸与固定次数的系数下界

本节给严格必要条件，不假设共轭保持非负性，也不提供一般猜想的证明。

设 C=AB 的总次数为 N，K由 A、B 的系数生成。第1轮已证这些系数是代数整数。任意嵌入 σ:K→C 对整系数乘积保持不变，因此 A^σB^σ=C；两因子仍首一、常数项仍为1，但其他系数不保证为实数或非负数。

若原嵌入下某个系数 α∈(0,1)，则非零整数范数满足

\[1\le |N_{K/\mathbb Q}(\alpha)|
=\prod_\sigma|\sigma(\alpha)|.\]

故必有某个其他嵌入使 |σ(α)|>1。更定量地，若 D=[K:Q]，则 D≥2 且 max_σ|σ(α)|≥α^{-1/(D−1)}。如果能够独立证明全部嵌入下所有系数的模≤1，就能排除反例；当前没有这一步。

首一二元 C 的 Cauchy 根界给 |z|≤2。对常数项为1的反转多项式应用同一界，得到 |z|≥1/2。设 m=deg A。对其共轭因子根作初等对称式估计，再对倒数根用常数项1，有

\[|\sigma(a_i)|\le {m\choose i}2^{\min(i,m-i)}=:M_{m,i}.\]

K嵌入C的分裂域，D≤N!，因此任何分数系数都满足

\[a_i\ge M_{m,i}^{-(D-1)}\ge M_{m,i}^{-(N!-1)}.\]

同样，1−a_i是非零代数整数，其共轭模≤1+M_{m,i}，故

\[1-a_i\ge(1+M_{m,i})^{-(N!-1)}.\]

这给固定次数的显式严格端点间隔，但界随次数急剧退化，不能将它当作任意次数的一致间隔。

例如 α=(3−√5)/2 是 (0,1) 内的代数整数，最小多项式 t²−3t+1，另一共轭 (3+√5)/2>1，范数为1。此例只说明“代数整数且在(0,1)”本身不矛盾，不声称它属于本题的可行因子。`computation/check_galois.py` 用精确数域核验此例。

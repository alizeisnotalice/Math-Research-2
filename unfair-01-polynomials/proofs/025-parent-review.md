# 第25轮主线程核验记录

## H8 完整精确认证

主线程从归一化系数上界重推首一，重新读取第18轮根幂积平衡引理，核对其二重传递稳定子乘积证明；从3u+2v=E独立重算补集约化计数。验证器由主线程独立编写，从根盘重新计算Fraction区间并仅追踪指定低次系数，不调用搜索器的全卷积或options缓存。不同代理又审阅并实际复跑该最终版本。复制到归档路径后再次运行成功。

证书中的区间端点由搜索结果向外舍入为分母2^40的有理数。独立检查要求 stored_lo ≤ recomputed_lo ≤ recomputed_hi ≤ stored_hi < 0，故压缩不改变严格符号结论。无条件接受搜索器成功标记、将近似端点pin到1、或者只核对保存的数值优选样本，均不是本包使用的验证步骤。

生成器的初版回放脚本不验证根盘和布局来源，因此未列作最终严格验证器。最终版本绑定输入/根盘哈希并重新检验数学关系、母根/提升根群标签和全部布局唯一性。14个反例用临时副本测试，外层hash按测试需要更新；全部被拒绝。生成链实际重建最终证书的SHA与主线程版本一致。

## H10 的8条进位

主线程核对最高v10仍保留的规范坐标(9,10)，故该例允许分裂1+9。两正v次数分支中的X1常数必须为0；v10行迫c=1，再由原因子逐系数≤1迫[u]X1=Y9(0)=1，不能省略潜在的缩放常数。

纯u因子的分组整除已修正。W=1时先由v3/4非规范行不在Y支撑内杀掉两组t=2进位，再杀u12的两项t=3；不能一开始说所有进位u次数都超过10。W=H时使用H整除完整括号且括号次数<10，未从一个和式推逐项整除。

## H16 的10条进位

初稿“deg_v(XY)=16”没有依据，因为两条高v行都可向v3/4转移。该过渡被撤回，不作为最终证明输入。

最终证明仅用干净v0/1/2行。X0=H,Y0=1；HY1+X1=H的非负次数预算给Y1=t、X1=(1−t)H；v2同理给Y2=s、X2=rH。v3/4行右边均含u16，常数项比较即迫两个左侧标量为0；代回迫所有进位多项式为0。最后取双变量UFD因子的非负坐标截面，归约到母式不可分解性。没有复用失效最高行前提。

## 计算证据边界

两进位整数审计只验证固定坐标列表；无界/结构结论由相应解析步骤承担。Hd有限frontier账本的独立验证器另核对全期望键集合及所有实际进位，不把“20,715个二元目标”写成“20,715个目标已排除”。数值GPU包和H8严格区间包分离。

一般猜想、H10(2,3)以及H7(3,4)在本轮仍开放。后继计算或证明未完成前不回写本轮为更强结论。

# H10(x^2)H10(x^3)：8310 根组布局的严格覆盖预备稿

令
\[
 H_{10}(x)=1+x+x^2+x^9+x^{10},\qquad
 C_{10}(x)=H_{10}(x^2)H_{10}(x^3).
\]
本稿为固定目标 \(C_{10}\) 准备独立精确 checker 的数学覆盖说明。它现在
不声称已经排除任何布局；只有在最终有理圆盘与负系数证书到位并通过 checker 后，
才可得到非负分解结论。

## 所需输入

最终证书必须逐项重验以下事实，而非信任数值根表或 options cache：

1. \(H_{10}\) 首一、常数项一、原始、非自反；模 \(7,73,19\) 的平方自由
   因子型分别为 \([10]\)、\([1,9]\)、\([2,3,5]\)。第一型给不可约和传递，
   第二型给点稳定子中的 9-循环，第三型经 3、5 循环的奇数公倍数幂给换位。
   因此 Galois 群为 \(S_{10}\)，特别二重传递。
2. 五个正虚部母圆盘及其共轭经精确 Rouché 不等式和两两分离认证为十个母根；
   每个母根的两个 \(x^2\)-提升、三个 \(x^3\)-提升（以及共轭）认证为
   50 个互异的目标根。
3. 每个 balls 条目与输入中同一 `source_group_index` 的
   `(block,family,lift_index,exponent)`、父圆盘、中心严格匹配。每个 block
   恰有两个 a-lift 及三个 b-lift 槽位。

在这些条件下，第 18 轮根幂积平衡引理适用：对十个母根 \(\alpha_i\)，若
\(\prod\alpha_i^{e_i}\in\mathbb Q^*\)，则所有 \(e_i\) 相等。这个结论
不使用“共轭保持非负性”。

## 从实际归一化因子到必要的根组选择

若 \(A,B\ge0\)、常数项为一且 \(AB=C_{10}\)，因另一因子的常数项为一且
\(C_{10}\) 二元，两个因子的系数均不超过一。最高系数之积为一，故 \(A,B\)
首一。经上面的 50 根分离，\(A\) 的根是一个不重复子集；实系数性又使它是
25 个共轭二次根群的并，\(B\) 取补集。

将十个母根配成五个共轭块。第 \(r\) 块中记所选 a-lift、b-lift 共轭群数为
\(u_r\in\{0,1,2\}\)、\(v_r\in\{0,1,2,3\}\)。把根积取六次幂得到
\[
 \prod_i\alpha_i^{3m_i+2n_i}\in\mathbb Q^*,
\]
所以有共同的 \(E\) 满足
\[
 3u_r+2v_r=E\qquad(r=1,\ldots,5).\tag{1}
\]
这是**必要**覆盖，不是任一选择有非负系数的充分条件。

补集使 \((u,v)\mapsto(2-u,3-v)\)，即 \(E\mapsto12-E\)。空集/全集给
常数因子。对非恒定补集代表，\(E=2,3,4,5\) 的布局数依次为
\[
 3^5=243,\qquad2^5=32,\qquad3^5=243,\qquad6^5=7776.
\]
终端 \(E=6\) 的每块只可取 \((u,v)=(2,0)\) 或 \((0,3)\)；固定首块为
前者以除去补集重复，余四块有 \(2^4=16\) 项。因此精确必要布局总数为
\[
 243+32+243+7776+16=8310.\tag{2}
\]
其中终端 code 0 选取全部 a-lift 群，补集选取全部 b-lift 群；经已认证的根
数和首一性，它应被识别为标准对 \(\{H_{10}(x^2),H_{10}(x^3)\}\)，而不是
由浮点接近性识别。

## 将由最终 checker 验收的符号判据

对提升根的开圆盘 \(D(c,r)\)，实际共轭二次因子为
\[
 (t-z)(t-\bar z)=t^2-2\Re(z)t+|z|^2.
\]
最终 checker 必须用有理闭盒包住其三个系数，以 `Fraction` 乘法重算每个布局
和补因子的指定系数。若认证区间上端严格小于零，则实际首一根积对应系数严格负。
正的常数项归一化缩放不改变符号，故足以排除实际非负因子。反之，未知、失败或
非严格 \(\le0\) 的区间绝不登记为排除。

因此，只有在 8309 个非标准布局都获得这种严格负证书、且唯一剩余项通过标准族
识别后，才可宣称固定 \(C_{10}\) 的归一化非负分解仅为常数或标准分解。

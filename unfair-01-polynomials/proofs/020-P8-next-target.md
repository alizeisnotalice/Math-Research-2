# 八次母多项式的精确搜索前提

令P(x)=1+x²+x³+x⁴+x⁶+x⁷+x⁸。独立整数Rabin核验给出完整模素数分解型：模2为[8]，模3为[7,1]，模5为[5,2,1]。因此P在Q上不可约，群传递且含一个7循环，进而二重传递；[5,2,1]元素的五次幂为换位，二重传递共轭给所有换位，所以Galois群S8。完整因子证书与逐项验证在020-P8-galois-certificate.json及verification中；Frobenius循环型依赖沿用已核验的Conrad来源。

P非自反。在负实轴有自包含恒等式

P(−y)=1+(y²+y⁶)(1−y+y²)>0（y≥0），

因为1−y+y²=(y−1/2)²+3/4；正实轴显然严格正。因此八个根恰分成四个非实共轭对。

对L>8，P(x)P(x^L)的支撑为无碰撞直和，所以目标二元。第18轮根幂积定理可直接应用：每个母根选取数必须满足Lε_i+m_i=E相同。实因子按共轭对选择，故非恒定补集代表数为

Σ_(E=1)^(L−1) binom(L,E)^4 + 2³。

最后2³来自E=L各块选原组或全提升组，并固定第一块为原组以消除补集对称。L=9共有607,041,386个代表。这个必要条件只减少数值搜索，绝不是系数非负或公平性的充分条件。

由第17轮S8根子集刚性，P自身没有非平凡归一化非负因子；第18轮分隔张量定理进一步给L≥17时该乘积公平。本轮未证明9≤L≤16；当前GPU选L9开始。100位母根数值提升、CPU与GPU近似运算均不冒充实代数数证书。

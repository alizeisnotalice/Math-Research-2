# 全部二元 H_d(x²)H_d(x³) 的非负分解分类

令 \(H_d(z)=1+z+z^2+z^{d-1}+z^d\)，整数 \(d\ge6\)。

**定理。** 目标 \(C_d=H_d(x^2)H_d(x^3)\) 是二元多项式当且仅当 \(d=8\) 或 \(d\ge10\)。对所有这些 \(d\)，以及所有 \(A,B\in\mathbb R_{\ge0}[x]\) 满足 \(A(0)=B(0)=1\)、\(AB=C_d\)，无序因子对必为
\[
\{A,B\}=\{1,C_d\}\quad\text{或}\quad\{H_d(x^2),H_d(x^3)\}.
\]
所以这个无界子类不含原猜想的反例。

**证明。** [第25轮二元性分类](025-Hd-x2-x3-binary-and-gap.md)精确给出允许的d集合。d=8由[完整1482布局证书](025-H8-exact-theorem.md)处理；d=10由[本轮8310布局证书](026-H10-exact-theorem.md)处理；d≥11由[本轮双向进位尾部证明](026-Hd-x2-x3-tail.md)处理，其中d>25又由[宏层Laurent定理](026-macro-laurent-factorization.md)统一覆盖。三部分没有遗漏允许的整数d，恒定分解均已单列。因此定理成立。

这里未声称d6/7/9的非二元目标满足相同分类，也未覆盖任意a,b的H_d(x^a)H_d(x^b)，更未解决任意二元多项式。

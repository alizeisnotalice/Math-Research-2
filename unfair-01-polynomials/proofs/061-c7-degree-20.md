# 第 7 行缺口排除首一次数 20

沿用第17至19次的首一二元模型、六次形状及 \(t,m,n,p,v,q\) 的记号。特别地 \(C_8=C_9=C_{10}=C_{11}=1\)，第8、9、10行总量都严格正。下文排除任一因子的次数等于20，另一因子的次数任意，允许全系数域严格大于 \(\mathbb Q(t)\)。

## 首项逐乘积锁零

若某因子次数为20，\(C_{20}\) 的一个首项乘常数项已经等于1。因此其余乘积逐个为零。低端的正项给
\[
A_{19}=A_{18}=A_{15}=0,\qquad B_{19}=B_{17}=B_{16}=0.
\]
同一饱和行还给
\[
A_8B_{12}=A_{12}B_8=A_9B_{11}=A_{11}B_9=A_{10}B_{10}=0.
\]
所以第10行只在一侧正。第8、9行则各有左、右、双侧三种。用 \(A,B,X\) 分别表示只在左、只在右、两侧都正。形状按第8、9、10行记录，共18种。

## 第 8 或第 9 行双侧正

当第8行双侧正，取 \(u=A_8\) 且 \(B_8=q-u\)，同时锁 \(A_{12}=B_{12}=0\)。此时 \(C_{12}\ge p B_8>0\)，故 \(C_{12}=1\) 并且 \(X_{12}=1\)。当第9行双侧正，取 \(w=A_9\)，另一侧由 \(C_9=1\) 决定。此时锁 \(A_{11}=B_{11}=0\)，并且 \(X_{11}=C_{11}=1\)。若第9行单侧，则第11行只能在相同侧，通过 \(C_{11}=1\) 恢复该项。第8至11行的重建使用
\[
A_k+B_k=1-X_k,\qquad X_k=\sum_{i=1}^{k-1}A_iB_{k-i}.
\]
直到第12行，卷积的每个内部乘积最多含一个来自第8行以后、尚带未知量的系数。因此 \(X_{11},X_{12}\) 对 \(u,w\) 是仿射式。

十个含 \(X\) 的形状提供相应的一元线性方程或二元线性方程组。全都可逆。将方程的系数在 \(\mathbb Z[t]\) 中用 \(H\) 降至五次，使用解的分子及分母在六次域中的乘法矩阵，所得精确范数如下。

| 形状 | 被迫落入 \(\mathbb Q(t)\) 的系数 | 范数 |
| --- | --- | --- |
| \(AXA\) | \(w\) | \(5855/11\) |
| \(AXB\) | \(w\) | \(21289/379\) |
| \(BXA\) | \(w\) | \(-31139/11\) |
| \(BXB\) | \(w\) | \(-1/379\) |
| \(XAA\) | \(u\) | \(274959/32960\) |
| \(XAB\) | \(u\) | \(-1486327/20407\) |
| \(XBA\) | \(u\) | \(206015/74569\) |
| \(XBB\) | \(u\) | \(-17/31\) |
| \(XXA\) | \(u\) | \(4807601/333325\) |
| \(XXB\) | \(u\) | \(925/7603\) |

每个范数均非整数。因此该系数不是代数整数，与首一整数积的因子系数整性矛盾。对二未知量的两支，证书以 Cramer 法先锁定 \(u\)。

## 第 8、9、10 行各单侧正

固定哪侧占用后，第8至10行系数全部确定。第11行只可能在第9行同侧，且 \(C_{11}=1\)。沿用有理根隔离区间，精确计算 \(X_{11},X_{12}\)。四个第8行在 \(B\) 的形状都被排除。

- \(BAA,BBA\) 有 \(0<X_{11}<1\) 且 \(X_{12}>1\)。
- \(BAB,BBB\) 有 \(X_{11}>1\)。

四个第8行在 \(A\) 的形状都满足 \(0<X_{11},X_{12}<1\)。故 \(C_{12}=1\)，且第12行只在第8行同侧，即在 \(A\)。又 \(A_8B_5>0\) 迫 \(C_{13}=1\)。若形状的第10行在 \(A\)，则 \(A_{10}B_5>0\) 还迫 \(C_{15}=1\)。

在任意包含全系数的数域中，沿用 \(\mathbb Z[t]\) 的模163上覆素理想，令 \(t\equiv-6\)。第13至19行用
\[
S_k=C_k-\sum_{i=1}^{k-1}A_iB_{k-i}
\]
逐行续算，只有第13、14行的分配自由。第19行因两侧锁零须有 \(S_{19}=0\)。余式在两自由系数上均为零，其余为
\[
0\equiv c+120C_{13}+112C_{14}+161C_{15}+11C_{16}+78C_{17}+6C_{18}+C_{19}\pmod{163}.
\]

| 形状 | \(c\) | \((C_{13},\ldots,C_{19})\) 的全部模候选 |
| --- | ---: | --- |
| \(AAA\) | 109 | 无 |
| \(AAB\) | 159 | \(0,0,1,0,0,1,0\) |
| \(ABA\) | 110 | \(1,0,0,1,1,1,1\) |
| \(ABB\) | 143 | 无 |

\(AAB\) 的余码与 \(C_{13}=1\) 矛盾，\(ABA\) 的余码与 \(C_{15}=1\) 矛盾。于是次数20排除。连同0至19次的证明，任一首一有限补全的两因子次数都至少21，积的次数至少42。更高次数仍开放。

## 复现

将本目录中的三个核验脚本放在一起，使用 Python 3 标准库和启用的断言。

    python3 -B verify_degree_20.py --out degree-20-new.json

实际回执为 degree-20.json。它保存18个形状的区间或范数证书，以及四个模分支的512个二进制模式核验结果。

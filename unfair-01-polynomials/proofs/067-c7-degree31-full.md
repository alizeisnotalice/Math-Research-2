# 第 7 项缺口与第 31 行的内部卷积

设 \(A,B\) 为逐系数非负的首一实多项式，\(A_0=B_0=1\)，积 \(C=AB\) 的各项为0或1，且 \(0<A_1,B_1<1\)、\(C_7=0\)。采用已证低端形状
\[
(A_0,\ldots,A_7)=(1,t,0,n,p,0,0,0),\qquad
(B_0,\ldots,B_7)=(1,1-t,m,0,0,v,0,0).
\]
此前对固定因子次数17至30的证书可以按第 \(j\) 行内部乘积逐个为零使用。结合第12至16行的内部严格正性，已有 \(C_8=\cdots=C_{30}=1\)。

置 \(I_j=\sum_{i=1}^{j-1}A_iB_{j-i}\)。以下排除 \(I_{31}=0\)。若 \(I_{31}=0\)，其所有乘积逐个为零。固定低项即迫
\[
A_{30}=A_{29}=A_{26}=0,\qquad
B_{30}=B_{28}=B_{27}=0.
\]
第8至15项互补于第23至16项。依次以左正、右正、双正、双零四种状态记录早项。前3项因两侧和严格正，只有前三种。其互补项依次为原侧非负、原侧非负、双零、自由拆分。因此支撑数为 \(3^3 4^5=27648\)，各自只有全一的积字。

每一行保留完整内部卷积。对单侧、双零和自由拆分三类，分别让 \(1-I_k\) 与 \([0,1]\)、\(\{0\}\)、\([0,2]\) 取交。自由拆分中，若 \(1-I_k\in[l,h]\)，两项各必在 \([\max(0,l-1),\min(1,h)]\)。早端标记正时还要求上端严格大于零。有向算术用单位 \(2^{-42}\) 的整数区间，乘法按四个端点乘积外向取整。每个失败形状保留首次不相交的行号和区间。独立全量重放还核对所有保留形状的逐项区间。

## 尾端有限域恒等式

令 \(Q=A_{<24}B_{<24}\)，其中第8至23行的系数用二元全一字和自由拆分符号表示。第24至30行的差 \(C-Q\) 由八个尚未锁零的晚端系数作线性组合。两个模点 \((p,t)=(1279,168),(163,-6)\) 的左核已独立核对。在这两个模点，左核向量的分量和均为0，故全一尾字要求 \(\sum_r\lambda_rQ_{24+r}=0\)。

记 \(E_1,\ldots,E_r\) 为早端锁零方程及该素域的尾端方程。每条单位证书都直接核验 \(1=\sum_i h_i E_i\)。生成可从某方程中消去唯一出现的常系数一次变量，并用多项式差商保留原式乘子。其后的有限域 Gröbner 基步骤只用于找乘子。重放从原卷积重建各 \(E_i\)，逐项相乘。所有实际系数均为代数整数。对包含系数的任意数域 \(L\)，\(\mathcal O_L\) 中存在这两个模点的上覆素理想，单位恒等式在任意扩大的剩余域中仍排除解。

## 双模保留 XXBAABBB 的平方证书

该支早端从第8行起依次为双正、双正、右正、左正、左正、右正、右正、右正。相应第22、23行两侧皆零。令 \(u=A_8,w=A_9\)。从全一积字与相应单侧零位重建完整卷积，记平衡余量 \(F=1-I_{23}\)，则
\[
F=a u^2+buw+d u+c w^2+e w+1.
\]
系数在基 \(1,t,\ldots,t^5\) 中为
\[
\begin{array}{c|r}
a&(4,-2,6,-12,3,-4)\\
b&(-12,20,-32,42,-24,8)\\
d&(117,-189,396,-668,443,-297)\\
c&(2,-8,21,-24,20,-6)\\
e&(-47,76,-158,265,-175,118).
\end{array}
\]
在 \(\mathbb Z[t]/(H)\) 中，精确余式给出 \(4ca=b^2\)、\(4cd-2be=-4c\)。因此
\[
F=\frac{(2cw+bu+e)^2}{4c}+1-u-\frac{e^2}{4c}.
\]
由根的有理隔离区间，用有理区间运算得 \(c>2\)、\(0<e<1/2\)。非负性给 \(u\le A_8+B_8=q=1-nv<9/10\)，故 \(F>11/160\)。由于 \(A_{23}=B_{23}=0\) 且 \(C_{23}=1\)，必须 \(F=0\)，矛盾。

| 初始支撑 | 27648 |

| 晚端区间排除 | 2 |

这排除了 \(I_{31}=0\)，故 \(I_{31}>0\)，并有 \(C_{31}=1\)。任一因子在该行的系数小于一，因此它的首一次数不能是31。结合此前排除，两个次数至少为32。若两次数相同，则该行含两个等于一的端点乘积。若两次数相差一，较大次数的行同时含长因子首项乘短因子常数项和短因子首项乘长因子一次项。同一积项在两种情形都超过一。因此两次数相差至少二，\(\deg C\ge66\)。

## 重放

在[发布包](../computation/results/067-degree31/README.md)的源码目录中使用 Python 3.13.18、SymPy 1.14.0。以下命令重建区间账本、从归档恢复原始输入并独立核验其全部形状和一个实代数保留支。

    python -B census31.py --out census-fresh.json
    gzip -dc ../degree31-archive/degree31-census-*.part.gz > census-bound.json
    python -B audit_census31.py --census census-bound.json --out census-audit-fresh.json
    python -B verify_real31.py --out real-fresh.json

下表列出四片半开候选索引范围。解压第 \(i\) 片的原文件，再以相应范围重放，输出须为新文件。

| \(i\) | start | stop |
| --- | ---: | ---: |
| 0 | 0 | 5200 |
| 1 | 5200 | 9700 |
| 2 | 9700 | 12000 |
| 3 | 12000 | 13215 |

    gzip -dc ../degree31-archive/raw-0-*.part.gz > raw-0.jsonl
    python -B certify31.py --census census-bound.json --start 0 --stop 5200 --verify raw-0.jsonl --out check-0.jsonl

对其余三片替换文件编号和索引范围。用于原生成的命令去掉 \(\texttt{--verify}\) 和该参数。归档清单记录生成与只乘回执的 SHA-256，以及 \(I_{31}=0\) 见证的覆盖绑定。

实际四片单位见证生成均退出0，用时 39.069、39.855、74.419、294.407 秒。只乘回重放均退出0，用时 22.282、22.527、33.077、54.051 秒。另从归档逐块解压并核对所有完整原始 SHA-256。

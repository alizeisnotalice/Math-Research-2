# 六条卷积等式的严格乘积收缩证书

考虑精确支撑 I={0,1,2,4,9}、J={0,1,3,4,6,11}。端点为1，支撑内系数严格正且不超过1。写

\[A=1+px+rx^2+sx^4+x^9,\quad B=1+qx+ux^3+vx^4+wx^6+x^{11}.\]

以下列出了对应对角的**全部**非零项：

\[c_1=p+q,\quad c_2=r+pq,\quad c_6=w+rv,\quad
c_{10}=sw+q,\quad c_{13}=r+v,\quad c_{15}=s+w.\]

这些位置都属于 I+J，所以每个 c_k=1。令 e_k=c_k−1，有精确多项式恒等式

\[e_1-e_{10}+w\{e_{15}-e_6+r(e_{13}-e_2)\}
=p(1-rqw).\]

左边等于0。另一方面 p,q>0 且 p+q=1，0<r,w≤1，因此

\[p(1-rqw)\ge p(1-q)=p^2>0.\]

矛盾。因此该支撑对不存在任何规范化非负实系数二元乘积分解。证明不依赖数值求解，也未假设系数有理；u无需参与矛盾。

`computation/check_exception.py` 用 SymPy 精确展开全部对角、核验恒等式及正余量分解；独立 `check_exception.wl` 用 Mathematica 从 A、B 直接生成等式并做实数消元。软件只提供交叉核验，严格性由上述恒等式与不等式承担。

一般可用规则：若已由完整卷积方程得出 p=pq∏u_j，其中 p,q>0、p+q=1、0≤u_j≤1，则右端<p。这是后处理充分条件；尚未证明任意碰撞支撑都产生此种循环。

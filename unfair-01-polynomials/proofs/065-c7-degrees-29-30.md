# 第 7 项缺口排除首一次数 29 和 30

设 \(A,B\in\mathbb R_{\ge0}[x]\) 均首一且常数项为一，\(C=AB\in\{0,1\}[x]\)，并有 \(0<A_1,B_1<1\)、\(C_7=0\)。任一因子的次数均不可能是29或30。另一因子的次数任意，系数域允许是 \(\mathbb Q(A_1)\) 的任意有限扩张。

## 首项配对及全早端

交换两侧后，第7项缺口处于已证低端形状
\[
(A_0,\dots,A_7)=(1,t,0,n,p,0,0,0),\qquad
(B_0,\dots,B_7)=(1,1-t,m,0,0,v,0,0),
\]
其中 \(m=1-t+t^2,\ n=1-tm,\ p=1-(1-t)n,\ v=t^2m\)。\(t\) 是
\[
 H(t)=t^6-4t^5+6t^4-7t^3+4t^2-2t+1
\]
在 \((0,1)\) 唯一的实根（有理 Sturm 链在0、1处的变号数分别为4、3），有理隔离区间为 \((71942965/10^8,71942966/10^8)\)。

\(H\bmod2=x^6+x^3+1\)。模该多项式，\(x^{64}-x\) 的余式为零，\(x^4-x\)、\(x^8-x\) 的余式分别为 \(x^4+x\)、\(x^5+x^2+x\)，且各与该多项式互素。故 \(H\) 由有限域不可约性判据知在 \(\mathbb Q\) 上不可约。\(C\) 为首一整系数多项式，\(A,B\) 的根均是 \(C\) 的代数整数根。两因子首一，因此其系数为这些根的基本对称函数，都是代数整数。

置 \(q=1-nv,\ x=1-pv-(1-t)q,\ y=1-pv-tq\)。正项 \(nv,pv\) 迫 \(C_8=C_9=1\)，并有 \(A_8+B_8=q\) 及 \(A_9+B_9=y+(2t-1)A_8\in[y,x]\)。代入有理隔离区间作有向运算，得到 \(t>1/2,\ q>0,\ y>0,\ tx+mq<1\)。第10行内部卷积 \(X_{10}=tB_9+(1-t)A_9+mA_8\) 严格正且至多 \(tx+mq\)，故 \(C_{10}=1\) 和 \(A_{10}+B_{10}>0\)。第11行的内部正项 \(tB_{10}+(1-t)A_{10}\) 迫 \(C_{11}=1\)。

若某因子次数为 \(j\)，其首项乘对侧常数项为1，第 \(j\) 行其余每项卷积乘积逐个为零。用 \(A,B,X,Z\) 表示早端某行只在左侧正、只在右侧正、双侧正、两侧全零。第8至10行各取前三种，第11至14行取四种。对 \(i=8,\ldots,14\)，\(A_iB_{j-i}=A_{j-i}B_i=0\) 要求互补行依次只能在相同侧（可零）、相同侧（可零）、双零或完全自由拆分。\(j=30\) 还有第15行中点条件 \(A_{15}B_{15}=0\)，以左或右并允许其为零覆盖。枚举 \(C_{12},\ldots,C_{j-8}\) 的二元位。初始分支数是
\[
3^3\cdot4^4\cdot2^{10}=7077888,\qquad
3^3\cdot4^4\cdot2\cdot2^{11}=28311552 .
\]
对某固定形状，任何有已知正乘积的积位直接置1。若剩余位数为 \(r\)，则需实际进入逐行处理的码数为 \(2^r\)，其余码都由该形状的正支撑排除。

在所有后续步骤中使用完整卷积
\[
S_k=C_k-\sum_{i=1}^{k-1}A_iB_{k-i}.
\]
单侧行把 \(S_k\) 放在许可侧，双零行施加 \(S_k=0\)，自由行置 \(A_k=u,\ B_k=S_k-u\)。早端符号计算在 \(\mathbb Z[t]\) 上进行，第15行以前至多仿射；第16至22行保持未知量的全部混合和平方项。若乘积的一项指标至少16，其另一项指标至多6，已经固定。其他卷积项是两个仿射式的乘积，所以早端度数至多2，程序在所有乘法里核对这个上界。晚端截断卷积独立使用完整有限域多项式乘法，不截去更高次项。

## 有向整数区间

用整数对 \((l,h)\) 表示 \([l/2^{42},h/2^{42}]\)。加法精确，乘法把四个端点乘积除以 \(2^{42}\) 后向外取整。由上述有理根区间给 \(t\) 的初始外包络。每个因子系数属于 \([0,1]\)，这是由 \(C_k\ge A_k,B_k\) 得到的全局必要条件。

设某行剩余总量 \(S_k\in[L,U]\)。

- 双零要求 \(0\in[L,U]\)，否则整个后缀都排除。
- 单侧把 \(S_k\) 与 \([0,1]\) 取交。若该行标为严格正，另要求 \(U>0\)。
- 自由拆分的每项都在 \([\max(0,L-1),\min(1,U)]\)。这是因为另一项至多1，且和受 \(S_k\) 上界控制。若本行标为双侧正，也要求 \(U>0\)。这些区间只是外包络，可容许边界值。

从低次到高次做上述传播，只有算出的区间与必要条件不交时才排除。对提前停止的分支，按尚未处理的二元位许可数相乘得到其覆盖码数。对区间尚未排除的早形状，再用精确六次域范数及仿射模矛盾作筛选。任一被线性等式锁入 \(\mathbb Q(t)\) 的系数若具有非整范数，就不可能是代数整数。这个检查不限制其余未知量的系数域。

## 七项晚行与精确消元

置 \(\ell=j-7\)、\(Q=A_{<\ell}B_{<\ell}\)。首项预算还迫
\[
A_{j-1}=A_{j-2}=A_{j-5}=B_{j-1}=B_{j-3}=B_{j-4}=0.
\]
在第 \(\ell\) 至 \(j-1\) 行保留这些零项并继续逐行传播区间。已知正支撑先留下18724、82728个晚端码；区间再排除330、4751个，分别留下18394、77977个待模核验的二元字。区间传播全程仍使用完整卷积。

由 \(2\ell>j-1\)，这七行每个乘积最多有一个新的晚端系数。因此 \(C_{\ell+r}-Q_{\ell+r}\) 对新的晚端系数为线性。对余下八列直接核对，权重
\[
\lambda^{(1279)}=(875,178,686,823,163,1111,1),\qquad
\lambda^{(163)}=(120,112,161,11,78,6,1)
\]
分别在 \(t=168\bmod1279\)、\(t=-6\bmod163\) 消去每列。于是任何实际因子对都满足
\[
z:=\sum_{r=0}^6\lambda_r C_{\ell+r}
 = \sum_{r=0}^6\lambda_r Q_{\ell+r}.
\]
\(H\) 在两个模点都为零。全部系数为代数整数，对包含它们的任意数域 \(L\)，整扩张的上覆定理在 \(\mathcal O_L\) 中给出两个相应的剩余域。剩余域可不同，也可扩张各自素域。二元积字在两处都是同一组0、1。

取所有早端锁零原方程 \(E_i=0\)，增加 \(E_{\rm tail}=Z-\sum_r\lambda_r Q_{\ell+r}=0\)。在每个模点将早端变量排在 \(Z\) 之前。先代入可直接消去的仿射方程，保留多项式差商的变换乘子。对于变量少的分支生成单变量投影恒等式 \(f(Z)=\sum_i h_i E_i\)。若投影不足以排除某字，则把该字的精确 \(z\) 代入 \(Z\)，生成特化单位恒等式
\[
1=\sum_i h_i E_i\big|_{Z=z}.
\]
两类见证均逐条乘回原始方程，检查等式。独立的只读乘子入口无需重新生成 Gröbner 基。若 \(f(z)\ne0\) 或后一个单位恒等式成立，则不论剩余域怎样扩张，该二元字都不可能。直接使用截断多项式的全卷积，而不把两项早端未知系数的乘积视为仿射。

`probe-29-30.json` 保存直接 Gröbner 基单位理想判定的完整结果。两次数另有可逐项乘回的冻结恒等式，共 4,323 条投影恒等式和 29,888 条单位恒等式。词数以实际七位字计，多个字允许有相同模值。该重算的 0 未决与乘子证明路线使用同一完整卷积入口，消元路线不同。早端另用六次整数环直接卷积抽查422个分支的1688组精确赋值，包含421个确含二次项的形状，并用4096组有理端点乘积核验有向取整，回执见 `arithmetic-audit.json`。全部3156个早端范数及模线性排除又以模 \(H\) 的 Laplace 行列式和多项式结式复核，逐条一致。回执见 `early-rejection-audit.json`。

结合同一低端条件下对所有不超过28的次数的先前排除，任一因子次数至少31。两因子同为 \(d\) 次会给 \(C_d\ge2\)。若一次数为 \(d\)，另一次数为 \(d-1\)，则长侧一次项乘短侧首项为 \(C_d\) 提供额外的正贡献，矛盾。因此两因子次数至少相差2，积的次数至少64。

积次数为 64 时，两侧次数为 31、33。保留上文低端方向，因为 \(B_2>0\)，若 \(\deg B=33\) 则 \(A_{31}B_2\) 违反第 33 行饱和，故 \(\deg A=33,\deg B=31\)。首项与低端正项卷积给 \(C_{31}=C_{32}=C_{33}=C_{34}=C_{35}=C_{38}=1\)。第 31 行中 \(A_{30}B_1=A_{29}B_2=0\) 迫 \(A_{30}=A_{29}=0\)，第 33 行中 \(A_4B_{29}=0\) 迫 \(B_{29}=0\)。结合两侧反向第 1 项均为零、反向第 2 项左零和反向第 3、4 项右零，得 \(C_{60}=C_{61}=C_{62}=C_{63}=0\)。若模 163 的平方次数恰为 7，第 6 个反转系数在两侧都为分数，所以 \(C_{58}=1\)。

## 重放

在 [复算目录](../computation/results/065-gap7/README.md) 使用 Python 3.13.18、SymPy 1.14.0，保留 Python 的断言。归档中的 `.part.gz` 按文件名顺序解压拼接，恢复各次数的原始乘子账本。`--witness` 重做全早端分支计数与七位字覆盖，继而对账本中的乘子乘回原始卷积方程。

```sh
gzip -dc archive/degree-29-*.part.gz > degree-29.json
gzip -dc archive/degree-30-*.part.gz > degree-30.json
python -B hybrid_29_30.py --only 29 --witness degree-29.json --out replay-29.json
python -B hybrid_29_30.py --only 30 --witness degree-30.json --out replay-30.json
```

可另从新文件名完全生成乘子，去掉上述命令的 `--witness` 及其参数即可。正支撑、早晚端区间、早端范数和两素数的消元均重算。直接判定路线用以下命令。

```sh
python -B prefix_29_30.py 29 30
python -B verify_degrees_29_30.py --scout prefix29.30.json --out direct-fresh.json
python -B audit_prefix_29_30.py --prefix prefix29.30.json --out arithmetic-fresh.json
python -B audit_early_rejections_29_30.py --prefix prefix29.30.json --out early-rejections-fresh.json
```

已从空目录另行重建完整前缀，两次前缀逐字节一致。`direct-verification.json` 绑定此前缀、直接消元回执、算术抽核及运行源码的 SHA-256。

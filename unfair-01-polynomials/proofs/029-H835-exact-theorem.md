# H8(3,5)：完整根布局的独立认证

令 H(x)=1+x+x²+x⁷+x⁸，C=H(x³)H(x⁵)。对所有 A,B∈R≥0[x]，若 A(0)=B(0)=1、AB=C，则 {A,B}={1,C} 或 {H(x³),H(x⁵)}。[本轮解析证明](029-H835-analytic.md)已给出不依赖根枚举的证明；本文件记录独立的计算辅助证明。

## 完整必要集合

整数卷积给 C 次数64、25项二元。常数项一及非负性先给各系数≤1，再由最高系数乘积为一得到两因子首一。常数因子单列。

H的模2、13、5平方自由因子型分别为[8]、[1,7]、[1,2,5]。独立整数Rabin验证逐因子不可约性与完整乘积；前两型给传递及二重传递，第三型的五次幂给换位，因此Galois群为S8。H非自反，[第18轮根幂积刚性](018-root-balance-and-separated-products.md)适用。

四个非实正虚部母盘及其共轭，以严格有理Rouché不等式覆盖全部八根，故没有实母根。每个母共轭对提升为3个a二次群和5个b二次群，合计32群、64根。各群母盘、替换指数、槽位及共轭绑定均重核；所有根盘两两分离，证明目标平方自由及两替换互素。数值求根只产生中心，不承担根数或分离结论。

首一实因子只能按共轭二次群选根。若某复母块选u个a群、v个b群，则根积的15次幂在每个母根上的指数为5u+3v。常数项一使整体根积属于Q*，幂积刚性迫四块指数同为E。补集把E变为30−E；非恒定情形取E<15，E15时固定首母块全a。E15每块仅有全a或全b两种选择。

## 倒序有理区间证书

单个共轭群因子为 x²−2Re(α)x+|α|²，首一。把普通升幂系数盒反转后，乘积的低次系数k正好是原因子次数N−k处的系数；N为所选群数的两倍。只截去反转后次数高于k的项，不会丢失该系数贡献。

搜索器从有理根盘构建128位向外端点区间，先查顶端偏移1，再对未决布局查更深偏移。3.669秒实际完整搜索的建议为：偏移1有1,742,662项，偏移5有5项，偏移6有2项，余下唯一标准项。每条建议只有两个字节(side,top_offset)，不携带可直接信任的数值界；标准用(255,255)。

独立验证器从根盘重建Fraction矩形盒，再以96位整数中心—半径球作有向卷积。与第28轮相同的严格误差公式保持包含关系；倒序核另经512个端点组合、4个偏移检验。全量1,742,669项均得到严格负上端。最小保守负余量为

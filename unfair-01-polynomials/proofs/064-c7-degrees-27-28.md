# 第 7 项缺口排除首一次数 27 和 28

设 \(A,B\in\mathbb R_{\ge0}[x]\) 都是首一、常数项为一的有限多项式，\(C=AB\in\{0,1\}[x]\)，且 \(0<A_1,B_1<1\)。若 \(C_7=0\)，任一因子的次数均不能等于27或28。另一因子的次数任意，允许两侧系数处于包含 \(A_1\) 的任意数域。

## 全部早端形状

使用已证的第7项缺口低端形状
\[
 (A_0,\ldots,A_7)=(1,t,0,n,p,0,0,0),\qquad
 (B_0,\ldots,B_7)=(1,1-t,m,0,0,v,0,0),
\]
其中 \(m=1-t+t^2,\ n=1-tm,\ p=1-(1-t)n,\ v=t^2m\)。\(t\in(0,1)\) 的最小多项式为
\[
 H(t)=t^6-4t^5+6t^4-7t^3+4t^2-2t+1,
\]
其有理隔离区间为 \((71942965/10^8,71942966/10^8)\)。此前证明 \(C_8=C_9=C_{10}=C_{11}=1\)，第8、9、10行各自两侧总量严格正。

若某因子次数为 \(j\)，它的首项与对侧常数项已用尽 \(C_j\)。其余非负乘积逐项为零。特别是
\[
 A_iB_{j-i}=A_{j-i}B_i=0 \quad(i=8,\ldots,13).
\]
早端第8、9、10行各取左侧正、右侧正或双侧正。第11、12、13行还可双零。互补行的许可依次为同侧（可零）、同侧（可零）、两侧全零和任意拆分。第28次的中点在第14行，还必须满足 \(A_{14}B_{14}=0\)，以任一侧且允许零覆盖该边界。给 \(C_{12},\ldots,C_{j-8}\) 取全体二元码，共有
\[
 3^3\cdot4^3\cdot 2^8=442368,\qquad
 3^3\cdot4^3\cdot2\cdot 2^9=1769472
\]
个早端分支，分别对应次数27与28。

逐行由 \(S_k=C_k-\sum_{i=1}^{k-1}A_iB_{k-i}\) 计算两侧的总量。单侧时把 \(S_k\) 放到允许侧；双零时施加 \(S_k=0\)；自由拆分时引入 \(u=A_k\) 并令 \(B_k=S_k-u\)。运算在系数环 \(\mathbb Z[t]\) 上进行。第15行以前没有两个较高未知系数相乘，因此早端系数至多一次依赖拆分变量。第16至20行继续以完整稀疏多项式做卷积，保留所有两个较高未知系数的乘积。乘积若含指标至少16的项，另一项指标至多4且已固定；其余乘积至多是两个仿射式相乘。因此至第20行确实不会产生三次项，程序在每次乘法中核对这一度数上界。这只用于早行分类，晚行截断乘积不作二次截断。

已知正项相乘与零积位冲突时立即排除。无拆分时用严格有理区间排除负系数。全仿射且可逆时，以 Cramer 法和六次域乘法矩阵范数排除某一个范数非整数的系数；一般系统还可用自身的仿射单方程检查范数、零行及选定模点矛盾。完整早端账本如下。

| 判据 | 次数27 | 次数28 |
| --- | ---: | ---: |
| 初始分支 | 442368 | 1769472 |
| 已知正乘积碰撞零位 | 439767 | 1763160 |
| 无拆分形状的区间负项 | 125 | 318 |
| 全仿射 Cramer 非整数范数 | 557 | 1148 |
| 仿射零行矛盾 | 734 | 2270 |
| 仿射单方程非整数范数 | 406 | 1012 |
| 仿射模矛盾 | 8 | 4 |
| 进入晚端 | 771 | 1560 |

这里的范数矛盾仅要求被某个方程锁入 \(\mathbb Q(t)\) 的系数为代数整数，允许其余系数属于更大域。

## 晚端全卷积和直接代入恒等式

记 \(\ell=j-7\) 和 \(Q=A_{<\ell}B_{<\ell}\)。\(Q\) 按已经生成的整段早端多项式相乘，保留含有二次早端系数的所有项。因 \(2\ell>j-1\)，第 \(\ell,\ldots,j-1\) 行每个卷积乘积至多含一个新的晚端系数。首项还锁定
\[
 A_{j-1}=A_{j-2}=A_{j-5}=B_{j-1}=B_{j-3}=B_{j-4}=0.
\]
在 \(t\equiv168\bmod1279\) 或 \(t\equiv-6\bmod163\) 时，用低端两列逐项检查，卷积中其余八个晚端变量的列都被相应权重消去。按行升序，权重为
\[
 \lambda^{(1279)}=(875,178,686,823,163,1111,1),\qquad
 \lambda^{(163)}=(120,112,161,11,78,6,1).
\]
于是
\[
 \sum_{r=0}^6\lambda_r C_{\ell+r}
   = \sum_{r=0}^6\lambda_r Q_{\ell+r}
\]
是任一实际补全在这两个模点的必要条件。由于 \(H\) 在两个模点都为零，两个映射均定义 \(\mathbb Z[t]\) 的素理想。全系数都为代数整数，把它们放进任意数域 \(L\)，整扩张的上覆定理使两点分别延伸至 \(\mathcal O_L\) 的剩余域。各剩余域都可严格大于素域；真实二元字在两处保持同一组0、1。

对每个早端形状及符合已知正项条件的七位字，固定 \(z=\sum_{r=0}^6\lambda_r C_{\ell+r}\)，以
\[
 E_1,\ldots,E_s,\quad E_{s+1}=z-\sum_{r=0}^6\lambda_r Q_{\ell+r}
\]
为有限域多项式系统。前 \(s\) 个是所有早端双零行原方程。以仿射方程先代入，再用总次数逆字典序求单位理想见证。实际计算的每个排除均保存了原始方程上的显式恒等式
\[
 1=\sum_{i=1}^{s+1} h_i E_i .
\]
例如用于代入的线性方程规范为 \(u-L=0\)，则把另一个多项式 \(f(u)\) 换成 \(f(L)\) 的差精确除以 \(u-L\)，由此回写乘子。最后始终按原始 \(E_i\) 做有限域多项式乘法，直接核验等式。这个等式在任意扩张剩余域中排除共同解，核验不依赖求解算法的完备性。字的权重相同时在同一形状和模点共享一条恒等式。

| 次数 | 符合已知正项的七位字 | 模1279排除 | 模163排除 | 未排除 |
| ---: | ---: | ---: | ---: | ---: |
| 27 | 5192 | 5189 | 3 | 0 |
| 28 | 20714 | 20698 | 16 | 0 |

共核验25873条不同形状、模点和权重下的单位恒等式，覆盖25906个字。故两次数均排除。结合已证明的更低次数范围，任一含第7项缺口的有限首一补全，两因子次数均至少29，积次数至少58。更高次数仍开放。

## 复验材料

同目录的核验入口使用 Python 3.13.18 和 SymPy 1.14.0。断言须启用。计算乘子时可分别执行

    python3 -B direct_mod_27_28.py --only 27 --out degree-27-new.json
    python3 -B direct_mod_27_28.py --only 28 --out degree-28-new.json

对于已冻结的乘子，只需按原方程重算恒等式

    python3 -B direct_mod_27_28.py --only 27 --witness degree-27.json --out degree-27-identity-new.json
    python3 -B direct_mod_27_28.py --only 28 --witness degree-28.json --out degree-28-identity-new.json

后两命令重建完整早端覆盖，读取冻结乘子，并直接验证每个需要的单位恒等式。全部运算使用整数、有理数和精确有限域算术。

归档保存两份无损 gzip 原始回执。需要用冻结乘子核验时，先将它们解压到自己的数据盘临时目录，再将该 JSON 路径传给对应的 --witness。解压后的原始文件哈希和实际全量回放账本见 verification.json。

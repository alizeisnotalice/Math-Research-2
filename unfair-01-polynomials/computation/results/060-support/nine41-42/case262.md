# 九点支撑 i262 的精确排除

设 \(A,B\) 的正系数支撑分别为
\[
I=\{0,2,3,4,7,8,9,14,20\},\qquad
J=\{0,2,3,5,8,9,10,15,21\}.
\]
设 \(AB\) 逐系数二元。每个 \(k\in I+J\) 的卷积系数严格正，因此等于1。由第0行 \(a_0b_0=1\)，可倒数缩放两因子使 \(a_0=b_0=1\)。第20、21行分别只有 \((20,0)\)、\((0,21)\) 一个表示，故 \(a_{20}=b_{21}=1\)。

所需的其余卷积行如下。表中每个表达式等于1。

| 次数 | 表达式 |
|---:|---|
| 2 | \(a_2+b_2\) |
| 3 | \(a_3+b_3\) |
| 4 | \(a_2b_2+a_4\) |
| 5 | \(b_5+a_2b_3+a_3b_2\) |
| 25 | \(a_4+b_5\) |

第4、25行相减给 \(b_5=a_2b_2\)，故第5行要求
\[
a_2b_2+a_2b_3+a_3b_2=1.
\]
但由 \(a_2+b_2=a_3+b_3=1\) 有精确恒等式
\[
1-a_2b_2-a_2b_3-a_3b_2=b_2^2b_3+a_2^2a_3>0.
\]
右边严格正来自固定支撑中的四个严格正系数，矛盾。故 i262 无可行分解。

若需直接的多项式证书，以 \(F_k\) 记归一化第 \(k\) 行卷积系数减1，则
\[
b_2^2b_3+a_2^2a_3
=(1-a_2b_2)F_3
 +\bigl((b_2+1)b_3+(a_2+1)a_3\bigr)F_2
 -F_5+F_{25}-F_4.
\]
这是全变量的多项式恒等式。右边由二元占用行预算恒为0。

`verify_nine262.py` 从两侧支撑逐项生成卷积分组，检查全部八个所用行的表示集合，并用 SymPy 精确展开验证恒等式差为0。实际解释器为 Python 3.13.18，SymPy 1.14.0。运行回执为同目录中的 verify-case262.json。

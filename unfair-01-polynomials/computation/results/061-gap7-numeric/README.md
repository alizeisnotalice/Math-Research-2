# 第 7 项缺口与第 9 至 11 项预算的 MPS 探索

数值模型固定前缀 \(C_0=\cdots=C_6=1,\ C_7=0,\ C_8=1\)，把第 9 至 11 项的剩余预算放入参数化。若第 11 项内部卷积数值上超预算，截断余项并让损失保留超预算部分。实际运行取次数 \((48,64)\)，8,192 并行轨迹，24,000 步，种子 2026111810。工具版本、精确低端方程和根隔离区间见 input.json。

记录样本 192 个，由[前轮独立数值样本验证器](../060-gap7-numeric/verify_saved_samples.py)以精确二进制有理数重新卷积。最小记录残差约 0.27119。运行正常退出并回收 GPU 缓存。本批结果只验证保存的舍入样本。

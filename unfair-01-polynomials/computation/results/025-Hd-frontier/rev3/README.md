# H_d frontier rev3 final overlay

This package reuses, rather than reruns, the rev2 exact carry coverage: 21,153 coprime triples and 20,715 injected targets, with a separate direct-coordinate audit. It updates only proof-status metadata after three specific targets were independently certified by the parent research line.

The finite support/carry ledger is deliberately kept separate from proof status. Carry data may identify an obstruction to a proposed row argument; it cannot itself certify fairness, exclusion, or a counterexample.

The mathematically smallest remaining target in the stored ordering is \(H_7(x^3)H_7(x^4)\), but it has one real mother root. The current GPU cache handles only conjugate quadratic blocks, so this target requires a real-linear-group extension. The round-25 operational priority is instead the first compatible open target \(H_{10}(x^2)H_{10}(x^3)\); its new parameter-specific input is a round-26 candidate and is not part of the round-25 finite coverage.

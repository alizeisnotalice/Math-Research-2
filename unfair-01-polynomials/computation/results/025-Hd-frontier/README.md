# H_d 非分隔替换的有限结构账本

rev2 保存 d=6..60、2≤a<b≤d、gcd(a,b)=1 的全部 21,153 个参数；其中 20,715 个目标为二元。独立验证器重新生成完整期望参数集合，再直接枚举 (S+S)² 所有实际坐标，验证注入性、全部进位和键唯一性。它验证的是覆盖和组合结构，不是非负分解的排除。

rev3 是后续证明状态及选题说明，原路径仅用于来源定位；实际对应账本位于相邻 rev2。当前闭合的三个新固定目标 H8(2,3)、H10(3,4)、H16(3,4) 的证明在本轮 proofs 中；不把 rev2 行内历史 status 当成最终证明判定。

H7(3,4) 的二元性、模 Galois 证书和一个实母根只用于说明当前纯二次根群 GPU 引擎不适用。real-block 布局计数是下一阶段准备材料，不是对此目标完成排除。下一唯一优先目标是 H10(2,3)。

复现：在 rev2 目录运行 python3 verify_hd_frontier_rev2.py；在 rev3 目录运行 python3 audit_h7_a3b4.py（需要 SymPy）。

# 八次实二次母式位置 2 的精确证书

本包对应唯一非有理位置 (S=\{2\}) 的八次实二次母式。任意有限带符号整数余因子均由其低次卷积和补零涵盖。同一结论经反转适用于 (S=\{6\})。

- 修正生产链覆盖 11,760 个核心、219 条第 4 行状态、461,683 个不同母式。精确正轴和根环筛拒绝 460,100 个，留下 1,583 个。全部根筛剩余母式的两种树在第 8 至 14 层为空，未知数为零。
- `data/` 的 tar.gz 分片按原字节保存修正生产的 35,280 份逐核记录及 1,583 份逐树记录。`frozen/` 保存同次生产的摘要、树输入及日志。根记录包括每个母式的 17 个范数系数和首个拒绝码，255 表示通过此必要筛。树记录包括按层计数和完整状态前缀 SHA-256。
- `verify_certificate.py` 检查文件清单、逐核输入字节链、覆盖与分层结果。它接受外部 `--replay` 输出以逐记录承诺比较。数学重算使用 `verify_fresh.py`，它从空目录运行全部阶段，并要求重算记录同封存记录一致。
- 历史版本误用与局部系数同名的 Newton-4 界。旧 303 条第 4 行记录中 136 条误纳、52 条漏枚举，故旧 438,181 母式及 1,571 通过项已经撤回。包内源码使用单独命名的 `NEWTON4_BOUND=(257,4)`。

复现需要 Python ≥3.11 和已有 SymPy（实际版本见回执）。运行 `-O` 或设置非零优化会被拒绝。输出目录必须是证书目录之外的一条新路径。

```sh
python3 modules/verify_certificate.py
python3 modules/verify_fresh.py --workers 4 --out /Volumes/data/CodexTemp/T2/unfair-01-polynomials/replay056-s2-new
```

# p2q7强正性路线的完整局部分支

给定二元短G，T取第34轮七种必要支撑。本包选择每个模2余类的最小列，在交叉A的首负行要求一个严格正F补偿；再加入B给出的偏移2和普通H给出的一个非零G下标补偿。所有笛卡尔选择共72个分支，不遗漏奇余类约束。

F已由二元G/H推出整数，所以首负之前的严格正系数至少为1。只使用H指标小于首负r的项；重复贡献迫系数≥2，或正H偏移中同时存在差2k和7k迫C碰撞。独立重建全部分支的验证器确认69个关闭，3个仍未知：T036的D={2,3,35}/{2,6,35}，及T06的D={2,7,21}。

这不证明p2q7所有F非负。首负之后的未知F系数可能抵消正项，不能直接沿用首负之前的卷积下界。核心最小反例下降只需要G二元，因而不依赖这三个强命题分支的解决。

将压缩JSON解压到data临时目录，与两个verify脚本置于同一工作目录后运行：

    /Users/zzh/.venvs/main/bin/python verify_p2q7_all_residue_repairs.py
    /Users/zzh/.venvs/main/bin/python verify_p2q7_explicit_certificate.py

主线程实际运行退出0，回执绑定输入和归档验证器。生成脚本也可在data临时工作目录直接运行。旧42分支偶类版本被72分支版本替代，不重复归档旧发现数据。

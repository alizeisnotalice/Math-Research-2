# 八次实二次原始母式非有理支持 \(\{1,2,3\}\) 和 \(\{5,6,7\}\) 的排除

## 定理

设 \(K\) 为任意实二次数域，横线表示其非平凡共轭。设八次首一且常数项一的母式
\[
P=1+ax+bx^2+cx^3+dx^4+ex^5+fx^6+gx^7+x^8,
\qquad a,b,c\in\mathcal O_K\setminus\mathbb Q,\quad d,e,f,g\in\mathbb Z.
\]
不存在有限、首一且常数项一的整数多项式 \(G,Q\)，使 \(A=GP,\ B=Q\bar P\) 逐系数非负且 \(C=AB\) 二元。允许余因子为1、任意有限次数和任意符号的中间系数。同时反转即覆盖非有理支持 \(\{5,6,7\}\)。一般均匀和猜想仍开放。

## 端点饱和确定两个非有理坐标关系

由 \(A_0=B_0=1\) 和 \(C\) 的二元性，所有 \(A_k,B_k\in[0,1]\)。越界系数补零。设 \(h=\deg G\)。\(A_{h+3}=c+\text{整数}\) 非有理且严格正，由 \(C_{h+8}\ge 1+A_{h+3}B_5\) 得 \(B_5=0\)，对称得到 \(A_5=0\)。而低端 \(A_1,B_1>0\)，同一首项预算迫 \(A_{h+7}=0\) 及其对侧为零，因此 \(G_{h-1}=-g\)，\(Q_{\deg Q-1}=-g\)。

写 \(K=\mathbb Q(\sqrt D)\)，\(D>1\) 平方自由。完整整基取 \(1,\omega\)，其中 \(\omega=(1+\sqrt D)/2\) 当 \(D\equiv1\pmod4\)，其余为 \(\sqrt D\)。写
\[
a=m+r\omega,\qquad b=u+s\omega,\qquad c=v+t\omega,\qquad
m,u,v,r,s,t\in\mathbb Z,\quad r,s,t\ne0.
\]
同时交换两因子、两余因子并对 \(P\) 共轭，可规范 \(r>0\)。\(s,t\) 的符号都保留。\(A_{h+2}\) 的非有理坐标为 \(s-tg\)，对侧为其相反数。若其非零，则两个系数均严格正，首项预算给 \(A_6=B_6=0\)。[中心第6行引理](analytic-center-zh.md) 证明，二次数域内 \(A_1,B_1>0\)、\(A_5=B_5=0\) 一律有
\[
0<A_2B_4+A_3B_3+A_4B_2<1.
\]
因此 \(A_6=B_6=0\) 不可能，真实模型必有
\[
s=tg,\qquad g\ne0.
\tag{1}
\]
这使 \(b,c\) 的非有理坐标只需一个自由整数，且无需假定它们属于 \(\mathbb Z[a]\)。

另由 \(A_5=B_5=0\) 的非有理投影有
\[
rG_4+sG_3+tG_2=rQ_4+sQ_3+tQ_2=0.
\tag{2}
\]
后面的有限入口用式 (2) 锁定 \(G_4,Q_4\)。

## 完整有限参数范围

二元、首一常数项一的 \(C\) 的根严格落在 \(1/2<|z|<2\)，因为在 \(|z|\ge2\) 和 \(|z|\le1/2\) 时分别有首项和常数项模严格超过其余项模的和。\(P\) 和 \(\bar P\) 整除 \(C\)，其倒数根模乘积为1。闭八维零和对数盒的极点是四个 \(+1\) 与四个 \(-1\) 的排列。初等对称和绝对值的包络及各阶模幂和沿该零和空间的非零方向严格凸，故开盒严格低于对应极点值。其结果为两个嵌入分别满足
\[
|a|<10,\quad |b|<83/2,\quad |c|<185/2,\quad |g|<10,\qquad
|S_2|<17,\quad |S_3|<65/2,
\]
其中 \(S_2=a^2-2b,\ S_3=-a^3+3ab-3c\)。初等对称和的严格性可由非零零和方向存在非零的相应子集和得到。

设 \(\omega-\bar\omega=\tau\sqrt D\)，其中 \(\tau=1\) 或2。由 \(a\) 的两嵌入界，\(|T_a|+\tau r\sqrt D<20\)，其中 \(T_a=a+\bar a\)，故 \(D<400\)。实际有112个平方自由底数容纳这样的 \(a\)，共有1,140个核心。对每个 \(a\)，枚举 \(0<|g|\le9\)，按式 (1) 取 \(s=tg\)，并施加 \(b\) 的两嵌入界和 Newton-2。第一实现用整数迹约束直接求允许的 \(T_b\) 闭整数区间，保留整基模2条件。第二实现直接在完整整基盒遍历 \(b=u+s\omega\)，例如 \(|s|\le38,\ |u|\le61\) 足够，然后逐项施加两个严格界。上述盒来自 \(\tau\sqrt D\ge\sqrt5\)、\(|T_b|<83\) 和 \(2u=T_b-s\operatorname{Tr}(\omega)\)。

## 共同第四行矛盾

第1行迫 \(A_1+B_1=1\)，唯一确定 \(G_1=-\lfloor a\rfloor,\ Q_1=-\lfloor\bar a\rfloor\)。第2行因内部项 \(A_1B_1>0\) 而有 \(C_2=1\)，并有 \(0<A_2+B_2<1\)。第3行内部项 \(A_1B_2+A_2B_1\in(0,1)\)，给 \(C_3=1,\ 0<A_3+B_3<1\)。第4行有正的内部项 \(A_1B_3+A_2B_2+A_3B_1\)，故必须 \(C_4=1\)。

整数平移到 \([0,1]\) 的规则完整保留所有分支。基值非有理时恰一个平移，基值为整数时保留0、1两个端点。对给定 \(a,b\) 和 \(t\)，令 \(c_0=t\omega,\ c=c_0+v\)。第3行用 \(\rho_3=G_3+v,\ \sigma_3=Q_3+v\) 做平移，因此 \(A_3,B_3\) 在该阶段不依赖 \(v\)。式 (2) 先给
\[
G_4-Q_4=-\bigl[s(\rho_3-\sigma_3)+t(G_2-Q_2)\bigr]/r,
\]
必须是整数。此差与 \(v\) 无关。据第4行
\[
A_4=d+cG_1+bG_2+aG_3+G_4
\]
及对侧公式，差 \(A_4-B_4\) 关于 \(v\) 为仿射函数，斜率
\[
G_1-Q_1-(a-\bar a)=2A_1-1-2(a-\bar a)<-2.
\]
最后不等式来自 \(0<A_1<1\) 和 \(a-\bar a\ge\sqrt5\)。单位区间要求 \(|A_4-B_4|\le1\)，所以在所有 \(|c|\)、\(|S_3|\) 严格界允许的 \(v\) 中至多一个。主实现用单调精确比较确定此 \(v\)，再查式 (2) 两侧整除。独立实现扫描整个整数平移区间并直接比较两侧差。其区间来自整数迹 \(|\operatorname{Tr}(S_3)|<65\) 和 \(S_3=S_3^{(0)}-3v\)，然后直接核两个嵌入，故不会漏任何 \(v\)。

固定 \(v\) 后，\(G_4,Q_4\) 已分别由式 (2) 确定。使用有限截断的 \(P\bar P\,GQ\) 的整性，已知 \(C_4=K_4+2d\)，其中 \(K_4\in\mathbb Z\)。主实现解 \(K_4+2d=1\)，35个整数候选均无法令两侧第4行同时位于 \([0,1]\)。独立实现穷尽两侧共有的整数平移 \(d\)，得到1,199个同时满足两侧单位区间的记录，逐个直接卷积都为 \(C_4=2\)。这两项核验均允许任意整数 \(d\)，未施加系数盒或 Newton-4。冻结账本给出这1,199个记录及两边的整基坐标。

| 阶段 | 精确数量 |
|---|---:|
| 允许的平方自由底数／\(a\) 核心 | 112／1,140 |
| 带 \(g\) 的 \(a,b\) Newton-2 前缀 | 181,088 |
| 第2行卷积通过 | 154,790 |
| 第3行规范平移通过 | 95,258 |
| 式 (2) 两侧差整除通过 | 75,083 |
| Newton-3 后低端第4行差预算通过 | 2,001 |
| 式 (2) 两侧均整除 | 1,885 |
| 共同 \(d\) 使两侧单位区间成立 | 1,199 |
| 同时满足 \(C_4=1\) | 0 |

因此未产生完整母式，额外根筛和尾部树没有输入。所有假设中的有限整数余因子，无论次数或系数符号，均满足高端关系和低端前缀覆盖，因为越界系数取零。中心引理与第4行冲突共同给出定理。两侧反转保持归一化及二元性，并保持余因子的整数性和许可范围。

# 第60轮八次 \(\{2,3\}\) 非有理支持证书

[中文定理及完整覆盖](theorem-zh.md)。

本包无需额外数据或 Python 库。完整重算88个实二次域、11,760个 \((L,a)\) 核心、3,980个至第5行前缀、5,203个第8行必要母式及根筛。对849个根筛余项逐一运行精确双向树，848项直接排除。最后的八次余项吸收公因子 \(1+x\) 后，七次核心的精确前缀树在第67层为空。本包重新生成这67层及末行的两个整数预算见证。

```sh
/opt/homebrew/bin/python3.13 /path/to/package/replay.py \
  --out /Volumes/data/CodexTemp/T2/round060-s23-replay --workers 4
```

选择包外不存在的输出路径。解释器须启用断言。每个过程保存实际 stdout、stderr、软件版本、退出码和散列。运行从零生成全部账本并与包内冻结文件逐字节比较。独立计算使用不同的完整整环坐标、不同的第三行平移、直接 Newton 递推和不同的 Schur 系数方向，逐项重合，不把冻结账本作为枚举输入。

| 文件 | 含义 |
|---|---|
| `source/s23_entry.py` | 核心、两侧前缀及完整整除入口 |
| `source/s23_tail.py` | 兼容高端分支、尾行及严格必要根筛 |
| `source/s23_trees.py` | 双向整数树及 AB／HGQ 卷积核验 |
| `source/verify_s23_front.py` | 完整整环的独立前端计算 |
| `source/verify_s23_tail.py` | 直接低行、Newton 递推和整数范数独立核验 |
| `source/verify_s23_trees.py` | 逐层重放与第67行矛盾证书 |
| `frozen/` | 各阶段的序列、首拒码、树账本和摘要 |

每个母式记录用 `[D,L,Tr(a),r,Tr(b),s,c,d,e,f]`，\(r,s\) 是两非有理系数在完整整基 \(\{1,\omega\}\) 下的第二坐标。尾账本为每个母式记录首拒码，前9个正轴失败为 `10–18`，外、内 Schur 失败分别为 `30+失败次数` 与 `50+失败次数`。`255` 表示必要根筛仍保留。树账本对八次直接不能关闭的母式保留未知状态；独立树摘要以实际因式乘法和七次空层将其严格排除。

反转后的 \(\{5,6\}\) 同样排除，一般均匀和猜想仍开放。

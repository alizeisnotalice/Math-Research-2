# 七次S2/S5无界余因子排除证书

[解析证明](../../../proofs/050-degree7-single-position-two.md)处理实二次整系数母式 P 的唯一非有理位置2和反转位置5。余因子G/Q为任意有限次数、允许变号的首一常数一整数多项式。一般均匀和猜想仍开放。

Python标准库即可重算；实际封装使用Python3.13.18。运行时禁止-O：

```sh
python verify_package.py --mode full --workers 4 --out /path/to/check.json
```

默认full、workers1。--mode trees仍完整重算4913核心、395低端前缀及9775棵树，但仅读取母式筛的归档字节，不重做全部筛。full还从独立实现重新计算37,808,085个母式的必要筛，全部首失败码和幸存者逐项一致才成功。

## 完整覆盖和独立性

正确盒使用二次系数a的117/4界及随b变化的s2界；旧错误固定680盒永久撤回。独立低端程序从(b,T,D)矩形枚举，和原程序按迹的剩余空间枚举得到完全相同4913核心；再直接遍历c卷积重生395前缀。HGQ第三实现亦逐态重生395前缀。去重359个(T,N,D,b,c)后，每core覆盖完整105×59×17尾盒，共37,808,085条。

父筛采用SymPy导出的显式Newton式与整数范数公式，独立筛用二次域系数对的Newton递推和直接P*Pbar乘法。两者全37,808,085失败码字节、全部9775母式一致。独立程序多存reject4..7计数、axis_命名，比较器显式重算失败码直方图并映射命名；首次直接比较计数schema失败已修正，不修改或丢弃原字节。

12个压缩blocks覆盖core0..358，含两套原始JSON文本、父原始压缩失败码及逐母式空层/规范轨迹SHA。manifest绑定冻结源、块、低端ledger及历史审计。publication-manifest另绑定最终README、验证入口、完整复跑回执和最终审查。

每棵树的证书必须由验证器从头重生，不能信任一个成功字段。AB搜索器直接卷积；HGQ验证器算整数H(GQ)，取整也独立实现。全部9775树、76172层轨迹完全一致；最大活态4，最晚空层67。任意有限余因子补零必须留路径，因此空树不设余因子次数界。

最后母式P=1+(2+sqrt3)x²+x⁷的完整66行唯一状态、67行唯一整数平移及C67=2或3保存在audits/last67-witness.json，独立直接AB验证在audits/last67-audit.json。frozen/verify_last_witness.py可重算所有前66行及最后矛盾。

父完整必要筛110.574秒；独立必要筛664.456秒。完整AB/HGQ逐态一致后，最终公开封装full/workers4实际237.380715秒通过，重新生成全部4913核心、395前缀、37,808,085筛码及9775空树。回执audits/packaged-full.json保存实际命令、版本、入口及核心manifest SHA。该入口SHA1906a8dfc0e9fae19fe844d8f7ca12f35c611ffa8e46462569a229b338d647de；运行进程已结束。

冻结的历史脚本可能保留原绝对路径；可移植命令使用verify_package.py，它明确传入包内输入并直接调用纯计算函数。巨大AB重复轨迹可再生，不另提交；所有严格判定只使用整数，GPU样本不参与证明。

## 数据与算法

certificate保存53个原rootdocs、53份原gzip失败码、4个无损紧凑树JSONL包及构建时完整AB/HGQ比较回执。每个树记录给出母式、首空层/unknown、最大活态及trace SHA；验证器必须重新生成所有状态，不能仅读成功标签。完整重复trace与1.8m个原始前缀是可再生产物，未重复提交。

frozen保存主格点生成器、行6/行7必要筛、直接整环范数、独立迹范数/降幂Schur、HGQ、Fraction直接AB。original保存移植前原代码，io-adaptations.json列原/移植SHA；改动仅输入/输出路径、返回值、依赖位置及尾空白，数学算法不变。

core-manifest.json绑定运行所需核心数据/源码；publication-manifest.json另外绑定最终入口、说明、回执与补充独立来源，不自指循环。第一封装运行只重算HGQ并比对已独审AB摘要；该次198.981秒报告保留为历史，不冒称当次现场双树。最终入口加入直接AB引擎，实际最终回执另保存。

独立前缀实现位于independent，含完整整环/行6/行5-7代码及其两个输入的原始gzip。它们原main保留绝对输入路径用于溯源；需要重新运行时先提取两个json到用户临时目录，再import相应模块、将模块INPUT设为该显式路径、设置sys.argv=['script','--out','用户新目录']并调用main()。行5-7只使用已证行6数据，不导入主程序。审计文件记录全部53域规范状态集合及重数完全匹配。

# 按精确第7行缺口形状固定前缀的 MPS 探索

从[一般低行证明](../../../proofs/059-first-gap-after-fractional-linear.md)中的六次整式隔离唯一单位区间实根，先用 SymPy 验证第0至7行的卷积等式。学习变量只分配第8行正余量与后续系数，尾端固定为一。精确前缀的位置记录在 input.json，MPS 使用其 float32 近似。

实际有两个有界运行。首个128条、100步的试跑验证设备。保存的生产运行采用次数有序对 (16,24)、4,096条初始轨迹、16,000步、8个窗口，MPS实际耗时19.55秒，禁用CPU算子回退。完成后程序同步并回收设备缓冲区，主进程已退出。结果仅覆盖这组选定数值轨迹。

每个窗口保存16行，主线程用 Fraction 重算全部128行的卷积，最小记录的最大残差为 \(371652938229995/1125899906842624\)，约0.3301。未发现可供等式认证的数值候选。初次审计误把最后窗口的残差水平假定适用于全部窗口，已改为逐行严格重算，原结果字节未改。

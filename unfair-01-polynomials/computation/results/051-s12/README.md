# 第51轮S12完整格点与第四行矛盾证书

[证明](../../../proofs/051-degree7-position-one-two.md)处理首一常数一七次实二次整系数母式中，非有理位置恰为{1,2}及反转{5,6}的情形。G/Q允许任意有限次数与变号。其余七次族和一般均匀和猜想仍开放。

在Python标准库环境执行（实际Python3.13.18），指定可写临时输出位置；禁止-O：

```sh
python verify_package.py --out /path/to/check.json
```

验证器从完整二次整数环格点重新计算81域、396738个(a,b)；独立Fraction-√D乘法和直接C2/C3卷积重新生成7245低前缀，与冻结集合完全比对。随后另一独立二次域有理数对实现遍历全部760725个c、全部精确共同d区间，重新算出194个合法单位前缀；每个C4均恰为2，并与父194集合完全一致。任何异常或遗漏都阻止pass，不接受归档成功字段代替重算。

不需要枚举e/f：它们不影响四行矛盾。高端A5/B5=0只用于必要的无理投影关系，未把G/Q设为非负、未限制次数。全部真实分解必通过已穷尽的必要低行，所以结论覆盖任意有限整数余因子。

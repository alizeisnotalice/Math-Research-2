# 对 032-crossed-descent-degree-bound.md 的只读终审

审阅对象：`sync/unfair-01-polynomials/proofs/032-crossed-descent-degree-bound.md`。

结论：在其明示量词下，证明链闭合；未发现需要修改的逻辑漏洞。

核对要点：

* 常数归一 `F/f0,G/g0` 保持 H、A、B，且之后首项 `u,v` 满足 `uv=1`；定稿在中央
  边界确实保留了这一点，没有误把归一后的因子当作首一。
* `n<q` 的 B 隔离、`q<n<2q` 的两项预算、`n=q,m=3q` 的模 p 平移隔离，以及
  `m=n=2q` 的中心项分案，覆盖了 `deg H=4q` 的全部可能次数。
* `q<2p` 时 `q-2p<0` 的两项 B 系数正确；`q>2p` 时倒数反转而非交换因子，保留所有
  假设，并正确产生 `f_(q+2p)=1`。最后 C 的两种表示确为不同的支撑对。
* 锐例的 A、B 显式公式正确。以 p,q=(3,5),(3,7),(5,7) 直接精确展开，均与
  `F(x^p)G(x^q)`、`G(x^p)F(x^q)` 一致；其 C 的 pq 次系数为 2，故没有误作原定理
  的反例。

这个定理只下降已给的 crossed 形式；定稿已明确它不处理任意 AB=C 分解，范围表述正确。

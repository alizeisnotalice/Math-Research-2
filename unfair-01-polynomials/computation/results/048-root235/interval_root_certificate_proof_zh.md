# 235 个冻结 degree-54 掩码的根盘—区间负系数证书

状态：**有限精确排除。** 本证明仅适用于输入账本中 task 18--23 的 235 个指定 mask；它不对
其他 mask、次数或均匀和猜想的一般情形作结论。

## 输入与证书

对每个 task，输入是首一、常数项为一的二元整数多项式
\(C(x)=\sum_{i=0}^{54}c_i x^i\)，以及按共轭组给出的 binary64 根种子。证书把每个种子
Newton 细化后四舍五入为 80 位十进制有理中心 \(z=a+ib\)，并使用半径
\(r=10^{-60}\) 的圆盘 \(D(z,r)\)。圆心和半径、所有不等式端点、以及最终负系数上界都以
整数分子／正整数分母保存；浮点只用于提出圆心，不承担不等式。

## 根盘的严格性

令 \(w=x-z\)，并置 \(\rho=|a|+|b|\)。因为 \(|z|\le\rho\)，在 \(|w|=r\) 上有精确有理上界

\[
 \left|C(z+w)-C(z)-C'(z)w\right|
 \le T(z,r):=\sum_{i=2}^{54}|c_i|
 \left((\rho+r)^i-\rho^i-i\rho^{i-1}r\right).
\]

又 \(|C'(z)|\ge\max(|\Re C'(z)|,|\Im C'(z)|)\)，故证书逐盘直接核验

\[
 r\max(|\Re C'(z)|,|\Im C'(z)|)
 > |\Re C(z)|+|\Im C(z)|+T(z,r). \tag{R}
\]

由 Rouché 定理，\(C\) 与 \(C'(z)(x-z)\) 在该圆盘中有相同的零点数，即恰有一个（按重数计）
零点。证书还以有理 \(\ell_\infty\) 距离核验任意两圆心的距离严格大于 \(2r\)，所以圆盘互不相交。
每个 task 共有 54 个圆盘，正好等于 \(\deg C\)，于是它们覆盖 \(C\) 的全部根，且根均单。

实根组中心严格实；非实组记录为 \((a,b),(a,-b)\)。由于 \(C\) 系数实，圆盘的共轭也是同一
Rouché 证书；唯一根遂成实根或严格的共轭根对。这也将根与原始组、而非任意重排，绑定。

## 从根盘到实系数区间

对一个实根圆盘，使用首一因子 \(x-\alpha\)，其常数项在
\([-a-r,-a+r]\)。对共轭根对使用

\[
 (x-\alpha)(x-\bar\alpha)=x^2-2\Re(\alpha)x+|\alpha|^2.
\]

其中一次项位于 \(-2a\pm2r\)，常数项位于

\[
 a^2+b^2\ \pm\ \bigl(2(|a|+|b|)r+r^2\bigr).
\]

这些都是包含真因子系数的有理闭区间。对给定 mask，按冻结的“group 0 固定给 \(B\)，其余组按
大端 bit 指派”规则分别卷积两侧的首一因子区间。若一侧原始常数项区间为 \([u,v]\)，证书逐侧核验
\(0\notin[u,v]\)，再用精确倒数区间 \([u,v]^{-1}\) 归一化到常数项一。区间加法和乘法均采取端点的
全包络（本证书的 `Ball` 写法等价于该包络的一个有理外包）。因此最终每个记录系数区间包含该 root
allocation 所对应的实际实因子系数。

证书对每个 mask 给出一侧和一个系数指标，其区间上端严格小于零；所以该根分配的对应因子不可能逐
系数非负。由于所有可能根已被上述唯一、分组绑定的圆盘覆盖，结论对这 235 个**已列出的** mask 成立。

## 独立重算与边界

本目录的 `verify_exact_root_certificate.py` 不导入生成器，重新计算 (R)、圆盘分离、54 根／组／共轭、
task ID 与 mask 半空间映射、原始种子到中心的 \(10^{-8}\) 绑定、常数归一化及负区间端点。父方另以不同的
粗 Taylor 尾界和 \(10^{-100}\) 定点外舍入区间算术复核；两种验证都应以实际输出文件为准。

证书依赖有限输入 JSON 的 SHA-256 绑定。它没有构造一般次数覆盖账本，因而不能被表述为对原猜想的
一般证明。

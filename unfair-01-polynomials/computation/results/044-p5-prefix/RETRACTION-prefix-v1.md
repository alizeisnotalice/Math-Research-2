# 撤回：此前 prefix 账本不得使用

父线程的第三实现发现 `choices` 递推错误：在选择第 `k` 个余因子系数时，旧代码的
`range(1,min(len(p),len(g)))` 漏掉了 `j=k` 的项 `p_k g_0`。正确范围为
\(1\le j\le\min(k,5)\)。例如 only-\(x^2\) 参数
`s=t=b=c=d=-2` 的 `k=1`，正确余项含 `b=-2`，而旧账本把它遗漏。

因此旧搜索器和所谓独立重放共享同一个 off-by-one，互相通过不构成验证。所有旧的
P5 prefix 有限排除、D12“自由前缀归零”及其覆盖回执均**撤回**；原文件、哈希和
负测保留，仅为可审计失败记录。早先 Phi-core/only-x 若复用相同 `choices` 逻辑，
也不得再作为结论。

修正实现和新回执只写入 `revision2-corrected/`，不会覆盖旧账本。

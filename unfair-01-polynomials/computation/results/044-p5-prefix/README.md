# 五次二次域母式：修正后有限搜索

令ω=(1+√5)/2，P=1+b x+(s+tω)x²+c x³+d x⁴+x⁵，其中s,b,c,d∈{-2,-1,0,1,2}，t∈{-2,-1,1,2}，共2500个不同参数行。枚举G,Q∈Z[x]、常数1且次数≤12，不预设系数盒；检验A=GP、B=Q P̄逐系数[0,1]及完整AB二元。

正确递推在第k步必须含j=1,…,min(k,5)，特别包含p_k g0。由0≤g_k+Σ_{j≥1}p_jg_{k−j}≤1，整数g_k至多两个选项；q同理，继而检验本层卷积。12步后强制所有更高G/Q系数为0，完整检验两因子及其乘积尾部。未限制首项的更大候选集也全被拒绝，故覆盖首一G/Q。

旧search和重放器共有一个range上端漏项错误，曾给出错误的自由前缀归零判断；这组未发布探索结论全部撤回，见RETRACTION。第一参数k1应有4尝试/3合法，旧版错误给0。修正版独立direct-A*B重放通过，父再用第三套isqrt精确floor、直接构造A/B和卷积逐参数重算。

父自由层数为7500,7500,7000,5600,3635,1926,904,477,202,104,40,15。完整15个末端前缀均由明确系数违例排除，见finite-cap12-tail-rejections.json；因此仅证明上述2500母式、degG/Q≤12无解。

不带强制尾的第24层仍有3个前缀，不能声称任意次数排除。corrected-depth24-summary及全状态压缩件作边界记录。

search_x2.py 与 direct_ab_verify.py 是本次实际版本；父verify_finite_cap12.py另用独立参数表和数学实现。所有算术为Python整数；isqrt floor的正负分支精确，不使用浮点近似。脚本保留实际本机输入路径，公开复现时将INPUT设为由本目录x2-D12.json.gz解压得到的x2-D12.json，其字节hash须与回执一致。

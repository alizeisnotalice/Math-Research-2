# 七次 S3/S4 完整排除证书

本包证明：实二次域中首一常数一七次母式只有第三位非有理时，不存在任意有限次数首一常数一整数余因子 G、Q，使 GP 与 Q Pbar 非负且乘积二元。反转给第四位同一结果。一般均匀和猜想仍开放。[解析证明](../../../proofs/049-degree7-single-position-three.md)固定全部假设。

## 可移植复现

只需要 Python 标准库，无外部数学库；实际主验证解释器 Python 3.13.18。不要使用 `python -O`。在本目录运行，输出位置换为可写临时目录：

```sh
python verify_package.py --mode full --workers 4 --out /path/to/full-verification.json
```

默认 `--mode full --workers 1`。完整模式重新枚举所有 669 个迹范数核心、27,909,836 个 Newton 必要母式，对逐项首失败码、幸存母式和计数逐字节比较，再从头重建全部 90,092 棵整数余因子树。所有末层为空才成功。四 worker 只并行独立核心，不改变整算算法或覆盖。

`--mode trees` 仍从头生成 8,697 个低端代表和 17,760 个前缀态、全部 90,092 棵树及 854,628 层，但只核对已归档母式筛的内容和哈希，不重新计算母式筛。实际封装 trees 运行 46.161 秒；其回执明确标注此范围。

## 数据与独立性

21 个 blocks 覆盖连续 0..668 索引。每条保存父筛、独立筛、紧凑树证书的原始 UTF-8 字节及 SHA，以及原始压缩失败码。manifest.json 绑定全部核心文件与分块；publication-manifest.json 另绑定最终验证入口、说明、运行回执及数学审查，不改已经核验过的核心 manifest。

父母式筛采用整数范数公式与升幂 Schur；独立筛直接在二次域系数对中相乘，并用降幂 Schur。此前完整 669 项独立运行 1449.111 秒，与父筛的所有 27,909,836 个失败码及幸存母式完全相同。对应实际命令、版本、输出来源见 audits/independent-full669-run-receipt.json。

frozen/independent_screen.py 的历史 main 只运行六个诊断核心，不是全范围入口。历史完整驱动逐字节保存为 frozen/independent_full_driver_original.py，其原始绝对路径保留用于溯源；可移植完整入口始终为 verify_package.py，它直接对全部 669 项调用 one()，不调用六项诊断 main。

树搜索器直接卷积 AB；父独立实现计算整数 H(GQ)，二次符号二分取整也独立实现。两者全层轨迹一致。紧凑证书只保存母式、首空层、最大活态及规范轨迹 SHA；验证器必须重新推导全部状态，不能把一个“成功”字段或 SHA 当作空树证明。最大首空层为 53，最大同时活态为 27。任意有限余因子补零后都必须延伸出一条路径，所以空树排除任意次数，并非只检验余因子次数≤53。

最后母式 (T,N,c,d,e,f)=(5,2,0,0,0,0) 在 48 层仍未知，继续完整整算到 53 行，两种末行选择分别强制卷积系数 2 或 3。audits/last-core-coefficient53-witness.json 和解析证明保存可读整数见证。

- 早期有理系数行漏掉 1 端点的 16,576 态版本撤回；最终完整前缀为 17,760，并逐态独立重算。

未压缩重复大轨迹是可再生产物，不入 Git；分块内每个母式都有重新计算所需输入。所有严格判断均为整数算术，GPU 数值样本不参与本证明。

# Round 36：q=21 的规则 6/7 独立审查

在既有短侧前缀前提下，所有次数小于 (2q) 的普通卷积项非负，且对
(j\in K) 有 (0<g_j\le1) 与 (h_j=1)。因此

\[
0\le f_j\le1-g_j<1. \tag{A}
\]

若 trace 的 `zero-single-product` 在 (k=s+j<2q) 处逐项证明除了
(f_sg_j) 外的每项为零，则 (h_k=f_sg_j\in[0,1))。二元性给
(h_k=0)，所以 (f_s=0)。它不需要 (h_s) 只有两个普通卷积项；(A)
已足够。

对于 `zero-two-products`，trace 要求 (0<s<t\in K)，(k=s+t<2q)，
且除 (f_sg_t,f_tg_s) 外所有项为零，至少一个待推出零尚未在零集。于是

\[
 h_k\le(1-g_s)g_t+(1-g_t)g_s<1,
\]

严格性来自
\(1-[(1-g_s)g_t+(1-g_t)g_s]=(1-g_s)(1-g_t)+g_sg_t>0\)。故二元性迫
(h_k=0)，两个非负项分别为零，继而 (f_s=f_t=0)。

独立程序以所有含 0 的 (21)-位掩码为起点，分别枚举
(p\in\{2,4,5,8,10\}\) 的无 (p)-差和无模 (p) 单元类条件；它不调用
生产 DFS。随后逐 event 重放规则 1--7、双侧零集和四角 unit 起点。此有限、
条件性的核验不将剩余 4 个 unknown 解释为可行因子，也不证明一般猜想。

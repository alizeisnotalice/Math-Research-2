# 推荐研究配置

配置依据：用户批准的初始化方案、旧仓库逐轮精简归档规则、经验库列出的源记录。未安装新软件、未启用付费服务、未创建定时任务。

## 研究闭环

每轮固定“目标与假设 → 关键推导/最小探路 → 决定性核验 → 报告与状态更新 → 精简提交与远端确认”。
中文报告为默认；符号沿用课题定义，正式论文按需要提供 LaTeX 与 PDF。
报告开头说明适用输入、实际改善和下一条未证不等式；负结果可以结束一轮。
若用户指定持续攻击同一命题，局部引理失败不能擅自更换主目标。

## 本机工具

Python 用于精确有理证书、快速搜索与复现；SymPy/mpmath/SciPy 按实际环境可用性选用。
Mathematica 用于精确符号、分段条件、消元和高精度；MATLAB 用于优化、积分、独立数值和论文绘图。
先选择一种适合的实现，决定性结论再做必要独立复核；不为占用资源重复跑旧批次。
初始化只探测已有工具入口，不执行旧数学脚本，不宣称数学重验成功。
不默认安装依赖；课题首次实际运行后记录真实版本和最小依赖。

临时目录在确认 data 挂载后创建。需要为某次命令重定向时使用：

```sh
TMPDIR=/Volumes/data/CodexTemp/T2 TMP=/Volumes/data/CodexTemp/T2 \
TEMP=/Volumes/data/CodexTemp/T2 XDG_CACHE_HOME=/Volumes/data/CodexTemp/T2/cache \
python3 <最终脚本>
```

LaTeX 输出目录、Python 字节码/绘图缓存及下载缓存也显式放该目录。完成本轮自己启动的计算后退出对应子核/会话；不关闭用户已有或其他课题的会话。

## 持久记忆与来源

仓库中的 AGENTS、STATE 和 knowledge 是跨会话可读记忆。不要把它表述成已自动导入全部 Codex 聊天历史。
按需读取旧报告时验证来源哈希、模型和当前有效状态；历史绝对路径只作定位线索。
旧 Math-Research 的 Git 历史仍由旧项目保存；新仓库不复制其 `.git` 或全部研究产物。

## 公开成果与本地材料

公开成果逐文件选择；本地不可替代材料放 `.local/`，可再生中间件放 CodexTemp。
必要论文附件需有公开分发依据；一般只保存题录、链接、哈希与自写笔记。
不因公开建仓就添加许可证，研究成果的许可方式留待用户明确指定。
GitHub 同步和本地备份分开验收，当前备份核查见初始化记录。

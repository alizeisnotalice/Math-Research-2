# 第69轮　共同谱的十点门槛与无界依赖构造

在私有方向的真实切片至多四点时，共同带的均值只取 0、±1/2、±1。若每十个以内的共同标签仿射独立，则每个地址至多同时激活四个共同标签，第68轮的数据秩界 (23/√96)√s 保持。九点独立已允许十个标签同时活跃，存在完整的布尔实现。此反例确定了活跃数判据的门槛。[证明与锐例](../proofs/069-wise-threshold.md)

若长度至多十的极小偶关系两两不交，即使关系有任意多条，每片至多激活 16 个共同标签，数据秩至多为 √(1009/96)√s。一般重叠关系也可按实际同时活跃的标签进行配对收缩，支付至多四倍的短关系秩。[不交回路定理](../proofs/069-short-circuits-finite-means-zh.md) · [重叠时的预算](../proofs/069-odd-annihilator-defect.md)

构造了共同秩 30N、依赖秩 2N、袋数无界的真实布尔族。在一个版本中每个共同标签在每个袋中都与私有标签共同活跃，在另一个版本中局部预算 529/96 取等。[构造及计算说明](../proofs/069-dependent-common-labels.md)

双机 CPU 与 Metal 分别核验同机上的全部输入，共计 1,000 万个确定性案例编号、279,999,960 个固定切面。实验针对独立商标签的纤维模型，允许同一商标签有许多不同原像。76,722,845 个切面以真实私有谱成本达到 529/96。另用 Python 独立核验 8,192 个案例。十回路的必要性由独立的精确反例检验承担。[运行记录](../computation/round069/dual/RUN_RECORD.md) · [十点反例证书](../computation/round069/result.json)

# 第52轮　共享频带的多个局部原像与符号相消

在仿射分割上固定一个共同标签 $\beta$。设其全局频带能量为 $E$，第 $i$ 块上相应的局部系数列为 $c_i$。由仿射限制的系数恒等式，真实带的谱点数满足 $s_\beta\ge\max_i\|c_i\|_1^2/E$。把各块系数的符号按实际块位置相加，可以从多个块联合得到更强下界。给定各带的下界后，按局部谱点数和块质量分配其平方预算，可建立不依赖随机块次序的共同秩判据。它假设各块已有 $D_i\le2\sqrt{s_i}$，不要求所有活动块的并为仿射平坦。[能量、符号与确定性秩判据](../proofs/052-energy-and-sign.md)

一族构造中，每个数据标签都被全部 $8\cdot4^k$ 个块读取，且在每块恰有四个局部原像。单块能量给出的带下界为4，不足以通过该秩判据；相同输入的已知局部符号给出精确下界 $16\cdot4^k$，足以通过。$k=0$ 时可用秩扣减为39，两种估计分别需要42和36。随 $k$ 增大，标签重数无界。这一结论由二次型分块证明；四个有限规模用完整整数 Walsh 另行核对。[精确结果](../computation/round052/signed-planes.json)

另外两组构造专门检验非仿射活动域。为确保共同切向确是所声称的数据空间，将一个非活动地址细分为八个选择单点，分别用不同的私有字符。在一个有符号例中，单块能量下界为 $64/5$，合并符号后为 $320/9$，实际频带64点。全局有912个谱点、$D=23$，可用秩扣减为27，符号判据所需为10。四组实例逐项比较12672个频带系数。[几何与解析公式](../proofs/052-verified-fibers.md) · [整数核验](../computation/round052/verify_corrected_gluing.json)

复现时在本轮计算目录运行 `python3 signed_planes.py` 和 `python3 verify_corrected_gluing.py`。两程序仅用 Python 标准库。一般 A28 仍开放；目前没有从布尔性单独推出任意分割都具有所需的局部符号相消。

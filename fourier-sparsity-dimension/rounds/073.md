# 第73轮　所有单次频率商的障碍与原谱秩比值的保持

用一个选择位在两组各 m 个变量的单点翻转函数间切换。令 N=2ᵐ，则谱大小为 4N−3、秩为 2m+1（m≥2）。对其遍历所有线性商及所有允许的活动陪集，单位权最优 LM/s 的量级为 √N，再允许逐带选任意正权，最优 D/s 的量级仍为 N 的三分之一次方。两种量级均有上下界。这回答了第71轮提出的选商问题。[两平面族的证明](../proofs/073-two-planes.md)

进一步，对任何给定布尔函数序列 G，只要稀疏度趋于无穷，就能构造 F，渐近保留 d_G/√s_G 的比值，同时强迫 F 的所有商和所有正权的 D/s 趋于无穷。因此即使只在接近极值的函数上寻找好商，也不能单凭这一乘积证明 A28。组装使用一个经有限概率法证明存在的固定49变量种子；本文没有给出该种子的具体真值表。另有全显式的多分支构造，在 d 与 √s 同阶时阻碍单位权的所有单商。[比值保持定理](../proofs/073-preserve-ratio.md) · [概率种子与张量证明](../proofs/073-all-quotients-cube-obstruction-zh.md) · [显式分支构造](../proofs/073-all-split-obstruction.md)

本机还穷尽四变量全部真值表的 4,390,912 个线性核测试，四变量以内每个函数都能令 LM/s=1。五变量负集为仿射单形的函数已有严格障碍；其 s=22，在全部374个核中，最优真实 LM=32，最优陪集 LM=28。另对两平面族的 m=1,2,3 实例逐核复算，七变量实例覆盖29,212个核。[小维核验](../proofs/073-small-dimensions.md) · [两平面计算](../computation/round073/two-planes.json)

一般 A28 的平方根界仍开放。这些反例排除了单商乘积的一致上界，仍允许直接使用已分配的法向秩、按代表行取商或按真实布尔分支递归。

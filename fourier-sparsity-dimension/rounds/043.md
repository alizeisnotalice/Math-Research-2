# 第43轮　共享与私有查询交错时的锐预算

允许选择树反复查询任意共享输入函数，同时穿插全局独立的私有选择位。设 $n$ 为有效私有位数，$g$ 为左右两边都还有有效私有位的共享节点数，两侧的有效性只要求在各自某个可达输入上出现。若全函数的稀疏度为 $s$，则

$$ n+g+1\le2\sqrt{s}. $$

任意多层的显式树可取等，单个共享方向的出现次数也可任意大。若共同输入的谱依赖空间维数 $b\le g$，由此推出全函数 $s\ge(d+1)^2/4$。证明通过每条共享路径的可达概率逐子树结算。它还给出一些私有查询线性相关、但标记节点的频率陪集仍分离时的扩展。[证明、取等族与假设](../proofs/043-mixed-tree-budget.md)

**验证。** 本机 Python 对七种模板的41375组赋值逐子树比较了12950000个整数系数，并检验了111743个含有效私位的子树；有456组根节点达到加强界等号。测试包括重复奇偶导致的不可达路径、非线性共享选择的不等概率分支，以及自身均值差为零而仍有效的私节点。[脚本](../computation/round043/mixed_haar_audit.py) · [本机结果](../computation/round043/mixed_haar_result.json)

本机 M6 和 MacBook M5 Pro 的 Metal 各计算128棵混合树的162116个系数。两台机器分别与自己的 CPU 和独立分层公式逐项比对，涵盖795个子树和33个完全不可达的私节点。[本机 GPU 结果](../computation/round043/local-mixed-metal.json) · [MacBook GPU 结果](../computation/round043/macbook_r43_shared_private_result.json)

复现时进入本轮计算目录，运行 `python3 mixed_haar_audit.py result.json`、`python3 audit_shared_private_tree.py`，以及 `swiftc -O R43SharedPrivateTreeMetal.swift -o mix && ./mix metal.json`。部分共享决策可以发生在没有有效私有位的一侧，这类节点不会贡献 $g$。对一般布尔函数，尚未控制未被扣减的共享维数，也未得到趋零反例。

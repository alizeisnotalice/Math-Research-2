# 第49轮　单问失败、两问取等的无界谱族

对每个 $H\ge1$，构造一个具有 $d=2N-1$ 个独立谱方向、恰有 $s=N^2$ 个谱点的布尔函数，其中 $N=4\cdot2^{H-1}$。因此 $s=(d+1)^2/4$。在第48轮的同常数秩预算中，任何一个严格降谱的奇偶查询都无法支付 $C=2$。然而任取两个独立的地址查询，合并计算这两层就恰好可以支付。该障碍覆盖任意大的谱维数。

构造用三位地址的四条互不相交的仿射线分配四棵变量互异的完整树。每个终节点给出一个 $N$ 点平坦谱带。一个降谱查询要么命中部分谱带，要么恰好使两个不同终标签的带发生碰撞。前者中每个仅能在一支出现的私坐标都降低两子的交秩。后者中，只有两条兄弟谱带可能完全碰撞，此时还需扣掉其最后一个共同祖先带来的两个独立线性约束。两种情形均不能传递一次同常数预算。将地址限制到一条线以后，剩余函数总是一棵完整树，这使两层预算闭合。[构造、全部方向的证明与两层账本](../proofs/049-aperiodic-sharp-family.md)

整数程序在高度1、2、3、4逐一核对全部严格降谱查询，数量依次为54、822、13014、207702，合计221592个。对应判据平方后，最接近成功的差值分别为−12、−48、−60、−124。各高度都用稀疏自卷积检验 $F^2=1$，前两高度另用完整真值表的 Walsh 变换复核。源程序无随机输入，使用64位二元消元。可在本轮计算目录用 C++17 编译并运行，四个高度的输出均为 JSON。[源码](../computation/round049/paired_lines.cpp) · [实际核验结果](../computation/round049/paired-lines-audit.json)

## 双机四路实测

第47轮双机 CPU 和双机 GPU 的长批分别完成后，恢复了 MacBook 的 SSH 持久连接，另以四个任务共用的 UTC 闸门运行新样本。本机分配12个 CPU 线程，MacBook 分配15个。CPU 用两种方法复核2048个新九变量三次函数，856个在全部五维仿射平坦上均非常数。GPU 在两个独立区间上计算3.7亿个不同三次函数的1894.4亿个 Walsh 系数，CPU 抽检362496个系数。

四路进程共同窗口为9.669秒。交叉两机各 CPU 分片和各自 Metal 命令的活动区间，剔除空档，得到累计6.024秒、392个区间。该交叠依赖两机系统时钟对齐。严格交集内，A28 的 CPU 占用采样均值在本机为5.990/12核、MacBook为14.413/15核，整机 CPU 活跃率中位数均为100%。本机 GPU 的30次采样为93%至100%，MacBook GPU的32次采样全部为100%。这些 GPU 百分比为整机读数；本任务的执行另由 Metal 命令区间验证。任务均已退出。[计时输入与复算方法](../computation/round049/load049/README.md) · [四路核验结果](../computation/round049/load049/VERIFIED.json)

# 第42轮　独立查询节点的锐预算与任意布尔叶

若每个节点使用不同的独立选择位，叶输出共享数据上的任意布尔函数，记 $s$ 为总 Fourier 稀疏度，则有效选择位数恰为选择投影谱的线性维数，并满足锐界 $n\le2\sqrt{s}-1$。叶谱无需稀疏，叶间可任意重复。证明将整树按路径上最深的选择频率精确展开，允许有效内部节点的两个子树均值相等。这类节点虽不产生自己的差分项，仍会出现在后代的谱上。[完整证明与取等族](../proofs/042-tree-query-budget.md)

若 $p_i$ 是到达叶 $i$ 的概率，$r_i$ 是其数据谱线性维数，则总谱维数满足 $d\le(2+\sqrt{\sum p_i r_i})\sqrt{s}-1$。因此平均叶谱秩一致有界的此类树不能产生 A28 零比值族。叶谱秩无界时，查询部分仍满足同一锐界。

**计算。** 本机12进程和 MacBook 15进程共同穷举完整三层树的 $6^8=1679616$ 种赋值。六种二变量叶分别以真值掩码0、15、3、5、1、2编码。每例用512点整数 Walsh 变换直接验证最深节点公式及查询秩界，共22例查询界取等。108个分片全部覆盖且互异。[源码](../computation/round042/exhaustive.c) · [本机48片](../computation/round042/mini.txt) · [MacBook 60片](../computation/round042/macbook.txt)

在2至5个数据变量的160个非字符叶案例中，MacBook 的 CPU、Metal 与独立公式逐项比较了307200个系数。另用独立 Python 实现验证36棵树，包括均值差为零的有效根。[设备结果](../computation/round042/macbook_r42_haar_tree_result.json) · [Python 结果](../computation/round042/audit_independent_tree_layers.json)

复现时进入本轮计算目录，执行 `cc -O3 exhaustive.c -o exhaust`，用 `./exhaust i 108` 对0至107的每个 i 各运行一次；每行依次为分片号、已检例数与取等数。可另运行 `python3 audit_independent_tree_layers.py`，以及 `swiftc -O R42HaarTreeMetal.swift -o haar && ./haar result.json`。一般 A28 仍开放。

# 第66轮　商空间中的四点关系与带孔核心

对任意线性频率核心 H，设 q 是核心外的实际谱点数，r 是投影秩，u 是所有投影四点零和关系的指示向量所张成空间的维数（标签集中补入零）。证明了 r≤2u+√q。因此 u=O(√q) 时，外部秩满足平方根界。证明对四点关系按连通分量计秩，再用布尔切片的活动区域与 Fourier 不确定性支付分量数。对一般输入仍需控制 u 或找到合适的核心并控制其维数。[证明](../proofs/066-projected-relations.md)

本机逐一计算四变量及以下的所有布尔谱，在所有坐标投影上核对关系秩与分量计数；四变量有 1,027 种不同支撑、16,432 个投影测试。[复现脚本](../computation/round066/verify.py) · [整数结果](../computation/round066/verified.json)

双机另对仿射限制核验了 140,000,000 个案例编号，各自的 CPU 和 Metal 独立处理同一范围并取得相同校验和。其中恰有 70,000,000 个带孔核心案例。一个实际布尔函数在 32 点核心内只有 20 个频点，整个谱有 28 点，外部秩为 3；碰撞预算用到的尾部数是 8。两个指定带孔模型的 28,740 个仿射限制另用 Python 完整枚举。

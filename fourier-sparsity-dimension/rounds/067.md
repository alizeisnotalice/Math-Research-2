# 第67轮　四点平面判据与锐投影秩界

任取一个频率核心，记 r 为投影标签的线性秩，q 为核心外实际谱点数。在投影标签集中，假设每个四点仿射平面都有一个方向恰有两组无序配对。此时每个真实布尔切片是单点或四点平面，且 r≤3√q/2；有任意大维数的取等例。这个条件容许重方向的数量与重数无界。若有 J 个平面破坏条件，仍有 r²≤q max(9/4,6J)。当每个切片线性秩至多二时，锐界进一步为 r²≤4q/3。[四点平面定理](../proofs/067-projected-near-sidon-zh.md) · [二秩情形与等号](../proofs/067-rank-two.md)

一般情况下，可在每个标签的四点关系邻域中缩小候选集。所有超过四点的切片都留在稳定集 K 中；其张成空间以外的增量秩仍满足常数 3/2 的平方根界。在四维的全部 65,536 个候选集上，逐一对照所有真实大切片，邻域方法在 29,680 个候选集上严格优于只保留重方向端点。对一般函数，K 的维数仍待控制。[证明](../proofs/067-peeling.md) · [核验结果](../computation/round067/localized.json)

两台 Mac 分别用 CPU 和 Metal 各自复算分配的全部案例。700 万个确定性案例编号共有 2,176,787,113 个投影基，全部满足基大小平方的切片占用上界。两机整机 CPU 有效空闲率采样均为零，项目平均用核 6.98 和 5.80，完成 1,954 和 1,465 条 Metal 命令。另用 Python 整数运算独立复核 4,096 个案例。[双机运行、收据及复现命令](../computation/round067/dual/RUN_RECORD.md)

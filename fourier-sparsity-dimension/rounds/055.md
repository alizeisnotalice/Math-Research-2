# 第55轮　任意布尔谱在多方向上的两个最小总质量

在布尔函数的 Fourier 支撑上取 r 个线性独立的仿射评价字。记 A 为这些字至少有一个取值为 1 的频率上，归一化 Fourier 系数的绝对值总和。只要求评价字在实际支撑上独立，允许某些非零标签完全缺失。

最小值为 A₀=2−2^(1−r)。当 r≥2 取等时，非零标签的支撑共同构成一个仿射平坦删去一个陪集，其上的幅度恒定，符号来自同一个仿射字符。证明还给出零标签带的系数峰值及物理空间正规形。

严格大于 A₀ 时，最小可能的差 A−A₀ 在 r=1,2 时均为 1/2，在 r≥3 时等于 1−6/2ʳ。证明先分析单个半窗的范数，再用超平面的取等结构和方向亏损的矩估计作秩归纳。每一秩均给出显式布尔函数取等。

- [端点证明](../proofs/055-endpoint.md) 和[各秩精确间隙证明与构造](../proofs/055-uniform-gap.md)。
- [四变量及以下整数穷举](../computation/round055/RUN_RECORD.md) 包括3344400个函数–子空间对。复现所需模块为第53轮的 [half_windows.py](../computation/round053/cpu/half_windows.py)。
- [双机复现记录](../computation/round055/dual/RUN_RECORD.md) 与[联合验收结果](../computation/round055/dual/VERIFIED.json) 包括20000000个五变量真值表、55213052568个满秩评价组。本机承担800万张表，MacBook承担1200万张表，两台机器分别用 C 和 Metal 交叉验证。所得秩2至6的最小正间隙依次为 1/2、1/4、5/8、13/16、29/32。样本为两个不相交的编号区间。

测得本项目进程的 CPU 峰值为本机 893.913%、MacBook 1033.711%，100%计一核。两机整机 CPU 和 GPU 采样峰值均为100%；开跑前 GPU 已有负载。四个正式作业均正常退出。以上有限核验独立于一般秩的解析证明。

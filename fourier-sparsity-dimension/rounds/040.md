# 第40轮　四变量全部基相位与六变量固定 MM 子码的精确枚举

四变量 bent 相位的次数至多二次。去掉仿射部分后，共有28个可行的二次基相位。固定任一个基相位，得到下表；加回任意仿射部分保持相同的合法扰动集合。

|码维数|最小实际支撑|达到最小支撑的码数（每个基相位）|
|---:|---:|---:|
|4|12|1500|
|5|14|5400|
|6|15|720|
|7|16|45|

[C++ 枚举](../computation/round040/census_4d.cpp)把码投影到齐次二次项空间，枚举投影及其仿射核，再枚举投影基在模该核意义下的全部提升。计算确认可行投影的维数至多2，仿射核维数至多5，由此也排除四变量的八维共同码。每一个所计空间都重新展开并核对共同合法性与支撑。[28个基的完整结果](../computation/round040/census_4d_result.json)包括见证和全部支撑大小的计数。对标准基，四维12点码在仿射辛群作用下有五个轨道，大小为120、180、240、240、720。

固定六变量标准 Maiorana–McFarland 基相位与第36轮的三维四原子偶权子码，并要求每一相位均保持在同一坐标分解的 MM 类中。对支撑至多40点的五维扩张，141845个非零候选陪集给出10059931090对；核验外部支撑，并检查两者之和仍为合法陪集，取二维商空间的规范代表避免重复。分别有132、2745、51120、18432、424792个码支撑为28、32、36、38、40。未出现其他至多40点的支撑。28点实例达到第39轮的全维锐界。见[枚举代码](../computation/round040/make_mm_e4_cosets.c)与[MacBook 输出](../computation/round040/macbook_mm_e4_five_result.json)。

本机12个工作线程执行四变量枚举。MacBook 上15个线程执行六变量 MM 枚举；交换机器复算后，五档计数及见证全部一致，四变量枚举的28行完整结果亦逐行相同。[Python 独立核验](../computation/round040/verify.py)直接检查28个基每基四组最小见证和 MM 五档见证。本机 Metal 计算了30408704个 Walsh 系数，与 CPU 的1900544行摘要逐行相符，见[Metal 源码](../computation/round040/RawWalshMetal.swift)和[设备输出](../computation/round040/raw_walsh_metal_result.json)。

MacBook 的 M5 Pro GPU 另以分层整数 Walsh 变换核验全部65536个四位参数符号表，1048576个系数与 CPU 直接字符求和完全一致。[设备输出](../computation/round040/macbook_phase_modes.json)

复现时进入 `computation/round040` 执行以下命令。两次 CPU 枚举均为完整确定性枚举，无随机参数。

```sh
c++ -O3 -std=c++20 census_4d.cpp -o census
./census 12
cc -O3 -pthread make_mm_e4_cosets.c -o mm
./mm 15
python3 verify.py
swiftc -O RawWalshMetal.swift -o metal
./metal
swiftc -O R37PhaseModesMetal.swift -o modes
./modes modes.json
```

一般六维及更高维共同码的精确最小支撑仍未知。上述有限结果没有给出一般 A28 的证明或反例。

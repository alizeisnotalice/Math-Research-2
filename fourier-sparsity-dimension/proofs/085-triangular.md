# 从字符出发的二次塔合成与谱代价

区分两种运算。

1. **新地址提升。** 与第 84 轮相同，F(u,x)=(-1)^{c(u)}G(x+T(u))，其中整个 u 块是本层新变量，c、T_i 的二元代数次数至多二。允许各层间作可逆仿射换元；允许后代平移从前各层的变量。
2. **固定寄存器的三角门。** 允许反复使用已存在的变量。按固定顺序排列寄存器，每个门把较早目标位加上较晚若干位的次数至多二的多项式，其余位不动。门可以重复使用此前已经出现的控制位。这不是第 84 轮的一次新地址提升。

记 s 为实际 Walsh 谱大小、d 为普通线性秩、R 为齐次谱秩、P=(R+1)/√s。

## 1. 线性步骤、幅度和恒定二阶差分的障碍

**线性步骤不能从字符生成非字符。** 若 c、T_i 均为仿射，还原为仿射换元及字符调制。更一般地，若每个活跃频率 e 的实际相位 (-1)^{c+e·T} 都是带符号字符，则为旧频谱的线性剪切，s 和 R 精确不变。因为相位随齐次标签成乘法线性，任选旧谱仿射基，其相位字频率确定一个一致的仿射映射，所有带均为该映射的图。因而从字符出发仅反复使用线性相位，甚至再作仿射限制，仍只得到字符或常数。

**新地址塔的幅度必要条件。** 初始字符唯一谱点的模长为一。在任一二次提升，每个父点由唯一旧数据标签和一个新地址频率组成，相位谱中非零模均为 2^(−r/2)，r 是实际极化秩。因此从字符出发所有非零模长始终是二的负整幂。可逆仿射换元、字符调制与添加虚变量只重标或移动系数。因此三个或更多变量上的单点翻转函数（其均值模为 1−2^(1−n)）不能作为无辅助限制的新地址塔输出。固定寄存器模型的不同结论见 §3。

**幅度条件并不充分。** 任何非字符新地址塔的相位 p=(1−F)/2 都存在一个方向对 v,w，使二元差分 D_vD_w p 恒等于一。第一次非仿射步骤以前仍为字符，第一次实际非线性来自某个新地址块上的二次相位。其非零极化给一组 v,w。所有随后平移旧变量的函数只依赖新地址，所以对旧变量的该二阶差分恒等式保留。仿射换元把 v,w 推送到新坐标，整体字符调制和虚变量也不会产生或消除此性质。

取四位排列 π（按十进制地址顺序）

```
(6,7,12,11,2,0,5,4,13,15,8,14,1,9,10,3).
```

八位函数 F(x,y)=(-1)^{x·π(y)} 等幅满谱，每个 Fourier 模长为 1/16（先对 x 求和只留下 π(y)=α）。但其相位没有恒等一的二阶差分。对该排列，整数直接核验：

- 任取非零 y 方向 b 和非零四位线性泛函 u，u·(π(y+b)+π(y)) 都不恒等于一。
- 任取不同的非零 y 方向 b,c，向量 D_bD_cπ 都不恒等于零。

若一对完整方向的 y 投影不同且都非零，第二条说明 D_vD_w(x·π(y)) 仍依赖 x；若 y 投影相同，则可把一个方向换成两者之和而保持二阶差分不变（D_(v+w)D_w=D_vD_w），从而转为一条纯 x 方向。只有一条纯 x 时用第一条。两条都是纯 x 则二阶差分为零。故该显式等幅 bent 函数也不属于新地址塔。仅靠此结构不变量也不能证明 A28：给任意函数张量乘一个独立二位 bent 因子就有恒等一的二阶差分，且 s 乘四、d 加二，保留至少一半秩稀疏度比，但未必满足纯二幂幅度条件。

## 2. 新地址塔经仿射限制能合成任意真值表

任意 n 位布尔相位 p 用布尔环中的平方自由代数正规形表示。将每项写成由 AND 门构成的树，最上层用 XOR 求和；复制输入使每个内部线只被一个父门使用。按离输出的距离分层，每个单项式用同样深度的完整二叉树，不足的叶填常数 1。可用 O(n2^n) 条线、在允许成批加入同一层新地址时至多 ⌈log₂n⌉+1 层（宽 XOR 仍是线性门）。

初始输出为一个目标位的字符。每次加入下层门的新变量：对本层每个尚待计算的目标位，添加下层孩子位的 AND 或 XOR，全部都是新地址块内次数至多二的平移。没有必要把中间输出物理位立即固定。最后统一取一个仿射限制，把全部内部目标位设为零，复制输入叶识别到真实 n 位变量，并代入常量叶。由公式树自底向上，得到确切 p。这给任意表的真实仿射限制。只用第 84 轮已证无损的秩二步骤也足够：公式没有扇出，每层不同 AND 门的新孩子互不相交，故可顺序加入各对控制位（这会增加按小步计的深度）。每步仅以新位的一个二次乘积平移一位，其余步骤全线性。因而未限制父函数甚至满足 P≤2。它仍有 §1 的不变量，因此合成与无辅助谱表示是两件事。

### 任意小谱膨胀的统一承诺不可能

设 H 的所有非零 Fourier 模长为二的负整幂，G 是 H 的一个 n 维仿射限制。每个目标系数 `Ĝ(β)` 是对应频率纤维内父系数乘 ±1 后的和。令 w(m) 为整数 m 写成带符号二幂之和所需的最少项数。这个最少项数在乘除二的整数幂时不变。若表示整数时使用负指数，各最低负指数上的带符号项数为偶数，可以两两抵消或合并，一直移除所有负指数。因此归一化乘 2^n 后，频率纤维宽度至少 w(W_G(β))：

```
s(H) ≥ Σ_β w(W_G(β)) .
```

存在满谱 G，使平均 w 至少 c n，其中 c>0 为绝对常数。取均匀随机真值表，条件于负点数为奇数。n≥2 时所有 W_G(β) 模四余二，全部非零。对任一 β，未条件化的 W_G(β) 是 2^n 个独立 ±1 之和，最大原子 O(2^(−n/2))，条件化至多乘二。另一方面，若 |m|≤2^n 且 w(m)≤t，则可令所用的非负指数互异（相同指数合并）。若最大指数为 E，其他 t−1 项最大可能抵消到仅剩 2^(E−t+1)，故 E≤n+t−1。取 t=⌊n/64⌋，整数候选数至多 Σ_{j≤t} 2^j binom(n+t,j)≤2^(n/4)（n 充分大，由 binom(a,b)≤(ea/b)^b）。因此对每个 β，w≤t 的概率 O(2^(−n/4))。按频率求平均并取一个不超过均值的真值表，得到 1−o(1) 比例的频点有 w>t。对这些满谱 G，任何纯二幂父谱合成满足 s(H)≥c n s(G)。

若字面上的 n 维仿射限制在父物理空间的余维只有 O(n)，则 d(H)=O(n)，而 d(G)=n，故 d(H)/√s(H) 至多为目标比值的 O(n^(−1/2))。更一般，若要在这些目标上达到固定正比例，而用一个 n 维实际仿射切片编码，父维数须为 Ω(n^(3/2))。这个障碍排除统一线性谱膨胀和低余维比值保持，不排除使用大量额外变量、同时增加父秩的构造。

### 可把任意目标放进 P 接近 2 的新地址塔

从字符 z 出发，每个当前叶的私有位 x_i 依次增加三个新控制位并作二次平移

```
x_i ← x_i + u_(i,0)+a_i(u_(i,0)+u_(i,1)).
```

此步让该叶按 a_i 选两个新的私有字符，同时保留原叶守卫因子。h 层得到 M=2^h 个叶，每条路径活动域是余维 h 的仿射平坦，地址宽为 M。不同数据标签各含其唯一的终端位，所有路径法向合计给 M−1 个地址维。故 s=M²、R=2M−1、P=2。选定一个叶，用本节公式树仅更新该叶终端位及它的新孩子。其他 M−1 个叶不依赖这些新变量。若单独合成该困难叶的实有谱大小和齐次秩为 s_H、R_H，则全塔恰有

```
s = M(M−1+s_H),    R = (M−1)+(M−1)+R_H.
```

第一项是廉价叶数据秩，第二项是选择路径的地址秩。独占终端位及困难叶全新坐标使数据块直和。通过固定选定路径及公式树的仿射约束，整个塔真正限制为 G。让 M≫s_H+R_H 即得 P→2。每个二次选择位同样可独立用一组新控制位调用第 84 轮的秩二步骤，故父 P≤2，极限从下方实现。普通谱线性秩在此构造和齐次秩相等（终端守卫奇偶为一），故普通比值也趋于二。

若要在低于该起点的指定比值附近取两侧常数倍，可以每次再张量独立二位 bent：普通谱秩加二、稀疏度乘四，且固定新 bent 地址可恢复先前限制。比值趋零且一次最多下降一倍，故能落入所需的因子二窗口。因此若一般 A28 的上确界有限，则这种充分允许额外变量的窄塔嵌入已经给出常数系数的下方比值保持。于是对第 84 轮已证 P≤2 的秩二窄塔，存在统一正比例保持的仿射嵌入与一般 A28 有界性等价；对允许任意秩的新地址塔，未知父比值是否有界，不能得出同一等价。若假想目标比值无界，P≈2 的填充不解决比值保持，且上面的谱开销障碍不能排除所有大余维方案。

## 3. 允许复用既有控制位时，可精确保住谱

固定坐标顺序

```
y, a₁,…,a_(n−2), x₁,…,x_n .
```

辅助 a 均允许任意初值。要把某个多项式乘积 fg 加入较早目标 y，使用一个顺序更后的辅助位 a。令 A 把 a 替换成 a+f，令 B 把 y 替换成 y+ag，其余位保持。依次施行 A,B,A,B，则

```
a 最终恢复初值；y 最终增加 (a+f)g+ag = fg .
```

构造一个 r≥3 控制的单项式时，取 g 为最后一个控制位，f 为其余 r−1 位的积。A 递归调用 r−1 控制的同类操作，把新的辅助位放在 a 的后面、所有真实控制位的前面；B 本身只是一个二次门。零、一、二个控制时分别用常数翻转、线性门或二次门。r≤n 时 n−2 个辅助位足够，全部门都满足控制位在目标后面的三角顺序。每个单项式完成后辅助位恢复，可对所有 ANF 项复用同一组辅助位。这样在**所有**寄存器字上把 y 变成 y+p(x)，真实 x 及辅助位全部保持。

从字符 (-1)^y 得到精确 F(y,a,x)=(-1)^y G(x)，额外 a 为虚变量。于是 s_F=s_G、P(F)=P(G)，普通谱秩 d_F=R(G)∈{d(G),d(G)+1}。没有为合成丢弃任何辅助位取值。代价是必须允许门复用已经出现的控制位。比如对三控积 x₁x₂x₃，只需 A:a←a+x₁x₂、B:y←y+ax₃ 的四门；输出有 3/4 幅度，立即越出新地址塔。若固定寄存器模型也只允许仿射门，则不能从字符得到非字符。反之，若允许在每个新地址步骤之后马上作仿射识别，把两个新控制位分别设为需要复用的旧控制位，就精确模拟该固定寄存器二次门。这说明秩二窄塔一旦允许中途仿射限制，闭包即覆盖所有真值表；不受限制的秩二塔上界不能在这一步直接继承。

一般 A28 仍开放。这些结论表明，允许旧控制复用的三角门类本质上覆盖整个问题。对严格的新地址二次塔，任意真值表在限制下可合成，谱开销或无界目标比值的通用保持仍是不同问题。

## 4. 本机整数核验

Python 3.15.0 实际运行 `python3 verify_synthesis.py`，退出码 0。核对一至三位的全部真值表及固定种子的 64 张四位表，共 340 张；在固定寄存器模型逐一复算全部 16,528 个包含任意辅助初值的输入，另独立核对新地址合成的实际仿射切片。对显式八位全谱障碍，核对全部 32,385 对不同非零方向的二阶差分及全部 256 个整数 Walsh 值。对三次积目标，直接构造深度 0、1、2 的三个选择器填充塔，父 (s,R,d) 分别为 (10,5,5)、(22,7,7)、(52,11,11)。另复算一个十四位奇重量随机真值表的最少带符号二幂项数直方图。实际输出见 `synthesis.txt`，无穷结论由解析证明承担。

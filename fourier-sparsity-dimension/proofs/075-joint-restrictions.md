# 第74轮两支分支的共同核压缩

设两支等概率布尔分支 \(F_b(y,z_b)\) 共用查询 \(y\in\mathbb F_2^a\)，外部变量独立。一次物理仿射压缩要求两支在同一仿射平坦 \(P\) 上同时保留各自的外部谱秩。记两支可以独立选择平坦时的最小保留查询维数为 \(h_0,h_1\)，共同最小维数为 \(h_{01}\)。

## 真实留秩的最佳一般上界

外部频带在压缩后非零，当且仅当它在某个物理地址 \(y\in P\) 的局部数据谱中出现。故扩张 \(P\) 不会减少外部秩。取分别最优的两个平坦，再取它们的共同仿射包，得到
\[
 \max(h_0,h_1)\le h_{01}\le\min(a,h_0+h_1+1).
\]
若分支必须共用物理平移，多付的最后一维可以是必要的。即使两支具有完全相同的实际谱点数和相同的原始外秩，右侧 \(h_0+h_1+1\) 仍可取等。

具体取 \(a=2k+2\)，写 \(m=2^k\)。令 \(A_0\) 为首 \(k\) 个基方向的线性平坦，\(A_1\) 为次 \(k\) 个基方向平坦加一个独立守卫偏移。它们的共同仿射包含前 \(2k+1\) 位。在 \(y\in A_b\) 时，分支 \(b\) 输出只对该地址使用的独立数据字符；在 \(y\notin A_b\) 时输出同一查询 bent \(\phi(y)\)。两支都是真布尔函数。每个非零外部频带是一个单地址指标，其查询谱含 \(2^a\) 点。每支外部秩为 \(m\)，尾部点数为 \(m2^a\)。零带也具有完整的 \(2^a\) 点谱，因为从 bent 的真值表删去 \(m\) 项最多改变每个未归一化系数 \(m\)，而原模为 \(2^{k+1}>m\)。

若用一个平衡选择位把两支拼成单一函数，压缩后出现的私有外部字符数为 \(|P\cap A_0|+|P\cap A_1|\)。只要该数非零，选择频率另增一维，因为每个出现的私有标签对应选择位的两个频率。若该数为零，两支都只输出同一个 \(\phi\)，外部秩为零。因此外部秩取满正好要求 \(A_0\cup A_1\subseteq P\)。单支各需 \(k\) 维，共同压缩需 \(2k+1\) 维，且拼接函数的零带也是完整查询核心。

## 代表频率的无碰撞保证与共同概率

每支选一组独立外部标签，为每带选一个代表。令 \(D_b\) 是该代表到同带其他点的非零差的并集，令 \(B_b\) 按带重复计算这些差。若共同频率核 \(W\) 避开 \(D_0\cup D_1\)，任意物理平移均保留两支秩。两个独立无碰撞核相交给共同保留维数至多 \(h_0^{\rm av}+h_1^{\rm av}\)。另由极大避开核的商中每个非零陪集都必须碰到标记差，可取共同保留维数至多 \(\lfloor\log_2(1+|D_0\cup D_1|)\rfloor\)。

更细的概率结论允许碰撞。设 \(M=2^a\)、\(L=2^h\)，从保留维数 \(h\) 的所有物理仿射平坦中均匀取一个，并记 \(\lambda=(M/L-1)/(M-1)\)。由第63轮的频率桶不确定性界，两支秩损失的期望和至多 \(\lambda(B_0+B_1)/2\)。任一分支丢秩时，该和至少为一，故共同失败概率也至多这个数。当 \(M=1\) 时压缩是平凡的。

系数 \(1/2\) 可取等。取某个非零查询角色 \(\ell\)，让分支 \(0\) 仅在 \(\ell(y)=0\) 时输出一个私有非零字符，分支 \(1\) 仅在 \(\ell(y)=1\) 时输出另一个私有字符，其余都输出常数。两支均有 \(B_b=1\)。若 \(\ell\in W\)，一个共同平坦只能命中一个活动半空间，恰有一支丢秩。若 \(\ell\notin W\)，每个共同平坦都命中两个半空间。失败概率恰为 \(\lambda\)。查询一维时，该例的零频带也是完整核心。

## 精确计算

Python 3.15.0、12 个工作进程。对所有一至四变量真值表及所有查询维数，计算每个函数在全部仿射查询平坦下的留秩情况和代表差。按这些完整资料分组，然后以权重穷尽每对分支，涵盖每个固定分解维数的全部真值表对。固定坐标分解足够，因为所有真值表构成的集合在任意共同线性坐标变换下不变。程序分别核对真实留秩界、无碰撞界和共同失败概率界。

在四变量两位查询、两位数据的分解中，掩码 291 与 325 单支各只需留一位，却不存在保留两支外部秩的同一物理直线。另有掩码 5 与 323，其确定性选定的差集分别为 \(\{1\}\) 和 \(\{2,3\}\)，单支各有一维无碰撞核选择，共同只能用零核。无碰撞结果依赖代表的选取。

对平衡完整核心构造核验 \(k=0,1,2\)，实际最小保留查询维组合为 \((0,0,1),(1,1,3),(2,2,5)\)。对每个实例枚举全部仿射查询平坦并用整数局部 Walsh 谱核对两支和拼接秩，另对拼接函数及最佳共同限制计算完整整数 Walsh 谱。最大完整真值表有 32,768 点。本次运行约 4.74 秒，所有工作进程正常退出。

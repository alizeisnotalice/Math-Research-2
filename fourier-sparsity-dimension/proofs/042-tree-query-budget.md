# 独立节点树的查询秩与非字符叶

设二叉树的每个内部节点 $v$ 使用不同的独立选择位 $z_v$，叶子输出共享数据 $y$ 上的任意布尔符号函数。写 $F(z,y)$ 为整树输出，$s$ 为其 Fourier 支撑大小。先将全部后代叶函数相同的子树替换为单叶。剩余内部节点数记为 $n$。每个这样的节点都真能影响 $F$：左右各可选一个输出函数不相同的叶子，在某个 $y$ 上二者不同，独立选择位可同时安排两条路径。反之只剩无效叶时 $n=0$。坐标无关版本要求所有查询在模叶数据空间后独立，可用线性换元化为上述模型。

**结论。** 无论叶子本身的谱多大，选择坐标上的投影谱线性维数恰为 $n$，且
$$ n\le 2\sqrt{s}-1. $$
令 $S_i$ 为各叶的数据谱，$p_i$ 为到达该叶的概率。令 $D=\dim\operatorname{span}(\cup_i S_i)$，$r_i=\dim\operatorname{span}S_i$。则总谱线性维数 $d$ 满足
$$d\le n+D\le \left(2+\sqrt{\sum_i p_i r_i}\right)\sqrt{s}-1.$$
特别地，叶内谱秩有统一上界的任意深度树满足带统一常数的 A28 二次界。叶函数、叶间共享变量、其具体 Fourier 系数及标签重复次数均可变化。只需平均叶谱秩有界也有相同结论。

**精确频谱公式。** $M_v(y)$ 记固定 $y$ 后对子树中全部选择位取均值，$\Delta_v=(M_{v_L}-M_{v_R})/2$；约定 $z_v=0$ 向左。令 $I_v$ 为到达节点 $v$ 的祖先位条件的指标。逐条根到叶的路径望远镜相加即得
$$F=M_{\rm root}+\sum_v I_v(z)\chi_{z_v}(z)\Delta_v(y).$$
每个非零项的选择谱恰为节点 $v$ 加上它的祖先的任意子集。不同项的选择频率集合不交，因为频率中出现的最深节点唯一。故用 $s(0)=0$，有
$$s=s(M_{\rm root})+\sum_v2^{\operatorname{depth}(v)}s(\Delta_v).$$
称 $\Delta_v\ne0$ 的节点为标记节点。每个有效节点自身或其后代必有标记，否则望远镜公式说明该子树只依赖 $y$。在每个标记节点取任一数据谱点，便可投影得到该节点位；将相差一个祖先位的两个选择谱点相加也得到祖先位。因此选择投影秩恰为 $n$。

**节点预算。** 令 $C=\sum_{v\ {m marked}}2^{\operatorname{depth}(v)}$，深度按当前子树局部计算。对有内部节点的约简子树证明 $C\ge(n+1)^2/4$。若根的两个孩子都是叶，则两个布尔输出不同，根被标记，$C=n=1$。若只有一个非叶孩子，根也必被标记；否则其均值逐 $y$ 等于另一叶的值 $\pm1$，每个后代叶的值都必须等于这个极端值，与约简矛盾。因此 $C\ge1+2C_1\ge1+(n_1+1)^2/2\ge(n_1+2)^2/4$。若两孩子都有效，无论根是否标记，都有 $C\ge2C_1+2C_2\ge[(n_1+1)^2+(n_2+1)^2]/2\ge(n+1)^2/4$。精确公式给 $s\ge C$，即得所述查询界。若 $n=0$，由 $s\ge1$ 单独成立。

**共享数据秩。** 取 $\cup_i S_i$ 的一个线性基 $E$，基数 $D$。在数据频率 $\beta\in E$ 上，$F$ 的部分变换是选择变量上的实函数，其物理支撑比例为 $u_\beta=\sum_{i:\beta\in S_i}p_i$，故该带至少有 $1/u_\beta$ 个非零频率。于是
$$ D^2\le\left(\sum_{\beta\in E}1/u_\beta\right)\left(\sum_{\beta\in E}u_\beta\right)
\le s\sum_i p_i |E\cap S_i|\le s\sum_i p_i r_i.$$
任何一个活跃数据谱点在某叶上有非零系数，因此数据投影谱恰为 $\cup_i S_i$。取基的步骤避免了把同一叶内许多线性相关的频率都计入成本。对于全部叶为字符的特例，第3轮另有更强的全谱锐常数。

**边界。** 令树共有 $h$ 层选择，形状完整，叶为常数，令最后一层的每对叶分别输出 $+1,-1$。仅最底一层被标记，$n=2^h-1$，$s=2^{2h-2}$，查询界恰取等。若同一选择位可在不同节点再次使用，不同节点的频率可能重叠；整个节点预算的精确分层公式需要新的论证。

# 近满奇核的中间尾长窗口

记号及跨层严格界沿用[第77轮](077-valuation.md)。

## 附录：层秩超过 K+1 时的定量间隙

若 r≥K+2，则另有

```
|P_j| ≥ 2^(K+1)(1−2^(−r)) + 2^K/8.
```

取优于此式的原有取整 Griesmer 下界时仍可保留它。这个估计在 r−K 较小、K 较大的区域比取整下界严格强。

令 D=2^K，坏字是 E_v 非零但重量大于 D 的字。二元 Reed–Muller 的经典第二重量间隙是每个坏字重量 ≥3D/2。以下给出本用途的直接证明。假设存在重量 w=D+e，0<e<D/2。若支撑在真仿射平坦内，先把该平坦的指标坐标作为公共乘积因子，限制到平坦后保持 K 而减少环境维数。故可设支撑仿射张满。K=1 时整数区间为空。对环境维数归纳，在 K≥2 时每个非平凡仿射二分的两部分都非空，各限制到 (n−1) 维后属于以 D/2 为最小重量的码。归纳假设及 w<3D/2 迫使其中至少一部分恰重 D/2，另一部分重 D/2+e。于是支撑指标的每个非零频率的未归一化 Walsh 模长都是 e。Parseval 化为

```
2^(n−K) (D+e−e²) = D+2e .
```

n≥K+1。若 e 奇，左端被 4 整除，而右端模四余二。若 e 偶，因 0<e<D/2，左端的二进赋值为 n−K+v₂(e)，右端恰为 1+v₂(e)，故 n=K+1。此时多项式次数至多一，非零重量只能为 D 或 2D，同样矛盾。归纳的初始情形 K=n 或 n−K≤1 由常数和仿射多项式直接得到。

若坏字少于 2^(r−3)，可先选一个最小字 E_v₁，再选 v₂∉{0,v₁} 使 v₂ 与 v₂+v₁ 均对应最小字，因为坏字和平移后的坏字共同只排除少于 2^(r−2) 个选择。令 T=span(v₁,v₂)，A 为对应的 (K+1) 维仿射包。每个不含坏字且异于 T 的 T-陪集，其四个向量 v 的 E_v 全在 A 中：对每个 v，用三个最小字 E_(v+v₁)、E_(v+v₂)、E_(v+v₁+v₂) 算 E_v 与三个基平坦的半重量交，应用 第77轮跨层证明 §1 的论证。T 中的字亦全部支持于 A。最多一个坏字排除一个 T-陪集，因此严格多于半数的向量对应 A 内的字。这些向量张满 V，故全部 E_v 都支持于 A。

仿射换坐标后，A 由 n−K−1 个坐标均为 1 定义。支持在 A 上的次数至多 n−K 的布尔多项式必须含这 n−K−1 个坐标的公共乘积因子，故限制到 A 后次数至多一。非零 E_v 要么重 D，要么为整个 A。前一种情形若对全部非零 v 成立，由 第77轮跨层证明 §1 有 r≤K。若有一个 E_v=A，则 P_j=A，所有该平坦实际标签的带长是偶数，故 π_W(A) 的仿射维数至多 K，其增量商标签的线性秩至多 K+1。两种情形都与 r≥K+2 矛盾。因此坏字至少有 2^(r−3) 个。对全部 E_v 取重量平均，得到所述加量。

r=K+1 的近等号几何确有真实实现，至少对 K≥2。修改 §3 的单层构造，让 a=1 分支改为 χ_t(z)·(1−2·1_{z'=0})，其中 t 是独立于 K 位 z' 的额外数据位。其数据谱是 t 加 K 维线性空间的完整仿射平坦。每个外标签有两个地址频率，估值均为 j=k−K，增量线性秩为 K+1，因此 |P_j|=2^(K+1)，正好达到第 65 轮原有取整下界。这也解释了定量间隙中 r≥K+2 的门槛。

## 中间区间的可增长真实族及平行两点带约束

令 h≥2，N=2^h，b=⌊log₂h⌋，a=2h+b。G_h 用 h 位地址 z 在 N 条独立数据字符 χ_(e_i)(x) 中选择第 z 条。它的 Fourier 系数恰在 (λ,e_i) 处非零，λ∈F₂^h，i∈{1,…,N}，每条系数为 ±1/N。引入独立位 t,v 与 a 位 y，在 t=0 切片上取 1−2·1_{y=0}，在 t=1 切片取 χ_v G_h。令 W 为 (t,y) 的全部频率。前支谱全在 W，系数皆是奇数乘 2^(−a)。后支的每个 (λ,e_i,v) 标签有两个频率，系数为 ±2^(−h−1)，故其共同估值为 j=a−h−1≥1。这样得到确切参数

```
k=a,   K=h+1,   M=2^(a+1),   q=2N²,   s=q(1+2^b),
r=h+N,   d=(a+1)+r.
```

秩计算中，地址差付 h 维，N 个 e_i+v 线性独立。由于 2^b≤h<2^(b+1)，

```
q/s = 1/(1+2^b) < 2/h,
(q/s)(log₂s)² ≥ (2h+1)²/(1+h) ≥ 4h.
```

因此 q/s→0 且 (q/s)log₂²s→∞，严格落在第 63 轮的未覆盖区间。该族的 r/√q→1/√2，d/√s→0。其作用是验证中间区间及单赋值高秩的真实可实现性。附录的加量在该族仅为 N/4，而真实 q 是 2N²。

**可重复的条件性支付。** 对任意查询核，把外带写成 B_β(y)。若所有实际外带恰有两个 Fourier 点，两个实系数等模，且所有频率对之差均为同一非零 w∈W，那么每条带恰在 w(y)=0 或 1 的一侧活动，而且活动时在该半空间上是常幅字符。于是，只取每侧任一实际物理地址，得到两个真实布尔数据切片 G_0、G_1。所有外标签由两片的非零谱支撑之并保留，设 q_i 为该侧所有外带的频点数，则

```
s(G_i) ≤ q_i/2+1,   q_0+q_1=q,   r≤d(G_0)+d(G_1).
```

特别若所有带的活动侧相同，则一个真实数据限制保留全部外秩，且稀疏度至多 q/2+1。证明只需写 B_β(y)=cχ_α(y)(1±χ_w(y))，与布尔切片的真实值域核验。上述中间区间族以及第 62 轮对任意真实 G 的同一选择构造均满足同侧假设，且载频使外标签的完整稀疏度恰为 q/2。故这种两点带模块可以反复套用。它改进了该类限制中的稀疏度支付，但仍须对所得的任意布尔切片控制 d，不能靠奇核比例消除一般的对数。

## 同一中间窗口内的两层严格界

第77轮三层例的参数亦可在中间窗口同时增长。令 t≥4，k=t+2⌊log₂t⌋，奇核 W 的维数 k+1。在物理地址空间内取 t 个余维 t 平坦、t−1 个余维 t−1 平坦，让它们全部不交。它们占 (3t−2)/2^t<1，可以用定长二进前缀先放大块再放小块实现。每块输出一个专属数据字符，余域输出 +1 并在其中一个地址翻号。每块的基数均为四的倍数，因此零带的每个未归一化系数模四余二，奇核恰为全 W。外带的真实系数是 ±2^{-t} 或 ±2^{-(t−1)}。两层增秩分别为 t,t−1，故满足第77轮跨层严格不等式的全部假设。

这里 q=(3t−1)2^{t−1}，s=2^{k+1}+q，故 q/s 与 1/t 同阶，(q/s)log₂²s 与 t 同阶。逐层界为 q≥3·2^t−4，第77轮将它严格提高至 q≥3·2^t−3。两层均能在同一窗口增秩；这个一个单位的加强仍不足以决定可行尾长的量级。其可实现性可由代码直接重建每条谱带，无需枚举指数多个物理地址。

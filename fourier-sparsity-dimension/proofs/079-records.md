# 仿射切割的零度与纪录谱约束

对 `F:F₂^n→{−1,1}` 用均值 Fourier 系数 a_ξ，S 为支撑，s=|S|，d=dim span S。对非空 affine cut X=S∩P，记 ν(X)=|X|−1−affdim X。后文纪录函数指稀疏度至多 s 的真实布尔函数都满足 d'/√s'≤d/√s。对 d→∞ 的一列纪录函数，使用统一的 o(1)。

## 1. 任意余维平坦的分母与关系空间

令 P 的余维 t≥1，k=max_{ξ∈X} k_ξ，其中 k_ξ 是 a_ξ 的约分后二进分母指数。假设 K=k−t≥1，记 O={ξ∈X:k_ξ=k}，并以 h_O(u) 表示次数至多 u 的二元多项式在 O 上的评价空间维数。那么

```
ν(X) ≥ h_O(K−1) ≥ 2^(K+1)−K−2.
```

当 k≤t 时没有附加条件。对 t=0 同样成立，最高层论证改用整数值函数 (F−1)/2；k≥1 时常数项减法不影响最高分母集合。

**证明。** 先将 P 调制到线性平坦，然后视其频带为内在 n−t 变量的函数。将带函数乘 2^(t−1) 后为整数，因为对 t 维物理子空间求带字符的平均所得仍落在 2^(1−t)ℤ。其最高分母指数是 K+1。按第 65 轮的整数 Fourier 层矩恒等式，1_O 正交于所有次数至多 K 的布尔多项式，故 |O|≥2^(K+1)。每个 deg p≤K−1 的评价字 1_O p 延拓到 X 后，正交于所有仿射函数。它于是位于 X 的齐次列关系空间，且复制该评价空间维数。

最后的 Hilbert 函数下界只需标准的 Kruskal–Katona 影子定理。用按次数优先的单项式序依次保留评价独立的平方自由单项式；选中的单项式集合是下闭的。确实，如果平方自由 m 的评价已在早到的单项式张成中，则乘一个新坐标并取平方自由约化，产生的各项仍早于扩充后的 m。保留的总数等于 |O|（所有点指标都由平方自由多项式表示），次数 ≤u 的保留数恰等于 h_O(u)。下闭族大小至少 2^l 时，次数 ≤u 的成员至少 Σ_{i≤u} binom(l,i)（u≤l）：若第 u 层不少于 binom(l,u)，直接用影子定理；否则任何大小 i>u 的层不得达到 binom(l,i)，且不得有超过 l 的成员。若低层数同时小于所求下界，则总数小于 2^l，矛盾。代入 l=K+1、u=K−1 得结论。u=0 直接计常数项即可。

单点翻号函数在 k+1 变量上满谱，全部系数分母指数 k；其任意余维 t≤k−1 的切割 X 都是 (K+1) 维平坦，上式取等。特别地，任意余维 t 的切割若 ν≤3，其所有系数的分母指数至多 t+1。第 78 轮只把 t+1 以上的分母排除于 coloop；这里控制整个切割。

## 2. 超平面切割在 ν=1 时的精确分类

设 t=1。齐次列关系空间的一维非零字给出唯一回路 R；其余列均为 coloop。回路长度偶且至少 4。设 ε 是 R 上真实系数符号的积。以下是全部可能的外带谱形，系数按绝对值列出。

| 类别 | 回路系数 | ε | 其他列 | 零物理地址数 / 总地址数 |
|---|---|---|---|---|
| A | 4 个 1/4 | + | 无 | 3/4 |
| B | 6 个 1/4 | − | 无 | 10/16 |
| C | 3/4, 1/4, 1/4, 1/4 | − | 无 | 1/4 |
| D | 4 个 1/4 | − | 一个 1/2 coloop | 4/8 |
| E | 4 个 1/2 | − | 无 | 0/4 |

零地址是经过移频后外带函数为零的地址。在最后一种情形外带已耗尽 Parseval 能量，s=4。每种形态可以实现。特别地，任意超平面外切割 ν=1 均有 |X|≤6，且每个系数模长至少 1/4。

**证明。** 选物理切割坐标 z，将要分析的频率半空间记为 z 的非零带。若该半空间原本经过零频，先乘 χ_z 交换两带。写调制后的 F(y,z)=g(y)+χ_z h(y)，则 h 取值于 {−1,0,1}，g 与 h 的活动域互补，g 在 h=0 处取 ±1。平移与整体变号恰给回路符号积固定为 ε 的所有正负赋值，coloop 符号任意。回路中任意两项的翻转，以及这两项的符号先取同号或异号，说明 2(a_i±a_j) 为整数，故全部回路模长同属 1/2 的正整数倍或奇数个 1/4。Coloop 模长自身为正半整数。由于偶回路，整体翻号保留符号约束。若 ε=+，可全取正，模长和至多一，只能 A。若 ε=−，最大值等于总模长减去回路最小模长的两倍。对半整数型，这只允许 E。对四分之一奇数型，长度至多六；长度六时全为 1/4 且无 coloop，即 B。长度四时最小值须为 1/4，最多增加一个 1/2 的单位。增加一个回路项是 C，新增 coloop 是 D；无增加时值只能是 ±1/2，排除。各列值域直接代入核验。

移去一共同频率后，长度四回路用二维仿射平面；长度六回路用 {0,e₁,e₂,e₃,e₄,e₁+e₂+e₃+e₄}。类 D 的 coloop 用额外的独立方向。给这些频率指定表中绝对值和符号积，得到真实 h。取 g=1−h² 即可把每种外带填成真实 F。

类 B 的地址也可用回路六个符号模整体取反来表示。固定一个参考符号为 +，其余五位负号个数奇。h=0 当且仅当恰有三位负号；剩余六个地址为五个重量一字和一个重量五字，仿射张满四维奇偶陪集。因此零地址集 Ω 不含四维地址空间的任何仿射超平面。类 D 中，四点 ±1/4 奇积回路是 1/2 倍的二次弯曲符号，coloop 是独立地址位的 1/2 倍字符。两项相消的四个零地址是该二次函数在独立位上的图，仿射独立（四个点的异或在独立位上非零）。因此这四点也不包含任何仿射超平面。

## 3. 真纪录的三种排除

对 d→∞ 的纪录序列，最终不会出现 A、C、D、E，只可能出现 B。此结论只需纪录性，无需随机基均匀边际。

先记一条共用估计。把外带的仿射方向记作 W，维数 c≤4，取与 W 互补的数据频率空间。固定额外的 z 位和一个零地址 i∈Ω，得到真实数据布尔切片 G_i，谱集 T_i，稀疏度 s_i。令 Ω 的大小为 L。固定 z 后，上述可能的 χ_z 调制只改变整体符号，所得切片是原 F 的真实限制乘常符号。全局调制可使原谱线性秩相差至多一；以下保留 d 表示原 F 的秩。只看 g 的外部数据标签 β，包含可能出现的零标签；令 m_β 是 g 在该带的地址谱宽，k_β 是它活跃的地址数。则 Σ m_β=s−|X|，Σ_i s_i=Σ k_β，mk≥2^c（有限 Fourier 不确定性）。g 的全体数据标签张成空间的秩 r≥d−c−2，因为所有 h 的谱点模 W 只给一个额外频率，可能的全局调制至多再付一维。外切割原本不经过零时有 r≥d−c−1。设 H 为数据频率空间的任一子空间，q_i=|T_i∖H|，r_i=dim((H+span T_i)/H)。第 63 轮近无损尾限制给

```
r_i/d ≤ sqrt(q_i/s)+o(1).
```

显式取不小于 s/√d 的最小二幂 M，R63 的真实限制满足 s'≤q_i+M、d'≥r_i−q_i/(2M)，且实际稀疏度 s'≤s_i≤s。把纪录性代入并以 d 归一化，此误差对所有 i 及 H 一致。因此 `(r−dim H)/d ≤ sqrt(L Σ_i q_i/s)+o(1)`，这里仅取 H 由实际数据标签生成。若选定依 k_β 从高到低扫过的数据标签基 B，则每个切片秩至少包含 B∩T_i 的基点数，于是

```
Σ_i d(G_i) ≥ Σ_{j=1}^L dim span{β:k_β≥j}.
```

反向由纪录性及 Cauchy–Schwarz 得左式至多 d√(L Σ_i s_i/s)。

**类 A。** 地址维 c=2，L=3。令 p 为 k≥2 标签所占谱质量（按 m/s 加权），x 为这些标签的总秩除以 d，x₃ 为 k=3 标签的总秩除以 d。k=1 的带必 m=4；k=2 仅 m=2 或 4（两个非零物理值的两类 Walsh 和）；k=3 必 m≥3（两项能给的活动数只有 2 或 4）。取 H 为全部 k≥2 标签张成空间，其外的 Σ_i q_i≤(1−p)s/4。由上一估计，

```
1−x ≤ sqrt(3(1−p)/4)+o(1),
1+x+x₃ ≤ sqrt(3[(1−p)/4+p])+o(1).
```

记 u=√(3(1−p)/4)。下式左端至少 2−u−o(1)，而 (2−u)^2−3[(1−p)/4+p]=(2u−1)^2。故沿任何纪录序列必须有 p→2/3、x→1/2、x₃→0，并且上述稀疏度、秩和估计渐近取等。

k=3 的谱质量为 o(1)。确实整个 k=3 频带在原谱中落入维数至多 x₃d+c+1 的线性空间（允许调制的一维），用第 64 轮纪录密度上界 (2) 即知。也可对原 F 维数至多 x₃d+c+1 的核用同一 M 的第 63 轮限制直接推出。k=2,m=4 标签的谱质量同样为 o(1)，否则 Σ_i s_i/s≤(1−p)/4+p 的估计有固定缺口。于是 k1,m4 型标签数为 (1/12+o(1))s，k2,m2 型为 (1/3+o(1))s，其他仅 o(s) 个谱点。

取 H 如上，令 r_i 为各 G_i 模 H 的商秩。Σ_i r_i/d≥1−x−o(1)→1/2；但 Σ_i r_i/d≤Σ_i√(q_i/s)+o(1)≤√(3 Σ_i q_i/s)+o(1)≤1/2+o(1)。Cauchy 取等迫使每个 q_i/s→1/36 且 r_i/d→1/6。任意两个零地址组成一条仿射直线，其合并的真实限制保留两地址的全部数据标签（Walsh 反演）；命中每个 k≥2 标签，所以保留 H；而遗漏的单地址商秩只是 d/6+o(d)。因此该真实限制秩至少 (5/6−o(1))d。对三个地址对算条件频谱宽：k1,m4 型在三对中活动两对，每对贡献两个频率；k2,m2 型在两条活动地址恰被同时取到时贡献一个频率（两个物理值等模），另外两对各贡献两个。例外只贡献 o(s)。故三对的平均稀疏度至多 (4/3)(s/12)+(5/3)(s/3)+o(s)=(2/3+o(1))s。某个限制因为 25/36>2/3 刷新纪录，矛盾。

**类 C。** c=2 而 Ω 只有一地址。从该地址的真实限制得 s'=(s−4)/4。外切割不经零时 d'≥d−3，d≥7 就刷新纪录；若经过零，只需再付可能的调制一维，d≥9 亦刷新纪录。

**类 D。** c=3，L=4。k=1,2,3 的带宽分别至少 8,4,6（不确定性）；k=4 时至少 4。两项 Fourier 支撑的物理活动域若非全体，必是超平面；而 Ω 不含超平面。三项 Fourier 支撑仿射独立，经移频为 a+bχ_u+cχ_v；三个系数均非零时，四种 (χ_u,χ_v) 至多一处取零（两个相邻零迫使 b 或 c 为零，两个相反的零迫使 a 为零），故至少六个地址活动。所以上述带宽下界成立。

令 p,q,u 为 k=1、k=2 或 3、k=4 的谱质量；p+q+u=1−o(1)。分别取 H=span{k≥2} 和 H=span{k=4}，以通用估计得到秩比例至少 1−√(p/2) 和 (1−√(p/2+2q))_+，各有 o(1) 误差。令 t=√(p/2)，z=√(p/2+2q)。按层算 Σ_i d(G_i)/d 至少 2−t+2(1−z)_+−o(1)，同时纪录与 Cauchy 给至多 √(4−6t²−z²)+o(1)。若 z≥1，平方差至少 1−4t+7t²≥3/7。z≤1 时平方差相对于 z 的导数是 −16+4t+10z<0（t≤1/√2），故仍不小于 z=1 的同一差。与纪录性矛盾。

E 已有 s=4，不能出现在 d→∞ 序列中。真纪录中 B 尚未排除。

## 4. 精确均匀边际时也能排除 B

若 F 另有分布于线性谱基上的随机基，其每个谱点的纳入概率是 d/s+o(d/s)（误差在所有点上一致），则类 B 在 d→∞ 时有真限制严格改进 d/√s。此均匀边际假设强于 R64 的 (2+o(1)) 倍最大秩密度结论；后者不提供这里所需的随机基。

对每个 i∈Ω，将随机基中其 g 带在 i 活跃的原频率投影到数据空间；一次投影减秩至多 c+1，且投影结果属于切片谱。以 Ω 均匀平均，令 A=Σ m_β k_β/(s−|X|)，B=Σ k_β/(s−|X|)，得到

```
E_i d(G_i) ≥ (A/L−o(1))d,   E_i s(G_i) = (B/L+o(1))s.
```

B 类中 c=4、L=10，m≥4，因为 Ω 不含超平面，而三项非零函数在至少四分之三的地址活动。再用 mk≥16，逐项有 k/m≤(5k−4)/16：k≤3 直接代入，k≥4 由 m≥4 即可。因此 B≤(5A−4)/16，且 A≥1，故 A²/(10B)≥128/125>1。若所有切片比值不超过父谱，便有 E d(G_i)≤(d/√s) E√s(G_i)≤d√(E s(G_i)/s)，与严格差矛盾。这个证明只排除具有所述均匀边际的 B 类。

## 5. 结果范围

一般布尔谱的任意余维切割受 §1 的锐分母约束，所有零度一的超平面切割由 §2 分类。真纪录的大秩序列若仍出现零度一切割，只能是 B 类六点奇符号回路。无附加假设排除 B、以及利用相互重叠的切割进一步得 d=O(c(S))，均未解决。

## 6. 任意余维的零度一切割大小锐界

若 t≥1 且 ν(X)=1，则 |X|≤2^(t+1)+2，取等时 X 本身是一个仿射回路，每个系数模长恰 2^(−t−1)，回路的系数符号积为负。这对每个 t 都可实现。

对一般余维 t，频带的值仍在 [−1,1]∩2^(1−t)ℤ。回路中同时翻两项、再比较两项取同号和异号两种情况，得到 a_i±a_j∈2^(−t)ℤ，因而非零模长至少 μ=2^(−t−1)；coloop 至少 2μ。若符号积为正，则所有项可同时正，直接得 |X|≤1/μ。若为负，则最优赋符的最大值为总模长减去回路最小模长的两倍。π 个 coloop 耗至少 2πμ，因此 1≥μ(|X|−2+π)。这给锐界，等号条件随即确定。

对任意 t，取长度 2^(t+1)+2 的仿射回路，给每点模长 μ 且指定一个负号。可行符号中负号数恒为奇数，故带值为 μ 乘一个不超过 2^(t+1) 的四的倍数，正好位于所需格子中。对每个地址 y 独立选择 t 个辅助物理位上的布尔表，使它在所选频带标签处的 Walsh 系数等于给定的 h(y)：例如在零标签令 +1 项数为 2^(t−1)(1+h(y))，再通过一次字符调制换到任一所需标签。于是原带精确实现。此构造只控制该选定仿射平坦内的谱，其他频带允许存在。

## 7. 整数复核

本机 Python 3.15.0 运行 `python3 verify_cut.py`，退出码 0，实际输出保存于 `verify_cut.txt`。对四变量全部 65,536 张真值表逐一检查 30 个仿射超平面。出现的 A、C、D、E 依次有 215,040、53,760、430,080、3,360 个函数—平坦对。B 需要外带仿射维四，故在四变量的超平面中不会出现，另由五位真实布尔函数的整数 Walsh 变换核对。五种形态和相应零地址数均已用明确真值表实现。一般余维长度锐例在 t=1,2 由完整真值表与整数 Walsh 变换核对，t=3,…,8 核对构造所需的全部奇负号数及格条件。另检查 247 个单点翻号的分母与零度取等切割。没有随机数或容差。纪录谱排除由解析论证承担。

## 8. 真纪录六点回路的最小多地址质量

即使没有随机基假设，若真纪录中类 B 出现且 d→∞，其零带中至少有 (1/29−o(1)) 比例的总谱质量来自 k_β≥4 的数据标签，更精确的下极限不少于 (29−√835)/3。

类 B 的地址空间有 16 点、零地址集 Ω 有 10 点。k=1,2 时带宽 m≥16,8；k=3 时 m≥12，因为三个真实物理支撑点仿射独立，交换物理与频率后应用 §3 中三项 Fourier 之和最多四分之一消失的论证。对 k≥4 则有 k/m≤2。已有 m≥4，只须排除 k≥5 而 m=4。若四个频率构成仿射平面，活动点数只能为 4 的倍数。若是 8，活动地址必为超平面，Ω 不含这样的子集。若四个频率仿射独立，可独立给四项赋符（允许共同变号）。和为零的符号数至多六，因为给定目标和的正实权子集构成反链。故活动点数至少 10。等于 10 则活动域就是 Ω。四个仿射独立频率经移频仅依赖三个线性地址坐标，活动域沿非零方向周期。它的六点补集却恰是一个仿射回路（五个单位向量与全一向量在五位奇偶陪集上）。若该补集沿非零方向周期，六点可分成三对，对所有六点异或得该非零方向，与回路异或为零矛盾。于是 k≥5 时 m≥5，结论成立。

令 p、δ 分别为 k=1、k≥4 的谱质量，令 t=√(10p/16)。照 §3 的纪录尾秩估计，k≥2 标签的总秩比例至少 1−t−o(1)。k≥4 标签所生成的子空间（加地址及可能的调制共 O(1) 维）捕获 δ 比例谱质量，故第 64 轮纪录密度界说明其秩比例至少 δ/2−o(1)。贪心基的逐层计数中，此秩至少各贡献在 k≥3 和 k≥4 两层，因此

```
Σ_i d(G_i)/d ≥ 2−t+δ−o(1).
```

由各支撑宽度及纪录性，平方上界却至多 `10[p/16+(1−p−δ)/4+2δ]+o(1)=2.5−3t²+17.5δ+o(1)`。相减化为

```
0.5 − 14.5δ + 0.75δ² + 4(t−0.5−δ/4)² ≤ o(1).
```

以 δ∈[0,1] 解得所述下界。这条约束排除主要由最多三地址活动的频带构成的真纪录六点回路，仍允许有较高多地址质量的六点回路。

# 第26轮：四点关系闭包与分量谱分割

状态：解析推导独立审查通过，本机有限代数检查完成；一般A28仍开放。

## 1. 精确闭包

设Z=W=F₂^k，q=2^k，H≤F₂^W包含全部仿射w函数。令

    D=H^perp,
    D₄=span{d∈D:wt(d)=4},
    Hbar=D₄^perp.

则H⊂Hbar，且对任意相位g:Z×W→F₂，

    g+H全部bent  ⇔  g+Hbar全部bent。

证明：固定α∈Z*、β∈W*，记A_w=Σ_z(-1)^{g(z,w)+α·z}。将完整Walsh的平方展开为H或Hbar参数上的字符和，所用角色仅为0与e_u+e_v（u≠v）。两个角色之差重量仅可能0、2、4。因H包含仿射函数，D不含重量2字；D₄⊂D且两者的重量4字集合完全相同。因此角色在H与Hbar上的相同/不同关系完全一样，常数角色也不与非零pair角色混同。

平方恒等于q²恰要求常数系数为q²、每个其他角色等价类的系数和为零。两种参数空间的分组相同，所以平方恒等式等价，对每个α、β同时成立。实数Walsh的平方q²等价于bent幅度条件。反向也可直接由H⊂Hbar得到。

两者的重量4对偶字集合相同还表明此算子幂等。此处不选择与参考相位正负号有关的匹配，而保留物理w评价码的全部四点关系；它与第5轮符号码匹配虽都来自二阶展开，却不是相同对象。

## 2. 同时扩张与分量指标

若f+V全bent且V包含H的提升，则对每个v∈V，f+v与H共同合法。由闭包定理f+v+Hbar也全部合法，故V⁺=V+Hbar是合法线性扩张；包含极大时Hbar原本就在V内。

将全部重量4对偶字的支撑视为W上的超边，连通分量记C₁,...,C_t，孤立点亦为分量。每条超边完全落在一个分量内，所以每个1_C与全部生成元的交数为0或4，均为偶数。因此1_C∈Hbar，闭包后得到独立块Z×C的完整物理分割。

这些块指标未必原本在V中。若后续使用残余核，必须区分V与扩张后的V⁺，不能偷换两者。

## 3. 逐相位的频率分割

取任意g与H共同合法。若u,v来自不同分量，则pair角色e_u+e_v不能与另一pair角色相同，否则差为重量4对偶字，其支撑连通这两个分量，矛盾；共一个端点时差为重量2，同样不可能。平方展开于是给A_u(α)A_v(α)=0。

因此对每个α，所有活跃w只落在一个分量内。由常数角色系数Σ_w A_w(α)²=q²，该活跃分量存在且唯一。令D_C(g)为分配给C的α集合；这些集合分割Z*。

对每个固定w，z方向Parseval为Σ_α A_w(α)²=q²。按C求和并比较每个活跃α的q²能量，得

    |D_C(g)|=|C|。

又若α∈D_C(g)，完整Walsh在任意β处只由C贡献，模为q；若α不在D_C(g)，C部分为零。因此物理块Z×C的部分谱精确为

    D_C(g)×W*，非零幅度q。

这是逐相位的完整谱分割。D_C可以随g变化，尚未证明其为仿射平坦，更未证明联合参数—频率块仿射，不能直接套用第9轮法向秩预算。

## 4. 有限代数验证与明确障碍

four_relation_closure.py对八点W中所有67个包含RM1的H完整核验闭包前后的pair角色分组相同；只有全偶校验七维码严格扩大到八维全空间。

十六点W的明确例：P={0,1,2,3}、Q={0,1,4,5}、T={0,1,4,6,8,11}，均以指标作为对偶向量。

- D=span(P,T)：H维14，Hbar维15；只有P生成四点关系。
- D=span(P,Q)：闭包不变，非平凡连通分量为{0,1,2,3,4,5}，共六点，不是仿射平坦。
- D=span(T)：H维15，但没有四点对偶字，闭包为全部十六维空间。

这些是精确有限关系检查，不是所有大维种子的分类。更直接的停滞例是H=RM(1,3)：其对偶由四点平坦生成、四点超图连通，闭包不变且只给整体块。因此四点闭包本身没有解决一般共同秩问题。

## 5. 真实非仿射频率分量

取k=3，C={0,1,2,3}⊂F₂³，为标准二维平坦，H为在C上总奇偶为0的七维w函数空间。它包含RM1，H对偶由1_C生成，因此H已经四点闭合。

令π交换3与4、固定其他点，取g(z,w)=z·π(w)。这是MM相位，加入任意w函数仍bent，当然与H共同合法。其C块部分谱为π(C)×W*，而π(C)={0,1,2,4}含0却不对异或封闭，不是仿射平坦。

nonaffine_component_spectrum.py实际核验全部128个g+H相位及该部分谱，所有非零值为±8、支撑大小32。这不是对一般预算的反例，只严格否定“闭包分量频谱自动仿射”这一步。

# 第19轮：六变量两倍块的完整有限覆盖

本附件给出精确枚举的数学归约和覆盖范围。计算支持的结论是：\(RM(3,6)\) 中全部重量16码字的支撑，都能沿某个二维线性核单射投影到四维空间。因此，六变量 bent 相位的全部合法16点翻号块均满足第19轮主定理的可投影假设。这是有限维结论，不是一般维数下的投影定理。

## 1. 六变量 bent 相位的次数界

令 \(f:\mathbb F_2^6\to\mathbb F_2\) bent，故 \(W_f(\xi)=8\varepsilon_\xi\)、\(\varepsilon_\xi\in\{\pm1\}\)。任意四维仿射平坦 \(a+H\) 满足
\[
\sum_{x\in a+H}(-1)^{f(x)}
=\frac14\sum_{\xi\in H^\perp}(-1)^{\xi(a)}W_f(\xi)
=2\sum_{\xi\in H^\perp}\pm1.
\]
右侧含四个符号，因而被4整除。于是 \(f\) 在每个四维仿射平坦上的重量为偶数，其所有四阶差分均为零。这等价于 Boolean 代数正规形次数至多3。因此 \(f\in RM(3,6)\)。若 \(f+1_A\) 也 bent，则 \(1_A=f+(f+1_A)\in RM(3,6)\)。所以只要覆盖全部重量16的三次以下码字，就覆盖全部真实合法16点块；并未假定每个这样的 RM 字都可作 bent 翻号。

## 2. 完整枚举的有限归约

六变量三次以下多项式唯一写成
\[
C(x)+Q(x)+\alpha\cdot x+c,
\]
其中 \(C\) 为20个无平方三次单项式的组合，\(Q\) 为15个无平方二次单项式的组合。按最高次数商空间上的 \(GL_6(\mathbb F_2)\) 作用分类 \(C\)。使用三种生成元：六坐标循环、交换前两坐标、替换 \(x_0\mapsto x_0+x_1\)。前两者生成全部坐标置换，其对第三种替换的共轭给出全部初等行加法，因此生成整个可逆线性群。

代换后的三次单项式若出现重复变量，会降到二次；程序只在三次商空间上分类，而随后完整枚举所有次数至多2的项，恰好吸收这些低次项。每个线性代换在整个低次纤维之间诱导双射；重量和可投影性均保持。因此每个三次轨道只需检查一个完整低次纤维。

程序对全部 \(2^{20}\) 个三次系数掩码进行生成元广度优先搜索，得到六轨道。生成元还在全部掩码上通过阶数检查。对每个代表逐一枚举 \(2^{15}\) 个 \(Q\)。若
\[
W_{C+Q}(\alpha)=\pm32,
\]
则恰有一个常数 \(c\) 使对应相位重量为16：正号取0，负号取1。其他系数不会产生重量16。于是对全部64个线性频率的 Walsh 计算完整而不重复地覆盖目标纤维。

对一个16点支撑 \(A\)，二维核存在当且仅当
\[
H\cap(A+A)=\{0\}.
\]
程序生成全部651个二维线性子空间；找到一个合格核即可证明该支撑可投影，若全部失败才判不可投影。差集用集合或按位 OR 构造，不能将重复差值的二进制位相加。正反对照集合的全部651个核都用直接陪集碰撞另行核验。本机另用直接 popcount 和陪集碰撞实现独立检查，具体实际运行见运行记录。

## 3. 计数与独立完整性检查

三次单项式按 \(i<j<l\) 字典序编码。精确结果为：

| 三次系数代表 | 轨道大小 | 代表纤维重量16数 | 不可投影数 |
| ---: | ---: | ---: | ---: |
| 0 | 1 | 2604 | 0 |
| 1 | 1395 | 784 | 0 |
| 20 | 54684 | 384 | 0 |
| 1064 | 468720 | 448 | 0 |
| 1536 | 357120 | 0 | 0 |
| 12640 | 166656 | 0 | 0 |

轨道大小之和为 \(2^{20}\)，加权重量16数为 \(232081500\)。共直接检查4220个重量16代表纤维码字，不能把加权覆盖数量写成逐一运行了两亿多次投影检查。

另一路独立整数计算使用 \(RM(3,6)^\perp=RM(2,6)\)。本轮实际构造两码的单项式基，核验秩分别42、22且基向量两两正交；维数互补证明该对偶关系。枚举全部 \(2^{15}\) 个齐次二次项及其线性/常数项，得到对偶码 \(2^{22}\) 个字的完整重量分布 \(B_i\)。由字符正交性，任一二元线性码的重量生成函数满足
\[
\sum_w A_w z^w
=|C^\perp|^{-1}\sum_{u\in C^\perp}(1+z)^{64-|u|}(1-z)^{|u|}.
\]
这是把 \(1_C(x)=|C^\perp|^{-1}\sum_{u\in C^\perp}(-1)^{u\cdot x}\) 代入左侧后逐坐标求和所得。取系数即
\[
A_w=2^{-22}\sum_i B_i\sum_j(-1)^j\binom ij\binom{64-i}{w-j}.
\]
精确整数计算独立得到 \(A_{16}=232081500\)。全部65个系数均为非负整数、关于32对称、总和 \(2^{42}\)，最小非零重量为8。它核对总覆盖计数；投影性质仍由上述完整代表检查承担。

MacBook 原生 Metal 与独立 Swift CPU 对六个纤维的全部 \(6\cdot32768\cdot64=12582912\) 个有符号 Walsh 系数逐项比较一致，纤维计数亦与 C++ 相同。GPU 不检查投影核，也不独立证明轨道划分。

## 4. 结论边界

上述有限覆盖加第1节的解析桥梁，支持全部六变量合法两倍块的可投影性；不是只检验已有20个共同码。更高维下的低次码字集合和核条件不同，不能外推。第19轮主证明仍明确把一般可投影性列为假设。源码、源/输入哈希、实际版本、运行与纠错记录见[第19轮计算记录](../computation/round019/RUN_RECORD.md)。

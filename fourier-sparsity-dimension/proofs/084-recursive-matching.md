# 固定匹配递归的多代共同查询成本

取 n 位地址空间上的一个固定完美匹配，V=2^n 个点，N=V/2 条边。每个节点使用独占地址变量，所有节点复用同一匹配形状，各边选择独占下一层真实布尔副本并乘一个私有守卫。递归 L 层，底种子稀疏度 s₀、齐次秩 r₀。要求匹配至少有两种不同边方向。P=(R+1)/√s，R 为齐次谱秩。以下区分一张非自适应线性查询表的所有答案、仅选择其中一个指定答案，以及只沿一条路径问。允许线性方程混合任何层的地址、守卫及底种子变量。

## 1. 递归谱与节点式限制

未经查询时，

```
s_L = N^(2L)s₀,    R_L = N^L r₀+n(1+N+…+N^(L−1)).
```

因为每个非零子标签带有 N 个地址频率，各私有守卫使各副本的齐次秩直接相加；不同边方向的地址法向空间之和恰为全地址空间。于是固定 n、底种子而令 L 增长时，P→(r₀+n/(N−1))/√s₀。该模板不能靠代数增大到无界 P；对 n 足够大，P_L 实际随层数递减。只在根选择一个不含完整边的 ⌊n/2⌋ 维地址单元，就仍能以 ⌈n/2⌉ 个方程达到一次 P 非降，费用不随 L 增加。所以多代费用须明确要在每代完成的任务。

**节点式乘积限制的精确公式。** 允许对每个存活节点选择不同的仿射地址单元 C_v，所有节点的限制彼此独立。若 M_v=|C_v|，一个完整边对应地址频带宽 w_{v,i}=M_v/2，一个跨边单点对应 w_{v,i}=M_v。记 h_v 为这些本地地址频带的共同方向张成维数。有任意跨边单点或至少两个不同完整边方向时，h_v=dim C_v；若全部为同方向完整边，h_v=dim C_v−1。对每个存活叶 ℓ 定义

```
μ_ℓ = ∏_{v ≺ ℓ} 1/w_{v,i(v,ℓ)} .
```

这恰为在节点地址各自均匀时选到 ℓ 的概率，因为每个完整边占两个地址、每个跨边单点占一个地址。记 B 为存活叶数，则完整限制精确满足

```
s = s₀ Σ_ℓ (1/μ_ℓ),       R = B r₀ + Σ_(v 为存活内节点) h_v .
```

每层连续应用独占守卫地址公式，稀疏度按路径乘地址宽，秩逐节点相加。由 Cauchy–Schwarz，s≥s₀B²，取等当且仅当全部存活叶等概率。此公式只对节点式乘积限制陈述，不把含跨节点相关的任意线性限制当作乘积。

若在每个节点用同一 C，其大小 M、完整边数 f、跨边点数 t、B₁=f+t，则 s=s₀[M(f/2+t)]^L，R=B₁^L r₀+h_vΣ_{j<L}B₁^j（h_v 对每节点相同）。若 ft>0，则 M(f/2+t)=B₁²+ft/2>B₁²，每代固定重用造成 P 的指数衰减。若 C 为空完整边的 ⌊n/2⌋ 维平坦，令 b=⌈n/2⌉、M=2^⌊n/2⌋，则 B₁=M、h_v=⌊n/2⌋，此共同限制的 P 对足够大的 n 在所有 L≥1 上严格提高。确实，在公式

```
P_L = [r₀+c+(1−c)B₁^(−L)]/√s₀
```

中，原树 B₁=N,c=n/(N−1)，限制树 B₁=M,c=⌊n/2⌋/(M−1)。后者 B₁ 较小，c 较大，且两种 c 对足够大 n 都小于 1。

**混合单元可由后代补偿。** 在根取任意有完整边又有跨边点的超平面 C（大小 N）。某个大小 M 的空完整边单元由随机仿射单元期望内部边数小于一得到，它的一张半平坦同样空。根的完整边子节点各取大小 M 的空单元，根的跨边子节点各取其大小 M/2 的空半单元。全部叶概率等于 2/(NM)，B=NM/2，因此即便根单元混合，父稀疏度仍精确取 s=s₀B²。对 n 足够大，此两代限制也严格提高 P：新增地址开销除以 B 至少为 (⌊n/2⌋−1)/M，未限制两代的该项为至多 2(n+1)/N。于是下文的逐节点清理费用不能自动解释成所有保住 P 的限制的费用，两种验收条件确有区别。

## 2. 混合查询的多代余维账本

对任意非适应线性查询表，设其频率方程的张成为 H，q=dim H。固定一个实际非空答案纤维。若节点 v 可从此前选择到达，就加上全部祖先“地址落在该条匹配边”的条件。每条边为二维域的仿射直线，这些条件也是线性方程。它们的法向空间记为 L_v，含于祖先地址空间之和。剩余可行输入在 y_v 上的投影是非空仿射平坦 Y_v，记 a_v=codim Y_v。投影的方程法向恰为 (H+L_v)∩A_v，A_v 是节点 v 的独占地址频率空间。

按祖先先于后代排列可到达的节点。设 F_j 为排列中前 j 个节点的地址频率空间的直和。由独占地址，

```
a_v ≤ dim((H+F_(j−1))∩A_v)
    = dim(H∩F_j)−dim(H∩F_(j−1)).
```

最后一个恒等式是把 H∩F_j 投影到 A_v，其核恰为 H∩F_(j−1)。因此

```
Σ_(v 可到达) a_v ≤ q .
```

这包括跨层地址相关性和随种子变量的混合。若要求某个选定答案只剩一条原始叶路径，则这条路径的每一个 Y_v 都在一条匹配边内，故每节点 a_v≥n−1。由账本 q≥(n−1)L。反向直接查询选定路径上各边的 n−1 个地址法向便精确达到。因此仅一个指定答案锁定一叶的最小共同查询数正好是 (n−1)L。

若同一张查询表的**每个**答案都必须锁定一个叶，则精确成本为 nΣ_{j<L}N^j。证明是任何查询核内的平移都必须保持所有输入的叶标签。在根，某个非零地址平移若不改变任何匹配边标签，则每条边都平行于它，矛盾。因此根地址分量必须为零。每个子节点都能被某个根地址选择，逐层重复说明所有节点地址分量都必须为零。故查询空间包含所有节点的全部纯地址方向。上界直接问全部独占地址位。仅问一个实际选定路径和对所有答案一次性询问在这里分别对应线性、几何级数费用。

## 3. 一个指定答案中的快速逐代清理

称条件地址单元“已清理”，若它没有同时出现完整边和跨边点。快速清理还要求每个可到达非叶节点 1≤a_v≤b=⌈n/2⌉。这是对选定实际答案下的每一个可到达节点的条件，不要求同一方程对于其他答案也成功。

可以为每个足够大的 n 同时选一个匹配，满足第 82 轮短查询性质，以及任意大小至少 M=2^⌊n/2⌋ 的真仿射单元都不可能被匹配完全填满。后者的固定单元失败概率至多 (M_v/V)^(M_v/2)≤2^(−M_v/2)，以逐条揭示单元内配对得到；全部仿射单元数至多 n·2^(n(n+1))，所以联合界趋零。此匹配在 h₀=⌊n/2−2log₂n⌋ 以内每个非平凡单元仍有两种边类型。

因此每个快速清理节点的 Y_v 只含跨边单点，至少 M 个点选择 M 个不同孩子，而且必有 a_v≥h₀+1。多代余维账本遂给出任意混合共同查询的下界

```
q ≥ (h₀+1) Σ_{j=0}^{L−1} M^j.
```

反向选择同一个空完整边的 b 余维地址单元并在每个存活节点都询问，这些纯地址方程彼此独立，指定答案下的节点数为 Σ M^j，因此 q≤bΣ M^j。两界的比值趋一，对 L 一致；每个指定生存路径分别要经过至少 (h₀+1)L 个条件地址余维，而该构造在一条路径上仅使用 bL。共同查询表仍需支付全部可到达节点，不能把路径上的线性费用当成一张表的总费用。

**逐节点的 P 验收也有同一下界。** 另一种可明确核验的目标是：在每个可到达节点，用其条件地址单元 Y_v 只限制本地地址，而保持该节点的子树种子原样，仅在这个虚拟的纯地址限制上要求 P 非降。仍要求 1≤a_v≤b。在非最后一层的节点，其孩子是至少一层未限制递归副本，齐次秩 r≥N+n≥12(n+1)（n 充分大）。如果 Y_v 内 ft>0，则
```
sqrt(M_v(f/2+t)) − (f+t)
= ft/[2(sqrt(M_v(f/2+t))+f+t)] ≥ 1/12,
```
因为 min(f,t)≥1、max(f,t)≥M_v/3。这使纯地址子比值不超过 r/√s_孩子，严格小于该原节点。故非最后一层仍必须是无完整边并有至少 M 个不同孩子。最后一层不需要控制孩子数，但 a_v≤h₀ 会强制 f,t≥64n，使上式差至少 64n/12>n+1；即使 r₀=1，也会严格降 P。于是所有可到达节点仍须 a_v≥h₀+1，同一几何级数下界成立。反向同一空内边单元在每个节点都保住局部 P。这个目标只检验每个节点的地址切割，不能代替对一个任意混合共同限制的最终整体 P 的判断。

## 4. 一张方程表在所有答案中的逐代清理

这里允许清理单元的余维超过 b，但仍要求每个实际答案中的每个可到达节点都满足 a_v≥1 且单元已清理。适当选择固定匹配时，这个目标也几乎要问完所有节点地址位。

在上述随机匹配同时加强两条性质：每个大小 ≥64n² 的真仿射单元都不能完全内部匹配；每个大小 ≥64n² 的线性子空间 K 都含一个实际边差。前者同上一节联合界。对于后者，先揭示 V/4 条匹配边，每次选当前尚未配对点最多的 K-陪集中的一个点。至少一半顶点尚未配对，故所选陪集仍至少有 |K|/2 个剩余点。这条边在该陪集内的条件概率至少 |K|/(4V)。从而没有任何内部边的概率至多 exp(−|K|/16)。对至多 2^(n²) 个线性 K 联合，|K|≥64n² 时总失败概率趋零。

对全树任一个固定节点 v，先只规定它所对应的祖先边选择，不固定 H 的答案。随着 H 的兼容答案变化，Y_v 跑过同一个方向 K_v 的所有陪集：任给 y_v 可自由完成全体输入使祖先选到 v，再取这组输入的实际 H 答案。各地址平坦法向均为固定的 (H+L_v)∩A_v。如果 |K_v|≥64n²，至少一个实际匹配边差落在 K_v，于是某个陪集含完整边；因非平凡条件 a_v≥1 且无完全内部匹配的真大单元，该陪集也必含跨边点。清理全答案不允许此情形。于是每个原树节点都有 a_v≥n−2log₂n−6（可向下取整）。对全体原节点按祖先次序用同一余维账本，得到

```
(n−2log₂ n−6) Σ_{j=0}^{L−1} N^j ≤ q ≤ n Σ_{j=0}^{L−1} N^j .
```

上界询问所有节点的全部地址位，所有条件单元都成为单点。渐近首项一致于 L。这说明不能把某个指定答案的快速清理成本移用到共同询问的全部答案上。一般任意混合限制只要最后保住 P 的多代成本，尚未由这些结果刻画。

## 5. 精确核验

本机 Python 3.15.0 实际运行 `python3 verify_matching.py`，退出码 0。用三位固定匹配和二位 bent 种子，逐局部地址带作整数 Walsh 变换并显式生成 10 组一至三层父谱，再以二元消元核对秩。固定种子 84021 枚举 320 个实际混合仿射纤维内的全部地址点，逐节点核对条件余维账本。三位两代的全部叶指标谱张成全部 15 维独占地址方向，选定一叶的实际纤维余维恰为 4。十位种子 84022 的两代补偿例取得 f=123、t=266、B=8192 和均匀叶质量 1/8192，父 (D,s)=(791563,274877906944)，子 (D,s)=(26265,268435456)，严格提高 P。实际输出见 `matching.txt`。随机匹配的渐近性质和任意层成本由解析论证承担。

## 附录：每代共用一份物理地址时的区别

若把模型改成同一深度所有节点共用一个新地址 y_j，而各叶仍持有独占底种子与守卫，则每个路径指标为各代所选边指标的乘积。谱仍有 s_L=N^(2L)s₀，地址维只付 nL，故 R_L=N^Lr₀+nL。选择一个叶的某个答案成本精确为 (n−1)L；把所有答案一次性分到确定叶的成本精确为 nL。对于快速逐代清理，从任一存活路径上的 L 个独立深度求和，得下界 (h₀+1)L；每代用同一个空内边单元得上界 bL。非平凡全答案清理类似介于 (n−2log₂n−6)L 与 nL。这里各自查询共用地址，每层只付一次，因此不能沿用私有节点的几何级数。若更进一步把各深度的物理地址也设为同一个 y，同一匹配形状迫使每代重复同一边下标，只剩 N 条对角线叶路径。整数脚本另显式核验独立共享深度地址模型的一、二、三代 (s,R) 分别为 (64,15)、(1024,54)、(16384,201)。

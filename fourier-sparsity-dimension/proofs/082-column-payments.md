# 多位切片的列宽、齐次关系与秩支付

写真实布尔函数 F(u,x) 的地址 u∈F₂^t，N=2^t。每个 F_u 是真实布尔数据切片，支撑为 S_u，稀疏度为 s_u，齐次谱秩为 R_u。对每条出现过的数据标签 β，记列 f_β(u)=F̂_u(β)，活跃地址集 T_β，k_β=|T_β|，以及 n_β=|supp f̂_β|。父频率系数正是这些地址 Walsh 系数，因此 s(F)=Σ_β n_β。全文计入可能出现的零数据标签。

## 1. 逐列界：仿射依赖及整数分母

**符号模式计数。** 对任意非零真实列 f，令 k=|supp f|、ν=k−1−affdim(supp f)、n=|supp f̂|。则

```
n/N ≥ 1−2^(ν−k)·binom(k,floor(k/2)).
```

如果右端为负，可与普通的 kn≥N 一起取最大值。将物理平移的符号向量再乘一个独立公共符号，恰在行地址的齐次评价码上均匀，码维为 k−ν。傅里叶和为零只取决于此符号模式，在大小 2^(k−ν) 的带符号陪集中等概率。给定 k 个严格正权，产生指定子集和的子集构成反链，大小至多中间二项式系数。后者可通过均匀排列的最大链与期望相交数至多一证明。故得界。特别，三个不同二元地址必仿射独立，故 n≥3N/4。四个仿射独立地址若系数等模，则 n=5N/8。k 为奇数且模长相同时，任何符号和都不能为零，故 n=N，与行地址几何无关。

若活跃地址本身是 r 维仿射平坦，且所有非零值等模，则 n=(N/2^r)·s(G)，G 是内在 r 位活动平坦上的布尔符号。因布尔谱不能恰有两点或三点，故或有 n=N/k（G 为带符号字符），或 n≥4N/k。二、三点禁例直接来自布尔平方中任意一对不同谱点的和无法由第二个无序对表示。取 G 为二次弯曲二位函数可实现四倍。

**分母判据。** 将任意列乘以共同二进分母成为整数向量 z(u)，对坐标子集 I 记 M_I=Σ_u z(u)∏_{i∈I}u_i，令

```
j = min_I (|I|+v₂(M_I)),
p_j(α) = Σ_{I:|I|+v₂(M_I)=j} ∏_{i∈I} α_i    [在 F₂ 上].
```

v₂(0)=∞。把每个 (-1)^(α_i u_i) 展开为 1−2α_i u_i，可知全部未归一化 Walsh 值 W_z(α) 被 2^j 整除，且 W_z/2^j 模二恰等于 p_j。这是非零的平方自由多项式，因此 j 恰为最小实际估值。于是 n≥wt(p_j)≥N/2^deg p_j。最后一步是二元多项式最小重量，可按一位分片归纳。

特别地，列中奇数个最细分母的地址会使 n=N。对偶数个奇数地址，设 C=Σ_u z(u) mod 4、v=⊕_{z(u) 奇}u，则 W_z(α)≡C−2α(v) mod 4。v≠0 时至少一半地址频率非零；若 v=0 而 C=2，则 n=N；v=0,C=0 时这一层不给下界。奇数同模是最细分母奇数判据的直接情形。所有列的实际分母置信不依赖浮点舍入。

任一列宽下界 b_β 可累加：任何标签集合 T 至少支付 Σ_{β∈T}b_β 个父频点。若这些标签的 k、ν、分母层等保证共同宽度 b，则它们贡献的新增商秩至多其频点成本除以 b。例如活动行仿射独立的列，至少各付 N/2（k=1 时付 N）。

## 2. 多位查询的秩—重合判据

令 V_u=span{(1,β):β∈S_u}，R=dim Σ_u V_u，L=Σ_u s_u=Σβ kβ，U=Σ_u(R_u+1)，J=Σ_u R_u−R。父谱投影张成维数恰为 R，设实际父投影核维数 t_eff≤t。定义

```
Δ=J+N−t_eff−1,   D*=Σβ [kβ−sqrt(kβ nβ/N)].
```

若 Δ/U≥D*/L，则至少一个真实地址限制保留或提高 P(F)=(R(F)+1)/√s(F)，其中 R(F) 为父齐次谱秩。t_eff 不便求时可替为 t，仍是充分判据。也可把 D* 中各 nβ 替为 §1 的任何宽度下界。

**证明。** 设 s=s(F)。由 Cauchy–Schwarz，

```
sqrt(s/(NL)) ≥ (Σβ sqrt(kβ nβ/N))/L = 1−D*/L.
```

而 R(F)+1=R+t_eff+1=U−Δ，且 max_u P(F_u)≥U/√(NL)，联立即得。更精确、但需知道父总稀疏度 s 的相应判据是 (U−Δ)² NL≤U²s；D* 的优势是可由单列下界逐项提供。

令 Q=Σβ(kβ−1)=L−|∪_uS_u|。普通不确定性只给 D*≤Q。k=2 且两值等模时这项为 1（等于 k−1），不等模时 n=N，降低到 2−√2；k=3 时再由 §1 得这项至多 3/2（从 2 改进），三值等模时进一步为 3−√3。等模平坦且相位非字符时，这列 sqrt(k n/N)≥2，因而相比普通界至少节省一单位重合费用。

**共享关系空间。** 在每个出现位置 (u,β) 放置一个二元坐标。K_row 是每行在齐次列上求和为零的关系空间，K_col 是每个标签列的出现位取偶权的关系空间（维数 Q）。设 h=dim(K_row∩K_col)。将 K_col 映到 ⊕V_u，各列偶权关系的像在对行求总和的核中，像维数 Q−h，故 J≥Q−h。于是无需求出全部 J，条件

```
(Q−h+N−t_eff−1)/U ≥ D*/L
```

也可直接使用。相交空间中非零关系每一非空行至少触及四个不同标签、每一非空列至少触及两个地址；两行时它正好是重合标签的齐次关系空间。 还可写成精确分解 J=Q−h+dim K−dim π(K_row)，其中 π 把出现位置按列求和，K 是全部不同标签之间的齐次关系空间。事实上 π 在 K_row 上的核维数为 h，所以 dim π(K_row)=L−Σ_u R_u−h；再用 dim K=|∪S_u|−R 即得。最后两项之差度量通过各行内部关系还未生成的全局数据关系。若 h=0 且所有行都非字符，则 L≥U，由普通 D*≤Q 已足够。允许 c 行为字符时 L≥U−c；若 N−t_eff−1≥c 也足够，因为 Q≤L、有 Qc/L≤c。

**精确地址核。** 对每列选择一个实际存活地址频率 α_β。令 W 是所有列内地址频率差所生成的空间。对不同数据标签的齐次关系 λ（Σ λ_β(1,β)=0），将其送入 Σλ_βα_β modulo W。该映射与锚点选择无关。父投影的核先含 W，取商后恰是此映射的像，所以

```
t_eff = dim W + rank(λ↦Σλ_βα_β mod W).
```

## 3. 两个真实二位查询见证

三个数据位，四个地址按整数二进制顺序排列。用 8 位整数真值掩码描述一行，掩码位为一表示函数值 −1。

- 掩码 (178,17,71,40)：四行均为四点谱、齐次秩三，U=L=16，J=8，t_eff=2，Δ=9。非空列按标签顺序 k=(2,4,2,2,2,2,2)，n=(2,1,2,2,2,2,2)。D*=Q=9，满足多位条件。
- 掩码 (204,123,156,219)：U=14、L=13、J=6、t_eff=2、Δ=7。k=(2,3,2,2,2,2)，n=(2,3,2,2,2,2)，D*=13/2、Q=7。旧的 Q/L=7/13 超过 Δ/U=1/2；三地址列的改进使 D*/L=1/2，恰通过本文充分条件。

两例每个父谱 s=13、R(F)=6，故 P(F)=7/√13<2，而最大行 P=2。三种单问方向指这两个查询位所张成平面内的非零方向。两例的每个此类单问均无法通过第 81 轮充分判据。第一例其 (j,k,e) 恒为 (5,9,9)，第二例依次为 (4,8,7)、(4,8,7)、(5,9,9)。这些有限见证并不排除其他频率方向的单问。

## 4. 奇重量等模切片的强支付

设所有 N 行是 a≥2 个内在数据位的奇重量布尔函数，且其全部 Walsh 模长完全一致。由第 62、76 轮同模对齐，各行可写为

```
F(u,x)=ε(u)G(x+b(u)).
```

令 p_β(u)=ε(u)χ_β(b(u))，则 f_β(u)=Ĝ(β)p_β(u)。所有 2^a 个数据标签出现。定义 C 为满足 χ_v(b(u)) 是带符号地址字符的 v 的集合，这是线性空间。对每个 β+C，该地址 Fourier 支撑恰为代表 p_β 的支撑的平移，宽度和方向空间相同。nβ=1 的列或者没有，或者恰构成 C 的一个完整仿射陪集；所有其他列 nβ≥4。故只要有非单点列，s≥(5/2)·2^a。

令 W 为全部地址带的方向空间之和，则父秩精确为 a+1+dim W。根据 §2，只需检查跨列锚点关系在模 W 后消失。对 v∈W^⊥，每个 p_β(u+v)/p_β(u) 均与 u 无关（所有该带频率给出相同字符值）。从原函数表示可见，固定 u 时这组比值恰是 β 的仿射符号模式。每条齐次标签关系遂使其乘积为 1，因此锚点关系的像在模 W 后为零。

**不提高极值比。** 令 K=max(2,max_β P(p_β))。若 a≥6，则 P(F)≤K；若存在单点地址带，这个结论在 a≥5 时已经成立。这里 p_β 本身是真实地址 Boolean 函数，但不要求它是 F 的仿射限制。

设 m=a−dim C。W 由 β/C 空间上任取一组仿射基的相应相位频谱方向生成，因为任一相位是基相位的奇数项乘积再乘地址字符。乘积的所有频率落在各支持仿射包之和中，所以其方向被基方向支付。若没有单点带，均匀选 (m+1) 个点的仿射基，并对方向秩和取平均。记 x² 为各陪集的宽度平均，则 x≥2、s=2^a x²，且

```
dim W ≤ (m+1)(Kx−2).
```

于是 P(F)≤K 只须 (m+1)+(a−2m)_+/4≤2^(a/2)：a−2m≤0 时左侧至多 a+1，a−2m>0 时至多 (a+2)/2。a≥6 时均成立。

若有单点带，从它的陪集出发加均匀的 m 元线性基。m=0 时 W=0、s=2^a，直接得 P≤2。m>0 时记 x² 为非单点陪集的宽度平均，则 x≥2、s=2^(a−m)(1+(2^m−1)x²) 且 dim W≤m(Kx−2)。P(F)≤K 只须

```
m x+(a+2−2m)_+/2 ≤ 2^((a−m)/2) sqrt(1+(2^m−1)x²).
```

若 a+2−2m>0，除以 x 后左侧至多 (a+2)/2，右侧至少 2^((a−1)/2)，a≥5 时足够。若 a+2−2m≤0，只需 m²≤2^a(1−2^(−m))：m≤a−1 时用 (a−1)²≤2^(a−1)；m=a 时用 a²≤2^a−1，均在 a≥5 成立。这个归约覆盖真实等模奇重量族；一般不同模长或不同活动域的系数表仍不能这样归约。


## 5. 整数核验

本机 Python 3.15.0 运行 `python3 -B verify_columns.py`，退出码 0，实际输出见 `columns.txt`。对三位地址全部 6,560 个非零三值整数列核对反链下界、Walsh 估值及最低层奇偶多项式；另以整数 Walsh 变换核对两个完整真实五位见证及其六个单问检验，两例均有 h=1 且 J=Q−h。奇重量等模族取 2 至 8 位数据变量、4 位地址变量，构造 72 个真实函数，逐父频率和二元秩核对解析式。没有随机数或浮点阈值。一般表的判据、幅度界及等模族归约由解析证明承担。

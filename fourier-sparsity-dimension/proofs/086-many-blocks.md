# 任意多 Petersen 图块的真布尔谱

给定 m≥1、整数 a≥1 满足 M=2ᵃ>15m，记 p=M−15m≥1。每个图块有自己的十个数据位，取十五条 Petersen 边的二元关联列 e_i+e_j，分配至十五个互异的地址单点。对所有图块使用不同地址。其余 p 个地址单点为填充，每个选择自己 n 位（n≥2 为偶数）的非退化二次 bent 符号。第一填充不加守卫，其余填充各乘独立新字符。先以各填充使用互不相交的 n 位为约定。选 n 使
  2^(n/2)≥3(R+1)，R=9m+a+p(n+1)。
对每个 m,a 总能选到；例如 n=4a+8 一定足够，因为 a≥4，R+1≤2ᵃ(n+3)，而 2^(a+4)≥3(4a+11)。若各填充共用相同的 n 个 bent 数据位，同一证明适用，秩公式改为 R=9m+a+n+p，对此 R 使用同一充分条件即可。地址单点分配的次序任意。

所得真布尔函数的谱稀疏度为 M(15m+p·2ⁿ)。每个图带有 M 点、每项模 1/M，每个填充带有 M2ⁿ 点、每项模 1/(M2^(n/2))，因为地址单点的谱是全地址且 bent 谱等模。独立守卫使重复填充的数据标签也不相交，图与填充的数据坐标分离。第一填充带齐次张成包含 (1,0)、a 个纯地址方向及本组 bent 方向。每一其他填充带加入相应的纯守卫方向，并提供自己的 bent 方向。写 D 为各填充带的齐次张成之和。全谱秩等于上述 R，模 D 后是 m 个独立九维偶校验空间 E_i 的直和，各块的图边按原关联列投影。

**任意割。** 若真子空间 X 没有包含 D，则某填充带的齐次张成不包含于 X。一个仿射平坦要么全在 X 中，要么与 X 的交至多为一半。故外质量至少 2^(n/2−1)，由 n 的条件，(codim X+1)/外质量≤2/3。

现设 X 含 D，写 U=X/D，u=codim U>0，u_i=codim_{E_i}(U∩E_i)。商可以混合不同图块，但 ⊕(U∩E_i)⊂U，故 Σ_i u_i≥u。若 u_i>0，在该块按 e_j+e_k∈U∩E_i 定义顶点等价类。设类数 t_i，类内的偶和全在 U∩E_i，故 u_i≤t_i−1。Petersen 图三边连通，跨类边至少 3t_i/2≥3(u_i+1)/2；每条恰支付一单位外模长。至少一个 u_i 正，因而外质量≥3(u+1)/2。取 U 为除一块外所有 E_i 的直和，余维九、外质量十五，证 L=2/3。

**无余圈单点张满集。** 对每个图块，将任一真实张满且每个选中点均在回路中的谱子集投到 E_i，舍去零列，保留可能的多条平行原像。所得是连通的十顶点多重图。每个像的非零出现都在某个投影关系中，因此没有桥。若只用十条或更少的多重边，连通无桥及握手公式强迫恰十条、每个顶点度二。这样的图是 Hamilton 圈，重边只能构成孤立二点成分，不能出现在十点连通二正则图。Petersen 图无 Hamilton 圈，故每块至少十一项；原证明及枚举见 085-petersen-packing.md。于是所有图块合计至少有 11m 个图频率点。用 C 的边际条件按全部图点求和，得 C≥11/15。按 L=2/3 仅能支付 10m 点，缺口为 m。

每块选择第 85 轮的十一边无桥张满子图，在图自同构上均匀平均。每条边入选概率为 11/15，在选中边的带上均匀选一个地址频率。对每个填充带独立取仿射坐标，令 t=a+n，选取
  {0,e₁}∪⋃_{j=2}^t {e_j,e₁+e_j}。
它是 t−1 个四点仿射平面的并，恰 2t 点；每点位于一个四点回路，齐次张成该带。再在该带中均匀平移。这个选择兼容奇数 t，此时单个长为 t+2 的仿射回路因奇偶性无法存在。每个填充谱点的边际为 2t/(M2ⁿ)。因 R≥t+1，条件 2^(n/2)≥3(R+1) 保证 2t≤(11/15)2^(n/2)。

全部填充选点已张满 D。各图的选点在商中张满全部 E_i。对于任何一个选中的图点，取经过其像边的圈，其提升频点之和落在 D，故可用已选填充点补出含该点的线性依赖。存在含该点的依赖等价于存在含该点的回路。这使所选集整体张满、每点都在回路上。图谱点的边际恰为 (11/15)/M，填充边际至多 (11/15)/(M2^(n/2))。故 C=11/15，各 m 均取等。

**本机核验。** 运行 python3 -B check-many.py。Python 3.15.0 整数枚举证实十边无桥张满简单子图数为零，十一边子图有 60 个，每条边在其中 44 个，44/60=11/15。额外检查 m=1,2,3,7,17 及独立或共用 bent 变量的十个参数配置，逐列删除核验填充选点的齐次张成。使用固定种子 86052 在这五个块数上验证 966 个随机商核的割支出，含多个图块混合的线性约束。整数证书和参数表在 result-many.json。

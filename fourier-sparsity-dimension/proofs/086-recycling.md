# 重复边标签的真实图选择器及迭代屏障

考虑一类真实布尔运算。子函数 G_i 各在独占变量组上，再乘独占的守卫字符得到 H_i。每个物理地址 u 指定一个超边 e(u)（可为空，并可多次复用同一超边）和符号 ε(u)。节点输出

```
F(u,x)=ε(u)∏_(i∈e(u)) H_i(x_i).
```

图边是两元素超边的情形。允许同一个真正子函数在任意多条不同边上复用。记实际不同标签数 m，A_e={u:e(u)=e}，p_e=Pr(A_e)>0，h_e=ε1_{A_e}，其地址谱 B_e=supp ĥ_e、宽度 k_e。避免与节点数混淆，记每个子函数的 s_i、齐次秩 R_i，旧归一化取 P_i=(R_i+1)/√s_i。本稿的“重复”允许整组识别多个子函数，但不假定不同守卫的子数据可以只共享部分坐标。

## 1. 精确谱及秩，和可逐边支付的损失

不同边 e 的数据频率带互不相交：在每个守卫坐标，活动标签恰记录顶点是否属于 e。因此

```
s(F)=Σ_e k_e ∏_(i∈e) s_i .
```

设 W=span ∪_e(B_e−B_e)，a=dim W。对每边任选实际地址锚点 α_e，记 r_*=rank₂{(1,α_e mod W,1_e)}，其中 1_e 是顶点空间的边入射列。则

```
R(F)=a+r_*+Σ_i(R_i−1),      r_*≤m .
```

各守卫子带的差空间互相独立，且由任何包含该顶点的边恢复。地址带差生成 W。模去这两类差空间后，每边剩一个齐次列，其数据投影是 1_e；不同守卫的锚点各自独立。这证明精确式。无符号指标掩码均以零为地址锚点，此时 r_* 为超边入射的齐次秩。

不确定性给 k_e p_e≥1。记 x_e=∏_(i∈e)√s_i，则

```
√s(F)=sqrt(Σ_e k_e x_e²) ≥ Σ_e x_e .
```

这是 Cauchy–Schwarz 和 Σ_e 1/k_e≤Σ_e p_e=1 的直接结果。令 K=max(2,max_i P_i)，写 L_i=R_i−1 和

```
σ_e = K x_e − 2 − Σ_(i∈e)L_i .
```

则 σ_e≥0。全为字符时直接用 K≥2；仅一项非字符时由其 P_i 约束；至少两个非字符时，每个 √s_i≥2，而这些数的和不超过乘积。最后一种情形若恰有 j≥2 个非字符，进一步有 σ_e≥2(j−1)。三点或两点谱的非字符不可能，因为布尔平方中的非零差会有唯一无序对。

## 2. 合并后的带符号掩码有 9/4 的不确定性缺口

对任意非零 h∈{−1,0,1}，记 p=Pr(h≠0)、k=|supp ĥ|。则有如下锐二分：

```
pk=1，且 h 是一个仿射平坦上的带符号字符；
或者 pk≥9/4。
```

证明如下。令 N=2^⌊log₂k⌋。整数 Fourier 粒度给 b_e=N ĥ(e)∈ℤ，见第 77 轮。简要证明：将目标频率移到零，反复选物理方向取两点平均，每次用对所有方向的平均计数消掉至少一半谱点，最终只剩目标；至多 ⌊log₂k⌋ 次平均，每次只付一个二分母。由 |ĥ(e)|≤p，若 pk<9/4，则每个非零 b_e 只可能是 ±1 或 ±2。若全为 ±2，则 Parseval 给 pk=4(k/N)²≥4。若有双单位且也有奇单位，记双单位数量为 b，Parseval 给 pN²=k+3b，而 pN≥2。最低估值奇层至少有 N 个点，即 k−b≥N。这是第 65 轮整数 Walsh 矩到二元 Reed–Muller 最小重量的论证。联立得 2N≤k+3b≤4k−3N，故 k≥5N/4，进而 pk≥5/2，矛盾。

余下全为单位模。因此 pk=(k/N)²<9/4，且全真实支撑是最细估值层的 Reed–Muller 字，最小重量为 N。非最小字重量至少 3N/2（第 77 轮已有独立的二元重量间隙证明；也可直接用第 53 轮的三值平坦谱间隙）。因此 k=N 并达到不确定性等号。等号时每个非零 Fourier 模长为 p，选一条频率并调制为零即知物理支撑上符号常定；所有活跃频率在物理支撑恒定，反演又保证其恰为相应湮灭空间的一整个陪集。反向真带符号字符显然取等。

锐例在 u,v∈F₂² 上取 h(u,v)=1_{u=0}−1_{v=0}，物理支撑 6/16，地址谱为两个非零坐标轴各三点，宽度六，故 pk=9/4。这个缺口适用于物理域内有任意符号和任意多个重复引用后合并的真实掩码。

**整体谱超额及地址秩。** 令 L 为不超过 m 的最大二幂，T_*=L(3m−2L)，Δ=Σ_e k_e−T_*。称第一类掩码良好，其他为不良。对良好掩码，因 1/p_e=k_e 为二幂，k_e≥3L−2L²p_e。对不良掩码，p_e(3L−2L²p_e)≤9/8，而 k_e p_e≥9/4，故 k_e−(3L−2L²p_e)≥k_e/2。相加得

```
Δ ≥0,      Σ_不良 k_e≤2Δ,     a≤m−1+2Δ .
```

最后一项用了真实几何。每个不良掩码的活动指标是 h_e²，其 Fourier 支撑落在 span(B_e−B_e) 内。模去所有这些方向的总和，良好块的正权指标和在每个陪集为常数，因为它等于一减去不良块指标之和。第 59 轮条件正权仿射覆盖界在该商中至多收取 g−1 个法向方向（g 为非空良好块数）；无良好块则不需要此项。不良地址方向总共不超过 Σ_不良(k_e−1)，从而得到所述上界。另一个直接来源是有 B 个仿射原始地址单元、每单元用一个带符号字符，再把相同边标签合并。如果 B≤Tm，任意合并的一次地址秩成本至多 (B−1)+(B−m)：第一项是原始仿射分割的法向秩，第二项支付相同边标签的各谱锚点差。于是 R(F)+1≤Σ_i L_i+2Tm，即使合并掩码并非仿射。

## 3. 重复复用的可扣减项与任意代上界

定义地址 Cauchy 余量 `η=√s(F)−Σ_e x_e≥0`。利用上一节和精确谱式，

```
P(F)≤ K+[2Δ−Σ_i(deg(i)−1)L_i−Σ_eσ_e−Kη]/√s(F).
```

证明只需把 R(F)+1≤Σ_i L_i+2m+2Δ 同 K√s(F)=2m+Σ_i deg(i)L_i+Σ_eσ_e+Kη 相减。这里 deg(i) 是在实际不同边中的度数。故重复利用一个有秩的非字符块，或在同一边乘两个非字符块，都有真实预算扣款。Δ=0 时每节点保住子代最大 P 与二的较大者，任意深度不增长。即使 Δ 无界，只要逐节点 2Δ 被重复顶点、乘积和 Cauchy 余量支付也一样；更一般，沿任意根叶路径 Σ_v 2Δ_v/√s_v 一致有界，亦可把实际地址超额累加支付。

**有界平均复用或每边秩费用给任意深度界。** 假定同一常数 T≥1 在所有节点满足 a+r_*+1≤2Tm。充分情形包括 B≤Tm 的原始仿射单元合并，或 Δ≤(T−1)m 的任意真实掩码。置 τ=4T−3，取

```
C=max(4T−2,  max_底种子 (R+τ)/√s).
```

则整个任意异质递归满足 `(R+τ)/√s≤C`。归纳假设下，对每边有

```
2T+Σ_(i∈e)(R_i−1) ≤ C x_e−(τ+1−2T).
```

按零、一、多项非字符得到：零项用 C≥τ+1；一项用归纳势；多项用各自 √s_i≥2 且和≤乘积。当 m≥2，逐边相加，m(τ+1−2T)≥τ−1，支付节点新分子的常数项。若 m=1，节点就是地址符号与各子函数的独立张量。该地址符号本身 R≤2T−1；若非字符，其谱大小至少四，故 (R+τ)/√s≤C，字符也满足。对所有张量因子再次使用零、一、多项非字符及平方根的和≤积，得所需归纳。

因此只限制平均每个实际标签原来出现的单元数，就能在真实大量复用、任意节点大小和异质种子下给深度无关上界。更直接的 Δ/m 条件允许同一标签的复用次数任意大。若将整个子块（含守卫）识别，先把顶点按等价类缩并，超边改成奇数重数类的集合，完全相同的边合并地址掩码。仍回到同一个模型。只识别块的一部分坐标时，边带可能交错，本稿不声称此公式成立。

**固定图递归的特殊情形。** 如果每个顶点子函数是上一代的同一私有副本，每代使用同一非平凡图及同一真实掩码，则 s_{j+1}=(Σ_e k_e)s_j²，R_{j+1}=v(R_j−1)+a+r_*，其中 v 为顶点数。只要谱增长因子超过一，稀疏度按双指数增长，秩至多按指数增长，此直接图迭代的 P 趋零。

## 4. 两个固定边标签的无符号等价，以及迭代失败

任给非恒布尔函数 G(u)，用两个固定图边 e₀={v₀,v₁}、e₁={v₀,v₂}，子函数只取私有守卫字符。定义

```
H(u,x)=1_{G(u)=+1} χ_(x₀+x₁)+1_{G(u)=−1} χ_(x₀+x₂) .
```

可视为逐物理单点反复选两个标签，不需要任何地址符号。两个指标带都含地址零频，且每个 G 的非零地址频率都恰在两带出现。故严格有

```
s(H)=2(s(G)+1_{Ĝ(0)=0}),        R(H)=d(G)+2 .
```

因此 P(H)≥P(G)/√2。若均值非零直接；若均值为零且 d(G)≥2，用 s(G)≥d(G) 及 (d+3)/(d+2)≥√(1+1/d)；秩一字符直接验算。故允许任意巨大的重复单元数，仅用两个无符号固定图边的族已和整个 A28 有界性等价。生成掩码时外部已给定 G；这不是从固定种子自己增长的构造。

若反复把刚才的 H 作为下一代的地址布尔函数，第二步起输入始终平衡，因为每个频率有守卫位。此时 s_{j+1}=2s_j+2，而普通谱秩只增加二。故这种特别节省标签的回收流程自身 P 趋零。试图靠重复图边生成发散族，须越过上述谱超额和复用扣款；本轮未得到发散种子。

## 5. 本机整数核验

Python 3.15.0 实际运行 `python3 verify.py`，退出码 0。检查三变量全部 6,560 个非零三值掩码、固定随机种子的 5,000 个四至五变量掩码、以及四变量六点等号例。另对 30 个有明确真值表的带守卫图或超图节点，逐父特征做整数 Walsh 变换和二元消元，核对带分解、地址锚点、谱超额和递归势；一个实际双代例得到 (R,s,Δ)=(7,64,0)。六位外给种子的无符号两边编码核对 (d_G,s_G,R_H,s_H)=(6,50,8,102)。全部有限检查只作公式与边界核验；一般不等式由解析证明承担，输出见 `verify.txt`。

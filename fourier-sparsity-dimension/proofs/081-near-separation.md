# 近分离外带的严格桥阈值与异常切片

令 H₀(x)=(F(x)−F(x+v))/2∈{−1,0,1} 为真实半差。删去若干 Fourier 项 D 后，剩余各拟阵组件的列张成 V₁,…,V_m 成直和；所以半差写为

```
H₀(x) = P(x)+b(x),     P=Σ_i h_i(x_i),     b=Σ_{ξ∈D∩{ξ(v)=1}} a_ξ χ_ξ.
```

这里各 x_i 可独立赋值，每个 h_i 的值域关于零对称。在有效物理空间上取均匀测度时，各 x_i 独立均匀。对真实半差，这种对称性可由局部平移翻转该块全部切中频率得到（共同使用 ξ(v)=1 也可）。额外物理变量不影响 P，允许 b 依赖全部变量。

## 1. 统一误差严格小于 1/4 时，可以精确舍入

若 ||b||∞≤η<1/4，则存在至多两个实际块，H₀ 恰等于它们各自的独立舍入之和：

- 只有一个强块时，H₀ 等于该块到 {−1,0,1} 的逐值舍入。
- 有两个强块时，两块都处处不为零。H₀ 恰等于两块的带符号 1/2 之和。每块到其所对应的 ±1/2 的距离至多 η−W。
- 无强块时 H₀=0。

这里 A_i=||h_i||∞；A_i>η 的块称强块，其余称弱块，W=Σ_weak A_i，且 W≤η。弱块不影响舍入。

**证明。** 因 H₀ 是整数且距离 P 至多 η，H₀ 是 P 唯一的最近整数。改变一个弱块的物理状态时 P 至多改变 2η。不同整数的 η 邻域之间间隔至少 1−2η>2η，因此舍入不变。固定所有强块，比较弱块同时在 ±极值的情形，得到 W≤η，且强块之和到同一个整数的距离至多 ρ=η−W。特别地，H₀ 只依赖强块。

随后对每个强块把状态从 −A_i 依次翻至 +A_i。每次上升 2A_i>2ρ，因此舍入值严格递增。{−1,0,1} 最多容许两次递增。只有一个强块时，所述逐值舍入即为 H₀。若有两个，其极值组合 (−A₁,−A₂)、(+A₁,−A₂)、(−A₁,+A₂)、(+A₁,+A₂) 的舍入值分别为 −1,0,0,1，故

```
|A₁+A₂−1|≤ρ,  |A₁−A₂|≤ρ,  |A_i−1/2|≤ρ.
```

现在固定第二块任意实值 u，并比较第一块的状态 ±A₁。两值距离 2A₁ 落在 (2ρ,2−2ρ)，故其舍入恰差一。取两端中点可知 u 距某个 ±1/2 至多 ρ。交换两块得同样结果。两强块之和到相应半符号和的距离至多 2ρ<1/2，故最近整数等于半符号和。无强块时强块之和为零，结论亦成立。

**对桥项的直接后果。** 舍入后的频谱支撑落在原先各块空间的并 ⋃V_i 内。任何真正跨块的频率（不属于任一 V_i）如果在半差中系数非零，都会与此矛盾。若某一轮对整个核外谱删去 D，且 Σ_D|a_ξ|<1/4，那么对每个 ξ∈D 可选一个湮灭核、且 ξ(v)=1 的 v，结论迫使 ξ 属于某个原保留块的张成。于是每个删项都回到一个原块，核外拟阵的分组件数不变，可直接应用第 80 轮，不需要抛弃切片。若 D 本来定义为真正跨块的频点，D 必为空。同一结论也适用于能独立赋值的条件切片，前提是取条件后各块的作用仍然独立且可翻号。

**阈值锐利。** 独立符号 x,y,z 上

```
H₀=(x+y+z+xyz)/4
```

取值为 −1、0、1，翻转三符号同时使它变号。因此 F=1−H₀²+H₀ 为真实布尔函数，H₀ 是在该平移下的真实半差。前三项是三块独立方向，最后一项是跨块频率，桥 ℓ₁ 恰等于 1/4。三项最大模均 1/4，不能舍入为所述半幅形式。亦可把不切中频率组成的偶次频率超平面作核，得到整条核外带的等号例。

## 2. 单靠均方误差时的概率型结构

令 ε=||b||₂，C₀=(1+π/√2)²，假设 Δ=C₀ε²<1/16。则存在如下两类情况之一：

1. H₀ 与两个固定块各输出 ±1/2 的和，在除去概率至多 13Δ 的输入外完全相等。
2. H₀ 与至多一个固定块的三值函数，在除去概率至多 12√Δ+3Δ 的输入外完全相等。

第一类和第二类的判据是各块的模整数特征函数的符号。此结论在块间独立下成立，误差估计不含块数或桥频率数。

**逐块舍入。** 设 c_i=E cos(2π h_i)。因对称性 E exp(2π i h_i)=c_i；因 H₀ 整数且独立乘积成立，

```
Π_i c_i = E cos(2πP) = E cos(2πb) ≥ 1−2π²ε² > 0 .
```

所以每个 c_i 非零，且负号数为偶数。将 h_i 舍入到最近的整数（c_i>0），或到最近的半整数 Z+1/2（c_i<0），记作 g_i。选择舍入使奇对称；同距的情况可用该块上翻号配对打破。对仅给出对称分布的版本，可以加入独立的本地硬币，最后从平均误差中选定硬币实现。对到相应格子的距离 d，有 1−cos(2πd)≥8d²，故

```
Σ_i E(h_i−g_i)²
 ≤ (1/8)Σ_i(1−|c_i|)
 ≤ −(1/8)log(1−2π²ε²)
 ≤ (π²/2)ε².
```

最后一步用 2π²ε²<1/2。误差独立且中心化，因此其和的 L² 范数至多 π ε/√2。Q=Σ g_i 是整数，三角不等式给 ||H₀−Q||₂≤(1+π/√2)ε，因而 P(H₀≠Q)≤Δ，特别是 P(Q∉{−1,0,1})≤Δ。

**半整数情形。** 半整数块若至少四个，固定全部模长，且固定其余符号，再翻动其中三个。沿全负到全正的翻转路径每次至少加一，因此八种符号中至少一个 Q 不在 {−1,0,1}，与 Δ<1/16 矛盾。所以只能有两块。若任一整数块非零，同样用三次翻动可知该事件概率至多 8Δ。若任一半整数块的模至少 3/2，保留另一块（模至少 1/2）并翻动二者，极端值之差至少 4，四种中至少一种 Q 不在三值集合，所以该事件概率至多 4Δ。再加 P(H₀≠Q)≤Δ，得到 13Δ。

**整数情形。** 任一 g_i 的模若至少 2，单翻此符号迫使至少两种之一出错，故发生概率至多 2Δ；若同时有两个不为零，翻两符号的四种至少一种出错，故概率至多 4Δ。设 p_i=P(g_i≠0)，取最大 p_i 的块 i_*，令 T=Σ_{i≠i_*}p_i。可把下标分成两群、每群激活概率和至少 T/3：若最大 p_i≥T/3 就单列它；否则逐个加入一群直至超过 T/3，该群至多 2T/3。各群激活独立，得 (1−exp(−T/3))²≤4Δ，因此 T≤12√Δ。除去概率至多 T 的其他块误激活，再除 P(H₀≠Q) 和大于 1 的异常，H₀ 与 g_{i_*} 的三值截断完全相同。

**整数情形误差阶锐。** 取 0<p≤1/2，取两个独立稀有三值块 g_i，各以 p/2 概率取 ±1、以 1−p 概率取零（用一个仿射地址门乘一个独立字符实现）。令 H₀ 为 g₁+g₂ 到 [−1,1] 的截断。它在同时翻转两个字符时变号，故仍是 1−H₀²+H₀ 的真实半差。取真正的块 Fourier 投影 h_i=(1−p/2)g_i，则余项 b 的频率全为跨块，且

```
||b||₂² = E H₀²−2p(1−p/2)² = p²(1−p)/2.
```

任何只依赖一块的拟合在该块的零状态必须近似另一个独立三值块，因而不一致概率至少 p(1−p)。故这一分支不能统一把 O(ε) 提高至 o(ε)。

## 3. 已分片时怎样计入异常地址

地址 u 固定后，令 η(u)=Σ_β |b̂_u(β)|，其中 β 遍历桥频率的不同数据标签，数目 B。逐带 Parseval 加 Cauchy–Schwarz 给

```
E_u η(u)² ≤ B Σ_{ξ∈D}|a_ξ|²,
δ := P(η(u)≥1/4) ≤ 16 B Σ_{ξ∈D}|a_ξ|² .
```

若只知道一阶均值，也有 δ≤4 Eη(u)。凡 η(u)<1/4 且块独立性与对称性经条件化保持的切片，适用 §1 的精确结论。先删 D 后原列全局独立不自动保证经任意地址条件化还独立，必须核对条件切片的投影空间。另一方面，整体 Σ_D|a|<1/4 直接适用 §1 的全局消桥，无须逐切片假设。

如果某非零数据标签不属于全部正常切片的谱张成，则其带函数只在异常地址中活动。不确定性使每条这样的带至少含 1/δ 个父频率。设 q 为父谱非零数据带总频点数，异常切片对正常总秩的新增量至多 δq；δ=0 时增量为零。因而 δ 单独不能支付所有外秩：在 m 位地址只有 u=0 的异常点选择一个大秩布尔寻址函数，其余地址输出常数。异常比例 2^(−m) 可以独立趋零，异常秩可以无界。

将 §1 阈值锐例乘上 1_{u=0}，则其半差仍由 1−H₀²+H₀ 实现。异常比例 δ=2^(−m)，跨块最高 λ 的整条桥带 L² 能量为 δ/16，但它在 u=0 的切片 ℓ₁ 恰为 1/4。该桥带父谱宽 1/δ，所以估计 δ≤16BΣ|a|²（此处 B=1）精确取等。这是只用未加权全局桥能量主张全切片分离的显式障碍。

## 4. 整数核验

本机 Python 3.15.0 实际运行 `python3 -B check_near_separation.py`，退出码 0。用整数 Walsh 变换穷举四位上相对全翻转为奇的 6,561 张三值表及六种固定直和坐标分组。严格阈值下的 280 对均无跨块桥且至多两块；恰在阈值出现 1,440 个有桥对。对阈值例的地址门控，复算 δ=1、1/2、…、1/256 的完整父布尔真值表、半差与整数 Walsh 系数。对两个稀有块的 L² 例，用有理数复算 p=1/2、…、1/4096 的全部九种值组合及条件投影。概率定理的任意维结论由解析论证承担。

# 每条匹配边接二位 bent 种子仍有全方向对数深度下界

取第 82 轮的匹配：n 位地址空间有 2N=2^n 个点，分为 N 条边。对于所有余维 1≤a≤h₀=⌊n/2−2log₂n⌋ 的仿射地址单元，单元内既有至少 64n 条完整边，又有至少 64n 个跨边顶点。该匹配在充分大的 n 存在，见第 82 轮随机配对证明。此处不要求各单元的事件独立。

对边 i 使用互不相交的私有数据位 w_i,x_i,z_i；边内函数取

```
χ_(w_i) · (−1)^(x_i z_i).
```

记 P=(R+1)/√s、R 为父或子谱的齐次秩，秩分子简记 D=R+1。则父函数精确满足

```
s=4N²,    R=3N+n,    D=3N+n+1,    P=3/2+(n+1)/(2N).
```

每条边贡献四条私有数据标签，在地址上各有 N 个频点。边方向至少有两类，否则某个物理半空间全无跨边或全无完整边，违背匹配条件。不同边法向超平面合计恢复全地址空间。数据标签各为 w_i+E_i 的四点仿射平面，其中 E_i=span(x_i,z_i)。所有父频率都在守卫位总奇偶性取一的平坦上，故齐次秩等于线性秩。父谱的差空间由全部地址方向、全部 E_i 和偶守卫方向组成。

**定理。** 对任意维数 1≤h≤h₀ 的内在物理线性查询，包含任意地址与私有数据混合，以及任何答案，所得真实限制均使 P 严格下降。反向有一个仅查 ⌈n/2⌉ 个纯地址位的仿射单元严格提高 P。故首次存在不降势答案的有效查询数为 (1/2+o(1))log₂R，同时父 P→3/2。外部虚变量及字符调制不改变该结论；自适应的每条短路径最后仍是一个仿射限制。

## 1. 混合查询后的边与秩

先查询原查询空间 H 与纯地址频率空间的交，记其维数为 a，留下一个仿射地址单元 C。其大小 M=2^(n−a)，含 f 条完整边及 t 个跨边顶点。B=f+t 是非空边数。剩余 w=h−a 个方程的投影在数据频率空间形成独立的 w 维空间 W，且全部在偶守卫平坦。解这些方程保留每个地址 u∈C；数据标签取模 W，系数至多多乘一个带符号地址字符。不同边的实际物理活动域不交，因此同一商标签即使由多边提供，也不会使该列恒零。

对每条非空边考察 d_i=dim(W∩E_i)，投影后四个原数据标签的线性秩是 3−d_i。记该边仍有非零列的商数据标签集合为 A_i，秩为 r_i，秩损失 ℓ_i=3−r_i。

- d_i=0 时四个标签互异，每个保留在该边全部在 C 内的点，系数模长均为 1/2。完整边的四条列都宽 M/2；跨边单点的四条列都宽 M。r_i=3。
- d_i=1 时，唯一内位方程在固定地址后给出一条二位仿射直线。bent 种子在这条线上为一个带符号字符。因此每个地址该边恰有一个商数据标签活动，模长为一。完整边的两个端点可能选同一标签（一个宽 M/2 的带，r_i=1），或者选不同标签（两个各宽 M 的带，r_i=2）。跨边单点只留下一个宽 M 的带，r_i=1。
- d_i=2 时，两个内位已由地址决定，只有一个商数据标签，完整边宽 M/2，单点宽 M，r_i=1。

完整边上的两点等模，因为每个地址的剩余 bent 分支是一个字符。两点取相同或相反符号，Walsh 权均恰在一半地址频率上非零；不同端点选择不同标签时各是单点支撑。商守卫奇偶性仍定义良好，所以 A_i 的点非零，两个不同点必线性独立，而四点情形恰只有一个全部四点之和为零的关系。

设 r=dim span ∪_i A_i，J=Σ_i r_i−r，L=Σ_iℓ_i+J=3B−r。则

```
D' ≤ 3B+(n−a)+1−L,          0≤L≤2w.
```

因为所有非空边原数据空间直和，未考虑边内消失前的投影秩至少 3B−w。相对各边的完整投影，只有 d_i=1 且实际留下一个标签时再少一秩，发生边数至多 w（各 W∩E_i 直和）。这给 L≤2w。没有纯地址方程时 B=N，原数据投影秩恰为 3N−w，于是还有 L≥w。

## 2. 跨边重复的四分之三秩支付

设 p_β 是实际提供商标签 β 的边数，C_dup=Σβ(p_β−1)。出现位置上定义行关系空间 K_row（每边标签的二元和为零）与列偶权空间 K_col；后者维数 C_dup。以 h_rel=dim(K_row∩K_col) 计，由第 82 轮的出现位置论证，

```
J ≥ C_dup−h_rel.
```

此处可直接付 h_rel≤C_dup/4。只有四点边有非零行关系，而且它的唯一关系触及四点。将四点行的「标签入射向量」在全标签坐标上列成二元集合，h_rel 恰为此向量族的关系维数。先枚举一组入射向量基，再处理剩余的 h_rel 个四点行。每个剩余行的四个标签都已在基行出现，因为其入射向量是基行的和。按此顺序每个剩余行各产生四次重复出现，因此 C_dup≥4h_rel。于是

```
C_dup ≤ (4/3)J.
```

这一步允许不同边之间有任意多且重叠的标签识别。也可直接证明 C_dup≤4J/3：排列各边，记 T_i=A_i∩⋃_{j<i}A_j。每个子集 T_i 满足 |T_i|≤4·rank(T_i)/3（四点平面的所有真子集都独立），而 rank(T_i) 不超过 span A_i 与前面各边张成空间之和的交维。逐边相加即得。

## 3. 无纯地址方程时的精细频数损失

此时 M=2N，所有边完整。先考虑不同边的实际 A_i 尚未合并。未作任何端点识别前每边消耗 4N。d_i=0 不损失，d_i=1 且两个端点选不同标签也不损失，只把成本变为两个宽 2N 的单点带。其余情形留下一个宽 N 的带，损失 3N，此时 ℓ_i=2。

一个有 p≥2 条边共同提供的商标签，在合并前每个提供者的宽度为 N，若该提供者只在单端点活跃则为 2N。记后一类提供者数为 k。合并后至多在 2p 个物理地址上活动，至少有 N/p 个频率。因此此列的跨边合并损失最多

```
N(p−1/p)+Nk ≤ (3/2)N(p−1)+Nk.
```

单端点活跃只能来自 d_i=1 且两个端点选不同标签的边，每边至多贡献两次 Nk 的项，此时 ℓ_i=1。于是「边内损失加单端点附加费」至多 2NΣ_iℓ_i。「跨边重复的其余损失」至多 (3/2)NC_dup≤2NJ。故

```
s' ≥ 4N²−2NL,     D'≤D−L,     1≤h≤L≤2h .
```

在所论 h≤h₀ 的范围内，2N(2D−L)>D² 对充分大的 n 一致成立（除以 N² 后左侧趋近 12，右侧趋近 9）。这正是 (D−L)²/(4N²−2NL)<D²/(4N²) 的化简，故严格降势。单条查询只识别一边内部时也包含在这里。

实际无纯地址查询的阈值比对数更大。由 L≤2h，凡 `h < D−D²/(4N) = (3/4−o(1))N` 均严格降势。反向不含纯地址的 3N−1 个方程已能实现任意地址布尔函数：令所有守卫位相同，固定每个 x_i=1，把 z_i 指定为地址的仿射形式，并使它的两个端点值等于所需的相位比特。两个不同物理端点上的任意二元值均能如此赋出。得到一个公共守卫字符乘任意指定 G(y)，取两位 bent G 即有 P=2。所有方程的数据投影线性独立，故查询空间确无纯地址方向。所以只允许无纯地址方程时，首次不降势的深度为 Θ(N)，而不加此限制则为 (1/2+o(1))n。

## 4. 含纯地址方程时

原始纯限制的频点数 s₀=4M(f/2+t)。余下混合方程的边内损失至多 (3/2)MΣℓ_i：跨边单点若由四个标签降为一标签，最多损失 3M 且 ℓ_i=2；完整边的损失更小。每个 p≥2 的跨边合并，其合并前总宽度至多 pM≤2M(p−1)，因此跨边损失至多 2MC_dup≤(8/3)MJ。使用 L≤2w 得

```
s'≥4M(f/2+t)−(16/3)Mw,   D'≤3B+n+1.
```

因 M=2f+t，有 M(f/2+t)−B²=ft/2。故

```
s'/4−[B+(n+1)/3]²
 ≥ ft/2−(4/3)Mw−(2/3)(n+1)B−(n+1)²/9 >0 .
```

最后一步由 f,t≥64n、max(f,t)≥M/3、B≤M、w≤n、M≥192n 得到。因此 P'<3/2<P。对同一查询空间的所有答案成立。

## 5. 上界及核对范围

与第 82 轮相同，随机取大小 M=2^⌊n/2⌋ 的仿射地址平坦。其内部完整边数的期望为 M(M−1)/(2(2^n−1))<1，故存在无内部完整边的单元。它的每个地址选不同的原私有 bent 种子，于是 s'=4M²，D'=3M+⌊n/2⌋+1，P' 对充分大 n 严格超过父值。这里全部混合下界和纯地址上界针对同一真实族。

谱线性秩与齐次秩相等的判断基于守卫奇偶性，在所有实际限制中该奇偶性也由商投影保留。允许函数前后添加虚变量或作字符调制：对任意查询只需在其与内在频率差空间的交上保留有效限制，其余方向可由虚变量回答，且字符调制不改变 P。

**无纯地址频数常数可取等。** 若匹配中有两条平行边，则其四个地址组成仿射平坦。查询这两条边上的三个私有位分别相等（含守卫位），无需查询地址。两边的四个原数据标签逐对识别，且每条合并后的列是在四点平坦上的等号等模指标，实际宽度恰 N/2。总频点损失 6N，L=J=3，取得 2NL。可将这样一对边放在包含其他方向的匹配里。另在单一边内查询一个数据位，若地址斜率在该边两端恒定，就少两秩而节省 3N；若斜率在端点不同，则只少一秩且频点数不变。具体四边实例一并做了整数核验。

## 6. 整数验证及有限十二位证书

本机 Python 3.15.0 运行 `python3 verify_bent_depth.py`，成功退出。对三个地址位的一组明确匹配，直接构造物理行系数、取整数 Walsh 变换并二元消元。穷举 32,752 个无纯地址的一位查询与答案，再核验固定种子的 2,500 个混合查询，分别遍历纯地址部分秩 0、1、2。

另独立复现第 82 轮种子 821012 的同一十二位匹配（SHA-256 为 52e046260d6c4ef276ab3db96b8cf982615dc96f17d02885e3ff4768de736f27）。接入上述种子后，父 (D,s)=(6157,16777216)。对所有一至二维有效查询，按纯地址部分的维数分类核验。纯地址秩零用 §3；纯地址秩一及二的最小整数比较缺额分别为 116146345934848 及 15077373106176。后二者以正量 D²·(3s_下界)−3s·D_上界² 计，纯地址秩二覆盖全部 11,176,620 个仿射单元。

取低四个地址位等于一的答案，即 f=3、t=250、M=256 的纯地址单元，得到 (D',s')=(768,257536) 并严格提高 P。因此该有限例的首次非降深度在三与四之间。一般无穷族的深度首项由解析论证保证。完整实际输出见 `bent-depth.txt`。

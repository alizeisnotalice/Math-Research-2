# 四变量常值叶奇偶决策树的最小内部节点数

在每个非空仿射子域 \(A\) 上，记 \(T(f|_A)\) 为计算限制函数所需的最少内部节点。若 \(f|_A\) 恒定，代价为零。否则遍历 \(A\) 上的全部非零线性方向（仿射常数只交换两支），取
\[
T(f|_A)=\min_q\bigl(1+T(f|_{A\cap\{q=0\}})+T(f|_{A\cap\{q=1\}})\bigr).
\]
若某个奇偶在当前域上恒定，可将该节点替换为其唯一可达子树。其余所有查询严格降低维数。递推因此既枚举了所有可能的首问，又逐支求到了最优的后续树。

parity_tree_census.py 从零维开始，对维数 \(0,1,2,3,4\) 的全部 \(2,4,16,256,65536\) 张真值表计算该递推。对每个奇偶超平面，取该奇偶的最高非零位为主元，按自由坐标参数化。这确保缓存的较低维真值表坐标与环境限制由仿射映射相连。谱及线性、仿射秩通过整数字符求和与二元消元另外计算。

四变量内部节点最优值从 0 到 6 的计数为 \(2,30,280,2760,21792,25440,15232\)。最大最优值为六，即最优树共有十三个顶点。所有 15,232 个达到该最大值的函数均有全十六点谱，线性及仿射谱秩均为四。

## 一个可独立解析核验的极值例

取负值集合 \(B=\{0,e_1,e_2,e_3,e_4\}\)，真值掩码为 0x0117。任取非零奇偶 \(q\)，设其坐标重量为 \(w\)。两个三维切片的负值点数分别为 \(5-w,w\)，且各自仿射独立。

三维域上，含 \(1,2,3,4\) 个负值点且负点仿射独立的函数，其最少内部节点分别为 \(3,2,3,3\)：

- 单点所在负叶至少需要三个独立查询，逐坐标选择正好用三个。
- 两点构成仿射直线，需且可用两个查询。
- 三点被含于一个仿射二维平坦，先判断是否位于平坦内，再判断平坦内唯一的正点，合计三个。树若至多有两个内部节点，各叶点数为偶数，无法得到奇数个负点。
- 四个仿射独立点不成平面，其补集也不成平面，因此无论首问是什么，两个子域都非常数，至少需三个节点。取一个奇偶将这四点分为两对，每个二维切片的两负点形成直线，只需再作一个查询，达到三个。

故当 \(w=1,4\) 时固定首问最少用七个内部节点，当 \(w=2,3\) 时最少用六个。全部十五种首问都覆盖。该例的负点数为奇数，而四变量任何字符的负点数为偶数，其符号内积不可能为零，故谱全十六点。JSON 保存了由另一套直接在环境仿射点集上递归的实现得到的全部首问代价，并逐点核验了其中一棵最优树。

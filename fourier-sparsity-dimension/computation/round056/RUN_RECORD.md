# 第56轮近字符检测的整数核验

Mac mini 本机 Python 3.15.0，12 个工作进程，主程序用时 0.481 秒。脚本精确核对四变量全部 65,536 张布尔真值表。先按 307 个非空仿射陪集和全部带符号字符独立生成几何目录，再与整数 Walsh 阈值及谱重建程序逐函数交叉验证。

| 范数 | 规范形 | 真值表数 |
| ---: | --- | ---: |
| \(1\) | 带符号字符 | 32 |
| \(2\) | 字符在一个余维二陪集上翻号 | 1,120 |
| \(5/2\) | 字符在一个余维三陪集上翻号 | 3,840 |
| \(11/4\) | 字符在一个余维四陪集上翻号 | 512 |

范数小于 3 的 5,504 张真值表与几何目录完全一致。另有 26,880 张真值表恰达 3，均排除于目录。每个并列最大频率都单独重建，合计 8,864 个候选，并逐点对照原函数。

另构造环境维数 8 至 70 的 14 个谱提升，覆盖载体在方向内及方向外的情形。每个例子逐系数复原，验证线性秩分别等于谱仿射秩与该秩加一。总计 4,212 个联合坐标原子各选一个代表进行真值对照，覆盖这些构造的整体物理定义域。主计算正常退出，标准错误为空。

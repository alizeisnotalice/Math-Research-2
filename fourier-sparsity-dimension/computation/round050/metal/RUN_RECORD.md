# 第50轮四线分割的双机整数 Walsh 核验

沿用第49轮的三位地址分割 `{0,1}, {2,4}, {3,7}, {5,6}`，并使用四位共同数据。每条线配置32个不同的局部布尔符号函数。在线的两个端点选择字符、二位 bent 在独立线性形式上的提升及其调制、平移与符号变化。八种模式包括同一线两个端点的数据谱重叠、数据频率平移和混合字符与 bent。四条线的选择独立，固定库共有 $32^4=1{,}048{,}576$ 个不同的拼接函数。

设 $m_\beta$ 为数据频率 $\beta$ 在至少一个端点非零的线数，$P_\beta=m_\beta/4$。设 $t_\beta$ 为该数据频率的真实地址支撑点数。每个非空频带检查 $s_\beta m_\beta\ge4$ 与更强的 $s_\beta t_\beta\ge8$。若只有一条线活跃，查验 $s_\beta=4r_{i,\beta}$，其中 $r_{i,\beta}$ 是线坐标上的局部频率原像数。全部 Walsh 系数均为未归一整数。

MacBook 处理 `[0,786432)`，Mac mini 处理 `[786432,1048576)`。两机CPU以局部提升逐系数回算，Metal从端点真值库直接生成整条真值表并做128点FWHT。134,217,728个系数完全一致。每个批次另直接按字符求和复核首末真值表，共128例，独立Python重算两机各8个已归档样本的完整谱系数散列与双方频带见证。两机回执记录实际Metal命令时间与进程退出。

| 证据 | 数量 |
|---|---:|
| 非空数据频带 | 12,862,720 |
| 单线私频带 | 7,748,608 |
| 单线私频带中恰有两个局部原像 | 5,629,696 |
| 有重复局部谱项的频带 | 5,114,112 |
| 至少一个系数完全相消的频带 | 2,597,632 |
| 完全相消的频率出现次数 | 8,772,464 |

例如MacBook见证的函数编号码136在 $\beta=1$ 的地址谱为 `[16,32,-16,0,16,32,-16,0]`，12个计重局部贡献覆盖8个地址频率，相消后余6。编号码4的 $\beta=0$ 仅在线0活跃，只占一个物理地址，在两个局部线频率均非零，8个全地址频率均非零。

## 复现

Swift源和两个JSON分片足以进行数学与运行摘要的独立复核。当前目录的精简归档文件由 `SHA256SUMS` 列出。

```sh
python3 -B verify_results.py local macbook /path/to/reverified.json
```

重跑时，使用对应机器既有的 Swift 模块缓存。用以下参数分别启动两个已编译的Metal程序。

```sh
./r50_four_line_metal macbook-result.json 0 786432 16384
./r50_four_line_metal mini-result.json 786432 262144 16384
```

需要附实际退出与时间证据时，可分别使用 `run_shard.py` 启动两个分片。待两个输出目录均出现 `ready.json`，分别将同一个未来UTC Unix秒数写入各目录的 `start_epoch.txt`。

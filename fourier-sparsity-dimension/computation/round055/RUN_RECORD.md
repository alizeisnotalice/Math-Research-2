# 第55轮方向谱质量的有限核验

本机 Python 3.15.0，12 个工作进程。完整遍历 \(n=2,3,4\) 的所有布尔真值表和全部维数 \(2\le r\le n\) 的物理方向子空间，共 3,344,400 个函数–子空间对。真实非零标签张满方向对偶的有 3,291,208 对，其中 321,344 对缺至少一个非零标签。

对所有张满实例，精确检查 \(A\ge2-2^{1-r}\) 和非端点间隙至少 \(5/32\)。86,168 个取等案例全部从真实 Walsh 谱重建共同方向 \(K\)、缺失的单个零标签陪集和补成后的仿射平坦。非零带的系数同幅，并有共同仿射符号字符。物理的活跃方向陪集各有唯一少数符号，活跃陪集集合、主符号和少数位置亦按相应仿射条件核验。取等案例中有 67,792 个整体谱不平坦。

以 \(a\) 表示共同的非零带系数绝对值。用共同符号字符的物理点作相位，零带目标陪集上的系数平均绝对值全部等于 \((2^{r-1}-1)a\)。逐项取绝对值再平均在 37,024 个取等案例中给出不同数值。

| 环境维数 \(n\) | 方向维数 \(r\) | 实测最小正间隙 |
| ---: | ---: | ---: |
| 2 | 2 | 无非端点 |
| 3 | 2 | \(1/2\) |
| 3 | 3 | \(1/4\) |
| 4 | 2 | \(1/2\) |
| 4 | 3 | \(1/4\) |
| 4 | 4 | \(5/8\) |

\(r=2,3,4\) 各构造了一个 \(n=r+3\)、\(|K|=4\) 的非平坦整体谱取等例。三位例 \(\chi_z(-1)^{xy}\) 的非零标签张满但未全部出现，\(A=2\)，比下界大 \(1/4\)。单字符在方向对偶上的有效秩仅为一，给出未张满时 \(A=1\) 的对照。

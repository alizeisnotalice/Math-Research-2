# 第63轮核心平坦压缩的精确核验

对谱内一个完整仿射平坦取最小点为载体，并调制至线性核心 \(C\)。记 \(M=|C|\)，尾部为 \(S\setminus C\)，共有 \(q\) 个谱点。把尾部投影到商空间，按频率字典序贪心选商基，记其秩为 \(r\)。每个被选频带 \(\gamma\) 取最小频率为代表。对该代表与同带其余频率的非零差，跨带去重得 \(D\)，保留跨带重复计数得 \(B=\sum_\gamma(m_\gamma-1)\)。

对每个核 \(W\le C\)，令 \(L=M/|W|\)，对每个不同仿射限制 \(x+W^\perp\) 用真实布尔符号作整数 Walsh 变换。另从原整数谱逐频率桶带符号相加，比较两种结果的每个系数。如此直接得到保留的外部秩 \(r'\) 和整个限制的实际稀疏度。调制前后在各商中作相应载体平移。

## 实测穷尽

Apple Clang 21.0.0、arm64、12 工作线程。对 \(n=1,2,3,4\) 的 65,812 张真值表、每个谱内完整仿射核心、每个核心下的全部核及每个核的全部仿射限制作精确核验。四变量一行包括 12,532,160 个核心、56,733,824 个核和 138,109,184 个仿射限制。原谱折叠与直接物理 Walsh 系数按不重复的原始真值表及核、平移计，共交叉核验 70,254,592 项。四变量实测用时 1.06 秒。最高奇层单列统计。四变量的 26,880 张非空尾部真值表都给出 \((M,q,r,|D|)=(8,2,1,1)\)，均有非平凡无损压缩，也均可选平移在 \(L=1\) 保持外部秩一。

所有测试均满足下列性质。

- 实际稀疏度至多 \(q+L\)。核避开 \(D\) 时，所有仿射平移均完全保留外部秩。令 \(h=\lfloor\log_2(|D|+1)\rfloor\)，总有 \(L=2^h\) 的无碰撞核。其解析原因是，包含意义下极大的避开核的每个非平凡商陪集都必须含有一个 \(D\) 的元素，因此该极大核的余维至多 \(h\)。若需要余维恰为 \(h\)，可再取其一个子空间。
- 给定 \(L\)，在相应维数的核和平移上均匀平均。记 \(\lambda=(M/L-1)/(M-1)\)（\(M=1\) 时压缩平凡），则实测仍满足更强的 \(\mathbb E(r-r')\le\lambda B/2\) 及 \(\mathbb E r'\ge r^2/(r+\lambda B)\)。当 \(r=0\) 时第二式按零解释。
- 强化式可用代表频率桶的不确定性解释。固定核 \(W\)，若基带代表与同带 \(c_\gamma\) 个其他原谱点在一个桶中相撞，则该桶的 Walsh 和随 \(W^*\) 平移至少以 \(1/(1+c_\gamma)\) 的概率非零。这来自 Cauchy–Schwarz 和 Parseval 的支撑不确定性。每个被保留的基标签独立，故损失概率最多 \(c_\gamma/(1+c_\gamma)\le c_\gamma/2\)。每个非零差落入均匀核的概率恰为 \(\lambda\)。对保留概率再用 Jensen 即得第二式。

## 严格边界

四变量一般子核心有 322,560 个 \((F,C)\) 在 \(L=1\) 选择任何平移仍不能完全保留外部秩。最小真值掩码为 23（负点 \(0,1,2,4\)），可取核心 \(\{1,9\}\)，外部秩为三，两种全压缩平移分别保留一维和二维。四变量另有 195,840 个 \((F,C,L)\) 违反用去重后 \(|D|/L\) 代替重数预算的均损上界。

Python 3.15.0 独立直接核验了上述首例，以及以下最高奇层的两个边界。

- 两位选择 \(s\in\mathbb F_2^2\)，在 \(s=0\) 放二位单点翻转，在 \(s=1,2\) 分别放独立数据字符 \(\chi_{z_1},\chi_{z_2}\)，在 \(s=3\) 放常数。最高奇层是 16 点核心，尾部 \(q=8,r=2\)。全部 16 个 \(L=1\) 平移的保留秩直方图为 \(0:8,1:8\)。在 \(L=2\) 时已有一个真实限制以稀疏度四保留外部秩二。
- 一位选择 \(t\)，在 \(t=0\) 放三位单点翻转，在 \(t=1\) 放 \((-1)^{v+z_1z_2}\)。最高奇层仍为 16 点核心，尾部 \(q=8,r=3\)。三个代表带的差均是选择位对应的同一非零法向，故 \(|D|=1,B=3\)。在 \(L=1,2,4\) 时平均损失分别为 \(3/2,7/10,3/10\)，都超过 \(|D|/L\)。

# 第59轮小实例独立核验

设非空不同仿射域 (A_i) 以严格正权满足恒覆盖。(m) 为域数，(a(u)) 为地址 (u) 上的活跃域数，(t) 为所有域法向的二元总秩，(r) 为中心指标 (1_{A_i}-mu(A_i)) 的实秩。三套计算在 Mac mini 上用 Python 3.15.0 和整数算术实际运行，没有使用随机采样。记录中的枚举进程均已退出。

## 任意正实权，地址维至多四

- 第一式 (tle m-max a(u))。把活跃最多的地址平移到 (0)。恒覆盖的每个非零 Fourier 系数为零，且所有经过 (0) 的域对出现的频率均给正符号。于是每个出现的非零法向频率必须也在某个遗漏域上给负符号，所有遗漏域的法向频率并集等于相应负符号部分的并集，且该并集张成全部法向。地址维为 (n) 时，只需枚举遗漏域个数 (1le k<n) 的候选；(k=0) 时所有法向均为零，(kge n) 时结论直接成立。四维有 240 个不经过原点的仿射域，满足符号必要条件的 ((k,t)) 计数为 ((1,1):15, (2,2):315, (3,2):595, (3,3):11760)。维数一至四均无 (t>k) 的候选。
- 第二式 (tle r)。当 (rle2) 时，从原指标中取 (r) 个，其值区分所有活动模式。若有完整二进制方形（或一维的两个模式），每个非恒定指标是坐标或坐标的补。正恒覆盖强制每个出现的非恒定坐标的补也出现，相应两域互补并都是仿射超平面，故 (tle r)。若二维实活动模式空间恰有三个模式，写三个模式原子为 (C_j)，则每个非恒定指标指示某个 (C_j) 或其补。分别记两类权为 (a_j,b_j)（缺失用零），恒覆盖等价于 (a_j-b_j=delta) 为常数。若 (delta>0)，三个原子构成仿射分割，R58 三域法向秩至多二，补域和原子共享平移周期。若 (delta<0)，三个补均为真仿射域，但总相对大小为二而每个至多二分之一。若 (delta=0)，出现的原子与补各为仿射超平面，没有三个互斥的半域。当 (nle4)，剩余唯一可能的反例为 (t=4, r=3)。
- 三个原中心指标的基决定覆盖中全部指标的共同平移周期，因为其余指标是它们与常数的实线性组合。对第一基域作仿射规范化后，穷尽 185,440 个三元组，其中 172,961 个的法向秩为四且中心实秩为三。对每个三元组枚举所有在观察模式上取 0/1 的仿射实函数，并检查拉回的支持是否确为仿射平坦。验证正依赖时，使用四个仿射独立模式相对首模式的差值作为实三维坐标。非恒定指示的每列是二进制列或其负数。最小正依赖至多四列，按子式得到的原始整数系数都在 ({1,2})（二阶二进制子式至多一，三阶至多二）。每个非负依赖可依次减去最小正依赖直至零，因此正依赖可以同时包含全部三个指定基域，当且仅当三个域分别被某个可用正依赖支持覆盖。没有三元组通过此判据。

## 整数权覆盖全普查

另从几何目录直接递归穷尽全部归一前整数权覆盖。四点、整数总权八得到 703 个不同支持。八点、整数总权二得到 369,158 个不同支持。两式均通过且可取等。用 Walsh 坐标写中心指标并逐行除域质量，所得矩阵至多有七列且项为 (-1,0,1)，故整数子式绝对值至多 (7^{7/2}<65521)，模素数 65521 消元给出精确实秩。两个等号可在任意维同时达到，取每个坐标的两个互补超平面，并给所有域同一权 (1/n)，则 (m=2n)，每点活跃 (n) 个域，两个秩均为 (n)。

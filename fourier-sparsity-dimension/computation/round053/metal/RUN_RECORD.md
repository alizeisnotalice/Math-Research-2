# 第53轮平坦谱最小方向与真实相位轨道

使用第11轮20个64点平坦谱。最小输入保留逐谱点的索引、系数符号和频域平移周期维数，绑定第11轮原始结果的SHA-256。每个谱点的最低位恒为1。把该固定谱坐标去掉得到14位物理函数；旧15位输入的最低位成为独立相位 $c$。编码 $d=2a+c$ 的非零谱翻号集合为 $\{\xi:\langle a,\xi\rangle+c=1\}$。

20个行证书各完整枚举32,768个相位方向（含零）。每行最少非零重量为8，恰24个最小方向。全部480个最小方向在谱坐标与原始六位标签空间中给出仿射3平坦，真实物理差分 $F(x)-(-1)^cF(x+a)$ 的非零域恰为2048点仿射11平坦。384个最小方向相位为0，96个相位为1。错用相反相位会取到互补的14336点活动域。

每个由最小字生成、维数为 $r=2,3$ 的子码只计一次。对每个实际物理轨道按相位修正真值，Metal输出全部精确真值模式的直方图。设该子码谱翻号并集大小为 $L$，轨道上修正真值的平均为 $m(x)$，则未取平均的谱部分给出 $\mathbb E(1-m(x)^2)=L/64$。每个非零同轨道方向的实际导数密度也独立与该方向重量除以64比对。共207,200项导数身份和各子码轨道平均身份通过。

独立Python还直接在物理真值上求所有最小方向对及独立三元组的共同活动点数。5,520对中960对各有1024点共同活动，其余为零；40,160个独立三元组的共同活动都为空。这些有限结果覆盖全部20条种子。表中支撑下界和三元共同活动的统计限于此归档实例。

MacBook M5 Pro承担前15行，Mac mini M6承担后5行，两机以同一UTC时刻启动，进程重叠1.092秒。两台设备共逐值复核327,680个由谱逆变换生成的Boolean真值，Metal遍历80,117,760条一至三维物理轨道、537,395,200个相位修正真值，853个子码的轨道直方图独立以CPU逐项复核。Python另重算两机各6份完整物理轨道见证。两个正式进程均正常退出。

## 复现

```sh
python3 -B verify_results.py local macbook /path/to/reverified.json
```

在对应机器用该机已有 Swift 模块缓存编译时，Swift程序接受输入文件、输出文件、首行与末行参数。

```sh
./r53_flat_orbit_metal r11_minimal_input.json macbook-result.json 0 15
./r53_flat_orbit_metal r11_minimal_input.json mini-result.json 15 20
```

`run_shard.py` 可同时生成退出与命令时序回执。待两个输出目录均写出 `ready.json`，给两目录的 `start_epoch.txt` 写入同一个未来UTC Unix秒数即可安排同步启动。精简归档文件以 `SHA256SUMS` 为准。

# 第29轮：一般仿射全-bent空间的文献范围审计

日期：2026-11-17。对象是 f+V 全 bent，不是 V 的每个非零元素 bent。检索结果仅代表此次实际可核读来源，不能证明不存在其他结果，也不能确认一般最大维数。

- Carlet，*Boolean Functions for Cryptography and Coding Theory*（2021），命题75，页227–228，[作者版](https://www.math.univ-paris13.fr/~carlet/book-fcts-Bool-vect-crypt-codes.pdf)：独立检索 Agent 核读其全-bent陪集与增变量 bent 构造的等价刻画，命题没有给任意陪集维数上界。紧随其后的说明区分了 vectorial-bent 的维数限制。1991原论文只核题录，本轮未获取全文。
- Meidl，*Generalized bent functions with large dimension*，AMC 18 (2024),1514–1530，[官方页面](https://www.aimsciences.org/article/doi/10.3934/amc.2023004)：主 Agent 实际复核官方摘要。其维数 q 上界对应一个分割的全部块常数方向空间；不能套到任意共同方向 V。全文未核读。
- Hodžić–Meidl–Pašalić，2016，[arXiv:1605.05713](https://arxiv.org/abs/1605.05713)：gbent对应的仿射空间带额外对偶兼容条件，不能替代一般全-bent陪集。主 Agent 本轮核对摘要范围；独立检索 Agent 依据此前核读的v1页8–13（Corollaries1–2及Theorem2）确认附加条件。已有PDF SHA256：b11fc5726a6e565b9de48ce23dd48c89b698176bf4c9926b729aadb1f468787e。

此次针对 affine spaces of bent functions、maximum dimension、2^(k+1)−1 的有界一手检索，未找到可核读的普适 dimV≤2q−1 定理，也未找到超过2q−1的构造。不得将这句话改写为“已知一般最优值为2q−1”或“文献已证明没有更大构造”。本轮第29轮数学预算来自项目内证明，不依赖搜索阴性结果。

# 第227轮　定宽体有限点逼近的锐首项与面积转移

设 \(E_N\) 是全体平面定宽一体用至多 \(N\) 个自身支撑点作内接凸包时的最坏最优 Hausdorff 误差。本轮确定两个不同量词的精确首项
\[
 \lim N^2 E_N=3\pi^2/8,\qquad
 \lim N^2 e_N(K)=\frac18\left(\int_0^{2\pi}\sqrt{\rho(t)}\,dt\right)^2 .
\]
后一式中 \(K\) 固定且 \(\rho=h+h''\) 为其可测曲率密度，所有固定输入的首项至多 \(\pi^2/4\)，仅圆盘取到。一致下界由随 \(N\) 变化的正 Reuleaux 奇边形给出。每顶点有一个开帽，这些帽两两不交，允许任意自适应选点也必漏掉一个。匹配的统一上界将法向角长加上边界弧长等分，对每个角格精确积分正弦核。[解析证明](../proofs/adaptive-inner-cover.md) · [有限阶有向核验](../computation/adaptive-inner-cover/inner-approximation.json)

记 \(\Lambda_N\) 为可容纳所有至多 \(N\) 个点的直径一输入的凸宿主面积下确界。令 \(U_N\) 为上述有限阶上界，\(r_N=\frac12\cos(\pi/N)\)，则
\[
 \frac{\Lambda-\pi U_N^2}{1+2U_N/r_N}\le\Lambda_N\le\Lambda .
\]
把第221轮的精确下端代入，得 **\(\Lambda_{2920}>.83745000007868357389\)**。还可从第221轮六组输入的定宽补全及一个正多边形，取得七组、每组至多2,920点的存在性证书。所得点组未逐点算为有理坐标。三个旧 B 档候选的面积代入转移上式，需要分别验证覆盖所有至多 8,766、8,167、9,988 点的输入，才足以按这一估计达到 B 档。[整数量化与面积预算](../computation/adaptive-inner-cover/size-budget.json)

对小点数，用共心的半径 \(1/2\) 圆盘与边长一正三角形的凸包，可显式容纳所有四点输入，故 \(\Lambda_4\le\pi/8+\sqrt3/4\)。任意多组四点输入加进五曲体模型，也不能提高第158轮的极小值。[四点通用放置](224.md) · [小点数面积推导](../proofs/adaptive-inner-cover.md)

本机以 Python 3.13.18 和 python-flint 0.9.0 的256位 Arb 核验相邻点数、开帽恒等式及有向面积上下端。从课题目录运行下列两条命令，最后一个参数取可写目录中的输出文件。

~~~sh
python -I -B computation/adaptive-inner-cover/verify_inner_approximation.py inner-replay.json
python -I -B computation/adaptive-inner-cover/size_budget.py computation budget-replay.json
~~~

一般最小面积沿用第221、225轮严格界，统一近似误差的锐首项并不确定 \(\Lambda-\Lambda_N\) 的精确首项。

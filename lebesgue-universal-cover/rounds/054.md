# 第54轮　一般凸万能覆盖的三方向宽度条件

设 Q 是平面凸万能覆盖，取任意三条互成 60° 的无向法线。若 Q 在三方向的宽度都不超过 1+δ，则

    |Q| ≥ M_hex /(1+90δ)²,

其中 M_hex 是第53轮的七体受限最小值。特别地，面积至多 0.83674 的任何凸万能覆盖，在每组三方向中至少有一个宽度严格超过 1.000009。若三宽均至多 1.000001，则面积严格大于 0.8379481。结论给出宽度与面积间的必要关系；一般的最小面积还需控制三方向宽度。

**从宽度得到近似支撑等式。** 平移 Q 使其内一个半径 1/2 的圆盘居中，旋转坐标使三个交替法向 u_j 的角为 2πj/3。因此在每个正负法向上 Q 的支撑不大于 1/2+δ。任一已放入的定宽测试体有平移 t、转角 φ，令 h_j(φ)=h(2πj/3−φ)，则 e_j=t·u_j+h_j(φ)−1/2 满足 |e_j|≤δ（下界由对向支撑给出）。故 |F(φ)|≤3δ，其中 F=Σ(h_j−1/2)。

**转角残差。** 记 d 为到最近精确根 φ₀ 的角距离。对正定宽体，按第53轮分支，|F|=A(cos(x−d)−cos x)，0≤d≤x。对 3|n 者取 x=a、A=3R；对 n=5,7 取 x=a/3、A=R(2cos(2a/3)−1)。此函数在 [0,x] 凹，故 |F|≥μd，μ=A(1−cos x)/x。支撑的全局 Lipschitz 常数可取 L=R sin a。光滑体对应的 |F|=3|c_k|sin(kd)，其中 d≤π/(2k)，故 μ=6k|c_k|/π，L=5|c₅|+k|c_k|。由此 d≤3δ/μ。

**平移与包含。** 令 t₀ 为精确根对应的唯一平移。则 |(t−t₀)·u_j|≤δ+Ld。由紧框架恒等式，|t−t₀|≤(4/3)(δ+Ld)：在单位立方上，向量和 Σv_j u_j 的最大模在顶点达到，各顶点的模为零或二。再计入旋转本身的支撑差 Ld，得真实副本与精确副本的 Hausdorff 距离至多 (4/3+7L/μ)δ。主工作区以 128 位 Arb 对六个非圆测试体逐一核对系数小于 45。

把 Q 中的各副本换成对应精确副本，新凸包含在 Q+45δB 中，同时是第53轮某个六边形中的可行配置。因 Q 含原点半径 1/2 的圆盘，Q+45δB⊂(1+90δ)Q。取面积并代入第53轮有理下端即得结论。复现命令是 computation 目录中的 python -B certify_hex_width_stability.py，系数和精确分数见 054-width-stability.json。

# 第216轮 · 定宽体的尖锐接触误差与多个相容角的全姿态反例

在半圆等分 \(n\) 格，只记录每个格端点的真实接触点。对任意定宽一体，固定平面坐标下的最优重建误差被精确确定为

\[
\frac{\sqrt{4-\sin^2(\pi/(2n))}-1-\cos(\pi/(2n))}{2}.
\]

给定两端接触后，一段连续的满曲率圆弧同时最小化扇内每个方向的支撑，而一段连续的零曲率区间同时最大化它。两极端体在同一坐标中的平均达到所示误差。两个真实闭定宽体具有相同的全部网格接触，且在一格中心的支撑差达到该数的两倍，给出相反方向的下界。由此得到两种全局面积估计。若 \(c_n\) 是覆盖文中测试全族及半单位圆盘所需的面积，则 \(c_n\le\Lambda\le(1+4s_n)c_n+\pi s_n^2\)，其中 \(s_n\) 有明确闭式并为 \(O(n^{-2})\)。[尖锐扇估计](../proofs/sharp-support-compression.md) · [最优重建和一般面积近似](../proofs/contact-data-minimax.md)

对位于宽一正六边形内的任意凸宿主，如果一个遗漏输入在基本六十度扇内有 \(r\) 个不同相容角，可以找到一个同样遗漏的至多 \(33r\) 弧定宽体，保留全部根、每根所需的平移以及十二个姿态的越界见证。若零集含有区间或无穷多个根，有限个有严格见证的角度邻域仍足以构造同一宿主的有限弧反例。一般宿主所需的弧数上限会依赖输入的严格余量。五组可复算的多根例分别有 3、7、11、21、31 个相容角。[全局根与有限弧见证](../proofs/multiroot-exact-witness.md)

在第214轮的实际 AH 裁线和两原斜帽上，一个显式五弧体排除了整段配对切线 \(.4157\le w\le .4420\)。六个解析角格给出全角度的根隔离，十二个姿态的最后一个由同一真角点在 530 个闭参数格上严格越线。原来相邻的两段未决区间缩为 \((.4145,.4157)\) 与 \((.4420,.4442)\)。[五个开关的闭式与剩余区间](../proofs/five-arc-tangent-band.md)

主工作区使用 Python 3.13.18、python-flint 0.9.0 和 SymPy 1.14.0 重算扇内矩恒等式、十五弧极端化、五弧整段反例和五个多根构造。与独立工位 Python 3.12.14 的四份结果相比，只有解释器版本字段不同。另以 192 位区间算术核对两种重建族的 B 档面积预算。复算时 \(D\) 表示一个可写的临时目录。

```sh
C=computation
S=$C/finite-arc-reduction
python -B "$S/sharp_error_check.py" "$D/sharp-error.json"
python -B "$S/purify_r214.py" "$C" "$D/purified.json"
python -B "$S/certify_five_arc_band.py" "$C" "$D/five-arc-band.json"
python -B "$S/certify_multiroot_extrema.py" "$D/multiroot-extrema.json"
python -B "$S/area_budget.py" "$C/finite-b-core/host-area.json" "$D/area-budget.json"
```

一般问题的精确面积以及 B 档对全体输入的共同摆放仍开放。

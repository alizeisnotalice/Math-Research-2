# 第40轮　三体全局下界 0.83475

对直径一圆盘、定宽三角形、定宽五边形的所有相对平移和转角，最小凸覆盖面积至少为 3339/4000。根盒外由第35轮的两体排除和旋转归一化处理。盒内沿用第39轮核对过的上游树作为划分起点，使用新面积门槛重新验证所有正体积交盒。四个平移量的角点界共享重心权重，因而可对两个不同内扇使用同一有理权重，得到比单个扇更高的统一下界。证明与输入哈希见 proofs/040-three-body-refinement.md。

复现时在 computation 目录执行下列命令，SRC 为第39轮冻结上游目录，Python 环境同第39轮。
```sh
python -B certify_three_body_refinement.py "$SRC" --workers 6 --threshold 0.83475 --max-extra 15 --output 040-refinement.json
python -B close_three_body_residual.py "$SRC" 040-refinement.json > 040-closure.json
python -B check_three_body_fan_dual.py "$SRC" > 040-dual-example.json
python -B verify_three_body_ledger.py
```

完整计算须依次通过两阶段。第一阶段留下的盒逐个进入第二阶段；最后一步核对两阶段数据的对应关系和二叉树计数。此界适用于一般 Λ；用更多测试体得到的来源下界更高，三体本身的精确最优面积仍待确定。

同轮给出该三体最优面积的可行上端。三角形平移 (−0.012154563566,0)，五边形角度为零、平移 (0.022997996669,0)。将每条单位圆弧细分16384份，用112位 Arb 检验取整材料点的坐标误差；加入整段弧相对弦的最大弓高后，以 Steiner 公式给出整个凸包的有理面积上界。脚本同时由固定盘的内半径和取整误差得到这个指定放置的面积下界。完整上端严格小于0.834780947305。因此三体最优值所在区间的宽度小于0.000030947305。复现命令为 python -B certify_three_body_outer.py 040-three-body-placement.json --K 16384，输出见 040-three-body-outer.json。这个可行上端只约束三体最优值。

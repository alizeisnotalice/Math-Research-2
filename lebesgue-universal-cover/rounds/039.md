# 第39轮　五维三体下界的两次完整重放

对直径一圆盘、定宽三角形和定宽五边形的共同覆盖问题，使用 Tomar 的五维证书，本轮得到 m(D,B3,B5)≥0.834700003。因此 Λ≥0.834700003。此界弱于 Tomar 用更多测试体报告的一般下界 0.8366。本轮实算覆盖的是三体的全部放置。

上游固定于 [10af986](https://github.com/tejasvi/lebesgue-cover-bound/tree/10af98606c98ca9ffd0d9f402cae1e2efe74b792)，使用 certificates/cert5d_08347.tar.xz。主工作区以 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 重放。第一遍核对归档和32个内部文件的 SHA-256，按冻结源码重建1024个根格下的分割树，再对全部16分片、27388个叶运行80位 Arb 验证。所有分片通过。面积阈值为原十进制值 0.8347。

第二遍将每个分片元数据中的十进制阈值换为 0.834700003。使用临时目录保留原始证书，分割坐标、节点顺序和所有见证数据不变。未改动的 lbcheck.py 对每个分片重新检查根盒外约束和角度覆盖，并重新比较每个叶的面积下界。该程序以 arb(repr(float(tau))) 读取阈值，包装程序检查其十进制表示精确为指定字符串。树结构沿用第一遍的精确验证。第二遍全部16分片通过，失败叶为零。上述结论采用上游几何判据与此处两次全量计算；没有重建 Lean 工程。

逻辑上，固定圆盘中心与三角形方向后，剩两组平移和五边形旋转。反射、旋转周期处理角度规范，根盒外平移用圆盘加远顶点的面积下界处理。根盒内的整棵树将配置分给终端叶，每个叶用远点或内部有向三角扇给出严格不等式。故每一种配置都满足下界，取下确界得到上述结论。

在装有上述依赖的 Python 中，从 computation 目录运行以下命令。SRC 指向固定上游仓库，CERT 指向解压的五维证书，SCRATCH 为已存在的临时目录。
```sh
python -B replay_tomar_parts.py "$SRC" "$CERT" > 039-tomar-5d-replay.json
python -B recheck_five_dimensional_threshold.py "$SRC" "$CERT" "$SCRATCH" 039-tomar-5d-replay.json > 039-raised-threshold.json
```

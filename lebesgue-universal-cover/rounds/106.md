# 第106轮　复合裁切构造的真实面积

第105轮已证明万能的固定凸体 H 满足

    0.844093473026735324082831248462910839390 < |H|
    |H| < 0.844093473026735324082831248462910839391.

因此一般最小面积 Λ 的上端可收紧至上述右端。左端只适用于 H。与第105轮相比，几何构造及其覆盖证明均沿用，本轮改进来自对整块 AH 帽的积分。

## 证明与复算

[Green 积分推导](../proofs/ah-eh-combined-green-area.md)给出切线交点的 112 次有理二分以及截去弧段的 24 格、14 阶 Taylor 有理余项。主工作区重放此证书，再用 128 格、18 阶余项重新计算原始 Gibbs 面积。两帽分居水平线两侧，故从原始面积分别减去两帽面积时可使用有理区间直接相减。所得区间完全包含于使用第98轮基线得到的较粗区间中。

在 computation 目录执行以下命令。第三条为独立几何数值交叉检查，需 python-flint。

```sh
python -B certify_ah_combined_area.py
python -B certify_gibbs_area_refined.py 1.5497 18 128
python -B check_combined_cap_polygons.py
python -B combined_area_from_caps.py
```

第二条的标准输出保存为 [gibbs-1p5497-refined-18-128.json](../computation/gibbs-1p5497-refined-18-128.json)。最后一条从三个面积回执直接复算文首端点。512 段弦与切线多边形的面积差约为 7.39546 × 10⁻¹⁵，二者之间包含完整的 AH 帽积分区间。

一般下界仍为第85轮的 0.83661。该复合体是否最优仍待证明。

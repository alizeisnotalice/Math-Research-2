# 第75轮　十二点见证的每个定宽补全都可另选摆放

设 X 为第67轮的十二点直径一见证。对每一个含 X 的定宽一凸体，均存在一个由该体决定的旋转和平移，将它放入切深 0.007 的候选体；在切深 0.0000155 和 0.005 时相同方法也适用。

以 X 的十二点为圆心作单位闭圆盘，记交集为 L。定宽性把每个补全的支撑函数夹在 1−h_L(−u) 与 h_L(u) 之间。这些界足以使六边形三组支撑线的平移相容方程在 1.44°、1.47° 的值异号；连续性为每个补全给出一个根。由前两组支撑线求平移后，最后一组也精确相切。对其余内接多边形边，在整个根区间上作区间估计。对 0.007，最小严格余量超过 1.83037×10⁻⁷；若 X 各点距定宽体均不超过 2×10⁻⁸，认证依然有效。

L 恰等于所有这些补全的并。其宽一方向的法锥约束，连同第67轮的障碍，排除了对全部补全共用一个刚体运动进入切深 0.0000155 候选体。逐体选择放置因而是实质条件。一般输入能否全部放入该候选体仍待证明。

主工作区运行 computation/certify_eh_all_completions.py，对每个切深将角区间分成 2048 格，以 160 位 Arb 重算。输入、脚本哈希与余量见 computation/075-completions.json，证明见 proofs/eh-all-witness-completions.md。

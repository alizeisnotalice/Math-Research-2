# 第44轮　Gibbs 构造的有理角改进

平面凸万能覆盖的最小面积满足

    Λ < 0.844093594386489758783.

取 σ₁=1.5494009336°，沿用第33、34轮的五个切区、放置和闭凸余集。将原有角度输入替换为闭区间 [1.549399°,1.549401°]，对每次依赖 σ 的三角运算包住整个区间，在主工作区重算 AH 圆障碍与接触次序、EH 内部、五种放置及整体边界拼接。角度无关的解析等式沿用相应轮次证明。全部几何检查通过；因此可在这个区间中选取精确有理角 σ₁。旧角 σ₀=1.5494° 同时落在该区间内。

面积改用第34轮同一条定向外边界上的 Green 积分。直线段 a→b 对两倍面积贡献 det(a,b)；圆心 c 的逆时针单位短弧贡献 det(c,b−a) 加其圆心角，各弧均核验了点积与行列式为正。唯一的非圆弧从 Z 到 T′，是将线段 Z+w(T−Z)、0≤w≤1 逐点作第20轮的配对。其贡献为 x y′−y x′ 的积分。128 等格的每格对密度在中点展开到七次，奇次项积分为零，用全格上的八阶导数除以 8! 的有理包络乘上非负八次幂积分。坐标运算按分母 10^48 向外舍入，三角函数与反正切的级数截断另计余项。精确面积端点保存在两个 JSON 内。

主工作区独立计算两个角度。在有理算术下，旧角面积下端减新角面积上端严格大于 1.58137×10⁻¹⁷。此数度量两个具体覆盖之间的实际面积改变；上界小数精度另受积分包络控制。本轮未证明 σ₁ 是这族的最优角，整个万能覆盖问题的精确值仍开放。

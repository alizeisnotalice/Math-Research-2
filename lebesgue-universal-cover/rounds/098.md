# 第98轮　由定宽互补条件选择两种摆放

固定 Gibbs 角 1.5497°，把 EH 端点移动 0.00036 弧度，得到 **Λ < 0.844093513590199027**。这个构造使用第90轮同角度的原面积和本轮的新增切除面积。

五段 Sprague 真圆弧均可由强制接触点验证全段支撑。第90轮单一摆放余下的瓶颈是斜截线 m₅：在切深 0.000106 已有一个19点直径一见证，使其任何定宽补全在指定右根姿态越过 m₅。但找到该相容根后，仍可把已经居中的形体 C 整体旋转60°。若第一姿态越过 m₅，第二姿态在 m₃ 方向的支撑值由定宽恒等式严格小于 1/2。故只需分别核验两个姿态各自其余的边，最后按同一体的实际 m₅ 支撑值选择姿态。

相容根在 [30°,33°] 内。右端相容函数小于 −0.000163209。两组摆放合计22条待验边，27个闭角格、51份对偶、6562条自适应切线，最小严格余量超过 0.000000756957。相对未经 EH 改动的同角度基体，切去面积大于 0.0000000807979134887366038。主工作区重算三种切深、五段真弧以及19点见证共五份结果，均与归档逐字节一致；用有理数核对面积上端向上舍入。

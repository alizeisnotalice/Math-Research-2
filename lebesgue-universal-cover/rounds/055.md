# 第55轮　九体族的可行面积上端

第50轮的第九个定宽体排除了第13轮固定八体覆盖。现在同时改变这九个测试体的放置，得到共同凸覆盖面积严格小于 0.83829834。测试族为 D、B₃、B₅、B₇、B₉、P₁₁、P₁₉ 以及第49、50轮的两个光滑定宽体。这个可行上端约束九体最优面积。

数值阶段在原八体放置上先寻找第九体的角度和平移，再允许 23 个参数共同调整。种子、候选坐标和软件版本见 055-nine-placements.json。认证阶段把十进制坐标按精确有理数解释。每条正定宽多边形圆弧作 2048 等分，圆盘及两条光滑边界分别作 8K、8K、16K 等分；两个普通正多边形直接使用所有顶点。用 160 位 Arb 将采样点坐标同分母 10¹² 的整数格点逐一比较。两条光滑边界二阶导范数分别小于 5/2、32/5；它们的弦插值误差和单位圆弧弓高统一由 5(22/7)²/(256K²) 控制。整数鞋带面积、周长向上舍入及 Steiner 公式给出全凸包双侧包络。

主工作区重算的有理端点同时证明三个严格比较。重排后的九体比第13轮固定八体面积小超过 0.0003856820；保持第13轮八体位置且按所选位置加入第九体时，面积增加超过 0.0002460052；在新位置加入所选第九体时，面积增加超过 0.00000520983。这三项比较都针对指定放置。一般凸万能覆盖的面积界沿用第47、48轮。

在 computation 目录执行

```sh
python -B certify_nine.py 013-eight-body-certificate.json 055-nine-placements.json 055-nine-area.json --degree 2048
```

四组精确端点及九体整数凸包顶点见 055-nine-area.json。优化脚本 optimize_nine.py 用于寻找输入；严格面积程序直接消费归档的有理参数。

# 第57轮　Gibbs 构造的三个局部阻挡

取第47轮的有理角。对这个具体凸万能覆盖，证明了以下三件事。

1. 正定宽三角形在原正六边形只有两个不同摆位；其中一个摆位有顶点落在已切除的 C 帽内，另一个必须同时包含三个交替顶点 B₁、D₁、F₁。这三点接触全部六条原支撑线，因此把任一条线平行内移都会失去该三角形。
2. 在其余四个切区保持不动、仅使用第33轮 EH 的放置充分条件时，未触发条件的点集之凸包就是当前余集。端点 U、T 均须保留，凸性因而强制保留整条弦 UT。
3. 在 AH 的反射机制、固定点 Z 及其余切区不动时，取保持凸性、具有一致一阶展开的奇对称分界扰动，要求退出 C 圆的位置可微。以126个有理区间覆盖配对直段后，一阶面积变分非负；分界正支有非零连续一阶变分时，面积一阶严格增加。零一阶变分的高阶变形仍可能需要另作分析。

主工作区用同一 Python 3.13.18 解释器复算全部不等式，所得 057-rigidity.json 与独立工作区逐字节一致。推导及每项的几何前提见 proofs/057-gibbs-local-rigidity.md。复现入口为 computation 目录中的 python -B certify_gibbs_local_rigidity.py。这些结果限定了可行的改进方向，本轮一般上界沿用第47轮。

# 第60轮　圆盘与定宽三角形迫出的四方向精确宽度

对每组相隔 45° 的四个无向方向，任一凸万能覆盖至少有一宽不小于 1+g，其中

    g = (√2+2cos(π/12))cos(π/24) / [√3(2+√2)] − 1/2
      > 0.060985526796930.

这个常数对圆盘 D 和正定宽三角形 B₃ 两个测试体恰为最优，改进了第59轮由光滑三次谐波测试体得到的四方向常数。它没有假设 Q 位于任何多边形内。

**下界。** 把 D 居中，令 B₃ 的第一顶点朝向 φ，平移为 t。写 f(x)=h₃(x)−1/2，u_j 的角为 jπ/4，y_j=t·u_j+f(jπ/4−φ)。两体凸包的宽度为 1+|y_j|。转动坐标、反射和三角形宽一性质给出以下约化：最小化 t 后，max |y_j| 关于 φ 是偶函数，在 φ 加 π/4 时只换位与变号，在 φ 加 π/3 时 f 变号且可把 t 换成 −t。因此它有周期 π/12，只需考虑 0≤φ≤π/24。

因为 u₋₁+u₁=√2u₀，线性组合 √2y₀−y₋₁−y₁ 消去 t。注意 y₋₁=−y₃。对顶点外法锥 |x|≤π/6 有 f(x)=cos(x)/√3−1/2，而 f 是偶函数且平移 π/3 后变号。故整个上述角区间内

    √2y₀−y₋₁−y₁ = [(√2+2cos(π/12))/√3]cos φ − (2+√2)/2.

右侧在区间右端最小。用 (2+√2)max |y_j| 控制左侧，得到 max |y_j|≥g。

**达到。** 取 φ=π/24。未平移时四个偏差依次为 A,−B,−B,A，其中 A=cos(π/24)/√3−1/2、B=cos(π/8)/√3−1/2。沿角度 3π/8 的单位方向平移距离 T=(B−A)/(cos(3π/8)+cos(π/8))（带符号）。四个偏差便成为 m,−m,−m,m。代回刚才的消平移等式即得 m=g。故这一放置的两体凸包达到等号。达到构形只针对两个测试体。

主工作区用 160 位 Arb 向外包住 g 和 T，并独立求值两个有符号偏差。复现命令为 computation 目录的 python -B certify_four_triangle_width.py，输出见 060-triangle-width.json。

# 第46轮　八维面积下界 0.836 的完整复算

对 D、B3、B5、B7 的全部共同放置，凸包面积至少为 209/250。因此任一平面凸万能覆盖的面积也至少为 0.836。此为对 Tomar 八维来源结果的全量复现。结合第44轮，目前本项目完整重放两端所得区间为

    0.836 ≤ Λ < 0.844093594386489758783.

输入固定到 tejasvi/lebesgue-cover-bound 的 10af98606c98ca9ffd0d9f402cae1e2efe74b792。核对 cert8d_0836.tar.xz 的 SHA256 及包内清单，再用冻结版本的 lbcheck.py 分别执行 24 个分片。每个分片先检验根的角度覆盖和根外平移，再按 Arb 判据处理该片的全部终端。以 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 六路运行，墙钟约 625 秒。24 个分片共 808905 个单扇叶，零失败；记录的最小浮点裕量约为 1.62×10⁻⁹，结论使用区间比较的通过状态。

主工作区逐项比对 24 个实际落盘的分片回执，额外独立运行冻结 treecheck.py，复现 65536 个初始格、1552274 个节点、最大深度 50，盒边界、体积和旁文件的错误计数均为零。证明依赖上游判据及其数学推导；十一维来源的完整重算是另一项工作。

在 computation 目录复现。SRC 为上述源码检出；CERT8 为其八维证书解包目录，RECEIPTS 为 data 盘上的临时分片回执目录。

# 第49轮　五体候选附近的光滑定宽障碍

固定第2轮的五体共同放置，记其真实凸包为 C，有理外包为 H。取支撑函数 h(θ)=1/2+cos(3θ)/80−19cos(5θ)/1200。奇谐波给出 h(θ)+h(θ+π)=1，曲率半径 h+h″≥1/50，故它确定一个光滑严格凸的定宽一测试体。h 为偶函数，所以镜像也包含在同一旋转族内。

证书把整圆分为 1024 格，每格取三个有理单位法向及正权重，使三法向的加权和为零、权重之和为一。这样加权支撑差消去任意平移。用整数半角参数求旋转中心方向，按 |h′|≤3/80+5·19/1200 减去覆盖全格的误差。主工作区使用 Fraction 重算全部 1024 格，每格的加权支撑差均严格大于 1/500+1/20000。于是 H 加上半径 1/500 的圆盘仍无法容纳该测试体的任何副本。

每个平移和弧度角坐标改变不超过 1/1250 时，原测试体的点移动不超过 (√2+1/√3)/1250 < 1/500，因为所有测试体相对其中心的外半径不超过 1/√3。凸包的支撑值变化受同一上界控制，故这一十一维邻域的凸包再向外膨胀 1/20000 仍不能容纳该光滑体。

对固定 C 还有显式面积损失。任意加入一副本后，存在单位法向及副本上的点 x，使其支撑坐标超过 C 的支撑值 h_C 至少 1/500。取 C 中圆盘在同方向坐标 2/5 处的弦，半长 3/10。弦与 x 构成的三角形越过 C 支撑线的部分全属新增面积。由相似三角形，其面积为 (3/10)d²/(h_C+d−2/5)，其中 d 是越出距离。此式随 d 递增，且有理外包给出 h_C<581/1000，所以增量严格大于 1/152500。此处固定 C；改变所有原测试体放置后的全域最优值仍待求。

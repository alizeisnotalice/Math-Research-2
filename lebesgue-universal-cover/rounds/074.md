# 第74轮　四体八维全域的多扇下界

圆盘和三个正 Reuleaux 多边形 D、B₃、B₅、B₇ 独立放置时，其共同凸包面积严格大于 0.8364。因此一般凸万能覆盖面积 Λ 也严格大于 0.8364。

每个参数盒内，从可验证的材料点循环导出关于同一组八个放置参数的仿射面积下界。非负组合可以抵消部分平移或转角斜率，所有系数取整均向保守方向补偿。累积面积以 2Q² 为分母，Q=2²⁸。通过盒的有理面积下端至少为 30134485826661463/36028797018963968，严格大于 0.8364。三个根盒外下界均大于 0.85。证明及整数取整细节见 proofs/four-body-global-multifan.md。

输入为第68轮固定上游的八维分割树。本轮只用它的几何分割，重新核验叶内面积。共 65536 个根格，808905 个原叶；第一阶段访问 5942930 次，关闭 802945 个叶；剩余 5960 个在更密材料表上经 132892 次检查全部关闭。材料点由 128 位 Arb 重新生成并验证成员资格。冻结入口为 computation/replay_four_body_multifan.py，以默认深度 23、25 和每盒调用限额 4095 运行。其余依赖和 C++ 实现以相同提交归档。

主工作区使用两个工作进程从头重放，分片逐项与独立工作区核对。发布回执 074-four-body.json 记录输入、源码、材料、实际构建及两级剩余叶的位置绑定。一般上界仍为第67轮结果。

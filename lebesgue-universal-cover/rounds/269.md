# 第269轮　八输入共同缩率、有理点见证与七体全域下界

设 \(G=120696470013529293/2^{57}\)，\(s=999999999/10^9\)。直径至多一的八个固定输入已经给出一般下界
\[
 \Lambda\ \ge\ \frac{G}{s^2}
 =\frac{153473498043733333587646484375}{183251937596162790924585271296}
 >0.83750000167500000390027878 .
\]
每个输入的旋转、反射和平移独立。下界相较第265轮提高约 \(1.6750\cdot10^{-9}\)。八个归一化输入为单位直径盘、正 Reuleaux 三、五、七、九边形及三组有理点。三组点中，原物理十一点先作表列的小位移，其后各点组均除以 \(s\)。这一步改变了固定见证的坐标。[精确分数和复算计数](../computation/scaled-eight-50/result.json) · [八输入证明、代码和点表](../computation/scaled-eight-50/scale.zip)

**缩放前的帽与材料。** 在同一组体心、手性与角度上，将五个曲体同心缩至比例 \(s\)。原五体凸包的每个实际支撑墙至少退入 \(.468(1-s)\)，移动旧十一点的投影损失至多 \(.4464(1-s)\)。这一墙估计在 5,442 枚核心叶使用三角体的中心模界。若联合面积小于 \(G\)，点与内盘的切线三角形使每方向直接帽的有效深度受面积差控制。把半径、墙和点的三项变化代入包内的帽面积公式，256 位 Arb 给出所需额外斜率小于 .021306，低于可用的 .0216。对有共同角或联合面积预算的行，使用同一姿态下的各真实帽。[原八体整域证书](265.md)

原生截弦也用到定义正曲体的辅助盘。写 \(U=2^{22}\)、\(\epsilon=1-s\)。每个定义圆心移动至多 \(3\epsilon/5\)，真实法切坐标比例至少 \((U-1)/U\)；冻结辅助点使用半径比例 \((U-2)/U\)。有理不等式 \((U-1)(s-3\epsilon/5)>U-2\) 保证这些端点仍在缩后的定义盘。原材料扇使用的旧圆盘、正体样点和抛物带按同心内含传递。[材料、径向与全域基准](254.md)

**五体基准的二择。** 旧核有时直接取已认证的原五体面积基准 \(B_0\)。为支付缩小五体的损失，在历史定位剩下的 501 个原叶上另建整树。保留真实材料已经达到 \(B_0\) 的叶，其他叶仅预支严格低于 \(s^2B_0\) 的有理数，并要求高靶由真实点组闭合。主工位重新计算了 26,482,643 个节点，得到 13,019,563 个材料终端与 222,009 个高靶终端。后者由 219,988 个 P128 终端和 2,021 个物理旧十一点终端组成。其余原叶沿用同心内含和径向损失估计；6,704,872 个外围原叶及各核心来源的选取沿用第234、265轮。新增二择消除了直接继承未缩五体基准的循环。[原外围](234.md) · [真实选源与二择重放](../computation/scaled-eight-50/scale.zip)

**八组全部有理的见证。** 对五个曲体使用有向区间控制的有理采点，按组重算整数凸包的精确最远点对；各有理点组的实际直径均小于一。八组点数依次为 60,837、60,834、60,831、60,831、60,822、128、11、11。它们独立摆放的联合凸包面积严格大于 **0.83750000000001744681634159**。按 \(10^{20}\) 分母舍入后的圆弧内含系数已计入这个小数。第七弧体组中有一个列出的点不是极点。全部整数坐标使用可逆四阶差分存储；运行解码器即可得到普通分子、分母点表，解码数据与从零重建的点表 SHA-256 逐字节相符。表末第九组十五点为可选附项。[全部坐标](../computation/scaled-eight-50/points-d4.json.gz) · [坐标解码器](../computation/scaled-eight-50/decode_points.py)

**另一套七输入。** 保持原尺度五曲体，仅取 P66 与原物理十一点，也有联合面积 \(\ge G>.83750\)。第265轮原账中该模型余 182 枚核心原叶；45、17、121 三批真证书补齐，其间重叠一叶。121 枚重算的差根用 P66 重新认证 9,934 条强表行，其中三条分别扣 1、36,117、45,334 个整数格。主工位从 48 个未完成的前缀恢复 604 枚真实子盒，重新计算全部 7,756,750 次附加访问；另重放北部 17 枚、逐号接合全部 5,442 枚。在此七体上重新生成七组共 2,715 个有理点，点数为 789、459、460、462、468、66、11，面积严格大于 .83749001840255078668577459331317405865。七体的曲体下端用 \(G\)；本轮 \(G/s^2\) 使用前述八输入。[七体全域接合及两个原核](../computation/scaled-eight-50/seven66.zip) · [Mac 独立45根](../computation/scaled-eight-50/seven-mac45.zip) · [P66 坐标与支撑数据](../computation/scaled-eight-50/p66.json) · [七组有理有限见证](../computation/scaled-eight-50/seven-finite.zip)

主工位使用 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 与 Apple Clang。八体程序的参数与历史材料表见压缩包 README。七体程序所需 R248 前缀、物理 Q 与基础角表沿用第265轮归档；新包内的 PROOF 给出分支恢复和原核调用方式。使用标准库恢复显式坐标可运行

~~~sh
python -B decode_points.py finite-points.json
~~~

# 第66轮　圆盘、Reuleaux 三角形与正 Reuleaux 五边形的最小共同凸覆盖

三个体均为宽一，各自可独立旋转和平移。最小面积精确等于第51轮单变量接触方程及圆弧面积式定义的 M₀，且

    0.8347809457752035 < M₀ < 0.8347809457752037.

极小放置在第35轮的对称规范下唯一。取第51轮的水平平移根 a∗ 和对应 b∗，两纵向平移量和相对转角均取零。对所有规范角 0≤φ≤π/15 及全部平移，面积至少为 M₀+10⁻¹¹φ²。该精确值解决了这个三体有限测试族。

第58轮给出零角唯一性，第64轮覆盖第一段角带。此次接续至 655/32768 的新解析盒覆盖 136300 个分支单元；其外部的三个相邻角带共访问 12117 次，余盒全部闭合。余下角带至 27/128 覆盖全部平移，经 5071 个种子盒、5325 次检查闭合。由于 π/15<27/128，这些证书覆盖全部规范角。面积超过 0.838 的放置自动满足所述下界。

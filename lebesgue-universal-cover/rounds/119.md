# 第119轮　四维有理对偶独立验证九点在四体极小宿主中不可容纳

按用户提供的《文献驱动攻坚与有限点证书》§6 第一项，取文档§3原样列出的九个有理点 P₉ 与第95轮宿主 K*。构造有理外多边形 Q，证明

    K* ⊂ Q，d_H(K*,Q) < 0.002416870，max scale(P₉,Q) < 0.995743.

最大尺度的不等式允许任意平移、旋转及反射。外包的统一误差小于文档九点外扩障碍 0.00392897。Q 由 81 条有理半平面定义，去冗余后有 49 条边。该结果独立于第97轮的角格权重和材料点选择，只复用相同宿主的严格几何数据。

**外包。** 用有理单位法向包住 K*，各支撑上端向外取整，随后用分数逐项裁切。点表、外包不等式与直径的整数核验见程序。以另一组 8192 个有理单位法向检查 Q 与 K* 的支撑差，后者的下端由各曲边体的实际材料顶点或经核验的圆弧支撑给出。每个方向至最近网点的角差至多 1/2048，因四分之一圆的参数为 2 atan(t)。Q 的所有顶点均在原点单位圆盘中，K* 亦在其中，两支撑函数各自的 Lipschitz 系数至多一。将差的网点上端再加 2/2048，得到所报全角误差。

**四维证书。** 设旋转缩放变量为 (a,b)，平移为 (x,y)。对输入每个点及外包每条半平面列一条线性不等式。正反两支分别检验。在投影平面取 48 个有理单位方向，各自将原不等式作非负有理组合，取得支撑上界。组合系数取整后的微小残差按四个变量各自的绝对值上界 4 支付：Q 的直径至多 2，而 P₉ 的直径大于 0.9，故缩放小于 3；输入点范数小于 1，故平移模长小于 4。至最近投影方向的角差≤1/12，除以 1−1/(2·12²) 控制全方向最大模长。两支各 48 个对偶，每个恰用四项，合计 384 项；含外包的 JSON 证书为 11,734 字节。所有最终线性组合及尺度比较均用有理数完成。作为可行对照，程序恢复了两种手性在单位正方形中的单位尺度平移。四维表示来自 [Agarwal、Amenta 与 Sharir 原文](https://escholarship.org/content/qt6fz149cx/qt6fz149cx.pdf)。

**复现与比较。** 用户文档 SHA-256 为 4ca76c94d51e630e7240f2e3eaeb3cf19da5f3ea20940404346c30aa74960b46。实际执行文档的两个基线程序：九点及三档加密输入的 369 个闭格均给出 0.00392897；3621 点的五组基线得到 0.8366001600533616。主机单次计时四维重放约 0.40 秒，附件中同时重放四档角格约 0.19 秒；因此本例保留四维程序作独立复核。该测试只排除指定宿主及满足相应稳定估计的邻域。

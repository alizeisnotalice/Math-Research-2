# 第205轮 · B 档候选覆盖的凸组合与曲率邻域

沿用第203轮的 65 线宿主，真实面积严格小于 0.844081601570555161。对这个宿主得到两项全参数覆盖结果。

1. 允许独立选择任意多个参数 0.4285 ≤ wᵢ ≤ 0.95，取参考定宽体 K(wᵢ)、Reuleaux 三角形 R 及其相反体的任意 Minkowski 凸组合，再取 Hausdorff 闭包。所得每一个体都能在三个固定姿态之一放入宿主。对支撑函数而言，Minkowski 凸组合是普通凸组合。证书给出 188 组非负有理乘子，每组排除三个姿态的同时违约，余下一组由相反方向的宽一恒等式排除。严格上端小于 −8×10⁻⁷。在取闭包时，从三个姿态中选取恒定子序列即可。
2. 对 0.427 ≤ w ≤ 1 的单参数三生成元单形，其周围 Hausdorff 距离至多 4.5×10⁻⁸ 的归一化定宽体也能放入。以半径 1/2 圆盘为中心的可证半径为 0.0046845。这给出了一个与五锚参数无关的条件：曲率密度与 1/2 的本质上确界距离至多 0.03 即可。

另对第203轮较浅的双切线候选，通过曲率积分对偶证明：任何在指定的两个姿态同时命中的定宽体，在 (1°,6.1°) 和 (6.1°,20°) 内各有一个相容根。仍须证明某个根同时满足其余支撑约束。

独立 Python 环境在主工作区重算凸闭包的区间树、支撑邻域和第204轮的 430 格扇形常数。该轮一般上界继续由 1.54° 的十一面构造给出，B 档仍缺所述覆盖域外的任意定宽体放置定理。

# 第111轮　有限正定宽体族全局极小的代数约化

对于单位圆盘和任意有限个正定宽奇边形，全局最小共同凸包至少有一个实代数坐标放置。把每个转角用其正弦和余弦表示后，可用半代数临界集生成一份有限的候选面积表，表中相等与大小均可判定。该结论在量词上覆盖五体的全部位置、转角和退化接触。

关键一步是区分面积值和面积微分。面积的逐段原函数含有法向角，因而不能直接对面积值作多项式量词消去；角前面的系数在每种胜出支撑类型上恒定且有理，因此其微分可在单位圆坐标中精确作代数运算。按活动次序和维数分层以后，每个临界连通分支只贡献一个面积值。[定理、退化情形和比较算法](../proofs/algebraic-critical-placements.md)

主工作区用有限事件切分独立检查了面积原函数。对第102轮记录的五体参考中心，按双精度候选交换点切为 127 段，逐段积分得 0.837295006221024，与既有局部证书的小数相符。复算命令为 `python -B computation/evaluate_support_events.py`。这是固定放置上的数值检查。五体全部临界分支的枚举和一般凸万能覆盖的最小值均待解决。

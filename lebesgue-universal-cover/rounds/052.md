# 第52轮　在八维放置盒上消去正定宽九边形的全部自由度

以 Tomar 四体放置 opt8_point 的十位小数有理坐标为中心，各坐标允许独立改变 1/4096（角坐标用弧度）。对盒内每种四体放置，无论如何平移、旋转或镜像正定宽九边形 B₉，五体凸包面积均严格大于 0.83662。精确中心记录在 computation/052-chord.json。

八维区间扇估计给出基体凸包面积严格大于 836433205303/10¹²。取基体共同内多边形的一条弦：若新增点越过基体的已知支撑上界，该点与弦形成的三角形有一部分完全落在基体外侧。由其面积和剩余预算推出一个新增点必须满足的线性不等式。115 个方向各选一条有效弦。将 B₉ 的一个旋转周期划分成 256 个闭区间，用三条法向的非负有理组合消去平移，每格分别验证严格矛盾。最弱归一化间隙仍大于 16690059/62500000000。

主工作区重算了该弦证书、较小盒的独立照明体证书，以及整棵十一维树的整数裁剪计数，三个输出均与研究工作区逐字节一致。已知半径和转角限制把 16193402 个叶缩至 5958474 个可能保留叶。此计数仅描述几何筛选；八维局部盒之外的面积仍需验证。证明、完整输入与命令见 proofs/052-illumination-and-chord-projection.md；三个输出为 computation/052-chord.json、052-illumination.json、052-clip.json。

# 第188轮　同一条低面积路径上，11点强制涨面积而18点可全程装入

将第155轮与第183轮的六体摆放按同一手性的14个实坐标线性插值，记所得凸包为 C(t)，0≤t≤1。对全程有 0.83750332922647 < |C(t)| < 0.83752270510713。现取任意一个六体摆放的凸包 K。只要整体对齐后 K 到某个 C(t) 的 Hausdorff 距离至多 **0.0003093125**，就同时有以下两个结论。

- 加入任意等距摆放的指定十一点集 Q11 后，联合凸包面积严格超过 0.83753。
- 指定十八点集 X18 的两种手性都能装入 K，每种手性在对齐后的坐标中各用一个沿全程固定的有理等距摆放。因此在路径本身上，增加 X18 的最小面积代价为零。

## 全路径估计

解析支撑速度界给出五曲体凸包的 Hausdorff 速度至多 0.000662，三十点的速度至多 0.003675。在16个等长段逐一扣除两者从段中点运动的最大距离，得到三十点全程位于五体凸包，余量大于 0.00021597857。另以128个闭段的有理内凸包、平行体面积公式及同一速度界认证全程面积区间。对16个段中点以长边帽和平衡法向分别认证可排斥 Q11 的邻域；在每个段中扣除至少覆盖半个段的运动误差后，最小剩余半径为 4949/16000000。主工作区重新验证全部两手性角格与面积闭段，所得回执与 MacBook 逐字节一致。[路径验证器](../computation/certify_six_anchor_path.py) · [冻结角格](../computation/six-anchor-path-witness.json) · [全路径回执](../computation/six-anchor-path-audit.json)

对于 X18，在相同16个中点分别构造五曲体的有理内多边形。每种手性选定一个有理半角正切和两个有理平移坐标；逐边用整数检查全部18个点。对于每个单位法向，支撑在半段上最多下降 0.000662/32。减去这个量后，全路径正手和反手的最小净空间分别大于 0.00070250465 与 0.00036604683。Hausdorff 距离再损失至多 0.0003093125，两个摆放仍然严格可行。这里的11点和18点是两组独立构造的指定输入。[有理姿态](../computation/x18-anchor-path-poses.json) · [严格边余量](../computation/x18-anchor-path.json)

## 复算

在课题目录下使用含 NumPy、SciPy、python-flint 的 Python 运行。

```sh
python -B computation/certify_six_anchor_path.py computation computation/six-anchor-path-witness.json --workers 4
python -B computation/certify_x18_anchor_path.py
```

本轮覆盖一条路径的整个邻域。其余低面积六体姿态的分类，以及一般最小面积的精确值，仍开放。

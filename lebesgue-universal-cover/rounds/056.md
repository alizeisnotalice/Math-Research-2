# 第56轮　同一七体族中，单位宽正六边形约束严格提高最优面积

令 m 为第53轮七体族在平面任意放置的最小凸包面积，m_hex 为同一七体全部位于一个共同的宽一正六边形内时的最小面积。两个最优值满足

    m < 0.83796232，    m_hex − m > 0.00013672.

证法是在 17 个相对平移及转角参数上寻找可行放置。精确参数按 B₃ 的两个平移、B₅/B₇/B₉ 的角与两平移、两个 Fourier 体的角与两平移排列。支撑函数、取向和归一化与第53轮相同。对数值搜索所得的十进制参数，以 160 位 Arb 将全部边界样点坐标取整，将每个非线性边段的二阶误差并入 Steiner 外扩，整数多边形给出双侧面积包络。主工作区以每条定宽多边形圆弧 2048 等分重算，得固定放置的面积介于 0.83796215 与 0.83796232 之间。用精确有理上端与第53轮的全枚举下端相减，严格超过 0.00013672。

第54轮证明的三方向关系只用到该七体族。因此对任意七体最优共同覆盖，每组三个相隔 60° 的方向必有一个宽度超过 1.000000905；否则其面积下端已超过本轮可行上端。以上说明即使对有限定宽测试族，将候选放入同一单位宽正六边形也可能损失最优性。一般凸万能覆盖最优体的宽度和精确面积仍未知。

在 computation 目录运行 python -B certify_free_seven.py，脚本读取 056-free-seven.json 中的 17 个有理参数，复用第55轮的点生成与向外误差核算。056-free-area.json 保存精确面积包络和两类最优值之差的有理下界。初始数值探索的采样面积不参与严格比较。

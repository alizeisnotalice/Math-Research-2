# 第175轮　七输入共同摆放与两个原叶的严格排除

输入为圆盘、正定宽三、五、七、九边形及两个有理点集 P30、Q11。MacBook M5 Pro 的两次 Metal 搜索各运行 262144 轮，每轮比较 8192 个姿态。种子 381117 和 381118 所得有限角评分分别为 0.8379671574 和 0.8379204273，命令缓冲区累计 GPU 用时分别为 351.42 和 384.64 秒。第二个起点经 CPU 细化得到归档姿态。

按每段圆弧 8192 等分，以 160 位 Arb 核验采样点的整数舍入误差。圆盘边界用 65536 等分。对全部取整点生成有 8343 个顶点的整数凸包，使用弓高及舍入误差给出外平行体面积上端。反向用所含半径二分之一圆盘吸收舍入误差得到下端。该具体摆放的真实凸包面积在 (0.8378949872364058, 0.8378949940836267) 内。这给出了七输入最小共同宿主面积的一个上界；一般万能覆盖仍采用第174轮上界。

从同一七输入出发，在靶值 0.83745 对原叶 1205/140208、1205/140080 独立重放四种搜索方式。共享中心库与普通面积帽联合，分别以 78509、109929 节点完全排除两叶。六输入对照在每叶 200000 节点预算内均未闭合。与旧的 2083 个原叶有非空交的共有 191 个，其他原叶仍须逐叶验证。

[固定姿态面积的有理端点](../computation/seven-point-families-area.json) · [两原叶的证明与复算](../proofs/mixed-point-original-leaf.md)

严格面积可用 `python -B computation/certify_seven_point_families.py` 重算。复现 GPU 候选搜索时，从归档的 metal-seven-search 目录将 seven.metal、resident.mm 和所选输入复制到独立工作目录，输入命名为 inputs.txt。第一起点使用 inputs.txt，第二起点使用 alternative-inputs.txt。用 Apple Clang 编译，再分别运行对应种子。

```sh
clang++ -O3 -std=c++17 -fobjc-arc resident.mm -framework Foundation -framework Metal -o resident
./resident 262144 381118
```

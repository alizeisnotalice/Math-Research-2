# 第30轮　切除区域的位置与边界

固定 σ=1.5494°。五个 Sprague 扇形各自完整落在 P 的八个闭半平面中。区间检查覆盖每段短弧，切点用单位圆的支撑恒等式处理，扇形由凸性得到。详见 proofs/030-sprague-fan-containment.md。

EH 的边界由一条弦和两段短弧组成。其封闭区域在 −1/2 < x < −499/1000 内，而圆心 S 的横坐标等于 1/2。边界到 S 的距离至少为 1。若内部存在距离不超过 1 的点，距离平方即在内部取得最小值，其梯度为零要求该点为 S，矛盾。因此整个内部严格位于单位圆外。Pál 支撑线上唯一等号点 U 由投影公式精确确定。详见 proofs/030-eh-geometry.md。

在 computation 目录运行下列命令可重建证书。

```sh
python3 -B certify_fans_in_p.py > 030-fans-in-p.json
python3 -B audit_eh_geometry.py > 030-eh-base.json
python3 -B audit_eh_geometry_final.py > 030-eh-final.json
```

本轮采用 Python 3.15.0。接下来将这些固定角区域结论接入整体凸性与覆盖放置证明。精确最小面积仍开放。

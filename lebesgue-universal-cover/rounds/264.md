# 第264轮　第152体及两邻盒的真实最小修补

以 \(D_E\) 表示第253轮容纳原 150 体和整个第151体邻盒的最小修补。保留 \(D_E\)，另要求容纳第152体 \(P(w,e)\)，每个输入允许各自选取旋转、反射和平移，宿主仍在原正六边形 \(H\) 及两条斜帽内。记新宿主超过 \(|D_E|\) 的最小面积为 \(\Delta\)。令 \(w_0=1.2,\ e_0=.08464386\)。当同时容纳一个闭盒时，对盒内每个成员的摆放可以独立选择。

| 输入 | \(\Delta\) 的严格范围 |
|---|---|
| 单个中心 \((w_0,e_0)\) | \(3.721652952651306201470860014307\,10^{-9}<\Delta<3.721652952651306201470860080259\,10^{-9}\) |
| 小盒 \((\lvert w-w_0\rvert,\lvert e-e_0\rvert)\le(6\,10^{-8},6\,10^{-9})\) | \(3.736200467862957015398502068061\,10^{-9}<\Delta<3.736200467862957015398502134423\,10^{-9}\) |
| 大盒 \((\lvert w-w_0\rvert,\lvert e-e_0\rvert)\le(10^{-5},10^{-6})\) | \(3.736200467862957015398502068061\,10^{-9}<\Delta<6.146236010619366178343764682991\,10^{-9}\) |

中心和小盒各有唯一的最小修补宿主。大盒的下端利用其中包含整个小盒；大盒精确最优面积仍待求得。其已构造宿主距 \(B=.844082046521218581802948589770767704354\) 尚有超过 \(9.69581\,10^{-8}\) 的严格余量。此次计算的是固定 \(D_E\) 并保留原外部限制后的最小增量。[面积分数与检验摘要](../computation/exact-152-repair/result.json)

### 中心的曲边与真实切换

第151体自身的中心和闭盒已经分别耗费 \(8.42548438041687\ldots\,10^{-8}\) 与 \(8.42548625677465\ldots\,10^{-8}\)。后一个最小宿主为 \(D_E=\operatorname{conv}(C_{150}\cup QP(.7982906999,.03268800001))\)，\(Q\) 先转 \(240^\circ\) 再关于横轴反射。若只要求第152体中心也在内，新最小宿主是 \(\operatorname{conv}(D_E\cup QP(w_0,e_0))\)。沿用第253轮的姿态穷尽，十种中心摆放越过旧帽；恒等姿态仅一条既有边的外三角形就比 \(B-|D_E|\) 大。[第151体最优解及第152体的原始姿态](253.md)

在局部法向 \(112.31^\circ\) 至 \(115.57^\circ\) 内，区间计算重建出旧支撑从 118 号曲体，经第151体角点，到 113 号和 112 号材料的顺序。新支撑只有一个外露顶点，起止法向约为 \(112.32723322511353^\circ\)、\(115.55232805898620^\circ\)。比较所有原输入与原核，窗外以 714 个闭角格、六条固定法向的精确接触及十二个单侧导数完成全周证明。若 \(f=(h_{Q P}-h_{D_E})_+\)，则 \(2\Delta=\int f\,d(S_{D_E}+S_{QP})\)，其中 \(S_C\) 为平面边长测度。积分包含一段单位圆弧及三条公共切线的原子；第一条旧切线的面积贡献已超过 \(3.34964\,10^{-9}\)。沿新旧真实边界另用 Green 公式相减，得到同一中心增量。[中心曲边积分、边原子及核](../computation/exact-152-repair/center.zip)

### 小盒角点强制了整个宿主

对小盒取 \(q_s=(1.19999994,.084643866)\)。当采用 \(Q\) 时，外露区内五弧支撑的参数导数使该角点逐方向达到整个小盒的最大值。窗外由 \(D_E\) 的实际材料支配；六条固定法向两侧以精确接触等式补上边界。每个小盒成员均可放入 \(\operatorname{conv}(D_E\cup QP(q_s))\)。在 \(q_s\) 的基本角域穷尽相容根，仅有零根，生成十二种候选。十种候选已由真实旧帽的支撑弦迫使总面积超过 \(B\)；恒等候选由另一条旧边给出大于 \(1.0751818894\,10^{-7}\) 的新增面积。余下唯一的 \(Q\) 在两帽内。于是每个满足预算且容纳 \(q_s\) 的宿主都要包含这同一个凸包，该凸包又足以容纳所有成员。证明针对整族最优，其他成员的单体最优姿态可以另选。[小盒全部十二姿态与面积双核](../computation/exact-152-repair/rectangles.zip)

### 大盒的角点可以免费放入

对大盒取 \(q_l=(1.19999,.08464486)\)。仍一致使用 \(Q\) 时，\(\operatorname{conv}(D_E\cup QP(q_l))\) 容纳大盒全部成员，角点新增面积的两端为 \(6.146236010619366178343764617624\,10^{-9}\) 与 \(6.146236010619366178343764682991\,10^{-9}\)。但 \(q_l\) 的基本角域内除零根外还有约 \(5.8429192061464^\circ\) 与 \(5.8728189366155^\circ\) 两个相容根。每根各有两种实际摆放，四个姿态的完整曲体都已经落在 \(D_E\) 之内。各姿态分别用 720 个实际闭角段核对支撑，六条固定法向的十二个贴边邻域使用真实面点及单侧导数。因此此角点单独的最小增量严格等于零；大盒的最小增量则严格为正。小盒与大盒的区别出现在可用旋角的变化，而不是面积计算精度。

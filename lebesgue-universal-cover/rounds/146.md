# 第146轮　同一三十点把一般下界提高到0.83732

圆盘、正定宽三、五、七、九边形及同一组三十有理点，各作任意平移、旋转或反射后，联合凸包面积严格超过 **0.83732**。第141轮的705个规范闭盒覆盖原五体在此门槛下的所有摆放。对每个盒，以旧五体的整数面积或三十点的额外面积关闭整棵树，包含全部614个旧叶及91个新增叶。六体最小值由紧性达到，一般凸万能覆盖面积故也严格超过该门槛。

本机重算外围的135,630,306个节点，4,096个几何数组与归档逐字节一致。本机及 MacBook 再分别从原树和材料表重算全部705棵末端树。两机一致得到55,314,125个节点、24,781,384个五体终端及2,876,031个三十点终端；468个原叶实际使用了三十点。MacBook 使用12个 CPU 工作线程，耗时163秒，退出码0。[全域证明](../proofs/finite-point-lift-083732.md) · [本机回执](../computation/finite-point-lift-083732-replay.json) · [MacBook 回执](../computation/tomar-six-083732-macbook-replay.json)

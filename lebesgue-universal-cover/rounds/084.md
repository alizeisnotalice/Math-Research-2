# 第84轮　保留真圆弧的 EH 连续摆放

固定第47轮角度，EH 端点移动 0.000105 弧度时，得到一般凸万能覆盖面积 Λ < 0.844093570875584138。

第81轮用内接多边形处理左侧 C₃ 单位圆弧。本轮直接验证这段弧的所有真实支撑线。摆放后，六个正六边形支撑条件和 m₅ 半平面给出 CB 接触点 b，它与 C₃ 横坐标相同且纵坐标不低于 C₃。对纵坐标不高于 C₃ 的点，距 C₃ 不超过距 b，而距 b 至多一；较高的点则由六边形左边线和第三象限外法向保证在线内。这样可以移去该段四条内弦，余下的 28 条非六边形边继续用第80轮的同一个相容根控制。

相容函数在 31.06° 处严格小于 −0.00001352025，其在 30° 的非负端由反射选择保证。各边分别划分整个角区间，自适应重放逐条核验闭格接缝。30 个边角格、60 份对偶和 3003 条圆盘切线全部通过，最小严格边余量大于 0.00000238383。主工作区 160 位 Arb 重放结果与原证书逐字节一致。相对第47轮的新增切除面积严格大于 0.00000002351090562121881，面积上端按有理数向上舍入。详见 proofs/eh-root-conditioned-relocation.md、computation/084-area.json。

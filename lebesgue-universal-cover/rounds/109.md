# 第109轮　加深 EH 后的复合凸万能覆盖

取 Gibbs 角 σ=1.5497°，保留第105轮 AH 铰点参数 0.38 和转角 0.00033 弧度，将 EH 切深从 0.00036 增至 0.00055。所得凸体 H 对平面所有直径不超过 1 的集合均为万能覆盖，且

    0.844093430168568369790989591004055152512 < |H|
    |H| < 0.844093430168568369790989591004055152513.

右端比第106轮一般上界降低约 4.28682 × 10⁻⁸。一般下界仍为 0.83661。

**覆盖。** 对 EH，先将同一个定宽体在两个反射法向上的支撑函数放入同一判据。分支可按其中较小者选择姿态。31 个闭角格和 60 组对偶给出严格余量。接着对所得拷贝检查 AH；双命中分支中在同一姿态同时验证新 AH 线、深 EH 线及其余约束。1340 个参数格各分 100 个角格，扣除位置误差后的最小支撑余量大于 0.0002064112。

**面积。** 深 EH 帽位于水平零线以下，AH 帽位于其上方；在第106轮固定角的基准面积区间中分别减去两帽的有理积分区间。左端仅界定该固定构造。

**独立核验。** 在主工作区运行下列命令。第一条重放全部 EH 对偶，输出与冻结输入逐字节相同。第二条重算全部双命中姿态格，除本地脚本哈希外结果与独立工作区相同。第三条核对几何参数、EH 证书哈希及各面积端点后输出上列区间。第一条的 OUT 为临时目录中的文件名。

```sh
python -B certify_eh_joint_switch.py 1.5497 0.00055 36 "$OUT" --eh-relocation --joint-eh --old-area eh-joint-1p5497-old-area.json --replay eh-cap-switch-joint-550.json
python -B certify_deep_ah_eh.py --combined-deep
python -B deep_combined_area.py
```

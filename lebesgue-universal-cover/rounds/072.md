# 第72轮　三夹带加一条切线的精确最优面积

在三个单位宽夹带与一个半平面相交的全部平面凸体中，万能覆盖的最小面积为 x/[2(1−x²)]+x/2+(1−x)/(1+x)，其中 x 是 x⁴−5x²+8x−2 在 (0,1) 的唯一根。最小面积严格介于 0.8531920598769746041 与 0.8531920598769746045 之间。该族的最优面积仍高于第67轮的一般上界。

宽一圆盘要求三条中线共点。第59轮证明三个中心夹带内总有一个放置；直径条件保证这个放置和它绕中点转半周的两个像中，至少有一个留在附加切线的内侧。固定包含切线法向的角隙后，对其他两个角隙及切线的位置使用正切函数的严格凸性，最优化只剩角隙一个参数。

对两条 Gibbs 切线得到不同限制。以三条等角法向为基准固定第一条，令其余两条的相对角扰动最大值为 M，0<M≤0.001 弧度。两个帽法向也允许在证明规定的基准方向附近各变动至多 0.001 弧度。即使每个中心夹带半宽可再增加 10⁻⁵M、两帽各可外放 10⁻⁵，七次或十三次谐波定宽体中至少一个无法放入。这里的障碍覆盖这些体的全部等距摆放。论证使用可行旋转必须同时满足的支撑方程和相位误差界。

主工作区使用 Python 3.15.0 重跑 computation/certify_three_strip_cap_families.py 与 certify_three_strip_width_slack.py，获得有理根隔离、面积和相位余量。完整假设及证明见 proofs/three-strip-cap-families.md 和 proofs/three-strip-width-slack.md。

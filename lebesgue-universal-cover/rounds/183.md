# 第183轮　一个六体宿主排除全部三种参考邻域

取五个曲体和有理三十点的明确摆放，以它们的共同凸包为宿主 H。主工作区用严格有理面积比较及 Arb 支撑函数重新得到 0.8375136706688 < |H| < 0.83751378。对第166轮三个参考轮廓，其任意旋转、反射、平移后要装入 H，分别至少须向外扩张 H 超过 0.00037985598、0.00033105937 和 0.00352694911。三项均大于 0.83753 门槛的相应邻域半径。

这排除了该门槛处仅靠三个参考邻域分类的存在性版本。因为同一个 H 内重选任何六体摆放，其凸包仍是 H 的子集；若该凸包可与某参考达到相应 Hausdorff 距离，则此参考也能装入 H 的相应外扩。证明以256个方向的真实宽度和每种手性8192个闭角格排除这件事。本机独立重算的逐格回执与冻结材料逐字节一致。已知这个 H 的面积大于 0.83742，较低门槛的三邻域分类仍需单独研究。[姿态、证明及复算](../proofs/structural-six-escape.md) · [参考轮廓非包含的完整回执](../computation/structural-six-escape-audit.json)

上界方向也找到一个使 EH 裁切下端触发条件达到边界的定宽一体。它满足原先避开两角帽的条件，同时含下端 T 的局部透镜。故若把末端沿单位圆弧继续下移，在 0<α≤0.0009 内严格转入的新末裁线会击中该体。原来的离散反射触发条件需要加强，是否还有另一姿态可放是独立问题。主工作区从几何输入重算回执一致。[下端触发定理](../proofs/eh-lower-endpoint-trigger.md)

本轮结论涉及指定参考轮廓与指定触发条件，一般上下界沿用第181、182轮。

# 第186轮　排除逃逸宿主的整个邻域，并缩小单组有理障碍

第183轮的六体宿主 C 逃出了原有三个参考邻域。现证明：任一六体摆放凸包 K 经整体等距对齐后，若与 C 的 Hausdorff 距离至多 0.00035，则同时容纳 K 及任意一个指定11点集副本的凸宿主面积都严格大于 0.83753。两种手性各以93个闭角格覆盖全部转角；最差支撑余量超过 0.000000535128。对 C 本身，两种手性各独立验过137个闭角格，装入该11点集所需外扩严格超过 0.00226438990。主工作区重算的结果与 MacBook 严格回执逐字节一致。[第四个邻域的证明及复算](../proofs/q11-structural-anchor.md)

## 面积门槛以下可明确列出的单组障碍

以下每行各给出六组合法有理点。对任一面积至多该行门槛的凸宿主，六组中至少有一整组不可能以任何等距摆放装入。

| 宿主面积至多 | 圆盘、定宽三、五、七、九边形的替代点数及原30点 | 单个障碍至多含 |
|---|---|---:|
| 0.83735 | 299、177、180、182、189、30 | 299 点 |
| 0.83740 | 557、327、330、329、333、30 | 557 点 |
| 0.83741 | 789、459、460、462、468、30 | 789 点 |

证明采用第182轮的六输入全域下界。逐组生成外切多边形的有理坐标，在所有有理边法向上核验其含有至少比例 κ 的相应原体，其中 κ 取五组共同的严格有理下端，并验证每组内的全部点对直径。第六组原点集凸包含有任意围绕自身一点缩至 κ 的副本。若某宿主能容纳全部六个点集，将它放大 1/κ 即可分别容纳原六组。于是其面积至少为 0.83742κ²，三个实际核验的有理数分别严格大于表中门槛。

对于 0.83740，557 点也是上述仅用 0.83742 及共同缩比传递方法所需的最大单组点数的最小值。若圆盘替代组只有 m≤556 点，已证的圆盘顶点数不等式给出 κ≤cos(π/m)/cos(π/(2m))。即使取最大允许值，0.83742κ² 仍小于 0.83740。其他两档的对应必要点数为298和788。[多边形顶点数不等式](../proofs/tangent-polygon-vertex-limits.md) · [精确面积下端、点对直径及三个坐标文件索引](../computation/small-obstructions-083742.json)

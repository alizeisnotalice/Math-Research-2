# 第65轮　三个精确单位宽方向的七体反例

取第53轮的七个定宽一测试体。第53轮证明，当三个宽一夹带的法向等角时，任何共同覆盖面积大于 0.83809903。本轮在不等角的三个方向上仍要求宽度精确为一，得到面积小于 0.837545863 的可行凸包。两者面积之差严格大于 0.000553167。甚至只将一个法向旋转 0.0001 弧度，也可构造面积小于 0.838098066 的七体覆盖。

令三个法向角分别为 0、2π/3+s、4π/3+t。确定平移的方程是 nᵢ·v=1/2−h(θᵢ−φ)，其中 h 是给定测试体的支撑函数。取 λᵢ=det(nᵢ₊₁,nᵢ₊₂)，下标循环，则 Σλᵢnᵢ=0。由于前两个法向线性独立，三个方程同时有解等价于 Σλᵢ(h(θᵢ−φ)−1/2)=0。在每个给定转角小区间两端用 Arb 证出严格异号，连续性给出一个根。前两个方程给出相应平移，第三个方程随之成立。每个测试体定宽一，因此它与三个闭夹带的两侧都相切。七个测试体的凸包也恰有这三个方向宽一；这里“恰”指三个宽度数值均等于一。

主工作区在 160 位 Arb、K=2048 下实际重跑 computation/certify_irregular_hex.py。它用第55轮格点凸包与曲率误差核验所有根区间对应的面积上界。参数及全部根区间端点符号分别见 computation/irregular_inputs.json 和 computation/065-irregular.json。

| s（弧度） | t（弧度） | 严格面积上界 |
| --- | --- | --- |
| 0 | 0.0001 | 0.838098066 |
| 0.01 | 0.02 | 0.837907536 |
| −0.03631707 | 0.03750075 | 0.837545863 |

因此，仅凭三个方向的宽度精确为一，不能把第53轮正六边形下界推广到这一七体问题。一般万能覆盖仍需要处理七体以外的输入。

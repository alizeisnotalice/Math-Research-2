# 第82轮　四方向面积估计的适用极限

第59轮的四方向不等式在等角方向上积分，给出平均宽度至少 33/32。再用宽度函数的 Fourier 系数、曲率测度的正性和第60轮的最大宽度门槛，可把平均宽度下界严格提高到 33/32+1/125000。配合所含中心圆盘与支撑面积公式，可得面积严格大于 0.80994813918。

这些条件无法单独推出第77轮的一般下界。具体而言，同心圆盘 D 与 Reuleaux 三角形 B₃ 的凸包已容纳第59轮测试用的三次谐波定宽体，故满足两轮全部宽度约束；其面积为 π/8+√3/4，约 0.82571178。若只用第59轮宽度条件，内切半径 1001/2000 的正九边形也通过全部约束，面积约为 0.82057171。这说明欲进一步提高一般下界，仍需利用单个支撑宽度以外的信息，例如同一输入体各点在同一次放置下的相容性。

完整推导见 proofs/width_integral_limits.md。主工作区使用 160 位 Arb 重跑 computation/certify_width_integral.py，结果 082-width-integral.json 与独立工作区逐字节一致。

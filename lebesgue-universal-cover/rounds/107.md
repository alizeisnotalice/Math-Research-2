# 第107轮　五体低面积放置的四个必要平移界

固定半径 1/2 的圆盘圆心为原点。若圆盘与四个正定宽体的凸包面积不超过 0.837295006222，则任意转角下，各体中心到原点的距离均须满足下表。五体的已知严格局部极小面积小于该门槛，故每个五体全局极小放置都在这四个开圆盘内。

| 移动体 | 中心距严格小于 | 在该半径上，与固定盘组成的凸包面积严格大于 |
|---|---:|---:|
| B₃ | 0.06835 | 0.83734267 |
| B₅ | 0.06650 | 0.83730755 |
| B₇ | 0.06004 | 0.83730562 |
| B₉ | 0.05699 | 0.83730343 |

证明先用两体凸包面积关于平移的凸性和旋转对称性，将圆外区域约化为一个圆周扇区。每个扇区由 2048 个闭角格覆盖。主工作区独立运行了平行体公式的初始证书，又以整格共享平移变量的仿射行列式证明了表中的四个更小半径。864 个材料点均由整数或 Arb 区间逐点核对。浮点凸包程序仅用于提出扇顶点的顺序。

在 computation 目录用安装 NumPy、SciPy 和 python-flint 的 Python 执行：

```sh
python -B certify_five_body_radial_limits.py
python -B certify_radial_affine_fans.py
```

# 第177轮　候选宿主上的混合面积等号筛选

检验命题为：在现有凸万能宿主上，固定顶点数的内多边形是否能单凭混合面积单调性达到等号？利用保留的 G—K 单位圆弧，证明对所有至多 m 顶点的内多边形，缺口一致严格大于 (0.014)³/[56(m+1)²]。这个估计直接适用于整族内多边形，并给出了构造等号证明时必须补偿的项。[定理、假设及复算](../proofs/circular-arc-mixed-area-gap.md)

另在主机和 MacBook CPU 重放结构指南附录的18点测试。按每种手性分别枚举54个对齐事件，支撑和最小值约为 1.20016031918551668、1.22340243776590507。该实验用于检查旋转事件和反射。两数衡量支撑和。第176轮的一般上下界保持有效。

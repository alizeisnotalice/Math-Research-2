# 第35轮　平移半径与两体最优面积

面积至多 419/500 的八体配置有 28 个必要的两两中心距约束。相对固定盘的七个平移半径依次严格小于 0.07、0.0908、0.0724、0.0647、0.076、0.0608、0.0918（B3、B5、B7、B9、P11、P19、Fourier）。前六个体原先统一使用 0.21，Fourier 体使用 0.24。B3 的改进使用平移方向上的凸性和1024个完整方向区间，证书中最小面积下界大于0.83823829。

只用这些半径外接方框，保持各角区间不变，代表盒体积已经小于第14轮矩形域的 3.765×10⁻⁷；再使用共同三重旋转，B5 的方向范围可缩至原来的三分之一。剩余区域仍须处理。

同一凸性论证给出固定圆盘与 Reuleaux 三角形的两体精确最优面积 π/8+√3/4，亦是一般问题的一个可自足验证的下界。详见 proofs/035-translation-inballs.md。主工作区在 Python 3.15.0 下实际运行 computation/certify_rotation_inballs.py 及 computation/certify_b3_radial.py，输出分别为 computation/035-inballs.json 和 computation/035-b3-radial.json。另从28条记录复核每个面积阈值，并重算七个方框的体积乘积。

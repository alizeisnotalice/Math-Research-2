# 第53轮　单位宽正六边形中的七体极值

若要求候选凸覆盖本身包含在某个宽一正六边形中，则 D、B₃、B₅、B₇、B₉ 和第49、50轮两个光滑体的共同覆盖最小面积严格位于

    (0.83809903, 0.83810754).

要求凸覆盖位于该六边形内使每个定宽体在三条方向同时贴紧。由支撑和的精确零点确定全部转角后，相应平移唯一。模去六边形和各体自身对称性后枚举 2592 个组合，其中 3 个需要更细计算。这个下端也适用于包含在宽一正六边形里的万能覆盖；一般凸万能覆盖允许更大的方向宽度。

推导见 proofs/053-hex-orientations.md。在 computation 目录以含 python-flint 的 Python 运行 python -B certify_hex_fourier_placements.py，输出 053-hex-fourier.json。程序记录粗格全枚举和细格包络，并取未细化组合的最小下端作最终比较。

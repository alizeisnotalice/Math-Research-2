# 第215轮 · 低于 B 档的 150 体宿主与第 151 个输入

固定第212轮的 Gibbs 凸核、原正六边形与两斜帽。能容纳该轮全部 150 个完整定宽体的最小面积 \(L_{150}\) 满足

\[
.8440818564775687807184593873363064034435
<L_{150}<.84408188388316461783076226076929883 .
\]

取凸核及 150 个指定姿态下的真实输入的凸包，即得右侧候选。其面积比计划 B 档门槛低逾 \(1.62638\times10^{-7}\)。两个曾使第203轮候选失败的镜像输入在这里均有摆放。编号 113 的五边形还给出一个越过旧配对切线的材料点，距离大于 \(.00010804\)。[完整证明](../proofs/finite-b-core-host.md) · [支撑点与共同摆放](../computation/finite-b-core/pose-audit.json)

在主工作区实际重建了 4,915,200 个支撑点，并用曲率上界包住相邻方向间的全部真实边界。凸核另以 794 个向外取整的半平面和有理交点包住。总凸包的面积由整数行列式计算，圆盘外扩的面积误差用 192 位 Arb 验证。[面积有理上端](../computation/finite-b-core/host-area.json)

参数以 \((.7982907,.032688)\) 为中心的一整个真实五边形盒，在此候选的任意平移、转动和镜像下都放不进。它的十个姿态越过原斜帽，其余两个分别在 \(112.325^\circ,113.311^\circ\) 越出候选支撑，较小超出量大于 \(7.17889\times10^{-6}\)。排除同样适用于该候选与半径 \(2\times10^{-9}\) 圆盘的 Minkowski 和。[全部姿态与闭参数盒](../computation/finite-b-core/obstruction.json)

复算使用 Python 3.13.18 与 python-flint 0.9.0。下列临时输出可放在同一个空目录，记作 \(D\)。两组采样彼此独立。

```sh
C=computation
S=$C/finite-b-core
python -I -B "$S/certify_core.py" "$C" "$D/core-outer.json"
python -I -B "$S/certify_poses.py" "$C" "$S/host-poses.json" "$D/pose-audit.json"
python -I -B "$S/sample_pentagons.py" "$C" "$S/host-poses.json" "$D/pentagons.json" 32768
python -I -B "$S/sample_profiles.py" "$C" "$S/host-poses.json" "$D/curves.json" --N 32768
python -I -B "$S/certify_host_area.py" "$S/host-poses.json" "$D/pentagons.json" "$D/curves.json" "$D/core-outer.json" "$D/host-area.json"
python -I -B "$S/certify_obstruction.py" "$C" "$D/obstruction.json"
```

一般万能覆盖的上下界沿用第208、213轮。新五边形给出了继续改动低面积宿主时必须处理的输入。

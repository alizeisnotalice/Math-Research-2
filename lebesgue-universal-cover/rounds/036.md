# 第36轮　三体同心邻域的全转角排除

在第35轮缩小后的中心域中，进一步排除 B3、B5 同时距原点至多 1/12500 的全部配置。证明覆盖整个 B5 方向圆。关键是同心圆盘与两个定宽体的凸包只需要八个非圆顶点，角度误差可用有理旋转及内接圆盘控制。

主工作区使用 Python 3.15.0 运行 python3 -B computation/certify_centered_three_body.py，并用 Fraction 核对邻域面积下界严格超过 419/500。证明见 proofs/036-centered-three.md，精确分数见 computation/036-centered-three.json。不同中心位置的三体极小值仍待认证。

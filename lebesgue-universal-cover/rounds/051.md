# 第51轮　三体零转角切片的全域极小与邻角界

令 M₀ 为固定 B₅ 相对于 B₃ 的转角为零、允许两个体独立任意平移时的最小凸包面积。严格得到

    0.8347809457752035 < M₀ < 0.8347809457752037.

沿同一方向独立平移各体时，任一横截面的上端为仿射函数族的上确界、下端为下确界。积分后可知面积关于这些平移量联合凸。先用共同镜像把两个纵向平移同时取零，再在两个水平平移变量上寻找零次梯度。计算在三重支撑接触曲线上找到一点，曲线两侧梯度的一个凸组合为零；联合凸性把这个局部条件提升为整切片的最优性。对应标量方程、接触次序与面积积分见 proofs/051-three-body-symmetric-slice.md。主工作区使用 160 位 Arb 从头重算拓扑符号、根的异号端点和面积包络，输出见 computation/051-slice.json。

由此，对于允许任意转角的三体问题，结合第45轮有 0.83477 ≤ m(D,B₃,B₅) < 0.8347809457752037。还可控制零角的邻域。记 H 为任意转角 θ 与任意平移下的真实凸包，H₀ 为保持中心并将 B₅ 旋回零角的凸包。B₅ 外半径 R=1/(2cos(π/10))<0.526（用 cos x≥1−x²/2 及 π<22/7）。故 H₀ ⊂ H+R|θ|B ⊂ (1+2R|θ|)H；后一个包含使用 H 含以原点为心的半径 1/2 圆盘。因此当 |θ|≤0.000005 弧度时，任意放置都有面积 ≥M₀/(1+2R|θ|)² >0.8347721。离开这段角域的三体最优放置仍待确定。

在 computation 目录用含 python-flint 0.9.0 的解释器运行 python -B certify_three_body_symmetric_slice.py 即可复现。

# 第162轮　一个十八点障碍加入五体后精确极小面积保持不变

令 X 为第153轮的十八点集。第158轮的五体极小宿主 K* 同时容纳 X 的两种手性。反射摆放到真实边界的内余量严格大于 0.00013547089；主工作区以187个有理内多边形顶点重放，逐边检验18个像的投影。于是五体加 X 的六组自由摆放，其最小共同凸包面积仍精确等于 M，最优宿主仍只有一个整体等距类。证明如下：每个六组宿主都含五体，故面积至少为 M；K* 取得等号。原五体在等号处的唯一性迫使任何等面积宿主都与 K* 全等。X 的摆放有正余量，所以作为标记点集的六组摆放并不唯一。

# 第92轮　五体十一维下界所需的原树截面

圆盘 D 固定在原点，正定宽三角形 B₃ 的朝向已固定。剩余坐标依次是三角形平移和 B₅、B₇、B₉ 各自的角度与平移。对整个配置绕圆心转 2π/3 不改变 D 与 B₃ 的朝向；B₅ 的角度以 2π/5 为周期，所以该群在其角圆上生成步长 2π/15。再对三角形的对称轴反射，B₅ 角变号。故每个五体配置有一个等面积代表满足 0≤ρ₅≤π/15。其他体随同一等距变换移动，角度可各按本体周期约回。若该代表的平移跑出第85轮的根箱，直接用该轮的统一根外面积下界 0.85914。

用 128 位 Arb 严格核验有理数 q=20943951024/10¹¹ 大于 π/15。对每个原闭叶的角截面 [l,h]，只在 l>q 时丢弃原叶，h≤q 与 l≤q<h 分别保留。脚本对原树哈希、前序分割、根片号与端点逐一核对。每次沿角维二分，将比较式两边的整数尺度加倍，全程采用精确整数。

| 原叶类别 | 叶数 |
|---|---:|
| 全部位于保留域 | 4,002,817 |
| 穿过有理边界 | 2,707,497 |
| 严格位于保留域外 | 9,483,088 |

由此，证明任何低于根外界的新门槛，只需对 1,024 个根分片内的 6,710,314 个保留叶给出面积证书。跨边界叶可直接核验全叶，或先精确裁至 q。主工作区按原分片间隔 11 取样，对三类中存在的类别各选一叶，共 373 叶，用第85轮的独立有理端点解码器复核，全部相符。对第85轮需要 Arb 的 11,997 个余叶求交，三类数量分别为 2,510、2,811、6,676。本轮没有对提高后的面积门槛作全域判定。

在 computation 中运行以下命令。CERT 是冻结的 cert11d_08366；MASKS 为自选输出目录。每个可再生的 uint8 掩码按原始节点编号索引，内部节点为0，以上三类依次为1、2、3。归档保存每一掩码的 SHA-256 和三类计数。

```sh
python -B tomar_five_orbit_slice.py "$CERT" result.json --masks "$MASKS"
```

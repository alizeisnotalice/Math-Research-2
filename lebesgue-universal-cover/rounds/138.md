# 第138轮　用九边形方向分离五体近极小放置

设圆盘及正定宽三、五、七、九边形的联合凸包面积至多为第123轮门槛 (T=0.837295006222)。取该轮固定三边形方向的规范代表，令 δ 为九边形转角到周期格 ((2π/9)ℤ) 的距离。则 δ 严格小于 9/200 或严格大于 3/10（单位为弧度）。五体极小点必满足此二择一条件，因为已有可行构形的面积小于 T。

由第123轮，代表位于501个闭盒之中。按11个坐标区间是否全部相交建立邻接图，使用共同单位为二的负44次幂的整数端点，得到三个连通分量，分别含346、130、25盒。在346盒的每一盒上，第九坐标的两个端点均与所在周期的两端相距超过3/10。在另两组，每一盒的规范角部分距同一周期端点小于9/200。以160位 Arb 区间夹住周期端点后，在另十个坐标检查相交，得到1324对跨零角接缝相遇的盒。连通性描述适用于外包盒；真实次水平集在每一组内的非空性、连通性及极小点唯一性仍待证明。

以第102轮原坐标接触邻域与501盒逐坐标相交，仅有4盒可能相遇。因而接触邻域上的估计仍需和邻域之外的面积证书结合。主工作区从原树重建全部501盒并复算，输出与独立工位逐字节一致。第134轮纯五体下界另已在独立工位完成第二次逐树重放，两个分片集合分别覆盖251和250个原叶。

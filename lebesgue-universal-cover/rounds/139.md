# 第139轮　从五体整数面积下界计算连续门槛的搜索范围

沿每个平移方向，对圆盘与单个定宽体的联合凸包面积使用凸性割线，可把原叶的最小平移半径直接换算成整叶面积下界。将这一估计和既有整数扇面积逐叶合并，得到覆盖全部6,710,314个规范原叶的索引。已有材料能排除的原叶只做整数比较，几何细分集中在剩下的叶上。

| 目标面积 | 仍待几何判定的原叶数 |
| --- | ---: |
| 0.83731 | 614 |
| 0.83732 | 220,284 |
| 0.83735 | 531,023 |
| 0.83745 | 1,026,024 |

独立工位分别从工作层和归档层生成索引，并从原树重建规范掩码。主工作区核验了排序整数向量的摘要、单调性及上表四个门槛的精确整数查询。0.83735 的候选中有21,393叶得到相同的面积下界约0.83734267295，来源是三边形旧径向截断。提高门槛时，不能把只在截断内部成立的材料分数用到整叶。一般覆盖的认证下界仍为0.83731。[径向估计、门槛和复算](../proofs/tomar-multi-target-scores.md) · [逐片摘要](../computation/tomar-multi-target-scores.json)

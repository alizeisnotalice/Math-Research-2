# 第73轮　十二点见证的连续刚体摆放

第67轮在切深 δ=0.0000155 时排除了十二点集合 X 的全部十二个固定六边形对称摆放。本轮给出一个连续转角的正面见证。将 X 转动 4.489 弧度，再平移 (−0.0156,0.0294)，十二点全部进入候选体的一个十七顶点内接多边形，各支撑线的最小内侧距离超过 0.00253354。同一摆放在切深 δ=0.005 时也通过。

在 δ=0.0000155 下，将整圈长度按 131072 等分计量。利用内接多边形认证 13445 份角长度允许平移，利用外支撑线的非负组合认证 116472 份角长度排除全部平移，剩余 1155 份。旋转加平移已经包含这个反射对称见证的全部等距像。每项通过或排除适用于整个闭角格。

主工作区在 160 位 Arb 下复算显式摆放，另从第67轮坐标证书重跑全部 8959 条区间判据。结果与归档的压缩证书解压后逐字段一致。推导及全角重算命令见 proofs/eh-continuous-witness-placements.md。本结论的对象是有限集合 X；含 X 的定宽补全能否整体放入这些候选体，仍需单独检验。

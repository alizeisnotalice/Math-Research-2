# 第76轮　四体八维放置的严格局部极小

圆盘、正 Reuleaux 三角形、五边形和七边形独立放置时，存在一个面积严格介于 0.83649045546121306 与 0.83649045546121308 之间的严格局部极小点。后一个数给出四体全域最小面积的可行上界。一般万能覆盖的上界仍由第67轮承担。

四条共同支撑线的接触方程把候选曲面化为两个角参数。区间 Newton 收缩和正定 Hessian 验证该接触构形内的唯一驻点；42 项支撑端点比较核对弧链。对余下六个横向自由度，七条内扇面积的梯度凸包包含以零为心、半宽 1/10000 的立方体，故沿横向有严格的一阶面积增长。合并两种估计，得到完整八维放置空间中的局部极小性。

主工作区用 Arb 重算 computation/certify_four_body_contact_stationary.py 与 certify_four_body_contact_transverse.py。两份 JSON 均与独立工作区逐字节一致。定义方程、参数区间及所有证明步骤见 proofs/four-body-contact-stationary.md。是否存在别处面积更小的放置，仍待全域证明。

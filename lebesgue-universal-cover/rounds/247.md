# 第247轮　加入完整十一点的全域面积代价与七输入真实摆放

固定五个直径一曲体（圆盘和阶数 3、5、7、9 的正 Reuleaux 曲体），它们的独立摆放最小凸包面积记为 $M_5$。取第237轮的有理十一点集 $Q$。每个输入可独立平移、旋转、反射。定义 $M(Q)$ 为这六个输入的共同凸包最小面积。则
\[
 M(Q)>0.83730,\qquad M(Q)-M_5>0.0000049937789747565 .
\]
对每个真子集 $E\subsetneq Q$ 都有 $M(E)=M_5$。每次单删后的严格内含摆放给出上端，随输入增加的单调性给出下端。与第237轮的严格不可放结论相比，本轮定量给出完整输入在全域迫使付出的面积。[十一点与单删姿态](237.md) · [五曲体最小面积](158.md)

在原始 6,710,314 枚 Tomar 闭盒的纯五体外围下，门槛 $0.83730$ 留下 541 枚完整原叶。对每枚原叶及其子盒，使用 256 个上支撑法向，每种手性覆盖 384 个闭角格，平衡三法向消去独立平移。超额投影与圆盘或原曲体内弦形成面积帽。所有严格比较采用定向区间或整数算术。主工位从源码编译整数核，重做全部 20,794,763 个节点，得到 9,514,678 个纯五体终端与 882,974 个需要 $Q$ 的终端。逐行输出与冻结的 541 行完全一致，SHA-256 为 `119e60a539e2739cbc01663d7daf8b58ab22ae21ca4e327458370b9b19d1d439`。例如总节点恰等于两倍终端总数减 541。结合外围和紧性可取严格门槛。[完整证明、整数核及重放数据](../computation/eleven-point-quantitative/global-083730.zip)

作为可行对照，另在这六个输入上加入原三十点，七输入的真实可行凸包面积严格夹在 $0.837761800093736973$ 与 $0.837761800534230504$ 之间。仅取第二波 Metal 的原始输出，已经有面积小于 $0.837762037519341639$ 的姿态。前者比第237轮同一组七输入的旧姿态节省严格超过 $7.71085060761\cdot10^{-7}$。本机 Apple M6 实做四波 7,340,032 次候选评分，命令缓冲区累计 17.4040911666661486 GPU 秒。主工位对精化及原始姿态分别运行原几何核，每真弧 32,768 及 8,192 段，并逐项复核四波计数。搜索值仅用于选姿，两个面积上端都来自严格包围。[姿态、有理面积回执与 Metal 源码](../computation/eleven-point-quantitative/seven-metal.zip)

两个 ZIP 分别为 80,886 与 132,581 字节，SHA-256 分别为 `9102025e7fce2f7dcf955c107fad2861a7e48b796a51f4650eccfe045f4947fb` 与 `57a1b0cf6abb5f6f5872bf2495cdd88d021912a1ece8b26d7194abe76dbf4a23`。各自的证明或 README 含复算命令、输入哈希及所需软件。一般问题的下端仍由第245轮给出。

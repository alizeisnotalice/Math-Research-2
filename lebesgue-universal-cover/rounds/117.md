# 第117轮　固定 EH 单弦临界深度的双边认证

固定 σ=1.5497° 和 EH 下端 T，保持第112轮两条 AH 裁线。切深 0.0005522 时，所得凸体是万能覆盖，面积严格位于

    (0.844093401087945927979259982635382690865,
     0.844093401087945927979259982635382690950).

同一 EH 单弦在深度 0.00055222 已不能容纳一个明确构造的宽一输入。这个反例也适用于额外切去两线 AH 帽的候选体。由弦帽的嵌套性，固定族的临界深度落在长度为 2×10⁻⁸ 弧度的区间内。这里的不可行结论允许任意刚体运动。

主工作区逐字节重放了可行端的 EH 单帽证书与不可行端的 18 点见证证书。复合 AH 时，围绕共同端点转动 EH 直线，支撑损失严格小于 0.000015955815，扣除后同一摆放的统一余量仍大于 0.000124589。随后以有理数分别扣除两个真实帽面积。复算单帽和反例的命令见[临界区间证明](../proofs/eh-fixed-family-sharp-bracket.md)。在 computation 目录执行以下命令重算复合上界：

```sh
python -B certify_ah_envelope_at_depth.py 0.0005522 eh-cap-switch-joint-552p2-revisit-ah.json
```

[复合上界的精确回执](../computation/ah-envelope-eh-552p2.json)。一般下界仍为第113轮的 0.8371。

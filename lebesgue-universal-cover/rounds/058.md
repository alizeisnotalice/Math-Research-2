# 第58轮　三体零转角的严格局部极小

记 M₀ 为 D、B₃、B₅ 在相对转角为零时的最小凸包面积（第51轮）。存在 ε>0，使任意 0<|φ|<ε 及任意两平移下的凸包面积严格大于 M₀。

首先证明零角切片中的最优平移唯一。水平极小点必须落在严格凹的接触曲线上，联合凸性排除多个水平极小点；对纵向平移，顶部与斜向三重接触所需的零变化速度比例异号，只在两个速度都为零时相容。随后保持三处接触方程，得到正角侧的一条补偿平移曲线（横向位置 a 保留为自由参数）。圆弧与线段积分的一阶角项由反射恒等式精确消失，160 位 Arb 重算二阶系数落在 (0.15,0.16)。这是按 φ² 计的系数。对应上边界法向导数严格在 (0.005,0.006)，确定了正角侧分支。

还须控制离开这条补偿曲面的放置。六个共线中间材料点各可选择插入或不插入，给出 64 个内扇面积下界。横截的三个独立梯度差张成三维空间，零点在梯度凸包内部，所以横截偏移会产生严格一阶增长。最后由有限面积次水平集有界、面积连续及零角最优平移唯一，排除趋于零角而逃出上述局部放置的序列。详细量词、符号分支和一阶消失的解析推导见 proofs/058-three-body-twist.md。

在 computation 目录运行 python -B certify_three_body_symmetric_slice.py 与 python -B certify_three_body_twist_jet.py。主工作区重新计算两条支撑线上材料点的次序、隐函数导数与二阶面积包络；后者与独立工作区的证书逐字节一致。输出为 058-slice.json 和 058-twist.json。本轮给出开角邻域的存在性，尚未定量给出 ε，三体全角最优性仍开放。

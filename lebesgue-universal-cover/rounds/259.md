### 两个姿态来自同一输入

取任意输入的宽一补全 \(K\)。由第255轮的首次 EH 摆放定理，选择满足旧 AH 及实际十一面 EH 的刚体副本。新物理图参数为 \((f,b,\epsilon)=(.336,.383,.018)\)。重建的 4,020 个首命中盒逐一满足 \(y-.518>.0219923313800882601710\) 及 \(\|x-C_0\|^2-1>.0004797991054809770757\)。因此首副本越过新线时，可对它应用原固定反射 \(Q_A\)，得到仍满足母域和 EH 的第二个副本。若两者都越线，把第二个材料点拉回首副本，就能在同一个 \(K\) 上使用双命中的有序分类。恰触保留半平面边界的摆放已经可用。参考参数端点为 \(.43\)，伙伴物理图的验证端点为 \(.62\)，面积积分使用完整的真实曲边。[首次摆放与反射](../proofs/sigma154-ah429-eh550-composition.md) · [双命中归约](../proofs/sigma154-deeper-composition.md)

### 固定铰点的全参数面积障碍

设其余几何固定，允许 \(0\le d<\pi/2\)，并要求新删掉的配对弧 \(q(w)\) 均有 \(w\le .43\)。若 \(b=-D/|D|\)，在 \(w=.43\) 处 \(b\cdot(q-P)\)、\(\det(b,q-P)\) 都为正。临界角为
\[
d_*=\arg_b(q(.43)-P)=.01871413993999316874486354358813\ldots .
\]
若 \(d>d_*\)，连续性使一些 \(w>.43\) 的真弧点也被删去，故题设推出 \(d\le d_*\)。原直边与深转线的法向的非负组合给出每一浅转线的法向，三者共有铰点，因而 \(K_{d_*}\subset K_d\)。对临界角两侧的有理夹逼分别重算真交点、原 Gibbs 面积及全部十一条 EH 的扣量，得到
\[
 |K_d|\ge|K_{d_*}|>.844086085046925304980185980482266994827>B.
\]
要靠这一族越过该面积障碍，必须让裁切进入 \(w>.43\) 的实际配对弧。定理的假设固定铰点、原直边、旧 AH 和十一面 EH。[临界角、全真弧与面积重算](../computation/turn01300-universal/parameter-barrier.zip)

令 \(L(d)\) 为真实 AH 扣除面积。在 \(.01250\le d\le .01871\)，射线与真弧的交点 \(q=q(w(d))\) 唯一。绕 \(P\) 的极坐标面积公式给出
\[
 L'(d)=\tfrac12 |q-P|^2,\qquad
 L''(d)=\frac{(q-P)\cdot q'(w)}{\frac{d}{dw}\arg_b(q(w)-P)} .
\]
在 \(w\in[.325,.430]\) 上的 1,050 个闭格以区间导数得到 \(.00046751978<L'<.00064551788\) 和 \(.02461954<L''<.03300617\)。这给出转角变化对应的真实面积变化范围；每个新深度的一般摆放仍需覆盖其全部输入。[两个导数的定向区间计算](../computation/turn01300-universal/area-variation.zip)

### 复算

Python 3.13.18、python-flint 0.9.0。主工位从新目录重算首次 EH、新物理图、真面积与伙伴接口并比较总回执；各分段另有独立逐原核的数值复算。总回执的 \(\texttt{complete}\) 表示全部 70 组拼接通过，\(\texttt{full_interval_replay}\) 表示本次入口是否重跑每个底层核，\(\texttt{independent_replay_ledgers_bound}\) 表示已把各段复算账本与冻结输出绑定。障碍包与导数包在独立目录均从源码复算。在课题目录执行以下命令，三个归档分别解压到新的目录。

~~~sh
D=computation/turn01300-universal
unzip -q "$D/certificate.zip" -d "$WORK/cover"
python -I -B "$WORK/cover/release01300/verify01300.py" "$WORK/covered"
cmp "$WORK/covered/cover-result.json" "$D/result.json"
unzip -q "$D/parameter-barrier.zip" -d "$WORK/barrier"
python -I -B "$WORK/barrier/kit/replay.py" "$WORK/critical" --full
unzip -q "$D/area-variation.zip" -d "$WORK/variation"
python -I -B "$WORK/variation/variation.py" "$WORK/barrier/kit" "$WORK/derivatives.json"
cmp "$WORK/derivatives.json" "$WORK/variation/variation.json"
~~~

全域入口附加 \(\texttt{--full}\) 可在一个新目录从头运行全部原区间核。

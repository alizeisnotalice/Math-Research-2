# 第285轮　固定正六边形及两条可移动斜帽的全族面积障碍

**整个两帽族的判决。** 取 \(H=\{x:x\cdot u(j\pi/3)\le1/2,\ 0\le j<6\}\)，其中 \(u(t)=(\cos t,\sin t)\)。设 \(m_j\) 的方向为 \(31.54^\circ+60^\circ j\)，且 \(B=.844082046521218581802948589770767704354\)。每个宿主 \(C\) 允许全部直径一输入各自平移、旋转和反射。如果 \(C\subset H\) 凸且普适，且 \(h_C(m_3),h_C(m_5)\le1/2\)，则
\[
 |C|\ge .844082116398457665703960 > B.
\]
更一般地，若分别把两帽向外移动，两个位移都至多 \(1.04\times10^{-7}\)，仍有 \(|C|>.8440820465708625525996544>B\)。故在同一六边形内达到 B 时，至少一条原法向的支撑必须严格大于 \(.500000104\)。若只改变两帽的角度而保持原截距，至少有一条须转过 \(0.0000103208769^\circ\)。其余边界可自由设计。[定理、完整姿态枚举和整数证书](../computation/fixed-two-caps-seven/excluded.zip)

**两项面积为何能相加。** 由居中圆盘、定向正三弧体、四组有锚点的透镜及强制交点得到有理多边形 \(D\subset C\)。在 \(x\in[-.160,.04025]\) 的268个结点上，用4,372个真实定宽五角完成全旋角根隔离。每体剩两个姿态，任选其一都必须支付与之配对的柱高。401,149个配对共1,564,530个 \(4\times10^{-8}\) 高度单位，在同一列同一副本内互不交叠。扣除 \(D\) 上边界与梯形积分的精确差额后，面积下端为 .844080778044788785470918。七个真正非正则七弧体在条带外另强制 .000001338353668880233042，已核遍独立选择姿态的128个组合。[先导有理匹配](../computation/fixed-two-caps-seven/weighted.zip) · [最终复算数值](../computation/fixed-two-caps-seven/result.json)

**两条线可独立外移的理由。** 令 \(U\) 的支撑为 \(1/2+\sin(3t)/16\)。以它作 Minkowski 侵蚀，对外移上限 \(\delta\) 取 \(\lambda=(225/14)\delta\)。逐一核实4,415个带标记五角、七个七弧体和四个透镜的姿态。所得 \(C'=\{x:(1-\lambda)x+\lambda U\subset C\}\) 保留前述计算所用的全部材料。16,384格定向积分给出 \(V(C',U)>.82319357472209281159\)，而 \(|U|=15\pi/64\)。混合面积公式于是给出
\[
 |C|\ge (1-\lambda)^2(.844082116398457665703960)
       +2\lambda(1-\lambda)(.82319357472209281159)+\lambda^2\,15\pi/64.
\]
在 \(\delta=.000000104\) 仍严格超过 B 达 \(4.9643970\times10^{-11}\)。只在原 \(H\) 内使用了这些姿态和支撑条件。一般凸万能覆盖的上下界见[当前总账](../STATE.md)。

**原候选为何看起来可行。** 一座390顶点宿主的真面积为 .8440816602658103808254…。它通过420,703个五角测试，并覆盖416,676个闭参数盒。三个真实七弧体分别以超过 .00003416、.00011610、.00012466 的全姿态余量排除它。另构造一座403顶点宿主，面积 .84408204108064092900023221883968…，包含五个真实七弧体各自半径 \(2.4275\times10^{-9}\) 的 Hausdorff 邻域。若坚持保留本轮选定的526点初始核，仅要求装入所列七个七弧体及一个五角，即便去掉两帽、只留 \(H\)，凸包面积也严格大于 .8440820473220627967147。该结论除保留核的要求外允许任意凸修补。[失败姿态、实际修补与连续邻域](../computation/fixed-two-caps-seven/neighborhoods.zip)

**核验与复算。** 主工位在新目录逐一重建原始圆弧、完整相容根、全部匹配、条带外面积、343个谐波根盒及放宽面积，在另一目录用 Clang 从源重建420,703项几何扫描和闭盒覆盖。使用 Python 3.13.18、python-flint 0.9.0、Arb 与有理整数。运行 `python -I -B replay.py NEW_DIRECTORY`，加 `--rebuild-base` 可重跑旧 C++ 几何扫描。[统一入口](../computation/fixed-two-caps-seven/replay.py)

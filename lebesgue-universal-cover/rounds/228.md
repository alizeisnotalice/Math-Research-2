# 第228轮　五个新增输入的最小单面宿主与自由重摆代价

取第223轮单面放宽后已确定的宿主 \(C_*\)，固定其全部材料，加入五个明确的定宽五边形。原六边形的 \(60^\circ\) 面可外移至多 \(3.01\times10^{-7}\)，其余五面保持。前四体记为 \(X_1,\ldots,X_4\)。第五体取 \(P(.819236970703,.034894452004)\) 时，所有五体各自重摆后的最小面积满足
\[
 .8440820130770037<M_5<.8440820140975347851512<B .
\]
允许越过斜帽仍可证明同一下端；给出的可行上端同时满足两条原斜帽。若首体取正手，面积增量必大于 \(1.30\times10^{-7}\)；反手时，首体和第五体合力迫使增量大于 \(9.22\times10^{-8}\)。双手性角域和共有平移条带均经整数、有理和区间核验。[姿态、全部参数及证明](../proofs/folded-free-repair.md)

将第五体另取为 \(Y=P(.811550290734,.034070)\)。先把前四体放在一个固定的反射构形，所得真实宿主 \(D_-\) 的面积位于 \((.8440820083564575,.8440820090895462)\)。若须保留整个 \(D_-\)，任意方向扩张以放入 \(Y\)，最小总面积严格位于 \((.844082054,.8440820774558181)\)，至少超过 B 档 \(7.47878\times10^{-9}\)。若只固定 \(C_*\)，同样的五体可重新摆放，达到面积小于 .8440820067607142，两种最优值严格相差超过 \(4.72392\times10^{-8}\)。

六面外扩的共同面积由平面混合面积计入，避免在相邻面的外伸区域重复计价。面积至多为 B 且容纳 \(C_*,Y\) 的任一凸宿主，对其中任一定宽一体的已摆姿态都须满足 \(q=1/2+h_1-h_0-h_2>-2.8\times10^{-7}\)。对 \(X_1\) 的指定闭参数盒，全部反手可行角落在 \([239.9975^\circ,240.00085^\circ]\)，正手尚保有零度附近和 \([354.01^\circ,354.28^\circ]\) 两个角域。这个有限输入结论保留了整套原150体、第151体和第223轮的参数线段，一般凸万能覆盖的严格上端仍见第225轮。[全部重算的数学回执](../computation/folded-free-repair/verification.json)

主工作区用 Python 3.13.18、python-flint 0.9.0、192位 Arb 实际跑完默认12项和另行双体联合排除，核对了80个公共依赖及15份本轮源文件和输入。由课题根目录运行，WORK 在 computation 目录以外。

~~~sh
python -I -B computation/folded-free-repair/verify.py computation "$WORK" "$WORK/all.json" --jobs 4
python -I -B computation/folded-free-repair/verify.py computation "$WORK" "$WORK/pair.json" --section pair
~~~

# 第110轮　任意放置的排序支撑恒等式与平移罚项

本轮转向不依赖参数网格的面积估计。对任意有限族平面宽一凸体，将它们的支撑值逐方向排序，可将全体凸包面积精确写成各体面积、凸包周长、中间排序层均值及非负 Fourier 余项之和。等式适用于任意平移与转角，以及支撑函数发生平手和边界不光滑的情形。

两个直接后果对后续的全域估计尤为重要。对于三体，若 H_ij 是两体凸包、m 是三项支撑值的中位数减 1/2，则

    |H| = (|H₁₂|+|H₂₃|+|H₃₁|)/2 − π/8 + (1/4)∫(m′²−m²).

中位数余项非负；任一高于一次的奇数 Fourier 模都给出可相加的面积下界。对于圆盘与正定宽奇边形 B_n，则得到任意平移长度的显式面积罚项和唯一最优同心放置。特别地，同心极小面积恰为 π/8+n tan(π/(2n))/4。一般平移罚项在中心附近的二次系数是尖锐的。

[完整证明、等号情形及多体公式](../proofs/global-support-order-statistics.md) · [独立数值交叉检查](../computation/support-order-checks.json)。数值检查用边界点的凸包与支撑积分分别计算三个不同的光滑定宽体，并对四个奇边形和不同平移检查罚项；证明使用支撑函数面积公式、对踵关系和圆周 Fourier 展开。在 computation 目录运行 `python -B check_support_order_statistics.py` 即可复算数值部分。

本轮未得到一般最小面积的新数值界。下一步需要在自由角度及平移变化下统一控制中间排序层；仅估计每个体的平移长度会丢失相对方向带来的面积增量。

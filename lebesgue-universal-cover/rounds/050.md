# 第50轮　排除第13轮八体可行构形的第九个定宽体

取 h(θ)=1/2+cos(5θ)/200+3cos(15θ)/1792。奇次数保证宽度为一，h+h″≥1/200 保证严格凸。把这个体加入第13轮使用的八体族。令 C 为第13轮固定放置的真实凸包，H 为其认证外包。则 H 加上半径 17/20000 的圆盘，仍容不下这个新体的任何等距副本。

按第49轮的三法向加权支撑差证明，在 2048 个有理半角参数格中逐个消去平移，并用 |h′| 上界控制整格转角。主工作区以 Python 3.15.0 的 Fraction 复算。最弱格的严格有理下界大于 7/8000；展示值约 0.0008882403621497804。余弦的偶性覆盖镜像。改变两个 Fourier 系数的绝对值之和至多 1/50000 时，支撑差损失至多 1/50000，曲率半径损失至多 224/50000 < 1/200。因此同一个膨胀外包排除整个系数族。

固定 Fourier 系数，若八体原始平移和弧度角的每坐标改动至多 17/50000，则每个原材料点移动至多 (√2+1)·17/50000 < 17/20000，各体本地原点都在该体内。变化后的凸包再膨胀 1/40000，仍然无法放入新体。对固定 C，第49轮的截冠三角形估计还给出加入任意副本后面积严格增加超过 867/727400000。第13轮证得的是特定八体放置可行；新增约束在远离上述邻域的放置上能迫使多大面积，仍待证明。

在 computation 目录用 python3 -B certify_fixed_cover_fourier_obstruction.py eight --verify 050-obstruction.json 重算 050-replay.json。宿主直接取第13轮外包证书，并校验其哈希。

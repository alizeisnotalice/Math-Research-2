# 第81轮　切深 0.0001 的凸万能覆盖

沿用第80轮的固定斜角，将 EH 端点沿 C₃ 单位圆移动 0.0001 弧度，所得凸体仍是万能覆盖，且 Λ < 0.844093571996149401。

若第62轮反射分支的两次摆放都进入 EH 耳，选择相容函数在 30° 非负的一侧。新参数下，同一体的相容函数在 31.1° 小于 −0.00010064354，故闭区间中存在根。按第80轮的根条件对偶法分成 16 个闭角格，32 条非六边形边的最小严格余量超过 0.00000255074。根处各边取同一旋转和平移。旧分支的几何不等式也由同一入口在新参数上重算。

主工作区以 160 位 Arb 重放 549 份对偶证书和 9976 条单位盘切线，输出与独立工作区的 eh-root-conditioned-100.json 逐字节一致。新增切除面积大于 0.0000000223903403585955555；以 Fraction 从 047-center.json 原面积上端减去这个切除面积的区间下端并向上舍入，结果见 computation/081-area.json。

从 computation 目录运行：

```sh
python -B certify_eh_relocation_root_condition.py 0.0001 31.1 OUTPUT.json --angle-cells 16 --replay eh-root-conditioned-100.json
```

全局分支和相容根证明见 proofs/eh-root-conditioned-relocation.md。一般下界沿用第77轮。

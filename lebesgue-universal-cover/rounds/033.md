# 第33轮　固定坐标候选的五种共同放置

每个已在 P 中的定宽一凸体都能用五种运动之一整体放入最终切除后的闭集。第26轮给出直径补全与初始放置，因此该闭集也容纳所有直径至多一的平面集合。证明见 proofs/033-fixed-cover-relocations.md。

证明分别追踪 AH、EH 的严格进入条件，先证所选等距像回到 P，再应用第28轮同一位置的包含结论。用凸体内部稠密性处理切除边界的接触。主工作区 Python 3.15.0 实际运行 python3 -B computation/certify_cover_relocations.py，输出在 computation/033-cover-relocations.json。其有理区间检查涵盖两条 F 切线的交序及端点距离，精确角运算核验帽映射，有限枚举核验分支穷尽性。

此轮得到指定闭集的覆盖性。给出凸万能覆盖的数值上界仍依赖其全局凸性和面积可加性。

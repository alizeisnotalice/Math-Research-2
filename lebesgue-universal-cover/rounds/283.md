# 第283轮　按三次曲率振幅的全段覆盖与显式单宿主

第三次曲率振幅记为 \(a=A_3\)，总曲率偏幅记为 \(q=\|h+h''-1/2\|_\infty\)。本轮得到两种不同量词的结果。任意直径一输入均可装入预先指定的三个多边形之一，三者面积最大者小于 .844076541772819091385619585133383。若要求同一座宿主容纳一整类输入，则有面积小于 .844081949713 的单一曲边宿主，容纳全部 \(q\le .4946\) 的宽一体。另有面积小于 .844078887615 的单一宿主，容纳全部 \(4q/\pi-a\le .02182\) 以及全部 \(q\le .02132\) 的宽一体。[定理与构造](../proofs/third-amplitude-covering.md)

**三段覆盖。** 低、中、高段对应真实的 60、58、44 边凸多边形。振幅区间依次是 \([0,.07435]\)、\([.073945,.163066]\)、\([.16259,2/\pi]\)。每段都允许其余谐波自由变化。低段最小平衡余量大于 \(2.66673438\cdot10^{-7}\)。中段的两个端点分别留出约 \(7.54\cdot10^{-7}\) 与 \(2.70\cdot10^{-7}\) 的振幅余量。高段全体证书的充分起点小于 .162589052。在每段对所有30个对径组和8120个三元平衡组消去同一输入的一次平移，再从宽一补全回到原输入。单宿主的 \(B=.844082046521218581802948589770767704354\) 目标继续开放。[低段证书](../computation/third-amplitude/low.zip) · [中段证书](../computation/third-amplitude/middle.zip) · [高段证书](../computation/third-amplitude/high.zip)

**单宿主的全局估计。** 对齐 Steiner 中心与三次相位后，所有宽一体满足 \(d_H(K,R_3)\le.3023(2/\pi-a)\)。在三个换号法向插值 Green 核，验得逐点系数 .6046；同一插值的显式点值已达到 \(\pi/(3\sqrt3)\)。将 \(K=(1-2q)D+2qL\) 分解为盘和真正的宽一体，把距离估计改写为到整条盘—三弧体 Minkowski 线段的误差。对线段的后部取凸包并加厚即可得到上面的 .02182 宿主。另将第277轮的真正通用宿主与内含盘插值，得 .4946 宿主。两种构造使用不同的固定集合。前一类含正三弧体并在每个可能的三次振幅上都有输入，后一类允许至界内的全部曲率密度。[连续角核与导数验证](../computation/third-amplitude/stability.zip) · [面积与余量](../computation/third-amplitude/result.json)

**不能直接并入旧宿主的真输入。** 向低段 60 边形添加任意姿态正三弧体并取凸包，增加面积严格大于 .0025；高段 44 边形则存在全姿态内圆障碍。一例真实光滑宽一体的 \(a=.0771104\)，其内圆半径比旧宿主能容纳的最大圆半径至少大 \(6.50194\cdot10^{-6}\)。和直径一盘作凸组合，得到从 \(a=0\) 到该振幅的逐值障碍。重新选择半面可以使一座面积小于 .842804225424 的宿主同时涵盖低、高端中各一整族。[固定宿主的正反两侧证书](../computation/third-amplitude/same-host.zip)

**实际复算。** 从五个公开分卷解包后，主工位重新执行了三段积分与真实面积核、中段全姿态反例、线性稳定性的全角区间核、低高共用宿主核及三段接合和两项解析面积上包。脚本使用 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0，无随机输入。从课题目录运行 `python -I -B computation/third-amplitude/replay.py NEW_WORK`，其中工作目录此前不存在。[统一复算入口](../computation/third-amplitude/replay.py)

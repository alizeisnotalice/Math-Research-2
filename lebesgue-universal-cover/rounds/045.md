# 第45轮　三体最优面积全域下界提高到 0.83477

对圆盘 D、正定宽三角形 B3 和正定宽五边形 B5 的全部相对平移与转角，得到

    0.83477 ≤ m(D,B3,B5) < 0.8347809458776.

上端沿用第42轮的可行放置。下端使用第40轮的全域约化，第一阶段核验 8154 个初始盒，余下 4878 个盒全部进入第二阶段。对每个终端盒，将至多四个内扇的面积用同一组非负有理权重组合，在四个平移坐标的 16 个角点逐一检验。角坐标由区间运算覆盖。第二阶段 9326 个终端全部闭合。证明、冻结输入和全量重算命令见 proofs/045-three-body-weighted.md。

完整两阶段计算由核心研究工作区执行。主工作区逐项复核两阶段账本与有理下端，又选 96 个等距索引的剩余盒按原始鞋带公式重算 250 个盒，复现 173 个成功终端（60 个单扇、103 个双扇、10 个三扇）。另存独立工作区 48 盒的重算记录。主工作区的 96 盒验证命令如下，SRC 为第39轮冻结的上游检出。

```sh
python -B audit_three_body_weighted.py "$SRC" three-body-83477-phase1.json three-body-83477-phase2.json --samples 96 > 045-replay.json
```

这个三体最优值的剩余区间宽度严格小于 0.0000109458776。三体下端同样约束一般万能覆盖的面积；其可行上端只约束该三体族。

# 第217轮 · 深度 .0101 和十一条 EH 裁线的通用上界

在 Gibbs 斜角 \(1.54^\circ\)、AH 铰点 \(.429\)、内转角 \(.0101\) 弧度上，十一面 EH 的闭凸宿主能摆放每个平面直径至多一的集合。其面积给出

\[
\boxed{\Lambda<0.844090575743746447226746535860385722151.}
\]

与第213轮上界比较，用两个宿主的面积区间向下计算，严格节省超过 \(2.84341428364\times10^{-8}\)。与指导文件固定的第199轮宿主比较，累计严格节省超过 \(1.47077747213\times10^{-6}\)。[真实面积与覆盖证书](../computation/sigma154-turn0101/universal-cover.json)

重建实际 AH 首命中的物理区域后，3,699 个初始物理格投影到 70 个参考格中的 5,182 个可达细格。每个参考格按已证导数或锚角条件，在同一输入上找到一处六边形相容根和共同平移，同时满足全部边界。第 0 格保留两种括根情形。以 \(F(23^\circ)\) 的有向锚阈值 \(-2\times10^{-5}\) 分支，所用角括为 \([12^\circ,23^\circ]\) 和 \([35^\circ,46^\circ]\)。在该格的全部75个细格，额外将 EH 行向内预留 \(9.488\times10^{-8}\)，重新检验全部边后，十一面共同摆放的最弱余量仍超过 \(1.31794482844\times10^{-9}\)。全体括根的最弱端点符号余量在第24格，超过 \(2.6450266723\times10^{-6}\)。[第0格原始回执](../computation/sigma154-turn0101/0101-j0-low35-retreat.json) · [共同摆放与曲边面积的证明](../proofs/sigma154-deeper-composition.md)

主工作区从21份选定回执、面积公式和物理格输入重新执行全域合成，70格所选根、姿态和两个宿主的真实面积均与独立工位完全相同。单面 EH 同样得到严格上端 \(.844090575875008122529805876370943371798\)。另外，第213轮的13份摆放回执已全部从各自物理参数重新生成，数值及文件内容逐字节相同。

复算使用 Python 3.13.18 与 python-flint 0.9.0。从课题目录运行下列入口；添加 `--replay-inputs` 及空目录路径即可分别重做本轮全部逐格区间运算。

```sh
D=computation/sigma154-turn0101
python -I -B computation/replay_sigma154_composition.py "$D/0101-physical.json" "$D/universal-cover.json"
```

该结果达到 A 档。一般 B 档及精确最小面积仍开放。

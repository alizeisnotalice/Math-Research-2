# 第32轮　圆盘凸包给出的 Fourier 平移限制

若八体配置的凸包面积至多 419/500，则 Fourier 体的平移向量长度严格小于 12/125。这个结论与其转角无关。其支撑函数在每个方向至少为 283/600，所以该体包含以自身平移中心为圆心、半径为 283/600 的圆盘。固定测试盘半径为 1/2。

将两圆心连线旋到横轴，设中心距为 d，两个闭圆盘的凸包为 C(d)。当 d ≥ d₀=12/125 时，C(d) 同时包含原点处半径 283/600 的盘与横坐标 d 处同半径盘。它们按系数 d₀/d 取凸组合，得到横坐标 d₀ 处的整个同半径盘。因此 C(d₀)⊂C(d)。

在 d₀ 处，用第14轮的512个有理盘内点和这些点缩放 283/300 再平移后的副本，计算两组点的整数凸包。其面积为

    151111124834897074374731074831525387 / 180000000000000000000000000000000000 > 419/500.

故 d ≥ d₀ 的全部位置被排除。在第31轮保留区域内，将 Fourier 平移方盒的每个方向等分为128格。只扣除距原点的最近点也满足 d ≥ d₀ 的完整格。对每个第29轮保留叶，先精确减去其 B3 投影与第27轮的排除交集，再乘以上述格在其 Fourier 投影中的面积。相对原四维平移盒，新增排除 614711/16777216，累计排除 15939863/16777216，剩余 837353/16777216。剩余集合包含圆周附近尚未整体排除的格。

实际运行 Python 3.15.0。复现命令为 python3 -B computation/verify_fourier_radial_filter.py。结果见 computation/032-radial-filter.json。本轮收缩了四维参数域，Λ 的精确值仍开放。

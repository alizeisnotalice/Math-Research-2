# 第77轮　四体八维全域下界提高到 0.83645

一般凸万能覆盖面积 Λ 严格大于 0.83645。对于第76轮的四体最小面积 M₄，本轮下界与已证可行上界一起给出

    0.83645 < M₄ < 0.83649045546121308.

其间距小于 0.000040456。全域下端使用第74轮的整数多扇证明，在新门槛下从原树重新计算；局部极小的可行性给出四体上端。

前两层依次验证 796326 和 12529 个原叶。余下 50 个都来自分片 6、14 和 17，数量依次是 6、11、33。第三层将圆盘材料点数增加到 512，对 B₃、B₅、B₇ 每段圆弧各取 128 个点，重算材料成员资格，并从原树重建剩余叶的有理端点。三片分别经 6468、5691 和 22135 次判断全部关闭。三层共作 6316932 次盒判断，原叶总数为 808905。关于平移根盒外部与规范角的估计也在新门槛重算。

在 computation 目录运行以下命令。CERT8 取第68轮固定上游版本的原始分片目录，两个工作目录取不同临时目录。第一条按设计以状态 1 输出 50 个剩余叶，第二条逐叶结清。成功标准是两个回执相互绑定、输入完整且最后没有剩余叶。

```sh
python -B replay_four_body_multifan.py CERT8 WORK1 first.json --target .83645 --depths 17 32 --calls 511 16383 --workers 2
python -B finish_four_body_multifan.py CERT8 first.json WORK2 final.json
```

主工作区实际输出为 077-first.json 和 077-last.json。完整多扇下界及其向上取整见 proofs/four-body-global-multifan.md。该计算不能判定第76轮严格局部极小点的全域最优性。

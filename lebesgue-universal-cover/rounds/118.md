# 第118轮　两段必含边界与整个正转裁线族的面积下界

固定 Gibbs 角 1.5497°，保留旧 AH 截角并在第117轮的嵌套弦族内自由选 EH 切深。AH 可同时加入任意多条正向转动的直线。在这个构造族内，每个仍然万能的凸覆盖体面积都严格大于 **0.844086034386379**。结合第117轮的可行构造，整个族尚可能改进的面积小于 0.000007367。该下界只适用于指定构造族。

证明先构造必须容纳的定宽输入。任一位于旧截角域内的闭万能覆盖都必须保留 AH 原直边从参数 0.429 到 1 的整段、相应的配对弧及与其相接的真圆弧。两个必含端点给每条候选裁线的斜率与截距施加线性不等式；连结这两端点的固定弦统治所有这些线所能移去的区域，因而也控制无限条裁线的交。主工作区复算了 68,646 和 24,000 个参数与角度的联合区间，并以 64 格、10 阶有理余项计算固定弦帽面积。最后用第117轮不可行端点的 EH 面积上界统一处理全部可行切深。

第113轮一般下界的第二次从空目录全量复算亦已结束。主工作区重新生成材料表，计算全部 6,710,314 个规范叶和全部加深判断，重新打包并解包。1024 个逐叶整数分数数组逐字节相同；所有首遍 JSON 仅执行时间不同，加深 JSON 仅因父回执的哈希随计时变化而不同。两次均得到同一严格下界及相同的逐盒计数。

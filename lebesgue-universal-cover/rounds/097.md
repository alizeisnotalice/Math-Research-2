# 第97轮　正定宽九边形与四体最优凸包的严格分离

记 K* 为第95轮求得的唯一四体极小凸包。将它与半径 r 的圆盘作 Minkowski 和，求允许任意平移、旋转、反射的正定宽九边形 B₉ 能放入所得外扩体的最小 r。严格结果为

$$0.00394138015 < r < 0.00394138020.$$

对每个转角闭格，选择三个有理单位方向，使其正权组合为零。在三条支撑不等式上取同一组合消去平移；共用41个闭格覆盖全部转角。另一侧显式给出 B₉ 的转角和平移，逐一检查37个法向子区间，得到上端。对四体面积不超过 0.836490455462 的任意近极小配置，先用第95轮的全域结果归入局部窗，然后由面积增长式控制六个平移和两个接触角；所得凸包在适当共同刚体变换后距 K* 的 Hausdorff 距离小于 0.000017269141。因此同一外扩半径对所有这些配置都严格大于 0.00392411。

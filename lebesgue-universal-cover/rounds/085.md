# 第85轮　五体十一维下界的全域重放

圆盘和定宽三、五、七、九边形均有直径一。任何凸万能覆盖都包含这五个测试体的某组刚体放置的凸包。固定圆心和三角形朝向后，对其余十一维参数全域计算，得 **Λ > 0.83661**。Tomar 预印本的正式下界为 0.8366，本轮用其原始分割树核验更高门槛 0.83661；精确最小面积仍开放。结合第84轮得到 **0.83661 < Λ < 0.844093570875584138**。

原始分割树采用 [Tomar 冻结版本](https://github.com/tejasvi/lebesgue-cover-bound/tree/10af98606c98ca9ffd0d9f402cae1e2efe74b792) 的 cert11d_08366。本机和 MacBook 从原叶实算，共覆盖 2,048 个根分片。本机完成 1,028 片、7,713,103 叶，MacBook 完成 1,020 片、8,480,299 叶。整数面积判据关闭 16,181,405 叶，80 位 Arb 关闭剩余 11,997 叶，未决数为零。整数与 Arb 的子盒求值次数分别为 1,767,349,652 和 16,955。根箱外四项下界均超过 0.85914。

整数面积接受门槛向上取整，且严格超过按相同比例放大的 0.83661。Arb 只接受下端严格超过门槛的盒。规范根箱紧，五体凸包面积随放置连续，因此其最小值也严格超过门槛。

主工作区从公开 ZIP 重新解包，核对全部原树、回执绑定、见证表、根箱外界和叶计数；独立生成的汇总与存档逐字节一致。包内 6,146 件，4,518,851 字节，SHA-256 为 e08f972ee6a4c8422b9fbcf53c45c4c5826a0c5c3468e1898eb0af050b11e86a。编译缓存目录已匿名化，数学数据、叶编号和判定可由公开材料核验。

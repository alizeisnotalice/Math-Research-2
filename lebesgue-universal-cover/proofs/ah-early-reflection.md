# 两线候选在第8参考格提前使用反射高根

两条新 AH 线分别取 \((0.427,0.001445142540)\)、\((0.4245278003,0.001817679638)\)。对从同一真实帽图得到的第8参考格，即 \(w\in[0.08,0.09]\)，采用高根及第9格起先前使用的反射手性，将转角参数取为 \(120^\circ-\phi\)。原来的未反射角格在 `Z-Tprime:16` 的区间估计出现负余量。

整个闭格可共用 \([16.02^\circ,19.49^\circ]\) 这一个角括。把参数格细分为75格，逐格使用 `ah-coupled-brackets.md` 的同源五锚点误差。两端检查原相容函数的正、负号。根端净余量始终大于 \(1.0185739\times10^{-6}\)。对括内32个角格分别直接放置反射姿态，同时检查所有直边及完整 \(0.000555\) EH 包络，最小支撑余量大于 \(0.0000418820339\)，落在首个参数格、首个角格的 `Z-Tprime:16`。引用该证书时需与同一参数、同一图域和同一 EH 外包络的其余各格证书拼接。

图域的配对弧远端为 \(0.10\)，物理投影下端为 \(-0.105\)，偏导管半宽为 \(0.0026\)。对原参考格的两坐标分别在零划分为四个管矩形，直接验证全管导数界。可从课题目录使用 Python 3.13 和 python-flint 0.9.0 重放。

```sh
python -B computation/certify_ah_early_reflection.py computation computation/ah-early-reflection-parameters.json OUTPUT.json
```

# 同一 30 点输入对五体高门槛全部剩余闭叶的排除

记 $P$ 为 finite-point-leaf-input.json 中已逐对核验直径、关于横轴对称的三十点有理输入，记 $T=0.837295006222$。直径一圆盘、四个正定宽奇边形 $B_3,B_5,B_7,B_9$ 和 $P$ 的各自刚性副本，在任意独立姿态下的共同凸包面积严格大于 $T$。这条结论给一般凸万能覆盖下界。它使用原五个曲边体和一个有限输入。第 180 分片的另外两个完整原叶得到更高的 $0.83730$ 排除。

## 全域量词

刚体运动允许平移、旋转和反射。把圆盘和 $B_3$ 用作全局规范后，沿用 $0\le\theta_5\le\pi/15$ 的原五体规范区域。对整个放置施加同一等距变换只改变新输入的允许姿态，因此原来的角域约化继续适用。

假设六体面积至多 $T$，则原五体面积也至多 $T$。原五体四级整数证书已经从 6,710,314 个规范原叶中将所有这种放置定位到 19 个原根上的 501 个原叶；见 five-global-localization.json 和该证书的独立全量重放。逐项核对 501 个二元组（分片号、0 基前序位置）后，对其全集加入同一个 $P$。每个证明从该原叶未经裁缩的全部十一维闭盒出发，并同时覆盖新增输入的全部刚体运动。

每个新输入角格选定三条法向、三个固定材料点的编号。严格算法逐项计算三条法向的整数平衡权重，核验各格中点偏转的正弦余弦界。每格内的加权材料支撑下端只用三十点坐标及格角计算，平移项精确为零。原五体支撑上端的端点插值、双倍有向面积的整盒扇形下端以及有理尖帽的面积增量，详见 finite-point-five-body-leaf.md。全域版在 384 格合计使用 2493 个候选三元组。各原叶可在其子盒中使用不同三元组，全程使用同一输入且每个角格都须通过。第 180 分片原叶 23955 的旧五体可行面积严格小于本门槛。

## 成功子树

探索时逐次提高原叶的调用上限。输入 501、272、32、3 个原叶的四阶段分别余 272、32、3、0 个。发布账本仅保留每原叶第一次成功的整棵二叉树；在其他预算下失败的尝试不构成证明的一部分。成功树共 43,425,649 个节点，旧五体单独关闭 16,172,403 个终端，三十点新增支撑关闭 5,540,672 个终端。349 个原叶实际调用新增点排除了至少一个终端。其余 152 个由较深或较密的旧体整数扇完全排除。总节点数等于总终端数的两倍减去 501。

每个原叶取整数门槛 $\lfloor 2^{57}T\rfloor+1=120666927296658443$。成功子树中每个终端的六体面积均至少是该整数除以 $2^{57}$。其余规范区域由前序五体证书的原五体面积或严格径向界排除，径向界适用于六体面积至多 $T$ 的反证假设。两部分合起来排除全部六体面积至多 $T$ 的摆放。有限体族的最小面积达到：固定圆盘后，对凸包的任一点 $x$，取垂直于 $x$ 的圆盘直径作底，三角形面积给出 $|x|\le2A$。因此有界面积次水平集上的所有平移有界，各体转角和两个手性构成紧集，凸包面积连续。由此六体最小面积严格大于 $T$，一般凸万能覆盖的最小面积至少为六体最小值。

## 重放

在 computation 目录运行下列命令，CERT 为冻结的 Tomar v9 证书，T32、T64 为分别以每弧 32 和 64 等分生成的材料表，NEW 为尚未创建的可再生成果目录，CACHE 为 Clang 共享模块缓存。

```sh
python -I -B tomar_fan_table.py CERT T32 --subdiv 32
python -I -B tomar_fan_table.py CERT T64 --subdiv 64
python -I -B replay_finite_point_global.py CERT T32 T64 NEW CACHE --workers 6
```

入口逐点检查两张材料表、重新编译带溢出陷阱的整数核、核对原叶集合和每棵成功树的节点数、两类终端数和深度，最后独立验证两个更高门槛原叶及对应的五体真低解。可用 --extra-only 单独快速重放两个额外块；可用 --parts 180 等参数作分片核验。若还需在同一入口从零重算 501 原叶以外的全部五体区域，添加 --replay-five。全域五体定位与三十点补域均已在独立工作目录完成全量复算。

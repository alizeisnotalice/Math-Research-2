# 五体面积的平移端点判定

在一个十一维闭盒上固定一条经有向边检验的材料链。旧面积核已证明链面积与逐边同体圆弓增益之和能作五体凸包面积的下界。这里改进链的刚体运动误差估计。全部坐标采用原核的整数尺度，下面先写未缩放的公式。

设材料顶点的名义位置为 \(p_i\)，它在所属体上的向量为 \(a_i\)。该体平移误差为 \(u_k=(x_k,y_k)\)，转角误差为 \(\delta_k\)。令 \(c_k=\cos\delta_k-1\)，\(s_k=\sin\delta_k\)，\(J(x,y)=(-y,x)\)。材料顶点的位移为 \(u_k+c_ka_i+s_kJa_i\)。将链的有向倍面积按此位移展开。每个体的一阶平移系数为 \((g_{ky},-g_{kx})\)。设 \(N_{kj}\) 为有向体对的带符号次数，\(v_{kj}\) 为原核汇总的平移与转角混合向量。转角一次系数分别记为 \(G_j,C_j\)。固定转角后，平移相关部分恰是

\[
 \sum_k (g_{ky}x_k-g_{kx}y_k)
 +\sum_{k<j}N_{kj}\det(u_k,u_j)
 +\sum_{k,j}\big[c_j\det(u_k,v_{kj})+s_j\,u_k\cdot v_{kj}\big].
\]

同体转角二次项通过 \(c_j^2+s_j^2=-2c_j\) 精确并入 \(C_j\)。异体纯转角项使用原核已证余量。独立的整系数多项式程序展开并核对异体边、同体边、圆恒等式和一阶系数。

上述表达式对各平移坐标分别仿射。对 \(x_k\) 的导数，扣除常数 \(g_{ky}\) 后，余项绝对值至多为
\[
 \sum_{j\ne k}|N_{\min(k,j),\max(k,j)}|h_{yj}
 +\sum_j (|v_{kj,x}|\Theta_j+|v_{kj,y}|\Theta_j^2/2).
\]
这里 \(\Theta_j\) 是该角偏差的绝对上界。对 \(y_k\) 交换两个向量分量与两个半宽。若常数项压过余项，下界必在已知的那一端取得。未能决定符号的平移坐标至多四个时，枚举其全部端点。多于四个时沿用原下界。若某个导数恒为零，任选一侧仍可取得最小值。

对一个平移端点组合，立即算入所有平移与平移的行列式，并合并各体转角的系数
\[
 G_j'=G_j+\sum_k u_k\cdot v_{kj},\qquad
 C_j'=C_j+\sum_k\det(u_k,v_{kj}).
\]
三个角在源根的范围都包含于 [0,2]，表行锚点也在同一个角域内，故转角相对锚点的偏差绝对值小于 π，正弦与偏差同号。对 \(G_j's_j\) 仅扣除其不利转向所能达到的最大偏差。对 \(C_j'c_j\) 只在 \(C'_j>0\) 时扣除 \(C'_j\Theta_j^2/2\)。各个除法均朝使面积下界减小的方向取整。最终取此下界和旧下界中的较大者。径向截断、原根外下界和全链朝向检查均承继原核。所有整数运算保留编译器溢出陷阱。

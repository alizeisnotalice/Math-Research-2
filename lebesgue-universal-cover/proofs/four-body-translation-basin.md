# 四体接触曲面上的定角平移盆地

以第76轮认证的接触驻点为 \(p_*\)，并记其面积为 \(M_*\)。用两个实际旋转角确定锚定放置。在固定角度下，六个原始平移坐标减去锚定平移得到 \(\delta\in\mathbb R^6\)。

令 \(\mathcal R\) 为以第83轮原始坐标的有理中心为中心的八维闭盒。六个平移坐标半宽取 \(0.000020002\)，两个角度半宽取 \(0.000100002\)。对每个 \(p\in\mathcal R\)，存在唯一一对锚定法向 \((\alpha,\beta)\) 落在中心 \((\alpha_0,\beta_0)\) 半宽 \(0.00012\) 的闭盒 \(V\) 中。该锚点的两个旋转角恰为 \(p\) 的旋转角，且 \(\|\delta\|_\infty<0.00010\)。在整个闭盒 \(\mathcal R\) 上，
\[
 \operatorname{area}(p)\ \ge\ M_*+\frac1{20}
 \bigl((\alpha-\alpha_*)^2+(\beta-\beta_*)^2\bigr)
 +\frac{11}{200000}\|\delta\|_1.
\]
于是 \(\mathcal R\) 中只有 \(p_*\) 的面积达到 \(M_*\)。

## 旋转角的逆映射

用第76轮接触公式从 \((\alpha,\beta)\) 得到 \(\Phi=(\phi_5,\phi_7)\) 和锚定平移。取有理矩阵 \(B\) 近似 \(\Phi\) 在中心的雅可比逆，精确核对其行列式非零。设 \(q=(\alpha_0,\beta_0)\)，对目标旋转角 \(\omega\) 用映射
\[
 T_\omega(u)=u-B\bigl(\Phi(q+u)-\omega\bigr).
\]
以相关 Taylor 模型在整个闭盒 \(V\) 核对 \(\|DT_\omega\|_{\infty\to\infty}<0.052\)。对原始角闭盒中的每个 \(\omega\)，再核对 \(T_\omega(0)\) 的各坐标绝对值加 \(0.052\cdot0.00012\) 小于 \(0.00012\)。于是映射是闭盒内的压缩，给出唯一锚点。程序使用实际验证的雅可比范数上界进行闭盒包络。由
\[
 u=T_\omega(0)+\left(\int_0^1 DT_\omega(tu)\,dt\right)u
\]
作五次区间细化。将所得区间代入各锚定平移的 Taylor 模型后，六个平移偏移的最大绝对值上界小于 \(0.00008118\)。

## 锚点面积和刚体平移

接触公式沿用第76轮的分支。对 \(V\) 以总次数 16 的双变量 Taylor 模型核验第83轮的支撑链拓扑，并核对锚点面积 \(F\) 的 Hessian 满足 \(\nabla^2F\succeq .1I\)。本次计算用 32 个闭子盒，最小的核验行列式 \(\det(\nabla^2F-.1I)\) 大于 \(1.184\)。以已证驻点积分二阶下界，得
\[
 F(\alpha,\beta)\ge M_*+.05\|(\alpha,\beta)-(\alpha_*,\beta_*)\|_2^2.
\]

在每个锚点沿用第83轮选定的七条材料扇。纯平移下，材料弧的面积贡献是平移的仿射函数，异体连接则贡献 \(\det(P+\delta_i,Q+\delta_j)/2\)。这里令圆盘的 \(\delta_0=0\)。于是每条扇的面积是固定锚点六个平移偏移的二次多项式，在 \(\delta=0\) 同值为 \(F\)。将七条扇在零偏移的六维梯度与首坐标 \(1\) 组成重心矩阵。预条件后的区间逆给出，半宽 \(0.00018\) 的梯度立方体内每个点的七个重心系数严格为正。全部子盒的最小重心系数下界大于 \(0.00275\)。

所有材料端点均属于其移动后的刚体。三个定宽多边形均为以正多边形顶点为圆心的单位圆盘交集，故包含以自身正多边形中心为圆心、半径 \(1-1/(2\cos(\pi/(2n)))\) 的圆盘。对原始盒 \(\mathcal R\) 中的放置，从锚点到实际平移的线段上，各体平移范数均小于 \(0.04\)，因而原点一直严格位于各体内部。每段材料圆弧的极角沿正方向严格增加。程序还核对异体连线的正方位。对每个 \(\|\delta\|_\infty\le0.00010\)，按
\[
 \det(P+\delta_i,Q+\delta_j)
 \ge \det(P,Q)-\|\delta_i\|_\infty\|Q\|_1
 -\|\delta_j\|_\infty\|P\|_1
 -2\|\delta_i\|_\infty\|\delta_j\|_\infty
\]
求下界，最小认证值大于 \(0.00122\)。同体材料的交接点一起平移，所以仍重合。零偏移的扇沿支撑链绕原点一周。沿每条从零偏移到实际偏移的线段，整条闭曲线避开原点且保持正向，故绕数保持为一。由此，每条扇围出的星形区域都在真实凸包内。

七个平移二次式的 Hessian 完全来自异体直线连接，矩阵元素为半整数，可直接累加。其最大绝对行和为 \(5/2\)。取与 \(\delta\) 同符号的梯度立方体顶点，至少有一条扇的线性项达到 \(0.00018\|\delta\|_1\)，而其二次项绝对值至多 \((5/4)\|\delta\|_\infty\|\delta\|_1\)。在 \(\|\delta\|_\infty\le0.00010\) 时，净线性系数至少为 \(0.000055\)。这给出声称的面积不等式。

## 复算与全域对接

在仓库根目录执行

    python -B lebesgue-universal-cover/computation/certify_four_body_translation_basin.py \
      --radius .00024 --transverse .00010 --gradient-cube .00018 --degree 16 \
      --raw .000020002 .000020002 .000100002 .000020002 .000020002 .000100002 .000020002 .000020002

冻结输出为 [four-body-translation-basin-bridge.json](../computation/four-body-translation-basin-bridge.json)。实算使用 Python 3.13.18、python-flint 0.9.0 和 160 位 Arb。角雅可比用逐项微分和 Cauchy 余项估计，运算中的幂以重复乘法形成，保持含零区间的有效外包络。中心近似逆只用于选择有理预条件矩阵，矩阵的可逆性、压缩映射和重心系数均有严格区间检验。

全域筛选的八维闭盒采用分母 \(2^{44}\)。将分子逐项除以该分母，与盆地原始盒的有理端点直接比较，得到最小包含余量 \(48533425669/204800000000000000000>0\)。核对数据为 [four-body-translation-basin-dyadic-inclusion.json](../computation/four-body-translation-basin-dyadic-inclusion.json)。

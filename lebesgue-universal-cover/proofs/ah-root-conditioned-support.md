# 在相容根上更换六边形基，把十个参考格并成两类

采用 \((p,\delta)=(0.427,0.00135)\) 的单线 AH 宿主和第126轮两段 EH。整个 \([0.30,0.40]\) 的双命中参考参数可以分成两类，各用一个固定有理角括。

| 基点闭区间 | 姿态及闭根括 | 根端统一净余量 | 同一摆放的全边统一净余量 |
|---|---|---:|---:|
| \([0.30,0.34]\) | \(300^\circ-\phi\)，\(10.35^\circ\le\phi\le12.80^\circ\) | \(>0.0000206295\) | \(>0.00028239853\) |
| \([0.34,0.40]\) | \(-\phi\)，\(2.91^\circ\le\phi\le5.20^\circ\) | \(>0.0000138048\) | \(>0.00056687469\) |

在 \(w=0.34\) 两个分支分别成立，任选一个均能满足全部放置条件。

设 \(n_0,\dots,n_5\) 为正六边形的外法向，\(R\) 将宿主法向带回输入体的坐标。相容根条件和定宽性保证唯一平移 \(t\) 同时满足

\[
t\cdot n_k=\tfrac12-h_K(Rn_k)\qquad(0\le k\le 5).
\]

若宿主边的法向为 \(u=\alpha n_k+\beta n_{k+1}\)，截距为 \(c\)，此根上的真实净余量恰为

\[
c-\tfrac12(\alpha+\beta)+\alpha h_K(Rn_k)+\beta h_K(Rn_{k+1})-h_K(Ru).
\]

对 \(u\) 所在的六十度扇，系数均非负且和至多 \(2/\sqrt3\)。每条边可同时计算原基 \((n_0,n_1)\) 与此扇的两端基，选择给出较大认证下端的表达式。两种表达式在每个实际相容根对应完全相同的平移。因而可逐行选择表达式，并允许选取依赖相应的角闭格。对任一角格，理想支撑组合以中点加区间导数计算，实际偏差以 `ah-coupled-brackets.md` 的共享五锚点和32个有序极点包围。余量充足的行直接使用已证明的全向误差 \(1.07 E(1+|\alpha|+|\beta|)\)。

对两段分别核验300与450个基点格，合计12000个角闭格。整个大角括内必须核对实际相容根的存在和可能的根姿态。新基在237项宿主边比较上将原先未过零的认证下端提升为严格正值。例如第33参考格最后一个基点、最后一个角格 \([4047/320,64/5]\) 上的 `Z-Tprime:16`，原基下端约为 \(-0.00024798472\)，改用 \((n_1,n_2)\) 给出严格下端 \(0.00113889561\)。这些端点只是两种证明方法在同一根上的保守估计。

```sh
python -B computation/certify_ah_root_conditioned_support.py computation computation/ah-root-conditioned-parameters.json OUTPUT.json
```

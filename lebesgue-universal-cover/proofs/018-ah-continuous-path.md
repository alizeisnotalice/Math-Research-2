# 第18轮：固定斜角AH候选路径的连续认证

固定σ=(7747/5000)°，使用第12、17轮坐标约定。所有三角参数以精确π乘有理数定义。
本轮证明第17轮以C=L(θ)为圆心的候选路径确实包含于
R={X(s,t): |s|≤θ, |t|≤τ}，并有唯一连续的参数提升。
不预设R为Jordan域，不断言该路径已满足原文最短性或万能覆盖命题。

## 精确坐标与角参数

原六边形DC的外法向为n=(1/2,−√3/2)，F3=(-1/2,f)，E3=R_(π/3)F3。
以F3为圆心的单位圆与DC相交，取右侧根G；代码用正交投影加根式构造该根。
令v=G−F3，e=(√3/2,−1/2)，θ=arg(v)+π/6。
区间验证v_x>0、v_y<0及e×v>0，给出0<θ<π/6。
L(s)_x=cos(π/6+s)−1/2，L(s)_y=(L(s)_x−1)/√3。
其x坐标在[−θ,θ]严格递减，L(−θ)=G。
利用n·G=1/2，直接计算

L(θ)_x=cos(arg(v)+π/3)−1/2=1/4+(√3/2)f=−(E3)_x。

两点都在DC，故C=L(θ)=(-(E3)_x,(E3)_y)。
M=(-1/4,−√3/4)，N_-=2M−E3，N(t)线性遍历[N_-,E3]。
因此Y=X(θ,τ)=(0,C_y+sqrt(1−C_x²))；Z=X(0,0)由L(0)、M的上单位圆交点给出。
代码中的圆交点公式没有依赖浮点选根。

## 路径与四圆不等式

写z=Z−C，d²=|z|²>1，取
T=C+z/d²−sqrt(d²−1)Jz/d²。
根式恒等式给出|T−C|=1及(T−C)·(Z−T)=0。
区间验证Z_x<T_x<0及T_y>C_y。
路径第一段是x∈[T_x,0]上的上圆弧y=C_y+sqrt(1−(x−C_x)²)，从Y走向T；
第二段为[T,Z]。圆弧在C圆上，切线段在C闭圆外。

圆弧上|X−E3|²=1+4C_x X_x≤1。
对圆弧的64个完整x区间，精确有理区间逐一验证|X−G|²<1。
T、Z在G与E3闭圆盘内，凸性保证整段[T,Z]也在二者内。
整个路径位于矩形[-.045,0]×[.545,.564]；圆弧y随x单调、线段凸性以及端点区间保证此事。
对这个整个矩形，区间验证|X−N_-|²>1。
因此路径每一点满足

|X−C|≥1，|X−G|≤1，|X−N_-|≥1，|X−E3|≤1。

## 存在、唯一与连续提升

固定路径点X，连续函数L↦|X−L|²在[C,G]两端分居1两侧，因此存在单位距离中心L。
在代码给出的路径矩形和整个L线段包络上，验证
(X−L)·(√3/2,1/2)>0，故距离平方沿C至G严格递减，中心唯一。
同理，在整个N线段包络上验证
(X−N)·(−√3/2,1/2)>0，得到[N_-,E3]上唯一单位距离中心N。
这两个导数有严格统一下界，根对路径点连续，继而s、t连续。
所有L、N之间距离平方严格在(0,4)，所以圆交点非退化。
路径点y大于所有中心y，必为两单位圆的上交点，即X=X(s,t)。
端点分别对应(θ,τ)和(0,0)。因此参数配对X(−s,−t)也连续且定义良好，
其端点分别为X(−θ,−τ)和X(0,0)。

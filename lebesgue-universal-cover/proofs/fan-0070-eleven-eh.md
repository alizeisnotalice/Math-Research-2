# 同扇相容根与 0.007 的完整 AH、EH 组合

固定 Gibbs 角 1.5497°、AH 铰点 p=.427，将新线转角取 .007 弧度。配对弧参数远端、物理投影左界的绝对值和图管半宽分别为 .225、.245、.0077。输入小数均为有限有理数。图逆偏导、真实配对高度截取、两处实际命中的手性及亏损预算均在新物理图上重新生成。

继续使用同一顶点扇内的次可加性。若 c>0、λ≥0，方向 u、v、cu−λv 同属一个理想线性支撑扇，则
\[
c h_K(u)-\lambda h_K(v)\le h_K(cu-\lambda v).
\]
两条扇基的非负坐标决定可消去的 λ，理想支撑的线性项精确相消。余下实际误差由共同接触序核估计。位置未知的扇跨越仍用原区间包围。

前四参考格按同一体的相容函数符号作两根分支。第4格仅把第一分支的左角端从 14° 改为 12°。两个分支各自的闭格界和条件号完整核验。参考格30在没有附加支撑符号条件的角括 [9.56°,14°] 中利用相容根恒等式。若 n₀−n₁+n₂=0，则同一居中平移处的支撑表示系数可加任意有理倍数的 (1,−1,1)。因为真相容根处三个定宽支撑差的同一线性组合为零，这一改变保持所估计的实际边余量。采用共扇联合估计后，该格根端余量大于 1.04865961×10⁻⁶，最小支撑余量从原配置的负下界改善为严格大于 6.23531063×10⁻⁷。最差边 K-C3-0 使用倍数 −2。其余较早格用逐格选定的高角端点，从参考格31开始使用低角根。

独立分段验证68个非零参考格。每份分段回执绑定派生几何及验证器指纹。分叉格的两条条件覆盖检查闭参数域。合计41179个放置角叶、24745个无根角叶。对真实 AH 帽做有理 Green 面积积分，而后复算十一段 EH 的17个命中条件及63份非负对偶。在该方案中最弱 AH 格已覆盖 EH 局部换弦代价，组合仍有大于 4.39783105×10⁻⁷ 的支撑余量。整个 EH 矩形对新 AH 线净距大于 .45873，故两处面积增益可以相加。

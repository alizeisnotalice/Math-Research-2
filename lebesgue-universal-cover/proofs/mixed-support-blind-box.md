# 第 1202 分片的一棵整叶不能共用足够强的混合面积证书

第169轮的 2,049 棵普通树中，有 35 棵使用至少 300,000 个三十点终端。预先将其按字符串 guide-3.3-holdout:part:pos 的 SHA-256 升序排列，取首项，得到第 1202 分片、前序节点 32259。原树实算 757,705 个节点，351,112 个终端使用三十点。以下结论针对这一个完整十一维闭盒。

设 \(K(q)\) 为五体在该盒内按 \(q\) 摆放的凸包。若一个有内点的多边形 \(P\) 满足 \(P\subset K(q)\) 对全盒的 \(q\) 成立，则指南第3.1节中使用该 \(P\)、五体及原有 \(P_{30}\) 的平衡共享容量支撑估计，在一组明确允许的姿态上至多为 **0.836830013302**。这个结论允许任意多的法向、权重行或转角分段。与旧门槛 0.83741 相差至少 0.000579986698，与新门槛 0.83742 相差至少 0.000589986698。

## 原因

对 \(P\) 每条边取向外法向 \(n_j\)，令法向长度等于边长。行 \(a\) 的权重满足 \(\lambda_{aj}\ge0,\ \sum_j\lambda_{aj}n_j=0\)，各行共享 \(\sum_a\lambda_{aj}\le1/2\)。给定一个允许的五体摆放及三十点姿态，用 \(H\) 表示它们的六体联合凸包。由于 \(P\subseteq H\)，在这组姿态上有
\[
 |P|+\sum_{a,j}\lambda_{aj}\bigl(h_{R_aX_a}(n_j)-h_P(n_j)\bigr)
 \ \le\ |P|+\tfrac12\sum_j\bigl(h_H(n_j)-h_P(n_j)\bigr)
 \ = V(P,H).
\]
第一步在每行内用平衡关系恢复真实平移，再用各体都包含于 \(H\)、各方向支撑差非负和容量约束。若 \(P\subset Q\)，混合面积的单调性进一步给出 \(V(P,H)\le V(Q,H)\)。

对筛定的 125 个整数法向 \(N\)，分别构造能使五体在此方向支撑尽量小的摆放。各体的两个平移坐标在闭盒中取使标量积最小的端点。对每个可旋转体，在闭角区间的左端、中点和右端选取有认证支撑上端最小的一个。各体姿态可以独立选取，故这给出 \(h_P(N)\) 的一个上界 \(b_N\)。不同法向可以使用不同姿态，因为 \(P\) 是全盒共有的。三角形方位固定，五边形角不超过 \(\pi/15\)，四个平移向量的模都小于 0.04，故使用的姿态也在规范范围内。

以有理半平面 \(N\cdot x\le b_N\) 的交构造 \(Q\)。使用 192 位 Arb 计算曲线支撑并向上舍入，随后用有理数求每个相邻边交点。程序验证每个交点同时满足全部 125 条不等式，每条边方向一致且长度严格为正。由此 \(P\subset Q\)，并有 \(|Q|\le 0.830127913284\)。

最后从冻结输入读入给定的同盒五体位置和一组三十点位置，定义 \(H\)。原三十点关于横轴的对称性通过逐点有理检验，因此两种手性给出相同的允许姿态集合。如果某条 \(Q\) 边向量是 \(\alpha JN\)，其中 \(N\) 是该边的整数外法向、\(\alpha>0\) 为有理数，则该边对 \(V(Q,H)\) 的贡献为 \(\alpha h_H(N)/2\)。使用有向舍入得到的支撑上端逐项相加，得
\[
 V(Q,H)\le 0.836830013302.
\]
原证书的第六体排除依然有效。盲检指出，这棵叶上把一个内多边形用于全部五体位置会失去必要余量。按五体位置细分后换取不同的 \(P\)，或先限制在已知的小面积子域，可另外检验。

    python -I -B computation/audit_mixed_support_blind_box.py R169_COMPUTATION CERT11D computation/mixed-support-blind-input.json

所需外部数据仅为冻结的第169轮普通树账本、三十点有理坐标、原分片 1202 的树与表头、原树总清单。三十点姿态和 125 个法向均在冻结输入中。最终验证不运行数值优化，也不运行浮点凸包算法。

## 盒内确有低面积的五体摆放

同一原盒内还可固定十一项分母为 \(2^{44}\) 的位置参数，使五体凸包的面积至多 **0.837345331409**。验证器在 32,768 条有理法向上向上舍入每个曲体的支撑，以有理对偶凸包求交半平面，所得外多边形有 5,035 条有效边。它包含该真实曲边凸包，其面积低于 0.83741 至少 0.000064668591。因此这棵盲叶即使允许任意精度的纯五体面积计算，也不能按原门槛整体排除。

    python -I -B computation/verify_mixed_blind_low_pose.py CERT11D computation/mixed-support-blind-low-pose.json

这个具体低面积点与前文用于上界混合面积预算的六体姿态分别给出。对于只在五体低面积子域上共有的内多边形，前文对全原盒的上端仍然需要另行证明。

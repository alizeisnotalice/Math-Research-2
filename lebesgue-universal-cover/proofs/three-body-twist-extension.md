# 用纵移控制三重接触权重的扩角证书

续用显式角域证明中的两分支锚点 $H_m(a,\phi)$ 和三条代表支持线。令 $L_i(\xi)$ 是第 $i$ 条线插点面积差的线性部分，$Q_i(\xi)=(-1,1,-1)_i\,\Delta y\Delta b/2$，其中 $\xi=(\Delta y,\Delta b,\Delta z)$。令 $B$ 的第 $i$ 行是 $L_i$ 的系数，不插点闭链的增量记作 $\ell(\xi)=\lambda^TB\xi$。由相反线的插点面积差恰好变号，仍有
\[
 A\ge H_m(a,\phi)+\ell(\xi)+\sum_i|L_i(\xi)+Q_i(\xi)|.
\]
较大扭角下，原权重第二分量可以大于一。取
\[
 v=B^{-T}(1,0,0)^T,\qquad \lambda'=\lambda-\eta v.
\]
证书在每格另核验 $v_2>8$，从 $\lambda_2$ 的上界与 $v_2$ 的下界选取同一非负有理 $\eta$，使 $|\lambda'_i|<1$。具体取向上舍入的 $\max\{0,(\sup\lambda_2-.99999)/\inf v_2\}$。因为 $v^TB\xi=\Delta y$，将 $|L_i+Q_i|\ge-\lambda_i'(L_i+Q_i)$ 代入得到
\[
 A\ge H_m(a,\phi)+\eta\,\Delta y-\lambda'\cdot Q(\xi).
\]
因此调权的线性损失只由三角形纵移控制，五边形平移只在易控的双线性余项中出现。

在 $-.017\le a\le-.0076$、$0\le\phi\le1/50$ 的两套解析延拓上，重新认证锚点 $\tfrac12\partial_\phi^2 H_m>.09$，且隐式根和顶部法向斜率的符号所需裕量成立。前轮证明已给精确的 $\partial_\phi H_m(a,0)=0$，所以 $H_m(a,\phi)\ge H_m(a,0)+.09\phi^2$。在要排除的正角带，原闭链和所有插点后闭链的连接行列式仍严格正，故仍是有效内扇。即使某解析延拓不对应实际材料，只在其物理分支选择处使用面积比较。

轴向离开最优点时另用零角基线。对上面这个 $a$ 区间，零角接触曲线的 $b_*(a)$ 位于 $[.0185,.0274]$ 内。已证的宽盒零角横截强制条件说明，对固定 $a$，$b_*(a)$ 局部最小化轴向面积；由轴向面积关于 $(a,b)$ 联合凸，这也是全域 $b$ 最小。因此 $H_m(a,0)=\inf_b A(a,0,0,b,0)$ 关于 $a$ 凸，并且最小点是已证的 $a_*$。在两端 $a\le-.0147$ 或 $a\ge-.0098$ 时，分别用相应截点与 $M_0$ 之差的严格有理下包络。切点本身也在证书的零角拓扑区间内。

使用上述基线与二次角增量，减去区间上的 $-\eta\Delta y$ 上界及 $|\lambda_2'-\lambda_1'-\lambda_3'|\,|\Delta y\Delta b|/2$ 上界，得到待验证的全盒不等式。输入区间为
\[
\begin{split}
 &-.017\le a\le-.0076,\qquad |y|\le .0008,\qquad 147/32768\le\phi\le1/50,\\
 &.0185\le b\le .0274,\qquad -.0045\le z\le .001.
\end{split}
\]
计算使用 `certify_three_body_twist_extension.py`，依赖上一轮区间脚本。这里证明的范围是此显式五维闭盒。若要得出整个正角带对任意平移的结论，需要进一步关闭此盒的全平移补集。

全盒共核验 136300 个双分支单元，最小剩余增量严格大于 $1.39\times10^{-6}$，所以这一范围内有 $A>M_0+1.39\times10^{-6}$。从仓库根目录运行 `python -B lebesgue-universal-cover/computation/certify_three_body_twist_extension.py`，标准输出对应 `computation/three-body-twist-extension.json`。实际环境为 Python 3.13.18、python-flint 0.9.0、Arb 160 位。

## 余角核验与三体全域最优值

最后一次重放只覆盖 $[655/32768,27/128]$，在两体平移代表根盒上无内盒切除。沿用同一阈值 $0.834780945776$，5071 个种子交盒产生 5325 次核验，终端包括 3935 个 Taylor 盒，以及使用一扇、两扇、三扇的 275、957、31 个盒。最大深度为 8，剩余盒数为零。由精确 dyadic 端点可直接与前一节的角带拼接。复现如下，输出对应 `three-body-twist-far-exterior-1310-13824.json`。

```sh
python -B lebesgue-universal-cover/computation/certify_three_body_twist_far_exterior.py SOURCE 1310 13824 OUTPUT
```

第35轮的共同转动与反射把任意三体放置规范到 $0\le\phi\le\pi/15<27/128$，同时面积至多 $.838$ 即位于所用平移代表根盒。三个区间 $[0,147/32768]$、$[147/32768,655/32768]$、$[655/32768,27/128]$ 因此涵盖整个问题。它们共同给出对于任意规范角和平移
\[
 A\ge M_0+10^{-11}\phi^2.
\]
这里余角所用的比较是 $10^{-11}(27/128)^2<0.834780945776-0.8347809457752037$。非零规范角严格不可能极小。由零角切片的唯一性，三体问题的规范最优放置唯一，且
\[
 m(\{D,B_3,B_5\})=M_0\in(0.8347809457752035,\ 0.8347809457752037).
\]
其精确值由零角切片中的单变量根和圆弧面积公式确定。具体地，由 $c=R_3+a$、$s=\sqrt{1-(r/c)^2}$、$L=1+g-3\sin\delta/2$，求根
\[
 \tfrac32s+g-1+(\tfrac12-L/s)(s-2g)=0
\]
关于变量 $a$ 于 $[-.012154558715405409,-.012154558715405408]$，取 $b_*=C-c+2g\sqrt{c^2-r^2}$，其他两个平移分量及角度为零。整个最优凸包即这组放置的凸包。

# 零转角最优放置的稳定性

设 $A(a,y,\phi,b,z)$ 是 $D$ 与平移 $(a,y)$ 的 $B_3$、旋转 $\phi$ 并平移 $(b,z)$ 的 $B_5$ 的凸包面积，取前一份零转角切片证明的 $M_0$ 与唯一最优放置 $(a_*,0,0,b_*,0)$。本证明给出一个开角邻域：存在 $\epsilon>0$，使 $|\phi|<\epsilon$ 时对所有平移都有 $A\ge M_0$，且 $0<|\phi|<\epsilon$ 时严格大于 $M_0$。角半径在此处未量化，所有角均以弧度衡量。

## 三对三重接触的解析锚点

记 $r=1/2$、$R_j=1/(2\cos(\pi/(2j)))$、$g=R_5\sin(\pi/5)$、$C=R_5\cos(\pi/5)$ 及 $k=R_5\cos(2\pi/5)$。令 $J$ 是逆时针直角旋转，$R_\phi$ 是旋转 $\phi$。用 $(a,\phi)$ 参数化一组特殊放置；待求的是 $y,b,z$。

给定 $a,y$，取 $p=(R_3+a,y)$，令
\[
 N_\pm(p)=\frac{rp\pm\sqrt{|p|^2-r^2}Jp}{|p|^2},\qquad n_\pm=N_\pm(p).
\]
它们是令 $n\cdot p=r$ 的两个单位法向，分别接近零角最优点的 $\pm\gamma$。记 $w_\pm=(b,z)+R_\phi(-C,\mp g)$。解线性二元方程组
\[
 n_+\cdot w_+=n_-\cdot w_-=-r
\]
确定 $(b,z)$。矩阵在基准点的行向量分别为 $(x,s),(x,-s)$，$x,s>0$，可逆。两对斜接触由 $B_3$ 的角点 $p$、$D$ 的 $rn_\pm$ 及 $B_5$ 的弧点 $w_\pm+n_\pm$ 给出。所有点的相反支撑材料都等于其减去相应的单位法向。这里的材料来自单位圆弧或角点的明确法向区间，斜接触点自基准起均在各自区间内部。

令 $u=(a-R_3/2,r+y)$、$v=(b,z)+R_\phi(k,r)$，并令 $N=N_-(u)$ 为接近竖直向上的法向。再解
\[
 E(a,y,\phi)=N\cdot v-r=0.
\]
零转角时 $y=0$ 对曲线上所有 $a$ 都是根。证书在包含 $a_*$ 的有理区间上核验 $E_y(a,0,0)>.9$。由隐函数定理，在 $(a_*,0)$ 附近得到解析 $y=y(a,\phi)$，因而得到 $b,z$。证书认证 $\arg N$ 对 $\phi$ 的导数在 $(.005,.006)$。所以充分小的 $\phi>0$ 下，$\pi/2<\arg N<\pi/2+\phi$。在此区间，$u,v$ 分别是 $B_3$ 左上顶点和 $B_5$ 右上顶点的支撑点。顶部三重线的三点是 $u,rN,v$，相反一面为各点减去 $N$。这些相反材料来自以 $u,v$ 为心的单位弧。反射令 $(y,z,\phi)\mapsto(-y,-z,-\phi)$，故下文只处理正角。

## 一个解析面积下界

取下表列出的材料和连接线。记 $\alpha_\pm=\arg n_\pm$ 在正负小角支，$d_\pm=\arg(-w_\pm/|w_\pm|^2-n_\pm)$ 分别是同一圆弧对 $D$ 的另一个接触法向角，$T=\arg N$。令 $\bar u=(a-R_3/2,-r+y)$、$\bar v=(b,z)+R_\phi(k,-r)$。每一行表示从上一行的终止角走到本行终止角，其间走指定的圆弧或停留于指定点。最后用线段连续连接相邻行材料端点。

| 终止角 | 圆弧圆心与半径，或固定点 |
| --- | --- |
| $\alpha_+$ | 点 $p$ |
| $d_+$ | 圆心 $0$，半径 $r$ |
| $3\pi/10+\phi$ | 圆心 $w_+$，半径 $1$ |
| $T$ | 点 $v$ |
| $5\pi/6$ | 点 $u$ |
| $\pi+\alpha_-$ | 圆心 $p$，半径 $1$ |
| $\pi+\alpha_+$ | 圆心 $0$，半径 $r$ |
| $7\pi/6$ | 圆心 $p$，半径 $1$ |
| $3\pi/2$ | 点 $\bar u$ |
| $\pi+T$ | 圆心 $u$，半径 $1$ |
| $3\pi/2+\phi$ | 圆心 $v$，半径 $1$ |
| $17\pi/10+\phi$ | 点 $\bar v$ |
| $2\pi+d_-$ | 圆心 $w_-$，半径 $1$ |
| $2\pi+\alpha_-$ | 圆心 $0$，半径 $r$ |
| $2\pi$ | 点 $p$ |

各正长法向区间在零转角时都已由切片证明排序。两个初始零长弧分别在 $[3\pi/2,\pi+T]$ 和 $[\pi+T,3\pi/2+\phi]$，由 $\pi/2<T<\pi/2+\phi$ 确认顺序。每一行的材料确属相应的体，可直接用圆弧法向区间检查。对于正圆弧，正面积角速度满足 $\det(P,P')=\rho(\rho+C'\cdot n)>0$，其中 $C'$ 是圆心、$\rho$ 是半径。这是对应体相对原点的支撑为正所致，在邻域内仍成立，因为三体均包含原点的一个固定小邻域。各异体连接线在基准点的端点具有严格递增的极角，故邻域内依旧如此。同行材料之间的零长连接是体自身的精确弧端或角点衔接。已经绕原点一周的闭链因此沿极角单调地围成星形区域，面积不超过实际凸包面积。以上论证也适用于后文所用插入三重线中间点的全部闭链。无需证明正角时该闭链已经是凸包的完整边界。

记此闭链面积为 $H(a,\phi)$。面积由圆弧和连接线的 Green 公式逐项得出，是半邻域上解析函数的限制，且 $H(a,0)=A(a,0,0,b_*(a),0)\ge M_0$。证明 $H_\phi(a,0)=0$ 时，可以在每条弧和线段上固定 $[0,1]$ 参数再微分。两倍面积的端点项沿闭链相消，面积导数为 $\int\det(V,dp)$。材料端点沿所在体的切向滑动在基准点与相邻支持线平行，故滑动分量在弧和连接线上均无面积导数。零长弧贡献也为零。于是只须积分各体的刚体速度在弧上及相邻连接线上线性插值得到的速度。两斜接触方程由 $x$ 轴反射互换，故 $b(a,-y,-\phi)=b(a,y,\phi)$，从而锚点的 $b_\phi(a,0)=0$；其他刚体速度在反射下为奇。基准闭链关于 $x$ 轴对称，积分成对抵消。因此 $H_\phi(a,0)=0$ 精确成立。

Arb 二阶级数按上述解析公式得到
\[
 .15<\tfrac12H_{\phi\phi}(a_*,0)<.16.
\]
因连续性，充分小的邻域内可统一取 $H(a,\phi)\ge H(a,0)+.1\phi^2$。

## 横向偏离三重接触不降面积

给定锚点 $(a,\phi)$，冻结各行局部材料。六条三重支持线上各有一个严格中间材料点，可独立插入或略过。它们的严格次序在基准点由切片证书以及反射、对径得到，因而小扰动后仍成立。在锚点这些材料恰共线。将 $y,b,z$ 偏移 $\xi$ 时，闭链中的材料随各体平移；前一节的极角单调保证所有 $2^6$ 条链仍给出真实面积的下界。它们在 $\xi=0$ 处都取值 $H$。

对一条正向线段 $P\to Q$ 及其中间材料 $M=(1-\ell)P+\ell Q$，加点相对于不加点的面积变化为 $\det(M-P,Q-P)/2$。在锚点，其一阶导数是
\[
 \tfrac12\det\bigl(\dot M-(1-\ell)\dot P-\ell\dot Q,\ Q-P\bigr).
\]
因此它等于长度的一半乘三个材料法向速度的仿射残差。在 $(a_*,0)$ 处，选 $n_+,n_-,N$ 所对应的三个插点差。它们的横移梯度线性独立：每个梯度均是相应接触方程微分的非零倍数。为见这一点，先用 $D,B_3$ 两材料决定支持法向的微分；若 $P_5=P_D+t(P_3-P_D)$，那么 $n'\cdot P_D=0$、$n'\cdot P_3=-n\cdot\dot P_3$，故移动后的 $B_5$ 余量微分就是 $n\cdot\dot P_5-t n\cdot\dot P_3$，恰是插点差的比例量。圆弧接点滑动为切向，所以该恒等式也适用于圆弧。两斜方程在 $(b,z)$ 的矩阵可逆，消元后顶方程的 $y$ 导数为已认证的 $E_y>.9$，得到秩三。

还须证明原点在这些面积下界的梯度凸包内部。基准点处，不插任何三重中间点时的 $b$ 导数是切片证明的 $L=1+g-\tfrac32\sin\delta$。镜像的一对右侧斜面各插点时分别增 $s/4$，因为端点距离为 $(R_3+a_*)s$、法向水平分量为 $r/(R_3+a_*)$。两相反线各插点分别减 $s/4$。顶部及底部的插点对 $b$ 无贡献。切片证书给 $L-s/2<0<L+s/2$。因此选 $\lambda=1/2-L/s\in(0,1)$，用概率 $\lambda$ 在两右面各插点、用 $1-\lambda$ 在相反两面各插点、用 $1/2$ 在顶底各插点。独立选择后，各闭链权重严格正，平均 $b$ 梯度为零。镜像同时反转 $y,z$ 两速度，所用概率镜像不变，故两者的平均梯度也为零。结合秩三，原点在梯度凸包内点。

由有限性及梯度连续性，在所有足够近的锚点，梯度凸包都包含以原点为心的同一个三维小球。于是某条冻结材料闭链的线性项至少为 $c\|\xi\|$，其中 $c>0$。二阶余项统一为 $O(\|\xi\|^2)$，因为固定材料的弧及连接线关于三平移坐标至多二次。缩小邻域后得到
\[
 A(a,y,\phi,b,z)\ge H(a,\phi)+(c/2)\|\xi\|\ge M_0+.1\phi^2+(c/2)\|\xi\|.
\]

## 对一个开角邻域的全部平移有效

当面积不超过 $M_0$，两平移向量有一致有界的次水平限制，例如第35轮适用于面积不超过 $.838$ 的平移半径界。凸包面积关于这些旋转和平移参数连续。若有非零角趋于零但面积不超过 $M_0$ 的放置，取平移子序列极限，就会得到零角切片的最优放置。其唯一性已证，故该序列最终进入本证明的局部邻域，与严格正的角度二次增量矛盾。这即给出所声称开角邻域。

复现命令为 `python3 -B lebesgue-universal-cover/computation/certify_three_body_twist_jet.py`，运行环境需 `python-flint` 和同目录的 `certify_three_body_symmetric_slice.py`。实际用 Python 3.13.18、python-flint 0.9.0 与 160 位 Arb，输出 `computation/058-twist.json`。数值二阶系数用包络而非有限差分；严格零的一阶项由解析反射证明。

## 附录　 最优平移的唯一性

极限梯度的 $b$ 分量异号，且两侧梯度公式连续延拓至三重曲线。在 $(a_*,b_*(a_*))$ 的邻域内，若 $b\ne b_*(a)$，可通过小幅改变 $b$ 严格降低面积。故该邻域内的最优点均在三重曲线上。又有
\[
 b_*(a)=R_5\cos36^\circ-c+2g\sqrt{c^2-r^2},\qquad b_*''(a)=-\frac{2gr^2}{(c^2-r^2)^{3/2}}<0.
\]
严格凹函数的图不含非平凡线段。若存在另一个全域最优点，联合凸性会使连线均为最优点，并在以上邻域中给出一段非平凡的线段，矛盾。因此归零后的横向平移唯一。

对这组横向平移，再考察沿任意纵向速度 $(v_3,v_5)$ 运动时的面积右导数，圆盘速度为零。固定横坐标考察上端点，记在该端点所有可实现凸组合中的最大、最小材料速度为 $v_{\max}$、$v_{\min}$。下端点由上端点反射且两体各自对称，故在该同一横坐标的面积差商极限为 $v_{\max}-v_{\min}\ge0$。若上边界一段非竖直支持线包含三个体处于不同横坐标的接触点，整体导数为零就要求这三个点的材料速度关于横坐标共线。否则在中间点附近，由中间材料与两端连线给出不同速度，再分别与一个端点插值，使差在一段正长度的区间上严格为正。

顶部水平支持线上，三个接触点的横坐标依次为 $a_*-R_3/2<0<b_*(a_*)+R_5\cos72^\circ$。圆盘接触点的横坐标及速度均为零，共线要求 $v_5$ 是 $v_3$ 的负倍数。在 $n_\gamma$ 的斜支持线上，三个横坐标依次为圆盘、$B_5$、$B_3$。共线要求 $v_5$ 是 $v_3$ 的正倍数。两处次序都由根区间复核。因而除 $(0,0)$ 外，纵向平移的面积右导数严格正。联合纵向凸性于是保证任何非零纵向平移严格增加该组横向平移的面积。配合横向唯一性，零转角切片的最优平移唯一。

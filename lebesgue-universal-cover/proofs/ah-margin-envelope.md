# 用第167轮的全域余量选择 AH 五段包络

保留第167轮的三条 AH 裁线以及宽一六边形、两段 EH 和真实 Sprague 圆弧。另加三条裁线，其铰点参数和转角如下，转角以弧度计。

| 铰点参数 \(p\) | 转角 \(\delta\) |
| ---: | ---: |
| 0.3988348378 | 0.000534048145 |
| 0.4007417347 | 0.000517816931 |
| 0.4099931706 | 0.000439274540 |

所得交集是凸万能覆盖。面积严格位于

\[
(0.844093395218375410388648671351126643458,
\ 0.844093395218375410388648671351126643543).
\]

相对第167轮，严格节省超过 \(3.6557555127\times10^{-9}\)。六条保留半平面中有五条在最终边界上形成非零直段；第167轮原先新增的中间线由新包络覆盖。

## 从一遍扫描中选择联合轮廓

沿用 \(D=T_a-Z\)、\(L=|D|\)、\(n=J(-D/L)\) 及坐标 \(x=Z+wD+Ly n\)。每条 AH 线保留 \(y\ge a-bw\)，其中 \(a=p\tan\delta\)、\(b=\tan\delta\)。第167轮在 2205 个闭参数格及每根括 32 个角格上求过相容根和支持余量。本轮在同一次重放中按旧参数格索引汇总两类最小值 \(r_j\) 和 \(s_j\)，它们已经扣掉原帽的接触亏损 \(3.21 E_j\)。

构造时先取亏损预算 \(E_j+0.7\min(r_j,s_j)/3.21\)。对每个物理 \(w\) 格试增高度，并重新检查图域、触发条件、配对落入的基点格、法向速度及图端余量。三个新线的高度在每个物理格内均递减，因此只需限制格左端。410 个非负物理格均得到通过此检验的高度预算。给定它们，候选直线的系数 \((b,a)\) 满足有限半平面条件

\[
b_2\le b\le b_1,\qquad a\le a_1,\qquad a\le p_2 b,
\qquad a-bw_i\le H_i.
\]

因此每个 \(w\) 上的最高允许直线可从系数多边形的顶点取得。数值求出活跃顶点，将其斜率改成有理转角，随后略降截距得到表中三线。完整的区间证明以这些有理参数为输入，独立检验几何及全族摆放。

## 用旧姿态余量核验新轮廓

把原 AH 几何段改用六条线，重算全部物理格及其投影，得到新的 \(E'_j\)。原图范围、触发余量和配对图端条件均严格成立。每个新活跃格均有第167轮已验证的根括。对原支持条件，只须额外扣去

\[
3.21\max(0,E'_j-E_j).
\]

新增线的向外未归一法向为 \(v_b=-n-bD/L\)。若 \(b=\lambda b_i+(1-\lambda)b_k\)，其中 \(b_i,b_k\) 是相邻旧斜率，则 \(v_b=\lambda v_{b_i}+(1-\lambda)v_{b_k}\)。支持函数次线性意味着，对同一姿态的新增归一支撑线，除去旧线余量及上述亏损增量，只需另付截距代价

\[
L\bigl(a-\lambda a_i-(1-\lambda)a_k\bigr)_+.
\]

旧线的单位余量改成未归一余量时可保守地用原单位余量，因为 \(|v_b|\ge1\)。证书逐格逐线核验这些转移，将新线余量再按法向模归一。新增截距代价的统一上界小于 \(4.950811\times10^{-7}\)。置放的最终余量严格大于 \(1.8245084\times10^{-5}\)，相容函数两端的符号余量严格大于 \(6.871612\times10^{-6}\)。一次独立复算还把三条线全放入旧的逐角格支持循环，得同样的严格根余量及大于 \(1.87401\times10^{-5}\) 的逐线摆放余量。

最终的覆盖分支与第167轮相同。先用 EH 证明取得避开原 AH 和两段 EH 的姿态。若命中增广 AH 帽，则沿用 \(Q_A\) 和 EH 触发规则。两姿态都命中时，使用上述通过新几何亏损检验的根括，取得同时进入 \(P\)、避原 AH、满足所有新 AH 线及深度 \(0.000555\) 的 EH 包络线的姿态。该姿态还满足由原强制接触控制的真实 Sprague 圆弧支持。闭包与定宽补全给出任意直径不超过一的输入。第150轮60点和第156轮18点也分别用恒等姿态直接核验，最小边余量均大于 \(2.15\times10^{-14}\)。

## 净面积差

新增线的斜率介于两条原外侧线，且满足 \(a<a_1\)、\(a<p_2b\)。因此新增帽局限在原 AH 直段上方的正 \(w\) 部分，和原配对曲线没有新增交点。按斜率排序，由相邻线的精确交点递增构造旧、新两个凸分段线性包络。新包络的四个折点约在 \(w=0.000045488,0.338000,0.349000,0.40997846\)。将两包络在变动部分的折点和端点叠合。每个小区间上的新旧边界都为仿射函数。相应顶点在旧曲线内侧多边形的最小支撑余量严格大于 \(2.50\times10^{-10}\)，由凸性可把整个折线间区域算作新裁切。

将两包络的高度差按各小区间作梯形积分，再乘坐标面积因子 \(L^2\)，得到严格有理面积差端点。第167轮的其他积分保持原值。记录中的两个新总面积端点直接由相应有理区间相减得到。

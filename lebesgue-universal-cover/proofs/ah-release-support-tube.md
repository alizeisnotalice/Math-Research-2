# 六夹带归一化下的支撑邻域和任意曲率扰动

设 C 是 [按位置外移的65线宿主](ah-tapered-release.md)，σ=1.5497°，真实面积小于 .844081601570555161。令 B 是以原点为圆心、半径 1/2 的圆盘，H 是宽一正六边形。以下 K 是任意已置于 H 的定宽一凸体。记 d 为 Hausdorff 距离，即单位方向上支撑函数差的上确界。

1. 若 w∈[.427,1]，0≤t≤1，且 K 与 (1−t)K_w+tR 或 (1−t)K_w+tQ_A R 的距离不超过 **7.5×10⁻⁷**，则 C 容纳 K。
2. 若 λ、α、β 非负且和为一，K 与 S=λK_w+αR+βQ_A R 的距离不超过 **4.5×10⁻⁸**，则 C 容纳 K。
3. 若 d(K,B)≤**.0046845**，则 C 容纳 K。

这些结论对无限多个支撑方向和任意合法曲率密度成立。它们给出该候选的实际覆盖域；一般直径一体的覆盖结论仍然开放。

**第一项。** 在原支撑放置程序中，每条直接决定的非六边形单位法向支撑都额外预留 7.5×10⁻⁷。六条 H 边对 K 与参考体同为精确接触。在两种姿态各只留下 m₅ 或 m₃ 未决的闭格上，使用实际 K 的恒宽关系 h_K(u)+h_K(−u)=1 选择至少一姿态，故该二择允许等号。其余直接行的误差均不超过预留量。两斜帽和六夹带成立后，五段真 Sprague 圆弧由实际 K 的接触支持。t∈[0,1] 的两种符号分别有13839和536个终端盒，其中互补选择分别占4418和38个盒。两个独立 Python 环境对最终证书逐字节一致。

**第三项。** 对圆盘 B，除了六个 H 面及两个斜帽外的全部直接边都留出至少 .0046845410；五段 Sprague 弧交给 P 的强制接触。考虑六个正斜外法向 mⱼ。由于 h_K(mⱼ)+h_K(mⱼ₊₃)=1，至少三个指标满足 h_K(mⱼ)≤1/2。这些指标中至少两个同奇偶，彼此相差2或4模6。用一个六十度整数倍的旋转，将这两个指标送到宿主所需的 m₃、m₅。该姿态对圆盘不动，其余直边因距离小于其净余量而通过。

**第二项。** 令 z=1−2min(α,β)。由 R+Q_A R=2B，存在第一项中的某个 X 使 S=zX+(1−z)B；z=0 时 S=B。取 z≥.06。若原证书在 X 上某行预留 ε=7.5×10⁻⁷，而 B 也满足该边，则 S 在这一行至少预留 zε≥4.5×10⁻⁸。互补支撑选择继续在实际 K 上作出。若 z<.06，则六边形外接半径 1/√3 给 h_X≤1/√3，定宽性又给 h_X≥1−1/√3，从而

\[
d(K,B)\le 4.5\times10^{-8}+.06(1/\sqrt{3}-1/2)<.0046845.
\]

第三项给出此类的摆放。

## 六个60°区间上的曲率判据

固定上文允许的参考体 S。定宽一支撑 h 的曲率测度满足 ρ(θ)+ρ(θ+π)=1，故有 0≤ρ≤1 的 Lebesgue 密度。K 和 S 在六个边法向 θⱼ 处同为 1/2。每个区间 [a,a+L]，L=π/3，支撑差 y=h_K−h_S 满足两端为零的 y″+y=f，其中 f=ρ_K−ρ_S。以局部坐标 x,v∈[0,L]，算子 −∂²−1 的正 Dirichlet Green 核为

\[
G(x,v)=\frac{\sin(\min(x,v))\sin(L-\max(x,v))}{\sin L}.
\]

因此 y=−∫Gf。核的最大值为 1/(2√3)，核的最大积分为 2/√3−1。又令 F(v)=∫₀ᵛ f；G(x,·)由零上升到 G(x,x) 再下降到零，分部积分并从 F 减去其上下值的中点，得

\[
|y(x)|\le \frac{\operatorname{osc}F}{2\sqrt{3}}.
\]

于是对相应支撑半径 η，只要六个区间各自满足以下三项中的任一项，就能应用对应结论：

\[
\int|f|\le 2\sqrt{3}\,\eta,\qquad
\operatorname{osc}_{v}\!\int_0^v f\le 2\sqrt{3}\,\eta,\qquad
\|f\|_\infty\le \eta/(2/\sqrt{3}-1).
\]

这一判据容许任意方向的密度变化，包括大量细尺度振荡。以 B 为参考，所有满足 \(\|\rho_K-\tfrac12\|_\infty\le .03\) 的定宽一凸体均能放入 C。先用正六边形归一化定理选择 K 的姿态，由 \(.03(2/\sqrt{3}-1)<.0046845\) 即得。旋转、反射和平移均保留该密度条件。

# 十八个有理点的整叶证书

在原始五体树分片 180 的前序原叶 23955 的全部十一维闭盒中，加入 finite-point-18-input.json 给出的 18 个有理点的任意刚体副本后，凸包面积严格超过 $0.83730$。点坐标公共分母为 $10^{10}$，全部点对距离平方的最大分子是 $99999999592924156114<10^{20}$。点集关于横轴对称，两种手性均已涵盖。

这个输入来自研判文档第 5.2 节的固定接触模板。初始十八点由九项 Fourier 体的十八个等距法向采样，再将各点的两个坐标作为未知量。每个角格的每个给定法向先固定一个点的编号。三法向取由行列式确定的平衡权重 $w_j$，以 30 点对照的同一角格加权支撑下端 $b$ 为基准。对格端点 $\omega$ 同时要求
$$
 \sum_j w_j n_j\cdot R_\omega p_{a(j)}\ge b+\eta .
$$
这里权重归一为和一。优化目标是最大化共同余量 $\eta$，同时要求点集关于横轴对称、水平坐标和为零以及 $\lVert p_i-p_j\rVert_2\le1$。先以当前点对差的方向给直径约束加线性割，再沿违反圆约束的方向迭代补割。每次浮点解求出后按其最大实际点对距离略作收缩，换用最有利的材料编号重复。该搜索只产生有理见证。对最终取整后的坐标独立逐对验直径、逐格验面积。尽管所求得的搜索代理余量约为 $-0.00123$，真实原叶的闭盒证明仍然通过，因为原叶只要求每个角格的某一平衡三元组补足特定子盒的面积差额。

全周 384 个闭格、1482 个有理三元组和对应 18 点编号已归档。严格复算访问 $1,972,721$ 个节点，由原五体面积关闭 $49,014$ 个终端，由十八点新增支撑关闭 $937,347$ 个终端，最大深度 70。证明与三十点整叶所用的面积尖帽和逐格整数比较相同；此输入的分母、坐标、各材料编号和全叶重算回执均另行给出。

在 computation 目录运行

```sh
python -I -B certify_finite_point_leaf.py CERT TABLE NEW CACHE --input finite-point-18-input.json
```

原五体加这 18 点在整个姿态空间中的最小面积，以及容许闭合该原叶的最小点数，均未由此确定。

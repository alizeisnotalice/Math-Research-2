# 一条跨越 AH 直段与配对曲线的裁线

固定 \(p=0.427\)、\(\delta=0.000595\) 弧度，沿用第126轮的两段 EH。所成凸万能覆盖的真实面积满足

\[
0.844093374562671835178166470806391361029 < |H| < 0.844093374562671835178166470806391361030.
\]

沿用 `ah-fine-pivot.md` 的分扇有向误差法和自适应根括。对增深后的物理帽重新计算每一格的图亏损、触发、图端、配对和正向导数上界。相容根和同一姿态下的支撑不等式全部重新认证。2585个参数格和31020个角格中，最坏摆放余量位于第34参考格且大于 \(0.0001200326189\)，最小根端余量在第40参考格且大于 \(1.0019553\times10^{-6}\)。双命中根姿态避开整个深度 \(0.000555\) 的 EH 包络，原真实 Sprague 圆弧由同一摆放的接触推出。其他摆放采用第126轮的 EH 根后 AH 反射及该新帽实际重算的 AH 触发。任意直径至多一的输入通过定宽补全得到摆放。

新线在物理区间 \([-0.072,0.427]\) 的两个端点均严格高于第167轮三条旧线。由仿射性，它在整个区间上占优，因而全帽由一条新线承担。已认证凸边界和两端异号条件表明，帽边界由 \(W=Z+pD\)、直段至 \(Z\)、配对弧 \(q([0,r])\) 及返回 \(W\) 的新线围成。新帽各点满足 \(y>0.518\)，与位于负纵坐标的 EH 新帽不交。把坐标原点移至 \(W\)，两侧直段在 Green 公式中的贡献为零，故真实帽面积为

\[
\tfrac12\int_0^r (q(w)-W)\times q'(w)\,dw.
\]

在 \([0,0.07]\) 上作112次有理区间二分，记录严格异号交根及局部导数下界。对有理左端以内用24格、14阶 Taylor 有理区间积分，最后对短根括的弧端误差单独包围。最后从同角 Gibbs 真实面积区间减去第126轮真实 EH 增益和此次真弧积分的有理端点。60点与18点的归档测试体在恒等姿态下均直接通过。

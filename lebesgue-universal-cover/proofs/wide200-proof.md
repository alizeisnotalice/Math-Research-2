# 更宽图窗的双线 AH 与十一段 EH

取尾线铰点 $p_A\in[.4268,.427]$、转角 $\delta_A\in[.00479,.0048]$。取前线铰点 $p_B\in[.4025,.403]$、转角 $\delta_B\in[.006095,.00610]$。这些区间的有限小数均按有理数读入。最深角点保留原配对曲线 $q(.200)$，物理投影左端取 $-.230$，图管半宽取 $.0057$。核验图逆偏导时把两个坐标轴分别细化到十二段，并沿真配对曲线的物理高度下界截去无效矩形。每个剩余格以这个高度下界和格中横坐标为基点重新估计实际图亏损。选择较大实际亏损为首点后，按手性保存首点和第二点两个不同上界。

前两个根括基于同一个输入体。在三个最早的参考格上，真实相容函数满足 $F(14^\circ)>0$ 和

$$
F(36^\circ)-F(23^\circ)>\tau,\qquad \tau=12/10^6.
$$

如果 $F(23^\circ)\le-\tau$，则在 $[14^\circ,23^\circ]$ 有根。否则，$F(36^\circ)>0$，且用同一条件验证 $F(46^\circ)<0$。右根分支的支撑余量 $M$ 由 $M-\lambda(F(23^\circ)+\tau)$ 下界认证，$\lambda$ 取非负有理系数。三个方向的相容函数与三个定平移的支撑方向共用实际接触坐标。区间计算分别验证根不存在的角格和有一个同姿态全边通过的角格。最弱一个 $F(36^\circ)-F(23^\circ)$ 的严格下界超过 $1.25901173\times10^{-5}$。其余参考格用已给定的普通根括及有向接触偏导，共覆盖68个非零参考格。

把十一段 EH 的最深单弦直接加入所有 AH 根的支撑行。一旦一个相容摆放避开该单弦帽，它同时避开全部十一段 EH 裁去的耳。这样计算无需从无关 AH 边的微小净余量扣除 EH 换弦估计。EH 的其它摆放分支仍以冻结的十七种命中符号和63份非负对偶复算。含 EH 耳的矩形在最深两条 AH 线以内有大于 .45936 的净距，故两处裁切面积可相加。同一个最深宿主摆放适用于参数盒内所有成员，其最后余量仍严格大于 $1.13876\times10^{-8}$。

较短的前线在配对弧和两线正高度交点前承担裁切。其真实帽面积用有理区间 Taylor 余项的 Green 积分包围。接续长缓线再裁去一个由两铰点和交点组成的三角形。采用正部高度的全空间单调性，分别用最深和最浅角点的有理面积端点夹住整族。再以经过十一段 EH 的共同固定面积扣减完成组合，得到

$$
0.844092143976411245816610250110475257401
< |H|
< 0.844092148025341633873505044965374228667.
$$

最深角点给出的组合面积上端为 $0.844092143976411245816611655908337527565$。整族上端较同一 EH 底座的 $(p,\delta)=(.427,.0056)$ 单弦严格低 $2.03735\times10^{-8}$ 以上。


## 复算文件

```sh
python -B computation/certify_ah_pinned_family.py computation computation/wide200-403-input.json AH.json
python -B computation/certify_eh_with_direct_ah_row.py computation AH.json \
  computation/eh-upper-chain-parameters.json computation/eh-upper-chain-weights.json EH.json
```

这两个入口还需要 `certify_ah_wide_physical_floor.py` 和 `certify_ah_direct_eh_row.py`，以及既有真 Green 面积、同一体双根、十一段 EH 几何和正对偶代码。输入和完整输出为 `wide200-403-input.json`、`wide200-403-certificate.json`、`wide200-403-combined.json`。

MacBook 的三批 Metal 在 .200 图窗实际筛查199580个参数盒，总计655819880次物理格评分。较激进的浮点面积首选仍需要更强的早端符号证明。严格端点由 Arb 计算承担。

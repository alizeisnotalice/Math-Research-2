# EH 连续摆放中的五段 Sprague 真弧

采用第90轮有理斜角 \(\sigma=1.5497^\circ\)。对相容根所给的连续摆放，只需另验 AH 的两段曲线、AH 直段、新 EH 弦和两条正斜帽线。五段继承自 Sprague 的圆弧均由已验证的 \(P\) 内含性与定宽性推出。

设 \(K\subset P\) 为定宽一凸体。第28轮的接触结论给出五个线段 \([c,d]\) 内各有 \(a\in K\)。对对应的以 \(c\) 为心的单位圆弧，设 \(u\) 为单位径向。若 \(u\cdot(d-c)\le0\)，则

\[
h_K(u)\le u\cdot a+1\le u\cdot c+1.
\]

第一步只用 \(K\subset\overline B(a,1)\)。这给出圆弧在 \(c+u\) 处的**整条支撑线**约束。短弧两个端径向满足同号不等式，则内径向为其归一化正组合，从而整段成立。

| 继承圆弧 | 圆心 | 强制接触线段 | 原完整短弧 |
| --- | --- | --- | --- |
| \(G\to K\) | \(F_3\) | \([F_3,F_2]\) | \(G\) 至 \(K\) |
| \(T\to I\) | \(B_3\) | \([B_3,B_2]\) | \(J\) 至 \(I\) |
| \(H\to U_1\) | \(C_3\) | \([C_3,B_1]\) | \(H\) 至 \(J\) |
| \(T'\to P\) | \(G\) | \([G,D_1]\) | \(X_{AS}\) 至 \(P\) |
| \(Q\to Y\) | \(E_3\) | \([E_3,D_1]\) | \(Q\) 至 \(X_{AS}\) |

每个完整短弧有一个端点是圆心在对应外支撑线的正交投影。圆心在反侧平行线上，所以该端径向与接触线段方向严格正交，点积恰为零。另一个端径向点积严格为负。独立的 160 位 Arb 重算在第90轮斜角给出五个负点积的绝对值分别超过 \(0.00393185,0.00387695,0.00600964,0.05960469,0.06564327\)。原短弧次序和各继承弧的子弧关系来自第28、34、62、90轮的几何。

保留已用内弦处理的 AH 两段曲线及所有相关直边。以这些直边端点和五条真弧的并取凸包，得到仍在候选体内的凸体。原凸边界的顺序保证，每条保留内弦的其余边界点都在该内弦的保留侧。新凸体的边界由这些内弦、未变的直边与保留真弧组成。其圆弧与临接直边交点的支持法锥由两侧极端法向生成。因此只要相容根姿态满足六条原六边形边以及两条正斜帽线，就已有 \(K\subset P\)，从而同时满足五段真弧。其余直边和内弦由第90轮的线性对偶验证。

在 \(\delta=0.00010565\) 上，旧 R90 证书可直接删去对应内弦的行，不需要再调用求解器。实际重放由 28 条非六边形边、33 个边角格、64 个对偶减为 12 条边、17 格和 32 个对偶。最小严格余量仍为真 \(m_5\) 截线 \(K\to C_3\) 的 \(2.8984359887\ldots\times10^{-8}\)。所以五段真弧在此没有限制切深。

## 真 \(m_5\) 截线的有限见证

对 \(\delta=0.000106\)，存在一组 19 点 \(X\)，其中八个距离为一的点对由单位向量差直接构造，其余平方距离距一的最小余量超过 \(8.5244\times10^{-9}\)。输入的 19 个标量是有理数，三个相容根方向的点 \(p_0,p_1,p_2\) 中，\(p_2\) 只用代数公式修正其沿 \(v_2\) 的分量。任一定宽一补全 \(K\) 包含 \(X\)，由三组原六边形边的对径点与两个斜帽各自的反向见证，必有 \(K,Q_2K\subset P\)。两体各包含一个严格的新耳内点，所以皆命中 F′ 且避开 C′，从而避开 AH。将 F′ 反射成 A 可见两体都命中 A，两个 \(-m_5\) 的反向见证反射成 A′ 也有严格余量。

取 \(\phi_0=31.054^\circ\)、\(\theta=240^\circ-\phi_0\)，并记 \(v_i=R_{-\theta}n_i\)。点集包含 \(p_i,p_i-v_i\) 三组单位点对，因此在任何补全内 \(h_K(v_i)=v_i\cdot p_i\)，而构造给出 \(v_0\cdot p_0-v_1\cdot p_1+v_2\cdot p_2=1/2\)。这锁定相容根和六边形中心平移。该姿态中有一点超过正 \(m_5\) 帽线，严格余量超过 \(4.40659\times10^{-9}\)。

可以进一步排除在 \([30^\circ,31.354^\circ]\) 改选另一个右根。对 \(30^\circ\) 至 \(\phi_0-0.3^\circ\)，用 \(L=\bigcap_{x\in X}\overline B(x,1)\) 的支持上界与定宽关系直接计算，给出统一 \(F_K>2.9935\times10^{-4}\)。对离 \(\phi_0\) 不超过 \(0.3^\circ\) 的角，相容函数的角导数严格小于 \(-0.02756\)。后一个估计来自如下支撑点界。若 \(p,p-u\) 是一对已知单位反点，\(p'\) 支撑邻近单位方向 \(u'\)，则

\[
 |p'-p|^2\le 2u\cdot(p-p')\le2|u-u'|\,|p'-p|.
\]

由支撑点唯一性及角导数公式，单个支撑值的角导数差的绝对值不超过 \((2+0.6)|u-u'|\)，因为体在原六边形内。合并三项，直接用根处三个已知的 \(p_i\) 给出负导数。以上限于第90轮所选的那一个六边形姿态，未给一般万能覆盖的下界。

实际计算以 160 位 Arb 对 `computation/eh-m5-obstruction-input.json` 重放。另两个较深切处的同类结果一并收入证书。

```sh
python -B computation/certify_eh_m5_obstruction.py computation/eh-m5-obstruction-input.json OUTPUT.json
```

## 两个相邻的六边形姿态

设已找到第90轮的右相容根 \(\phi\)，并将体按 \(\theta=240^\circ-\phi\) 旋转后平移到六条原六边形边的唯一中心姿态 \(C\)。若 \(h_C(m_5)\le1/2\)，用 \(C\)。若 \(h_C(m_5)>1/2\)，用 \(C'=R_{60^\circ}C\)。后一个姿态自动满足

\[
h_{C'}(m_3)=h_C(m_2)=1-h_C(m_5)<1/2,
\]

因为 \(R_{-60^\circ}m_3=m_2=-m_5\)。两姿态保持原六边形，故若分别核验 \(C\) 除了正 \(m_5\) 帽线之外的所有新边，以及 \(C'\) 除了正 \(m_3\) 帽线之外的所有新边，就能无条件选择一个姿态进入候选体。五条真 Sprague 弧随后的约束由上面的解析结论补齐。

第二姿态可以在同一个四点支撑模型中核验，将第90轮计算的角参数由 \(\phi\) 换成 \(\phi-60^\circ\)。两次计算的物理旋转恰差 \(60^\circ\)，相容关系因 \(F(\phi-60^\circ)=-F(\phi)\) 保持。第二次使用两条原六边形边求出的平移正是第一姿态平移的 \(60^\circ\) 旋转，因为它也满足中心化等式且解唯一。两套含 \(\mu F\) 的线性目标各自使用经过严格核验的角格与非负对偶。

在 \(\sigma=1.5497^\circ,\delta=0.0002\)，所取右根区间为 \([30^\circ,31.8^\circ]\)，右端统一 \(F_K<-1.70532\times10^{-4}\)。两个姿态的 22 条非六边形边分别经过 23 个边角格与 47 组端点对偶，最小严格余量超过 \(3.73786\times10^{-5}\)，出现在第一姿态的新 EH 弦。此切深的其余遮盖分支跟随第62、90轮，并逐项重算新弦所需的弧序、S 圆和 E′ 帽条件。由第90轮同一斜角处的旧面积严格上端减去新帽下端，得到一般上界 \(\Lambda<0.844093549565233228\)。证书已在不调用 SciPy 的环境中逐字节重放。

在相同斜角和切深 \(0.0003\) 时，右根区间改为 \([30^\circ,33^\circ]\)，右端统一 \(F_K<-5.40933\times10^{-4}\)。24 个边角格、48 组对偶给出最小严格余量超过 \(4.76460\times10^{-7}\)，主动边仍是第一姿态的新 EH 弦。新增帽面积严格大于 \(6.72949662757294495\times10^{-8}\)，从而

\[
\Lambda<0.844093527093146240.
\]

第二个证书也在无 SciPy 环境中逐字节重放。

切深进一步取 \(0.00036\)，保留右根区间 \([30^\circ,33^\circ]\)。右端严格 \(F_K<-1.63209\times10^{-4}\)。27 个边角格与 51 组对偶给出最小余量大于 \(7.56957\times10^{-7}\)，主动边为第一姿态的 EH 弦。新增帽面积严格大于 \(8.07979134887366038\times10^{-8}\)，故一般上界提高为

\[
\Lambda<0.844093513590199027.
\]

该证书及有限 \(m_5\) 见证都已逐字节重放。对 \(0.000375\) 继续抽检，当前第一姿态的 EH 弦上界对测试乘子失去严格正余量。两姿态中的正斜帽由互补式处理，新的主动困难出现在 EH 弦。

```sh

  --old-area computation/eh-joint-1p5497-old-area.json \
  --replay computation/eh-cap-switch-200.json
python -B computation/certify_eh_cap_switch.py 1.5497 0.0003 33 OUTPUT.json \
  --old-area computation/eh-joint-1p5497-old-area.json \
  --replay computation/eh-cap-switch-300.json
python -B computation/certify_eh_cap_switch.py 1.5497 0.00036 33 OUTPUT.json \
  --old-area computation/eh-joint-1p5497-old-area.json \

```

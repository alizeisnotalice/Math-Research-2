# 十一点新输入在原树留出叶上的检验

训练只使用四体极小凸包和第108轮竞争凸包。用固定种子 20261118 从 onegroup65535 的真实剩余原叶快照按分片取样，保留 20 个从未用于选法向或优化点坐标的原叶。所选叶包含第180片的23955叶。重放重新核对快照成员、原树清单、节点类型和分母 $2^{44}$ 的原坐标端点。

对每个留出盒先检验盒心的实际宿主，再检验整个闭盒。以某方向 $u$ 为例，若一个三、五、七或九边形的平移坐标半宽为 $e_x,e_y$，角度半宽为 $e_\theta$，则它的支撑上端可取
$$
 h_{\mathrm{center}}(u)+|u_x|e_x+|u_y|e_y+L_ne_\theta,
 \qquad L_n>\tfrac12\tan(\pi/(2n)).
$$
圆盘保持原有支撑值。各体的上端取最大值，再用于正向及反向整周的三个平衡支持方向证书。

20 个盒心全部严格需要大于 $10^{-6}$ 的外扩。完整闭盒中，第182片19870叶严格需要大于 $0.00005$ 的外扩，第1204片28722叶严格需要大于 $0.00010$。前者的两手各核验88个闭角格，后者各核验67个。其余盒仍待判断。

若加入点集后的总面积小于 $T=0.83730$，向外突出至少 $s$ 的一点与圆盘的一条直径形成三角形。该点到圆心的法向投影至多 $2T$，故支撑线之外的三角形部分面积超过 $s^2/(4T)$。结合第113轮五体严格下界 $0.8371$，两个整闭盒分别得到六输入面积严格大于 $0.837100000746446\ldots$ 与 $0.837100002985787\ldots$。若增广面积已至少为 $T$，这两个较小的界也自动成立。

在 computation 目录执行

    python -B replay_multi_host_holdout.py TREE \
      multi-host-holdout-source.json multi-host-holdout.json multi-host-points.json

TREE 为原 cert11d_08366 目录。两套本机 Python 环境的严格输出逐字节一致。上述全闭盒支持排斥还没有在 $0.83730$ 门槛完成面积排除。

# 连续转角区间的共同内体

设光滑定宽体的支撑函数为 h(u)=1/2+cos(3u)/80−19cos(5u)/1200，u 表示法线角。若中心角为 c，目标角与 c 的弧度距离至多 Δ，则旋转体支撑函数满足

    h(u−θ) ≥ h(u−c)−(7/60)Δ.

这是中值定理，因为 h' 的两个正弦项振幅和为 3/80+19/240=7/60，在 u=π/2 取到正最大值。又 h+h''=1−1/2−cos(3u)/10+19cos(5u)/50 ≥ 1/50。故对 (7/60)Δ ≤ δ ≤ 1/50，函数 g(u)=h(u−c)−δ 满足 g+g''≥0。其支持点为 g(u)n(u)+g'(u)n'(u)，其中 n(u)=(cos u,sin u)。直接验证：这个参数点关于 u 的导数为 (g+g'')n'(u)，投影到固定方向 n(v) 后，导数为 (g+g'')sin(v−u)。故该投影的最大值在 u=v 达到，等于 g(v)。其凸包的支撑函数正是 g。由于 g 不超过每个目标转角体的支撑函数，这个凸包同时包含在它们之内。

把整圆等分成 32 个角区间，则 Δ=π/32。取 δ=11/960，用 π<22/7 得 (7/60)Δ<δ<1/50。对任意法向可用中心旋转体的支持点沿负法向移动 δ，产生整个角区间共同可用的材料点。平移只须加在最终材料坐标上一次。若坐标还要取有理近似，应在内移量上另加欧氏舍入误差上界，并保证总内移量至多 1/50。以上给出连续角材料的合法性。使用这些点排除特定参数盒仍须核验盒内的面积。

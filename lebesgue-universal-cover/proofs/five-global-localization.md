# 五体面积在 0.837295006222 以下的放置区域

固定圆盘中心与三边形方向，取 $0\le\theta_5\le\pi/15$ 的对称规范代表。记 $T=0.837295006222$。每个面积不超过 $T$ 的五体放置，都有一个代表位于附表列出的 19 个原始根分片的 501 个原闭叶中。特别地，该必要条件适用于全域极小点，因为已有五体可行构形面积严格小于 $T$。

## 覆盖与判据

第 92 轮的二面体作用与五边形周期给出上述角域。圆盘与各单体的整格径向估计给出 $\lVert t_i\rVert_2<r_i$，其中 $r_i$ 依次为 $0.06835,0.06650,0.06004,0.05699$。七、九边形保留完整转角周期。原始树各平移边界的绝对值都大于相应 $r_i$；角域也包含全部规范转角。因此树外无需采用原源码的历史面积判定。

重放程序加载已固定摘要的原始树清单，对每片重算分支和规范掩码。以 $2^{-44}$ 为坐标单位，将五边形上端放宽至 $\lceil 2^{44}(0.20943951024)\rceil$，四体半径向上取整。若 $x,y$ 区间内的绝对值下端为 $m_x,m_y$、外半径整数为 $R$，则当 $m_x^2+m_y^2>R^2$ 时整盒在次水平集外。否则可与 $|x|\le\lceil\sqrt{R^2-m_y^2}\rceil$、$|y|\le\lceil\sqrt{R^2-m_x^2}\rceil$ 取交集，平方根用整数比较修正。

其余剪枝使用逐体、逐体对合并误差的整数扇形，见《十一维五体扇形的共同旋转与平移误差》。相邻同体边可计入位于相应角楔内的圆扇形或抛物带。整数两倍面积的门槛 $120666927296658443/2^{57}$ 严格大于 $T$。若整盒不通过，沿所选整坐标取 $m=l+\lfloor(h-l)/2\rfloor$，仅当两个闭子盒都通过才接受父盒。耗完预算保留原叶。每一阶段从上阶段保留叶的全集继续；所有原叶分类和面积剪枝均现算。

## 剩余盒与重放

five-global-localization.json 中 rows 按全部 2,048 根的编号排序，列为根编号、初始叶数、每轮的剩余数和访问数。retained 字典逐片列出这 501 个原叶的 0 基前序位置。envelopes 给出每个分片剩余闭盒的总坐标包络，envelope 为全体包络；下、上端点均采用分母 $2^{44}$，未经圆盘或五边形上端裁缩。重放逐坐标重新解码每个剩余原叶并核对所有包络。余叶最多的是分片 1205、180、181、176，分别有 92、57、52、52 叶。构形 $p_*$ 位于分片 180 的前序叶 23955。

在 computation 中运行下列命令，其中 CERT 指已提取的 Tomar v9 证书，NEW 是尚不存在的输出目录，CACHE 是已有共享编译缓存或其新建子目录。

```sh
python -I -B replay_five_global_localization.py CERT NEW CACHE --workers 4
```

入口重新生成并认证 32 等分见证表，复算四个径向界，编译带有符号整数溢出检查的 C++ 内核，对选定的原根从头执行四个阶段，检查逐片计数、坐标包络及原叶编号。可用 --parts 0,180,256 重放普通根、含已知驻点的难根和完全在规范切片外的根。可选 --table 指定已有母表；仍逐点验证。依赖 Python、NumPy、SciPy、python-flint 及支持 128 位整数和溢出陷阱的 Clang。四阶段单入口已在空目录生成材料表并逐点复核，重放全部 2,048 根、逐个核对 501 个余叶及其包络。归档回执为 five-global-localization-replay.json。作为独立交叉检查，另一路在各阶段插入经现场复算的其他剪枝，在第三阶段结束时所余的 1,759 个原叶与本通路逐号相同。该定位结论尚未判定这些余盒内的全域极小值。

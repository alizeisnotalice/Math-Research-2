# 三次谐波和正多边形法向的定量支撑障碍

取 $u(t)=(\cos t,\sin t)$，$0<c\le 1/16$。支撑函数 $1/2+c\cos3t$ 定义定宽一凸体 $K$，因为相对两个方向的支撑和为一，曲率半径 $1/2-8c\cos3t$ 非负。反射像也是旋转像。令 $n=5$ 或 $n\ge7$。对任何平移 $p$、角相位 $\gamma$ 及 $n$ 个正多边形单位外法向 $u(t_j)$，有
\[
 \max_j\{\langle p,u(t_j)\rangle+c\cos(3t_j-\gamma)\}\ \ge\ c/2.
\]
所以容纳 $K$ 的任何凸集，在这些法向上至少有一条支撑高度达到 $1/2+c/2$。原点和法向组的共同旋角均可自由选择。

**正权消去平移。** 写 $w_j=(1+\cos(3t_j-\gamma))/n$。这些权重非负，和为一。正多边形的非平凡单位根之和为零。分别用频数 $1,2,4$ 得 $\sum_jw_j u(t_j)=0$，用频数 $3,6$ 得 $\sum_jw_j\cos(3t_j-\gamma)=1/2$。因此括号的加权和正是 $c/2$。六个法向时频数6退化为常数。对正六边形可选相位使各三次谐波样本全为零。

**五个法向上的锐性。** 取 $t_j=2\pi j/5$，令 $p=(-c,0)$、$\gamma=\pi$。五个超额为 $-c(\cos t_j+\cos3t_j)$。在 $j=1,2,3,4$ 时，两个余弦之和为 $-1/2$，在 $j=0$ 时为2。故规则五方向的最小最大超额恰为 $c/2$。在 $c=1/16$ 时，这个定宽体的精确均匀外移需求为 $1/32$。

**允许方向彼此独立扰动。** 设 $|\tilde t_j-t_j|\le\alpha$（弧度），$b=\cos(\pi/n+\alpha)>0$，记
\[
 \delta=\max_j \{\langle p,u(\tilde t_j)\rangle+c\cos(3\tilde t_j-\gamma)\}.
\]
每一方向距某个 $\tilde t_j$ 至多 $\pi/n+\alpha$，故 $\delta\ge |p|b-c$。又因为正弦余弦的导数绝对值有界，每一项受扰动所损失的量至多 $(|p|+3c)\alpha$。代入规则法向下界并消去 $|p|$ 得
\[
 \delta\ \ge\ c\,\frac{1/2-3\alpha-\alpha/b}{1+\alpha/b}.
\]
对 $n\ge5$ 可统一使用 $b=\cos(\pi/5+\alpha)$。此条件只检验选定方向的支撑，可直接应用于曲边宿主。固定笛卡儿原点后若令正五边形模板旋满一周，每个相位都有至少一个方向的支撑达到 $1/2+c/2$。对相位积分，满足该支撑下界的角度集合测度至少为 $2\pi/5$。这个结论还可用于有其他支撑约束的宿主；单凭它尚不足以给一般面积界。[有理及区间数值](../computation/broken-strips/regular-release.json)

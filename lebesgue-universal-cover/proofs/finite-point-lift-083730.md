# 同一三十点输入的 0.83730 全域下界

固定 finite-point-leaf-input.json 中的三十个有理点 $P$。圆盘、正定宽三、五、七、九边形及 $P$ 的任意六个独立全等副本，其联合凸包面积严格大于 $0.83730$。此处六种输入中的第六种是同一组直径小于一的三十点，允许独立平移、旋转和反射。

原五体在更高门槛 $T=0.83730$ 的外域证明给出额外 40 个原叶，连同旧定位中保留的 501 个原叶共有 541 个，两组前序索引不相交。外围使用原五体的面积分数和这一门槛上仍然有效的四个径向界。新的补域证书逐项核对这两个原叶集合的并集。在这 541 个原叶内全部重新计算面积，不使用此前在较低门槛通过的原叶面积。其余规范区域沿用同一门槛的五体外围证明。设六体面积至多 $T$，其中的五体面积也至多 $T$，必落在这 541 个原叶中的一个，遂与下述全叶验证矛盾。固定圆盘后，联合凸包内每个点 $x$ 与垂直于 $x$ 的圆盘直径作出的三角形给出 $|x|\le2A$；次水平集紧性保证极小值达到，故六体最小面积和一般凸万能覆盖最小面积均严格大于 $T$。

材料点、反射对称性、384 个闭角格和 2493 个三元组均与前一固定三十点证书相同。每个法向只使用在该格指定的输入点。三个整数权重精确抵消平移；正弦余弦的格内不等式、原五体支撑的外端点和尖帽面积的核验见 finite-point-five-body-leaf.md。这个比较逐个角格核验有限输入的支撑，全部通过时才排除一个十一维闭盒。

四轮按每原叶调用上限 65,535、262,143、1,048,575、4,194,303，依次把 541 个未决原叶缩至 300、38、4、0。最终只保留每原叶的整棵成功二叉树，重放 50,124,311 个节点，其中 18,237,508 个终端由原五体下端关闭，6,824,918 个由三十点新增面积关闭。372 个原叶使用了至少一个新点终端。整数门槛是 $120667646975914122/2^{57}>0.83730$。面积末端全部覆盖；外域或半径排除涉及的独立不等式仍按各自原证明处理。

在 computation 目录运行如下命令。OUTER 指同门槛的五体外围索引 tomar-outer-083730-retained.json，其 SHA-256 为 901f258d9a4ff75fa3cf3d788d487c2890b179e3c256ec813bb0c0845c7c7969。其余输入与三十点补域的前次重放相同。

```sh
python -I -B replay_finite_point_global.py CERT TABLE32 TABLE64 NEW CACHE --workers 4 --lift finite-point-lift-083730.json --outer OUTER
```

可用 --parts 限定局部试算。整批入口核对原树和两张材料表、新旧待证原叶的并集，验证三十点坐标和全体接触三元组，并逐叶逐项比对成功树统计。光滑 Fourier 体仅用于早期寻找点集和法向，本证明的三元组分子只含有限有理点坐标。

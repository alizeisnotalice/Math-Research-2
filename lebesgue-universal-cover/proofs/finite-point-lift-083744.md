# 五个定宽体与三十点在全部放置下的面积下界 0.83744

取圆盘、四个正定宽奇边形 $B_3,B_5,B_7,B_9$ 以及冻结的有理三十点集。它们在任意独立刚体放置下的联合凸包面积至少为 $G=120687823102244742/2^{57}>0.83744$。任一凸万能覆盖能容纳各测试输入，故其面积亦满足此界。

本靶五体外围的四层从 304,462 个待查原叶依次缩至 101,859、17,047、5,644、2,963。它保留上靶全部 2,659 叶，新增 304 叶。坐标是原树 $2^{-44}$ 单位的完整闭区间。对同一份 2,963 原叶清单，以下三类逐号不交，且逐号并集相等。

| 终止证明 | 原叶 | 访问节点 | 三十点终端 |
|---|---:|---:|---:|
| 32/64 级原材料表与方向加权联合帽 | 2,833 | 834,556,633 | 224,648,659 |
| 整原叶五体动态面积 | 124 | 227,226 | 0 |
| 加密材料表与方向加权联合帽 | 6 | 17,613,580 | 7,948,166 |

第一类含 1,396 棵 32 级树、1,437 棵 64 级树和 192,631,074 个五体终端。第二类的 124 个完整原叶均单独达到 0.837445，共 60,510 个终端。第三类为 176 片 35174、35426、35428 及 180 片 23933、23934、24225。每棵从整原叶开始，沿用原 1,632 个材料点并加入 2,336 个已经逐锚点验证属于缩率 0.999999006 曲体的材料点。正权方向平衡消去三十点集的任意平移，全部转角闭区间及反射对称性处理任意刚体放置。该加密改变计算中对已有五体的内逼近，六个测试输入保持固定。

首轮普通计算分 MacBook 2,015 叶与本机 824 叶。MacBook 2,011 叶和本机 822 叶直接通过。四个 MacBook 触限叶分别进入三个加密树及一个纯五体树。本机 176/35174 触限，176/35426 在加密整叶已通过后结束重复的普通计算。两者与预先单列的 180/24225 均使用整原叶加密证书。另 123 个原叶预先进入五体动态面积核。由此可从原始分工逐号得到表中的最终分类。

六组有限有理输入各含 1024、648、650、651、648、30 点。记 $C$ 为其同姿态凸包，取 $e=236329089467/80372250000000000$。经验证的内逼近使曲体与三十点的凸包包含于 $C+eB$，且 $C$ 含半径 $r=1/2-e$ 的圆盘。Steiner 公式及 $P(C)≤2|C|/r$ 给出 $|C|>(0.83744-(22/7)e^2)/(1+2e/r)>0.83743015029$。[有理坐标及距离误差的构造](finite-point-lift-083743.md)

## 复算

在含相应依赖的 computation 目录运行下列命令。TREE 是原树，T32、T64 是材料表，WORK 为新目录，CACHE 为编译缓存。RETAINED、LEDGER 是本靶分片索引与账本。KIT 取 five-affine-selected-083744-final.zip，UPSTREAM 是含提交 10af98606c98ca9ffd0d9f402cae1e2efe74b792 的上游目录，DENSE 是含六棵加密树及其独立入口的 computation 目录。

```sh
python -I -B replay_finite_point_083744.py TREE T32 T64 WORK CACHE RETAINED LEDGER --workers 8 --five-kit KIT --upstream UPSTREAM --dense-source DENSE
```

普通记录按片号和原叶号排序后的九列紧凑 JSON（末尾一枚换行）SHA256 为 2b1df3361b54a6de44125ce4b84d41e0a3f9823bb0f7a4e4977ce88ef0ca7543。生成的 WORK/replay.json 分别统计三类重放。

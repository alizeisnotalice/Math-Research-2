# 第16轮：固定圆盘提供更强的凸包内核

记C(p)=conv(∪ S_i(p))，始终固定D=(1/2)B于原点。
若所有非圆盘材料体外半径≤3/5，参数每坐标偏差≤s，则

d_H(C(p),C(p0))≤δ=(99/70+3/5)s，

因为√2<99/70，且支撑函数的最大值保持统一误差上界。
不同于逐材料体缩放，此处只需h_C(p0)(u)≥1/2，无须对平移范数另作假设。
第15轮实际重新生成的有理凸包H满足h_H≤h_C(p0)+η，η=2/10^9。
令α=(1/2−δ)/(1/2+η)>0，则对任意单位方向u，

αh_H(u)≤α(h_C(p0)(u)+η)≤h_C(p0)(u)−δ≤h_C(p)(u)。

故αH⊂C(p)。这给出适用于任意中心的局部下界核，只要相应H与采样误差经过认证。
对第13轮中心、s=1/10000，实际精确计算给出

α=1749295000/1750000007，

|αH|=25663933086541922108196559773/30625000245000000490000000000>419/500。

因此第15轮局部盒在每坐标扩大两倍后仍被排除，参数体积扩大2^20倍。
这并未证明任何其他中心的盒可被排除。

# 释放旧配对边时，必须在一整段上向外加面积

固定原 Gibbs 角 1.5497°。设闭凸万能宿主 C 位于原宽一正六边形内，保留原来排除十个非候选姿态的两条直线约束 m3、m5，并满足铰点 p=.430、正向转角 .018≤δ<π/2 的 AH 半平面。允许任意改变原配对曲线一侧。记原 Gibbs 宿主为 G，则
\[
 |C\setminus G|>1.8992200\times10^{-13}.
\]
更强的逐点约束是 C 必须包含下述整片区域。这可以筛掉只在单一参数附近松开切线的构造。

沿用[铰点反例](ah-pivot-obstruction.md)的定宽一体 K_t(w)=(1−t)K_w+tQ_A R 和其三角形顶点 V。将 [.42885,.42999] 等分为114个闭格，第 i 格允许的混合比例上端 t_i 为[有理列表](../computation/b1-forced-release.json)。对每个 w 和 0<t≤t_i，十个姿态因 m3、m5 的严格违反而排除。恒等姿态在原裁线上的违反至少为
\[
 |D|(.430-w)\sin(.018)-2t/\sqrt3>0.
\]
其余转角沿用全扇相容函数。在并合角室内，理想体相容函数的全角上端不超过格左端的 √(a²+b²)−1/2，因为判别式随 w 递减。在室外和两端各半度以外，用第198轮冻结的严格负余量。两者均可支付 6t/√3 的扰动。两端各半度使用三对接触的原端斜率，加上扰动后仍保持严格符号。原六夹带固定平移，故反射 Q_A 是唯一可能的姿态。它含有
\[
 X(w,t)=(1-t)q(w)+tV .
\]
由万能性，所有这些点都属于 C。紧闭性补入 t=0。

对于每个 t>0，点 X(w,t) 都严格越过 G 在 q(w) 的切线。向量 V−q(w) 的第二坐标为正，且 det(q′,V−q)<0，所以从 V 望向 q(w) 的极角连续严格单调，并且整个极角范围在一个开半圆内。不同 w 的射线不相交，参数图在各格内部单射。其面积元为 (1−t)|det(q′,V−q)|。在每个闭格下界这个行列式，然后乘格宽与 t_i−t_i²/2，求和即得所列数值。证明还逐格给出了实际必须恢复的射线长度。此必要条件只计算向外增加的面积；候选宿主在其他方向的内切仍可带来更大的净收益。

~~~sh
python -B computation/certify_b1_forced_release.py OUTPUT.json
~~~

## 对任意足够薄的释放给出单件反例

取 w=.42893 和 t=.00000063949。格内根与恒等姿态的排除如上。其余十个姿态越过原 m3 或 m5 的法向距离仍超过 .0009，反射姿态则越过旧配对切线超过 5.77457×10⁻⁹。因此凡仍保留原宽一正六边形及上述 AH 半平面，并且整体包含于 G 加半径 5.77457×10⁻⁹ 圆盘的宿主，都漏掉这个具体输入。这个推论允许稍微放松 m3、m5，因为十个违规距离远大于所允许的外扩。特别地，即便采用方向局部化的凸包修补，只要其全局外扩半径不超过 1.6×10⁻⁹，上述反例仍成立。

# 11D 原叶盒上的整数扇形下界

本节只用 Tomar 的原始根箱、二分树及平面测试体定义，不用历史叶下界。目标面积取 τ=0.83661。圆盘与四个正 Reuleaux 体的放置参数沿用上游，依次为 t₃、ρ₅、t₅、ρ₇、t₇、ρ₉、t₉。

## 整盒的移动见证

Q=2²⁸。在每个旋转轴的 1,025 个有理网格角 θₐ 上预生局部坐标 q∈Q⁻¹ℤ²。程序以 128 位 Arb 逐点检查圆盘见证的 |q|<1/2，及各多边形见证对**每一个已转动定义圆心**的距离严格小于 1。候选点的生成公式和浮点取整仅用于给出 q，一切成员资格由随后的球算术不等式承担。若真角为 θₐ+s，则 R_s q 必在真体中。

名义平移为 Q⁻¹ 整数格点 t。实际点为

    xᵢ+ηᵢ = t + d + R_s qᵢ,     xᵢ=t+qᵢ.

同一体所有点共享 d 和 s。用原有理盒向上取整得到 |dₓ|≤hₓ、|dᵧ|≤hᵧ、|s|≤a。令 h=hₓ+hᵧ，Dᵢ=h+‖qᵢ‖₁a，则 |ηᵢ|₂≤Dᵢ。同时 ηᵢ=d+sJqᵢ+eᵢ，|eᵢ|₂≤‖qᵢ‖₁a²/2，这由二阶余项的积分形式即得。圆盘对应的三个变化量全为零。

## 扇形可用性

对名义点取精确整数凸包，按逆时针排列，并允许删除顶点。对每条连接不同体的连续边 (i,j)，检查

    det(xᵢ,xⱼ) > ‖xᵢ‖₁Dⱼ + ‖xⱼ‖₁Dᵢ + DᵢDⱼ.

对同一体的连续边记 v=qⱼ−qᵢ，改用更强的允许检验

    det(xᵢ,xⱼ) > h‖v‖₁+‖t‖₁ ‖v‖₁a.

确实，行列式等于 det(qᵢ,qⱼ)+det(t+d,R_s v)，与名义值之差由右边控制。两种检验均保证实际相邻行列式严格正。删点直到每边都通过，或不足三点而放弃。此时保留的名义多边形是逆时针凸多边形，所有严格正相邻行列式表明原点在内；它的绕数为一。从名义位置到真位置按 (d,s) 线性插值，沿途各相邻行列式仍严格正。各角增量连续且在 (0,π)，和为整倍数 2π，故始终等于 2π。因此从圆盘中心到相邻动点的三角形在真实凸包中且内部两两不交。

## 将同一体的一阶误差相加

写 uᵢ=xᵢ₊₁−xᵢ₋₁。两倍有向面积之差有精确恒等式

    ∑ det(ηᵢ,uᵢ) + ∑ det(ηᵢ,ηᵢ₊₁).

对每一体 b 设 G_b=∑uᵢ，g_b=−∑qᵢ·uᵢ。第一和的下界损失至多为

    ∑_b (|(G_b)ᵧ|hₓ + |(G_b)ₓ|hᵧ + |g_b|a)
      + ∑ᵢ (‖qᵢ‖₁ a²/2)‖uᵢ‖₁.

第二和中，不同体的连续边损失至多 DᵢDⱼ。同一体令 A=R_s−I，则

    det(ηᵢ,ηⱼ)=det(d,A(qⱼ−qᵢ)) + (2−2cos s)det(qᵢ,qⱼ),

其损失至多 h‖qⱼ−qᵢ‖₁a + max(0,−det(qᵢ,qⱼ))a²。这里 0≤2−2cos s≤s²。两倍名义面积减去各项损失已是整盒通用的下界，无须假设盒内凸包顶点名单不变。

## 定宽整数的逐式界和输入绑定

所有坐标、整除及比较在编译时使用 `-ftrapv`。几何量用 Q 单位，面积用 Q² 单位，门槛取 ceil(2τQ²)。函数 up 在有符号 128 位中完成非负向上整除并返回同一宽类型；只有明确代表长度的值才经 small 范围检查转成 64 位。输入验证锁定 Q=2²⁸、原盒分母 2⁴⁴、角网格 1024、五组坐标及总见证数 N≤4096。逐点验证 |qₓ|,|qᵧ|<Q，逐盒 |lo|,|hi|<2⁴⁴，其余下列界均为这些检查的简单后果。

- |t|∞≤Q，|xᵢ|∞≤2Q，|uᵢ|∞≤4Q，‖uᵢ‖₁≤8Q。两平移半宽各≤3Q，h≤6Q，角偏差≤2Q，故 Dᵢ≤10Q。这些有量纲的长度均可安全转回 64 位。
- 整数凸包的三点有向面积项≤32Q²；单一 q 行列式≤2Q²，x 行列式≤8Q²。不同体相邻方向的误差界≤180Q²，同体的两项更小。四则计算在 128 位中进行。
- 单一体梯度两分量分别≤4NQ；旋转梯度绝对值≤8NQ²。最大的未除分子可由 16NQ³≤2¹⁰⁰ 控制。旋转梯度的向上整除保留 128 位，故无需把这个显然可能超过 64 位的粗界缩小。一个二阶位置余项损失≤32Q²，一条不同体边损失≤100Q²，同体边损失≤56Q²。即使全部用 200NQ² 加上五组梯度损失估计，总累计绝对值小于 2⁸⁰。上述数字均离有符号128位的极限有余量。
- 細盒端点的求和、角索引缩放以及其校正偏差绝对值不超过 2⁵⁶。节点数不超过 2²⁹，每原叶最多 2²⁴ 次子盒求值，分片计数小于 2⁵⁵。凡候选对半点不在 2⁻⁴⁴ 网格上，该子问题返回未证明。一次失败不会写成成功；两个子盒均通过才关闭父盒。

表中携带原始根箱的全部 dyadic 整数、原分母、角索引、生成器 SHA 和上游输入 manifest SHA。认证入口对每个分片逐项检查根头和码流哈希，并在每次批处理前执行与生成公式独立的 128 位 Arb 成员检查：直接用 (θₐ+2πj/n) 构造全部转后圆心，逐个对整数见证作距离检验。固定输入 manifest 的 SHA 为 56cbe5dfdadc6b5aa07cf6ec9acf4f637a3c4fa78db54df0ae2d78916d292410。每个收据绑定当前表、源文件、可执行库与所用原分片。

## 文件

- tomar_fan_table.py 生成并认证名义角度见证。
- tomar_integer_fan.cpp 计算带方向整数下界，支持原树扫描及叶上递归。
- trim_tomar_integer_fans.py、probe_tomar_integer_fans.py 分别运行完整指定分片和确定性的抽样诊断。

样本关闭比例只能描述相应样本。以该方法报告一般下界时，还需提供整个共有根箱上每个原叶对应的成功或严格替代证明，及根箱外证明。

## 从每个原始根启动重放

生产入口 run_tomar_integer_parts.py 使用 --fresh 对每片的原始 253、254、255 码叶新算，逐片验证两份冻结的输入哈希。run_tomar_portable_parts.py 采用已经在主机独立作过逐点 Arb 成员检查的同一份见证表，以固定 SHA 验收传来的字节，每次都新算所选片号。两入口均按所附 C++ 源码重新编译动态库。两台实际运行的 Apple Silicon 主机所用 Apple clang 21.0.0 生成字节完全相同的库。每个原始二叉分片的根由 11 个二进位按数组 C 行序从公共根箱二分得到。

finish_tomar_v3_parts.py 将整数阶段剩余的每个原叶还原为原树精确盒，使用冻结上游 lbcheck.py 设定的 80 位 Arb 球运算，在相同的 0.83661 目标下新算。组合叶的移位与权重只生成候选见证，面积证书按新目标验收。子盒平分前后逐坐标核对有理二分、二进浮点边界和父子覆盖。

    python -I -B tomar_fan_table.py "$C" "$TABLE"
    python -I -B run_tomar_integer_parts.py "$C" "$INT" "$LIB" "$TABLE" --fresh --workers 2
    python -I -B finish_tomar_v3_parts.py "$UP" "$C" "$INT" "$ARB"
    python -I -B audit_tomar_v3_coverage.py "$UP" "$C" "$TABLE" --pair local "$INT" "$ARB" --require-complete

这里 UP 是上游 v9 检出目录，C 为 cert11d_08366 解包目录，TABLE 为新建的 npz 表。LIB 为可重建的动态库输出文件，INT 与 ARB 为初始空的分片结果目录。只检查部分片号时，可给前两个分片程序指定 --parts，汇总时去掉 --require-complete。主机与 MacBook 分担时，对每个不重叠的输出目录添加一个 --pair。汇总程序逐片核对原始前序码所表示的树、每个余叶的编号与标签、数学检查程序及三份分片产物的 SHA，并重算根箱外面积及角度范围。全量门槛为全部 2,048 个分片、16,193,402 个原叶、零个余叶。

如某分片的补验在给定深度仍留有余叶，提高 --depth，在空目录内用同一原始整数分片作输入，对该分片全部整数余叶重算；汇总时取通过的补验记录。对照原始整数分片 SHA、余叶编号及标签，它与较浅尝试的成败无关。bundle_tomar_v3_receipts.py 从已核验总账提取每片的 integer JSON、位置 NPZ 与 arb JSON，写出含 coverage.json 的可还原 ZIP，并重读全部字节逐件比对。

## 全分片核验与公开回执

从空目录重做全部面积运算的单一入口为

    python -I -B replay_tomar_v3_full.py "$UP" "$C" "$NEW" --workers 2

该命令重建见证表和本机整数核，从每个原分片的全部叶启动，再以 80 位 Arb 处理其余叶。深度 12 的未闭合分片从固定的原始整数余叶重算到深度 24，必要时继续提高深度。最后检查全部原码树、分片覆盖及根箱外界，并生成公开归档。NEW 必须是尚不存在的输出目录。命令中各 Python 程序位于 computation 目录。当前冻结二进制目标为 Apple Silicon 上的 Apple clang 21.0.0。

对已有的公开 ZIP 作全分片绑定与覆盖审计，可以运行

    python -I -B audit_tomar_v3_public.py "$UP" "$C" "$TABLE" "$ZIP" "$TEMP_PARENT"

该入口对完整 2,048 片逐件校验 SHA、原始前序码树、叶编号及补验记录，并重新验证见证表成员资格、根箱外下界和完整覆盖。面积算术从头重放使用上面的第一条命令。

publish_tomar_v3_archive.py 把各主机编译旗标中的模块缓存目录统一记为 <CLANG_MODULE_CACHE>，并按新的整数收据重新绑定每个 Arb 收据和公开总账。ZIP 中 provenance.json 保留原始私有 ZIP、覆盖总账以及每片三件原始回执的哈希。此变换只改变编译缓存位置的显示及所涉哈希，原始区域、数学见证、判别结果与私有回执均保留。

## 全域实算

对冻结的 2,048 个根分片，完整重放计 16,193,402 个原叶。整数扇形及其自适应二分在 1,767,349,652 次盒求值中关闭 16,181,405 个原叶。余下 11,997 个原叶全部由 Arb 关闭，所用 16,955 个子盒求值中，最深的一条成功支路有 20 层二分。公开回执共 6,146 件，压缩为 4,518,851 字节。其 SHA-256 为 e08f972ee6a4c8422b9fbcf53c45c4c5826a0c5c3468e1898eb0af050b11e86a。

凸覆盖若含有五个测试体的某组放置，就含有它们的凸包。固定圆盘中心和 B₃ 朝向，再用反射和周期把其余角度放到指定区间。若某个平移超出根箱，上述半圆盘和梯形给出至少 0.85914 的面积。根箱内每个放置包含在本次遍历的某一原叶中。故全数新算给出一般下界 Λ≥0.83661。

在严格不等式的层面，整数比较所用的 ceil(2τQ²)=120568207496141782 严格大于 2τQ²，球运算的接受判据亦为严格大于 τ。因此每个根箱内放置实际都有面积大于 τ。公共根箱紧，五体凸包面积随放置参数连续（各体 Hausdorff 连续，取有限凸包及凸体面积均连续），其最小值仍大于 τ。结合上面的统一根外界，可得 Λ>0.83661；这里没有从紧性中指定一个额外十进有理增量。

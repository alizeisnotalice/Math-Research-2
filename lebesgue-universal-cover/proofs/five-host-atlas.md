## 全原叶的支撑区间

先将所含圆盘中心置于原点，再以三边形的方向和二面体稳定子规范坐标。第123轮的全域定位使这些参数落入归档的 501 个原闭叶。用固定 SHA-256 的原始二分树解码各叶的全部端点，其公共分母为 \(2^{44}\)。五个测试体取凸包时，支撑函数逐方向取最大值。

对无平移、中心角为 \(\rho\) 的正定宽 \(n\) 边形，令
\[
 R_n=\frac{1}{2\cos(\pi/(2n))},\qquad
 s=\operatorname{dist}\bigl(\theta-\rho,(2\pi/n)\mathbb Z\bigr).
\]
其支撑函数是
\[
 h_n(\theta)=
 \begin{cases}
 R_n\cos s,&0\le s\le\pi/(2n),\\
 1-R_n\cos(\pi/n-s),&\pi/(2n)\le s\le\pi/n.
 \end{cases}
\]
第一段来自最近顶点的法向锥，第二段来自相关单位圆弧。因 \(n\) 为奇数，圆弧中心顶点的方向与圆弧法向扇区中点相反。两段在接点同为 \(1/2\)。由此，转角在一个闭区间内变化时，支撑的极值只可能在区间端点、峰值 \(R_n\) 或谷值 \(1-R_n\)。后两项各由相对角区间是否碰到对应的周期格来决定。Arb 比较若不能排除触碰，便计入相应极值。

在 3,072 个整周法向上向外舍入转动支撑与法向的正、余弦，支撑单位为 \(2^{-28}\)。把平移区间投影到这些法向，四角乘积的精确整数极值给出投影上下端。逐体取最大即得到整个原叶的支撑上下端 \(L_i(\theta),U_i(\theta)\)。原叶中点轮廓同法求出。此后每个叶与指定轮廓的每个采样法向上，取
\[
 \max\{U_i(\theta)-L_j'(\theta),\,U_j'(\theta)-L_i(\theta)\}.
\]
这里带撇的上下端已作用轮廓指定的等距变换。三边形二面体的六种角变换在角网格上都只是置换。附加共同平移时用分母 \(2^{28}\) 的有理向量计算两个投影端点。浮点只用于提议平移和选代表。

对任一已平移的单体，角 Lipschitz 常数可取平移向量模长加上 \(R_n\sin(\pi/(2n))\)。圆盘的常数为零。三边形在自身姿态中固定方向，但其支撑随法向变化，计算此常数时仍包含三边形。有限最大值继承这些常数的最大者。于是候选和模板的支撑差可从采样网格以最大缺失角 \(\pi/3072\) 扩至全周。未附加平移时，整数角余量为 \(178115/2^{28}\)；有共同平移时再逐叶加上对应向量的 \(\ell^1\) 模长乘 \(\pi/3072\) 的向上取整。Hausdorff 距离等于全周支撑差的上确界。

## 从内部凸包到宿主

令 \(K\) 为所含五体副本的凸包。用第144轮的圆盘尖帽估计。原点距宿主中任一点皆小于 \(R=0.703\)，因为半径 \(1/2\) 的圆盘和模长为 \(R\) 的一点的凸包已经严格超过 \(0.83732\)。代码用 Arb 核验这一单点面积。若 \(d=d_H(H,K)>0\)，取一个最大支撑差方向。实现宿主支撑的点，法向投影记为 \(x\le R\)。由这个点与圆盘投影 \(1/(4x)\) 处垂直弦构成的尖帽，位于 \(K\) 的支撑线以上的面积至少为
\[
 \frac{d^2}{\sqrt{4x^2-1}}.
\]
因此
\[
 d\le\sqrt{(T-L_5)\sqrt{4R^2-1}}
 \le \frac{597105}{2^{28}}
 <0.002224390 ,
 \qquad L_5=\frac{120666205824033364}{2^{57}}.
\]
和前述原叶距离相加，即得宿主半径。

## 第108轮逃逸的检验

第108轮逃逸五体放置完全容纳该轮 Fourier 输入。实际以有理支撑内点和面积舍入，重算逃逸宿主面积下端严格大于 \(0.83765424\)，旧可行面积上端严格小于 \(0.837657369\)。五体接触盆地的冻结有理中心与逃逸宿主都在后一个面积门槛以内。

给定方向 \(\theta\)，宽度为 \(w(\theta)=h(\theta)+h(\theta+\pi)\)。平移不改变宽度，两凸体在任一刚性对齐下的 Hausdorff 距离至少为最大宽度差的一半。对 3,072 个相对旋转角和两种镜像计算法向网格的最大宽度差下端，再减去相对角插值误差。得到逃逸宿主到接触宿主的距离在任意等距对齐后都严格大于 \(0.01021657\)。固定规范框下，距离在 \(0.02847744\) 和 \(0.02909943\) 之间。因此在面积门槛 \(0.837657369\) 上，单独用接触轮廓及半径 \(0.01021657\) 的球会遗漏逃逸例。即使单轮廓可以另选，覆盖这两个等距类也需要半径大于 \(0.00510828\)。

## 复算

MAIN 为公开计算目录，TREE 为 Tomar 原 cert11d_08366。冻结运行使用本机 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0。两套 Python 环境使用 160 位和 192 位 Arb 运算，重放的完整输出逐字节一致。

    python -B computation/certify_five_host_atlas.py MAIN TREE > result.json
    python -B computation/certify_five_host_atlas.py MAIN TREE --bits 192 > second.json
    cmp result.json second.json

加 --emit 可以保存整叶及中点轮廓的网格支撑区间和距离矩阵。JSON 的每条记录中，轮廓号从零开始，二面体号依次为 \((\sigma,k)=(+,0),(+,1),(+,2),(-,0),(-,1),(-,2)\)，对应支撑参数 \(\sigma\theta+2k\pi/3\)。有共平移时，分子数组与 501 个原叶的顺序相同。所报上端为支撑单位 \(2^{-28}\) 的整数，正文小数向上舍入。

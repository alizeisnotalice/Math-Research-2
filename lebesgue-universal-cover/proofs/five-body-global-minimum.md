# 圆盘和四个正胡勒奇边形的全域唯一极小构形

令 D 为直径一的圆盘，Bₙ 为直径一的正胡勒 n 边形，n∈{3,5,7,9}。允许五个体独立刚体运动，取共同凸包面积的下确界 F₅。记 G(α,β) 为《五个定宽测试体的一个严格局部极小构形》中由两条公共支撑线、指定交点分支及 22 段材料边界定义的解析面积函数。令 (α*,β*) 为驻点隔离盒中 ∇G=0 的唯一解。则

    F₅ = M = G(α*,β*)
       ∈ [0.837295006221025243456393253909267018677 ± 5.09·10⁻⁴⁰].

等号在五体接触构形处达到。在允许整体反射、平移及旋转的意义下，标记五体的最优放置只有一个等价类。因而一般凸万有覆盖面积至少为 M。一般万有覆盖的精确最小面积仍待求解。

## 规范化和已证的局部比较

把 D 的中心移至原点，固定 B₃ 方向。剩余坐标为 t₃ₓ、t₃ᵧ、θ₅、t₅ₓ、t₅ᵧ、θ₇、t₇ₓ、t₇ᵧ、θ₉、t₉ₓ、t₉ᵧ。各 θₙ 按 2π/n 取模。整体转过 2π/3 和横轴反射生成三边形的二面体群，因此任一放置均有 0≤θ₅≤π/15 的代表。驻点构形的 θ₅≈0.03367569013824 位于该区间内部。它和镜像只有在 2θ₅ 为 2π/15 的整数倍时才可能由三边形的保向对称互换；故若等价关系只允许整体保向运动，标记放置恰有两个类。各体自身的对称变化给出同一几何放置。

已证驻点构形的面积严格小于有理数 U=0.83729500622102525。驻点处两角 Hessian 正定，全部材料接触正常。原局部盆地的两法向半宽 3·10⁻⁶，九个横向偏差半宽 8·10⁻⁵。新增盆地的相应半宽分别为 6·10⁻⁶、7·10⁻⁵。在两域的并内均有 A≥M，等号仅在 (α*,β*,ξ=0) 成立。新增比较在 400 个闭角格上证明 G 的 Hessian 扣去 0.1I 后正定，对所有材料链的横向二阶余项统一估计，并以有理权验证每个九维象限均有足够的一阶增长。具体在新域上

    A ≥ M + 0.05[(α−α*)²+(β−β*)²] + 0.000000034 ‖ξ‖₁.

九个横向偏差以相同 t₃ 确定的接触流形锚点为基。程序直接检查两条切线的角区间和九个偏差的区间，亦可用已认证的原始长方体作为充分条件。

## 精确圆弧的材料链

在已验证的接触流形锚点固定每个参与刚体的材料点和材料圆弧。六个共同法向处各自允许保留任意一部分中间接触点，依次有 8、8、8、8、4、2 种选择。中间点在相应支撑直线上且切向次序递增，因此所有 32768 条链在锚点的面积相等。近锚点以原驻点或由受测盒的 t₃ 中点导出的两法向提出，每个采用的锚均重新检查完整支撑归属和切换顺序。还可采用驻点与当下 t₃ 之间的中点作为第三个锚。

设刚体在锚点和实际位置的平移分别为 t₀、t，其相对转角的旋转矩阵为 R。材料点 P₀ 刚体移动到 P=t+R(P₀−t₀)。对于圆弧，令 v 为带弧半径的两端外法向之差。该弧对两倍面积的增量精确为 det(t,Rv)−det(t₀,v)。每条连接线段 P₀Q₀ 对两倍面积的增量为 det(P,Q)−det(P₀,Q₀)。所有公式来自沿边界积分 det(x,dx)。

对每条实际使用的异体连接线段，核验整个从锚到待测盒的连续刚体运动中有向行列式为正。若锚端点到实际端点的最大位移为 dₚ、d_q，即以

    det(P₀,Q₀) > ‖P₀‖₁ d_q + ‖Q₀‖₁ dₚ + dₚd_q

作充分条件。锚点及待测盒的各体内切圆都含有原点，沿同伦的平移也有此性质。真实材料弧的极角因而正向，正行列式的线段也正向；绕数连续并等于一。每一条通过这些检查的材料链都包围一个位于共同凸包中的区域。某个事件的部分选择可以舍去，只保留全部连接线段均通过的选项。

用 y∈[−1,1]¹¹ 表示盒中规范化的原始参数。对有向面积增量在盒中点作一阶 Taylor 展开。若旋转角偏差不超过 w，一个相对材料点向量 u 的位移至多 ‖u‖₁w，减去线性旋转后的余项至多 ‖u‖₁w²/2。对于一条连接边，当两个端点的全位移界为 Dₚ、D_q 且各自的一阶余项为 Eₚ、E_q 时，两倍面积余项的绝对值至多

    ‖P‖₁ E_q + ‖Q‖₁ Eₚ + DₚD_q.

圆弧项按同一公式或其直接双线性展开估计。用 192 位 Arb 计算锚、端点、导数和余项，再把每个仿射常数与斜率保守量化到面积格 2⁻⁶⁸。每个斜率的量化误差按 |yⱼ|≤1 从常数项扣除。

每个事件可独立选择，故一个锚的面积下界具有

    A−U ≥ f₀(y) + Σₑ maxₖ fₑₖ(y)

的形式，每个 f 都是经下取整的仿射函数。任取非负权重且各事件内部权和为一，右侧均下界于相应的仿射组合。不同锚的下界也可取凸组合，五体整数内点扇的仿射下界可同时参加。线性规划仅提出权重，每个事件和每个锚的权重都独立量化成非负整数，权和精确为 2³²。对最终的 F+g·y，如果 F−Σ|gⱼ|>0，则整个盒 A>U。若全局极小点可能落在该盒中，则必须有 F+g·y≤0。解此线性不等式，按照 2⁻⁴⁴ 网格向外舍入即可严格缩小单坐标。剩余盒分成共享割点的两个闭盒。分割选择和浮点提出的锚点不承担任何面积断言。

## 从全部原根到等号

在 2,048 个原根、16,193,402 个叶的树上，二面体规范截面保留 6,710,314 个叶。四层既有定位从原始分裂轴重算，门槛 0.837295006222 高于 U，排除了 6,709,813 个规范叶。根盒外由四个内切圆比较式处理，其最小下端超过 0.8591458809。高门槛的四个必要平移半径同样适用于 A≤U 的区域。余下 501 个原叶的所有端点均独立从原树解码。以下每一层的输入严格等于前一层保留的全部闭盒，后代回执记录父文件的 SHA-256、具体序号和父给出的 22 个整格端点。

|---|---:|---:|---:|---:|---:|
| 1 | 501 | 132707 | 105 | 6 | 0 |

| 3 | 89 | 22396 | 72 | 2 | 9 |

第四层唯一的盆地终端还作了额外替代核验。重新遍历其父树获得窄盒的 22 个真实整数端点，然后完全关闭所有盆地判据，联合材料核在单个节点上即严格排除 A≤U。因而即使只采用原先两法向半宽 3·10⁻⁶ 的局部唯一性证明，九个第三层终端也已包括全域的所有可能等号点。新增较宽盆地提供另一项局部定量结论。

每个非盆地终端均排除了 A≤U 的放置。全部盆地终端均满足 A≥M，在盆地内已证 M 的唯一等号点。由于实际接触构形达到 M<U，以上覆盖证明全域上 A≥M，所有等号放置都归入同一规范驻点。在紧凸覆盖体的表述中，若其面积为 M，则它包含的这五体的共同凸包也有面积 M。一个有内点的紧凸体的真凸扩张会严格增加面积，因此最优五体覆盖正是最优放置的凸包。

## 独立复算

两个补包分别为 five-basin-layers-1-3.zip 与 five-basin-layer-4.zip。其 SHA-256 为 6cc1cec098e1ca115c03b9b8c1a6619f54601c5f8573533e43ab018fa2a4094f 和 550b4a800ec45f6fff8161119751ce661bba71f867971191dd57dff7f216269a。原作者的历史叶面积没有参与证明。以下命令重算高门槛父定位、两套局部盆地、驻点及四层补算，并检查每份原叶和后代回执

    python -I -B computation/audit_tomar_five_global_minimum.py UPSTREAM CERT TABLE HIGH_COMPUTATION SCRATCH CLANG_CACHE --replay-parent --replay-local --replay

只对四层补算做全部几何运算时使用 --replay。使用 --parts 180 可单独重算所选原分片，程序在每次运行中都检查所有父子链。省略重放开关仅核对冻结证书、原始根端点、归档成员、严格门槛和账本闭合。

若希望独立核对仅依赖旧盆地的等号证明，另执行

    python -I -B computation/audit_five_final_basin_box.py UPSTREAM CERT HIGH_COMPUTATION SCRATCH CLANG_CACHE

该入口从已绑定的第四层归档重新提取唯一盆地终端所在的父树，逐节点复算取得待测窄盒，然后在禁用所有盆地判据的情况下重算最后一次严格排除。

# 五体有限族的全域严格下界 0.83729

设 F₅ 为能够同时包含直径为一的圆盘及正胡勒三、五、七、九边形的凸体的面积下确界。各体允许独立刚体运动。在规范角域 ρ₅≤π/15 中，五体全域定位证书从 2,048 个原根出发，在 6,710,314 个规范闭叶中排除了 6,709,813 个面积不超过 0.837295006222 的原叶。见《五体全域定位》及其四层重放记录。余下 501 叶分布于 19 个根。有限参数域之外的两圆盘估计最小为 0.8591458809 以上。根内与根外共同覆盖全部允许的放置。

本次从这 501 个原叶的闭端点重新运算。每个形状原点取在其内心。母树端点落在 2⁻⁴⁴ 格上，子盒共享中分点。每次计算动态扇形时，先提出 65 个刚体姿态扰动。程序对提出的材料点执行整数距离检验，对真圆心的位置执行 Arb 区间检验，并验证循环顶点跨积正且绕原点一周。真凸包因而包含扇形，对满足楔内条件的同体弦还包含共同圆弓。对每个这样的扇形，在整个参数盒上得到带余项的仿射面积下界。非负有理权凸组合、盒面收缩与外向格点舍入沿用《由五体高门槛的 501 个原叶得到一般下界 0.83725》的证明。浮点优化提供候选权，最终收缩与接受由整数不等式决定。

第一批使用既有圆弧提案及五体径向提案，32 个原叶中有 31 个通过，成功树合计 13,267 个节点。另一个原叶为分片 180 的前序位置 23955。第二批加载冻结的 gen11 圆弧提案，使正胡勒九边形的可见圆弧直接参与提出顶点。第一批余下的原叶连同尚未处理的 469 个原叶全部通过，合计 105,588 个节点。两批成功原叶编号互不相交，其并集为高门槛父证书冻结的 501 个编号。第一批未完成的树留在归档中，其任何节点均未计入证明。

因此

    F₅ ≥ 120666205824033364 / 144115188075855872 > 0.83729.

任何凸万有覆盖都包含上述五体的某组副本，得到同一一般下界。与五体已认证可行放置的面积上界 0.83729500622102525 合并，五体下确界所在区间的宽度小于 0.000005006222。有限族的全域精确最优值仍待证明。

## 算术与复现

公开包 tomar-five-083729.zip 含 503 个成员，524782 字节，SHA-256 为 d040caaf37c8d6dad2bc2273f5cc6364a6862b9f5696b6de666f8276a65ab6b7。其输入包括上一轮的四层高门槛父证书、原根文件及分裂轴数组。原作者的历史叶面积未参与证明。对全部 501 棵成功树、分片输入绑定、每次重算的完整计数和四个根外界，可运行

    python -I -B computation/audit_tomar_five_083729.py UPSTREAM CERT TABLE HIGH_COMPUTATION ARCHIVE SCRATCH CLANG_CACHE --replay

追加 --replay-parent 会从原始根与分裂轴重新执行较高门槛的四层定位。省略两项重放选项仅检查冻结账本、源码、输入、输出和覆盖集合。可用 repeat_tomar_five_083729.py 传入相同位置参数及 --workers 2，使两组不相交的原根并行重放 501 棵例外树。公开回执使用 macOS arm64、本机 Apple clang++、Python 3.13.18、NumPy 2.5.5、SciPy 1.18.1、python-flint 0.9.0。位于原仓的 gen8.py 与 gen11.py 固定在提交 10af98606c98ca9ffd0d9f402cae1e2efe74b792。动态求解中所有输入参数、随机种子和源码摘要写入逐叶回执。

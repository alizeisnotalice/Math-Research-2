# 第21轮：固定斜角AH区域的严格面积区间

固定σ=1.5494°，采用第18–20轮已经认证的C=L(θ)最短路径及修剪后的Jordan边界。
该区域的面积严格满足

0.00008151833 < |A_H| < 0.00008151841。

这里A_H指本项目坐标重建得到的区域；尚未独立证明从万能覆盖中删去它后仍能覆盖所有直径1形体。

## 精确代数参数化

以w∈[0,1]参数化原切线段X(w)=Z+w(T−Z)。它从Z走向T。
对单位法向n和指定线方向e，单位圆与n·L=1/2的选定根为

L=X−(n·X−1/2)n−sqrt(1−(n·X−1/2)²)e。

分别取DC的(n_L,e_L)和DE的(n_N,e_N)，得到L(s)、N(t)。第20轮的分支证明保证此根正确。
若c=L_x+1/2，则配对中心

L(-s)_x=c/2+(√3/2)sqrt(1−c²)−1/2，
L(-s)_y=(L(-s)_x−1)/√3，N(-t)=2M−N(t)。

取两配对中心的上单位圆交点，得到代数曲线Q(w)=X(-s(w),-t(w))。
它从Z走向T'。所有根式分母在积分区间的有理包络中严格非零。

## Green积分与圆弧

边界由T'→X_AS（圆心G）、X_AS→Y（圆心E3）、Y→T（圆心C）、
线段T→Z、配对曲线Q:Z→T'组成。
单位圆心c的短圆弧a→b之Green积分为

c×(b−a)+atan2((a−c)×(b−c),(a−c)·(b−c))。

三个点积均严格正，叉积/点积绝对值小于1/2；
以32项反正切交错级数及|z|^65/65余项作有理包络。
线段积分为T×Z。面积为闭合Green积分绝对值的一半；Jordan性已在第20轮证明。

## 区间Taylor积分

对Q的代数表达式实施三阶自动Taylor运算。系数按导数除以阶乘存储。
乘法是卷积，倒数递推由fg=1确定，平方根递推由g²=f确定；零阶区间均用向外有理平方根。
把零阶w设置为一个完整小区间、一阶系数设置为1，其余为0，
所算系数包含该区间每一点的相应Taylor系数。
因此对f(w)=Q_x Q_y'−Q_y Q_x'，所得二阶系数区间包含f''(w)/2。

在宽度Δ、中心m的每一格，有严格积分包络

∫f ∈ Δ f(m)+(Δ³/12) enclosure(f''/2)。

这是二阶Taylor公式在格上积分：一次项精确抵消，剩余t²的积分等于Δ³/12。
采用1024格，所有运算逐步向外舍入至10^-24；根式端点用整数平方检查。
输出的最终有理面积区间为

[254744800318486439/3125000000000000000000,
81518401528427961897/1000000000000000000000000]。

其宽度为65426512301417/10^24，严格包含于开头的两个有限小数之间。

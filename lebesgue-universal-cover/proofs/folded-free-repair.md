# 单面五体夹界与自由重摆

验证器用公共计算目录中的几何和支撑数据复算两个有限输入结论。设 $C_*$ 为第223轮的单面连续宿主，$H_j$ 的外法向为 $60j^\circ$，阈值 $B=.844082046521218581802948589770767704354$。

## 单面五体

固定整个 $C_*$，保留 $H_0,H_2,H_3,H_4,H_5$，允许 $H_1$ 外移至多 $3.01\times10^{-7}$。下端允许凸宿主越过两条旧斜帽。五体逐一任取转角和手性，两对固定条带唯一确定各自的平移。

| 标记 | $w$ | $e$ |
| --- | ---: | ---: |
| $P_1$ | .811550290734 | .034078764549 |
| $P_2$ | .826834081565 | .035564309539 |
| $P_3$ | .7542632795 | .0281418485 |
| $P_4$ | .756754178453 | .028431537535 |
| $P_5$ | .819236970703 | .034894452004 |

下端先用 $P_1,P_3,P_4$ 排除 $P_1$ 的正手分支，该分支的增量大于 $1.30\times10^{-7}$。再用 $P_1,P_5$ 的联合凸包排除增量至多 $9.22\times10^{-8}$ 的反手分支。$P_5$ 可取任一手性。两次均在多体角格上取同一个有理内凸包，旧 AH 帽只扣一次。上端使用同样的五体，都先转 $239.999999^\circ$ 再关于横轴反射，证明了五个副本与 $C_*$ 的共同凸包同时保持单面条带及两条原斜帽。因此最小面积 $M_5$ 满足
$$
.8440820130770037<M_5<.8440820140975347851512.
$$
至 B 的余量介于 $3.24236837966\times10^{-8}$ 与 $3.34442148819\times10^{-8}$。两条下端的全部角盒都终止。

## 固定错误折叠与自由重摆

本组使用 $P_1,P_2,P_3,P_4,Y$，其中 $Y=P(.811550290734,.034070)$。固定错误折叠宿主 $D_-$ 含整个 $C_*$ 以及前四体已指定的反手副本，转角依次为 $174.143146^\circ,239.999999^\circ,239.999999^\circ,174.122279^\circ$，附加放宽 $H_4$。复算给出
$$
.8440820083564575<|D_-|<.8440820090895462.
$$
若完整保留 $D_-$，并允许 $Y$ 自由平移、转动和反射，也允许新宿主自由越过六面和两条旧斜帽，则最小面积 $A_-$ 满足
$$
.844082054<A_-<.8440820774558181.
$$
下端核验 $D_-$ 的首体确有平移不变量 $q<-3.1199\times10^{-7}$，再用六面混合面积与同一平移盒中的 AH 材料关闭 $Y$ 的全角全平移域。上端保留四个原姿态，然后将 $Y$ 以 $240.00083^\circ$ 反手加入。固定实心内核下，面积有界的宿主直径一致有界，Hausdorff 紧性和面积连续性给出最小值。

若只保留 $C_*$，允许重摆相同五体，则有两套明确的 B 档摆放。正手近折叠放置的共同凸包面积小于 $.8440820067607142$，在 $H_1$ 的原放宽之外只需将 $H_3$ 再放宽不到 $2\times10^{-8}$。五体使用 $239.999999^\circ$ 的反手摆放时，仍可保持 $H_1$ 单面域。其重算面积小于 $.8440820106824689973870$。同五体自由重摆与保留 $D_-$ 的最小面积严格相差超过 $4.72392\times10^{-8}$。

对任何含 $C_*$ 和 $Y$ 且面积至多为 B 的凸宿主，每个已放置的定宽一体都满足 $q>-2.8\times10^{-7}$，其中 $q=1/2+h_1-h_0-h_2$。对 $P_1$ 附近的闭参数盒 $|w-.811550290734|\le4\times10^{-7}$、$|e-.034078764549|\le10^{-7}$，结合六面预算和两条斜帽排除后，反手唯一保留角段为 $[239.9975^\circ,240.00085^\circ]$。正手保留 $[354.01^\circ,354.28^\circ]$ 和零角附近闭区间 $[0^\circ,.00085^\circ]\cup[359.9975^\circ,360^\circ]$。这些是必要区间。五体夹界中的 $P_5$ 与自由折叠分离中的 $Y$ 是不同的输入。

## 六面的总面积

设 $H=\bigcap_{j=0}^5\{n_j\cdot p\le1/2\}$，$n_j$ 是角度 $60j$ 度的单位向量。令 $D\supset C_*$ 为任意凸宿主，$Q=D\cap H$，写 $\delta_j=h_D(n_j)-1/2\ge0$。$Q$ 包含 $C_{150}$，原六面上保有第215轮凸核的六个真实线段，长度记为 $L_j$，各大于 .41542。平面混合面积的单调性及投影到外法向的边长测度给出
\[
 |D|-|Q|\ge V(Q,D)-|Q|
 =\tfrac12\int (h_D-h_Q)\,dS_Q
 \ge\tfrac12\sum_{j=0}^5 L_j\delta_j.
\]
相邻两平面外伸的几何区域可能重叠，上式仍能同时对六面计价。对另一个已摆放的一宽体，设转动、手性确定而尚未平移时在前三法向上的支撑为 $h_0,h_1,h_2$，定义 $q=1/2+h_1-h_0-h_2$。因 $n_0-n_1+n_2=0$，它不依赖平移，故也可直接从已摆放体计算。其六向有符号支撑多出的量以 $x,z$ 表为
\[
 (x,q+x+z,z,-x,-q-x-z,-z).
\]
其中 $x,z$ 是相对于按 $n_0,n_2$ 居中的平移偏差。若宿主已经容纳某个 $q\le-a$ 的体，则三个偶数面额外面积和至少为 $a\min(L_0,L_2,L_4)/2$。另一方面原 $C_*$ 使第1面必有 $\delta_1>.0000003000633153$。其余体可取不同平移，这些共同下端仍成立。

设旧 $C_*$ 在 $H$ 外侧的面积上端取 $S=|C_*|^+-|C_{150}|^-$。第219轮给出 $|C_{150}|^-$，两种释放宿主真实面积比较证书给出 $|C_*|^\pm$。若宿主截面 $Q$ 在 AH 弦正侧的材料内证面积为 $J$，该侧真 $C_*$ 面积上端为 $U=.000107728773120711$，则
\[
 |D|-|C_*|\ \ge\ J-U+
 \tfrac12\sum_{j=0}^5 L_j\delta_j-S .
\]
这是因为 $Q$ 包含 $C_*\cap H$，弦负侧已有材料完整保存。$J$ 的每个有理格点须同时处于 $H$ 的内部或边界。程序对 $Y$ 的所有新增格点逐个核验六面，旧 $C_{150}$ 的格点由原宿主的全体支撑条件保证。斜帽深度只在由单一斜帽三角形已足够排除的角格使用。

若假定 $|D|$ 不超过指定目标，则上述六面费用给出 $Y$ 各方向偏差、相容量和自由平移的紧区间。对其两种手性和全部闭角格，先应用这些必要条件。余下格把真实弦上支撑点与两弦端构成的三角形转成整数内格点；必要时继续划分二维平移，而同一体逐方向保持同一平移。每格在六面费用中取刚才的旧强制值、未知体实际支撑给出的下端、以及偶数面总强制值的最大联立下端。$X_1$ 在 $D_-$ 中有 $q<-3.1199\cdot10^{-7}$。按这个固定 $a$ 和面积门槛 .844082054，对 $Y$ 的整格证书排除了所有摆放（free-fixed-lower.json）。此证明实际只要求宿主含 $C_*$ 和某个具有上述负 $q$ 的定宽体；第四个反射副本有更负的 $q$，也足以换用。

## 全体准许姿态

将门槛固定为 B 而将 $a$ 改为 $2.8\cdot10^{-7}$，同一混合面积程序排除了所有格（free-B-lower.json）。因此任何面积不超过 B、容纳 $Y$ 且包含 $C_*$ 的宿主，对它所含的每一个已摆放的定宽一体都严格有 $q>-2.8\cdot10^{-7}$。

取 $|w-.811550290734|\le4\cdot10^{-7}$、$|e-.034078764549|\le10^{-7}$ 的闭矩形。上项不等式与六面正向预算及两原斜帽的真实线段相合，给出该矩形每个 $P(w,e)$ 所有可能的角域。反手仅余 $[239.9975^\circ,240.00085^\circ]$；正手仅余 $[354.01^\circ,354.28^\circ]$ 和零角附近，即 $[359.9975^\circ,360^\circ]\cup[0^\circ,.00085^\circ]$。程序对 $q$ 和斜帽支撑组合使用同一 $(w,e)$ 的导数区间，再对整角格用支撑导数求界。两种手性均以一度闭格覆盖全圆并按需二分，最大深度7，所有允许小区间的端点纳入初始角切分。以上是必要的角域；零角附近和正手近折叠槽是否能覆盖任意输入，仍待证明。

## 真面积与复算

构造上端对原核单位弧用每段4096份的相邻切线，初始多边形法向用新增材料的1440个支撑方向生成，但每个最终法向的新增支撑直接对真实曲体求值。原150体先用归档32768方向支撑点与全角半径外包；加强版 certify_hull.py 在旧外包可能主导时重算150体的真实支撑，遇退化扇则保留现有上界。参数闭区间保有第223轮已证的二阶外余量。旧宿主下端 material_lower.py 抽取 AH 一侧的实际输入内格点，并计入第4面实线段和反射副本支撑点在弦负侧形成的外侧三角形。新宿主是完整材料的闭凸包。所有最终面积均为有理端点。

## 复算

~~~sh
PY -I -B verify.py COMP WORK OUT
~~~

用装有 **python-flint 0.9.0** 的 Python 路径替换 **PY**。**COMP** 指向项目公开的 **lebesgue-universal-cover/computation**，包含 **released-hexagon**、**single-repair** 和 **free-face-expansion** 等计算目录。**WORK** 为可写工作目录，**OUT** 为验收 JSON 文件路径且其父目录须存在。脚本会在 **WORK** 下创建唯一的运行子目录，并保留每项回执和算术输出。

默认依次重算公开宿主真面积、单面两分支下端及上端、固定旧摆放两端、自由修补两端、同五体自由重摆两种上端和整盒必要角域。通过 **--section single** 和 **--section free** 可以分别运行，**--section pair** 另行复跑 $P_1,P_2$ 的无条件联合增量。默认一次至多并行两个本机进程。公共几何、基础采样点和 **free-witness.json** 从 **COMP** 读取。**joint-fixture.json** 仅为严格 AH 外半平面选择候选法向，所有切高仍使用区间重算。公开参考回执提供经核验的早期材料，新的角域和面积均按实际几何重新结算。

主工作区使用 Python 3.13.18 及 192 位 Arb 实际复算默认的12项，另重算双体联合下端。从 computation/folded-free-repair 运行上述命令。主回执列出13份不同数学输出的 SHA-256，依赖表列出80个公共源和输入的哈希。[双手性与面积核验](../computation/folded-free-repair/verification.json) · [依赖表](../computation/folded-free-repair/dependencies.json)

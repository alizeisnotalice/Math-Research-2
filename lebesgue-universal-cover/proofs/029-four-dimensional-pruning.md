# B3–Fourier 四维平移前置剪枝

本实验处理第 14 轮全局参数盒中的
`(t_B3x,t_B3y,t_Fx,t_Fy)`，而不处理 Fourier 转角或另 16 个 F8 参数。它是严格
前置排除，不是 20 维穷举或一般下界证明。

## 统一于 Fourier 转角的内核

固定盘 `D` 使用第 14 轮证书的 512 个有理内点。B3 使用

```
Q_B = {(11/20,0),(-11/40,47/100),(-11/40,-47/100)}.
```

程序用有理 `sqrt(3)` 区间及 Reuleaux 三个单位圆盘的平方距离，逐点严格
验证 `Q_B subset B3`。

Fourier 体的支撑函数满足

```
h(theta) >= 1/2 - 1/80 - 19/1200 = 283/600.
```

因此无论 Fourier 体怎样旋转，均包含中心为零、半径 `283/600` 的圆盘。取其
严格有理八边形内点

```
Q_F = {(+/-47/100,0),(0,+/-47/100),(+/-33/100,+/-33/100)}.
```

轴点平方范数为 `(47/100)^2`，对角点为 `2(33/100)^2`，均严格小于
`(283/600)^2`。故它不依赖 Fourier 的任意转角。

对每个四维盒，在中心用 `D`、`Q_B+t_B3`、`Q_F+t_F` 求材料凸包。材料只保留
标签和未平移基点；在每个角点必须由标签重建 `q+t`，且程序断言中心的重建等于
已用于 hull 的中心平移顶点。这专门防止此前“中心平移加两次”的错误。

相邻材料点的行列式最多含一个 B3 平移和一个 Fourier 平移的叉乘。因此它对四个
平移坐标逐个都是仿射（multiaffine）；同体的二次平移叉积自动抵消。面积鞋带和
每个定向行列式的极小值都在四维盒的 16 个角点取得。若所有方向行列式严格正且
16 个内扇形面积均大于 `419/500`，则整个盒被排除：扇形三角形属于
`conv(D union (B3+t_B3) union (F+t_F))`，也属于任意 F8 候选覆盖。

## 实际有限树

根盒为 `t_B3 in [-.21,.21]^2`、`t_F in [-.24,.24]^2`。采用循环单坐标二分
（二叉而非 16 叉），最大深度 16、节点预算 8000。实际处理了 8000 节点，因达到
预算，5291 个未处理/未排除终端叶均完整保留。输出用完整二进制前缀叶集表示分区；
验证器不构造四维细格，而是验证这些前缀恰好完整覆盖根盒且互不重叠。

- 总排除比例为原四维平移盒的 `28597/32768`，保留 `4171/32768`。这些是**相对
  原四维参数盒的比例**，不是整个 `R^4` 的体积。
- 在所有排除叶中，最小内扇形面积为
  `838008996753860298776547135901/10^30`，约 `0.838008996754`，严格高于目标。
- 为比较 B3-only 投影，读取已验证 B3 二维叶集仅作分类（不参与四维不等式）。
  B3-only 的提升排除比例为 `2523/4096`。此次四维扇形剪枝中，有
  `2211/16384` 的原四维盒比例位于该 B3 投影排除集的**不交补**：这是严格可计量
  的、真正由 B3–Fourier 耦合带来的新增排除。其余已排除叶中有
  `3521/16384` 完全位于旧 B3 投影排除域，另有 `17133/32768` 与其相交；混合叶
  没有被计入新增量。

因此该实验明确改变后续策略：先运行该四维扇形树比只提升 B3 二维剪枝能排除额外
的全局 4D 参数盒部分；但预算内仍有保留叶，不能把它写成完整 4D、20D 或 Lebesgue
常数下界证书。


在盒中心，固定盘内点的凸包包含原点于内部。行列式沿参数路径严格为正使相邻射线的有向夹角始终介于0与π，故绕数保持为1，所计各扇形三角形内点不交。

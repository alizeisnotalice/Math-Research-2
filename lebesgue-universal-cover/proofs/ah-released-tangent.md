# 改换 AH 配对切线后的凸宿主和定宽反例

固定 σ=1.5497°，保留第199轮十一段 EH。记原直边为从 Z 到 Tₐ 的线段，D=Tₐ−Z。记 q(w) 为对应的真实配对点，沿正向边界从 Z=q(0) 到 T′=q(1)。固定新 AH 半平面为绕 Z+pD 向内旋转 δ 后的原直边半平面。以下区间面积均以同一真实平面坐标的 Lebesgue 面积计。

## 构造及真实面积

对 a≤w≤b，以 q(a) 和 q(b) 的两条支撑切线替换旧弧。短修正版的新边界经两线交点，逐边按从 q(a) 到 q(b) 的顺序。长链另取 k=57,61,…,121 的 q(k/128) 外单位法向 u，支撑常数由 u·q(k/128) 增为 u·q(k/128)+10⁻⁶。相邻线对的交点给出真实顶点。证书检验相邻外法向叉积为正、所有直边沿正向切线前进、每个内顶点严格左转。两端平直接续旧弧切向。从旧边界删除的弧严格正曲率，其总转角小于 π。因此替换保持边界正向及总转角 2π，得到凸体。旧宿主位于每条外移支撑线的保留侧。新边界全位于原 P。旧弧边和直边继承自 P，新折链的全部端点和角点均通过 P 的六个六边形法向及 m₃、m₅，最小净余量在三种宿主中分别超过 .00282767、.00275589、.00049495。凸性给出整条折链及所围区域的包含。

取 w=.429、t=10⁻⁸，V=(0,1/√3)。点 (1−t)q(w)+tV 属于下文统一放进各个新宿主的反射像。它超出旧 G 的 q(.429) 支撑线超过 9.2174892×10⁻¹¹，故三个新宿主均有确定点落在旧 G 之外。

计算从 q(a) 到 q(b) 的新折链 Green 积分，再减去同端点的真实配对弧积分，所得为新增面积。删除面积等于新直线在原 G 切去的真耳与第199轮旧直线真耳之差。确实，在原直边归一化坐标中，旧裁线有正切深的点满足 w<.427；新直线的 p 和正斜率均更大，故旧耳包含在新耳内。新裁线与配对弧相交于 a 之前。由凸性和端点异号，该弦在配对侧只穿过边界一次。新增部分包含在替换折链及其端点弦围成的凸多边形内，所有顶点严格留在新裁线内侧。交叠修正恰为零。EH 和其他原边界完全相同。

|首版|4.73164563114×10⁻¹¹|5.55925969957×10⁻⁶|5.55921238311×10⁻⁶|5.49690268151×10⁻⁶|

## 一整个定宽输入族在同一姿态中的放置

令 K_w 为第96轮构造的定宽一五边形，R 为一个顶点在 V 的原点居中 Reuleaux 三角形。对 K_{w,t}=(1−t)K_w+tQ_A R，直接放置 Q_AK_{w,t}，平移为零。三个宿主分别容纳以下闭参数矩形。

|宿主|w|t|全部非平凡检查的统一余量下界|
|---|---|---|---:|
|首版|[.42868,.430]|[0,10⁻⁸]|3.53×10⁻⁸|
|短修正版|[.4285,.4301]|[0,.00005]|3.79×10⁻⁸|
|长链|[.4285,.950]|[0,.00005]|1.76×10⁻¹⁰|

512个闭格重验五顶点各对非单位距离小于一，十个单位方向按正角度排序，邻方向点积大于 3/4。方向扇上原支撑为 u·vᵢ+c，c∈{0,1}；各向六边形支撑接触顺序由同一闭格检验为顶点指标 1,3,0,1,3,0。三对接触点按坐标构造精确落在相应直线上，对合扇给出六个精确支撑 1/2。反射 Q_A 保持六边形，R 亦有同样的六个支撑。三角形其余方向的支撑由三个顶点及法向落在弧扇内部的单位圆支撑确定。两个定宽体的支撑在 Minkowski 和下相加，故只须用 t 的两个端点。对每个可行顶点扇，用中心值加上 w 导数的全格投影包围作上界；扇端点歧义同时纳入邻扇。逐格对一整个凸体的支撑取上界。第150轮60点和第156轮18点两个有理反例也均在各宿主的恒等姿态内，所有实际检查行最小余量超过 2.15×10⁻¹⁴。

长链处五组圆弧按真正的圆支撑验证。已证同一姿态在 P 内，其中六边形面为精确等式，两条正斜帽边 I→E₃ 和 K→C₃ 分别给 m₃ 和 m₅。对下表每组边，第28轮保证 K 在所列线段 [c,d] 内有接触点 a。该组真弧的全部外径向 u 满足 u·(d−c)≤0，来自端径向同号及内径向是它们的归一化正组合。于是每一组均有 h_K(u)≤1+u·a≤1+u·c，给出整弧的所有支撑，在上述固定姿态同时成立。

|计算名|实际弧|圆心 c|强制接触段 [c,d]|
|---|---|---|---|
|Q|Q→Y|E₃|[E₃,D₁]|
|Tp|T′→P₀|G|[G,D₁]|
|H|H→新 EH 的弧端|C₃|[C₃,B₁]|
|Te|T→I|B₃|[B₃,B₂]|
|G|G→K|F₃|[F₃,F₂]|

原完整扇、端点符号及继承短弧见 [五段 Sprague 真弧](eh-sprague-exact-arcs.md)。其中 Tp 从配对弧终点 T′ 出发，沿 G 圆到 P₀。此前的 Z→T′ 对应 chord_Z，未替换部分的内弦以及所有新折线均另行检验。Y→Tₐ 同样保留128条内弦检验。短宿主对五段 Sprague 弧采用更强的内弦逐条放置检验；长链的60点及18点离散见证也逐条通过所有五组内弦。

## 否定首版和长链

若替换只做到 55/128=.4296875，凸性保证 q(.4299) 处的原切线继续全局支撑新宿主；该点在改弧右端之后。对 p=.430，这直接触发第199轮的无内根扰动反例。扩大到56/128并且覆盖整个并合窗口，仍不能排尽更大扰动。

|宿主|w，t|恒等姿态违规|Q_A 姿态违规|其余十姿态最小违规|
|---|---|---:|---:|---:|
|首版|.42883，.000015|>1.52325×10⁻⁸|左端切线 >4.55998×10⁻⁹|>.00094713|
|长链|65/128，.0002|>.0001770285|65/128 外移切线 >7.24216×10⁻⁷|>.00067017|

两件明确给定的定宽一体分别由249和236个闭角格检验六边形相容函数在 [.5°,59.5°] 严格为负。角格中心算两个体的精确支撑，五边形使用对应扇的导数包围，三角形的导数绝对值以其外接圆半径 1/√3 控制。两端半度由三对接触的一阶展开和至多 (3/2)(1−cosφ) 的二阶误差给严格负号。于是六边形中仅有60°整数倍的正交部分及其反射，且平移由两条独立支撑唯一固定为零。表中后十姿态实际违反 P 的 m₃ 或 m₅，首版和长链均在 P 内，故排尽所有刚体运动。

特别地，任何包含于 P 且保留长链新直线 p=.950、δ=.011 的万能宿主，在 q(65/128) 的旧外法向上的支撑必须比原支撑大于 1.724216×10⁻⁶。这来自唯一剩余姿态 Q_A 对显式输入的实际支撑。该必要条件独立于十九段的具体取法。短修正版已证明能装入击穿首版的反例。剩余问题是对一般定宽一体建立完整姿态选择，或给出击穿短修正版的另一件输入。

## 复现

在主课题根目录执行下列命令。两套本机 Python/Arb 环境分别从同一归档输入启动，五份 JSON 的全部字段一致。

```sh
python -B computation/certify_ah_released_tangent.py computation first.json
python -B computation/certify_ah_released_tangent.py computation repair.json --repair
python -B computation/certify_ah_released_tangent.py computation long.json --long
python -B computation/certify_ah_released_tangent_obstruction.py computation first-obstruction.json
python -B computation/certify_ah_released_tangent_obstruction.py computation long-obstruction.json --long
```

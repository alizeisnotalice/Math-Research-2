# 万能覆盖的宽一方向与四方向不等式

方向按模 π 计。设 Q 为平面凸万能覆盖，w(θ) 为方向 θ 的宽度。则方向集 {θ:w(θ)=1} 至多有三个元素。反过来，任意指定的不多于三个方向构成的集合，恰好是某个紧凸万能覆盖的全部宽一方向。以下还给出严格定量的四方向约束。

**至多三方向的构造。** 给定三个不同方向，令 u_j 为任意定向的单位法向，取单位圆盘三对平行切线围成的闭六边形 P，即 |u_j·x|≤1/2 的交。对任何直径至多一的测试集，取其闭凸包 T；转角 φ 下沿 u_j 的最大、最小投影的中点记作 c_j(φ)。这些函数连续，且 c_j(φ+π)=−c_j(φ)。取非零线性关系 Σλ_j u_j=0，则 Σλ_j c_j(φ) 在某角为零。三法向矩阵秩为二，故可以同时解出 u_j·t=−c_j(φ)。平移后所有投影都中心化，长度至多一，所以 P 万能。P 包含内切圆盘，指定方向宽为一；任何其他法向的圆盘接触点在 P 内部，故相应宽度严格大于一。两个指定方向时直接取两条带之交，所需平移由两方程解得。一个指定方向时可在足够大的圆盘内只保留对应条带；它包含一个用该方向构造的上述万能六边形，并且其余圆盘切点均在内部。空集可由半径一圆盘实现。

**四方向的普适约束。** 取测试体 D 为半径 1/2 的圆盘，K 的支撑函数为 h(θ)=1/2+c cos(3θ)，c=1/16。因 h+h″=(1−cos(3θ))/2≥0，h 确为凸体的支撑函数（也可取 c 由下递增的严格凸体极限）。它的宽度恒为一，反射对称，直径为一。将已放入 Q 的 D 居中，K 的一副本具有平移 t 和转角 φ。记

    f(θ)=t₁ cos θ+t₂ sin θ+c cos(3θ−3φ).

两体凸包的宽度恰为 1+|f(θ)|，故对所有 θ 同时有 w(θ)−1≥|f(θ)|。令 z=exp(2iθ)，则 exp(3iθ) f(θ) 是 z 的三次多项式，其三次项系数为 c exp(−3iφ)/2，非零。四个不同的无向方向给出四个不同的 z。一方面 f 无法在这四处均为零；另一方面，Lagrange 插值的首项系数和三角不等式给出

    Σ_j (w(θ_j)−1) / Π_{k≠j}|sin(θ_j−θ_k)| ≥ 4c = 1/4.

特别地，若每对无向方向夹角至少 β（取锐角或直角），则其中最大宽度至少为 1+sin³(β)/16。

**等距方向的加强。** 对任何 θ₀ 及 θ_j=θ₀+jπ/4，坐标旋转可令 θ₀=0。正交求和给出 |Σ_j f(θ_j)exp(−3iθ_j)|=2c，因一次谐波及三次谐波的共轭项求和为零。四个实系数位于 [−1,1] 时，相应复向量和的模最大值可在立方体顶点取得。十六组符号的平方模为 4±2√2，各出现八次，故最大模为 1/sin(π/8)。从而

    max_j w(θ_j) ≥ 1 + sin(π/8)/8.

对 D 与 K 这两个测试体，界可达到。令 m=sin(π/8)/8，φ=π/8，t=(m/2,(√2−1)m/2)，代入所得四个 f 值为 m(1,1,−1,1)，取两体凸包即得。等号构造只针对两体测试族，更大族可能给出更强门槛。符号枚举按有理数与 √2 的系数作整数运算，复核脚本与输出见 computation/verify_four_strip_width.py、059-four-widths.json。

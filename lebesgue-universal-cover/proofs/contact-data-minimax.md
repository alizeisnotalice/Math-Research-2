# 从等距法向接触数据重建定宽体的最优误差

在半圆取 \(n\ge2\) 个等长角格，格宽 \(d=\pi/n\)。观测量是各格端点的接触点 \(h(t)u_t+h'(t)u'_t\)。给定这些数据，在固定平面坐标中重建整个定宽一凸体时，最坏情形的最优 Hausdorff 误差恰为

\[
\frac{E(d)}2,\qquad
E(d)=\sqrt{4-\sin^2(d/2)}-1-\cos(d/2).
\]

在每个格上，以同一对端点接触构造两种可达到的极端支撑 \(h_-,h_+\)。它们的曲率密度分别为 \(1_I\) 与 \(1-1_J\)，其中 \(I,J\) 是由接触点位移确定的单个区间。半圆另一侧用定宽关系补全，因每格接触位移完全匹配，两者分别给出闭定宽体 \(P_-,P_+\)。取它们在**同一坐标系**中的 Minkowski 平均 \(M=(P_-+P_+)/2\)。在前半圆上有 \(h_-\le h_K\le h_+\) 且 \(h_+-h_-\le E(d)\)，在后半圆上不等式次序反转。因此 \(d_H(K,M)\le E(d)/2\)。\(M\) 仍然定宽一，其曲率半径几乎处处取 \(0,1/2,1\)。相对于常数 \(1/2\) 的背景，每格至多两个指示区间改变密度，反侧也如此，全圆至多 \(8n\) 个不同的切换点。[扇内逐点极值与锐例](sharp-support-compression.md)

反过来，取一个格，在其上使用上引证明的两个等号构造，在其余半圆取圆盘曲率，另一半圆各取对径补。所得两个闭凸体在每个网格法向都有同一接触点，而在该格中点的支撑差恰为 \(E(d)\)。任何只使用这些接触数据的重建都返回同一结果。由 Hausdorff 距离的三角不等式，两个真体至少有一个距该结果不小于 \(E(d)/2\)。这证明了上述最优性。

## 普适面积的双边近似

这给出与有限夹带离散化不同的一组中间面积。令 \(a_n\) 为覆盖半径 \(1/2\) 圆盘及**所有**至多 \(2n+1\) 单位弧的定宽多边形所需凸宿主的面积下确界。令 \(b_n\) 为覆盖同一圆盘及所有网格端点数据所生成的平均体 \(M\) 的相应下确界。任取一组可行接触数据就生成一个平均体；所有数据仍构成连续参数族。两种情形都有严格的全体误差控制，其中 \((c_n,s_n)\) 可分别取 \((a_n,E(\pi/n))\) 或 \((b_n,E(\pi/n)/2)\)。

\[
c_n\ \le\ \Lambda\ \le\ (1+4s_n)c_n+\pi s_n^2.
\]

事实上测试体全为真直径一体，故第一项成立。若凸宿主 \(C\) 同时覆盖所选测试全族与圆盘，先将某个被容纳圆盘的中心取作原点。几乎处处的外法向 \(u\) 满足 \(x\cdot u\ge1/2\)，面积恒等式 \(2|C|=\int_{\partial C} x\cdot u\,ds\) 给出 \(P(C)\le4|C|\)。任意定宽一体都与某个同类测试体的距离至多 \(s_n\)；该测试体的摆放刚体保持这个距离，所以 \(C+s_n\mathbb B\) 可容纳整个输入。平面定宽补全将此结论推广到全部直径至多一的集合。对平行体应用面积公式，再取下确界即得。特别是两列都以 \(O(n^{-2})\) 的绝对误差逼近 \(\Lambda\)，证明对宿主的方向、外半径或是否在正六边形内没有预设。[已有有限代数多边形近似](finite-strip-universal-bridge.md)

例如，若一个含半径半单位圆盘的宿主具有第215轮展示的面积上端，且覆盖相应的整个连续测试族，则对单位弧多边形可取 \(n=3579\)（至多7159弧），对平均体可取 \(n=2531\)，相应外扩后的面积均严格低于 B 档。这两个整数都是上述统一面积公式下的最小值，因为 \(E(\pi/n)\) 随 \(n\) 严格递减，并已分别核验前一个整数。第215轮的具体宿主已有不能放入的五弧体。[有理门槛与定向计算](../computation/finite-arc-reduction/area-budget.json)

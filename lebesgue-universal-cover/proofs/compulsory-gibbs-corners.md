# 原 Gibbs 宿主内的所有万能凸子集都高于 B

固定 \(1.50^\circ\le\sigma\le 1.54^\circ\)。以 \(H\) 表示原宽一正六边形，\(P(\sigma)\) 为其与两条半平面 \(m_3\cdot x,m_5\cdot x\le1/2\) 的交。下文证每个闭万能覆盖 \(C\subseteq P(\sigma)\) 都含 \(C_3=n_0\cap m_5\) 与 \(B_1,F_1,D_1\)。与连续两耳障碍合用，对任意闭凸万能覆盖 \(C\subseteq G_\sigma\) 均有
\[
 |C|>.844082371714350267716580889258117757>
 B=.844082046521218581802948589770767704354 .
\]
最后的面积结论使用原 Gibbs 宿主包含条件。四顶点的强制性本身对较大的两帽域 P(σ) 直接成立。

## 一个 Reuleaux 三角形同时强制三个顶点

取顶点为 \(B_1=(1/2,1/(2\sqrt3))\)、\(F_1=(-1/2,1/(2\sqrt3))\)、\(D_1=(0,-1/\sqrt3)\) 的定宽一 Reuleaux 三角形。三个 120° 相隔的法向有相同的未平移支撑，三法向之和为零；装入 H 时三项必均为半宽，且平移为零。在任一顶点的外法锥内，支撑是 \(\cos\alpha/\sqrt3\)，其值只有在 \(|\alpha|=\pi/6\) 时为半宽。反向锥上由宽一性取补数。因此只有60°整数倍的旋角，反射不增加几何像。与上述三角形相反的几何像在辐角 210° 处有半径 \(1/\sqrt3\) 的顶点，m₃ 投影为 \(\cos\sigma/\sqrt3>1/2\)，被禁止。余下唯一几何像恰含 B₁、F₁、D₁。

## 二十一个锚给出 C₃ 的真实定宽见证

令 \(J(x,y)=(-x,y)\)，\(J_{90}\) 为逆时针直角旋转。取
\[
 c=C_3,\quad l=c-m_5,\quad v=\tfrac12 n_1-.04J_{90}n_1,
 \quad w=v-n_1,\quad a=(0,.501).
\]
另取下表六个精确有理点，将 \(c,l,v,w\) 以及这六点的 J 像一同加入，连同 a 得二十一点集 X。

| 横坐标 | 纵坐标 |
|---:|---:|
| .026049970901 | .515888228177 |
| .336263316958 | −.347577565759 |
| .181470788663 | .464793989670 |
| .447623842314 | −.212397700613 |
| .293446043323 | −.390014410874 |
| .067495484760 | .504591212874 |

五个解析单位点对为 \(c,Jc\)、\(c,l\)、\(Jc,Jl\)、\(v,w\)、\(Jv,Jw\)。其余205个点对全都满足平方距离小于 \(1-.000022798\)。取任一定宽一补全 D，令 \(D_0=(D+JD)/2\)，由对称性得 \(X\subseteq D_0\)。第一、第四、第五对单位点分别钉住三对六边形边：因 \(n_0\cdot c=n_1\cdot v=n_2\cdot Jv=1/2\)，故六法向的支撑均为半宽。

令 \(U\) 为支撑函数 \(h_U(u(t))=1/2+\sin(3t)/100\) 的纵轴对称定宽一体。该函数的曲率半径至少 .42，U 包含原点。对每个 \(0<\lambda\le10^{-7}\)，取真实定宽一体
\[
 K_\lambda=(1-\lambda)D_0+\lambda U.
\]
六个原六边形法向的支撑仍为半宽。

定义消去平移的相容函数
\[
 F(\theta)=\sum_{j=0}^2 h_{K_\lambda}(u(\pi+\theta+2j\pi/3))-3/2 .
\]
旋转后能装入 H 的必要条件为该函数在相对旋角处为零。宽度一给出 \(F(60^\circ+\theta)=-F(\theta)\)，纵轴对称再给 \(F(60^\circ-\theta)=F(\theta)\)。第一度用 \(Jc,Jw,v\) 在三个旋转方向上的投影。若 B 是对应的初始切向投影之和，则
\[
 F(\theta)\ge (1-\lambda)(1.5\cos\theta+B\sin\theta-1.5)
                 -(3\lambda/100)\sin(3\theta).
\]
右侧在零处等于零，第一度的向内弧度导数大于 .02059189。对 [1°,30°] 上每个闭角格，由 X 的21个投影下端分别束住三个支撑，再扣除谐波的最坏损失。整段斜角用11个连续闭格，合计2386个根角盒，全域严格余量大于 \(5.83686\times10^{-8}\)。因此只有60°整数倍的旋角可行。每种此类正交姿态的平移为零。Kλ 本身纵轴对称，反射产生的几何像已经包含在这六种旋转中。

在 m₀、m₁ 上，取 X 的最大投影并扣除谐波扰动的最坏损失，得混合体支撑超过半宽的余量均大于 .00587289。在 m₂ 上，\(m_2=-m_5\) 且 \(m_5\cdot c=1/2\)，故 \(m_2\cdot l=1/2\)。谐波项带来严格超额 \(\lambda\cos(3\sigma)/100>.0099675\lambda\)。定宽性使 m₃、m₄、m₅ 的支撑都严格小于半宽。旋转 k·60° 时，两条旧斜帽的拉回下标为 3−k、5−k，只有 k=0 时二者同时属于 \(\{3,4,5\}\)。所以 Kλ 在 P 中只有恒等几何像。

不必指定补全 D 的选择。每个 C⊆P 若普适，就须包含 Kλ，故含 \((1-\lambda)c\)。令 λ↓0 由闭性得 \(c=C_3\in C\)。整个21个闭单位圆盘的交也强制：交内任一点 p 及 Jp 均在交内，且由 \(c,Jc\) 这对水平单位对径锚得 \(|p_x|\le1/2\)，因而 \(|p-Jp|\le1\)。将两点先加入 X 再补全，上面的证明保持成立。

同一个见证给出能实际排除削角体的反例。若闭集 C⊆P 删掉 C₃，写 \(d=\operatorname{dist}(C_3,C)>0\)，取 \(0<\lambda<\min(10^{-7},d/|C_3|)\)。该 Kλ 的唯一容许几何像含 \((1-\lambda)C_3\notin C\)。因此仅换用其他 AH 或 EH 支撑也无法修复这种削角。

## 角点复算

所用21个点、根角分割、非单位点对、斜帽和余量由 Python 3.13.18、python-flint 0.9.0、192位 Arb 计算。

    python -I -B certify_compulsory_C3.py COMP compulsory-C3.json

结合上一轮的完整闭轮廓与连续面积复算，得到开头所列原 Gibbs 宿主内的一般子集面积障碍。它不约束伸出原 Gσ 的新宿主。

## 左端点 H 给出的原 Gibbs 宿主面积障碍

取 1.50°≤σ≤1.54°。令 H 为 EH 耳的原端点，H=JC₃，J 是纵轴反射。这个 H 属于二十一个直径锚点。对任意普适的闭集 C⊆P(σ)，每个见证 Kλ 的唯一容许像都包含 (1−λ)H。令 λ↓0，得 H∈C。

现在再设 C 是原 Gibbs 宿主 Gσ 的凸子集。原强制轮廓按正向经过 F₁,E 及 S 圆上的 E→T 圆弧。F₁、E、H 都在 x=−1/2 的边上，按 F₁,E,H 排列；加入强制线段 EH、HT，替换圆弧 E→T，其余边界沿用第225轮。新轮廓由径向向量积 [E,H]、[H,T] 为正以及原轮廓的径向次序保持简单，并包含于 C。由 Green 公式，其面积增量为
\[
 \frac{[E,H]+[H,T]-[S,T-E]-\arctan([E-S,T-S]/\langle E-S,T-S\rangle)}2 .
\]
所有三角函数以弧度计，每个原闭角格上用四阶 Taylor 区间与原面积导数相加，得到新轮廓关于 σ 的弧度导数严格小于 −.00065510231；两个径向向量积的全域下端都超过 .00742523。故最小值在 1.54° 取得。该处新增面积大于 .00000174814229041430907322499413725330，得到
\[
 |C|>.84408411985664068202565411425225501127180755 .
\]
它比 B=.844082046521218581802948589770767704354 高出 .00000207333542210022270552448148730691780755 以上。这个下界适用于角域内每个原 Gibbs 宿主中的全部闭凸万能子集。要在这个角域达到 B，必须超出原 Gibbs 宿主；两帽松动或其他几何改动有待分别分析。

复算使用 Python 3.13.18、python-flint 0.9.0、192 位。输入 JOINT 为第225轮 continuous-joint.json，TIPS 为 compulsory-C3.json。

    python -I -B certify_H_corner_gain.py COMP JOINT TIPS H-corner-gain.json

## 两个 AH 支撑足以建立整个障碍

令 Pσ 只保留正六边形与两条斜帽，1.50°≤σ≤1.54°。令
\[
 L_0=\{z:u_0\cdot (z-T_a)\le0\},\qquad
 L_q=\{z:u_q\cdot (z-q(.435))\le0\},
\]
其中 \(u_0=T_a-JE_3\) 是原直段的单位外法向，\(u_q=-J_{90}q'(.435)/|q'(.435)|\)。任意普适闭凸体 C⊆Pσ∩L₀∩Lq 都满足
\[
 |C|>.84408411985664068202565411425225501127180755.
\]

证明可以逐项列出对母宿主的使用。Pσ 的六边形和两条斜帽直接强制四条圆弧 TI、GK、QY、YTₐ，及其三套单位圆盘交。这同时强制 E₃、圆弧 ET、弧端点 T、I、G、K。唯一 Reuleaux 三角形和二十一个锚的定宽补全均只用 Pσ，因而 B₁、F₁、D₁、C₃、H 同样强制。

对十三个参数 w=.435,.45,.50,…,1，取第225轮重放的八锚组，先用六边形六个闭支撑和 Pσ 的两条斜帽证明全部几何摆放只可能是恒等或 Q_A。八锚的 Q_A 像含 x(w)∈∂L₀，与谐波体正权混合后在同一相位严格越出 L₀。因此这些混合体都只能以原姿态摆入 C，令权重趋零得全部 q(w)。w=1 时，将强制的五边形弧上各点与原锚一并补全，在同一论证下得到整个 T′P 弧；亦可直接调用 proofs/sigma-paired-rigidity.md 的第一条，所需母宿主恰是 Pσ∩L₀。

最后单独考察 w=.435。在这一参数处的八锚补全中，给顶点 \(V=(0,1/\sqrt3)\) 的定宽一 Reuleaux 三角形以充分小的正权重。六个整倍角仍为唯一相容根；十个其他二面体姿态严格越斜帽。恒等姿态含点 \((1-\lambda)q(.435)+\lambda V\)，而整角域中 \(u_q\cdot(V-q(.435))>0\)。故恒等姿态越出 Lq，仅 Q_A 可用。该相位含趋于 x(.435) 的点，由闭性 x(.435)∈C。这里仅需 Lq 这一条半平面。

由凸性连接上述点和真圆弧即可逐段重建 上节含 H 的整个轮廓。理由中没有使用原 Gibbs 其余配对支撑或 EH 裁线。因而任一位于 Pσ、面积不超过 B 的普适闭凸体都必须跨过这两条指定半平面中的至少一条。可取原 EH 端点 H 在原 x=−1/2 竖边向下的充分小移动作为严格放大的例子：H 本身在 Pσ 的非竖边、L₀、Lq 上均有严格余量，原 Gσ 的同一竖边在 H 截止。

## 有限有理见证与同时外移

取 \(A<.84408411985664068202565411425225501127180755\)。存在一个由有限个有理点集组成的清单和常数 \(\eta,d>0\)，使以下结论对整段 \(\sigma\) 一致。将 \(P_\sigma,L_0,L_q\) 的十条单位法向半平面同时向外放宽至多 \(\eta\)。其中任一面积至多 \(A\) 的闭凸宿主 \(C\)，至少漏掉清单中一个点集 \(X\)，而且对每个刚体运动 \(g\) 均有 \(\max_{x\in X}\operatorname{dist}(gx,C)\ge d\)。各 \(X\) 的直径可取严格小于一。

为证明，记 \(\Delta(C,K)=\inf_g\sup_{x\in K}\operatorname{dist}(gx,C)\)。对非空有界闭集，旋转和手性是紧参数；平移趋于无穷时目标趋于无穷，故此下确界取得。\(\Delta\) 对 \(C,K\) 分别就 Hausdorff 距离都是 1-Lipschitz。把六个六边形面和两个斜帽、两个 AH 支撑先固定于原高度。面积至多 \(A\) 的非空凸紧宿主连同闭参数 \(\sigma\) 构成紧集，因为六个六边形面统一有界，支撑行随 \(\sigma\) 连续，面积对凸紧集的 Hausdorff 极限连续。对其中每个 \(C\)，上节定理给一项 \(\Delta(C,K)>0\) 的直径一见证。将 \(K\) 略作收缩，取有限网并以精度足够高的有理点替换网点，即得直径小于一且仍有正亏损的有限 \(X\)。连续性给 \(C\) 的一个开邻域；紧性选出有限多个 \(X_j\)。\(\max_j\Delta(C,X_j)\) 在原紧集的最小值 \(d_0>0\)。若不存在同时放宽量，就有 \(\eta_k\downarrow0\) 及在该放宽内亏损小于 \(d_0/2\) 的反例。六条六边形行仍统一限定半径，取收敛子列得到原紧集中的反例。故某个 \(\eta>0\) 与 \(d=d_0/2\) 适用。这个紧性证明没有给 \(\eta,d\) 指定十进制数值。

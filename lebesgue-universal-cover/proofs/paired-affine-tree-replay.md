# 确定性联立筛在盲叶 1202/32259 的原位姿树中运行

第 192 轮的联立下界可以在六体树内部自动生成。每个待查闭盒先走原五体扇及原 \(P_{30}\) 联合帽。遇到原核不能关闭的角格时，才尝试联立下界。仍未通过的节点按原材料扇选定的轴同样二分。两套算法始终使用整原叶的角端点插值；改变子树起点时也保持这组锚。

从不裁缩的原叶 1202/32259 出发，两套算法都严格关闭。联立筛将节点数由 2,844,977 降为 688,939，减少 **75.784%**。另在已知低五体位姿的第 182 轮真实路径上，预先固定其深度 28 前缀。对整个子树，在同一面积目标 \(0.83743\)、同一 \(2^{-44}\) 端点、同一材料表及 384 个角格下，两种算法都严格关闭。深度 44 的既知子盒也由自动筛选复算。

## 整数判据

记 \(Q=2^{28}\)，面积整数尺度 \(S=2Q^2\)，靶整数 \(g=\lceil 0.83743 S\rceil=120686381950363983\)。保留原核五体面积中的位姿一次项。对每个坐标在盒的两端向下取整，再线性插值，得到以 \(S\) 为单位的仿射下端 \(L(q)\)。对每个方向的圆盘及四个曲体分别构造支撑上端 \(B_{ij}(q)\)，以 \(Q\) 为单位。每项的盒端值向上取整，转角项使用整原叶的认证插值。令 \(B_i(q)=\max_jB_{ij}(q)\)。若原核的常数支撑上端为 \(\bar b_i\)，可采用墙 \(\min(B_i(q),\bar b_i)\)，它仍高于真实五体支撑。

设原五体核整数下端为 \(a_0\)，记 \(e=g-a_0>0\)。反设 \(S A_6\le g\)。沿用原核由 \(e\) 和 \(\bar b_i\) 算出的方向特定帽深 \(D_i\)。这是以 \(Q\) 为单位且含相应法向长度上舍入的深度。如果某方向的真墙外深度超过 \(D_i\)，该帽单独提供超过 \(e/S\) 的面积，已与反设矛盾。否则深度为 \(\delta_i\) 的单帽提供至少 \(\frac{e}{S}(\delta_i/D_i)^2\) 的面积。原核的半径界保证非锐角方向的正帽不交。一个正平衡三元组至多含一锐角对，故只将这一对放在同一分组。

每个角格的三法向行给出加权支撑下端 \(G\)，法向权重 \(\omega_i>0\) 的和为一，且其加权法向和为零。对任意第六体平移，令
\[
m(q)=G-\sum_i\omega_iB_i(q).
\]
使用真实墙产生的正深度有 \(\sum_i\omega_i\delta_i\ge m(q)\)。按原核向上舍入 \(t_i=\lceil\omega_i D_i\rceil\)，再设 \(C=\sum_J(\sum_{i\in J}t_i)^2\)。联合帽的柯西不等式给出 \(S(A_6-A_5)\ge e\,m(q)_+^2/C\)。对任意非负整数斜率 \(k\)，因而有
\[
S A_6 \ge L(q)+k m(q)-\left\lceil{k^2 C\over4e}\right\rceil.
\]
斜率候选由盒中点的下舍入正余量和整数参数确定。中点可以跳过没有潜力的行，只在所有活动体组合的全盒仿射下端均严格超过 \(g\) 时承认一行。程序通过逐点支配消去永远无法取得支撑上端的仿射项。对每个剩余组合，按系数符号精确取 11 个坐标的不利端点。这一步保留了面积及三个支撑在同一位姿上的相依性。

每个旧角格或联立角格必须各自通过，反射由 \(P_{30}\) 的有理对称性处理。原核用浮点初猜求 \(D_i\) 后，以整数四次方比较修正；新筛的候选斜率和通过条件均为整数运算。编译以 `-ftrapv` 检测有符号溢出。

## 重放

`COMP` 指包含第 182、192 轮资料的主工作区的 computation 目录。先用 `COMP/tomar_fan_table.py` 的 `--subdiv 64` 生成材料表，其规范数组重放时再检验。路径前缀来自第 192 轮的低位姿输入，逐级验证旧靶 \(0.83742\) 均未终止且分裂轴匹配。

    set -e
    mkdir -p WORK
    python -I -B COMP/tomar_fan_table.py CERT WORK/table64.npz --subdiv 64
    for d in 28 44; do
      python -I -B computation/replay_paired_affine_tree.py COMP CERT WORK/table64.npz WORK/run CACHE --path-depth "$d" --limit 600000 > "WORK/replay-$d.json"
      cmp "WORK/replay-$d.json" "computation/paired-affine-tree-depth$d.json"
    done
    python -I -B computation/replay_paired_affine_tree.py COMP CERT WORK/table64.npz WORK/full CACHE > WORK/replay-root.json
    cmp WORK/replay-root.json computation/paired-affine-tree-root.json

可用 `--times` 单独写入墙钟时间。子树深度不限制每个终端的角度覆盖。可用 `--path-depth 0` 从完整原叶启动，超预算或遇到首个未知子盒时，该算法对应计数数组的首项为零。

复算环境为 Python 3.13.18、python-flint 0.9.0、NumPy 2.5.5、Apple Clang 21.0.0。用第二个 Python 环境、重新生成的 64 级材料表与独立编译目录，完整原叶的联立核及两个子树的双核再次重放，全部整数计数与冻结回执一致。本轮严格结果覆盖完整盲叶与列出的两个真子树。其余同靶原叶未在本轮比较。

# 等定宽体凸包的全局支撑函数恒等式

在欧氏平面固定任意坐标原点，令所有测试体宽度为 1，放置任意（包括反射）。记 h_i(θ) 为各自支撑函数，u=(cos θ,sin θ)。以下积分均在整周上，导数取几乎处处的弱导数。令 Q(h)=∫(h²−h′²)/2。支撑函数是 Lipschitz 函数，凸体面积等于 Q(h)；该式由光滑凸体的面积公式对支撑函数作圆周卷积逼近得到。卷积在 H¹ 中收敛，凸体在 Hausdorff 距离下收敛，面积亦收敛。

## 两体精确比较

令 H_ij 为两体凸包。对于任何位置和角度，

    |H_ij| = (|K_i|+|K_j|)/2 + (1/4)∫|h_i−h_j|.

证明：设 U=max(h_i,h_j)，V=min(h_i,h_j)。逐角排序给出 Q(U)+Q(V)=Q(h_i)+Q(h_j)；在平手集合上两弱导数几乎处处相同。又因等定宽，V(θ)=1−U(θ+π)，故 Q(U)−Q(V)=∫U−π。因为 ∫h_i=∫h_j=π，∫U−π=∫|h_i−h_j|/2，合并即得。V 可以不是凸体的支撑函数，推导只使用其函数值与弱导数。

固定方向时，优化相对平移由此化为二维凸问题，即求 g=h_i−h_j 的最佳 L¹ 一次谐波逼近。任意可测函数 ψ 满足 |ψ|≤1 且 ∫ψu=0 时，∫ψg 给出与两体平移无关的下界。若选 ψ 在 g 的非零处等于其符号并满足该平衡条件，即得到最优平移证书。

## 三体恒等式与非负余项

设 H 为三体凸包，M 为 h₁,h₂,h₃ 的逐角中位数。写 M=1/2+m。则

    |H| = (|H_12|+|H_23|+|H_31|)/2 − π/8 + (1/4)∫(m′²−m²).

证明：逐角最小值、中位数和最大值的 Q 值之和等于三个原函数 Q 值之和。由等定宽，最大和最小函数的 Q 值之差仍为 ∫max_i h_i−π。对三项，∑_{i<j}|h_i−h_j|=2(max−min)；取积分并用对踵关系，∫max−π=∑∫|h_i−h_j|/4。代入两体公式即得 2|H|=∑|H_ij|−Q(M)。m 对踵反对称，故 ∫m=0，展开 Q(M) 得上述结果。

余项全域非负，由圆周 Wirtinger 不等式得出。若 m 的实 Fourier 系数为 a_k,b_k，仅奇阶可能非零；保留任意有限组 k≥3 的项便给出显式下界 π∑(k²−1)(a_k²+b_k²)/4。余项为零当且仅当中位支撑函数是某个平移单位直径圆盘的支撑函数。以三个平移圆盘作检查，此余项恰是三圆心三角形的面积（由外平行体面积公式）。因此对不共线平移，两体贡献之和确实遗漏一项正面积。

## 正定宽奇边形的全局平移罚项

令 D 为半径 1/2 的圆盘，B_n 为正定宽奇边形，顶点外接半径 R=1/(2cos a)，a=π/(2n)，n≥3。中心重合时 f=h_B−1/2 每个顶点法向扇上为 R cos θ−1/2，|θ|≤a，其余扇由对踵反对称给出。于是 ∫|f|=2n tan a−π。正 n 边形面积加 n 个单位圆弓的面积给出 |B_n|=nR²sin(2π/n)/2+(π−n sin(π/n))/2。由两体公式，中心重合时凸包面积为 π/8+n tan(a)/4。

对任意方向的平移向量 t，d=|t|，定义 L=tan(a)/2 和 B=max(L+d,d/a)。则对所有 d≥0，

    |conv(D,B_n+t)| ≥ π/8+n tan(a)/4 + n d²/(4B).

证明：t 在平移前后的支撑差中增加 v=t·u。n 重对称保证 ∫sign(f)v=0。共有 2n 个等距变号方向 θ_j，各自取 f 与 v(θ_j) 异号的一侧，长度取 |v(θ_j)|/B≤a。这些单侧区间内部互不交。因 |f′|≤L 且 |v′|≤d，距零点 s 处，f+v 在这段内保持 v(θ_j) 的弱符号，绝对值至少 |v(θ_j)|−Bs。于是 |f+v|−|f|−sign(f)v 在区间内的积分至少 |v(θ_j)|²/B，在其余处也非负。等距方向满足 ∑(t·u_j)²=n d²。乘两体公式的系数 1/4 即得。该界在 d 趋零时给出精确的二次主项系数 n/(2tan a)：逐个在简单零点用 f 的一阶展开，符号翻转区间的积分为 |v(θ_j)|²/L+o(d²)；零点有限且 |v′|≤d，余量对平移方向一致。

任意包含 D、B₃、B₅、B₇、B₉ 某组放置的凸体，均同时服从四个两体罚项以及每个三体子族的中位数界。要得到一般面积的匹配下界，仍需要对其余自由角度和多体余项给出统一控制。

## 任意有限体族

更一般地，令 s₁≤⋯≤s_N 为 N≥2 个支撑值在每个方向上的排序，μ_j 为 s_j 的整周均值，P 为全体凸包周长。令 E_j=πμ_j²−Q(s_j)。将 s_j 展开成 Fourier 级数可得 E_j≥0，其每个 k≥2 阶非负项为 π(k²−1)(a_{jk}²+b_{jk}²)/2。则有精确恒等式

    2|H| = ∑ᵢ |K_i| + P − π − π∑_{j=2}^{N−1} μ_j² + ∑_{j=2}^{N−1} E_j.

事实上，排序保持各 Q 值的总和，s₁ 与 s_N 的对踵互补性给出 Q(s_N)−Q(s₁)=P−π。将中间层的 Q 值代入即得。对五体和六体，该公式均可直接去掉未估计的 E_j 项，保留任意已控制的 Fourier 项；主要困难遂在于对放置变化同时估计各排序层的均值和选定系数。该恒等式不要求原集合的放置共轴、相交或可微。

# 新五点与十一点对五曲体精确极小值的影响

设 \(H_*\) 是第158轮五个曲体的唯一极小宿主，其面积为 \(M=0.837295006221025243456393253909267018677\pm5.09\times10^{-40}\)。令 \(P_{11}\) 为 "$COMP/two-host-witnesses/sparse/points.json" 的完整新十一点，\(P_5\) 为序号 0、2、5、7、9 的子集。把五个曲体分别增广 \(P_5\) 或 \(P_{11}\)，两类六输入的全域最小面积都恰等于 \(M\)。

证明只需构造一次放置。调用第158轮驻点模型，在已证包含精确驻点的整个双角隔离闭盒上，以 Arb 算出全部11个真实摆放参数的区间。将各下端向下、上端向上取整至 \(2^{-44}\)，得到 special-audit.json 的 star_grid_cover。每个正定宽曲体采用 五点管证明 中的共同内核构造，圆盘固定。将每段圆弧256等分，经取整和同步缩放得到对整个参数盒有效的有理内多边形。取正手性，先将所有新十一点旋转 4.692998241067 弧度，再平移 \((.000755287022,.003626387338)\)。全部点与内多边形的每条有向边均具有正的行列式，最小下端大于 \(6.77914\times10^{-7}\)。这些点因此位于真实极小宿主内部。增广问题包含旧五体，故其面积下界至少为 \(M\)；同一摆放已经达到 \(M\)。五体在达到等号时仍满足第158轮的唯一性结论。十一点的摆放具有严格内含余量，可在一个开邻域内变化。

此处结论仅涉及五个正定宽曲体加一个选定的新点集。凸万能覆盖还须包含其他直径一的输入；极小宿主 \(H_*\) 不能直接当作万能覆盖。

**预登记叶的七输入对照。** 在 180/24225-71-70-51 内的同一低面积五体姿态，将完整新十一点按 五点管证明 中五点同一姿态放置。有向边最小行列式大于 \(3.29526\times10^{-8}\)，于是五曲体与新十一点仍有联合面积 <.837458260623。进一步放入原 P30，在此固定五曲体姿态下，不论 P30 如何独立平移、转动或反射，536个角格的弦面积证明都给出严格下界 .8378。另一方面让 P30 取正手性，旋转 2.072535035761 弧度后平移 \((.009584006714,-.018933413589)\)，并保持上述新十一点姿态。五个曲体和两组点的真实联合面积严格小于 .839056002671。新增十一点已经在五曲体凸包内，故它们不会增加该具体七输入摆放的面积。这里的 .8378 下界仅对这个固定五体宿主及自由摆放的 P30 成立。

以下从 computation/five-point-tube 目录运行，COMP 为整个课题 computation 目录的绝对路径。

```sh
python -I -B verify_special.py "$COMP" "$COMP/two-host-witnesses/sparse/points.json" special-input.json special-replay.json
python -I -B verify_old_p30.py "$COMP" special-input.json p30a.json old-p30-replay.json
```

允许五曲体也重摆后，另有更小的七输入可行上界。取 joint-pose.json 的17个参数，前11个曲体坐标取最近的 \(2^{-44}\) 格点；原 P30 取正手，新十一点取反手，各自按其后三项参数旋转、平移。每个圆弧4096等分，对五曲体与41个点同时作有理外平行体核验。这一显式共同摆放的面积严格小于 **.837719727007**。此数是七输入自由摆放极小值的上端，两点组按同一宿主真实并存。固定旧低宿主所得的 .8378 下界不约束这一自由摆放。复算命令为

```sh
python -I -B verify_joint.py "$COMP" "$COMP/two-host-witnesses/sparse/points.json" joint-pose.json joint-replay.json
```

# 五体高门槛的四个平移圆盘

圆盘 $D$ 的半径为 $1/2$，中心固定在原点。若 $D$ 与 $B_3,B_5,B_7,B_9$ 的某一放置的凸包面积不超过 $T=0.837295006222$，则四个平移向量必须满足

| 正定宽体 | 平移长度的严格上界 |
|---|---:|
| $B_3$ | $0.0685$ |
| $B_5$ | $0.06675$ |
| $B_7$ | $0.0603$ |
| $B_9$ | $0.05725$ |

**把无界域缩为圆周。** 对固定 $n$，令 $f(t)=|\operatorname{conv}(D\cup(B_n+t))|$。在任意平移直线 $t=t_0+su$ 上，沿 $u$ 方向取截面。凸包中点可写成 $(1-\lambda)d+\lambda(b+t_0+su)$。给定垂直于 $u$ 的投影坐标后，允许的 $d,b,\lambda$ 与 $s$ 无关，允许截面的投影范围也与 $s$ 无关。截面的上端是 $s$ 的一族仿射函数的上确界，下端是同一族的下确界，截面长度因而关于 $s$ 凸。逐截面积分即得 $f$ 的凸性。将 $t$ 绕原点旋转 $2k\pi/n$ 得到的向量平均为零，$f$ 在这些向量上取相同值。于是 $f(0)\le f(t)$，$f$ 在从原点出发的各射线上单调不减。不等式 $f(t)>T$ 只要在一条完整圆周上成立，就覆盖该圆周外侧。$B_n$ 的任意转角可吸收到平移方向；由反射及 $n$ 重旋转，对平移方向只需覆盖 $[0,\pi/n]$。

**有理内扇与角度误差。** 对表中半径 $s$，将该角区间等分为 $N=2048$ 片。每片中点处的平移分量用分母 $Q=2^{28}$ 的有理数逼近，逐分量用 Arb 核验误差小于 $1/Q$。任一实际方向与所在片的取整中点平移相差至多
$$
\delta=s\pi/(2nN)+2/Q.
$$
对 $D$ 的96个整数材料点核验半径，对 $B_n$ 的 $32n$ 个点核验它们到该体每个定义单位圆盘的圆心的距离。SciPy 提供内扇的候选顶点顺序。整数行列式逐边严格为正，正向越过横轴的次数恰为一，所以所得内扇各三角形内部互不相交，其并位于取整平移对应的凸包内。所有网格中的最小两倍格面积分子 $m$ 保存在回执。

对实际方向，设两体凸包为 $K$。取整中点的内扇包含于外平行体 $K+\delta D_1$，其中 $D_1$ 为单位圆盘。因 $B_n$ 的外接圆半径为 $R_n=1/(2\cos(\pi/(2n)))$，$K$ 位于半径 $R_n+s$ 的同心圆盘内。周长单调性与外平行体面积公式给出
$$
 |K|\ge m/(2Q^2)-2\pi(R_n+s)\delta-\pi\delta^2.
$$
四个严格下端依次超过 $0.83732817,0.83749884,0.83753718,0.83754861$，均超过 $T$。任何五体凸包都包含对应的两体凸包，因此四个圆盘限制同时成立。

**来源与复算。** `five-body-radial-material.npz` 保存整数分母 $2^{28}$ 下的零角材料坐标，取自五体 32 级表（SHA-256 `fe5b816060d713642dc44e3f8981f4ae5d1b2b1c1e271b7dff75f031dd75d87c`）。独立入口直接核验这些整数的材料包含性，因而原数据来源仅用于可追溯性。实际采用 Python 3.13.18、python-flint 0.9.0、SciPy 1.18.1 和 160 位 Arb。在 computation 目录运行

```sh
OPENBLAS_NUM_THREADS=1 python -B certify_five_body_radial_limits.py
```

所得 `five-body-radial-limits.json` 收录每个圆周的面积下端以及取整与离散误差界。

## 整格仿射面积的改进

取较小的四个半径 0.06835、0.06650、0.06004、0.05699，仍使用每体 2048 个角格。在某角格的取整中点处，记候选扇的有序顶点为整数向量 v_i，标签 m_i 为零或一，表示顶点属于固定盘或移动体。格中实际平移相对取整中点的修正 d 以格点为单位，每个坐标均有绝对值上界 e。于是每条边对两倍格面积的贡献恰为

    det(v_i,v_j) + det(d, m_i v_j − m_j v_i).

脚本对每一条边的线性式分别取下界，核验在整个修正盒内都严格为正。中点内扇绕原点一次。沿修正盒内的线段连续移动，任何边都不能经过原点，故绕数保持为一，相邻辐角之差均介于零与 π 之间。各三角形的内部因此始终互不相交。随后先把全部边的仿射式相加，再对总线性项作坐标绝对值估计，即得整个参数格的面积下界。每个顶点依然属于对应的实际测试体，原点属于固定盘，故内扇面积为真实凸包面积的下界。最后使用前述射线单调性处理各圆周外侧。

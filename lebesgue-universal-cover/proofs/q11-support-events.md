# 固定十一点权重的边法向事件与两枚原叶复验

对第166轮的实际十一点 \(Q_{11}\)，按原中心内多边形、原权重、原联帽预算和两手性重新检查全部 **1,098 个闭角区间**。这些旧窄格都没有内部对齐事件。每个冻结材料点都在区间中点严格实现对应方向的支撑，因此整个窄格的支撑和确为原证中的同一个正弦式。事件精算和原公式给出的每格最小值一致。

首行是面积靶 \(0.83755\) 的第155轮锚、正手、原角圈数 \([0,1/64]\)。两端支撑和分别为 \(0.05627955824111118379\ldots\) 与 \(0.05638489979047159853\ldots\)。扣掉原联帽上端后，严格余量为 \(0.00011577444288856917598\ldots\)。MacBook 独立核对所得下端相同。

## 事件计算

对反射后的点集先取整数凸包。设 \(m\) 为其中一条边的外法向，\(n\) 为某正权宿主法向。两向对齐的旋转可用非零整数对
\[
 (c,s)=(m\cdot n,\det(m,n))
\]
表示，真正的余弦和正弦为 \((c,s)/\sqrt{c^2+s^2}\)。同向的重复整数对用正公因数归一化并去重。对长度至多半圈的闭角区间，两条有向半平面检验决定哪些旋转落入区间。仅在 Arb 严格排除某一包含不等式时才略去该事件。于是数值临界的边界仍计入支撑下端。

在一个事件方向上，对每个 \(n\) 逐点用整数计算未归一化的转动投影，取最大值并取有理加权和，最后除以 \(\sqrt{c^2+s^2}\) 与公共坐标分母。闭区间两端用 Arb 三角函数。相邻事件之间，\(h_{R_\theta Q_{11}}(n)\) 的支持顶点固定。平衡权消去平移后，支撑和非负且满足 \(S''=-S\)，所以每段最小值在端点。这个论证逐个固定权重行使用。

将上述首行原权重另在半圈 \([0,1/2]\) 上作回归检验，正手和反手各有15个内部事件。两支最小值都严格低于各自两个半圈端点，面积余量分别约为 \(-0.001232311592018\) 与 \(-0.001232311585289\)。这是一个实际发生内部切换的冻结行，也检验了区间过宽时判据确实会拒绝。

## 复算

COMP 指向公开计算目录，WORK 与 CACHE 分别为独立临时目录和 Clang 缓存。原树及64级材料表沿用第175轮。

    python -B computation/certify_q11_support_events.py COMP > r166.json
    python -B computation/certify_q11_support_events.py COMP --one
    python -B computation/compress_q11_event_banks.py COMP \
      COMP/mixed-point-cap-bank-083745.json WORK/cap.json
    python -B computation/compress_q11_event_banks.py COMP \
      COMP/mixed-point-only-bank-083745.json WORK/mixed.json
    python -B computation/replay_mixed_point_leaf.py COMP TREE TABLE64 WORK/cap-run CACHE \
      --target .83745 --cases 1205/140208 1205/140080 --budget 200000 --modes 3 \
      --reuse 1205/140208 --cert WORK/cap.json
    python -B computation/replay_mixed_point_leaf.py COMP TREE TABLE64 WORK/mixed-run CACHE \
      --target .83745 --cases 1205/140208 --budget 233280 --modes 2 --cert WORK/mixed.json

第166轮完整事件表在两个本机 Python 环境逐字节重放，Arb 精度160位。第175轮角段压缩用固定权重行和有理角端点，不使用优化器。全盒重放按整数检查子盒是否完全落入中心的已证范围。

# 有理角 1.5497° 时 AH 与 EH 两个新增裁帽

固定 Gibbs 角 \(\sigma=1.5497^\circ\)。EH 沿用第98轮的两个相邻六边形姿态。将旧端点 \(U\) 沿 \(C_3\) 圆弧顺时针旋转 \(0.00036\) 弧度得到 \(U_1\)，另一端 \(T_{\rm EH}\) 保持原值。AH 沿用第96轮的裁线方式，将朝向 \(T_a\to Z\) 的直线绕
\[
  W=Z+0.38(T_a-Z)
\]
逆时针旋转 \(0.00033\) 弧度。沿两个有向裁弦各取左侧。所获闭凸体为万能覆盖，且
\[
 \Lambda<0.844093478256858252.
\]

## AH 局部误差与两个相容根

记 \(D=T_a-Z\)、\(b=-D/|D|\)、\(n=Jb\)。AH 新裁线的另一交点位于配对曲线 \(q([0,0.05])\) 内。与第96轮类似，任何新帽点可写作 \(x=Z+wD+\eta n\)，其中 \(-0.052\le w\le0.38\)，并且
\[
 0\le\eta\le |D|\tan(0.00033)(0.38-w).
\]
把此 \(w\) 区间划成长度 \(1/1000\) 的闭格。对每格各自核验右端界 \(h_i\)、AH 坐标图内含性及 \(x_y>0.518\)、\(|x-C|>1\)。后两个符号保证新增帽保留第24、33轮的三个触发条件，即命中 \(C'\)、避开 \(D'\) 和避开 \(F'\)。

用第96轮的坐标图 \(X(\ell,t)\)、旧边界 \(t=g(\ell)\) 和配对 \(\psi\)。对于帽点所在的第 \(i\) 格，沿固定 \(\ell\) 的线段从 \(t\) 到 \(g(\ell)\) 包围 \(-n\cdot X_t\)，得到严格正下端 \(m_i\)。原旧边界在直线 \(T_aZ\) 的保留侧，所以
\[
 g(\ell)-t\le h_i/m_i.
\]
把旧直段基点 \(Z+vD\) 的 \(v\in[0,0.41]\) 划成长度 \(1/100\) 的闭格。任一实际命中点对应的旧基点是 \((\ell,g(\ell))\) 与其配对中落在直段上的那个。算法逐格比较 \(\ell\)、\(\psi(\ell)\) 的非正可能值与各旧基点格的 \(\ell\) 范围。对于每个相交的旧基点格，将该帽点格的 \(h_i/m_i\) 纳入其亏损上界 \(E_j\)。每个 \(E_j\) 取所有命中格上端的最大值。这在离所选铰点近的旧基点格得到较小误差。例如第34格 \(v\in[0.34,0.35]\) 的亏损上界小于 \(0.000042\)，而全帽最大值小于 \(0.000236\)。

若 \(K,Q_AK\subset P\) 双双命中新 AH，至少有一个所选命中点落在新增帽。若恰有一个选点在新增帽，取其为首点，另一点的亏损上界为零。若两个都在新增帽，取对应 \(E_j\) 较大的那个为首点。这样，首点的 \(E_j\) 对两个命中点都适用。证书统一核验首点的参数及其配对参数到图区间边界的距离都超过 \(2(0.000236)/3 \ge 2E_j/3\)，因此可以把这个共同误差送入第96轮的单调性估计。

此时第96轮的双命中不等式给五个实际锚点的误差上界
\[
 0.7E_j,\quad (2/3)E_j,\quad
 \bigl((2/3)\cdot0.23+0.65\bigr)E_j,\quad E_j,\quad 0.65E_j.
\]
其中两个正向图的偏导范数在相关管内小于 \(0.23,0.65\)，第四个为 DE 接触点。全部误差均至多 \(E_j\)。保留相邻单位边点积大于 \(3/4\) 的十扇区，因而全向支撑误差至多 \(1.07E_j\)，相容函数及中心化后任一单位方向的支撑比较误差至多 \(3.21E_j\)。

在覆盖范围内按旧基点格选两个根分支。在 \(v<0.34\) 的格中使用 \(300^\circ-\phi\) 的旋转及相容函数从正到负的过零。在后续可能有实际首点的格中，用 \(-\phi\) 的旋转及从负到正的过零。两类根的括区都由脚本给出有理中心，半宽按格取 \(1.4^\circ,1^\circ,0.8^\circ\) 或 \(1.1^\circ\)。1340 个参数闭格验证根的两端严格余量，最小值超过 \(0.0000808818\)。每格再对完整括区的 100 个角闭格核验摆放，扣除支撑误差后的最小余量超过 \(0.0002064112\)。正斜帽线、旧内弦和新 AH 线均直接检查，EH 弦也使用同一新深度的 \(U_1T_{\rm EH}\) 直接检查。五条 Sprague 真弧由强制接触补齐，并在同一斜角和切深重核端点 Voronoi 符号。

## 复合体的全部摆放

先按第98轮的完整 EH 构造摆放任意定宽一体。原始五种离散分支依赖的三条 EH 触发仍由深度 \(0.00036\) 的证书给出。具体地，命中 EH 内部迫使原体避开 \([F_3,R]\)、命中 \(F'\)、避开闭 \(C'\) 和闭 \(B'\)。\(Q_1\) 像缺 \(C'\) 并触及 \([F_3,R]\)，\(Q_3\) 像命中 \(D'\) 并避开 \(F'\)。\(Q_2\) 像缺 \(C'\)，若仍进 EH，则由两姿态共用的相容根覆盖。两姿态为 \(240^\circ-\phi\) 和 \(300^\circ-\phi\)，第二姿态在第一姿态超出 \(m_5\) 时自动通过 \(m_3\)。

已直接重放两个姿态对旧 AH 直线 \(T_aZ\) 的对偶。其严格余量分别超过 \(0.00763306202491\)、\(0.00111912574365\)，都超过新裁线支撑比较的最大变化 \(2(0.00033)=0.00066\)。第98轮给出的摆放均可通过以下统一步骤处理新帽。若该摆放进入新 AH，则使用 \(Q_A\) 重新回到 \(P\)。因原摆放缺正 \(C\) 帽，反射像缺 \(F'\)，所以仍避新 EH。若反射像也进入新 AH，用上一节的双命中摆放。这样得到经过同一刚体运动的整副本；平面内部的分类、闭包和第26轮的定宽补全给出全部覆盖。

## 面积与复现

两新帽分别在 \(y>0.518\) 和 \(y<s_y<0\) 的区域，二者面积可相加。EH 使用第98轮 Green 公式的严格下端。AH 使用第96轮的内三角形构造，铰点和另一截点证实在新增帽相应位置。其有理严格下端为 \(0.00000003533334077570666\)。从第98轮 EH 体的有理面积上端扣除即得文首界。

在 `computation` 中使用 Python 3.13.18、python-flint 0.9.0 和 NumPy 2.5.5。

```sh
python -B certify_eh_cap_switch.py 1.5497 0.00036 33 "$OUT" \
  --old-area eh-joint-1p5497-old-area.json --replay eh-cap-switch-360.json
python -B certify_ah_eh_combined.py --combined
```

前一行重放 EH 两姿态的 51 份对偶。后一行生成 `ah-eh-combined-360.json` 的全部 AH 数值、组合面积及两条 \(T_aZ\) 对偶余量。

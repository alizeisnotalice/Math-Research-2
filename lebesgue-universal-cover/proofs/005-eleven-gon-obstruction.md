# 第5轮：正十一边形排除固定五体覆盖

令H与ε为第4轮证书定义的有理凸包和有理膨胀半径，C=H+εB。
令R=1/(2cos(π/22))，P11=conv{R u(2πk/11):k=0,…,10}。
最大顶点距离为2R cos(π/22)=1，凸包不增直径，故P11是合法测试形状。

本轮严格证得：不存在欧氏等距g使g(P11)⊂C。因此这个具体C不是万能覆盖。
它不是对所有五体最优放置的排除；尤其不推出m(F5∪{P11})>m(F5)，不提高Λ的下界。

## 1. 半平面外放松

对整数向量q，令
 b(q)=max_{v∈Vert(H)}q·v+ε(|q_x|+|q_y|)。
因为||q||₂≤||q||₁，C中所有x满足q·x≤b(q)。这是向外放松；在放松中已不可行
即可推出在C中不可行。源码将边法向近似为整数向量，但近似方向不需要认证：
b(q)针对实际整数向量重新精确计算，因此任何非零q都给合法半平面。

## 2. 全旋转参数覆盖与反射

P11具有周期2π/11的旋转对称性，且关于x轴镜像不变，故任一反射副本也是一个旋转副本。
只需处理长度2π/11的旋转基本区间。取M=180，中心θ_j=2πj/(11M)，半宽d=π/(11M)，
闭区间I_j=[θ_j−d,θ_j+d]（j=0,…,M−1）覆盖一个完整基本周期。
跨越零点的负角无须截断；由周期性覆盖剩余末端。

## 3. 精确平移排除证书

每个I_j选择三个整数法向q_i、非负有理权重λ_i与三个顶点索引k_i，满足
 Σλ_i=1，Σλ_iq_i=0。
权重来自三法向叉积，最后重新以Fraction核验等式，不相信优化器的浮点对偶值。
若存在t使Rotθ(P11)+t⊂C，则对所有i有
 q_i·t ≤ b(q_i)−q_i·[R u(θ+2πk_i/11)]。

用有理三角区间求各点积在整个I_j上的下界l_i。加权后必要条件为
 0 ≤ Σλ_i(b(q_i)−l_i)。
证书对每个区间严格验证右侧为负，因此排除该区间所有θ及全部t。
顶点k_i无须在整个区间始终成为支撑点：包含P11必然包含任何被选顶点，这已足够。

π的Machin夹逼、Taylor余项及角区间传播沿用已经审查的rational_trig.py；所有最终
判断采用Fraction。浮点LP只建议选哪些约束和顶点，不承担严格结论。
全部180格归一化最差上界约−0.0021919146593824845，小数仅展示；JSON保存确切有理值。

## 4. 独立复核与适用范围

certify_obstruction.py使用NumPy/SciPy选择稀疏见证，再精确认证。
verify_obstruction.py仅需标准库：重算每条b(q)、权重非负与平衡、全部角区间的点积
下界及严格负性；核对完整180格、原第4轮证书哈希，不调用优化器。

新增测试形状是正十一边形本身，无需依赖Reuleaux十一边形的补全或边界定理。
本轮未遍历六体所有相对放置，故不声称取得六体最优值或一般下界改进。

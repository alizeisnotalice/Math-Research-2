# 低面积五体宿主到唯一极小轮廓的定量距离

设 H 为任一紧凸宿主，它能容纳圆盘和正胡勒三、五、七、九边形的各一个副本，各体直径为一。设 M 为五体共同凸包的精确最小面积，K* 为唯一规范极小轮廓。若 |H|≤U=0.83729500622102525，写 e=|H|−M，则存在同一个整体等距变换 g，使得

    d_H(gH,K*) ≤ 5.381635 √e + 59880.24 e.

在上述全部面积范围，亦有较强的单项估计

    d_H(gH,K*) ≤ 5.381635 √e < 0.00000001376648.

因此一个固定轮廓即可控制所有这些宿主。若 e=0，则归一化后的宿主正好等于 K*。

## 从切线角到五体凸包

任选 H 中一组五体副本，记 K 为其凸包。用一次整体等距变换同时规范化 H 与 K。由于 |K|≤|H|≤U，四层五体全域覆盖及其第四层的一节点替代证明，这组放置的规范代表必属于原局部盆地。令 η=(α−α*,β−β*)，ξ 表示相对于同一 t₃ 所确定接触锚的九个原坐标差。有

    |K|−M ≥ 0.05 ‖η‖₂² + 0.0000167 ‖ξ‖₁.

记 tₙ(α,β)、θₙ(α,β) 为解析接触图上的位姿。对正胡勒 n 边形，支撑函数对转角的 Lipschitz 常数至多为 ℓₙ=tan(π/(2n))/2。因此同一刚体在两个位姿之间的 Hausdorff 距离至多为平移差长度加 ℓₙ 倍转角差的绝对值。B₃ 方向固定。对各体取最大即可控制所有副本的凸包距离，因为凸包的支撑值是各体支撑值的最大值。

在整个旧角域上检验雅可比的组合范数

    Lₙ = sup [‖D tₙ‖₂→₂ + ℓₙ ‖D θₙ‖₂].

计算使用原九次双变量 Taylor 模型，把闭角域各轴均分为 12 段。归一化复双圆盘内的解析余项上界为 E，在实格 (x,y) 上一阶导数余项至多 E/(1−max(|x|,|y|))，转回角坐标时除以尺度 0.000006。对平移的 2×2 雅可比，按其 Gram 矩阵的二次特征方程直接求谱范数上界。所得 L₃<0.398044，L₅<0.242965，L₇<1.182659，L₉<0.120382。共同上界的实际向上有向值为 L≤1.182658764779。

沿两个法向角之间的线段积分，并分别估计九个横向位置偏差。因所有可动方向的 ℓₙ<1，单体的横向平移长度与转角误差之和均至多 ‖ξ‖₁。于是

    d_H(gK,K*) ≤ L ‖η‖₂ + ‖ξ‖₁.

## 从凸包到宿主

规范后的 H 和 K 都包含以原点为圆心、半径 r=1/2 的圆盘。圆盘与一个距原点 R=0.703 的点的凸包面积严格超过 0.8376009054，因而超过 U。故 H 包含在原点的半径 R 球中。记 δ=|H|−|K|。对 H 相对 K 的最大支撑超出量取实现法向，连接相应支撑点与圆盘在该法向投影 r²/x 处的垂直弦。超出 K 支撑线的三角形面积为 r d_H(H,K)²/√(x²−r²)。由 x<R 得

    d_H(H,K) ≤ (4R²−1)^(1/4) √δ.

令 z=‖ξ‖₁，β=0.0000167，c=(4R²−1)^(1/4)。面积收支给出 δ+0.05‖η‖₂²≤e−βz。由三角不等式和 Cauchy–Schwarz 不等式，

    d_H(gH,K*) ≤ C √(e−βz) + z,
    C = sqrt(c² + L²/0.05) < 5.381635.

用 z≤e/β 即得到所述平方根加一次项的估计。根据驻点面积球，U−M<6.5436067461·10⁻¹⁸，故 2√e<5.381635 β。在 0≤z≤e/β 上，5.381635√(e−βz)+z 关于 z 单调下降，所以最大值在零处。最终取向上舍入的数字得到单项估计。在 U 处，直接使用两项式也给出严格上界 1.376687·10⁻⁸。

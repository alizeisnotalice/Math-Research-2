# 五体低面积候选的谐波排除和十一维剪枝

取圆盘 \(D\) 和正 Reuleaux 多边形 \(B_3,B_5,B_7,B_9\)。冻结 Tomar v9 公开候选 opt11_point.json 的十一项十进制精确值，作为五体放置中心 \(p_*\)。圆盘固定原点，\(B_3\) 方向固定，参数按 \(B_3\) 的两个平移坐标，再按 \(B_5,B_7,B_9\) 各自的弧度角及平移坐标排列。该公开候选给出低面积的可行位置，本轮不假设它全局最优。输入记录其源哈希。

新增体选支撑函数
\[
 h(\theta)=\tfrac12+\tfrac{1}{100}\cos(3\theta)-\tfrac{41}{2400}\cos(5\theta).
\]
有 \(h+h''\ge1/100\)，故 \(p=h u+h'Ju\) 确定光滑严格凸边界且 \(h\) 为支撑函数。两谐波均为奇次，故宽度恒为一。\(h\) 为偶函数，反射放置可吸收到旋转。该体包含 \(0.47B\)，支持角 Lipschitz 常数为 \(277/2400\)，其中 \(B\) 是闭单位圆盘。

## 移动五体的共同内多边形

在盒中心，以第55轮的 Arb 采样将每个旋转后的本体单独近似成有理多边形，支撑误差至多 \(2/10^{12}\)。对于第 \(i\) 体，若两个平移坐标的半宽为 \(h_x,h_y\)，旋转半宽为 \(h_\rho\)，取误差预算
\[
 e_i=\operatorname{up}\sqrt{h_x^2+h_y^2}
      +L_i h_\rho+4/10^{12}.
\]
第一项用整数平方根向上取整。\(L_i\) 为支撑函数关于角度的上 Lipschitz 常数，来自 \(B_i\) 两段支撑分支的最大斜率 \(\tfrac12\tan(\pi/(2i))\)。圆盘不移动。四个 Reuleaux 体的本体内圆盘半径下端取 \(0.42,0.47,0.48,0.49\)，记为 \(r_i\)。

将旋转后的采样多边形先绕本体原点缩放 \(1-e_i/r_i\)，再平移至盒中心位置并取整。对任一盒内真体、任一单位法向，缩放损失至少 \(e_i\)，足以吸收角差、平移差及两次取整。于是采样多边形在整盒内始终成立。四个缩放多边形与盘内点的凸包 \(P\) 是五体真实凸包的共同内材料。这逐体消化误差，不需把整个宿主绕盘心同倍率缩进。

## 任意转角和平移下的严格下端

对整圈转角比例的一个区间 \([a,b]\)，在角格中点转动新增体材料。两次取整误差加全格支撑误差至多
\[
 c=4/10^{12}+(277/2400)(22/7)(b-a).
\]
将材料缩放 \(0.47/(0.47+c)\)，得到各真转角都包含的 \(Q\)。固定 \(P,Q\)，凸包面积 \(A(t)=|\operatorname{conv}(P\cup (Q+t))|\) 随平移凸。沿平移直线作垂直截面，固定截面内的许可凸组合参数不随平移而变，左右端点为仿射族的下确界与上确界，长度为凸函数，积分即得。

任取一个有理平移点 \(t_0\)，整数凸包得到严格凸的顶点循环，保留各点来自 \(P\) 或 \(Q+t_0\) 的标签。充分小的平移仍保持这个所选子多边形的严格凸性。其鞋带面积关于平移为仿射，在 \(t_0\) 正好接触 \(A\)，故由凸性给出全局下界。角格证书保留若干平移点和非负权重。权重归一后，加权仿射式在平移方框 \([-1/4,1/4]^2\) 的最小值直接由两个斜率的绝对值给出。方框外存在新体内圆盘一点距原点超过 \(0.72\)，与 \(D\) 的凸包已超过所有报出门槛。

| 旧十一维中心周围统一半宽 | 全角格数 | 新六体面积严格下端 |
| ---: | ---: | ---: |
| \(0\) | 163 | \(0.83880001906\) |
| \(1/4096\) | 92 | \(0.83770134770\) |
| \(1/1536\) | 101 | \(0.83670095336\) |

对原固定位置，五体面积 \(<0.837295153\)，同位置增加一个明确副本可得六体面积 \(<0.838851260\)，而任意加入副本的面积增加 \(>0.0015048667\)。若重新调整所有位置，归档的 14 项精确参数给六体面积 \(<0.837677741\)。所以半宽 \(1/4096\) 的闭盒与自由六体全局极值严格分离，下端比该可行上端大 \(0.0000236068\) 以上。自由六体最优值和一般万能覆盖最小面积仍待确定。

## 对原十一维树直接剪枝

以原始弧度坐标和原二分算法，从冻结证书的 uint8 预序档逐节点恢复盒。两种非零半宽的排除盒分别与 4 和 42 个原叶有正体积交集。后者涉及分片 176–183。每个原叶和已排除子盒相交时，按坐标顺序剥去低侧和高侧余板，每个坐标最多留下两块。核验器精确比较原叶体积与交盒及余板的体积之和，再验证全部原叶被剪体积的总和等于排除盒体积。这里仅剪去原叶的已证交盒。中心所在原叶为分片 180、预序位置 23955。对两种盒，从该原叶继续 53 次或 36 次二等分，取得完全包含在排除盒内的原格式子盒。

## 独立复现及公开依赖

所有几何和有理比较仅需 Python 标准库与 python-flint。生成阶段的数值优化记录没有纳入核验。建议在仓库根目录执行：

    python3 -B lebesgue-universal-cover/computation/certify_five_harmonic.py --check

若也重放十一维树的叶绑定，用环境变量 TOMAR_CERT 指向解压后的原 cert11d_08366 目录，再执行：

    python3 -B lebesgue-universal-cover/computation/certify_five_harmonic.py --tree "$TOMAR_CERT" --check

原树来自 Tomar v9 的公开补充材料，标识符 DOI 10.5281/zenodo.23717912。使用 cert11d_08366.tar.xz，其 SHA-256 为 6b5d28bc488edcfde9c6a49f3cb364f9086f445a58f85f166da23727036cf122。重放只读取有关分片的头和预序文件，逐分片的实际哈希见结果簿。主要证明计算并不需要原树，原树只承担几何分片绑定。第55轮的 certify_nine.py 为既有共享依赖。冻结的 v9 版本来源见输入文档。 [公开补充材料](https://doi.org/10.5281/zenodo.23717912) · [v9 源码](https://github.com/tejasvi/lebesgue-cover-bound/tree/v9)

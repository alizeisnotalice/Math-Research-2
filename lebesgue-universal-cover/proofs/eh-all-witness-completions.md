# EH 十二点的全部定宽补全可以连续摆放

固定第47轮斜角，令 \(X\) 为按切深 \(0.0000155\) 构造的十二点双命中见证。令 \(H_\delta\) 为第47轮候选体经 EH 新弦截取的凸体。每个包含 \(X\) 的定宽一凸体都可以经某个刚体运动进入 \(H_{0.0000155}\)、\(H_{0.005}\) 和 \(H_{0.007}\)。以下给出对整个补全族统一适用的角区间，每个补全的具体角与平移由其自身支撑函数决定。

## 圆盘交夹逼与相容角

令 \(L=\bigcap_{x\in X}\overline B(x,1)\)。若 \(K\) 是上述补全，则 \(K\subset L\)。以角度作支撑函数自变量，宽度一给出

\[
1-h_L(\alpha+\pi)\le h_K(\alpha)\le h_L(\alpha).
\]

令 \(F_K(\phi)=h_K(\phi)-h_K(\phi+\pi/3)+h_K(\phi+2\pi/3)-1/2\)。160 位 Arb 核实，对全部补全，有

\[
F_K(1.44^\circ)<-6.82774\times10^{-7},\qquad
F_K(1.47^\circ)>4.32522\times10^{-7}.
\]

由连续性可以取零点 \(\phi\in[1.44^\circ,1.47^\circ]\)。设 \(\theta=\pi/3-\phi\)，\(v_j=R_{-\theta}n_j\)。宽度一给出 \(F_K(\phi-\pi/3)=-F_K(\phi)=0\)，故旋转后在三条六边形固定方向上的支撑满足平移相容式。令 \(a_j=1/2-h_K(v_j)\) 并取

\[
t=\big(a_0,(2a_1-a_0)/\sqrt3\big).
\]

由 \(n_0-n_1+n_2=0\) 及定宽性，\(R_\theta K+t\) 在全部六条固定六边形边上的支撑恰为 \(1/2\)。

对候选体的圆弧和 AH 配对曲线分别取八等分参数点，连成内多边形。其余直边原样保留。对非六边形边的单位法向 \(n=d_0n_0+d_1n_1\)，所需支撑正是 \(h_K(R_{-\theta}n)+d_0a_0+d_1a_1\)。在整个根区间的闭格上，用上面的夹逼和带号系数给出严格上界。三种切深分别得到最小余量大于 \(4.34583\times10^{-5}\)、\(1.40846\times10^{-5}\) 和 \(1.83037\times10^{-7}\)，所以每个补全的上述运动进入内多边形。计算对第三个切深使用 2048 格，对前两个参数 256 格已足够。

计算 \(h_L\) 上界时，只须考虑每一对圆的两个交点，以及各圆沿计算方向的支撑点。若一个点严格在另一圆盘外便剔除，未决点保留。原因是极值点或者位于单一圆的光滑弧内部，或者为两个活跃边界圆的交点。带 Arb 包络的方向仍逐点是单位向量，所以单圆支撑公式沿整个区间有效。

这一论证也覆盖满足 \(\operatorname{dist}(x,K)\le\epsilon\) 对每个 \(x\in X\) 成立的定宽一凸体。误差形式为 \(K\subset L_\epsilon=\bigcap_{x\in X}\overline B(x,1+\epsilon)\)。利用 \(|x|<3/5\)，乘 \(\alpha=(2/5)/(2/5+\epsilon)\) 的中心同缩把 \(L_\epsilon\) 送入 \(L\)。六个固定方向各有一对侧边见证，所以 \(L\) 已在原六边形内，\(|y|<3/5\) 对 \(y\in L\) 成立。每条支撑夹逼的误差于是至多 \(3\epsilon/2\)。这使相容函数端点的符号余量减少至多 \(9\epsilon/2\)，使每条非六边形边的余量减少至多 \(15\epsilon/2\)，因为 \(1+|d_0|+|d_1|<5\)。对前两种切深取 \(\epsilon=8\times10^{-8}\)，对第三种取 \(\epsilon=2\times10^{-8}\)，两类严格余量均保持为正。

## 整个外包无法用同一运动放入

\(L\) 恰是所有包含 \(X\) 的定宽一凸体的并。包含关系由单位直径给出。反过来，任取 \(y\in L\)，集合 \(X\cup\{y\}\) 的直径仍为一，可定宽补全。因而 \(L\) 每个方向的宽度至少一。\(L\) 严格凸，故两侧支撑点唯一。宽度为一的方向是角度宽度函数的最小点。由支撑函数的角导数等于唯一支撑点的切向坐标，两侧点之差沿该单位法向，且恰等于该法向。

若该方向和其反向分别在两侧点的顶点法锥内部，小转角将保持两支撑点固定，宽度变成余弦而小于一。所以有一侧支持法向等于某活跃圆的径向。若该侧支撑点是 \(p\)、外法向为 \(u\)，则另一侧点是 \(p-u\)，也就是该活跃圆的圆心，属于 \(X\)。因此所有宽一方向只能落在 \(X\) 中某原点的法锥或其反向。法锥由活跃单位圆的径向生成，活跃关系就是七个精确的单位距离点对。严格约束在点的小邻域内不影响法锥。其余所有点对的距离严格小于一。

模 \(180^\circ\)，证书核验这些法锥均避开开角段 \((0^\circ,60^\circ)\)。具体而言，\(b,w,b-n_0,w+m_5\) 处的法锥都来自第四象限径向及其反向，允许水平轴。相应反射的法锥来自 \([60^\circ,90^\circ]\) 径向及其反向。\(q,-q\) 的法锥同属模 \(180^\circ\) 的 \(120^\circ\) 单方向。\(z,Q_2z\) 无活跃圆，没有非零支持方向。

如果 \(L\) 能进入原正六边形，必须在三条相差 \(60^\circ\) 的方向同时取宽一。这三方向中恰有一个模 \(180^\circ\) 落在 \([0^\circ,60^\circ)\)。因此该方向只能是 \(0^\circ\)，转角只能是 \(60^\circ\) 的整数倍。\(L\) 已在原六边形的六个方向都触边，所以这些取向在原六边形中只允许零平移。由于 \(X\) 关于 \(Q_2\) 对称，反射可化成旋转。前一结果排除 \(X\) 的全部六边形固定对称摆放进入 \(H_{0.0000155}\)，便也排除了 \(L\) 的全部连续摆放。这解释了为何要用定宽夹逼逐体选择相容根。

## 复现

Python 3.13.18 和 python-flint 0.9.0 实际重算退出零。计算脚本复用 `audit_eh_continuous_placement.py` 的内多边形构造。从课题目录运行

```sh
python -B computation/certify_eh_all_completions.py computation/067-witness.json OUTPUT.json 0.0000155 0.005 0.007 --num-cells 2048
```

输出见 `computation/075-completions.json`。结论限于含该见证或在给定误差内逼近它的定宽一凸体。

# 同一组三十点与五个曲体的全域面积严格超过 0.83735

前五个测试体是半径 $1/2$ 的圆盘及 $n=3,5,7,9$ 的正定宽奇边形。第六个测试体是 finite-point-leaf-input.json 给定的三十个有理点。六体各自独立作任意平面刚体运动后，联合凸包最小面积严格大于 $T=16747/20000=0.83735$。沿用 3651 个有理点的六组坐标，纯有限输入的最小面积严格大于 $0.83734015134$。

## 叶覆盖及整数计数

同靶五体外围的规范角、径向界和五体评分交集留下 460860 个原叶。四层原树核验依次留下 118130、12666、2871、1046 个原叶。末端逐号核对发现，1046 中包含上一靶值 0.83731 的全部 614 个原叶，新增 432 个。旧 614 的每个数值门槛都重新设到本轮靶值。六体面积至多 $T$ 时，五体子凸包也须满足该上界，故同靶外围和这 1046 个闭原叶穷尽了规范域。

153 个原叶由此前单帽核关闭。其余 893 个原叶使用第 132 轮的联合帽核模式 2，包含新增的全部 432 个。两核输入相同，来自三十点的 2493 个正权平衡三元组覆盖全部 384 个闭角格，并通过各材料点的不确定旋转区间精确消去第六体的平移。点集关于横轴对称，覆盖反射。联合帽采用半径 $707/1000$ 的已认证面积排除；该引理有效到 $0.838>T$。旧体面积证据则使用经核验的 32 或 64 级材料表。每一棵接受树的双倍面积整数门槛为 $120674852735317915$，尺度为 $2^{57}$。

666 个原叶至少一次使用了第六体。每棵二叉接受树满足节点数等于其终端数的两倍减一。这一恒等式也在每条冻结记录的复算中核对。

固定圆盘中心在原点后，面积受上界控制的任意一个测试体上的点 $p$ 满足 $|p|\le 2A$，因为圆盘的垂直直径同 $p$ 所张三角形面积为 $|p|/2$。各体平移有界，旋转反射取值集紧致，面积在这些放置上连续。因此六体最小值达到，闭排除给出严格下界。

## 六组显式有理点

第六体的面积补证仅使用这三十个有理点。再把前五个曲体换成 six-rational-point-groups.json 的其余五组明确有理点。若 $C$ 为同一姿态下 3651 个点的联合凸包，$K$ 为相应曲体及三十点的联合凸包，已证 $K\subset C+eB$，且 $C$ 含半径 $r=1/2-e$ 的圆盘，其中 $e=236329089467/80372250000000000$。Steiner 公式及 $P(C)\le 2A(C)/r$ 推出
$$
 A(C)>\frac{T-(22/7)e^2}{1+2e/r}
 =\frac{760783173624432442576596045066915203140902451716193}
 {908571232847369619377605985906250000000000000000000}
 >0.83734015134 .
$$
六组点数分别为 1024、648、650、651、648、30。每组都可以单独平移、旋转或反射。

## 复算方法

同靶外围输出为 RETAINED 和 LEDGER，分别为完整 retained.json 与 stage-ledger.json。TREE 是 Tomar 十一维原树，T32 和 T64 是已生成的两份见证表。R132 是归档 C++ 文件 tomar_six_083730_guard.cpp。WORK 使用新目录，CACHE 是本机的 Clang 模块缓存。在 computation 下执行

```sh
python -I -B replay_finite_point_083735.py TREE T32 T64 WORK CACHE --workers 6 --terminal-ledger finite-point-lift-083735.json --outer RETAINED --outer-audit LEDGER --weighted-source R132
```

入口核验同靶外围清单和账本的完整性及哈希，重建 1046 个原叶的源树端点，复核两份材料表、全部角格和正权平衡条件，重新编译两核并逐原叶重放。纯有限输入的坐标文件和严格有理下端也由同一入口输出。外围独立重算另使用该门槛的五体四层入口。

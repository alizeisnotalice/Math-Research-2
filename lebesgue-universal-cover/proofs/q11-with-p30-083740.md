# 同一十一点在 0.83740 的真正原叶上补充三十点

固定第121轮的原有理点 $Q_{11}$ 作为第七组输入。与旧五体和第六组 $P_{30}$ 一起使用时，它在 $0.83740$ 的六个真实原叶中产生了新终止子盒。原叶 1205/140208 的对照从整个原闭盒开始。64级旧材料、原树、分裂轴选择、正反面积帽判据、访问预算与深度限制均相同。预算取20,000，加入 $Q_{11}$ 的分支实际访问18,569节点并穷尽全部子盒，其中8,119个终端由原五体关闭，1,166个由 $Q_{11}$ 关闭。只用原六组的对照在该预算耗尽。将预算增至1,048,575后，原六组以28,071节点关闭同一原叶。由此，七组方法在该叶少访问9,502个节点。

其余五叶在1,048,575节点预算均留下余盒。此轮记录的整树前缀证明如下。

| 原叶位置 | 仅六组的 P30 终端 | 七组的 P30 终端 | 七组的 Q11 终端 |
| --- | ---: | ---: | ---: |
| 176/35174 | 480,784 | 481,180 | 298 |
| 180/24225 | 183,016 | 268,871 | 77,917 |
| 1201/73614 | 0 | 0 | 259,420 |
| 1205/139716 | 0 | 0 | 230,526 |
| 1205/139730 | 0 | 0 | 172,617 |

每个子盒依次尝试旧五体材料扇、$P_{30}$ 面积帽和 $Q_{11}$ 面积帽。旧面积下端距靶小于或等于 $1/25000$ 时才尝试第三项。两组有限输入各自的条件都独立覆盖其全部刚体运动。节点统计因此直接记录第七组所增加的终止子盒。尚余原叶的全盒状态由后续更大预算的证书决定。

## 对称见证的有理折损

按 $Q_{11}$ 公开原坐标顺序，以关于横轴的反射 $J$ 将第 $i$ 点和第 $-i\bmod 11$ 点配对。定义 $z_i=(p_i+Jp_{-i\bmod 11})/2$。这组对称中间点可以沿用固定384闭角格的三法向证书。用有理平方比较逐点验证 $\|z_i-p_i\|<10^{-9}$。三法向使用的整数方向长度均不超过 $1+2/2^{22}$。计算把每个加权支撑下端降低
$$
 2^{-28}\left\lceil 2^{28}(1+2/2^{22})10^{-9}\right\rceil .
$$
经过该折损，原 $Q_{11}$ 的任意正手和反手刚体放置均满足同一个支持函数下端。旧五体端点和角间误差逐盒重新包围，随后沿用方向特定的联合帽整数判据。所有三法向正权和平衡等式、原点集直径、对称点直径、角格覆盖及纯整数二叉树守恒关系均由重放验证。浮点线性规划仅用于提出三法向。

## 复算

COMP 指向 computation，TREE 指向 Tomar v9 的 cert11d_08366。TABLE64 为认证用64级材料表，WORK 和 CACHE 分别为重放目录和 Clang 共享缓存。最小整叶对照的指令为

    PYTHONPATH="$COMP" python3 -B "$COMP/replay_q11_with_p30.py" \
      "$COMP" "$TREE" "$TABLE64" "$COMP/q11-leaf-bank.json" "$WORK" "$CACHE" \
      --cases 1205/140208 --budget 20000 --workers 2

去掉 --cases 和 --budget 参数可重放六个原叶及其同预算对照。各行可按分片、位置和 Q11_enabled 对齐。精确重放用 NumPy、python-flint 和带 -ftrapv 的 Clang。搜索建议阶段另用 SciPy。

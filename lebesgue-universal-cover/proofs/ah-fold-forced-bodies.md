# 临界铰点右侧的整族强制凸体

固定斜角 1.5497° 和原 Gibbs 宿主 G，使用[铰点反例](ah-pivot-obstruction.md)中的坐标和理想五边形 K_w。设 C 是位于 G 内的闭凸万能宿主。则

\[
 \overline{\operatorname{conv}}\!\left(\bigcup_{w_*\le w\le .430}K_w\right)\subset C .
\]

先固定开区间内的 w。取反例证明中的定宽一体
\(K_t=(1-t)K_w+tQ_A R\)。对一切足够小的正 t，相容方程和原六个支撑面只允许十二个零平移姿态。十个姿态严格越过 G 的直线面，另一反射姿态严格越过 G 在配对点的真实切线。这十一种排除都只用 G 的约束。因此 C 要容纳 K_t，必须以恒等姿态容纳它。对任意 x∈K_w 和任意固定 y∈Q_A R，点 (1−t)x+ty 属于 C。令 t 趋于零即有 x∈C。此处同一次摆放固定全部点。

两端由连续性补入。在有限的法向扇上，支撑表达式均为锚点投影加常数，锚点和扇端依参数连续且相邻表达式在扇端相等。因此支撑函数在参数与方向的紧直积上连续，K_w 在 Hausdorff 距离下连续。使用 C 的凸性及闭性得到所给包含式。

特别地，每个上述 K_w 含 x_w=Z+wD，故与[已有尾段](ah-compulsory-boundary.md)拼接得到从 w_* 到 1 的完整强制直段。该结论允许宿主沿其他方向同时裁切，假设仍要求 C 位于固定的 G 内。全体一般宿主的面积最小值另需下界证明。

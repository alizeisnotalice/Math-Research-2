# 理想八锚族的变斜角相容根合并曲线

令 \(1.54^\circ\le\sigma\le1.56^\circ\)、\(.42775\le w\le.42957\)。采用第198轮的八个锚点与相容函数 \(F=\sum_{k=0}^2h(u(\phi+120^\circ k))-3/2\)。在整个参数矩形中，每个八锚定宽一补全的内部相容根数由唯一的严格递减函数 \(w_f(\sigma)\) 决定。低于 \(w_f\) 有两个不同内根，等于 \(w_f\) 有一个二重内根，高于 \(w_f\) 无内根。端根始终存在。

在固定扇 \([52.65^\circ,55.15^\circ]\) 上，三个支持依次使用第4锚的对端圆弧、第2锚顶点、第6锚的对端圆弧，索引从零开始。逐闭格检查查询方向在相应相邻单位半径生成的锥内。该锥内的顶点支持等式由两个邻点的单位闭盘给出，反向的圆弧等式来自定宽。故对每个补全有精确公式
\[
 F=a(\sigma,w)\cos\phi+b(\sigma,w)\sin\phi+\tfrac12.
\]
扇中唯一极小角始终严格在两端之间。设 \(\Delta=a^2+b^2-1/4\)。其正、零、负号分别对应极小值的负、零、正号。464210 个外扇角盒提供严格正下界 \(3.7292\times10^{-10}\)，零度和六十度附近由定宽接触锚的导数不等式补齐。因此全部内部根均由这一个扇内的公式决定。

在 \(64\times256\) 个参数格上，以 Arb 有向幂级数包围两维偏导。对 \(\sigma\) 的计算按每度计。两个偏导都严格为负。最不利端点 \((1.56^\circ,.42775)\) 的 \(\Delta\) 大于 \(5.2105\times10^{-7}\)，另一最不利端点 \((1.54^\circ,.42957)\) 的 \(\Delta\) 小于 \(-4.4626\times10^{-7}\)。单调性和隐函数定理给出唯一 \(w_f\)，导数落在 \([-.098507,-.074395]\) 每度。固定铰点 \(w=.429\) 时，\(\Delta\) 在 \(1.5460^\circ\) 为正，在 \(1.5461^\circ\) 为负，因而这两个角间有唯一一次合并曲线与该铰点相交。

在 \(\sigma=1.54^\circ\)，独立的窄箱复算给 \(w_f\in[.4295222514414,.4295222514415]\)。正向连续摆放的证明覆盖到 \(w=.429515\)，与这个合并位置相差不足 \(7.252\times10^{-6}\)。合并曲线约束的是该八锚族的相容姿态。要推出整个变斜角宿主的万能性，仍需处理一般输入及其所有裁线在同一姿态下的兼容条件。

复算使用现有 Python、numpy 和 python-flint。三个脚本与已归档计算依赖放在同目录，执行下列命令。

    python -B computation/certify_low_sigma_fold_splice.py LOW.json
    python -B computation/certify_moving_sigma_fold_splice.py MOVING.json

## 保留旧切线的 .429 铰点必要墙

令 \(\sigma_*\) 为合并曲线与 \(w=.429\) 交点。对该点的独立有向代入把括缩至
\[
 \sigma_*\in[1.54603709348333041715^\circ,1.54603709348333041725^\circ].
\]
若 \(\sigma_*<\sigma\le1.56^\circ\)，取 \(w_f(\sigma)<w<.429\)。考察任何保留原宽一正六边形、两条原 \(m_3,m_5\) 半平面和 \(q(w)\) 处原配对外切线内侧，并采用 \(p=.429,\ 0<\delta<\pi/2\) 的内转 AH 半平面的候选。此候选无法覆盖所有直径一输入。以下几何论证只需要所列半平面。

取八锚补全的原方位 \(K_w\)，使 \(x(w)=Z+wD\in K_w\) 与 \(q(w)\in Q_AK_w\) 同时成立。令 \(R\) 是顶点 \((0,1/\sqrt3)\) 与 \((\pm1/2,-1/(2\sqrt3))\) 的 Reuleaux 三角形。由定宽，混合体 \(K_t=(1-t)K_w+tQ_AR\) 定宽一。三个正六边形支撑均为半宽，两端相容角保持精确根。对未扰动的 \(K_w\)，本节的相容式可能整体变号，但在开扇内始终同号。端角的严格一阶余量使相容式与 \(\sin(3\phi)\) 的比值在闭扇上同号且远离零。三角形相容式为 Lipschitz 函数且两端为零，与 \(\sin(3\phi)\) 的比值有界。因此正的充分小 \(t\) 不产生额外相容根。所有允许姿态只能落在十二个正六边形二面体元素上，相应平移严格为零。

恒等姿态中 \(x(w)\) 超出 AH 新裁线 \((.429-w)|D|\sin\delta>0\)，这个严格违反在充分小扰动后持续。反射姿态中，\(Q_AK_t\) 含 \((1-t)q(w)+tV\)，其中 \(V=(0,1/\sqrt3)\)。程序在同一 \(64\times256\) 参数网格上证明
\[
 \frac{-Jq'(w)}{|q'(w)|}\cdot(V-q(w))>0.00858925,
\]
故每个 \(t>0\) 都严格越过相应配对切线。另十个二面体姿态中，八锚之一越过 \(m_3\) 或 \(m_5\) 的下界大于 \(0.0009253492\)，也在正的充分小扰动后持续。所有姿态已排除。

    python -B computation/certify_moving_sigma_pivot_obstruction_splice.py WALL.json

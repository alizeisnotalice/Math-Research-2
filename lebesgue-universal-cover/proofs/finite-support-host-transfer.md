# 有限支撑在四体最优宿主与逃逸宿主间的转移

以 (K_*) 表示第95轮的唯一四体极小凸包，以 (K_e) 表示第108轮面积严格小于 (0.837657369) 的逃逸宿主。后者包含圆盘、四个规则定宽奇边形以及完整的第103轮九项 Fourier 体 (S)。(P_9) 是文献驱动报告的九点输入。

## 逃逸宿主与四体极小宿主严格分离

对任一刚体变换 (g)，把 (gK_e) 放进 (K_*+rB) 所需的半径严格大于 (0.012)。因此两宿主任意等距对齐的 Hausdorff 距离也严格大于 (0.012)。

从 (K_e) 的圆盘与规则奇边形各取圆弧分点，按 (10^{12}) 格点取整，逐点误差小于 (2/10^{12})。因为 (K_e) 含原点半径 (1/2) 的圆盘，将格点分母改为 (10^{12}+4) 就把这些有理点全部送回 (K_e) 内。其凸包有96个顶点。

对旋转与反射两支，每个闭角格取两或三个有理单位法向 (u_j) 和正权 (w_j)，满足 (sum_jw_ju_j=0) 及 (sum_jw_j=1)。在逃逸宿主内的有理点中选取对应点 (x_j)。若摆放后全部进入 (K_*+rB)，则平移消去后
[
 sum_j w_jig(u_j\cdot R_\theta Sx_j-h_{K_*}(u_j)ig)\le r.
]
这里 (S) 表示相应的手性映射。中点转角附近的左端写成 (A\cos\alpha+B_0\sin\alpha-C)。按第97轮的原支撑核计算 (h_{K_*}) 的上界，再由 (A>0) 得到整格下界 (A\cos h-|B_0|\sin h-C)。771个闭角格覆盖两支全部转角，最小严格下界超过 (0.01205900972)。总共用到逃逸内凸包的8个有理材料点。

同一个 (P_9) 在 (K_e) 中有显式摆位，放入上述有理内凸包后，逐边支撑净余量仍大于 (0.00003696468)。 on the reference side, the report's strict padding (r(P_9,K_*)>0.00392897) transfers to any host whose isometric Hausdorff distance to (K_*) is smaller than that certified padding. 具体地，半径 (0.003) 的闭邻域全部排除无扩张放入 (P_9)；距 (K_e) 小于 (0.0000369) 的凸宿主则都能放入 (P_9)。后一结论用支撑函数的双向 Hausdorff 界和现有摆放的严格余量。任何一个同时覆盖 (K_*) 与 (K_e) 等距类的 Hausdorff 球半径都严格大于 (0.006)。因此在面积门槛 (0.837657369) 上，一个以四体极小宿主为参照的单邻域证书无法覆盖这两个宿主的 (P_9) 判定。

代码也用有理取整和内缩复核 (P_9\subset B_9)。

## 同一 Fourier 输入的稀疏反例与密集转移

令 (S_8) 为 (S) 在法向 (2\pi(j+1/50)/8) 的八个支撑点经有理取整和内缩所得的点集。它以**同一个反射、旋转和平移**放进第102轮十一维原坐标盒内所有五体宿主。对盒内每个原定宽体，用其含圆半径和旋转、平移的支撑 Lipschitz 界先取公共内缩，再作有理内多边形。五体公共内凸包上逐边逐点计算得到的净余量超过 (0.00188378)。

第99轮驻点在这个原坐标盒内。因此圆盘、三、五、七、九边形加 (S_8) 的自由六体最小面积小于 (0.837295006222)。独立优化得到的一组非驻点有理摆位也通过严格的2048段每弧、整数凸包和外平行体上界，面积小于 (0.83729965)。这两个可行构形都低于 (0.83730)。第108轮的完整 (S) 在同一盒内本来给出严格面积排除，八点离散消去了这个宿主区的障碍。

细采样可以恢复整个盒上的排除。取 (S) 的 (N) 个等距法向支撑点，同样取整，并用公共分母 (10^{12}+10) 内缩。整数距离验证它们的直径小于一。原曲率半径满足 (0.01\le\rho\le0.99)，上界来自宽一关系 (\rho(\theta)+\rho(\theta+\pi)=1)。对目标法向 (u(\alpha))，最近样本的法向与其相差至多 (\pi/N)。由 (p'(\theta)=\rho(\theta)Ju(\theta))，向 (u(\alpha)) 投影并积分，损失至多
[
 0.99(1-\cos(\pi/N))\le \frac{0.99\pi^2}{2N^2}.
]
格点误差和内缩又至多 (12/10^{12})。故以
[
 \delta_N=\frac{0.99(22/7)^2}{2N^2}+\frac{12}{10^{12}}
]
控制全向 Hausdorff 误差。

给定角度与平移，令 (A_N) 为有限增广宿主的面积。包含原半径 (1/2) 圆盘给其周长至多 (4A_N)。将完整 (S) 放在同一姿态，增广宿主包含于有限宿主的 (\delta_N) 外平行体。第108轮在整个第102轮盒内的下端 (A_{
m ref}=0.83945005239) 因此给出整盒上的有理严格下界
[
 A_N>\frac{A_{
m ref}-(22/7)\delta_N^2}{1+4\delta_N}.
]
(N=88) 实际生成并验证后得 (A_{88}>0.8373341036)，超过 (0.83730)。88是这个误差公式达到该门槛的最小样本数。若在第108轮更宽的盒使用 (0.83730023870) 的已证完整 (S) 下端，同一个公式达到 (0.83730) 所需的最小 (N) 为8284。

这项转移覆盖给定的十一维宿主区域。全域方面，第108轮的外部逃逸宿主包含完整 (S)，所以也包含上述所有内采样。细化同一个 (S) 在这些宿主上保持相同的可行反构造。


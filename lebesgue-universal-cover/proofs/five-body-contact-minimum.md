# 五个定宽测试体的一个严格局部极小构形

固定直径为一的圆盘 $D$ 的中心和正胡勒三边形 $B_3$ 的方向，余下十一维放置变量依次为 $t_3,\theta_5,t_5,\theta_7,t_7,\theta_9,t_9$。在这个放置空间中存在一个严格局部极小点，面积属于
$$
[0.837295006221025243456393253909267018677\ \pm\ 5.09\,10^{-40}].
$$
因而五体的全域最小值严格小于 $0.83729500622102525$。原始 opt11 文件给出的十一项十进有理参数放置，其面积比新构形严格大于 $1.2\,10^{-10}$。五体全域极小值是否为该局部极小值仍待证明。

## 由两条共同支撑线确定运动

令 $r=1/2$，$v_{n,k}=(\cos(2\pi k/n),\sin(2\pi k/n))/(2\cos(\pi/(2n)))$，$p_{n,k}=t_n+R_{\theta_n}v_{n,k}$。方向记为单位法向 $A=(\cos\alpha,\sin\alpha)$、$B=(\cos\beta,\sin\beta)$。$A,B$ 和它们的反向分别支撑全部五体。以下各方程确定靠近 opt11 的分支。

1. $A\cdot p_{3,0}=B\cdot p_{3,1}=r$ 唯一确定 $t_3$。取单位圆方程 $D'\cdot p_{3,0}=r$ 异于 $A$ 的第二根 $D'$。
2. 七边形满足 $A\cdot p_{7,0}=B\cdot p_{7,1}=r$，$D'\cdot p_{7,2}=-r$。九边形满足 $A\cdot p_{9,0}=B\cdot p_{9,2}=D'\cdot p_{9,8}=r$。对任意一体，前两式解出 $t=t_0+t_c\cos\theta+t_s\sin\theta$，代入第三式成为单位圆与直线求交。若直线为 $L\cdot u=h$，其两个单位根是 $(hL\pm\sqrt{|L|^2-h^2}JL)/|L|^2$，其中 $J$ 为逆时针直角旋转。上述两体依次取负根、正根。
3. 取 $p_{9,1}\cdot F=r$ 的负根 $F$。五边形满足 $A\cdot p_{5,3}=-r$、$B\cdot p_{5,1}=r$、$F\cdot p_{5,3}=-r$，消元后取正根。符号均采用脚本中固定的约束顺序。

构形位于此光滑二维流形上。$A,B$ 处的五体同切，$D'$ 处圆盘与三、七、九边形同切，$F$ 处圆盘与五、九边形同切。正胡勒奇数边形与半径为一的弧段对应的支撑值为 $1+p_{n,k}\cdot u$，顶点支撑值为 $p_{n,k}\cdot u$，这些相等关系直接由上述方程及定宽性质得到。

## 面积与驻点的隔离

支撑归属由各边形的顶点、圆弧分界角以及活跃的体际切换共同划为 62 个原子角区间。对每一段及每一竞争体，其支撑值之差具有 $a+b\cos\theta+c\sin\theta$ 的形式。两个端点的比较由 56 个已知接触等式和严格 Arb 不等式完成，同时检验区间中可能出现的驻点最小值。在横跨 $2\pi$ 处采用同一连续角分支。这样得到的完整圆弧和公切线段封闭成凸包边界。

对该边界用格林公式精确求面积 $G(\alpha,\beta)$。顶点段参数令弧半径为零。自动微分的区间 Hessian 在归档驻点盒上正定，行列式大于 $93.45$。有理近似逆 $C$ 满足 $x\mapsto x-C\nabla G(x)$ 严格将闭盒映回自身，收缩范数小于 $6.21\,10^{-11}$。唯一驻点的法向角近似为
$$
\alpha=0.5134408330402378347081910977212867,\qquad
\beta=1.578292413856733932999241953055303.
$$
先在盒心计算面积，再以区间梯度和 Hessian 的泰勒余量控制驻点与盒心的差，得到前述面积球。

## 九个横截方向

$A,B$ 线性独立，两个接触三角形顶点在各自切线上的投影绝对值均大于 $0.1$。由隐函数定理，邻近任一放置可按其 $t_3$ 确定两个法向角。把其余三体的九项放置变量与相应流形锚点之差记为 $\xi$。依据切向坐标递增排列，各重切线的体标号顺序为

| 法向 | 顺序，0 表示圆盘 |
|---|---|
| $A$ | 3, 5, 9, 0, 7 |
| $-A$ | 7, 0, 9, 5, 3 |
| $B$ | 5, 0, 7, 9, 3 |
| $-B$ | 3, 9, 7, 0, 5 |
| $D'$ | 0, 7, 9, 3 |
| $F$ | 0, 9, 5 |

每段中间接触点可以选用任意子集，合计有 $2^{15}=32768$ 条等面积边界链。冻结所选各体的材料点和圆弧，再将它们随所属体刚体移动。每条链在充分小的扰动后仍为凸包内的星形曲线。具体地，锚点上各非零连接段的端点极角严格递增，次序由连续性保持；各参与圆弧的支撑直线到原点有严格正距，所以弧上的极角也保持正向。每个弧段都在所属体中，每个连接段均在凸包中，绕数仍为一。有限条所选链可取公共扰动半径。

边界速度的面积一阶变化为 $\int\det(V,dp)$。连接段 $P,Q$ 贡献 $\det((V_P+V_Q)/2,Q-P)$。圆弧平移项为 $\rho\det(V,n_1-n_0)$；对旋转使用中心的刚体速度，沿圆弧法向的附加旋转速度与弧切向平行。10 条已归档链的九维梯度构成一个单纯形，其原点重心坐标均大于 $0.05$。逆矩阵区间核验给出这个单纯形包含 $[-0.00027,0.00027]^9$。故任一横截偏移至少有一条链的一阶增量达到 $0.00027\|\xi\|_1$。有限条链的二阶余量在邻域内一致为 $O(\|\xi\|^2)$，所以所有充分小的非零横截偏移均严格增大面积。结合二维驻点的正定 Hessian，就得到完整十一维的严格局部极小。

## 旧放置的面积比较

以公开 opt11 的十进输入为精确有理数，由它的 $t_3$ 还原两条相应法向，再按上述方程求同一接触流形上的比较构形。两者的凸包 Hausdorff 距离小于 $1.308\,10^{-11}$。用来控制转角误差的界是 $|h_n'|\le\tan(\pi/(2n))/2$：在顶点或圆弧的各个有效区间，法向与相关顶点半径的夹角到 $0$ 或 $\pi$ 的距离不超过 $\pi/(2n)$；再加上平移误差即可。旧凸包包含于半径 $0.62$ 的圆盘，故周长至多 $1.24\pi$。由外平行体面积公式，从比较构形的已认证面积中扣除 $1.24\pi\delta+\pi\delta^2$，得到旧放置面积严格大于 $0.83729500635103374$。

计算入口为 `certify_five_body_contact_stationary.py` 与 `certify_five_body_contact_transverse.py`，直接用 Python 3.13.18 和 python-flint 0.9.0 运行。两份 JSON 保存实际 192 位验证的区间及可重放约束。

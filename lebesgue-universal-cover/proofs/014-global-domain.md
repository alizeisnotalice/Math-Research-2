# 第14轮：面积小于0.838的全部八体放置的全局参数盒

设F8为第13轮八体，τ=419/500。若一个凸集C面积<τ且分别包含F8的全等副本，
则可同时变换整个配置，使D位于原点、B3旋转角为0，并使全部相对放置落入下列20维盒：

- B3,B5,B7,B9,P11,P19的各平移坐标在[-21/100,21/100]；
- Fourier体的各平移坐标在[-6/25,6/25]；
- B5角∈[0,π/5]，B7角∈[0,2π/7]，B9角∈[0,2π/9]；
- P11角∈[0,2π/11]，P19角∈[0,2π/19]，Fourier角∈[0,2π]。

这只认证盒外不可能面积<τ，不宣称盒内最小面积≥τ。

## 1. 刚体归一化与反射

所有测试形状都关于其定义坐标的x轴反射对称，故各自的反射可改写为旋转。
先将盘中心移到0，再共同旋转令B3角0。各正n形体允许按2π/n取模，Fourier体按2π取模。
最后共同反射x轴保持D和B3的规范形状，将所有角与平移y坐标取反；以此可将B5的
周期角限制在半周期[0,π/5]。只能这样缩减一个全局镜像自由度，不能分别把其他角都减半。
两个B3平移参数加六个其余体的三参数，共20维。平移盒关于x轴对称，故该约化保留边界。

## 2. 正n体的远点下界

Bn及Pn均包含顶点Rn u(2πk/n)，Rn=(2cos(π/(2n)))^-1。
中心位移t的长度m>0时，总有一个旋转后的顶点方向与t夹角≤π/n。
该顶点到原点的距离至少
 g_n(m)=sqrt(Rn²+m²+2Rn m cos(π/n))。
对m≥0，g_n严格递增（n≥3）。有理π与Taylor区间计算严格给出
 g_n(21/100)>S_n，其中
 S3=7061/10000，S5=7064/10000，S7=7079/10000，S9=7086/10000，
 S11=709/1000，S19=887/1250。

若m≥21/100，C包含D及某个长度>S_n的点。将整个C旋转令该点在正x轴，
D不变。凸性及0∈D保证(S'_n,0)∈C，其中S'_n=floor(10^15 S_n)/10^15≤S_n。
这次旋转只用于估计面积，无需保留前面的角度规范。

## 3. 不依赖反三角函数的精确面积排除

生成器选取512个分母10^15的圆盘内有理点Q，并对每个点用整数平方明确验证
x²+y²≤1/4。初步浮点选点只提供这些整数，不承担任何成员资格或面积结论。
随后整数凸包及有理鞋带公式严格计算
 |conv(Q∪{(S'_n,0)})|>419/500
（n=3,5,7,9,11,19），见outer_domain_certificate.json中的完整点列与分数。
于是|C|>τ，与假设矛盾。故每个正n体的中心长度<21/100，尤其各坐标落入声明的闭盒。
独立验证器从保存的整数点重算圆盘成员、三角下界与凸包面积，不依赖选点过程。

## 4. Fourier体

其支撑函数h≥1/2−1/80−19/1200=283/600。若中心长度m≥6/25，沿中心位移
方向取支撑点，则该点范数至少m+283/600≥427/600。
同样以S'=floor(10^15·427/600)/10^15为径向点，与512盘内点的凸包面积严格大于τ。
故该中心长度<6/25。向下截断只减小测试凸包，不会错误抬高下界。

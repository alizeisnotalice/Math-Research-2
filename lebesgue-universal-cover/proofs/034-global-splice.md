# 固定斜角 Gibbs 候选体的全局拼接

取精确斜角 σ=1.5494°。以下 `Pσ` 指第28轮的八边形，字母 P 仍表示 A 角 G 圆弧的切点。用 Tₐ 表示 AH 的切点，用 Tₑ 表示 EH 的切点。设 U₅ 为五个闭切除的并。本证明识别 `closure(Pσ ∖ U₅)` 的边界、凸性和面积。反射与旋转放置需另证。

## 相邻耳的共边

第20轮的坐标矩形 R 是中心参数 (L,N)∈[C,G]×[N₋,E₃] 的同胚像。证书给出两个中心包络的 y 坐标严格为负、Nₓ−Lₓ<0、上交点的 y 坐标严格为正。下交点的 y 小于两中心的 y 坐标平均值，因而为负。这对 G,N 和 L,E₃ 同样成立。

若 X(L,N) 在 G 的单位圆上，它必须是 G,N 的唯一上交点 X(G,N)。同胚性于是给出 L=G。反向直接由定义。换成 E₃ 单位圆同样给出 N=E₃。两个参数域去掉相应边后各自连通，并都包含给出 Z 的参数。证书给出 Z 严格在两圆盘内，所以

- 删去 L=G 边后，R 全在 G 开圆盘内。
- 删去 N=E₃ 边后，R 全在 E₃ 开圆盘内。

故 R 在两闭圆盘的交集内。E₃ 是 n₄ 支撑线上的点，且 n₄=−n₁，所以 E₃ 的单位圆盘满足 n₁·x≤1/2。类似地 G 的单位圆盘满足 n₂·x≤1/2，因为 G 在 n₅ 支撑线上。证书从 R 的整域有理盒检验 Pσ 其余六个严格线性不等式，因此 R⊂Pσ。

第20轮删掉往返段后所得的 AH Jordan 曲线全部在 R 内。R 的外部连通且无界，故整块闭 AH 都在 R。其内部是开集，不能碰 R 的边界。由于第28轮 AS 的每个闭扇除生成圆弧外的点严格在其相应圆盘外，AH∩AS 只能在两条生成弧上。由 R 的圆盘边界刻画与第20轮修剪后边界，实际交集恰为 E₃ 圆弧 Y→X_AS 与 G 圆弧 X_AS→T′。交界以外，AH 曲线的 C 圆弧和直段只有 Y 在 N=E₃ 或 L=G 边上，直段的配对曲线只有 T′ 在这些边上。证书核实 Q,Y,X_AS 的严格短弧次序，也核实 X_AS,T′,P 的严格短弧次序。其中同名 E₃ 与 G 分别由同一支撑线相交及同一单位圆与支撑线交点的右根定义。X_AS 是 G,E₃ 两圆的上交点，故与 R 在 (G,E₃) 的角点一致。P=G+n₂，正是第20轮在 (G,N₋) 的切触角点。

EH 的三边闭 Jordan 曲线由 Tₑ→U 的直段、C₃ 圆弧 U→J 和 B₃ 圆弧 J→Tₑ 组成。局部证书已匹配 U、Tₑ 为原 ES 对应弧的严格内点，另一圆交点在两段短弧外。U 严格在 B₃ 开圆盘内，Tₑ 严格在 C₃ 开圆盘内，这由本次证书复核。于是 C₃ 圆弧 U→J 除 J 外全在 B₃ 开圆盘内，B₃ 圆弧 J→Tₑ 除 J 外全在 C₃ 开圆盘内。再由圆盘凸性，直段以及整个 EH 区域都在两个闭圆盘之交。第28轮 ES 的两扇只有各自生成圆弧进入相应闭圆盘，因此 EH∩ES 恰为 U→J→Tₑ 两弧。B₃ 是 m₀ 支撑线上的点，C₃ 是 n₀ 支撑线上的点，故上述圆盘给出 m₃ 与 n₃ 两项半平面。两弧的径向量始终在第三象限，每个坐标的极值在端点，故三个端点的包络盒包含整块 EH。证书从此盒得到 Pσ 其余六个严格不等式。

用第28轮完整扇盒、R 整域盒、EH 盒分开三组 CS、ES∪EH、AS∪AH。前两组有严格水平间隔，最后一组有严格竖直间隔。至此五耳均在 Pσ，内部两两不交。

## 拼接曲线、整周转角与凸性

待识别边界 Γ 按以下顺序遍历。圆弧在括号内标记圆心，省略括号的普通边段为直线。

```text
B1 → Q →(E3) Y →(C) Ta → Z →(配对曲线) T' →(G) P
   → F1 → H →(C3) U → Te →(B3) I → E3 → D1 → G
   →(F3) K → C3 → B1
```

各圆弧都是逆时针短弧。第23轮曲率证书给出配对曲线严格正曲率及全程第三象限切向，Tₐ、Z、T′ 都前向切合。本次证书检查其余每个真正的角在 (0,π/2)，并检查 Q、P、H、I、K 的前向切合。其中 H 在 n₃ 支撑边，I 在 m₃ 支撑边，K 在 m₅ 支撑边，各由圆心到支撑边的正交投影定义。K 的实际出边为 K→C₃，接着 C₃ 再转向竖边 C₃→B₁。

直段 B₁→Q、P→F₁、F₁→H、I→E₃、E₃→D₁、D₁→G、K→C₃、C₃→B₁ 的方向角依次可抬升为

\[
150°,\quad210°,\quad270°,\quad300°+\sigma,\quad330°,
\quad390°,\quad420°+\sigma,\quad450°.
\]

这些角分别来自 n₁、n₂、n₃、m₃、n₄、n₅、m₅、n₀ 的正向边切向。上部替换的切向位于第二或第三象限，EH 替换的切向位于第四闭象限，G→K 的切向位于第一象限的下一周。证书检验每段圆弧的端切向象限及短弧叉积、点积，因此整段留在相应象限。所有前向角均在这组展开角上递增，最后接到初始方向 510°。所以 Γ 的切向角非降，总增量严格为 360°，且每个跳角小于 π。

这也直接推出 Γ 简单。若不同参数给出同一点，两次访问把遍历分成两条闭的正长度子路径。两条子路径的切向角展开宽度之和不大于 2π，故至少一条的宽度不大于 π。取其角域的中线作投影方向，整条子路径的投影速度非负。当角域宽度小于 π 时，投影速度在每个正则段严格为正。当宽度等于 π 时，因每个角跳跃小于 π，至少一段正长度的正则路径有严格内部切向角，从而其投影速度严格为正。任一情形都与该子路径闭合矛盾。

在 Γ 的任一点取一侧切向，或取该点两侧切向之间的任一方向 φ。沿 Γ 从该点出发走一圈，向 φ 左法向的投影位移先不减再不增，因为投影速度符号由 sin(切向角−φ) 给出。最后投影回到零，所以整条曲线位于该切线的左闭半平面。由凸曲线判据，Γ 正向围成一个凸体 K_*。

## 边界链与闭包

从 Pσ 的正向多边形边界减去五个正向耳边界作为有向链。原有 CS、ES、AS 的正向边界分别为

```text
G → C2 → K →(F3) G
H → E2 → I →(B3) J →(C3) H
Q → A1 → P →(G) X_AS →(E3) Q
```

在这些列出的边界，每个耳沿原支撑边的走向与 Pσ 一致，故为正向。AH 的正向链为 Y→(E₃)X_AS→(G)T′→Z→Tₐ→(C)Y，EH 的正向链为 U→(C₃)J→(B₃)Tₑ→U。判定后两者取向时，可以在所列逆时针共弧的严格内部取一点。Jordan 耳在对应圆盘内，故其内侧在切向左边。五链相减时惟有前述子弧和支撑边反向抵消，留下 Γ。

对避开所有边界曲线的点，绕数的可加性与这些正向 Jordan 曲线的内外绕数给出

\[
\mathbf 1_{\operatorname{int} K_*}
=
\mathbf 1_{\operatorname{int} P_\sigma}-
\sum_{E\in\{CS,ES,AS,AH,EH\}}\mathbf 1_{\operatorname{int}E}.
\]

各耳均为其内部的闭包，所以若其边界点在 int K_* 内，则该耳内部也将与 int K_* 相交。这与绕数式矛盾。类似地 int K_*⊂int Pσ。反过来，Pσ∖U₅ 的每一点都能用 int Pσ∖U₅ 内避开所有边界曲线的点逼近，因为 U₅ 闭、Pσ 为其内部的闭包、有限条相关曲线无内点。绕数式说明这些逼近点都在 int K_*。因此 K_*=closure(Pσ∖U₅)。全部边界均为有限条光滑或分段光滑弧，面积为零。积分绕数式，得到五切除面积的严格相减式。第22及25轮的区间因此识别出该凸体的面积严格小于 0.8440935944。

## 与第33轮闭集的同一性

设 A=Pσ 去掉三个闭 Sprague 切区，V 是 AH 和 EH 的闭并。第33轮定义的 H 为 closure(closure(A) ∖ V)。因为 V 的补集开，closure(A) ∖ V 中每一点可由 A ∖ V 中的点逼近。因此 H=closure(A ∖ V)=K_*。第33轮证明这个闭集容纳所有直径至多一的平面集合，本轮证明它凸且具有五耳相减的面积。结合第22轮的精确有理上端及第25轮的算术重放，得到 Λ≤|K_*|<0.8440935944。这里的候选体以第17轮修订的起始圆心和第30轮指定的 EH 直弦为定义。

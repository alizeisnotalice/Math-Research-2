# 在 AH 直段内部换铰点的裁切

取第86轮的凸万能覆盖 \(H_0\)，固定 Gibbs 角 \(1.5495^\circ\) 和 EH 切深 \(0.00010555\) 弧度。以下 \(T\) 表示 AH 的切点，\(T_{\rm EH}\) 表示 EH 的切点。记
\[
 D=T-Z,\qquad b=-D/|D|,\qquad n=Jb,\qquad
 W=Z+D/4,\qquad \delta=1/4000,
\]
其中 \(J\) 是逆时针直角旋转。定义
\[
 H_1=H_0\cap\{x:\det(R_\delta b,x-W)\ge0\}.
\]
则 \(H_1\) 为凸万能覆盖，且
\[
 \Lambda\le |H_1|<0.844093559167933607.
\]

## 新帽、参数亏损与原有接触条件

旧 AH 离开直段 \(TZ\) 后的曲线记作 \(q(w)\)，其中 \(q(0)=Z\)，且 \(q(w)\) 是旧配对映射作用于 \(Z+wD\) 的点。新裁线经过 \(W\)。有理参数 \(w_f=1/25\) 满足 \(q(w_f)\) 严格位于保留侧，\(Z\) 严格位于裁去侧。旧体凸，旧曲线严格转向。因此闭帽由直段 \(WZ\)、一段 \(q([0,w_f])\) 的初段和新裁弦围成。核验 \(b\cdot(q(w)-Z)<0.041|D|\) 在 \([0,w_f]\) 一致成立。帽的每个点均可写作
\[
 x=Z+wD+\eta n,\quad
 -0.041\le w\le1/4,\qquad
 0\le\eta\le (1/4+0.041)|D|\tan\delta<2.816\times10^{-6}.
\]
这些是线性约束，故在整条边界上的验证推出对闭帽成立。

令 \(L(\ell)=L_0+\ell e_L\)、\(N(t)=M+te_N\)，以旧 AH 的两个单位圆上交点 \(X(\ell,t)\) 作图。反求 \(\ell,t\) 时取两条侧边与以 \(x\) 为心的单位圆的较小线坐标根。令 \(g\) 为旧边界的参数图 \(t=g(\ell)\)，以严格递减对合 \(\psi\) 表示 DC 参数配对。于是 \(g(\psi(\ell))=-g(\ell)\)。原 AH 闭耳满足 \(t\ge g(\ell)\)。

令 \(E=21/100000\)。新帽的同类参数满足 \(t\ge g(\ell)-E\)。为证此，固定其 \(\ell\)，将 \(t\) 与 \(g(\ell)\) 连接。证书逐格包围这一线段，验证 \(-n\cdot X_t>0.014\)。写 \(a=X-L(\ell)\)、\(b_0=X-N(t)\)，两个切向导数直接来自单位圆方程：
\[
 X_\ell=-\frac{a\cdot e_L}{\det(a,b_0)}Jb_0,\qquad
 X_t=\frac{b_0\cdot e_N}{\det(a,b_0)}Ja.
\]
其中 \(g\) 的负参数半段可用单位圆与旧直线的选定交根直接求得，正半段由 \(\psi\) 得出。原边界点在旧直线的保留侧，因此若 \(t<g(\ell)\)，则
\[
 0.014(g(\ell)-t)
 \le n\cdot (X(\ell,t)-X(\ell,g(\ell)))
 \le \eta
 <0.014E .
\]
同时逐格验证新帽各点 \(x_y>0.518\) 和 \(|x-C|>1\)，位于原接触参数图内。于是新旧两部分共有第24轮的帽触发条件。具体地，命中者因直径一及 \(D'\) 的高度界而避开 \(D'\)，其 DC 接触点迫使命中 \(C'\)，继而避开反向 \(F'\)。第24轮的接触序仍给 \(\ell_0\ge\ell\)、\(t_0\ge t\)。由此，第33轮的 \(Q_A\) 把整副本放回 \(P\)，且该副本由于避开 \(F'\) 而避开第86轮 EH。

## 双命中后把两个接触参数锁定到同一对旧边界点

设 \(K,Q_AK\subset P\) 都命中新 AH 内部。第24轮禁止两者同入旧 AH 内部，故交换二者后，可令 \(K\) 的命中点 \(x=X(\ell,t)\) 在新增闭帽。令 \(x'=X(\ell',t')\) 为 \(Q_AK\) 的命中点。其 DC 接触参数记作 \(\ell_r\)。原体 DC、DE 接触参数记作 \(\ell_0,t_0\)。原接触序和反射界给出
\[
 \ell'\le\ell_r\le\psi(\ell_0)\le\psi(\ell),
 \qquad g(\ell)-E\le t\le t_0,qquad
 g(\ell')-E\le t'\le-t_0.
\]
因而 \(g(\ell')-g(\psi(\ell))\le2E\)。

以 \(J_0\) 表示由直段 \(Z+wD\)、\(0\le w\le 0.27\) 及其配对曲线对应的闭 \(\ell\) 区间。负半段的切向逆映射给 \(g'<-3.5\)，而 \(0.95<-\psi'<1.05\)；配对关系于是给出整个 \(J_0\) 上 \(g'<-3\)。证书核验新增帽的 \(\ell\) 和 \(\psi(\ell)\) 离 \(J_0\) 双端均超过 \(2E/3\)。因此由 \(g\) 的全局单调性，\(\ell'\) 也在 \(J_0\)，且 \(\psi(\ell)-\ell'\le2E/3\)。应用递减对合和上式得
\[
 0\le\ell_0-\ell\le0.7E,qquad
 0\le\psi(\ell)-\ell_r\le 2E/3,
 \qquad
 |t-g(\ell)|,\ |t_0-g(\ell)|,\ |t'+g(\ell)|\le E.
\]
最后三个双侧界只用 \(t\le t_0\)、\(t'\le-t_0\) 和
\(g(\ell')\ge g(\psi(\ell))=-g(\ell)\)。

置 \(x_*=X(\ell,g(\ell))\)、\(x_*'=X(\psi(\ell),-g(\ell))\)。在这两条图的相关参数矩形内，导数范数满足 \(\|X_\ell\|<1/5\)、\(\|X_t\|<3/5\)。由上面的五个参数控制，依次取 \(K\) 的 DC 接触、EF 接触、\(Q_Ax'\)、DE 接触和 \(x\)，得到五个实际点。它们与以下理想点各相距至多 \(3E/4\)：
\[
 L(\ell),\quad Q_A L(\psi(\ell)),\quad Q_A x_*',
 \quad N(g(\ell)),\quad x_*.
\]
例如第三点只付 \((2/3)(1/5)E+(3/5)E<3E/4\)；最后一点有完全相同的 \(\ell\) 参数。若 \(\ell>0\)，将实际与理想的五点同时经 \(Q_A\) 反射并重排，第二个边界点成为正向直段上的基点。故统一取参数 \(w\in[0,0.27]\) 和理想基点 \(x_*=Z+wD\)。

## 同一根与同一摆放

五个理想点沿给定顺序的相邻距离均精确为一。第一边由配对公式得到，其第二端为
\[
 Q_A L(\psi(\ell))
 =(-1/2,L_y+\sqrt{1-(L_x+1/2)^2}),
 \qquad L=L(\ell).
\]
其余四边由两对单位圆构造和 \(Q_AN(t)=N(-t)\) 得出。对 \(w\) 划分的540个闭格，证书检查其十条有向单位边沿用第89轮的循环顺序，且相邻方向点积大于 \(3/4\)。由此定义全向理想支撑值 \(h_*\)：在一个顶点扇内为 \(u\cdot v\)，反扇在反向取宽度一的互补值。任一顶点扇内，单位方向是两端方向的非负线性组合，系数和小于 \(11/10\)。由实际体包含五个对应近点，且实际体同属以这五点为中心的单位盘，得到
\[
 \sup_{u\in S^1}|h_K(u)-h_*(u)|
 \le (11/10)(3/4)E.
\]
该式在反扇由定宽性得到。

令 \(u(\phi)=(\cos\phi,\sin\phi)\) 并取
\[
 F_K(\phi)=h_K(u(\phi))-h_K(u(\phi+60^\circ))
            +h_K(u(\phi+120^\circ))-1/2.
\]
每个 \(w\) 闭格各用一个明确的角括区，理想值两端异号，扣除三项支撑误差后的严格余量仍大于 \(0.00010289\)。采用 \(\theta=300^\circ-\phi\) 的实际相容根，按正六边形三个法向同时平移。对任一单位法向 \(u\)，设 \(u=d_0n_0+d_1n_1\)。平移后的支撑比较误差系数为 \(1,-d_0,-d_1\)，其绝对值之和至多3，因为
\[
 |d_0|+|d_1|=
 \max(|u_x+u_y/\sqrt3|,|u_x-\sqrt3u_y|)\le2.
\]
每个角括区再分为80个闭格，直接比较经过同一个旋转平移后的支持值。四条 \(Y\to T\) 的内弦、旧 \(TZ\) 直边、四条 \(Z\to T'\) 的内弦、\(U_1T_{\rm EH}\)、\(m_3,m_5\) 及新支撑线的理想余量都大于 \(0.00083291\)，实际误差至多 \(0.00051975\)。

五段保留 Sprague 圆弧的全部真实径向支撑条件直接由刚才的同一摆位推出。其圆心 \(c\) 各是定宽体强制接触线段 \([c,b_0]\) 的一端，依次使用 \([E_3,D_1]\)、\([G,D_1]\)、\([C_3,B_1]\)、\([B_3,B_2]\)、\([F_3,F_2]\)。这些接触由四个六边形面与两条帽线按第28轮的穿越论证给出；\([G,D_1]\) 还用 \((G,C_2]\) 与 \([F_3,F_2]\) 的距离严格大于一。证书在此角重新核验相应符号。对于每段的单位弧径向 \(u\)，两端 Voronoi 符号给出 \(u\cdot(b_0-c)\le0\)，并由端径向非负组合覆盖整个小弧。若 \(a\in K\cap[c,b_0]\)，则
\[
 h_K(u)\le u\cdot a+1\le u\cdot c+1.
\]
这是该圆弧每点的真实支持线。把旧 \(Y\to T\) 和 \(Z\to T'\) 两段替换为上述内弦，可以用这些弦、其余原真弧的支持线、旧直边及六条六边形边围出内体。各角点的其余支持线由相邻法向非负组合推出。再与新裁线半平面求交即得到 \(H_1\) 的一个内凸体。所求同一个相容摆放进入此内体。

## 其余分支与严格面积

第62轮的旧 EH 离散分支仍成立。各选像避开 AH 的触发依据是缺少 \(C'\) 或命中 \(D'\)。这些条件也排除新帽。第86轮的 \(Q_2\) 双命中时，原体避开新 AH，反射体由于缺 \(C'\) 也避开新 AH，故都满足第86轮的旧连续摆位模型。重放第86轮的证书，取得该摆位与旧 \(TZ\) 的专属严格余量 \(>0.0090554373129026602\)。原点半径小于1的正六边形包含已摆放体及铰点 \(W\)，所以在整个摆放上的支撑比较变化至多 \(2\delta=0.0005\)。同一个第86轮相容摆位也通过新裁线。两轮的真实 EH 圆弧条件采用相同几何。平面内部的命中分类给出全部分支，定宽补全处理任意直径至多一的集合。

令 \(s=Z+0.99|D|\tan(\delta)n/4\)。证书核验 \(s\) 在三角形 \(WZq(1/25)\) 内，具体地，过 \(Z\) 的 \(n\) 向直线与边 \(Wq(1/25)\) 的交点更高。由 \(H_0\) 的凸性，\(s\in H_0\)。两点 \(s,Z\) 都在切除侧，故裁掉至少三角形 \(WZs\) 的面积。其严格下端为 \(0.00000001158419305978677\)。证书用这一有理下端扣除第86轮的有理面积上端，得到文首的严格小数界。

## 复现

在 `computation` 中用 Python 3.13.18 与 python-flint 0.9.0 执行

```sh
python -B certify_ah_segment_cap.py
```

脚本使用128位 Arb 包围，输出各参数、余量和依赖哈希。同时以第86轮原命令重放61份对偶，得到本文使用的 \(TZ\) 独立余量。

```sh
python -B certify_eh_joint_parameters.py 1.5495 0.00010555 31.05275 "$OUT" \
  --old-area eh-joint-1p5495-old-area.json --replay eh-joint-1p5495-105p55.json
```

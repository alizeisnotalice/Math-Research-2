# 保留 Gibbs 凸核时整段 AH 重构的面积下界

取原角度 \(\sigma=1.5497^\circ\)。从 Gibbs 曲边宿主开始施加第199轮的十一段 EH 裁切，暂保留原来的整个 AH 区域。用弦 \([T_a,T_p]\) 切去含 \(Z\) 的帽，保留原点一侧的闭凸集 \(K_0\)。允许宿主的 AH 在任意位置弯折，亦允许它在其余部位比 \(K_0\) 更大。设 \(H\) 为居中宽一正六边形，\(m_3,m_5\) 是原两条斜帽的外单位法向。记

\[
 P_\eta=H\cap\{m_3\cdot x\le\tfrac12+\eta\}
             \cap\{m_5\cdot x\le\tfrac12+\eta\}.
\]

**定理。** 若 \(K_0\subset C\subset P_{0.00000001208341}\)，且闭凸集 \(C\) 经平面等距变换覆盖所有直径至多一的集合，则

\[
 |C| > 0.8440818564775687807184593873363064034435.
\]

与 B 档上界门槛的差约 \(1.90044\times10^{-7}\)。定理还适用于将法向 \(m_i\) 改为单位向量 \(m'_i\)，切高增加 \(d_i\) 后满足 \(d_i+|m'_i-m_i|/\sqrt3\le\eta\) 的边界。因为 \(C\subset H\) 给出 \(|x|\le1/\sqrt3\)，这些宿主均在 \(P_\eta\) 内。

### 真实曲边的基底面积

第199轮十一段 EH 宿主面积加回该轮 AH 的真实帽面积，就是本轮弦裁切以前的面积。删去从 \(T_a\) 沿直段到 \(Z\)、再沿真配对弧 \(q(w)\) 到 \(T_p=q(1)\)、最后沿弦返回所围的面积。以 \(T_a\) 作 Green 积分原点，直段和闭弦的贡献为零，所以

\[
 |K_0|=U_{199}^{\rm host}+A_{199}^{\rm AH}
       -\tfrac12\int_0^1\det(q(w)-T_a,q'(w))\,dw.
\]

复用有导数余项的 128 段 Taylor 积分，在 160 位 Arb 中检验

\[
 |K_0|>0.8439741301130277,\qquad |T_p-T_a|^2>0.01007656807905897.
\]

凸性与 \(0,Z\) 的严格异侧行列式决定弦的保留侧，后面所加的材料全在另一侧。[第199轮面积](../computation/flexible-006-eleven-eh.json)

### 从定宽体抽取必在宿主中的有理点

取 117 个有理参数的 Reuleaux 五边形、31 个分段常数曲率半径的常宽体、一个镜面对称常宽体及其十三圆弧版本，共 150 个独立测试体。前 105 个五边形用第211轮的整盒相容证书，其余 12 个当场做全部开扇和两个端角的认证。曲率输入重新解闭合线性系统，验证 \(0\le\rho\le1\)，并重算整个六十度开扇的符号。两个镜面对称输入使用第207轮的相容角与镜像证书。[五边形](../computation/nonideal-pentagon-library.json) · [额外十二个五边形](../computation/nonmonotone-pentagon-inputs.json) · [镜面对称构造](../computation/ah-tapered-mirror-counterexample-audit.json)

由于每个测试体的六法向支撑都是半宽，容纳它的宽一六边形必须在每个方向双边相切。相容零点已由上述输入逐体隔离，居中平移唯一。逐姿态测试两斜帽，只有严格超出 \(1/2+\eta\) 才能删去该姿态。对每个保留下的姿态，用 1081 个法向取真正的支撑点。分段边界在一格中可能遇到切换时可以跳过该方向，保留的每个点都是该输入的材料。当法向为 \(n\) 时，用支撑函数及其角导数写成 \(h(n)n+h'(n)Jn\)。反射使角导数反号。

取 \(v=T_p-T_a\)，对外帽上的一点 \(X\) 设

\[
 x=\frac{v\cdot(X-T_a)}{|v|^2},\qquad y=-\frac{\det(v,X-T_a)}{|v|^2}>0 .
\]

两弦端此时为 \((0,0),(1,0)\)。若这个姿态可放，则三点的实三角形包含在 \(C\) 中。任取严格较低的有理高度 \(Y\)，令 \(t=Y/y\)。用区间严格验证格点 \(X_0\) 满足 \(tx<X_0<tx+1-t\)，便有 \((X_0,Y)\in C\)。所有有理格点坐标共同分母为 \(10^{11}\)。因此面积只从三角形内部取下界，计算精度和法向取样密度只影响结果的强弱。

### 所有姿态选择的面积比较

每个测试体有若干种可能放置，每种放置给出弦外的一个有理凸多边形。按测试体依次从每组选择一个，把它与当前所有已选点取凸包。全程以整数行列式求凸包和两倍面积。若某个选择已包含在当前凸包中，其他选择得到的凸包都含有这一分支，以后作相同选择仍保持包含关系，故保留该最小分支已经足够。若整数面积加上基底下端已经超过比较门槛，可记下这一支的下端并结束该支。最后取所有提前结束分支与末层保留分支下端的最小值。任何实际万能覆盖都以某种可行姿态容纳每一个测试体，因而面积至少达到这一比较值。

以 \(.844081861\) 作剪枝门槛，处理 150 组、3602 个中间状态，末层有 12 个状态尚低于剪枝门槛。对它们逐一求面积得到定理中的严格界。严格性来自 \(|K_0|\) 的有理下端和外帽面积的精确整数比较。[整数证书及逐层计数](../computation/nonmonotone-ah-core.json)

复算使用 Python 3.13.18、python-flint 0.9.0。在课题目录运行

```sh
python -B computation/certify_nonmonotone_ah_core.py computation output.json
```

将两条斜帽进一步放宽时，程序把新准入的姿态重新送入凸包分支。同一方法还证明下表，\(\eta\) 是两条斜帽各自允许的最大外移量。

| \(\eta\) | 法向数 | 宿主面积严格下端 |
|---:|---:|---:|
| \(.00001\) | 481 | .84408161880167059706384 |
| \(.00010\) | 361 | .84407995631598351436874 |

第一行以 \(.84408160\) 剪枝，84 组已经足够结束所有分支。第二行以 \(.8440800\) 剪枝，最后一个保留分支的实际有理下端略低于剪枝值。[第一行回执](../computation/nonmonotone-ah-core-medium.json) · [第二行回执](../computation/nonmonotone-ah-core-wide.json)

```sh
python -B computation/certify_nonmonotone_ah_core.py computation medium.json --cap-shift .00001 --steps 240 --target .84408160
python -B computation/certify_nonmonotone_ah_core.py computation wide.json --cap-shift .00010 --steps 180 --target .8440800
```

### 固定深裁线时的进一步限制

若保持原 \(m_3,m_5,H\) 并要求 \(C\) 位于转角 \(\delta=.01262\) 的 AH 内半平面，则万能性强制铰点 \(p<.83331\)。这里不要求 \(C\) 含有 \(K_0\)。取非理想五边形 \((w,e)=(.77347,.03012)\)，按同样的全角证明用 247 个闭格和端点符号排除其他连续角。两个未被斜帽排除的姿态在 \(p=.83331\) 处均越过新线，较小的超出量仍大于 \(1.24048\,10^{-9}\)。该线切高对 \(p\) 的导数小于 \(-.000488424\)，故同一例子排除所有更大的铰点。[反例与导数证书](../computation/pentagon-deep-pivot-certificate.json)

# 0.83731 五体定位与可迁移的整叶整数分数

令 $T=0.83731$。标准五体的规范放置若面积至多 $T$，必落在最终列出的 **614 个原闭叶** 中，分属 26 片。起始域由原始规范叶和早已认证的整叶分数重新构造。旧 $0.83730$ 的 541 个原叶全部包含在新清单内，新清单另有 73 叶。

## 径向截断与初始域

对每个正定宽多边形 $B_n$，固定平移方向后记 $f(d)$ 为圆盘与移动后 $B_n$ 的共同凸包面积。凸包的截面长度对该平移变量凸，积分得 $f$ 凸。中心重合时，圆盘外只剩顶点及其两条相切连接，直接积分得到
$$
 f(0)=\frac{\pi}{4}+\frac n4\left(\tan \frac{\pi}{2n}-\frac{\pi}{2n}\right).
$$
第107轮的数据对每个方向给出 $f(r)\ge L$。取严格有理上端 $U\ge f(0)$ 且 $U<L$，则在 $d\ge r$ 时
$$
 f(d)\ge L+(d/r-1)(L-U).
$$
因此不用重新跑旧圆周证书，也可将各半径外移至新的需要值。仅为 $0.83731$ 时，分母 $2^{44}$ 的四个外半径分子分别为
$$
 1202425916136,\quad1169954722363,\quad1056337023647,\quad1002716102351.
$$
实际几何重放采用能统一跨越 $0.83732$ 的略宽半径
$$
 1202425916136,\quad1170258912492,\quad1056570804948,\quad1002925546042.
$$
两组半径在原叶初筛所得保留位置逐片相同。后一组的径向面积下端仍有整数余量，可用于继续抬靶。

直接重比较第113轮公开分数时，整叶分数 $b\ge2101$ 蕴含绝对整数下端至少为 $120669088127794881$，单位 $2^{-57}$，略大于 $T$。在全部 6,710,314 个规范原叶中，这一比较排除 5,647,793 叶。新径向截断再排除 4,662 叶，剩余 1,057,859 叶。截断是在原树上实算，已有的 501 和 541 清单不参与筛选。原树根域之外由相应径向界及角对称归一化排除。

## 四层几何与整叶分数

对每个仍活跃的原节点，使用冻结的五体整数扇和同体圆弓下界。在第123轮公开核的基础上暴露真正通过比较的整数下端。所有新子盒沿原坐标闭二分。一个原叶通过时，截断内分数取全部通过的子盒的最小整数下端。由更上层原节点直接接受时，其下端用于该节点下的相应活跃叶。

若某个平移坐标边界因径向条件而裁缩，则从闭盒移去的点必有至少一体在对应圆盘之外。把截断内分数与发生剪裁的各体的径向面积整数下端取最小值，才得到完整原叶的分数。若只有五边形角域的规范化裁切，则不需径向修正。若整个节点因径向条件而空，整叶只登记经验证的径向下端。归档分别保存原叶完整分数和截断内分数。跨目标比较只用完整分数。

## 复算

令 MAIN 为拥有第107、113、123轮冻结输入的计算目录，TREE 为原 cert11d_08366，TABLE 为已验证 32 等分母材料表，WORK 与 CACHE 分别为独立工作目录和 Clang 共享模块目录。在本计算目录执行

    python -B select_tomar_083731_scores.py MAIN TREE WORK/init CACHE \
      --emit WORK/seeds > WORK/seed-audit.json
    python -B replay_tomar_083731_scored.py MAIN TREE TABLE WORK/seeds \
      WORK/seed-audit.json WORK/scored CACHE --workers 3

第一条只用原树、已有分数、旧径向证书及新凸外推。第二条重新验证母表，然后进行完整四层。可用 --parts 240 重放一个有实际尾叶的分片。全量计算使用本机 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 和 Apple Clang 21.0.0。整数编译启用溢出停止。第二套环境从原树重建了整域初筛，并重新编译重算第240片的四层，结果分别与相应存档逐字节一致。

要迁移下一靶，可先独立生成其初筛，再用四层归档审计完整整数分数：

    python -B select_tomar_083731_scores.py MAIN TREE WORK/init-next CACHE \
      --target .83732 --radius-target .83732 --emit WORK/seeds-next > WORK/seed-audit-next.json
    python -B audit_tomar_083731_score_layers.py WORK/scored \
      WORK/seeds WORK/seed-audit.json WORK/seeds-next WORK/seed-audit-next.json \
      --next-emit WORK/unresolved-next

允许用四个分卷解包后替代 WORK/scored 的逐层数组。须同时放入对应的 stage-ledger.json 和 retained.json。审计逐片检查来源哈希、四层集合差、整数下端、径向帽上限和至下一靶的提升。解包后的分卷实际完成这一审计，结果与运行目录相同。

第六输入的具体几何不参与这里的定位，因此同一清单可交给三十点与固定光滑体的各自面积验证。

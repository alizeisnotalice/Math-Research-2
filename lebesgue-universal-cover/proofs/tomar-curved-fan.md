# 同体弦与圆扇形的面积增量

在圆盘 D 与四个正 Reuleaux 体的十一维放置空间中，沿用整数扇形法的见证坐标与有向边测试。下述改进对每个通过方向检查的同体边单独计入一块额外面积。不同边位于互不重叠的有向角楔内。

## 单位盘交中的中点

令 a,b 属于若干单位圆盘的交，v=b−a，L=|v|。每个定义圆心 c 都满足

    |(a+b)/2−c|² = (|a−c|²+|b−c|²)/2 − L²/4 ≤ 1−L²/4.

故以弦中点为中心、半径 L²/8 的闭圆盘包含在原盘交内。对逆时针扇边 a→b，设 z=det(a,b)>0，Z 是 z 的下界，P 同时控制 |a| 与 |b|。取

    0 ≤ κ ≤ min{L/8, Z/(4PL)}，  m=(a+b)/2−κJv，  J(x,y)=(−y,x).

中点内盘包含 m。两相邻行列式分别为 z/2−κ a·v 与 z/2+κ b·v，均至少为 z/4。于是 m 在 a,b 的开角楔内，且在有向弦外侧。把原三角形替换为两块经 m 的三角形，两倍面积净增 κL²。弦长来自同一体上的两个固定局部坐标，对该体的旋转与平移保持不变。代码从原方向检查得到 Z，用向上取整的扰动估计得到 P，对 κ 与两倍面积增量一律向下取整。

## 固定圆盘的边

若两端属于圆心为原点、半径 1/2 的固定圆盘，其角楔内整个圆扇形均可使用。设夹角为 α∈(0,π)，两个端点均在圆盘里，有 4 det(a,b)≤sin α。由 arcsin(s)≥s+s³/6 可得 α≥sin α+sin³α/6，因此两倍面积相对弦三角形的增量至少为 (4det(a,b))³/24。程序在 Q=2²⁸ 尺度先将 4det(a,b) 的长度单位向下取整，再乘方。旋转体使用上一节的中点法。

新增计算中单位弦长平方至多 8Q²，平方根用浮点数提供初值，再用整数平方逐项校正。对同体边，方向测试保留的 Z 不超过 8Q²。κ 的未除分子不超过 8Q³，面积增量的未除分子也由 8Q³ 控制。定圆分支的 sine 不超过 Q，故三次方不超过 Q³。所有这些中间积均用有符号 128 位；其余界同原整数扇形证明。

## 抛物带形式

对 s∈[0,1] 设 x_s=a+sv。恒等式

    |x_s−c|² = (1−s)|a−c|²+s|b−c|²−s(1−s)L²

给出半径 s(1−s)L²/2 的内圆盘。取 k≤min{L/2,Z/(PL)}，则整条带

    x_s−uJv， 0≤s≤1，0≤u≤k s(1−s)

属于单位盘交并位于弦的外侧。点相对 a 与 b 两射线的行列式分别至少是 sz−k s(1−s)PL 与 (1−s)z−k s(1−s)PL，进一步至少为 s²z 和 (1−s)²z。映射 (s,u) 的雅可比绝对值为 L²，故可额外计入两倍面积 kL²/3。归档程序 tomar_parabolic_fan.cpp 对定圆边采用圆扇增量，对其余满足同体条件的边采用本节的抛物带下界。

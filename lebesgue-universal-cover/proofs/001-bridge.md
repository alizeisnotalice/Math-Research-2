# 第1轮：有限测试族、有效网及加强的面积误差

对象：D=(1/2)B 为直径1闭圆盘；所有覆盖均为平面紧凸集；允许 O(2) 与平移。
Λ 是覆盖所有直径≤1集合的面积下确界。以下为本轮解析证明，不宣称文献新颖性。

## 1. 归一化与最优值存在

非空有限直径集合的闭凸包紧，直径不增加。令 X 为含0且直径≤1的非空紧凸集。
每个此类集合都属于单位圆盘 B；Hausdorff 极限保留凸性、含0及直径约束，故由
Blaschke 选择定理 X 紧。任意目标可平移到 X。单位正方形容纳任意此目标的某个
平移（各坐标宽度≤1），故 Λ≤1；容纳 D 又给 Λ≥π/4。

固定有限 F⊂X 并加入 D。任何可行 C 先把其所含 D 的圆心移到0。
对 x∈C，取 D 中垂直于 x 的直径端点 a,b；三角形 abx 面积为 |x|/2。
因此 |x|≤2|C|，即 C⊂2|C|B。

取面积趋于 m(F) 的可行序列 C_j，舍去初始项后面积有统一上界 M。
由上式及 Blaschke 可选 C_j→C。对每个 K_i∈F，选 R_ij K_i+t_ij⊂C_j。
因0∈K_i，t_ij∈C_j；O(2)紧，平移有界，有限次取子列可得每个放置收敛。
极限放置包含于 C，故 C 可行。凸紧集面积的 Hausdorff 连续性给 |C|=m(F)。

同理 Λ 本身达到：对万能覆盖的极小化序列先取覆盖集的同一收敛子列；然后对
每个固定 K∈X 分别选放置参数的收敛子列即可。子列可以依赖 K，因极限 C 已固定，
得到 ∀K∃放置，无需一个同时适用于不可数多个 K 的参数子列。故极限 C 万能。

## 2. 更强的周长估计

若 rB⊂C，则凸体边界几乎处处具有外单位法向 ν，且 x·ν=h_C(ν)≥r。
Gauss–Green 公式（凸体为 Lipschitz 域）给

    2|C| = ∫_{∂C} x·ν dH¹ ≥ r P(C).

取 r=1/2，得到 P(C)≤4|C|。该估计适用于带角点的凸体；圆盘取等。
于是它比先外接到半径2|C|圆盘再使用周长单调性更强。

## 3. 桥接

取 X 的有限 Hausdorff δ网 Fδ 并加入 D，令 Cδ 为最小覆盖，mδ=|Cδ|。
对任意 K∈X 选网点 F 与合法放置 gF⊂Cδ；等距保持 Hausdorff 距离，故
 gK⊂Cδ+δB。该外平行体仍紧凸，且是万能覆盖。
Steiner 公式因此给出

    mδ ≤ Λ ≤ mδ + δP(Cδ) + πδ² ≤ mδ + 4mδδ + πδ².  (1)

这加强了附件中的 4πmδδ。注意有限族中每个形状分别选择放置；不要求这些副本
互不重叠，也不能把它们的放置独立性误换成共同旋转。

## 4. 有理、明确但规模巨大的有限网

取 n≥1，h=1/n，G_n={(i/n,j/n): -n≤i,j≤n}。枚举所有含0的子集 Q⊂G_n，
只保留满足 diam Q≤1+2h 的子集。这个判据用坐标平方距离即可作有理精确判定。
定义 F_Q=(1+2h)^(-1)conv Q；所有 F_Q 含0且直径≤1，因此属于 X。

给定 K∈X，逐坐标最近舍入（平局固定规则）到 G_n，令 Q 为全部舍入像。
Q 有限且含0，舍入误差至多 h/√2≤h，故 d_H(K,Q)≤h 且 diam Q≤1+2h。
设 P=conv Q。因 K 凸，K⊂P+hB 且 P⊂K+hB，故 d_H(K,P)≤h；又 P⊂(1+h)B。
缩放的逐点位移至多

    (1−1/(1+2h))(1+h) = 2h(1+h)/(1+2h) ≤ 2h.

故 d_H(K,F_Q)≤3h。上述有限族加 D 即明确的 δ_n=3/n 网。
设其最小覆盖面积为 m_n，(1) 给

    0≤Λ−m_n≤12m_n/n+9π/n²≤12/n+9π/n².

若需单调层级，取前 n 个网的并集再加 D；其最优值单调，仍服从当前 n 的误差界。
此枚举法有效但指数规模极大，不作为实用优化算法；本轮没有枚举 n≥2 的全部子集。

## 5. 数值证书接口与精确值障碍

若有限族的全局认证下界为 L，且一个明确可行覆盖的认证面积上界为 U，则

    L ≤ Λ ≤ U+4Uδ+πδ².

总间隙包含有限优化误差 U−L 和网逼近误差，不能省略前者。取 U≤1、δ=3/n，
对0<ε≤1，n≥ceil(24/ε) 可保守确保 4δ+πδ²≤ε（使用 π<4）。
这是网误差预算，不意味着有限优化误差也已解决。

有限族最优覆盖的存在、Λ的达到和有限网收敛，均不推出某个有限族的最优值等于Λ。
尚需候选的全局万能性与等面积一般下界；本轮没有给出这两项的匹配。

## 6. 计算的角色

computation/check_bridge.py 使用 Fraction 精确核对101个含D的有理法向多边形，
包括一个面积5/6、周长10/3的等号案例；核对n=1全256个含0子集以及n=2至多
两个非零点的255个合法子集；核对4组误差预算。通用定理由以上证明承担。
该面积5/6多边形并未被证明万能，不是改进的全局上界。

# X18 在较低面积五体宿主中的摆放

取第153轮的显式有理十八点反例 \(X_{18}\)，其相对于第145轮所检验的宿主的包含极小性已在第156轮核验。\(X_{18}\) 在下列五体凸包中均有保持手性与反转手性的严格有理摆放。表中的余量是到所用有理内多边形每条支撑线的严格距离下界。

| 固定宿主 | 保持手性 | 反转手性 |
| --- | ---: | ---: |
| 第155轮 P30 自由摆放的五体凸包 | \(7.30814\times10^{-4}\) | \(2.05291\times10^{-4}\) |
| 第99轮五体接触图的驻点隔离盒 | \(3.58556\times10^{-5}\) | \(1.3547089\times10^{-4}\) |
| 第102轮五体原坐标接触盒的中心 | \(3.58556\times10^{-5}\) | \(1.3547089\times10^{-4}\) |
| 第108轮五体逃逸宿主 | \(4.06461\times10^{-4}\) | \(5.96205\times10^{-4}\) |

第155轮的 P30 与 \(X_{18}\) 可独立放进同一个五体凸包，因此同时采用这两个有限输入仍有该轮的上端 \(0.83751202822\)。只在原五体上另加 \(X_{18}\) 时，它甚至进入第99轮面积约 \(0.837295006221025243\) 的局部极小摆放，其凸包面积保持原值。

## 有理内多边形加严格摆放

在每个曲体的每条半径一圆弧上取 128 等分点，直径一圆盘另取 1024 等角点。第99轮的接触图用隔离盒内的两个角直接求出各体参数，在这一整盒内同时核对曲线样点的坐标。对每个样点，160 位以上 Arb 逐分量保证取整至 \(10^{-12}\) 网格的误差严格小于 \(10^{-12}\)。整数凸包换回坐标后，包含于真实宿主 \(H\) 的半径 \(2\times10^{-12}\) 外平行体。又因为 \(\frac12B\subset H\)，凸性给出

\[
H+2\cdot10^{-12}B\subset(1+4\cdot10^{-12})H.
\]

由此把整数凸包的公共分母取为 \(10^{12}+4\)，所得有理内多边形完整地落在 \(H\) 中。各有理旋转用半角切确定，逐一检验 \(c^2+s^2=1\)，平移也是有理数。逐边取 \(X_{18}\) 中 18 个像的最大投影，并用整数平方根的向上取整控制边法向的模长。于是每个正的分数余量同时证明了对真实曲边宿主的严格包含。

## 整个第102轮接触盒

保持第102轮中心的反射摆放。对旧五体任一允许的原坐标扰动，用平移的最大欧氏位移及支撑函数的转角余量估计 Hausdorff 偏差。对 \(B_3\) 只需支付平移；对 \(B_5,B_7,B_9\) 的转角 Lipschitz 常数分别小于 \(0.163,0.115,0.089\)。取 \(1.415>\sqrt2\)，从第102轮原坐标半宽直接得整个盒上 \(d_H(H,H_0)\le 8.679\times10^{-5}\)。扣除该值后，同一个 \(X_{18}\) 放置仍有严格大于 \(4.86808\times10^{-5}\) 的余量。故该接触盒内所有摆放的五体凸包都能独立容纳这一第六输入。

这两类宿主给出了严格容纳，未出现需要向外扩展的正距离，因此本次没有启动 \(0.83740\) 的原叶批算。

## 复算

`x18-lower-host-placement-input.json` 保存每个宿主两种手性的有理姿态。回执包含各个严格分数下界以及所用第99、102、108、155轮材料的 SHA256。从含归档材料的课题目录运行

```sh
python -B computation/certify_x18_lower_hosts.py computation \
  computation/widened-projected-obstruction-18-points.json \
  computation/x18-lower-host-placement-input.json OUTPUT.json
```

实际重放用 Python 3.13.18 与 python-flint 0.9.0，验证阶段不调用 SciPy。

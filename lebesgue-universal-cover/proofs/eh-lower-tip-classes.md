# 近下端的一般定宽体：三类符号的共同放置

记 \(V=U_{0.00055845}, T_\alpha=B_3+R_\alpha(T-B_3)\)。设定宽一体 \(K\subset P\) 有点 \(z\) 满足 \(|z-T|\le5\times10^{-7}\)。帽命中均指正投影严格超过 \(1/2\)。满足下列三条中的任一条，即可找到一个摆放进入 \(P\)、避旧 AH 并满足全部 \(VT_\alpha\) 的保留半平面，\(0\le\alpha\le0.0009\)：

1. \(K\) 避开 \(F'\)。
2. \(K\) 命中 \(F'\)，并避开正 \(A\)。
3. \(K\) 命中 \(F'\) 和正 \(A\)，并避开 \(D'\)。

对 \(p_A=0.427,\delta_A=0.00205\) 的扩大 AH，三类在 \(0\le\alpha\le0.00002\) 也有满足全部支撑的同一摆放。此结论对上述各类中的所有定宽体成立。剩余的近下端类是 \(F',A,D'\) 同时命中；一般改界还须处理实际新帽所在范围及全部原有放置。

## 从近接触算出两个支撑锚点

写 \(r=5\times10^{-7}\)。\(E'\) 法向对 \(z\) 的余量大于 0.0067656，所以 \(K\) 必避对面的闭 \(B'\)。若 \(K\) 避开 \(F'\)，则正 F 线段上的强制接触在 \([F_3,R]\)。取 CB 接触 \(b=(1/2,b_y)\)。由 \(K\subset P\) 有 \(b_y\ge (C_3)_y\)。若 \(b_y<S_y\)，则对整个 \([F_3,R]\) 的最近点为 \(R\)，且 \(|b-R|>1\)；最近点断言在 \(C_3,S\) 两端按仿射点积核验，矛盾。于是 \(b_y\ge S_y\)。由 \(|b-T|\le1+r\) 和 \(|S-T|=1\)，

\[
 0\le b_y-S_y\le\frac{2r+r^2}{2(S_y-T_y)}<1.533946\times10^{-5}.
\]

另一项估计对三类均成立。取 \(a=B_3+t e\in K\cap[B_3,B_2]\)，其中 \(e\) 为指向 \(B_2\) 的单位向量。由 \(|a-T|\le 1+r\)、\(|B_3-T|=1\)，

\[
 0\le t\le\tau=\frac{2r+r^2}{2(B_3-T)\cdot e}<3.667982\times10^{-5}.
\]
取 \(n_1\) 方向的支撑点 \(q\)。因 \(q-n_1\in K\) 且 \(|a-(q-n_1)|\le1\)，有 \(|a-q|^2\le2(1/2-n_1\cdot a)\)。从而 \(q-n_1\) 与 \(B_3-n_1\) 距离不超过 \(\tau+\sqrt{2\tau|e\cdot n_1|}<0.005949\)。

令 \(J(x,y)=(x,-y)\)，\(W=R_{120^\circ}=Q_AJ\)。第一类中，用 \(b\) 为圆心的单位圆盘包住 \(K\)，故 \(JK\) 在 \(VT_0,VT_{0.0009}\) 的支撑余量分别超过 0.01271、0.01982。对所有三类，用 \(q-n_1\) 为圆心的单位圆盘求得 \(WK\) 在两端弦的余量分别超过 0.00782、0.01571。中间各弦共顶点 \(V\)，角度严格单调且同属锐角扇，因此端法向的正组合覆盖所有中间方向。

## 三类共同摆放

第一类中，\(J\) 把正 E、正 C 的原像分别放在 \(F',B'\)，故 \(JK\subset P\)。当它命中旧 AH，触发 \(Q_A\) 后，\(WK\subset P\) 且避旧 AH。两姿态均满足所需 EH 弦。在第二类中，\(W\) 把正 E、正 C 的原像放在正 A、正 E，故 \(WK\subset P\)。若它命中 AH，触发又会迫使 \(Q_AWK=JK\subset P\)；但 \(K\) 命中 \(F'\) 使 \(JK\) 违反正 E，矛盾。因此可直接选 \(WK\)。该推理同样适用于具有相同触发的扩大 AH。

第三类中，\(Q_2\) 把正 E、正 C 的原像放在 \(B',D'\)，所以 \(Q_2K\subset P\)。原体命中 A 而避正 D，故 \(Q_2K\) 避 \(C'\)，自动避 AH。若 \(Q_2K\) 含某个违反 \(VT_\alpha\) 的点 \(z'\)，则该点在两段真圆弧和弦围成的耳内，坐标位于 \([V_x,T_{0.0009,x}]\times[T_{0.0009,y},V_y]\)。记 Pál 外法向 \(p=u(7\pi/6)\)，\(Q_2p=-p\)。由该矩形及 \(|z-T|\le r\) 直接算得 \(p\cdot z+p\cdot z'>1.0024047\)。两点 \(z,Q_2z'\) 同属 \(K\)，违反直径一。于是第三类也全部通过。

第一类应用扩大 AH 时，若 \(JK,WK\) 都命中扩大帽，使用其共根姿态。若它违反新弦，取该耳内一点 \(y\)，设 \(L=|V-T|\)。对 \(0\le\alpha\le h=0.00002\)，矩形给 \(|y-V|\le L+h, |y-T|\le L+2h\)。旧深度 \(0.000555\) 与 \(VT\) 共用 \(T\)，而 \(VT\) 和 \(VT_\alpha\) 共用 \(V\)。记前两条弦的单位外法向为 \(n_U,n_V\)。因 \(|T_\alpha-T|\le h\)，最后一步的单位法向变化至多 \(2h/(L-h)\)。共同根姿态的总支撑损失上界为

\[
 |n_U-n_V|(L+2h)+\frac{2h(L+h)}{L-h}<4.037352\times10^{-5}.
\]

程序合并 AH 普通格和根条件格，核对全部68个非零参考格，扣减后余量仍大于 \(1.53668\times10^{-5}\)。故扩大的 AH 和各真边界仍在同一姿态成立。

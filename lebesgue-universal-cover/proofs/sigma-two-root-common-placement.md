# 两个斜角处八锚定宽补全的共同摆放

在 \(\sigma=1.54^\circ\) 或 \(1.5497^\circ\) 取第198轮八锚族，\(w\in[.42849,.42851]\)。从 Gibbs 的真弧边界得到宿主，将 AH 直线在 \(Z+.429(T_a-Z)\) 处内转 \(.009\) 弧度，EH 采用第199轮十一段轮廓的同参数重建。任何包含该八锚的定宽一体，在下表中两个互不相交的相容根括各有一个摆放进入同一个完整宿主。两次使用同一个姿态规则 \(U=F_yR_{300^\circ-\phi}\)，其中 \(F_y(x,y)=(x,-y)\)，再由两条独立正六边形支撑线求唯一平移。

## 同一个相容根上的支撑

每个闭 \(w\) 区间分为32格，用第198轮的八锚支持下界验证各根括端点。定宽恒等式给出 \(F(\phi+60^\circ)=-F(\phi)\)，由此得到负号端的上界。每个固定补全在两端有异号，故每个根括内都有相容根。六面支撑相容关系在反序时仍成立。由于 \(n_0+n_2+n_4=0\)，在根处用 \(n_0,n_2\) 恢复平移后，第三个支撑值也等于半宽，定宽再给出相反三面。

以五个循环锚 \(v_i\) 为圆心的单位圆盘交包住任何该输入的定宽补全。其单位法向极值点或是某个 \(v_i+u\)，或是两单位圆的交点。逐格枚举并用其余圆盘删去确定不可行的点，得到补全支撑的共同有向上界。下界用八锚投影及反向顶点扇。将两边界值在同一角括内用于平移的线性表达式，不独立选择不同姿态。每根括验证16个闭 \(w\) 格，每格32半平面，直接盖住该格与整个根括的笛卡尔积。32行包含 \(m_3,m_5\)、保留的 \(ZT_a\)、新 AH 线、\(Y\to T_a\) 内弦、非圆配对弧的16条内弦及11条 EH 线。所有这些行在同一姿态下有表中的严格下界。

## 真边界与内弦替换

用单位圆和 Green 公式中的相同端点构造完整有向边界。六条线和圆弧端点闭合。非圆配对曲线 \(q\) 在131072格的全参数区间上验证 \(q'_x,q'_y<0\) 和 \(\det(q',q'')>0\)。每个弧和每一处非切向拼接的切线严格向左转，其角度均由有向区间算出。零角拼接在 \(Q,T_a,T'=q(1),P,H,I,K\)，其中 \(Q,P,H,I,K\) 都是对相应支撑线的正交投影。\(T_a\) 是从 \(Z\) 向镜像圆引出的切点。第198轮的端点几何给出 \(L(1)=c,b(1)=G\)。对 \(|Z+wD-L(w)|=1\) 在 \(w=1\) 求导，由 \((T_a-c)\cdot D=0\) 及 \((T_a-c)\cdot e_L>0\) 得到 \(L'(1)=0\) 和 \(b'(1)=0\)。对 \(|q(w)-b(w)|=1\) 求导便得 \((T'-G)\cdot q'(1)=0\)。程序另验这七处的相接方向内积为正。各角之和在 \((\pi,3\pi)\)，闭曲线回到同一方向，故总转角为 \(2\pi\)。

转向单调的闭曲线在每个边界点都支撑自己的凸包。具体而言，以该处的外法向投影，沿走向的导数先非正、后非负。投影最终回到起值，此值就是最大值。各方向的支撑点由曲段及凸角法锥覆盖，因而该轮廓给出凸宿主。以弦替换 \(Y\to T_a\) 和非圆配对弧的部分，得到完整宿主中的凸内近似。内近似只增添上述17条内弦作为支撑线。

仍须满足继承的5段 Sprague 真弧。对已通过两条斜帽线的定宽体，正六边形支撑将它置入 \(P(\sigma)\)。由第90轮的强制接触线段，圆心 \(a\) 的相应线段上存在 \(v\in K\)，且弧的任一单位径向 \(u\) 满足 \(u\cdot(v-a)\le0\)。所以 \(h_K(u)\le1+u\cdot a\)。在两个斜角处独立核验该论证的五个严格端径向符号，并核查新弧为原短弧的子弧。共同姿态因而进入包含全部真弧与十一 EH 线的宿主。

这个结论覆盖表中两档斜角及指定 \(w\) 区间的所有八锚补全。第198轮在 \(1.56^\circ\) 的无内根结果和本轮比较互补。对更一般的直径一输入，仍需重建变斜角下的分支覆盖。

## 复现

以有 NumPy 与 python-flint 的 Python 执行。把脚本和冻结回执放入课题的 computation 后，脚本从同目录读取其余原件。独立试验目录也可把原件放在脚本旁的 upstream 目录。

    python -B computation/certify_two_sigma_ideal_placement.py OUTPUT.json

回执记录各依赖散列、凸性格数、根端格数及支撑余量。Metal 的角格用于找到窄根括，区间证明不读取 Metal 输出。

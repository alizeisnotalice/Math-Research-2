# 不等角七体的混合谐波扩展

沿用第65轮三个非等角七体放置。每个配置的七个体中已包括 \(B_9\)，两光滑体用第55轮系数。新增测试体 \(K_+\) 的支撑函数是
\[
h_+(\theta)=\tfrac12+\tfrac1{80}\cos(3\theta)+\tfrac{13}{800}\cos(5\theta).
\]
曲率半径 \(h_++h_+''\ge1/100\)。因此 \(p=h_+u+h_+'Ju\) 确定光滑严格凸的边界，\(h_+\) 是其支撑函数。两项谐波为奇次，故定宽一。支撑函数为偶函数，镜像放置可以吸收到旋转。

## 原三个宿主的全角、全平移下界

对任一原宿主 \(C\)，有理样点凸包 \(H\subset C+\eta B\)，\(\eta=2/10^{12}\)，其中 \(B\) 为单位盘。原点圆盘 \((1/2)B\subset C\) 给出 \(P=H/(1+2\eta)\subset C\)。脚本对第65轮的转角端点重新核验严格异号，从每个整根区间包络真实样点。因而内包含对每个括区内的任何合法根成立。

新增体包含 \(0.47B\)，支持角 Lipschitz 常数为 \(19/160\)。对整圈比例区间 \([a,b]\)，将本体的有理边界样点旋转到格中点，重新取整。两步取整及角变化带来的支持误差由
\[
c=4/10^{12}+(19/160)(22/7)(b-a)
\]
控制。将所得样点凸包乘 \(0.47/(0.47+c)\)，得到整格所有新增转角共同包含的内多边形 \(Q\)。

固定 \(P,Q\)，\(A(t)=|\operatorname{conv}(P\cup(Q+t))|\) 关于 \(t\) 凸。沿任一直线改变平移，对垂直该线的任一固定高度，许可的基点与凸组合权重保持不变，截面右端为仿射函数族的上确界，左端为下确界，故截面长度凸。积分给出 \(A\) 的凸性。

在有理平移点 \(t_0\) 选取严格凸的整数凸包顶点循环，保留每点的固定或移动标签。顶点循环在 \(t_0\) 邻域内仍为凸多边形。其鞋带面积对平移为仿射，且在 \(t_0\) 恰等于 \(A(t_0)\)，所以此仿射式是 \(A\) 的全局下界。每格保存若干这样的平移点及正整数权重。权重归一后，加权仿射式在 \([-1/4,1/4]^2\) 的最小值为
\[
\sum_j w_j\beta_j-\tfrac14\big\|\sum_jw_j g_j\big\|_1.
\]
方框外 \(K_++t\) 的内圆盘含距原点大于 \(0.72\) 的点，与原点盘本身的凸包已超过目标。各格的有理加权值严格超过 \(0.8386\)，角格依次无缝覆盖整圈。其中三个宿主的角格数分别为 86、119、94。

如果旧放置每个角和平移坐标独立扰动至多 \(1/12000\)，共同圆盘保持固定，旧七体的 Hausdorff 扰动至多 \(\rho=(99/70+29/100)/12000\)。正 Reuleaux 体的支撑角斜率至多其半顶点角的正切的一半，两旧谐波体用各项斜率之和。旧测试体支撑角 Lipschitz 常数均至多 \(0.29\)。对扰动前后的配置加入同一个新增体副本，由 Steiner 公式及 \(P(C)\le4|C|\)，扰动后面积至少为 \((0.8386-\pi\rho^2)/(1+4\rho)>0.83812\)。以上结论允许新的凸包超过原夹带。

## 单点预算与自由重排

对第三个宿主，输入指定 \(K_+\) 的一个确定放置。宿主取第55轮弦误差的有理外包 \(H+\varepsilon B\)，新增体取有理样点凸包再外扩一个小正方形，得到其外多边形 \(V\)。对 \(V\) 的每个顶点 \(y\)，使用 \(H\) 所有可见边与 \(y\) 的三角形面积之和计算 \(|\operatorname{conv}(H\cup\{y\})|\)。由整数半径检验，其周长小于4，故加上 \(4\varepsilon+(22/7)\varepsilon^2\) 给出真实单点增广面积上界。对 \(V\) 全部 2052 个顶点的最大上界小于 \(0.83799238\)。单点增广面积关于 \(y\) 凸，同一上界因而适用于整副本所有点。这个副本进入预算 \(0.83809903\) 的单点照明体，而整副本一起加入的面积仍大于 \(0.8386\)。

若共同改变旧七体与 \(K_+\) 的放置，则有一个自由八体凸包面积严格小于 \(0.837723081\)。输入的二十个精确十进制按 \(B_3\) 的两个平移、\(B_5,B_7,B_9,K_+,K_5,K_8\) 各自的角与平移排列。用第55轮曲线采样与双侧 Steiner 比较核算，\(K_+\) 取 \(16K\) 个样点，其二阶导范数小于3，仍适用第55轮统一弦差。这里是明确可行上端。原三个宿主的下界属于固定位置，从中不能得出一般下界的提高。

## 复现

在仓库根目录，用含 python-flint 的 Python 执行：

    python3 -B lebesgue-universal-cover/computation/certify_harmonic_extension.py --check

脚本读取同目录的 harmonic_extension_inputs.json 和第65轮 irregular_inputs.json，复用 certify_irregular_hex.py 的支撑几何与 certify_nine.py 的采样及面积算术。角格以整数记录右端点，左端点取上一格右端点。每行平移见证按两个整数坐标加一个正整数权重排列。不含优化器搜索记录。重放仅需 Python 标准库与 python-flint，用 160 位 Arb，并逐项比较 harmonic_extension_results.json。结果中的环境版本供记录，比较不要求相同 Python 补丁版本。

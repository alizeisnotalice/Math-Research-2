# 五体整叶分数的连续门槛索引

五个曲边输入仍取单位直径圆盘和正胡勒三、五、七、九边形。用规范化原树的同一批 6,710,314 个闭叶，对任意有理数 $T\le0.83745$ 可直接筛出尚无五体面积证书越过 $T$ 的原叶。一次生成索引后，只需整数比较。$0.83735$ 的 531,023 个候选原叶包括先前 $0.83731$ 定位的全部 614 叶。此处计算五体外围成本，未对第六输入执行面积计算。

设 $A=2^{57}$ 并以 $A^{-1}$ 为面积整数单位。要严格越过 $T$，下端整数应至少为 $G(T)=\lfloor AT\rfloor+1$。每叶取以下下端的最大值。

1. 第134轮的全域五体整数下端 $120666205824033364$。
2. 第113轮逐叶桶 $b>0$ 恢复的整叶下端 $\lceil A(8371000+b-1)/10^7\rceil$。
3. $0.83731$ 四层归档对同一原叶给出的完整整数下端。
4. 下面根据原叶实际平移坐标端点计算的径向割线下端。旧截断内材料分数也独立重组。重组前后的八个测试门槛均有同一余叶数，且至 $0.83745$ 的逐叶整数排序哈希相同。

## 径向割线与原树端点

第107轮认证了每个形状在平移半径 $r$ 上的统一面积下端 $L/A$。Arb 验证四个中心重合面积均严格小于有理上端 $U/A$，这里 $U$ 向上取整至面积整数。沿任一固定平移方向，凸包面积是平移长度 $d$ 的凸函数。故当 $d\ge r$ 时，面积至少为 $[L+(d/r-1)(L-U)]/A$。

原树坐标单位为 $F^{-1}$，其中 $F=2^{44}$。令 $x$ 和 $y$ 为原叶对应两个坐标闭区间中绝对值的最小整数，取 $k=\lfloor\sqrt{x^2+y^2}\rfloor$，用 128 位整数比较验证平方根的向下舍入。若 $r=p/q$ 且 $kq\ge pF$，则该体径向整数下端为
$$
 L+\left\lfloor\frac{(kq-pF)(L-U)}{pF}\right\rfloor.
$$
对所有四体取最大值。旧截断同样用上述割线验证。旧层曾在祖先盒上用原圆盘半径裁切时，重做同一公式得到的原叶截断盒包含于祖先截断盒。因为另一坐标的绝对值下端只能增大，截断用的向上圆整边界 $\lceil\sqrt{R^2-y^2}\rceil$ 只能减小。移去区域是超出至少一个新截断坐标边界的并，四体割线在各对应边界上取最小后，与截断内旧材料下端取最小值，得到完整原叶下端。截断盒空时可直接使用针对完整叶的径向估计。

逐片重读原树文件及其 SHA-256，确认每个树根为总根相应的闭二分片，内部二分共享精确中点。五边形规范角上端为 $\pi/15$，整数裁切上端 $3684498829194/2^{44}$ 在其上方。另两旋转角原根覆盖各自完整周期。四个平移矩形的各边离原点的最小距离分别为 $3543626940416, 3570102435840, 3549661495296, 3539130646528$，共用分母 $2^{44}$。在这些最小根边界及其外侧，四体对应的保守割线面积均超过 $0.85998$。新靶 $0.83735$ 的向外截断半径分子及其面积整数下端如下。

## 复算

在计算目录运行下列命令。MAIN 包含公开的第107、113轮数据和 $0.83731$ 四层索引。TREE 是原 cert11d_08366。STAGES 可由 $0.83731$ 的公开分卷解包，并补入对应 stage-ledger.json 与 retained.json。WORK 和 CACHE 分别为独立临时目录与 Clang 共享模块缓存。

    python -B audit_tomar_multi_target_scores.py MAIN TREE STAGES WORK CACHE \
      --emit WORK/floors > WORK/report.json
    python -B audit_tomar_multi_target_scores.py query WORK/report.json WORK/floors \
      0.8373101 0.837315 0.83735
    python -B audit_tomar_multi_target_scores.py query WORK/report.json WORK/floors \
      0.83735 --part 181

每片生成的位置与面积整数是平行数组 pos 和 full_floor，均有独立哈希。整域查询直接在已排序整数向量中二分。第一次读取已核验的规范掩码与工作层输出，第二次从原树重新计算规范掩码，并读取由公开分卷重组的四层输入。两次的 1,024 片位置与整数哈希、各门槛计数以及排序哈希一致。运行环境是本机 macOS arm64、Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 及 Apple Clang 21.0.0。整数编译启用了溢出停止。

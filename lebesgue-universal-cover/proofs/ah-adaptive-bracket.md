# AH 双命中中的有向支撑误差与非对称根括

固定上轮使用的 Gibbs 角、EH 两段和真实 Sprague 边界。保留第167轮三条 AH 线，再裁一条铰点为 \(0.409995\)、转角为 \(0.00051920\) 弧度的线。所得凸万能覆盖的真实面积满足

\[
0.844093393709073433643894640415099725075 < |H| < 0.844093393709073433643894640415099725160.
\]

沿用第112、126和167轮的两次命中分类。在新增 AH 帽的全体物理闭格上重新检验图域、触发条件、端点和配对范围，求出对应直段参考格上的共同亏损上界 \(E\)。下面说明变化的双命中摆放。

## 各方向的单侧误差

把第105轮的五个理想锚点编号为 \(0,1,2,3,4\)。对应实际锚点的位置误差至多为 \(E\) 乘以各分量

\[
(t_0,t_1,t_2,t_3,t_4)=(0.70,0.70,0.84,1,0.84).
\]

两个侧边接触分别由 \(0.70E,2E/3\) 控制。伴随点由 \((2\cdot0.24/3+0.68)E=0.84E\) 控制，首命中点由 \(0.68E\) 控制。DE 接触的误差至多 \(E\)。两首点交换时配对反射只交换 \(0,1\) 和 \(2,4\)，以上界对两种标号同时适用。

设顶点扇的端法向为 \(e=v_k-v_i,f=v_k-v_l\)，均为单位向量。对单位方向 \(u=\alpha e+\beta f\) 且 \(\alpha,\beta\ge0\)，令 \(d(u)=h_K(u)-h_*(u)\)。实际体含有距 \(v_k\) 至多 \(t_k E\) 的点，所以 \(d(u)\ge-t_k E\)。实际体位于以另两个实际锚点为圆心的单位盘内。沿 \(e\) 方向有 \(h_K(e)\le 1+e\cdot v_i+t_i E=e\cdot v_k+t_iE\)，沿 \(f\) 同理。由支撑函数的次线性，

\[
-t_k\le d(u)/E\le \alpha t_i+\beta t_l.
\]

证书以交叉积直接包围两个非负系数，同时用 \((\alpha+\beta)\le\sqrt{8/7}<1.07\) 截住宽角格的区间误差。对负扇，由定宽关系 \(d(-u)=-d(u)\) 反转上述区间。扇端和跨扇闭角格取一切可能扇的区间并包。程序使用未经采样的闭格法向和闭格锚点。

## 根括与同一平移

每个直段基点闭格分别测试相容函数 \(F_K(\phi)=h_K(u_0)-h_K(u_{60})+h_K(u_{120})-1/2\) 两端。三个误差按其符号相加。围绕有理预测角分别向左右搜索，半宽按 \(1/20\) 度变化，以 Arb 重算后的真实符号余量大于 \(10^{-6}\) 作为通过条件。无需假设根唯一或预测角函数正确。对闭格内每一基点和任一实际双命中体，连续性均给出一个相容根。

设某一单位宿主法向 \(u=d_0 n_0+d_1 n_1\)，其中 \(d_0=u_x-u_y/\sqrt3\)、\(d_1=2u_y/\sqrt3\)。同一居中平移下，实际净余量等于理想余量加上 \(d_0d(Rn_0)+d_1d(Rn_1)-d(Ru)\)，其中 \(R\) 含所选角及手性。各有向支撑误差在整个角格上以上节方法包围。余量充足的格可直接扣除已证一般误差 \(3.21E\)。理想余量沿用第112轮的中点加导数区间法。全部2205个基点格及26460个角格都通过。最小根符号余量在第31参考格、第60子格右端，大于 \(1.00286\times10^{-6}\)。最小摆放余量在第34参考格最后一个子格、边 `Z-Tprime:16`，大于 \(0.00009888528\)。此摆位同时通过所有必要直边、AH 线和 EH 支撑，沿用第112轮的强制接触推出真实 Sprague 圆弧支撑。第126轮处理的其余离散与 EH 连续分支沿用相同触发条件与角度变化估计。定宽补全得到对任意直径不超过一的集合的覆盖性。

## 真实面积与复算

在旧直段局部坐标 \(x=Z+wD+|D|yn\) 中，新线的斜率严格介于外侧两条线的斜率，且截距小于第零线的截距、在 \(w=0.410\) 严格低于零。故变动部分全部在旧直段上。新包络的折点约为 \(0.0016163662301,0.4099881569353\)。凑齐新旧包络的折点，在每个仿射条带的端点核验实际旧弧内侧多边形的全部支撑，最小净距大于 \(1.37510\times10^{-10}\)。对线间区域作梯形精确积分并乘 \(|D|^2\)，对第167轮面积区间作有理端点相减，得文首端点。两组归档的60点及18点输入均另在恒等摆位直接通过。

从课题目录复算，使用 Python 3.13.18 与 python-flint 0.9.0。每次重建物理图和根括，面积阶段以160位 Arb 运算。

```sh
python -B computation/certify_ah_adaptive_bracket.py computation computation/ah-adaptive-bracket-lines.json OUTPUT.json
```

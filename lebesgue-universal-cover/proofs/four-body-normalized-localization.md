# 四体全域极小点的规范角域与必要位置

固定半径 $1/2$ 的圆盘中心及 $B_3$ 的方向后，仍可对四体整体实施 $2k\pi/3$ 旋转以及横轴反射。三个平移随同一正交变换而动。相对角 $\rho_5$ 已按 $2\pi/5$ 取模，而 $2\pi/3$ 的整数倍在这一商圈上生成步长 $2\pi/15$ 的循环群。反射令角变号，因此每个放置有一个等价代表满足
$$0\le\rho_5\le\pi/15,\qquad 0\le\rho_7\le 2\pi/7.$$
不存在同时进一步独立约去第二角的需要。为避免无理边界，程序在稍大的有理角域 $\rho_5\le215/1024$ 上工作，以 Arb 检查 $\pi/15<215/1024$。

取有理门槛 $T=0.836490455462$。第76轮的真四体局部极小构形面积严格小于 $.83649045546121308<T$，故每个全域极小点的一个规范代表都必须落在面积未能严格排除的盒中。根盒外按四体内切圆证明核对，三个下端皆大于 $T$。在原树808905个闭叶中，有330215个与扩大后的规范角域相交。沿第三坐标精确裁至该角域，再用同一全盒整数多扇核重新验证。结果如下。

| 材料 | 初始原叶 | 严格排除 | 剩余 | 盒判断 |
|---|---:|---:|---:|---:|
| 盘96点、各体 $24n$ 点 | 330215 | 324029 | 6186 | 2187923 |
| 盘384点、各体 $64n$ 点 | 6186 | 5899 | 287 | 523112 |

287个余盒全部位于原树第17分片。其他23个分片在规范域内完整排除。两次独立运行（GCC、Apple clang）得到相同的逐分片数量。每个全域极小点都可取一个规范代表，其八个坐标满足下表的闭区间。更精确的集合为证书中287个盒的并。

| 坐标 | 下端 | 上端 |
|---|---:|---:|
| $t_{3x}$ | $-3338275/268435456$ | $0$ |
| $t_{3y}$ | $-3338275/268435456$ | $0$ |
| $\rho_5$ | $2635359/268435456$ | $18447513/268435456$ |
| $t_{5x}$ | $23608291/1073741824$ | $57334421/2147483648$ |
| $t_{5y}$ | $-3372613/536870912$ | $0$ |
| $\rho_7$ | $22588791/33554432$ | $97884761/134217728$ |
| $t_{7x}$ | $0$ | $838711/134217728$ |
| $t_{7y}$ | $-7548399/536870912$ | $-2516133/268435456$ |

局部极小构形位于上述包络内。目前这些盒还没有全部落入已证局部极小盆地，四体全域极小值的精确性仍需补域。

在 computation 目录运行下列命令。CERT8 是公开的八维原树，WORK 为 data 卷上的临时目录。程序重新生成并逐点认证两组材料、解码全部原叶及其规范截面、重新编译内核并验证各次二分。输出按分片记录端点和整数遍历哈希；第17分片的每个余盒前八项为下端、后八项为上端，共用分母 $2^{44}$。

```sh
python -B localize_four_body_global.py CERT8 WORK out.json --workers 3
```

实际运行输出为 computation/four-body-normalized-localization.json。数学公式与整数扇的正确性证明同四体全域多扇证书。

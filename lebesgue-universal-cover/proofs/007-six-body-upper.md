# 第7轮：新增十一边形后的六体可行覆盖

令F6={D,B3,B5,B7,B9,P11}。存在明确凸覆盖容纳F6，且

 m(F6) ≤ 2336286496896237198610734467/2788079616000000000000000000 < 0.838。

这是有限测试族的严格上界，不是Λ上界；也不是该族最小值的认证。
它与第5轮无矛盾：第5轮固定了原五体外覆盖，本轮允许产生不同的更大凸包。

位置由computation/certify_six_body_upper.py的PARAMS给出，十四项十进制全部解释为
精确有理数，依次为t3x,t3y,rho5,t5x,t5y,rho7,t7x,t7y,rho9,t9x,t9y,rho11,t11x,t11y。
D固定在原点、B3方向固定，其余各体独立平移及旋转；这些参数仅定义一个可行放置。

前五体用第2轮的圆弧模型及严格三角区间，K=128，坐标舍入分母10^9。
P11的11个顶点为t11+R11 u(rho11+2πj/11)，R11=(2cos(π/22))^-1。
每个顶点同样以有理区间包围后舍入，误差≤2·10^-9。因P11是这些顶点的凸包，
其完整边界由凸性包含，不需额外弦高；原先圆弧统一误差仍适用。

全部4131个点的有理凸包有154顶点，脚本检查每个采样点都在该凸包中。
使用与第2轮相同的Taylor余项、外扩ε和向上周长后，Steiner公式产生上述精确分数。
007-six-body-certificate.json保留全部有理顶点及参数；007-verification.json为
独立标准库面积/周长/最终比较复核。一般几何证明沿用第2轮，新增有限顶点部分如上。

数值位置来源于本轮optimize_six_body.py：局部Powell、指定平移搜索框[-.1,.1]^2和
两个启动点，只作探路；并未证明这个框覆盖全局最优，也未声称局部解为全局解。
有理上界认证只使用找到的明确位置，与局部搜索是否最优无关。

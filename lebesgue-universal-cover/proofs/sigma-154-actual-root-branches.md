# 改变 Gibbs 斜角后的真实双命中根与全形面积

在 \(\sigma=1.54^\circ\)，AH 铰点 \(p=.429\)，新增弦与原直段的夹角 \(\delta=.0062\) 弧度下，所有双命中定宽一体都有一个真实相容根，使居中后的身体满足 AH 分支的全部宿主不等式。第69格的最小相容符号余量大于 \(3.87764\,10^{-6}\)。第24格的限制边 `I-E3-0` 给出最小摆放余量，大于 \(1.25211\,10^{-6}\)。对于同一铰点，在 \(1.5497^\circ\) 已有全局不可覆盖反例。这给出了主宿主斜角变化切实改变 AH 容许铰点的例子。新角度的初次 EH／AH 重摆仍须另外接入，才能得到普适结论。

## 根与角格

从 \(1.54^\circ\) 重新计算六边形、旋转六边形、Gibbs 的全部顶点、Sprague 弧、反射、配对曲线和导数、增弦、全部摆放支撑行及相容方程。以真实负投影配对弧为底，各物理格给出图横坐标区间 \(J\) 和正图亏损的上界。全域的最大亏损小于 \(.005238389\)。取正亏损较大的命中点为首点。两个亏损均为零时，取在新增闭帽中的一个；旧宿主规则保证两点不能同时在原开耳中失配。

在每个参考细格，以单调图横坐标的两个端点得到闭区间 \(I\) 及其配对闭区间 \(\psi(I)\)。若所有新增闭帽物理格的 \(J\) 均与两者无交，则此细格不含所选首点，因而可从真实输入域剔除。在70个参考格各分75小格后，前69格逐一验满，第69格仅前4小格可达，一共5179格。对每个可达格的每个支撑符号类别，证书以闭角括的严格异号夹住真实根。所有可含根的角叶分别有一种同时通过全部物理行的二面体姿态。第0–3格用两角括，按同一身体的一个支撑值分侧；余格各有在完整实际接触预算下成立的共同角括。第65–69格采用 \(.5^\circ\) 的负端以及 \(6.15^\circ\) 或 \(6.16^\circ\) 的正端。

## 全形面积预算

按有理 Taylor 余项重算 Gibbs 全面积及 AH 配对曲线的 Green 积分，在相同新角度重新裁切 EH 的十一段凸边界，分别从对应角度的 Gibbs 面积中扣两处真实面积。按 \(\sigma=1.54^\circ\) 得到以下定向小数上端。

| \(p\) | \(\delta\)（弧度） | 全形面积上端 |
|---|---|---|
| .427 | .0062 | .844091993187163302754522703769266792766 |
| .429 | .0062 | .844091981204637818775666032541109960706 |
| .429 | .009 | .844091008415096240863417882821782105416 |
| .429 | .012 | .844089756983580565316110651284390302267 |
| .429 | .016 | .844087724148719828241460975764168771573 |

后四行共用铰点但需要各自的双命中证书。对于 \(\delta=.009\)，参考铰点范围仍为 \([0,.43]\)，只把未知伙伴的图和斜率管延伸至 \(.48\)。在所需域验证 \(\|X_\ell\|<.28,\|X_t\|<.78\)，且 \((2/3)\cdot .28+.78<1\)，所以此前一倍亏损的图误差仍成立。物理亏损小于 \(.008318701\)。带面积目标的该形体在第65–69格均有真实根、且同根摆放通过一切行。仅凭第30格原单括 \([7.8^\circ,15.1^\circ]\)，根端与摆放的计算下界分别约为 \(-.000381275\) 与 \(-.000141066\)，因而该格尚无此单括证书。早端及完整初次重摆仍有独立的覆盖问题。

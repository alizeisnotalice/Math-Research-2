# 排除正胡勒九边形的另一朝向分支

以圆盘固定原点，以正胡勒三边形的一个顶点半径固定横轴。记九边形的顶点半径与横轴的夹角为 θ₉，并令

    δ₉ = dist(θ₉, (2π/9)ℤ).

三边形残余旋转 2π/3 给 θ₉ 增加三个九边形周期，横轴反射使角变号。因此 δ₉ 对残余刚体对称不变，且取值于 [0,π/9]。

四层五体全域定位证明，任何面积不超过 0.837295006222 的规范放置都落在 501 个原叶的并内。把每个原叶的 11 对端点精确解码到分母 2⁴⁴ 的整格。闭矩形相交当且仅当逐坐标闭区间相交。矩形交图的三个连通分量大小依次为 346、130、25。在 θ₉=0 与 2π/9 的公共角缝上，后两组有 1,324 对矩形的其余十个坐标相交。对全部原盒直接以 160 位 Arb 检查，第一组满足 δ₉>3/10，后两组满足 δ₉<9/200。这一结论只使用原叶的区间端点，不需要假定真正的低面积集合在任何一个分量内连通。

五体已认证的严格局部极小构形给出可行上端 U=0.83729500622102525。对 155 个 δ₉<9/200 的原叶，在门槛 ceil(2⁵⁷ U)/2⁵⁷ 下重算五体有理扇、圆弓面积及非负整数权的仿射收缩。每棵树从原始端点开始，在规范角域与高门槛已证的四个必要平移半径内工作；该截断之外的放置已由较高门槛排除。44,245 个检查节点中，8,780 个终端由整数几何核确定，3,373 个由仿射扇的整数权凸组合确定。没有终端借用局部盆地。因此每个五体全域极小构形都有 δ₉>3/10。在剩下的 346 个原叶中，四个原矩形与已证的局部盆地矩形相交。它们的分片与前序位置为 (176,35228)、(176,35845)、(180,23955)、(180,24887)。

数值验证环境和相同整数几何核见五体下界 0.83729 的说明。五体定位及其四层全域重放回执、局部构形的严格可行上端和全域规范化仍是本结论的前提文件。完整几何复算命令为

    python -I -B computation/replay_five_far_orientation.py UPSTREAM CERT HIGH_COMPUTATION computation/five-far-orientation.zip SCRATCH CLANG_CACHE --replay

省略 --replay 时仍重新解码 501 个原叶，检查角间隔、缝上相交对、例外集合、155 棵树的原始端点和账本归零。固定补包 SHA-256 为 1600ee09d8d929e4286b0e116c66528efc0c413d5acfef7fc504dfe5a29d5342。

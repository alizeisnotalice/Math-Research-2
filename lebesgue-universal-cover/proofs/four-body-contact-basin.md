# 四体接触极小的显式盆地

记 $M_*$ 为第76轮接触候选面积，$(\alpha_*,\beta_*)$ 为已认证的驻点，四条确定锚点的共同支撑线沿用该轮记号。令
\[
 \begin{aligned}
 \alpha_0&=.51250444532618500354392,\\
 \beta_0&=1.577473015380594982391575.
 \end{aligned}
\]
在 $|\alpha-\alpha_0|,|\beta-\beta_0|\le2\cdot10^{-5}$ 上，由 $B_3$ 的平移确定两法向，再用同一接触方程确定 $B_5$、$B_7$ 的六个锚定坐标。实际的后六坐标减去相应锚定坐标记为 $\xi$。本次证明在 $\|\xi\|_\infty\le1.5\cdot10^{-4}$ 上有
\[
 A\ge M_*+\frac1{20}\bigl((\alpha-\alpha_*)^2+(\beta-\beta_*)^2\bigr)+7\cdot10^{-6}\|\xi\|_1.
\]
特别是，每个固定 $B_3$ 平移在此域中都只有一个最优的 $B_5$、$B_7$ 配置，并由四条接触方程确定。在整个域中达到 $M_*$ 的规范放置唯一。

## 双变量 Taylor 包络

将 $\alpha,\beta$ 分别写成 $\alpha_0+Rx$、$\beta_0+Ry$，其中 $R=1/25000$。目标实域是 $|x|,|y|\le1/2$。每项表达式在复多圆盘 $|x|,|y|\le1$ 上表示为总次数不超过 $12$ 的多项式 $P(x,y)$ 加解析误差 $E(x,y)$，各系数和误差上界均用 Arb 计算。过程只使用上一轮已明确选枝的接触公式和逐弧倍面积。

乘法将超出次数的项按系数绝对值和放入余项，对两个已有误差用 $\|P_1\|_1\varepsilon_2+\|P_2\|_1\varepsilon_1+\varepsilon_1\varepsilon_2$。计算解析函数时把常数项 $c$ 和其余项 $w$ 分开。在 $\|w\|<|c|$ 时用几何级数计算倒数；正平方根用二项级数，且 $c>\|w\|$。两式的尾由相应几何界控制。对 $\arctan(c+w)$，使用两条复对数级数之差，$j$ 阶系数来自 $((c+i)/(1+c^2))^j$ 的虚部除以 $j$，故尾绝对值至多 $v^{13}/(13(1-v))$，其中 $v=\|w\|/\sqrt{1+c^2}<1$。正弦和余弦的尾用 $e^{\|w\|}\|w\|^{13}/13!$。每一步均保留整个复域的误差上界。所有除法和所用根式验证分支与奇点具有严格分离。

锚点面积最终的解析误差上界小于 $7.27\times10^{-20}$。对任意实子盒，在余项上用两个独立复变量的 Cauchy 导数界：令 $d=1-\max(|x|,|y|)$，二阶纯导数误差至多 $2\sup|E|/d^2$，二阶混合导数误差至多 $\sup|E|/d^2$，再除以 $R^2$ 换成原法向变量。多项式项直接微分。证书逐一核验支撑拓扑中的端点及可能的区间内部极小，并给出 $\nabla^2F-.1I$ 的两个 Sylvester 符号，行列式严格大于 $1.46$。因此整个两角闭盒均有 $\nabla^2F\succeq.1I$。以已证驻点积分二阶下界，即得驻点以上的二次面积余量。

## 六变量偏差的面积余量

固定任一锚点，按第76轮选择同样七条材料边界。每条通过在六条多重支持线上插入或略过严格居中的接触材料形成，局部材料随各体刚体运动。用双变量 Taylor 包络保持各梯度之间的相关性。其分量附加一个首坐标 $1$ 后，组成 $7\times7$ 矩阵 $G$。先用中心近似逆选择有理矩阵 $B_0$，再用 Arb 计算 $(B_0G)^{-1}B_0$。这一矩阵作用于 $(1,v)$，其中 $v\in[-10^{-4},10^{-4}]^6$，得到严格正的重心坐标，最小下界大于 $.011$。于是七个梯度的凸包在每个锚点均包含该六维立方体。

对实际的刚体偏差域，在所有七条材料链上逐一认证异体连接方位仍严格正。同行材料的衔接在刚体运动后仍是原来同一个点。合法圆弧的极角继续严格增加，因为各移动体都含原点内点。完整闭链绕数为一，故它围成的星形区域包含于真实凸包。锚点处各链面积均为 $F(\alpha,\beta)$，因此第一阶最大增量至少 $10^{-4}\|\xi\|_1$。

直接计算固定材料在刚体扰动下的二阶余量。对一段半径 $\rho$ 的弧，设同一弧的世界法向差为 $N$，锚定平移为 $t$。扰动后唯一非恒定的弧面积项为
\[
 \frac{\rho}{2}\det(t+\Delta t,R_{\Delta\phi}N).
\]
相应的二阶项仅涉及该旋转的自二阶导数及其与本体平移的混合项。不同体之间的连接给出 $\det(P,Q)/2$，在两端刚体运动下直接作二阶求导。对每条链求六维 Hessian 的最大绝对行和上界 $L$，由 $|\xi^TH\xi|\le L\|\xi\|_\infty\|\xi\|_1$ 得到线性余量 $10^{-4}-(L/2)(1.5\cdot10^{-4})$。其实际下界严格大于 $7.12\times10^{-6}$。以上两项合并得到所述面积不等式。

## 原始八维闭盒

原始坐标仍按 $(t_{3x},t_{3y},\phi_5,t_{5x},t_{5y},\phi_7,t_{7x},t_{7y})$ 排列。取下列精确十进制中心：

```
(-.00255163398964655,-.00193331458560072,
 .02867263048929559,.02508688430651930,-.00328479589201898,
 .70156070130903857,.00288748433564455,-.01271885155848397)
```

每一坐标半宽可独立取
\[
 (4\cdot10^{-6},4\cdot10^{-6},8\cdot10^{-5},1.4\cdot10^{-4},1.3\cdot10^{-4},4.9\cdot10^{-5},1.4\cdot10^{-4},1.4\cdot10^{-4}).
\]
此闭盒整个包含于上面的接触坐标域。核验先以两个原始 $B_3$ 平移作为 Taylor 变量，由同一圆盘切线公式取 $\alpha,\beta$ 两个法向；再计算六个锚定参数，将原始坐标半宽加到锚点在整个 $B_3$ 盒内的变幅上。该次计算使用总次数 $10$ 的多项式，以保留两平移传到六锚定参数中的相关性。最终两个法向偏移上界分别小于 $1.922\times10^{-5}$、$1.399\times10^{-5}$；六横截上界全部小于 $1.484\times10^{-4}$。因此此八维盒可直接用作全域树的一个精确终止条件。从此域自身不能排除盒外存在更小值。

## 复现

在已有第76轮的 `certify_four_body_contact_stationary.py` 与 `certify_four_body_contact_transverse.py` 的仓库根目录运行：

```sh
python -B lebesgue-universal-cover/computation/certify_four_body_basin.py --transverse .00015 > BASIN
python -B lebesgue-universal-cover/computation/certify_four_body_basin_raw_box.py BASIN --width .000004 .000004 .00008 .00014 .00013 .000049 .00014 .00014
```

冻结输出为 `four-body-basin-enlarged.json` 与 `four-body-basin-raw-anisotropic.json`。同样复算了每坐标半宽 $4\cdot10^{-6}$ 的闭盒输出 `four-body-basin-raw-isotropic.json`。实际执行用 Python 3.13.18、python-flint 0.9.0 和 160 位 Arb；无需优化器或随机输入。

## 加宽法向盒

将复多圆盘物理半径 $R$ 提高到 $6\cdot10^{-5}$，用两个闭子盒核验实二维域，得到 $|\alpha-\alpha_0|,|\beta-\beta_0|\le3\cdot10^{-5}$，同时保持 $\|\xi\|_\infty\le1.5\cdot10^{-4}$。新的复余项小于 $1.44\times10^{-17}$，$\nabla^2F-.1I$ 最小核验行列式仍大于 $1.46$，横截有效线性系数仍大于 $7.10\times10^{-6}$，所以开头的同一面积下界适用于加宽后的整个域。

用两原始平移的相关包络覆核，八维等半宽 $5.8\cdot10^{-6}$ 的闭盒全部落入加宽域。两个法向最大偏移分别小于 $2.786\times10^{-5}$ 和 $2.029\times10^{-5}$，最大的横截偏移小于 $1.496\times10^{-4}$。这一等半宽盒与前面的各向异性盒都可用作全域树的终止条件。

```sh
python -B lebesgue-universal-cover/computation/certify_four_body_basin.py --radius .00006 --transverse .00015 > WIDER
python -B lebesgue-universal-cover/computation/certify_four_body_basin_raw_box.py WIDER --width .0000058
```

相应冻结输出为 `four-body-basin-wider-angles.json` 和 `four-body-basin-raw-isotropic-enlarged.json`。`four-body-basin-audit.json` 汇总两套尺度的精确半宽、源码绑定和真极值点属于盒内的核验。

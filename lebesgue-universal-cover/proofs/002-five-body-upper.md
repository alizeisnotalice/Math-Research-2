# 第2轮：五测试体族能力上限的有理证书

设 F5={D,B3,B5,B7,B9}，其中 D 为半径1/2圆盘，B_n 为宽度1的正奇数
Reuleaux n边形。m(F5)是分别容纳这些形状的凸集最小面积，不是Λ。

本轮证明

    m(F5) ≤ 145920431033097875119778171 / 174254976000000000000000000
          < 4187/5000 = 0.8374.

展示小数约0.837396063990149不承担认证；上面的有理比较承担严格结论。
这不是新的万能覆盖，也不证明五体不能决定真实Λ：若Λ本身≤0.8374，两者仍可能相等。
它严格说明仅靠这五体不可能证明Λ≥0.8374。

## 1. 几何定义与位置

令 u(t)=(cos t,sin t)，R_n=1/(2cos(π/(2n)))，v_l=R_n u(2πl/n)。
B_n边界由圆弧

    v_l+u(t),  t∈[2πl/n+π−π/(2n), 2πl/n+π+π/(2n)]

组成。其等价定义为以全部v_l为中心的单位闭圆盘交。
圆弧端点恰是v_{l+(n−1)/2}和v_{l+(n+1)/2}（下标模n）：令a=π/(2n)，
利用R_n−cos a=−R_n cos(2a)、sin a=R_n sin(2a)直接验证。
按外法向顺序，圆弧的法向区间长度π/n，顶点法向锥长度π/n，交替覆盖整圆，
构成闭凸边界。若u在v_l的法向锥，则正向支撑点v_l、反向支撑点v_l−u，
两支撑线间距1；另一半方向同理。因此各B_n定宽1、直径1。

对每体施行 u↦Rot(rho)u+t。D置于原点；B3旋转为0，其余角度及平移按
computation/certify_five_body_upper.py 中PARAMS记录，十一项十进制均解释为精确有理数。
来源为Tomar仓库v9的明确候选位置，而非本轮局部优化的结果；参数映射见来源账本。

## 2. 独立有理三角计算

本轮没有运行来源的浮点几何程序。只使用Python标准库Fraction、整数运算和isqrt。
由Machin恒等式π=16 arctan(1/5)−4 arctan(1/239)，分别取32、8项交错级数，
下一个项的绝对值为余项界。Machin恒等式可由有理正切恒等式验证：令a=arctan(1/5)、b=arctan(1/239)，tan(2a)=5/12<1，故0<4a<π/2；tan(4a)=120/119>tan b，故0<4a−b<π/2；再算tan(4a−b)=1，定支得4a−b=π/4。脚本断言上述有理恒等式。得出的有理区间完全落在

    [3141592653589793238,3141592653589793239]/10^18

之内；脚本实际断言包含关系。所有π系数、平移和旋转均作有理区间运算。
对每个角区间，选有理中心x并加入准确的最大位移rad。实际断言|x|<12。
sin/cos取到81阶Taylor多项式（cos的81阶项为0），Taylor余项不超过|x|^82/82!。
两函数全局1-Lipschitz，故再加rad覆盖整个角区间。结果按10^-18网格向外取整。
正余弦、倒数半径和坐标的区间传播均采用四端点乘积/正区间倒数。

每个真采样点得到有理网格点q∈10^-9 Z²，并实际验证其每坐标区间包含于
[q_i−10^-9,q_i+10^-9]；所以欧氏误差≤sqrt(2)10^-9<2·10^-9。
区间误差不来自机器浮点或提高标称精度；唯一float仅用于最终展示小数。

## 3. 全弧包含与面积

取K=64，每条Reuleaux圆弧等分K段，D等分8K段。共2072个采样点（包含重复端点）。
单位半径弧段角宽Δ≤π/(3K)，弧到弦距离≤1−cos(Δ/2)≤Δ²/8。
D的半径是1/2且步长π/(4K)，其弦距≤π²/(256K²)，小于统一界π²/(72K²)。
相邻端点有理化后，同样凸组合的误差≤2·10^-9。因此所有真边界、各形状及其凸包A
都包含于H+εB，其中H是全部有理采样点的凸包，

    ε=(22/7)²/(72K²)+2/10^9 = 236342237/7056000000000.

用π<22/7（上述π区间也验证这一关系）即可取此有理ε。
脚本以整数叉积构造102顶点的H，并逐点逐边检查所有2072个采样点在H内。
整数鞋带公式给

    |H|=1674568157073428067/2000000000000000000.

每边的整数坐标差平方和为d，以ceil(sqrt(d))/10^9向上估计长度；isqrt及平方比较
提供精确整数认证。求和得

    P(H) ≤ 3343221633/1000000000.

Steiner公式遂给

    |A| ≤ |H+εB| = |H|+εP(H)+πε²
        ≤ |H|+ε·3343221633/10^9+(22/7)ε²
        = 145920431033097875119778171/174254976000000000000000000
        < 4187/5000.

H+εB显然是F5的可行凸覆盖，因此m(F5)不超过此有理上界。
H本身只是近似采样点的凸包，未声称包含原五体，面积认证必须保留ε膨胀。

## 4. 复现与验收范围

主认证程序生成全部区间及有理顶点；002-five-body-certificate.json保存102个顶点、
面积、周长上界、ε、最终有理上界、解释器及脚本哈希。
独立程序recheck_certificate.py只重算证书的鞋带面积、向上周长和Steiner有理比较；
它不代替三角区间与全弧覆盖的证明。MacBook实际运行该独立算术复核并退出0。

本轮未重验Tomar的0.8366全域下界，因此不把它记作本轮独立认证。
更没有证明此五体放置是最优，也没有把m(F5)上界转为Λ上界。

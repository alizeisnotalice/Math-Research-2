# 允许各自等距放置时，小直径包容模板所需的数目

定义 N(δ) 为一族平面集合所需的最少成员数，要求每个成员直径至多 1+δ，而且每个平面宽一体都可通过一次等距变换放入其中一个成员。模板可取任意形状；取闭凸包保留直径和包容性。则当 δ 趋于零时

    log N(δ) = Θ(δ⁻¹ᐟ²).

上界由第115轮的放大前条带交 P 直接给出：取 m 为使 s_m−1≤δ 的 O(δ⁻¹ᐟ²) 的整数，至多 5·14^(m−2) 个模板。

**构造大量分离的宽一体。** 给定 m≥2，令 A=1/(8m²)，把 [0,π] 等分 m 段。每个二进制字 b 定义一个支撑函数 h_b=1/2+g_b。在第 j 段上令 g_b(θ)=A b_j sin²(mθ)，在另一半圆令 g_b(θ+π)=−g_b(θ)。端点处函数和一阶导数连续，没有原子曲率；几乎处处 h_b″+h_b≥1/2−2Am²−A>0。故 h_b 确实是凸体的支撑函数，且宽度恒一。所有这些体与原点圆盘的 Hausdorff 距离至多 A。不同字在不同位对应的区间中点相差 A，所以在当前坐标中距离恰为 A。

**估计刚体运动能消去多少差别。** 令 δ=A/4，固定一字 K。若另一字 L 在某个运动 RK+t 后与其 Hausdorff 距离至多 δ，则由两体与圆盘的距离可得 |t|≤2A+δ<3A。令 J=ceil(16πm)。每类定向使用 J 个等角度，每个转角可在 π/J 以内近似；因 |g_b′|≤Am，支撑误差至多 A/16，反射后同样成立。在 [−3A,3A]² 中每个坐标以 A/8 为步长取 49 个候选值，把 t 取整增加的 Hausdorff 误差至多 √2 A/16<A/8。故 L 与某个离散姿态的距离严格小于 δ+A/16+A/8<A/2。每个这样的开球最多包含一个二进制字。一个字在允许等距运动后的 δ 邻域，因此至多含 2·49²·ceil(16πm) 个字，包括自身。

**为何包容模板也受此限制。** 若两个宽一体 K,L 的拷贝都放在同一个直径≤1+δ 的凸集 C 内，每个单位法向 u 上都有

    h_K(u) ≤ h_C(u) ≤ 1+δ−h_C(−u) ≤ 1+δ−h_L(−u) = h_L(u)+δ.

互换 K,L，可知这两个拷贝的 Hausdorff 距离≤δ。由上一段，每个模板能容纳的字数至多是同一个上界。于是

    N(1/(32m²)) ≥ ceil(2^m / (2·49²·ceil(16πm))).

由 N 的单调性，在一般 δ 下取 m=floor((32δ)^(-1/2)) 即得渐近下界。对 δ=10⁻⁶ 取 m=176，以 22/7 代替 π 使下界略微减小，仍需超过 10⁴⁵ 个模板。[整数复核](../computation/strip-packing-checks.json)

此计数针对以小直径模板逐体包容所有输入的策略。它没有给万能覆盖的面积下界，也不限制能直接处理一整类形状的解析不等式。

# 用六边形相容根控制连续摆放的边界

沿用《任意 EH 双命中的连续摆放》中的坐标、支撑函数 \(F_K\) 与联合必要条件。固定斜角 \(\sigma=1.5494009336023418793^\circ\)。这里改用 \(30^\circ\) 附近的六边形相容根，并把根方程同时纳入每条边的支撑上界。

## 选择原体或反射体

在第62轮的 \(Q_2\) 分支，若原体和反射体都进入新 EH 内部，则它们都在 \(P\) 内，都避开 AH 内部。确切地，原体避 AH 是该分支的前提，反射体避 AH 由原体不命中正 D 帽从而反射体不命中 C′ 得出。余下情况按第62轮已有刚体运动处理。

记 \(Q=Q_2\)。其轴角为 \(120^\circ\)，故 \(h_{QK}(\alpha)=h_K(240^\circ-\alpha)\)。由定宽性，\(F_K(\phi+60^\circ)=-F_K(\phi)\)。因此

\[
 F_{QK}(\phi)=F_K(120^\circ-\phi)=-F_K(60^\circ-\phi),
 \qquad F_{QK}(30^\circ)=-F_K(30^\circ).
\]

可以在 \(K,QK\) 中选一个体 \(L\) 使 \(F_L(30^\circ)\ge0\)。对证书参数，联合支撑模型证明所有这种输入在某右端角 \(\phi_*>30^\circ\) 都满足 \(F_L(\phi_*)<0\)。于是 \([30^\circ,\phi_*]\) 内具有相容根。旋转 \(\theta=240^\circ-\phi\) 后，取 \(v_j=R_{-\theta}n_j\)，\(a_j=1/2-h_L(v_j)\)。\(F_L\) 的周期为 \(120^\circ\)，所以相容根给出 \(h_L(v_0)-h_L(v_1)+h_L(v_2)=1/2\)。平移 \(t=(a_0,(2a_1-a_0)/\sqrt3)\) 后，六个原六边形法向的支撑均恰为 \(1/2\)。

## 联合约束与根条件

从原模型增加一个任意点，总共允许四个任意支撑点，并加入它与其余点的逐点距离约束。由于 \(L\) 和 \(QL\) 都进入 EH 内部，第62轮的 F′ 和 E′ 命中论证给出二者都避开 C′、B′ 帽。因此对模型的每一个点及其 \(Q\) 像都可加入对应的两条半平面。

令 \(S_A\) 为从原 Sprague 闭集去掉 AH 后的闭余集。由于 \(L,QL\) 都避 AH 内部且在 Sprague 集中，它们属于 \(S_A\)。同时 \(S_A\subset H_{\delta}\cup E_1\)。新耳 \(E_1\) 的全部点在由 \(U_1,T\) 两端坐标确定的矩形内，因为两段边界短弧的横坐标单增、纵坐标单减。计算对 \(H_\delta\) 取若干条真实的支撑线，只在它们也严格包住该矩形的四角时把它们加进模型。这些支撑线来自原直边、圆弧的径向切线、AH 配对曲线的正向切线。它们允许同时作用于模型的每一个点及其 \(Q\) 像。

对内多边形的单位外法向 \(n=d_0n_0+d_1n_1\)，平移后的支撑为

\[
G_L(\phi)=h_L(R_{-\theta}n)-d_0h_L(v_0)-d_1h_L(v_1)+(d_0+d_1)/2.
\]

在相容根，\(F_L(\phi)=0\)，所以可对 \(G_L+\mu F_L\) 作上界。系数 \(\mu\) 为每条边和每个角格单独选定的有理数。展开后得到

\[
G_L+\mu F_L=h_L(R_{-\theta}n)+(\mu-d_0)h_L(v_0)+(-\mu-d_1)h_L(v_1)+\mu h_L(v_2)+(d_0+d_1-\mu)/2.
\]

逐项以定宽性改写负系数，将目标变为四个支撑函数的非负加权和加已知常数。用四个任意点和旧线性对偶方法分别给两个端角的目标上界。以端角旋转的正组合插补，角格半宽为 \(a\) 时，再乘 \(1/\cos a\) 控制该加权和。所选 \(\mu\) 在一个角格的两个端点保持相同。这样可在整个角格核验 \(G_L+\mu F_L\) 小于该边的支撑常数，无需在相容根之外保证 \(G_L\) 也满足相同边界。由相容根和全部边余量，\(L\) 的这个姿态进入内多边形。

第62轮其余分支所需的耳与弧几何，在每个切深单独重算。新增帽面积采用第62轮 Green 积分式并从第47轮旧体的严格面积上端扣除。

## 保留左侧的真圆弧

对更深的切除，可把内近似中 \(H\to U_1\) 的四条弦换回真圆弧。所用内凸体是原内多边形顶点与这一段边界圆弧的凸包。各保留弦连结原边界相邻采样点，所以都支撑该凸包。其余边界恰为所加圆弧。候选姿态仍由六边形相容关系及其余弦的证书满足 \(P\) 的所有不等式，尤其 \(m_5\cdot x\le1/2\)。因此其 CB 支撑点 \(b=(1/2,b_y)\) 满足 \(b_y\ge C_{3,y}\)。

圆弧的单位外法向 \(u\) 满足 \(u_x,u_y\le0\)，这是 \(H-C_3=(-1,0)\)、\(U_1-C_3\) 严格第三象限及短弧次序的结果。对候选姿态中任一点 \(x\)，若 \(x_y\le C_{3,y}\)，则 \(|x-C_3|\le |x-b|\le1\)，从而满足该圆弧的切线。若 \(x_y\ge C_{3,y}\)，用 \(x_x\ge-1/2\) 得 \(u\cdot x\le u\cdot H\le u\cdot C_3+1\)。因此候选姿态自动满足这整段真实圆弧的所有支撑线。圆弧和临接弦交点的法向锥由对应两侧极端法向生成，也无需另测。

## 两种切深的严格结果

取 \(\phi_*=30.75^\circ\) 及 12 个闭角格。Arb 核验 \(F_L(\phi_*)<-1.45978\times10^{-4}\)，在 32 条非六边形边上的全角格最小严格余量大于 \(8.42584\times10^{-6}\)。新增帽面积严格大于 \(1.1190189991101190301\times10^{-8}\)，故得到一般上界

\[
\Lambda<0.844093583196299768.
\]

切深增至 \(0.0001\) 时，取 \(\phi_*=31.1^\circ\) 与 16 个闭角格。Arb 核验 \(F_L(\phi_*)<-1.00643549\times10^{-4}\)，全部 32 条非六边形边最小严格余量大于 \(2.55074282\times10^{-6}\)。新增帽面积严格大于 \(2.23903403585955555\times10^{-8}\)，故得到一般上界

\[
\Lambda<0.844093571996149401.
\]

用 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 重放 `computation/eh-root-conditioned-50.json` 与 `computation/eh-root-conditioned-100.json`。两次重放无需调用 SciPy，实际退出零且输出与原证书逐字节一致。

```sh
python -B computation/certify_eh_relocation_root_condition.py 0.00005 30.75 OUTPUT.json --replay computation/eh-root-conditioned-50.json
python -B computation/certify_eh_relocation_root_condition.py 0.0001 31.1 OUTPUT.json --angle-cells 16 --replay computation/eh-root-conditioned-100.json
```

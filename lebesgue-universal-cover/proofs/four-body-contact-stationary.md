# 圆盘、三角形、五边形和七边形的严格局部极小

这里的四体依次为 $D,B_3,B_5,B_7$，其中 $D$ 是半径 $r=1/2$ 的圆盘，$B_j$ 是正 Reuleaux $j$ 边形。固定 $D$ 在原点，固定 $B_3$ 的顶点方向为零。由 Tomar 的 `opt8_point.json` 选择接触构形，随后只依赖显式方程和 Arb 区间核验。在此构形中存在唯一的两维接触驻点，且它在八维完整的放置空间中是严格局部极小。其面积严格介于 $0.83649045546121306$ 和 $0.83649045546121308$ 之间。因此后一个数是四体全域最小面积的可行上界。

## 两维接触流形

令 $p_{j,k}$ 为 $B_j$ 的第 $k$ 个放置后顶点，编号从零开始，其局部坐标为
\[
 \frac{1}{2\cos(\pi/(2j))}\bigl(\cos(2\pi k/j),\sin(2\pi k/j)\bigr).
\]
法向取单位向量。下表列出决定流形的四条线。记号 $+k$ 表示该顶点在支撑线上，对应 $n\cdot p_{j,k}=r$。记号 $-k$ 表示该顶点是支撑圆弧的圆心，对应 $n\cdot p_{j,k}=-r$，实际支撑点为 $p_{j,k}+n$。标为空白的体不参加该方程。

| 法向 | $B_3$ | $B_5$ | $B_7$ |
| --- | --- | --- | --- |
| $n_A$ | $+0$ | $-3$ | $+0$ |
| $n_B$ | $+1$ | $+1$ | $+1$ |
| $n_C$ |   | $-2$ | $-2$ |
| $n_D$ | $+0$ |   | $-2$ |

四线均与 $D$ 相切，支撑值为 $r$。以 $\alpha=\arg n_A,\ \beta=\arg n_B$ 为自由参数。前两行的 $B_3$ 方程直接线性解出其平移。因为同一个 $p_{3,0}$ 位于 $A,D$ 两条圆盘切线上，第二法向为
\[
 n_D=p_{3,0}/|p_{3,0}|^2-n_A.
\]
随后用 $A,B,D$ 三个方程求 $B_7$。对某个候选刚体角 $\phi$，前两条线性方程解出
\[
 t=t_0+t_c\cos\phi+t_s\sin\phi.
\]
将此代到第三条方程，得到 $u\cdot(\cos\phi,\sin\phi)=d$。在两条单位根中，所需分支为
\[
 (\cos\phi,\sin\phi)=\frac{d u-\sqrt{|u|^2-d^2}\,Ju}{|u|^2},
\]
其中 $J$ 表示逆时针直角旋转。两斜线 $D,C$ 的 $B_7$ 弧心相同，因此另一方向为
\[
 n_C=-p_{7,2}/|p_{7,2}|^2-n_D.
\]
再用 $A,B,C$ 的三个方程，以相同分支求 $B_5$。两个角分支的余弦都严格正，所用平方根的分支与初始构形一致。至此，整个放置由 $(\alpha,\beta)$ 明确确定。$A,B$ 反向的四重线仍支撑整个凸包，$C,D$ 反向的三重线位于第四个体的支撑线内侧。

## 支撑链和区间驻点

面积使用真实凸包的逆时针圆弧与连接线。除上述四线与 $A,B$ 的反向外，另外的异体交点记为 $E,F,X,Y,Z$：

- $E$ 是 $p_{7,0}$ 与 $D$ 相切的另一法向，$F$ 是以 $p_{5,3}$ 为心的单位弧与 $D$ 相切的另一法向。
- $X$ 满足 $(p_{5,2}-p_{3,0})\cdot n_X=1$，取与 $150^\circ$ 相邻的指定根。$Y$ 是 $p_{5,2}$ 对 $D$ 的第二切线，其第一法向为 $-n_C$。
- $Z$ 是 $p_{7,3}$ 对 $D$ 的第一切线，取与 $182.82^\circ$ 相邻的根。

从正 $x$ 法向出发，逐段到达 $A,E,F$，进入五边形弧、再经过五边形右上顶点到达 $B$；接着依次经过三角形左上顶点、三角形单位弧、$X$、五边形顶点、$Y$、盘弧、$Z$、七边形顶点及七边形单位弧到达 $-A$；再经三角形两个单位弧与一个顶点到达 $-B$；最后经五边形右下的弧、顶点和弧到达 $C$，由盘弧接到 $D$，返回三角形右顶点。所有同体转变发生在该体明确的原始法锥端点。代码中 `chain` 给出逐条圆弧圆心、半径和终止角。

为了严格确认这是凸包边界，在全部原始法锥端点和上述交点处切分法向圈。对每个原子角区间，两个体的支持差恒形如 $d+v\cdot n(\theta)$。端点上逐个检查严格正性或方程所保证的等号；区间内部可能的极小只有法向 $-v/|v|$，由方向叉积判定是否落入。实际共核验 $42$ 个原子角区间，不存在遗漏的内部极小。由此支持链在整个认证参数盒内均成立。对圆心 $p$、半径 $\rho$ 的一段圆弧，其倍面积增量为 $\rho\det(p,n_{\rm end}-n_{\rm start})+\rho^2(\theta_{\rm end}-\theta_{\rm start})$。每条连接线另贡献 $\det(P,Q)$。这些表达式给出解析面积函数 $F(\alpha,\beta)$。

驻点盒为
\[
 \begin{split}
 .51250444532618500354390&\le\alpha\le .51250444532618500354394,\\
 1.57747301538059498239155&\le\beta\le1.57747301538059498239160.
 \end{split}
\]
对 $F$ 用 Arb 级数求一、二阶导数，并从盒中心 Hessian 的近似逆选有理矩阵 $C$。脚本核验 $x\mapsto x-C\nabla F(x)$ 严格将整个闭盒映回自身，收缩系数小于 $6.4\times10^{-9}$，且 $C$ 可逆。因此恰有一个区间驻点。全盒 Hessian 正定，行列式大于 $4.35$，故该驻点在接触流形上严格极小。通过在盒中心计算面积，并用已认证梯度及 Hessian 给出局部误差上包络，得到所述面积区间。

参数近似值依次为
\[
\begin{split}
(t_{3x},t_{3y})&=(-.00255163398964655,-.00193331458560072),\\
(\phi_5,t_{5x},t_{5y})&=(.02867263048929559,.02508688430651930,-.00328479589201898),\\
(\phi_7,t_{7x},t_{7y})&=(.70156070130903857,.00288748433564455,-.01271885155848397).
\end{split}
\]

## 完整放置空间的局部极小

$A,B$ 的法向彼此线性独立，且各自接触的 $B_3$ 顶点在相应支撑线的切向坐标绝对值大于 $.1$。因此这两个法向是 $B_3$ 平移的一组局部坐标。对任意邻近放置，先按它的 $B_3$ 平移确定 $(\alpha,\beta)$，其余六坐标相对接触流形的偏差记为 $\xi$。

固定流形上的任意一点作为锚点。六条活动多重线上，严格切向次序分别为
\[
 (3,5,0,7),\ (7,0,5,3),\ (5,0,7,3),\ (3,7,0,5),\ (5,7,0),\ (0,7,3),
\]
次序对应 $A,-A,B,-B,C,D$，其中 $0$ 代表圆盘。每条线的中间材料点可任意插入或跳过，于是有 $2^{10}=1024$ 条闭链，锚点处面积均为 $F$。对横截偏移，保持各体局部材料并随其作刚体运动。足够小的偏移下，正向连接的严格极角次序保持，弧段的极角速度为正，因为相应体含原点内点。各闭链仍绕原点一周并形成位于真实凸包内的星形区域，所以均为面积下界。

每条固定材料链有解析面积。其一阶变化为 $\int\det(V,dp)$，其中弧上的 $V$ 是刚体速度，线段上的 $V$ 由两端线性插值。故线段贡献为 $\det((V_P+V_Q)/2,Q-P)$。圆弧的平移项为 $\rho\det(V,n_1-n_0)$；旋转项也用同式，其中常向量 $V=J(p-t)$，因为径向项的速度与弧切向平行，对行列式无贡献。

由全部梯度中取七个作为单纯形顶点。Arb 认证其仿射行列式非零，表示原点的全部重心权重严格大于 $.063$。再用同一个矩阵的逆，证明单纯形包含整个 $[-10^{-4},10^{-4}]^6$。对任意横截偏差，至少一条闭链的线性增量不少于 $10^{-4}\|\xi\|_1$。二阶余项在邻域一致为 $O(\|\xi\|^2)$。结合接触流形上已证明的严格最小值，得到完整八维放置空间的严格局部极小。

## 复现

从仓库根目录运行以下两条命令。证明核验只需含 python-flint 的 Python；`--locate` 的可选找根和权重探路还用 SciPy。

```sh
python -B lebesgue-universal-cover/computation/certify_four_body_contact_stationary.py
python -B lebesgue-universal-cover/computation/certify_four_body_contact_transverse.py
```

实际运行 Python 3.13.18、python-flint 0.9.0、Arb 160 位，输出分别为 `four-body-contact-stationary.json` 和 `four-body-contact-transverse.json`。目前四体全域最小值仍需进一步下界证书。

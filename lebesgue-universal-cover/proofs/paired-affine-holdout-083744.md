# 五个预登记原叶上 0.83744 的联立筛盲测

在五个闭合前登记的原叶上，比较同一五体材料扇和 \(P_{30}\) 角格库的两种六体树。每种算法每叶最多访问 1,500,000 节点，允许根后深度 135。两核都从完整原叶起步。插值锚、材料密度、384 个闭角格和分裂轴规则一致。面积整数门槛为 \(120687823102244742/2^{57}>0.83744\)。

## 登记与结果

## 深度瓶颈的独立诊断

对 1205/151326，保留联立核在深度 135 的第一个未知闭盒的精确 \(2^{-44}\) 端点。对盒心的真实五体凸包，以每圆弧 2048 点的有理面积方法得 \(A_5(q_0)>0.837571622203\)。整个盒的平动与转角支撑误差给出
\[
K(q_0)\subset K(q)+3.168201\times10^{-6} B_2 .
\]
每个曲体的居中外半径小于 \(3/5\)，本盒的平移模均小于 \(2/5\)，因此 \(P(K(q))\le 2\pi\)。由 Steiner 公式和 \(\pi<22/7\) 扣去面积误差，得到这个未知盒对所有位置的严格下界
\[
A_5(q)>0.837551707765>0.83744 .
\]
这排除了该首余盒本身，并说明此处的旧五体材料精度可成为联立筛的瓶颈。整原叶其余部分仍须完整重放。[首余盒严格诊断](../computation/paired-affine-holdout-083744-stall.json)

## 复算

`COMP` 为主线式样的 computation 目录，`CERT` 为冻结原树。32 和 64 级表可用 `COMP/tomar_fan_table.py` 生成，实际选叶均使用同一 64 级表。每次重放重新验证表内材料资格与规范数组哈希，以溢出陷阱编译。墙钟时长来自同机三线程试跑，会随负载变化。

    set -e
    mkdir -p WORK
    python -I -B computation/replay_paired_affine_holdout.py COMP CERT TABLE32 TABLE64 WORK/run CACHE computation/paired-affine-holdout-083744-plan.json --workers 3 > WORK/replay.json
    cmp WORK/replay.json computation/paired-affine-holdout-083744-audit.json
    python -I -B computation/check_paired_affine_holdout_stall.py COMP WORK/replay.json > WORK/stall.json
    cmp WORK/stall.json computation/paired-affine-holdout-083744-stall.json

环境为 Python 3.13.18、python-flint 0.9.0、NumPy 2.5.5、Apple Clang 21.0.0。第二个 Python 环境使用独立生成的 64 级材料表和独立编译目录，重新运行全部五叶的两套核及首余盒验证，两个冻结回执均逐字节一致。

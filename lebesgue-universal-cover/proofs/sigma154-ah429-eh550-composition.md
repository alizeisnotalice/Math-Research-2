# 1.54° 的 .429/.0062 AH 弦与两种 EH 裁线

固定 Gibbs 斜角 \(1.54^\circ\)。AH 以 \(Z+.429(T_a-Z)\) 为铰点，向内转 .0062 弧度。EH 将原上端 \(U\) 沿 \(C_3\) 单位弧顺时针移 .000550 弧度，并同原下端 \(T_{\rm EH}\) 连弦。两个裁线均取保留侧。这个闭凸体容纳所有平面直径至多一的输入，面积在
\[
 [0.8440919817096892836567,\ 0.8440919817096893679282]
\]
内。相对第 201 轮的已证真实宿主，严格节省超过 \(2.5018276149\times10^{-9}\)。

## 首次 EH 摆放及其余分支

精确在 \(1.54^\circ\) 重算 R34 的原六边形和两帽几何、AH 最短障碍、接触次序、EH 严格内部与全形凸性，以及五种旧摆放的正负帽映射。用这些原判据先取一个在 \(P\) 内且避开旧 AH 的定宽一副本。记加深到 .000550 的闭 EH 耳为 \(E_d\)。新的 \(C_3\)、\(B_3\) 两段短弧及直弦严格正向拼接。使用两端径向到弧内的归一化正组合，在实际耳上重验如下触发条件
\[
 z_y<s_y,\qquad |z-s|>1,\qquad e'\cdot z>1/2
 \quad(z\in\operatorname{int}E_d).
\]
其中 \(s\) 为原 EH 的 CB 圆心，\(e'\) 为负 E 斜帽法向。于是进入新耳的定宽体触发低 CB 接触，避开 \([F_3,R]\)，命中 \(F'\) 且避开闭 \(C'\) 与 \(B'\)。[新耳三条件与折弦](062-shifted-chord.md)

既有副本若已避新 EH，即可进入下一节。若进入新 EH，按照 \(A,A'\) 的命中分类。缺 \(A'\) 使用 \(Q_1\)，缺 \(A\) 的另一分支使用 \(Q_3\)，均给出同一个避旧 AH 与新 EH 的副本。二者都命中时用 \(Q_2\)，它给出仍在 \(P\) 且避旧 AH 的副本。此时只有原体和 \(Q_2\) 像双双命中新耳需要连续重摆。

对真实双命中，从这一对输入选 \(L\) 使 \(F_L(30^\circ)\ge0\)。同角重建的联合支撑模型给出
\[
 F_L(36.01^\circ)<-6.6909315874\times10^{-6}.
\]
每个实际相容根 \(\phi\) 均可用相差 \(60^\circ\) 的两个六边形中心姿态之一满足两条正斜帽线。五段 Sprague 真弧由 \(P\) 的强制接触保证。54 个闭角格和 63 份逐项验证的非负对偶处理另外的支撑条件，最弱严格余量超过 \(1.0537060313\times10^{-5}\)。在 EH 方向选择直接支撑、\(Q_2\) 支撑或同一输入上的正权平均。正权平均通过时，直接与反射支撑至少一项通过。

根姿态若进入旧 AH，先应用旧 \(Q_A\) 分支，从而避旧 AH 并避 \(F'\)，自然避新 EH。若它已避旧 AH，则直接 EH 支撑通过时原样使用。若使用反射方向且当前姿态仍触新耳，按上面的离散分类使用 \(Q_1,Q_3,Q_2\)。\(Q_2\) 的 EH 余量就是根格中通过的反射方向。全部分支遂给出同一个在 \(P\) 内、避旧 AH 与 .000550 EH 的定宽副本。[根后重新分类与正权平均](eh-deep-second-relocation.md)

## 将首次摆放送入新 AH

若上述副本进入增广 AH，1.54° 的真实物理图检验首命中点位于 \(y>.518\) 且旧 \(C\) 单位圆外，可用旧 \(Q_A\) 触发定理。这个 \(Q_A\) 像在 \(P\) 内，并因源副本避正 \(C\) 帽而避 \(F'\)。因此像同样避开 .000550 EH。若一次 \(Q_A\) 已避增广 AH，就使用这个像。

若两者都命中增广 AH，调用同角、同一实际输入的 70 个可达格证书。活跃格恰为 \(0,\ldots,69\)，各格的物理首命中子格从冻结图重新定位。根端最小严格余量大于 \(3.8776466622\times10^{-6}\)，摆放余量大于 \(1.2521189492\times10^{-6}\)。该图的 EH 行是同一 \(1.54^\circ\) 下的 .000555 深弦。它与 .000550 弦共享 \(T_{\rm EH}\)，.000550 的新上点位于深弦裁掉侧，定向行列式余量大于 \(2.2562662066\times10^{-9}\)。同一凸基形上的两耳因此嵌套，70 格给出的同一姿态同时通过较浅 EH、新 AH 和其余真实边界。

## 面积与复算

新 AH 配对弧与线的实际交点参数位于 \([0.2069997363932266745537,0.2069997363932266745538]\)，严格小于物理覆盖的 .207 远端。有理 Green 积分得到新 AH 帽。EH 用同角真圆弧积分。EH 矩形全域对新 AH 保留侧的余量超过 .45918，所以两处面积扣减可相加。每块闭耳由其内部取闭包，满维定宽副本避开耳的内部就属于闭的候选覆盖。配合平面定宽补全，得一般覆盖。

    mkdir -p WORK
    python -I -B computation/certify_sigma154_eh_transfer.py COMP \
      computation/eh-sigma-154-single550-weights.json \
      COMP/sigma-154-ah-reachable-full-certificate.json \
      COMP/sigma-154-ah-reachable-full-parameters.json WORK > WORK/replay.json
    cmp WORK/replay.json computation/sigma154-ah429-eh550-composition.json

`COMP` 为主线 computation 目录。程序重新定位活跃 AH 格和两弦几何，重放 EH 端点对偶、R34 首次摆放几何与全部面积；70 格的真实双命中严格验证作为哈希绑定的独立证书使用。

## 十一面 EH 的同比微缩

把原十一面方案的每个 EH 圆弧位移深度乘以 .997，保持铰点比例与两条单位法向的绝对退距。最深上点 \(V\) 的深度为 .00055677465。重验松弛两线的交点严格位于该段弧端三角形内，经过该点的两个新法向各是原两个法向的严格正组合。九条新增线的实际命中高度及支撑行也在新几何下逐一重算。所有十一条线都成为真实边界。[十一面原方案的分类与圆弧积分](eh-upper-chain.md)

同一输入的两个 EH 违例点仍按四种旧类型、\(H0,0H,1H,HH\) 和九种实际高点线的 \(H1\) 子型覆盖。对每个类型验证端点支撑对偶。十七类最弱的右端上界仍严格小于 \(-3.4417244932\times10^{-6}\)。在这个最深单弦上重跑 54 个闭角格和 63 个放置对偶，最小放置余量超过 \(9.8419200905\times10^{-6}\)。旧 AH 恢复及 \(Q_1,Q_2,Q_3\) 后续分支按上文作用于该单弦耳，避开其中每一条实际十一面裁线。

记 \(T=T_{\rm EH}\)，\(n_{555}\) 和 \(n_V\) 分别为 .000555 弦和新深弦从保留侧指向耳内的单位法向。若 AH 共同根姿态中的点 \(z\) 违反新深弦，则 \(z\) 落在深弦耳中。两端短圆弧在坐标上单调，故 \(|z-T|\le |V-T|\)。因此
\[
 n_V\cdot(z-T)\le n_{555}\cdot(z-T)+|V-T|\lVert n_V-n_{555}\rVert.
\]
第二项严格小于 \(9.487569003631\times10^{-8}\)。原 AH 共同根的 .000555 行余量扣除该项后仍大于 \(1.1572432591\times10^{-6}\)，与新深弦违例矛盾。这样十一面 EH 与 .429/.0062 AH 的真实裁线由同一姿态通过。

两处裁切仍由整矩形严格分离。把最深真实弦耳的 Green 积分减去弦与十一面链包围的有向多边形面积，得到新 EH 实际切量。最终覆盖面积在
\[
 [0.8440919815784276083536,\ 0.8440919815784276926252]
\]
内，较第 201 轮严格减少 \(2.6330892902\times10^{-9}\) 以上。

    python -I -B computation/certify_sigma154_eh_chain.py COMP \
      computation/eh-sigma-154-chain997-weights.json \
      computation/sigma154-ah429-eh550-composition.json > WORK/replay-chain.json
    cmp WORK/replay-chain.json computation/sigma154-ah429-eh-chain997-composition.json

\[
 [0.8440910089201477057445,\ 0.8440910089201477900160], \qquad
 [0.8440910087888860304414,\ 0.8440910087888861147129].
\]
该面积计算复用首次 EH 摆放，.009 的 AH 双命中新姿态由另一个可达图证书承担。若该图的 .000555 行余量严格超过上述法向损失，两个面积区间都适用于相应组合的万能覆盖。

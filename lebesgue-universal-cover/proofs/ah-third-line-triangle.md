# 在第126轮 AH 折点增加第三条裁线

沿用第126轮的斜角、宽一六边形和两段 EH。在原 AH 两线之外，加上铰点参数 \(p_3=0.404\)、转角 \(\delta_3=0.00046\) 弧度的第三条裁线。所得凸体仍为万能覆盖，面积严格位于

\[
(0.844093398874130923149790692260851114163,
\ 0.844093398874130923149790692260851114248).
\]

面积相对第126轮减少超过 \(2.2090693423\times10^{-9}\)。第150轮60点与第156轮18点同时通过独立支撑检查，且各自可原位进入。

## 保留全族摆放

令 \(D=T_a-Z\)、\(b=-D/|D|\)、\(n=Jb\)。第126轮已有两条线 \((p_1,\delta_1)=(0.355,0.00060)\)、\((p_2,\delta_2)=(0.410,0.00030)\)。在坐标 \(x=Z+wD+|D|y n\) 中，第 \(i\) 条线保留 \(y\ge a_i-b_iw\)，其中 \(a_i=p_i\tan\delta_i\)、\(b_i=\tan\delta_i\)。三条线联合切掉的帽仍只涉及已认证的旧 AH 直段和配对弧邻域。帽的高度逐格使用三个仿射上界的最大值，直接重算第112轮的触发不等式、图参数亏损及双命中相容根。

先由第126轮的 EH 部分把定宽一体放到 \(P\) 内，同时避开旧 AH 及两段 EH。若命中新的 AH，则触发反射 \(Q_A\)。反射像仍在 \(P\)，避旧 AH。又因为原体避正 C 帽，其反射像避 \(F'\)，因而避开深度 \(0.000555\) 的 EH 包络耳，也避开两段 EH 耳。若两姿态均命中三线 AH，则在旧相容根证明的 2205 个闭参数格上重算。对每个角括使用 32 个子格，把 EH 支撑比较直接放在第126轮深度 \(0.000555\) 的包络弦上。扣除接触误差后，根两端的符号余量严格大于 \(2.27679\times10^{-5}\)，摆放支撑余量严格大于 \(4.71610\times10^{-5}\)。真实 Sprague 圆弧的五个原强制接触仍适用，故该同一刚体姿态满足新宿主全部边界。

重放使用固定 SHA256 的旧 AH 验证器。只改第三线参数、被测 EH 深度及其对应的第126轮证书读入。旧角括、分格和误差公式均沿用。尝试更深的 \((0.409,0.00050)\) 时，旧固定角括对 \(Z\to T'\) 的最后一条内弦会失去约 \(4.9\times10^{-7}\) 的支撑余量。对该区间收窄角括后，新的不足出现在参数 \(w=0.35\) 附近的低根符号。这个试算只定位了现有全族判据的局限。

## 追加裁切的面积

有 \(b_1>b_3>b_2>0\)。设 \(w_0=(a_1-a_2)/(b_1-b_2)\) 是原折点。第三条线与旧两线分别交于

\[
w_1=\frac{a_1-a_3}{b_1-b_3},\qquad w_2=\frac{a_3-a_2}{b_3-b_2}.
\]

定向区间证实 \(0<w_1<w_0<w_2<p_2\)，三个坐标约为 \(0.194,0.300,0.39275\)。仅在 \((w_1,w_2)\) 内，第三线高于原两线的最大值。这一区域的三个物理顶点分别是两个新交点与原折点。对原曲线的有理内侧取弦生成的凸多边形，核验这些顶点具有大于 \(2.0029\times10^{-7}\) 的支撑余量；对旧 AH 两支撑线的满足由上述交点顺序得到。因此该三角全部位于第126轮旧宿主内。增加第三条线后恰少去它的面积

\[
\Delta=\frac{|D|^2}{2}(w_2-w_1)(a_3-b_3w_0-a_1+b_1w_0).
\]

该式不涉及配对弧积分，直接用定向区间得到两个有理端点。将这两个端点与第126轮的原有面积区间相减，得到正文的新面积上端。

## 第150、156轮反例的约束

第150轮排除的宿主 \(Q\) 把 EH 切至深度 \(0.0072\)，并外扩东侧宽一面。新盖保持原六条宽一夹带，不再尝试通过外扩 \(Q\) 恢复覆盖。第126轮第一段 EH 上端 \(U_{0.000555}\) 在三条新旧 AH 线的保留侧，因此仍在新盖边界。对 \(Q\) 的 \(0.0072\) 弦，这个点的外向距离严格超过 \(0.00021093\)，也就超过第150轮排除的 \(0.0000211\) 邻域。直接把第150轮60点和第156轮18点代入新盖的内多边形，两个输入都在恒等姿态下得到大于 \(2.15\times10^{-14}\) 的严格边余量。

## 复算

从含第126、150、156轮归档的课题目录运行

```sh
python -B computation/certify_ah_three_line_cut.py computation .404 .00046 OUTPUT.json
```

实际用 Python 3.13.18 和 python-flint 0.9.0 运行。验证不调用 SciPy；回执记录替换后的证明脚本哈希、候选面积精确端点与两组有限输入的独立摆放结果。

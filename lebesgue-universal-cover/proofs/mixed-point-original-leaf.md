# 在 0.83745 的完整原叶上验证中心内多边形

第161轮的旧六组包括圆盘、正定宽三、五、七、九边形和三十点 \(P_{30}\)。给定 \(Q_{11}\) 作为第七输入，在 \(T=0.83745\) 的两个真正 Tomar 原闭叶 \((1205,140208)\)、\((1205,140080)\) 上，七组在共同20万节点预算内均完整排除。六组对照在两个原叶上都用尽预算。各阶段由原闭叶起算，允许各体独立旋转、反射和平移，包括两个有限输入各自的姿态。

| 原叶 | 六组完整节点数 | 普通 \(Q_{11}\) 面积帽 | 中心内多边形库与普通帽联合 | 联合方式的中心终端数 |
| --- | ---: | ---: | ---: | ---: |
| 1205/140208 | 233,309 | 83,919 | 78,509 | 900 |
| 1205/140080 | 314,309 | 118,319 | 109,929 | 1,186 |

在第一个原叶，完全停用普通 \(Q_{11}\) 帽，只使用由中心内多边形提供的长边联合帽时，173,897节点闭合，3,144个终端由中心证书关闭。这个对照仍先运行同一套旧五体整数扇和 \(P_{30}\) 判据。

单独构造18个纯混合面积中心证书，保留原叶根中心并加入17个真实后裔盒的中心。停用普通 \(Q_{11}\) 帽及联合长边帽后，第一个原叶以233,255个节点完整闭合，其中17个为纯混合面积终端。预算若取233,280，六组仍用尽预算。纯混合面积在这一个对照上净省54节点。仅原叶根中心给出的纯混合面积证书有严格半径 \(0.000902031\) 以上，但在含普通帽或长边帽的树中没有先触发终端。这一区别使根中心证书的强度与实际搜索收益可以分别核验。

## 从一个中心过渡到完整参数子盒

对中心 \(q\) 的五体凸包 \(C(q)\)，按有理采样、向内缩放和整数凸包得到内多边形。参数中心取原叶或真实后裔盒的有理中点。冻结库保存11维整数分子，公共分母为 \(2^{45}\)。给定输入盒 \(B\)，逐坐标取 \(B\) 端点到中心坐标绝对差的最大值。对四个正定宽体分别用
\[
 d_n(B,q)=\sqrt{\Delta x_n^2+\Delta y_n^2}+L_n\Delta\theta_n
\]
作为其运动误差。三边形方向固定，取 \(L_3=0\)。另三者的常数可分别取 \(0.163,0.115,0.089\)，由 \(\tfrac12\tan(\pi/(2n))\) 的 Arb 上界给出。圆盘固定。各体取凸包后，Hausdorff 距离不超过这些误差的最大值。运行中以整数平方核验 \(d_n(B,q)\le r_q\)，只有整个盒满足中心证书半径时才关闭。

对于纯混合面积库，若某转角格的平衡权证书给出混合增长 \(\gamma\)，以 \(P\) 记相应中心内多边形，并用 \(p\) 表示其有理周长上端。设 \(w_i\) 为该格混合权，\(\ell_i\) 为对应边长。第166轮的单向支撑预算说明，只要
\[
 |P|+\gamma-r_q\bigl(p/2+2T-\sum_i w_i\ell_i\bigr)>T,
\]
就在该格排除了所有平移。子盒的三十点摆放从未被固定。这个不等式对冻结库逐格、逐手性复核后，才将整数半径传给纯整数搜索。

联合长边库沿用第166轮的相离帽预算。对给定中心半径 \(r_q\)，把 \(P\) 缩入 \(B\) 中所有真实五体凸包。第161轮为含这个五体凸包的同一六体族提供面积下端 \(0.83740\)，因此在设定靶值下，宿主相对所含六体可以增加的面积至多 \(0.00005\)。对 \(Q_{11}\) 的全角格用相离长边帽分配此预算。每个中心都重新算其实际边长、角格和联合下端。脚本重新核验圆盘加一点的径向限制。所有证书作用于闭盒，角格覆盖两个手性的完整一周。

## 复用的成本和范围

32项的主库含一个原叶根中心纯混合证书及31个长边联合帽证书。它只用 \((1205,140208)\) 搜索的子盒提议中心。相同冻结库复用于 \((1205,140080)\) 时把普通七组方案的搜索节点再降低8,390，约7.1%；前一个原叶再降低5,410，约6.4%。在第165轮已有的2,083个原叶端点上，以整数判定32个几何区域与原叶的交，得到191个相交原叶。三组额外留出原叶 \((1205,139729),(1205,140281),(181,184606)\) 在20万节点范围内尚余子盒，对照和共享库所得访问数相同。几何相交只度量候选的可复用范围。

本机记录的单次搜索阶段，以普通帽和联合方式对照，在两个成功叶上分别约为2.33比2.06及3.19比2.88个CPU秒。32项中心库的全证书检查约9个CPU秒，尚不合算于逐叶专门生成。单独的18项纯混合面积库约耗5.7个CPU秒核验，远超54节点的节约。已有两次整叶成功说明中心证书可跨叶执行；更大范围的收益取决于相交区域在搜索中实际成为终端的次数。这里的一般下界仍沿用已完成的全域证书。

## 复算

COMP 指向公开计算目录，TREE 为 Tomar v9 cert11d_08366，TABLE64 为第160轮已认证的64级材料表，CACHE 为 Clang 共享模块目录。以下各次使用独立的工作输出目录。两套本机 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0 及带溢出停止的 Apple Clang 21.0.0 重放。两套环境复算成功树的节点和终端数一致；CPU 时间另记。

    python -B computation/replay_mixed_point_leaf.py COMP TREE TABLE64 WORK CACHE \
      --target .83745 --cases 1205/140208 1205/140080 --budget 200000 \
      --modes 0 1 2 3 --reuse 1205/140208 \
      --cert computation/mixed-point-cap-bank-083745.json \
      --overlap-index COMP/tomar-083741-retained.json

    python -B computation/replay_mixed_point_leaf.py COMP TREE TABLE64 WORK2 CACHE \
      --target .83745 --cases 1205/140208 --budget 233280 --modes 0 2 \
      --cert computation/mixed-point-only-bank-083745.json

六组完整节点数可用 --modes 0、--budget 1048575 重做。中心库中的角格、精确平衡权、半径和绑定的原点表在每次搜索前全量算术核验。浮点LP只在生成阶段提出候选。

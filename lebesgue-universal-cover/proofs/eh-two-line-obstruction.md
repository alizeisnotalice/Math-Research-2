# 两段 EH 的支撑限制与连续参数障碍

固定 \(\sigma=1.5497^\circ\)，记 \(S_A\) 为原凸多边形 \(P\) 去除三块 Sprague 耳和旧 AH 后的闭凸体，EH 处保留真弧。保留原 EH 下端 \(T\)。令

\[
U_d=C_3+R_{-d}(U-C_3),\qquad W=(1-r)U_e+rT.
\]

以折线 \(U_dWT\) 代替两段原弧。这里 \(d\ge e\) 是上端深度，\(e\) 固定第二段支撑线，\(r\) 是折点在 \([U_e,T]\) 上所占比例。只考察原弧与这两条支撑线围成的局部 EH 切除。严格认证的单弦深度 \(0.0005522\) 是面积比较基准。

当 \(e=0.00055\)、\(0.00055\le d\le0.006\)、\(0\le r\le0.99\) 时，这族两段 EH 中任何面积优于基准的轮廓都不能作为万能覆盖。对同样的 \(d,e\) 及 \(0.99<r\le1\)，若该轮廓能进入万能覆盖，则它相对基准可额外切除的面积严格小于 \(4.52\times10^{-12}\)。独立的 48 个轮廓试算含有 43 个严格优于基准的面积，逐个构造反例排除了这 43 个，其中包括若干 \(e\ne0.00055\) 的值。

## 从有限点集到补全的支撑条件

第117轮的 18 点集 \(X\) 带三组原六边形单位接触。其任一定宽一补全在 \(0<\phi<60^\circ\) 的相容函数严格为正。因而补全进入原宽一六边形时，只可能处在零平移的原六边形对称姿态。原正帽再排除其中十种，剩恒等和 \(Q_2\)。以下每个新反例都由同一验证器逐个复算上述全角结论。旧见证的两个 EH 点记为 \(z\in X\) 和 \(z'\in Q_2X\)。若候选体保留于两条半平面 \(n_j\cdot x\le b_j\)，其万能性要求

\[
\bigwedge_{j=1}^2 n_j\cdot z\le b_j
\quad\text{或}\quad
\bigwedge_{j=1}^2 n_j\cdot z'\le b_j.
\]

对全点集的相应必要条件可把 \(z,z'\) 分别换成 \(h_X(n_j),h_{Q_2X}(n_j)\) 的支持不等式。这个条件对同一反例的任意局部裁切都成立，与裁切边数无关。

为了判断全部补全，令 \(L=\bigcap_{x\in X}\overline B(x,1)\)。每个补全都在 \(L\)。若一个固定姿态下 \(L\) 满足全部新支撑不等式，该姿态就对所有补全都满足这些不等式。允许姿态随补全改变时还有一个精确判据。设整个候选集为 \(C\subset P\)，则存在某个补全在恒等和 \(Q_2\) 下都进不了 \(C\)，当且仅当存在

\[
p\in L\setminus C,\qquad q\in L\setminus Q_2C,\qquad |p-q|\le1.
\]

必要性取同一个补全中的两个违例点。充分性对 \(X\cup\{p,q\}\) 作定宽一补全，因为每个新点到所有 \(X\) 点的距离已由 \(L\) 控制，新点彼此的距离也满足直径约束。该判据保留了所有补全共用同一输入的量词。

取 \((d,e,r)=(0.001,0.00055,0.08)\) 时，在恒等姿态下旧 \(X\) 仍越第一段线。在 \(Q_2\) 下，整个 \(L\) 满足两条 EH 支撑线，余量分别严格大于 \(9.87779\times10^{-6}\) 与 \(1.020298\times10^{-7}\)。\(Q_2L\) 对 \(C'\) 帽的支撑余量也严格大于 \(0.00243309\)，故第33轮 AH 触发条件保证每个补全避开旧 AH。原正帽与 Sprague 接触结论同时适用，因此同一反射恢复了旧 \(X\) 的全部补全。横向调整所对应的 EH 总面积增益严格大于 \(1.31832844623505214\times10^{-7}\)。然而另一组 18 点对同一轮廓的两个可用姿态均严格越线。固定旧见证补全的恢复与一般覆盖在此得到不同结论。

## 折线的几何及单调性

第二段所在直线与原两弧交于 \(U_e,T\)。为便于计算，把朝右的一面写成 \(x\ge L_i(y)\)。令 \(k=(W_x-U_{d,x})/(U_{d,y}-W_y)\)，则第一段为

\[
L_1(y)=W_x-k(y-W_y)=U_{d,x}+k(U_{d,y}-y).
\]

第二段斜率绝对值记为 \(k_2\)。原 C₃ 圆的左边界 \(x=C_{3,x}-\sqrt{1-(y-C_{3,y})^2}\) 关于 \(y\) 严格凸。\(U_d\) 位于 \(U_e\) 上方，且 \(U_d,U_e\) 始终在该圆左下短弧上。第二段由 \(U_e\) 出发的斜率大于该点圆切线斜率，故 \(U_d\) 严格在第二段保留侧。这给出 \(k<k_2\)。又因为 \(W\) 在圆盘中且低于 \(U_d\)，圆弧严格凸给出第一段斜率大于 \(U_d\) 处的圆切线斜率。第二段在 \(T\) 的衔接沿用参考切深 \(e\) 的证书。于是 \(\max(L_1,L_2)\) 是凸折线，且切除仅发生在高度 \([T_y,U_{d,y}]\) 内。固定 \(e=0.00055\) 的计算用 \(d\le0.006\) 的正弦余弦界，确认 \(U_d\) 不越原弧上端的水平半径。

固定 \(r\) 时，\(|W-C_3|\le1\) 且 \(U_d\ne W\) 给出

\[
\frac{\partial k}{\partial d}=\frac{(U_d-C_3)\cdot(W-U_d)}{(U_{d,y}-W_y)^2}<0.
\]

因此在 \(y\ge W_y\) 的第一段活动区，增加 \(d\) 使 \(L_1(y)\) 增加。低于 \(W_y\) 的活动线仍为 \(L_2\)。固定 \(d\) 时，若 \(W'=T-U_e\)，则

\[
\frac{\partial k}{\partial r}=\frac{-W'_y(k_2-k)}{U_{d,y}-W_y}>0.
\]

因此在 \(y\le U_{d,y}\) 增加 \(r\) 会提高 \(L_1(y)\)，而高于 \(U_{d,y}\) 两条线均不切除。EH 耳在 \(d,r\) 两方向分别嵌套。总增益等于单弦 \(U_dT\) 的增益减去 \(U_dWT\) 三角形面积。退化情形 \(d=e\) 或 \(r=1\) 由相应单弦和连续性给出。

## 十个折点区间

每行在左端折点与指定上端深度处给出一组严格反例。其击中第一段的点位于 \(W_y<y<U_{d,y}\)。增加 \(d,r\) 后，这些点仍在第一段活动范围内且越线。若另一点击中第二段，越线继续成立，因为第二条支撑线固定。随着参数增大，该反例因而仍排除两个可用姿态。若上端深度低于见证深度，面积增益可由同一深度和区间右端折点的增益所控制。

| 折点比例 \(r\) | 排除深度下端 \(d\) | 若低于排除深度，EH 增益上界（单位 \(10^{-7}\)） |
| --- | ---: | ---: |
| \([0,0.004]\) | 0.001 | 1.240722 |
| \([0.004,0.01]\) | 0.0007 | 1.239958 |
| \([0.01,0.04]\) | 0.0006 | 1.241083 |
| \([0.04,0.2]\) | 0.00056 | 1.241081 |
| \([0.2,0.4]\) | 0.000555 | 1.241081 |
| \([0.4,0.72]\) | 0.000553 | 1.241442 |
| \([0.72,0.9]\) | 0.0005524 | 1.241442 |
| \([0.9,0.95]\) | 0.0005523 | 1.241499 |
| \([0.95,0.97]\) | 0.00055224 | 1.241471 |
| \([0.97,0.99]\) | 0.00055222 | 1.241528 |

基准单弦的严格增益下界为 \(1.24153221596049723168\times10^{-7}\)。最后一组反例也排除 \(r\ge0.99\) 且 \(d\ge0.00055222\) 的轮廓。故其余折点下能保留万能性的最大面积增益，至多为单弦深度 \(0.00055222\) 的增益。减去基准增益的严格差小于 \(4.52\times10^{-12}\)。这些结论依赖固定下端 \(T\) 和参考深度 \(e=0.00055\)。

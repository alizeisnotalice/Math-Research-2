# 原正六边形摆放的 EH 双命中反例

固定 \(\sigma=1.5494009336023418793^\circ\) 与 \(\delta=0.0000155\)。存在定宽一凸体 \(K\subset P\)，满足 \(Q_2K\subset P\)，而二者均命中新耳内部。\(K\) 还严格命中 \(A,A',F'\)。进一步，原正六边形的十二个二面体摆放中，无一将 \(K\) 送入该切弦所得的候选覆盖体。

记 \(Q=Q_2\)，\(p=u(7\pi/6)\)，\(D=T-U_1\)，\(k=D_x/(-D_y)\)，\(H=1/2-U_{1,x}\)，\(a=C_{3,y}-U_{1,y}\)。设

\[
y_0=\frac{1/2-p\cdot U_1}{1/2-\sqrt3 k/2},\qquad
z=U_1+y_0(k,-1)+10^{-10}(-1,2),
\]
\[
r=\sqrt{1-(H-ky_0)^2}-a-y_0-10^{-7},\qquad
b=C_3+r e_y.
\]

令 \(m=m_5\)，\(M=-m_y\)，\(s=Mr-10^{-8}\)，\(q=n_5/2\)，取

\[
w=b+(s-1)m-\sqrt{2s-s^2}\,J_0m,
\qquad X_0=\{z,b,b-n_0,w,w+m\},\qquad
X=X_0\cup QX_0\cup\{-q,q\}.
\]

七个点对的距离由构造严格等于一。三对为 \((b,b-n_0),(b,w),(w,w+m)\)，三对是其镜像，另一对为 \((-q,q)\)。其中 \(|b-w|^2=(1-s)^2+2s-s^2=1\)。其余点对均严格小于一，最小平方距离松弛大于 \(5.35898\times10^{-11}\)。六个正六边形法向上各有一个点恰取 \(1/2\)。证书验证其余全部 \(P\cap QP\) 半平面不等式，最小严格余量超过 \(9.99\times10^{-9}\)。

证书给 \(-m_3\cdot Qz>1/2+0.00343823\) 和 \(-m_5\cdot w=1/2+10^{-8}\)。由 \(QX=X\)，这也给两反射切面对应的反侧点。取 \(X\) 的任一个平面定宽一补全 \(K\)。对于原六边形的各面，由 \(X\) 在对面有接触及 \(\operatorname{diam}K=1\) 得 \(K\) 仍在该面的内侧。同理，四个反侧见证强制四条斜切面，故 \(K\subset P\cap QP\)。于是 \(K,QK\) 均含 \(z\)。

新耳可写成两个单位圆盘交在新弦的右侧部分。弦经过 \(U_1,T\)，且证书验证 \(U_1\) 严格在 \(B_3\) 圆内、\(T\) 严格在 \(C_3\) 圆内。弦出段的两条射线各被一个相应圆盘排除。两圆的两个交点分属新弦两侧，且 \(J\) 位于右侧，故带截线的圆盘交边界恰由 \(U_1\to J\to T\) 的两段短弧与弦组成。证书核验 \(z\) 对两个圆盘及新弦的不等式都严格，所以 \(z\) 在耳内部。\(Qw\) 在 \(A,A'\) 的严格侧，\(w\) 在 \(F'\) 的严格侧。

对其余十个正六边形二面体变换，证书各给出 \(X\) 中一个点，其像越过 \(P\) 的 \(m_3\) 或 \(m_5\) 截线。恒等与 \(Q\) 均因 \(z\) 失败。因此原五个刚体运动及其他固定正六边形二面体摆放在此 \(\delta\) 均失效。任意角度与平移的摆放仍待检验。

Python 3.13.18 与 python-flint 0.9.0，实际运行退出零。`computation/witness_eh_double_hit.py OUTPUT` 写出坐标包络、距离松弛和各摆放的证点。`computation/067-witness.json` 是本次输出，计算采用 160 位 Arb。

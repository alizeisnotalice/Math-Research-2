# 连续斜角下四个旧顶点的必要移位

设 \(1.50^\circ\le\sigma\le1.54^\circ\)，\(G_\sigma\) 为原 Gibbs 宿主，\(C\subseteq G_\sigma\) 为任意闭凸万能覆盖。以下顶点均随斜角定义，法向等式的偏置均为 \(1/2\)。
\[
 B_1=n_0\cap n_1,\qquad F_1=n_2\cap n_3,\qquad
 D_1=n_4\cap n_5,\qquad C_3=n_0\cap m_5.
\]
若 C 含这四点，则其面积严格大于 .844082371714350267716580889258117757。若面积至多为 B=.844082046521218581802948589770767704354，则四点中至少一点到 C 的欧氏距离严格大于 .0000002306。这个结论允许 C 任意改动其他边界。原 Gibbs 宿主的包含条件用于约束定宽扰动体的全部连续姿态。

## 强制轮廓的所有边

令 \(\Gamma\) 为如下有向边界。由 \(B_1\) 连 Q，沿 E₃ 单位圆至 Y，沿其镜像圆至 \(T_a\)，沿原直线至 \(x(.435)\)。接着依次连 \(q(.435),q(9/20),q(10/20),\ldots,q(1)=T'\)。从 T′ 沿 G 单位圆至 P，连 \(F_1,E\)，沿 S 单位圆从 E 至 T，沿 B₃ 单位圆到 I。再连 \(E_3,D_1,G\)，沿 F₃ 单位圆到 K，最后连 \(C_3,B_1\)。

前三组定宽见证强制四段真弧 \(QY,YT_a,GK,TI\)。QY 见证本身含圆心 \(E_3=n_4\cap m_3\) 这个锚，故亦强制它。T′P 的强制性来自 w=1 的八锚圆盘交。这些断言适用的母宿主分别是两帽域 P(σ)，或附加原 AH 半平面的 P(σ)，而 \(C\subseteq G_\sigma\) 满足相应包含条件。四套证明见项目 proofs/sigma-mandatory-arcs.md、proofs/sigma-paired-rigidity.md 及本包 joint-arc-proof.md。ET 的整段 S 弧和 AH 的十三个配对点及 \(x(.435)\) 由本次证明强制。其余边由两个已强制的端点与凸性，或由题设四个旧顶点之一与相邻端点之间的凸性得到。因而四点都属于 C 时，整个 \(\Gamma\) 及其内部均属于 C。

## 全斜角和真实反例

把斜角区间均分成 200 个闭格，对每个闭格和十三个 w 值联合作根隔离与两条斜帽姿态排除。AH 使用 730877 个闭相容角盒，TI 使用 16774 个，GK 和 QY 分别使用 9000 个和 2600 个。AH 配对点的外切线排除在需要时继续细分当前斜角格。终端符号对整个角格成立。

\(\Gamma\) 只包含有限段真短单位圆弧与直线，故其面积由上述顺序的 Green 式直接给出。在每个斜角格用中心二阶导数展开面积的一阶导数，并以整格四阶导数的严格余项界验负。对每条弧分别验半径内积正，叉积以中心展开和整格三阶余项验证严格正。程序内导数针对弧度。将 ET 的 S 弧换成 ET 直弦所得闭凸宿主的面积导数也在全域严格为负。两种面积各自的极值因此位于如下端点。
\[
 \min_\sigma |\operatorname{int}\Gamma_\sigma|
 >.844082371714350267716580889258117757,\qquad
 \max_\sigma |C^{\rm chord}_\sigma|
 <.844079998138643738622641440751839816 .
\]
前者在 \(1.54^\circ\)，后者在 \(1.50^\circ\)。整个斜角区间均采用 joint-arc-proof.md 的实际定宽反例，谐波混合权重为 \(10^{-7}\)。ET 所对的弧角平分点与弦的距离为 \(b/(1+\sqrt{1-b})\)，其中 \(b=|T-E|^2/4\)。从这个量扣除混合权重乘以 \(1+|S|\)，所得统一外超量大于 .0001304169。全域面积由有限 Green 公式独立求出，四个先前单角的原配对弧积分提供另一种复算路径。

## 四个顶点同时小幅移动

记四个顶点 \(v_i\) 到 C 的距离为 \(d_i\)。先设所有 \(d_i\le10^{-6}\)，取 C 中距各顶点最近的点 \(v_i'\)，替换上列轮廓中的对应点。各段直边、其余固定弧及新顶点都在 C 中。原曲线围住原点。以原点为圆心，四个被替换顶点与相邻顶点的有向行列式在全部斜角上大于 .12，且顶点模长小于 1。替换后，每个相关行列式变化不超过 \(2\cdot10^{-6}+10^{-12}\)。在把旧顶点线性移动到新顶点的整个过程中，相邻极角保持原来的严格次序。原曲线上的其余弧与弦均保持原次序，得一个简单闭轮廓，其内部包含于 C。原点可由居中宽一圆盘的唯一平移看出属于 C。

单顶点改变引起鞋带面积的一次项绝对值至多是其相邻两顶点距离的一半乘以 \(d_i\)。四个变量中只有 \(C_3,B_1\) 在轮廓中相邻，故仅有一个二次项。于是
\[
 |C|\ge |\operatorname{int}\Gamma|-\tfrac12\bigl(
 |Q-C_3|d_{B_1}+|E-P|d_{F_1}+|G-E_3|d_{D_1}+|B_1-K|d_{C_3}
 + d_{B_1}d_{C_3}\bigr).
\]
程序在全部200个斜角格验算这四个系数的统一上端。四个距离皆至多 \(2.306\times10^{-7}\) 时，面积损失严格小于 \(\min_\sigma|\operatorname{int}\Gamma|-B\)，从而排除面积不超过 B 的万能覆盖。某个 \(d_i>10^{-6}\) 时所需结论已经成立。

另一个较粗的独立检查将上述四点添入 C 并取凸包，所得体仍普适且包含于 \(G_\sigma\)。若四点离 C 均至多 d，该凸包包含在 C 的 d 平行体内。由 Steiner 公式及正六边形的周长，面积损失至多 \(2\sqrt3 d+\pi d^2\)，给出 \(d>.00000009387515\)。

# 面积缺口控制单个有理障碍的点数

设 Λ 为平面凸万能覆盖的最小面积。取 N≥3 和整数 q≥2，考虑正方形 [−1,1]² 中以 q+2 为公共分母、直径至多一、至多 N 点的全部非空集合。它们构成与待测宿主无关的有限目录。记

    E = 3π²/(8N²) + 2/(q+2),     r_N = (1/2)cos(π/N) − 2/(q+2).

若 r_N>0、G≤Λ，并且

    A(1+2E/r_N) + πE² < G,

则对每个面积至多 A 的紧凸宿主 C，目录中至少有一个点集无法以任何平面等距变换置入 C。点集可随 C 改变。该结论给出固定宿主的最大见证规模，求出具体坐标仍需要测试该宿主。

## 用弧长和转角的和采样

按平面定宽补全定理，只需覆盖全部宽一体 K。设 h 为支撑函数，u(θ)=(cos θ,sin θ)，v=u′。非负曲率测度 μ=h+h″ 满足 μ(θ)+μ(θ+π)=dθ，故具有密度 ρ，0≤ρ≤1，且其积分为 π。于是 h 为 C¹,¹，唯一支撑点 x=hu+h′v 满足 x′=ρv（几乎处处）。角点对应 x 为常值的角区间，也包括在内。[Harrell，支撑函数与曲率关系，公式 (1)、(3)、(8)–(10)](https://harrell.math.gatech.edu/Pubs/reul.pdf)

将总质量为 3π 的 (1+ρ)dθ 等分，取 N 个分点对应的支撑点。对任意方向，从该方向到最近分点可取一条参距 w≤3π/(2N) 的弧。记其转角为 t，弧长为 L，于是 w=t+L。两种行进方向上，分点对所选方向的支撑亏损均形如 ∫₀ᵗρ₀(z)sin(z)dz，其中 ρ₀ 是沿所选弧读取的密度。用 sin(z)≤z，在密度上限一和总质量 L 下，把质量放在 [t−L,t] 上可使一次矩最大。因此亏损至多

    tL−L²/2 = wL−3L²/2 ≤ w²/6 ≤ 3π²/(8N²).

这是对每一个支撑方向同时成立的内接凸包误差。圆盘的分点恰为正 N 边形，其内圆半径为 cos(π/N)/2。

## 合法有理化与宿主外扩

以 K 的最小外接圆心为原点，平面 Jung 界给出 |x|≤1/√3。每个样本 x 替换为 y=round(qx)/(q+2)，两个坐标各自就近取整。每对整数分子的距离至多 q+√2<q+2，因此新点集合法，且落在上述目录中。每个点的位移至多 (2/√3+√2/2)/(q+2)<2/(q+2)。于是 K 包含在新点凸包的 E 平行外扩中。这一步允许新点稍微越出原体。对圆盘样本的所有支撑下端应用相同舍入误差，所得有理点凸包仍包含半径 r_N 的同心盘。

若 C 容纳整个目录，则 C+EB 能容纳任一宽一体。又因容纳圆盘的有理样本，C 自身包含某个半径 r_N 的圆盘。以来自该圆盘中心的支撑距离积分得 Per(C)≤2|C|/r_N，Steiner 公式遂给出

    Λ ≤ |C+EB| ≤ |C|(1+2E/r_N)+πE².

这与假设矛盾。相同论证还给出一般问题的双边近似：若 L 是此有限目录的最小共同宿主面积，则 L≤Λ≤L(1+2E/r_N)+πE²。所有目录成员都有有理坐标；每组可以独立作刚体运动。

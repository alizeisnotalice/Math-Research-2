# 改变两斜角必付出的统一面积代价

固定 1.50°≤σ₃,σ₅≤1.54°，e₃,e₅≥0。宿主仅保留宽一正六边形 H 及这两条改角、外移的斜帽，可自由摆放、旋转和反射。令 d=|σ₅−σ₃|，以弧度计。当两角不等时，普适性要求
\[
 e_3+e_5>\begin{cases}.11858d,&\sigma_3<\sigma_5,\\
 .12172d,&\sigma_3>\sigma_5.\end{cases}
\]
作为比较，前述正向定理只需约 .127d 的总外移即可给出对所有定宽体有效的一次摆放。

记 \(A_i=|P(\sigma_i)|\) 为各自共角的第一阶段真实面积。任何上述不等角普适八边形都满足
\[
 A_{\rm new}>\max(A_3,A_5)+.0298d .
\]
所以改斜角在第一阶段即有严格正的净面积损失，后续要超过旧上界必须从其他边界回收这一成本。对代表角对 (1.50°,1.54°)，另一个更细的有理傅里叶见证给出 \(e_3+e_5>.000083239291\)、\(A_{\rm new}>.84537230261651728567647106688856085804\)。取 c=1.50° 并让第二帽恰通过其强制顶点即有一族实际摆放的面积上端 .845373720。由此，代表角对最小普适八边形面积的两端相距小于 .000001418。

## 随预算移动的实际定宽体

输入 uniform-mobility.json 给出两组精确有理数，以下计算不依赖发现系数时所用的线性规划。取奇频 k=5,7,…,191 中不被 3 整除者，\(\eta_k=1\) 若 k≡1 (mod 6)，另一情形取 −1。对每组数据读出有理 a<0 及 bₖ，令
\[
 V(t)=-\tfrac a8\sin3t+\sum_k\frac{b_k}{1-k^2}\big(\sin kt-\eta_k\sin t\big),\qquad
 g(t)=\sin5t+\sin t.
\]
给任意 c∈[1.50°,1.54°]，增序时取 \(x=150^\circ+c\)，降序时取 \(x=30^\circ+c\)。以 \(\beta=-V(x)/g(x)\) 并置
\[
 h_c(t)=1/2+R(V(t)+\beta g(t)).
\]
R 是各组独立核验的正有理缩放，选定后不依赖 c。h 关于纵轴反射对称，满足定宽等式，并在六个六边形方向上均为半宽。所有高频修正在三个偶方向上的和恒为零，故相容函数为 \(-3Ra\sin(3t)/8\)。连续根严格等于六十度的整数倍，对应平移恒为零。

为证明所有 h 都是支撑函数，全圈取4096个等分点。对 \(p=V+V''\)，二阶导数模不超过 \(9|a|+\sum k^2|b_k|\)。各格线性插值误差至多是此常数乘以格宽平方除以八。再加入 \(24|\beta|\) 的补正，并以 R 作有理缩放，使 \(h_c+h_c''\) 严格大于零。100个连续角格包围所有 c 和客体角，在临界相位 \(h_c(x)=1/2\) 是代数恒等式。

增序时记三个方向为 \((30^\circ+s,150^\circ+s,270^\circ+s)\)。中间支撑残差的导数在 s 的整个区间严格负，其绝对值至少 .11858；第一项恒正，第三项恒负，两者的绝对值均超过 .11858 乘整个角距 .04°（以弧度计）。降序时第一项为临界项，导数严格正，第二、三项分别恒负、恒正；相应三项的常数均可取 .12172。角格及导数的参数独立纳入，因而也覆盖 c 和受测角恰在不同格子的情形。对相位 30°−s，纵轴对称把三偶支撑按 (1,0,2) 排序。六个奇支撑由反向取补数。

设两预算之和小于相应已认证斜率 k 乘 d。可取两斜角之间的 c，使 \(e_i<k|c-\sigma_i|\) 同时成立。中值定理给每个临界残差都严格超过它相应的 eᵢ，四个稳定项也成立。增序时第3、5面正相位三偶支撑的符号分别为 (+,+,−)、(+,−,−)；降序时分别为 (+,−,+)、(−,−,+)。两手性的角标关联见 asymmetric-first-stage.md。在十二个姿态中成对残差严格异号且绝对值各超过对应的预算，所以此 h_c 无一姿态可放入。使用截短到 .11858 和 .12172 的常数均严格小于机器认证的下端，结论可写严格大于。

## 面积与代表角对

每个角点的无外移去除量是一个独立的三角形面积。故零外移异角八边形的面积恰等于 (A₃+A₅)/2。可从任何必要外移预算中向下取子预算，使两高度和恰为 .11858d。两子预算均至多 .11858·.04°（以弧度计）。在此区间，每单位外移的真实面积增加率至少为
\[
 \frac{2\sqrt3(\cos\sigma/\sqrt3-1/2-e)}{4\cos^2\sigma-3}.
\]
将 σ,e 用定向区间整体包围。两共角面积差至多为 \(\sup|A'(\sigma)|d\)，其中
\[
 A'(\sigma)=2\sin\sigma(2\sqrt3\cos\sigma-3)^2/[3(4\cos^2\sigma-3)^2].
\]
从相对平均值的增加扣除一半此差额，剩余严格大于 .02980993d。

对于指定角对，focused-3.json、focused-5.json 给出两组相容和仍为三次正弦的解析定宽体，余弦项另外使用 \(\cos kt-\cos t\)。其曲率同样由4096点及二阶导数余项验证。其一在第3帽六个指定支撑上的有符号余量大于 .0000832392916，在第5帽保留严格余量；另一体把两帽作用交换，第5帽余量大于 .0000832751510。二者的任意 Minkowski 凸组合保持相同相位、相同十二个符号和严格定宽性。若非负预算总和至多 .000083239291，选取系数即可让每个指定的第3、5帽有符号余量分别超过 e₃、e₅，排除全部姿态。在固定必要总预算时，真实面积增加量为两高度的凹二次函数之和，最小值位于全预算给某一帽的两端点之一，得到开头面积下端。

对于任意非负预算分配，在两个斜角之间按预算比例选择共同参考角。每条帽移动角度 $v$ 所需外移至多 $E(v)\le (\tfrac12\tan14.25^\circ+0.04\pi/(180\cdot4))v<.127159v$。因此 $e_3+e_5\ge.127159d$ 即足以同时放入两个帽。

三个数值证书使用 Python 3.13.18、python-flint 0.9.0、192位。scout_fourier.py 记录有理系数来源，采用 SciPy HiGHS 的定向符号线性规划；严格验证入口均不调用优化器。两条松动斜帽所付出的面积只能与后续同一姿态的弧、直边、切角节省合并。这里只给第一阶段的普适充分布置及必要成本，一般凸万能覆盖的上界仍为项目已认证值。

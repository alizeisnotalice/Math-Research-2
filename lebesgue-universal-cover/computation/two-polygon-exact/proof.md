# P30 与新 Q11 的精确自由摆放最小面积

## 定理及精确值

取 `inputs.json` 的第 221 轮正式有理 P30 和第 224 轮新有理 Q11；令两组点分别任意旋转、平移和反射，M 为它们的共同凸包面积最小值。则 M 是 `algebraic.json` 所指定的有理二次代数数

    M = a + b u,

其中 a、b 是该文件记录的精确有理数，u 是 `triple.json` 的有理二次方程在下述区间中的唯一根：

    0.108593342693011958445226574522256019480351996922779371800 ± 4.07×10⁻⁵⁸.

这里 u=tan(θ/2)，对应相对角 θ=0.21633894982906111246766879453371402406282449583… 弧度，面积约为

    0.760198857818779512765076279990898231872944360572787643054.

该数是两个指定有限输入的结果，不是凸万能覆盖面积。

## 根与实际摆放

由精确有理点构造 CCW 凸包；P 的边按 `micro-scan.json` 所保存的 CCW 列表从 0 编号。P 的边 0、7、26 的外法向分别以 Q 的顶点 5、8、3 为支撑。`triple.py` 将三条实际支撑线相交条件写为 α cos θ + β sin θ + γ=0，并代入 u=tan(θ/2)，以有理系数的二次方程隔离指定根。它验证三个 Q 支撑点各自严格唯一，求前两条线的交点作为平移，并核对第三条线；`algebraic.py` 在二次域中对第三条线的恒等式进行**精确**运算而非仅判断区间包含零。代入所有实际边的 hinge 公式得到真实可行凸包。`algebraic.py` 还对正 hinge 的活动顶点逐个做严格支撑验证，在二次域中将面积化为 `a+b*u`。

## 局部全局性

固定 P，令 Q 具有指定手性，角域取完整 [0,2π]。P 的点集经精确有理算术验证关于 x 轴反射不变，整体反射将 Q 的另一手性化为此手性，所以不遗漏独立反射。

对每个角 θ，所有 P 边和旋转 Q 边都使用带边长的 CCW 外法向。若 λ 属于 [0,1] 且这些法向的 λ 加权和为零，hinge 恒等式给出对所有平移统一有效的面积对偶下界。位于根的微格为 344314，左右端各为 2π·344314/10⁷ 与 2π·344315/10⁷，根严格在内部。`local_exact.py` 对两个闭半格分别构造随 θ 精确平衡的对偶权重，左侧两条活动边为 (7,26)，右侧为 (0,7)；全部权重处于 [0,1]。计算在整个左半格证下界导数严格小于零，在整个右半格证下界导数严格大于零。所用活动支撑点在各自整个闭半格均严格唯一。

在根处，两组对偶均满足互补松弛：只有边 0、7、26 的 hinge 等于零，恰好 8、9、10、15、16、17、20、27、28、29、33 为正，其余为负；所有非零 hinge 的绝对值严格大于 1.4089×10⁻⁵。两组对偶都在实际三接触摆放取等。故该微格中，除根外所有角度的任何平移都有严格更大面积。

`join_exact.py` 逐格拼接全域：原 10000 个粗格中 192 个各细分 100 个，其余使用粗格界（4393 格用单独区间导数界）；细格中 34431 格再分 10 个微格，其余使用粗位移界或 503 个细格的区间对偶导数界。除根所在微格外，每个格的统一下界均严格大于实际三接触面积上端；最小排除余量大于 3.0486×10⁻¹⁰。所有格是闭格，重叠边界不遗漏。于是上述三接触面积是全域最小值。

## 独立复算

从本目录执行 `python -I -B replay.py WORK`，WORK 为新的工作目录。程序绑定同仓库第221与224轮的有理点表，将三层浮点候选复制到 WORK，并重新进行严格证明。运行需要 Python 3 与 python-flint。主工位使用 Python 3.13.18、python-flint 0.9.0，在160位和192位 Arb下完成全角域及二次域核验。

# 四点宿主的精确五顶点障碍

取 D 为半径 1/2 的中心圆盘，B₂ 为单位圆盘，u(t)=(cos t,sin t)，文中角度用度。设 T 有三个顶点 u(30°+120°j)/√3，C₄=conv(D∪T)。原有四点定理表明它容纳所有直径至多一的四点集。记 Q 为正五边形五顶点构成的集合，归一化其直径为一；记 R 为这些顶点所定的宽一正 Reuleaux 五边形。对 X=Q 和 X=R 同时有
\[
 \min\{a≥0: gX⊂C₄+aB₂\text{ for some isometry }g\}
 =δ= r\cos6°+(\sqrt3/2)s-1/2=0.02497754438799409\ldots
\]
其中 r=1/(2cos18°)，b=r[(√3/2)cos6°+cos72°]，d=r²sin²6°，s=d/(b+√(b²−d/4))。Q 给出此固定宿主的最小遗漏点数五。允许反射，因为输入本身有反射对称。四点定理及 C₄ 的识别分别在主工作区 proofs/four-point-cover.md 和 proofs/adaptive-inner-cover.md 末节。

## 取得等号的摆放

令未平移顶点为 r u(6°+72°j)，平移向量 p=s u(330°)。五点关于 330° 轴对称。j=0 的平移后投影落在 C₄ 法向 0° 的竖边内，其纵坐标严格介于 0 和 1/(2√3)。j=4 是其镜像。因此这两点距 C₄ 恰为 r cos6°+√3s/2−1/2。j=1 和 j=3 位于 C₄ 的圆弧外，径向分别严格介于 60°、120° 及 180°、240°。这两点距 C₄ 恰为 √(r²+s²−2rs cos72°)−1/2。上面的 s 是两距离相等所得小根，方程是 s²/4−2bs+d=0，平方前两边均为正。j=2 位于 150° 的径向，距原点 r−s<1/√3，故在 C₄ 内。

在距任一顶点径向 ≤18° 的法向上，R 的支撑等于该顶点投影。事实上相邻两条单位弧的法线在顶点处分别与径向成 ±18°。此投影 ≥r cos18°=1/2。其余法向的对径法向必在上述顶点锥中，由定宽性得到其支撑 ≤1/2。于是 R⊂conv(D∪Q)。s<δ 给出 p+D⊂C₄+δB₂，故同一摆放容纳整个 R。

## 任意摆放下的反向界

C₄ 的圆盘支撑方向包括 [60°,120°]、[180°,240°]、[300°,360°]。旋角 φ 的最小所需外扩有周期 72° 和 120°，故有周期 24°。再关于 30° 轴作镜像，φ 变成 60°−φ，其模 24° 等于 12°−φ。只需处理 φ∈[6°,18°]。

对于任意三个此类圆盘支撑方向 v₁,v₃,v₄ 及其严格正平衡权重 w₁,w₃,w₄（权和一），任何将五点放入 C₄+aB₂ 的平移都要求
\[
 a≥ f(φ)-1/2,qquad f(φ)=r\sum_{j=1,3,4} w_jv_j\cdot u(φ+72°j).
\]
平移项被平衡恒等式消去。权重按叉积 [v₃,v₄]、[v₄,v₁]、[v₁,v₃] 正规化。三段使用以下方向。

| φ | v₁ | v₃ | v₄ |
|---|---|---|---|
| [6°,9°] | (ru(78°)+p)/(1/2+δ) | (ru(222°)+p)/(1/2+δ) | u(300°) |
| [9°,15°] | u(84°) | u(228°) | u(300°) |
| [15°,18°] | u(90°) | u(234°) | u(306°) |

三段的权均严格正。因 f''=−f（导数用弧度），且每段 f>0，核验端点即涵盖整段。第一段左端按三点接触及平衡严格等于 1/2+δ，右端超出 .0000125032。第二段两端超出 .0000330715。第三段左端超出 .0000330715，右端超出 .0007535677。故所有等距变换所需外扩均 ≥δ。以上界的实数符号和三角端点可由本目录仅依赖 python-flint 的 verify_three_arcs.py 复验，无角度搜索。原 47 段独立计算由 verify_concrete.py 保存。

复现命令（在本目录执行）；实际版本 Python 3.13.18、python-flint 0.9.0、192 位。
```sh
python -I -B verify_three_arcs.py three-arcs.json
```

# 第四层全部余叶的首轮整叶排除

第四层保留的 5,442 枚原叶分布于 170 个非空分片。逐号核对发现，其中 3 枚已由先前整叶证书关闭。本次实际执行其余 5,439 枚原叶的终端。新增 2,160 枚整叶在原始闭参数域上严格排除到 \(0.83750\)。与先前三枚合并后余 3,279 枚。

| 证书中实际使用的输入 | 新闭原叶 | 含旧三叶 |
|---|---:|---:|
| 五个曲体 | 459 | 461 |
| 五个曲体及原 \(P_{30}\) | 1,590 | 1,591 |
| 五个曲体及原 \(Q_{11}\) | 111 | 111 |
| 合计 | 2,160 | 2,163 |

所有选中的原 \(Q_{11}\) 树均来自七输入模式，其中每棵的 \(P_{30}\) 终端计数为零。因此这些证书可归为五体加原十一点，归档时与原三十点六体分列。本次未使用其他新十一点输入。

首次遍历用 4,095 或 8,191 节点预算。分片 0181、1205 的部分余叶追加原 \(Q_{11}\)，0181 的 160 枚候选按前两次的真终端信息被分到 32,767 节点的三种模式。共 7,291 次尝试，记录 42,986,457 次真实访问，5,131 次预算退出。每个成功结果均重新核对其原闭叶上下端点、输入模式和完整二叉计数。对同一原叶的多次证明只计一份。上表中的七体分类只标出实际使用的十一点，保留具体 \(P_{30}\) 与 \(Q_{11}\) 终端计数。

最后补齐的 128 个分片共 790 枚首次任务，其中 649 枚在短预算下全整叶关闭。四个共享批次分别生成共用密材料表及 256 段转角支撑网格。另在 0181 和 1205 做独立有限回归，两片合计验证 1,562 个整数材料行切片一致、1,008 次 Arb 真支撑比较通过。联合区间共享的证明条件见 PORTABLE.md。

新闭叶与旧闭叶、未闭叶的并集逐号等于完整第四层余集。所有未闭叶整棵保留。一般 \(0.83750\) 下界仍须关闭这些原叶及核对相应全域转移。

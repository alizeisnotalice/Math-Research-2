# 三个 Tomar 预登记原叶在 \(0.83750\) 的严格排除

固定圆盘中心与三边形方向，取 Tomar v9 的三个完整闭原叶。每个达到的排除都允许指定输入各自转动、反射和平移。

| 分片与原叶 | 输入 | 访问节点 | 实际终端 |
|---|---|---:|---|
| 1205/140208 | 五个曲体 | 109,641 | 五体 54,821 |
| 1205/140080 | 五个曲体 | 122,279 | 五体 61,140 |
| 180/24225 | 同五曲体与原三十点 \(P_{30}\) | 5,615,271 | 五体 522,841，三十点 2,284,795 |

180/24225 的三十点终端中 1,813,759 个使用整盒弦帽。原叶的 11 维端点采用 \(2^{-44}\)，面积门槛采用严格大于 \(67/80\) 的整数 \(120696470013529293/2^{57}\)。每次二分都保留两个闭半盒，共同中分面由任一支有效覆盖。所有节点排除合成后，每个指定原叶内的联合凸包面积严格大于 \(67/80\)。一般万能覆盖的其余原叶仍需证明。[整盒弦和面积帽证明](PROOF.md)

## 依赖与从头复算

COMP 指本仓库的 lebesgue-universal-cover/computation。源模型和点云沿用 COMP 的 tomar-six-high-input.json、finite-point-leaf-input.json、finite-point-global-input.json 及既有认证入口。纯五、纯六重放都只读取原三十点数据文件。纯五模式跳过所有外加点帽。纯六模式关闭十一点分支。两种模式共用同一个严格五体核与材料表。

TREE 来自 Tomar v9 的 cert11d_08366.tar.xz。源压缩包的 SHA-256 为 6b5d28bc488edcfde9c6a49f3cb364f9086f445a58f85f166da23727036cf122。程序绑定已解压目录中的 SHA256SUMS、part0000.json 及对应原叶的 part0180、part1205 的 JSON 头和 NPY 预序数据。原树只提供闭盒端点和分割地址，各闭盒重新计算。 [Tomar v9 补充数据](https://doi.org/10.5281/zenodo.23717912)

使用已有 Python 3.13.18、NumPy 2.5.5、python-flint 0.9.0、Arb 128/160 位与 Apple Clang 21.0.0。可由 COMP 的原生成器还原 64 级旧材料表，再逐格认证并绑定整数数组。WORK 放可再生计算，CACHE 指共享 Clang 缓存。下列命令从本包目录运行。

~~~sh
python -I -B "$COMP/tomar_fan_table.py" "$TREE" "$TABLE64" --subdiv 64

python -I -B replay_three_leaves_083750.py \
  "$COMP" "$TREE" "$TABLE64" "$WORK" "$CACHE" --workers 4
~~~

程序先从 180/24225 原根以 100 万节点搜索实时生成 15 个未闭子树。每项整数地址 \(2k+s\) 表示沿坐标 \(k\) 选第 \(s\) 个闭半盒。分组取前 9 个、次 4 个、最后两个各单列。从当前闭子树重算三十点支撑锚，四组均保持整数端点和原独立平移。每组都完整闭合后核对真实原叶坐标、前沿地址、所有父节点分割坐标和终端总数，最终原叶无未闭地址。两个纯五叶分别从其原始闭根搜索。总回执在 WORK/three-leaf-result.json。

## 检查冻结回执

~~~sh
python -I -B replay_three_leaves_083750.py \
  "$COMP" "$TREE" "$TABLE64" "$AUDIT_WORK" "$CACHE" --audit-frozen frozen
~~~

此入口重构三个原闭叶的覆盖账本，并核对冻结的节点与终端数。从头复算入口另外重新执行全部几何和整数核验。

## 七体整叶对照

原叶 180/24225 也在加入原十一点 \(Q_{11}\) 后完整关闭。单根核验访问 5,282,119 个节点，终端依次为五体 375,679 个、三十点 2,212,876 个、十一点 52,505 个。其中三十点使用新弦帽 1,772,333 次，十一点使用新弦帽 16,008 次。七体采用原根的支撑锚，六体拼接采用原根及其补集闭子树的各自支撑锚。共有的 100 万节点预算回归使用相同原根设置，相关计数见 PROOF.md。

~~~sh
python -I -B replay_three_leaves_083750.py \
  "$COMP" "$TREE" "$TABLE64" "$Q_WORK" "$CACHE" --stage seven
~~~

七体阶段另依赖 COMP 的 multi-host-points.json 和 q11-leaf-bank.json。三叶排除的默认入口使用五体和原六体。

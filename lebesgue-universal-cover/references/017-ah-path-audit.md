# 第17轮：Gibbs Definition 8 的路径圆心兼容性

来源：Philip E. Gibbs, An Upper Bound for Lebesgue’s Covering Problem,
https://arxiv.org/abs/1810.10089 ，PDF第8–10页、图7–8、Definition 8。
本地PDF SHA-256：df420d8754fd888a2adc8a1392d92f4d2f9ef4789adf263437c0afffad48712f。
本轮直接读取PDF第8、10页文本及第9、10页图像；原文全文不归档。

沿第12轮坐标惯例，L(−θ)=G，N(τ)=E3，X(s,t)是以L(s)、N(t)为圆心的两个单位圆的上交点。
设Y=X(θ,τ)，Z=X(0,0)，C=L(θ)。定义立即给出|Y−C|=1。
文献的小斜角路径描述提到以G为圆心的起始圆弧；在本次重建惯例中，该圆心与起点不兼容。
不能静默把原文G替换成C后就宣布原证明已核验；以下仅调查这一候选解释。

## 两条独立计算

标准库双精度几何程序在σ=1.5494°得到
|Y−G|≈0.997886042778567，|Y−C|≈1，|Z−C|≈1.000748547112035。
另外使用mpmath80位精度，从支撑直线交点重新构造F3、E3、G、L和X，不导入双精度几何程序，
重现上述距离及L(−θ)=G。高精度本身不是定向区间证明。

## 候选圆弧—切线路径

取z=Z−C，d²=|z|²>1；两个切点为
T=C+z/d² ± sqrt(d²−1) Jz/d²。
选择距Y较近的切点，沿单位圆从Y到T，再沿线段到Z。
实际切点约(−.008796530568668082,.5599648673599221)，圆弧转角约.009445156556848733弧度。
切线正交残差<7e−17。

对路径点反解L(s)与N(t)：分别与DC、DE直线取单位圆交点，在本区域选择相邻分支，
再由L_x+.5=cos(π/6+s)及t=(N−M)·e_N求回参数。
100、1000、4000段/片三次实际运行中，反解重构残差<6e−16，参数盒越界最大<3e−15。
配对曲线X(−s,−t)两端与P、Z吻合；数值积分的AH面积分别为
.00008152226893072946、.00008151840791874017、.00008151837135541142。
该收敛趋势是数值证据，尚无误差界。

## 尚缺证明

仍须证明参数图像确为指定区域、整个候选路径位于该区域、该路径最短、
反解分支与配对曲线在连续域中有效，并完成orbiform反射放置证明。
若区域局部位于单位圆C外侧，该圆弧—切线是自然的圆障碍测地线候选；
本轮未将采样核对升级成这些解析结论。
没有认定论文错误，没有独立复现最终Gibbs面积，没有得到Λ新上界。

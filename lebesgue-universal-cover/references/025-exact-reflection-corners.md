# 精确反射—角落引理（供 AH 第24轮整合）

固定斜角 `sigma`（弧度），写

```
u(alpha)=(cos(alpha),sin(alpha)),
m_j(sigma)=u(pi/6+sigma+j*pi/3),
m'_j=m_j(-sigma).
```

令 `R` 是过原点、轴角为 `pi/3`（60 度）的反射。对每个方向角，

```
R u(alpha)=u(2*pi/3-alpha).
```

因此，全部等式都在单位法向量层面精确成立：

```
R m'_4
= u(2*pi/3-(pi/6-sigma+4*pi/3))
= u(7*pi/6+sigma)=m_3,

R m'_2
= u(2*pi/3-(pi/6-sigma+2*pi/3))
= u(11*pi/6+sigma)=m_5,

m'_2=u(5*pi/6-sigma)=-u(11*pi/6-sigma)=-m'_5.
```

若相应斜切线写为 `m·x=1/2`，则正交映射 `R` 保持右端常数并将负斜角的
`D'` 切线送至原来的 `E` 切线、将负斜角的 `F'` 切线送至原来的 `C` 切线：

```
m'_4·x=1/2  <=>  m_3·R(x)=1/2,
m'_2·x=1/2  <=>  m_5·R(x)=1/2.
```

原六边形也由 `R` 保持。因此，只要 `K` 避开（闭）`D'`、`F'` 角落，
`R(K)` 避开相应的 `E`、`C` 被切去的角落，并由原构造定义有 `R(K)⊂P`。
此处尚不推出 `R(K)⊂S`；该步仍恰为单独的 Sprague/Lemma-1 依赖。

## C 是 C' 截点

令 `V(x,y)=(-x,y)` 为竖轴反射。几何构造给出

```
C=V(E_3),                  V(DE)=DC,
V(m_3)=m'_5.
```

由于 `E_3` 在 `m_3·x=1/2` 上，便有

```
m'_5·C = (V m_3)·(V E_3)=m_3·E_3=1/2.
```

同时 `C∈DC`。故 `C` 正是 DC 与负斜角 `C'` 截线 `m'_5·x=1/2` 的交点。
这避免把此关键关联只当成图形直觉。第24轮的区间计算已认证
`m'_5·e_L>0`，所以 DC 上严格位于 `C` 的 `e_L` 正方向的点满足
`m'_5·x>1/2`，即处在 `C'` 的严格角落侧。

## 闭 F' 角落的严格排除

采取构造的闭半平面约定

```
C' = {x: m'_5·x >= 1/2},
F' = {z: m'_2·z >= 1/2}.
```

若 DC 接触点 `L_0` 严格在 `C'` 侧，则 `m'_5·L_0>1/2`。对任意闭 `F'`
点 `z`，由 `m'_2=-m'_5` 有 `m'_5·z<=-1/2`。所以

```
m'_5·(L_0-z)>1.
```

因为 `m'_5` 是单位向量，`|L_0-z|>1`。直径至多一的 `K` 不可能同时含有
`L_0` 与任何闭 `F'` 点。这同时覆盖 `F'` 的边界；无需把“未进入内部”错误
加强或在边界上漏掉等号。

`D'` 的闭包由第24轮的纵坐标严格间隔排除：AH 内点 `x` 有
`x_y>259/500`，而闭 `D'` 的每一点有 `y<-62/125`，故 `|x-z|>507/500>1`。

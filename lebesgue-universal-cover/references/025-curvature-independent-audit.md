# 第23轮 AH 局部凸转向审计增补

审计对象来自主工作区第23轮；本文件不修改主工作区。它审计的只是固定
\(\sigma=1.5494^\circ\) 下 AH 替换边界的局部转向，绝不推出整个 Gibbs
覆盖凸性、万能性或面积结论。

## 结论

通过，未发现实质数学漏洞。

- `certify_ah_curvature.py` 以 Python 3.15.0 实际重放并退出0。512个闭参数叶区间连续覆盖 \([0,1]\)，每叶都严格给出
  \(Q'_x<0,Q'_y<0\) 和 \(Q'_xQ''_y-Q'_yQ''_x>0\)。最小曲率分子下界为
  \[
  76087244433328072103/10^{24}>0.
  \]
  因而配对曲线正则、严格正曲率、切线角连续递增。这支持“局部无凹转向”；单凭正曲率不声称整条曲线无自交，原证明也没有这样外推。
- \(Y\) 处，进入的 \(E_3\) 圆弧切向与离开的 \(C\) 圆弧切向的叉积和点积均严格正，故是正向凸角。\(T\) 处圆弧到线段的衔接由切线恒等式给出。
- \(Z\) 处的配对映射可以写为局部坐标图的共轭
  \[\Phi=X\circ(-I)\circ X^{-1}.\]
  在 \(Z\) 的局部逆并非只靠全局同胚断言：第21轮/面积脚本实际使用两条中心线的显式根式逆，且相关根式在该邻域严格正；两圆交点非退化。因此 \(D\Phi_Z=-I\)，从而 \(Q'(0)=Z-T\)，与 \(T\to Z\) 的线段切向一致。
- \(T'\) 处，接触方程的隐式微分分母 \((T-C)\cdot e_L\) 为正，而分子 \((T-C)\cdot(T-Z)=0\)，所以配对的 \(L\) 参数一阶速度为零。这使 \(Q'(1)\) 与 \(G\)-圆相切。实际证书还给
  \[
  Q'(1)\cdot J(T'-G)>0,
  \]
  从而排除反向拼接。

第23轮正文将“雅可比非奇异”归因于第18轮单调性与非退化圆交点。为避免“连续单射未必微分同胚”的误读，建议明确引用上述局部显式根式逆和严格正根式，作为 \(D\Phi_Z=-I\) 的可微前提。现有代码已经实际使用了这个更强事实，因此这是文字补强，不是计算或结论缺口。

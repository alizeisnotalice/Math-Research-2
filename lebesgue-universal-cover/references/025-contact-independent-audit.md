## 结论（截至主工作区 `37dd1af`）

在下列明确前提下，`proofs/024-ah-contact-reflection.md` 的核心接触序及反射排除成立；我没有找到该机制的反例：

1. `K` 的 DC、DE、EF 接触点存在；DC 与 DE 接触点落在论文/构造所给的相应边段；
2. 参数图 `X` 是第20轮所证明的同胚，且 AH 的修剪后 Jordan 域确实是
   `{-theta<s<theta, f(s)<t<tau}`，其中 `f` 连续、严格递增、奇；
3. 第18、20轮的“较小线坐标根”结论用于整个相关直线，而非仅用于物理接触参数恰落在 AH 内；
4. 第3节所用的负斜角角落、镜像和 `P -> S`（Sprague）命题各自另有定义及证明。

特别地，反射后的 DC 参数只能推出 `s_r >= -s_0`，**不能**推出来源文字所称的严格 `s_r<s_0`。第24轮采用的不等式方向足够：

```
t_0 > f(s_0)  =>  -t_0 < f(-s_0) <= f(s_r).
```

因此，当 `s_r<=theta` 时，对反射体应用接触序的逆否命题即可；当其 DC 接触点落在 `C` 的另一侧（形式记作 `s_r>theta`）时，它在每一个 AH 内点的较小 DC 单位距离根之前，直接由距离大于 1 排除。后一个分支不应强行把 `s_r` 拉回参数矩形。

## 可直接使用的量词化补证

令 `q_L` 为 DC 上沿 `e_L` 的仿射坐标，令 `q_N=t` 为 DE 上沿 `e_N` 的坐标。对于任意 AH 内点
`x=X(s,t)`，第20轮的选根结论给出 `L(s)`、`N(t)` 分别是方程
`|x-L|=1`、`|x-N|=1` 的较小根。故

```
|x-L_0|<=1  =>  q_L(L_0)>=q_L(L(s))  =>  s_0<=s,
|x-N_0|<=1  =>  q_N(N_0)>=q_N(N(t))  =>  t_0>=t.
```

这里没有、也不需要断言 `X(s_0,t_0)` 落在 AH 内；事实上它可以在 `R` 的边界。由
`t>f(s)`、`f` 严格递增，严格地得到 `t_0>f(s_0)`。

反射轴为给定的 60 度轴。若 `U=(-1/2,u)` 是 EF 接触点，则直径条件与 DC 上端根
`U(s_0)` 给出 `u<=U_y(s_0)`；故

```
q_L(reflect(U)) <= q_L(L(-s_0)),
```

等价于 `s_r>=-s_0`（`L_x` 随 `s` 严格递减）。同时
`reflect(N(t_0))=N(-t_0)`。将此与前一严格不等式组合，正是上面的反射排除。

## 审计中必须保留/建议显式补上的点

- 第24轮第2节在形式上先假设 `s_0,t_0` 已在完整参数矩形，随后才在第4节从 `K⊂S` 与角落排除推出范围。为避免循环，最好将范围引理移到第2节之前，或把第2节写成上述不依赖参数范围的线坐标版本。
- `C` 是 `C'` 截线与 DC 的交点可用一行精确计算补上。令斜角为 `q`（弧度），
  `a=5*pi/6+q`，`F_3=(-1/2,(1+cos(a))/(2 sin(a)))`，`E_3=R_(pi/3)F_3`，
  `C=(-E_{3x},E_{3y})`，则对于 `n_{C'}=(cos(11*pi/6-q),sin(11*pi/6-q))`，直接三角化简给出
  `n_{C'}·C=1/2`，而 DC 的法向 `n_DC=(1/2,-sqrt(3)/2)` 亦有 `n_DC·C=1/2`。
  `F'` 对侧的单位投影间隔、以及 60 度反射将 `D',F'` 分别送到 `E,C`，同样应给出一行精确坐标/法向计算（或引用已认证的独立引理）。现有 `024` 代码只认证了 `C'` 法向沿 DC 的严格符号，未认证这些等式本身。
- “触 EF/DC/DE”是适用于 orbiform 的独立接触引理，不能从任意直径 `<=1` 的一般 `K⊂S` 自动推出；第24轮已经把它留作前提，应在最终 Proposition 7 链条中明确接上。
- `K*⊂P` 之后得到 `K*⊂S` 仍依赖 Lemma 1/Sprague 论证。第24轮正确地没有把该依赖伪装成已独立完成的结论。

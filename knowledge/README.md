本库是对旧 T 的系统盘点与有来源的经验提炼。它不等于导入全部聊天记忆，也不等于重新认证旧项目数学结论。

阅读顺序：[研究地图](RESEARCH_MAP.md) → [通用方法](METHODS.md) → [失败路线与反例](FAILURES.md) → [工具经验](TOOLS.md)。
来源与实际覆盖见 [来源清单](sources.csv)、[覆盖报告](COVERAGE.md)、[目录盘点](catalogue.csv) 和 [去重摘要](inventory-summary.json)。

## 证据状态约定

- **严格证明（原来源）**：原材料提供证明并如此归档；本次核查其表述和范围，不自动视为本次独立认证。
- **数值证据**：仅对所列输入、参数、精度和实际运行有效。
- **猜想/开放**：尚无完整证明；充分条件尚未证实也归于此。
- **已否定**：原材料有指定断言的反例；必须说明反驳哪一步、是否属于原模型。
- **待核验**：只有陈述、索引或不完整证据；使用前回到原文。

每个经验条目引用 S 编号，解析到 sources.csv 中的相对路径、SHA-256 和阅读层级。
本机旧项目根目录为 `/Volumes/data/CodexProjects/T`。来源可能包含尚未发表内容，默认只公开自写摘要和定位，不复制全文。

# 计算与工具经验

本次实际执行的是目录盘点、SHA-256 去重和配置检查。旧材料中记载的软件版本、核数、算例与误差不计作本轮新运行。

- **精确证书优先保留最小实现**：Python Fraction/整数多项式可提供便携核验；标准库证书与数值搜索分开归档。适用于有限有理对象，不代表连续空间已证明。来源 S07、S13、S16–S18。
- **独立实现要说明独立在哪里**：不同几何组装或积分算法可以共享底层有理库；共享库依赖应披露，不能因“两个软件一致”省略归一化。八维审计在这方面给出清楚示例。S15。
- **高精度不等于区间认证**：浮点根区间、中点舍入为零、容差加倍与严格有向区间证书分列；记录跳过或未定案例，不只统计成功数。S12、S03、S05。
- **预防伪验证**：源码/输入哈希证明运行身份，不能替代并集重算；历史脚本可能覆盖封存输出，只在仓外副本运行。S13–S15。
- **符号验证守住分支**：保留重复极点、零投影、共同时间、分段门槛和端点；完整消去后再积分，不能删除单项的发散。适用范围见 Green 审计 S15。
- **扩大计算要有决策价值**：先定位最坏候选，再增加精度或参数；不要为重复阴性搜索消耗全机资源。资源预算按当前任务和机器可用状态决定，不硬编码旧线程的核数。S22–S23。
- **论文交付独立验收**：编译成功、引用检查、逐页视觉验收、数学审查分列；源文件、PDF 和证据对应同一版本。S09、S16–S18。

# 通用方法经验

这些条目是从旧项目提炼的操作原则；引用具体数学推论仍需逐项检查来源假设。

| 编号 | 方法与适用条件 | 证据状态与限制 | 来源 |
| --- | --- | --- | --- |
| M01 | 开始前锁定对象、量词、原分母和严格门槛；写清一般输入、固定输入族、模型优化各自优化了什么 | 多项目反复出现的范围检查原则，无新增数学定理 | S02、S09、S16–S18 |
| M02 | 同一源/同一见证的约束应贯穿证明；逐接收点或逐切片换最优源时单独计算放松费用 | 旧强极大及欧氏球材料有具体障碍；不能从抽象共同预算直接推出新算子界 | S07、S22–S23 |
| M03 | 将门槛位移、分档数、联合体积、截断尾和累计误差写成同一个账本，再判断是否达到目标精度 | 适用于渐近传播；具体费用必须在当前参数区间重推 | S10、S23 |
| M04 | 有限优化先保留真实几何与共同可行性；需要严格证书时重建有理/区间证书和严格成功余量 | 优化器结果或有限网格不提供连续域全称证明 | S13–S18、S23 |
| M05 | 固定维数、固定层深/固定输入的极限与对维数/层数/输入一致的上确界分开证明 | 条件传递不能反向证明其前提；构造的一侧改进不是精确常数匹配 | S09–S10、S16–S18 |
| M06 | 用反例定位具体失效引理，说明是否真实原模型、是否保留所有归一化，以及原目标是否仍开放 | “局部加强失败”与“原目标被否定”分列 | S05、S07、S08 |
| M07 | 接手先建立来源依赖图与有效状态，不从“审查通过”或来源元数据推出证明已认证 | 题录身份、全文阅读、主张审核、整篇证明及包装完整性分别记录 | S19–S21、S24 |
| M08 | 一轮先做最能改变判断的推导和最小探路，完成后归档必要证据、当前状态和下一条带量词的不等式 | 继承研究组织方法；不默认继承旧项目不停机/资源/模型指令 | S01、S22–S23 |

## 新课题首次套用时

先填 PROJECT 模板，再检查：结论对哪些输入成立？哪一份质量被算了几次？数值范围和定理量词是否一致？已知反例针对当前接口吗？
数学细节在当前课题内证明或精确引用；经验索引不能当作证明附件。
